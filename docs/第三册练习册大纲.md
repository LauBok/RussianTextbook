# 俄语教程 第三册基础练习册大纲

## 定位与编排

本练习册按第三册正课 L01–L60 的顺序编排，集中训练各课讲授的、可以批量操练和机械判分的形式与用法：形动词与被动结构（第一单元）、副动词与无主语句（第二单元）、构词与变格（第三单元）、第六单元的语法疑难点，以及第四单元里格的一处操练（关联词）。全书按知识点分节，节号连续（练习 1、练习 2……），每节以“练习 N　知识点”为标题并标明适用的课，如“练习 1　主动形动词现在时　第 1 课”；节下设若干大题（一、二、三……），大题下是小题（1、2、3……）。只给需要单独练的语法点出题，没有必要单独练的课写“不出题”，不强求每课都有练习。一块知识点讲完以后，紧接着插入一节综合练习，与普通各节一样接着编号，标作“练习 N　综合：形动词与被动结构　第 1–9 课”。第三册每单元的复习课正好排在一块知识点讲完之后，所以 L10、L20、L30 三课的位置都改为本单元的综合；全册最后的 L60 改为全册总复习综合（照第二册 L72）。书末设“教材课号—练习”与“语法细项—练习”两份索引。

第三册不再以变格变位为主线，第四、五单元（句法、语体）的内容多是语序、标点、语气和语体的选择，答案依赖语境，不能拆成可机械判分的单个形式，而且程序判分时忽略标点。因此这两个单元基本不出题，只在 L37 为“指示词与关联词各自的格”设一节（这是一个答案唯一、可以批量操练的变格操作），L36 地点从句的指示词—关联词搭配并入这一节。L19（命令式与假定式的语气）、L29（近义词辨析）、L59（寓言古旧形式）也不出题，理由见逐课表。

## 与教材练习的分工

已核对 `exercises/B3-L01.yaml` 至 `B3-L60.yaml` 的题型及题目要求。第三册教材练习以写作为主线，每课固定有：理解问答（open）、句中填形式（fill，5–8 题，如“用括号里动词的主动形动词现在时填空”）、改写（rewrite：[кото́рый]{.ru} 从句 ↔ 形动词短语、从句 ↔ 副动词短语、主动 ↔ 被动、人称句 ↔ 无人称句、肯定 ↔ 否定、动词结构 ↔ 名词结构）、选择（choice，4–6 题）、中译俄、缩写或作文；第三单元起有构词填空，第六单元多一组新词填空；复习课是多组选择、填空、改写和翻译。练习册不把这些题型换一批词后再整组重复，也不设置课文理解、翻译、整句改写、缩写、作文。逐课表中的“覆盖细项”记录需要练熟的内容，不直接作为题面要求；具体呈现以“练习册形式”列为准。

| 教材已有的做法 | 练习册的处理 |
| --- | --- |
| 句中填一个形动词、副动词或派生词 | 改为由动词（来源词）到目标形式的构成矩阵，词项扩到 14–20 个，必要时带中间形式列（复数第三人称、过去时阳性）；句中填空只作每节最后一步，换用教材没有的词 |
| 整句改写（从句 ↔ 短语、主动 ↔ 被动、动词 ↔ 名词结构） | 不设整句改写；只抽出其中一个步骤做成矩阵或关系标注表（“名词（格已定）+ 从句 → 形动词的形式”“副动词 + 主句 → 从句谓语”“动词词组 → 名词词组”），不能改的行写“—” |
| 选择题（形式、体、前置词、语义） | 改为意义对应表：给出已变好的形式或完整短句，按意义或类别归栏（classify），不在同一句里同时选形式、构成和判断语义 |
| 复习课多组选择 | 复习课改为综合，综合以矩阵、归栏和单点核查为主 |

形动词、副动词和派生词的构成必然要求写出词形，但通过批量结构与系统覆盖形成分工。优先采用以下形式：

| 形式 | 学生操作 | 用途 |
| --- | --- | --- |
| 构成矩阵 | 一行一个动词或来源词，横向写出中间形式和目标形式 | 形动词、副动词、短尾、派生词的构成；行按构成类型依次分组排列（组名不印），最后混排 |
| 并列对照栏 | 同一来源词并列写两三种已学形式 | 主动 / 被动形动词、形动词 / 副动词（[-ся / -сь]{.ru}）、两体的副动词、人名 / 城市名的第五格、[по]{.ru} + 第六格 / [по́сле]{.ru} + 第二格 |
| 词组配合矩阵 | 固定目标格，把修饰语与名词组合写出词组 | 形动词 + 名词、外来词 + 形容词、数词 + 形容词 + 名词、复合前置词 + 名词 |
| 关系标注表 | 给出被说明的名词（格已定）和从句还原句、主句与从句、或主体与谓语，只写该用的形式 | 形动词与 [кото́рый]{.ru} 的互换、副动词与从句的互换、指示词与关联词的格、无人称句的主体 |
| 意义对应表 | 给出已变好的形式或短句，归入意义栏 | 副动词的意义、否定中的体、前缀的非运动意义、否定宾语的格、[в тече́ние / во вре́мя]{.ru} |
| 单点核查表 | 表中有正确及错误形式，学生标出错误并只改错的部分 | 构成、一致、重音与固定写法；用在综合和易错点，不是每节必设 |

构成矩阵与关系标注表是主体，对照、核查和意义表按语法需要使用，不要求每课轮流出现所有形式。逐课编写前须比较对应教材的具体小题：若目标操作和呈现均已重复，优先改为跨词项或跨形式的矩阵；仍无新增训练价值时省略该组。

## 练习设计

### 大题的层次

每个大题只要求一个明确操作，例如“写出下列动词的主动形动词现在时”“写出与名词一致的形动词”或“按意义把句子归栏”。形式训练与意义选择分别编排。一节之内大题之间要有区别，通常按三步走：

1. 先分类型练：按构成类型分组排列词项（如同一组都是复数第三人称 [-ут]{.ru} 的动词），组名不印，类型不在题面点明。
2. 再混合判断：类型混排，或者先归栏判断（classify），再写形式（matrix）。
3. 再放进词组或句子：被说明的名词、前置词或支配词已给出，只写目标形式；需要语义辨别时改用意义对应表。

不要求每节都经历同样的三步，也不固定每节题量。新授构成类型可先安排 14–20 个不同词项，跨类型混合安排 20–30 个词项，作为首轮题量参考；特殊类型按常用词数量安排（[ше́дший]{.ru}、[бу́дучи]{.ru}、[-йти]{.ru} 类副动词、只有复数的名词等只有几个常用词的，不凑数）。优先覆盖常用词及不同构成、拼写和重音类型，不为凑数量加入罕见词。句子的辅助词汇保持简单，不能带入尚未讲授的形式。

体、副动词的意义、否定宾语的格、[в тече́ние / во вре́мя]{.ru}、[благодаря́ / из-за́ / несмотря́ на]{.ru} 等选择必须提供足以确定答案的语境；有多个合理答案时须列明，不能仅依靠一个时间词判断。课文说明“两种理解都对”的（副动词的时间 / 原因、阴性名词前形容词的复数第一 / 第二格、[со́здана / создана́]{.ru}、[скуча́ть по вас / по вам]{.ru}），答案全部列出。

本练习册不设置朗读、听辨、语体改写、语序和标点训练（程序判分时忽略标点，标点只能在 classify 里按“正确 / 有误”归栏，且只在 L07 使用一次）。综合练习先按训练点分别检测，再安排混合矩阵或单点核查表。答案按练习编号编排；规则题按练习解释规则，特殊形式逐项说明，语义选择题解释当前语境。书末诊断表将错题对应到具体训练点及可回练的练习。

### 题面不泄露答案

本节规则优先于本大纲其他地方与之冲突的写法。题面只说“做什么、写成什么形式”，不说“怎么变”。学生应当自己判断词属于哪一类、用哪个后缀或词尾、要不要换格。

- `task` 只写操作和目标形式：“写出下列动词的主动形动词现在时。”“写出下列动词的副动词。”“写出下列名词的复数第二格。”“用括号里的词填空。”“写出与名词一致的形动词。”
- 不写：词尾、后缀或变化方法（“去掉 [-т]{.ru} 加 [-щий]{.ru}”“先写出复数第三人称再变”“[-нн-]{.ru} 改成 [-н-]{.ru}”“[е]{.ru} 脱落”“[г]{.ru} 变 [ж]{.ru}”）；词的类别（“第二变位动词”“完成体及物动词”“以辅音结尾的外来词”“按字母读的缩略词”）；选择条件（“[кото́рый]{.ru} 是第一格时用主动形动词”“先发生的动作用完成体”“主语不同时不能用副动词”“注意形动词和被说明的名词一致”“注意性、数、格”）；错误类型（“形动词和名词的格不一致”“构成时用了将来时词干”）。
- 大题之间仍然按难度分层（先单一类型、再混合、再进入词组和句子），但分层只体现在选词上，`task` 不点明类型；同一节里各大题的 `task` 靠操作和形式区分（如“写出形动词”“写出与名词一致的形动词（词组）”“用括号里的词填空”“改正错误”），必要时加“（词组）”“（句中）”这类中性字眼。同一节里两个大题的 `task` 可以完全相同，不加（一）（二）。
- `hint` 只给推不出来的东西：新词的性和释义、第二变位或有交替的新动词的 [я / ты]{.ru} 形式、不规则的过去时阳性（[вы́рос, у́мер]{.ru}）、按课文须“逐词记”的形式（新词的指小后缀、人称名词后缀、形容词后缀、无后缀名词、只有复数名词的第二格、[-ь]{.ru} 结尾外来词的性）。已讲规则能推出的不提示（复数第三人称、交替、体、及物与否、能不能构成某种形动词或副动词）。
- 表头 `cols`、分类栏 `bins` 写语法名称没关系（“复数第三人称”“被动形动词过去时”“完成体副动词”“第二格”“性质形容词”），那是题目本身要求的形式或类别；但中间形式列（复数第三人称、过去时阳性、单数第一人称）只在每节首个构成矩阵里出现，后面的大题撤去。
- 解析 `why` 照旧写规则和易错点，那是答案部分。
- 有些词项本身没有目标形式（完成体没有现在时形动词，[писа́ть]{.ru} 没有被动形动词现在时和副动词，不及物动词没有被动形动词，[кото́рый]{.ru} 间接格的从句不能换成形动词），表里照常列出，学生自己判断后写“—”，题面不预先印“—”。

### 新词规则

新词可以放开使用，条件是目标形式能按已学规则推出。第三册每课新词约 50 个，各课生词表和第一、二册的累计词表都可以直接用；表外的词按以下处理：

- 动词：第一变位 [-ать / -ять]{.ru} 规则动词可直接用；第二变位新词、有辅音交替的第一变位新词给出 [я / ты]{.ru} 形式（复数第三人称、单数第一人称交替由它们推出）；过去时不规则的新词给出阳性过去时；体对新词给出另一体。没有某种形动词或副动词的动词只用课文列出的（[писа́ть, пить, брать, ждать]{.ru}；[ждать, есть, петь, мочь, бежа́ть, е́хать]{.ru}），其他新词不用来考“没有”。[-ать / -ять]{.ru} 动词构成 [-т-]{.ru} 被动形动词的只用课内的 [нача́ть, заня́ть]{.ru}。

### 书写与重音

第三册课文不标重音，但练习册照第一、二册标重音：题面、`hint`、`gloss` 以外的俄语、答案、`accept` 和解析里的多音节俄语词一律标重音（组合重音符 U+0301），单音节词不标；ё 一律写出。所有俄语放在 `[…]{.ru}` 里。构成或变格引起重音移动时，答案完整标出（[сыно́к — сынка́]{.ru}，[решён — решена́]{.ru}，[продаве́ц — продавца́]{.ru}，[написа́ть → напи́санный]{.ru}，[гля́дя, сто́я, держа́]{.ru}，[лю́бящий]{.ru}）。课文说“查词典”的重音（第二变位形动词、未完成体副动词）不在题面提示，答案标出；判分程序忽略重音，学生写不出重音不算错，但答案必须标全。本文件是规划文档，表中俄语也标重音，用检索用词形，不作为学生题面直接排版。

### 版面规则

版面要紧凑：

- 一对一的变形题排两到三栏，每个小题写成“前置词 ＿＿（原形）”这样的一行，括号里只写原形，没学过的词再加中文释义和性；前置词、支配词或被说明的名词印在空线前面，不进括号。
- 答题空线按手写长度留：每个字母约 3 mm，最短 24 mm、最长 70 mm，同一大题的空线一样长；脚本按最宽一格自动选三栏、两栏或一栏。形动词、副动词的空线一般按 12–15 个字母留。句中填空的空线 26–45 mm，短句排两栏。
- 多列矩阵（中间形式、格、形动词类型、性数）只在需要同时写几个形式时使用：序号列 6%，原形列 22%，其余各列等宽，同一节的格表、构成表列宽一致，便于对照竖读。待填列以 4–5 列为限；词组矩阵（形动词 + 名词、数词 + 形容词 + 名词、前置词短语）待填列不超过 3 列，四个格的词组表拆成两个大题或改为“行 = 格”。
- 关系标注表的题干（被说明的名词 + 从句还原句、副动词短语 + 主句）占一行，不折成两行；题干超过一行的改排一栏。
- 归栏题（classify）词项行内连排，栏目表在下面，栏高按每栏词项数留写字格。
- 书末答案用紧凑列表，不重画表格：一对一题写成连排的“1. … 2. …”，多列矩阵每行一条、两栏排。

### 撑满页面

每节练习另起一页，最后一页不留大片空白：空出四分之一页以上时，先给最后一道大题加小题（矩阵加行、填空加题），仍不够再加一道大题补满，补的大题只练本节已有的形式（通常是“放进词组或句子”的填空或单点核查），不引入新知识点。逐课表里写“版面不满时加……”的，就是预先选好的补页大题。`python3 tools/workbook.py --book 3` 排版后会列出最后一页空得多的节；只溢出几行的节脚本自动分两级收紧行距重排，不必删题。

## 索引与编写清单

学生看到的练习编号在构建时按出现顺序自动生成，不写进源文件；源文件里每个大题有内部 id，便于引用和修改。综合练习记录所回收的原练习。细项标签应细到可单独回练，例如“主动形动词现在时：构成”“被动形动词过去时：[-енн-]{.ru} 与交替”“短尾被动形动词：数量主语”“形动词与 [кото́рый]{.ru}：不能互换的情况”“完成体副动词：[-йти]{.ru} 类”“副动词的意义：条件”“[не хвата́ть]{.ru}”“指小表爱：[-ок]{.ru} 的变格”“外来词：不变格名词的性”“姓氏：[-ов, -ин]{.ru} 混合变格”“[по]{.ru} + 第六格”，不只使用“形动词”“构词”等大类。

练习清单记录：适用课号、内部 id、对应教材已有题型与避重处理、目标操作、构成或变化类型、已学规则范围、新增词及提示、词项数量、答案类型、对应综合练习。语法索引按细项汇集新授与综合位置；教材索引按课列出可做的练习，不出题的课注明“见练习 N（综合）”或“本练习册不设”，L36 注明“见练习 N（第 36–37 课）”。

全书共 4 节综合，分别排在 L10、L20、L30、L60 之后，都是复习课改成的综合，L60 为全册总复习（第六单元各点只在这里回收）。不出题的课：L19、L29、L59（语气、近义词、古旧形式），第四单元 L31–L36、L38–L40（L36 并入 L37 一节），第五单元 L41–L50；L10、L20、L30、L60 四课自身不出普通题，由综合代替。其余 34 课（L01–L09、L11–L18、L21–L28、L37、L51–L58）各成一节，加上 4 节综合，全书共 38 节。

第三册按“已学范围”表逐课放开形动词、副动词和各类构词与变格。不提前使用第四册才讲的内容；不把语序、标点、语气和语体做成填空或矩阵。某课形式上无新规则时，可以少设题，集中练该课的核心形式或回收既有规则。

## 实现格式

- 每课一个文件 `workbook/B3-L01.yaml`，存本课的练习，`groups` 列表顺序即大题顺序；综合练习单独一个文件 `workbook/<课号>-综合.yaml`（`workbook/B3-L10-综合.yaml`、`B3-L20-综合.yaml`、`B3-L30-综合.yaml`、`B3-L60-综合.yaml`），排在该课之后。不出题的课不建文件；L36 不建文件，它的内容在 `B3-L37.yaml` 里，该文件顶层 `lessons: [B3-L36, B3-L37]`。
- 文件顶层写 `heading`（普通节“第 1 课　主动形动词现在时”，综合“综合练习　形动词与被动结构”，构建时去掉前缀作节标题）；综合文件另写顶层 `lessons`，列出全部回收的课。
- 每个大题写内部 `id`（普通 `B3-L01-01`、`B3-L01-02`……；综合 `B3-L10-综合-a`、`-b`……）、`lessons`（普通练习 `[B3-L01]`，综合列出回收的课）、`task`（一个明确操作和目标形式，不提示做法，见“题面不泄露答案”）、`type`、`tags`（细项标签，供语法索引）、`why`（解析，按“第 N 题：……”写，相同解析构建时自动合并）；综合练习另写 `recycles`，列出回收的原练习 id。
- 学生看到的“练习 N”在构建时按顺序自动编号；标题显示为“练习 1　主动形动词现在时　第 1 课”“练习 10　综合：形动词与被动结构　第 1–9 课”或“练习 29　指示词与关联词　第 36–37 课”。
- 题型只用四种：
  - `matrix`：构成、变格或关系标注矩阵。`cols` 为列名（如复数第三人称、形动词现在时、第二格、谓语），`given` 标出已填好的示范列（默认第 0 列），`rows` 每行写 `base`、`cells`（按列给答案，不存在的形式写“—”，可选 `accept`）、`hint`（只给推不出来的东西）、新词的 `new: true` 与 `gloss`。只有一列待填时自动排成两到三栏的“前置词 ＿＿（原形）”。单点核查也用 `matrix`：`base` 是含错误的词组或短句，`cells` 是改正后的部分，原本正确的行写原形式。
  - `classify`：分栏归类。`bins` 为栏目（如可换主动形动词 / 可换被动形动词 / 不能换；时间 / 原因 / 条件 / 方式伴随 / 让步），`items` 每项写 `text` 和 `answer`（所属栏目），两可的项 `answer` 写成列表，新词同样加 `new` / `gloss`。
  - `fill`：句中填空。`items` 每项写 `stem`（空位写 `___`）、`hint`、`accept`。
  - `choice`：只用于必须给出完整语境的语义选择、且教材该课没有同一选择题时；`items` 写 `stem`、`options`、`answer`。本大纲的逐课规划没有用到，编写中确有需要时再用。
- 不用 `rewrite`、`translate`、`open`。
- `tools/exercises.py` 已有这几种题型的答案与判分（忽略重音、ё/е、大小写和标点，同教材）；`tools/workbook.py` 排版 PDF，书末答案按练习编号编排。
- `tools/check.py` 的 workbook 模式按第一、二册规范检查第三册练习册：多音节俄语词全部标重音（不沿用第三册课文“不标重音”的规则）、ё、`[…]{.ru}` 标记；标 `new: true` 的词须有 `gloss`，未标的词须在第三册当课累计词表（含第一、二册）内；`tags` 只能用语法索引里已有的细项。
- 构建：`python3 tools/workbook.py --book 3` 生成 `dist/第三册练习册.pdf`（正文、书末答案），并报告最后一页空得多的节；分段样稿 `python3 tools/workbook.py --book 3 L1 L20`，输出到 `build/`。网页另作第三册练习册首页，与第三册课页互相链接。

## 校核要求

出题前按目标课逐项确认训练点已经讲授，对照“已学范围”表核对形动词、副动词的类型和各类构词、变格是否已经放开，尤其核对交替、重音移动、没有某种形式的动词和逐词记的派生。出题后对照教材该课和第二册练习册的相关小题（第二册 L14、L55、L57、L61、L62、L67–L69、L71），检查目标操作与呈现是否重复，再检查题面是否泄露答案（`task` 没有写方法、类别、条件和错误类型，`hint` 只给推不出来的东西）、词项覆盖、语境是否足够、答案是否唯一或已列出全部可接受形式；检查混合题和补满页面的大题没有额外引入新语法。正式题目、答案和解析中的俄语按教材字体与第一、二册重音规范处理，ё 写出。
