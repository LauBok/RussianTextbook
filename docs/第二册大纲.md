# 俄语教程 第二册 课程大纲

## 总体结构

第二册从 A2 起步，目标达到 B1（ТРКИ 一级），新增词汇约 1000，累计约 2300。全册 72 课，分 8 个单元，每单元 8 课新授课加 1 课复习，每单元最后一课为复习与单元测试。

| 项目 | 数量 |
| --- | --- |
| 新授课 | 64 |
| 复习课 | 8 |
| 每课新词 | 约 16 |
| 课文长度 | 200–300 词 |
| 对话与叙述 | 约 1 : 2 |

**语法覆盖**：名词、形容词、代词复数各格的全部变格；不规则复数；比较级与最高级；短尾形容词；动词体的系统用法；辅音交替与特殊变位；带前缀的运动动词及其转义；以 кото́рый、что́бы、пока́、е́сли бы、хотя́ 等引导的复合句；数词变格；不定代词与否定代词；直接引语与间接引语的转换；构词初识。形动词和副动词只在第八单元认识形式，系统讲解留给第三册。

**故事线**：接第一册，王磊二月回到莫斯科，继续住在彼得罗夫家，读第二学期。新增人物 Ди́ма（王磊的俄罗斯同学）。故事按月份推进：二月开学，三四月春天，五月假期去喀山和伏尔加河，六月考试周，七月放暑假回国。各单元的俄罗斯知识尽量与当月的节日和季节对应。

## 每课构成

结构沿用第一册，有三处变化：

1. 不再单列语音·语调。重音移动、读音例外等放进课文注释或生词注音。
2. 缩写成为每课必做的练习。第一至二单元按问题把课文压成 50–80 词的一段；第三单元起增加作文（100–150 词）；第五单元起增加书信写作。
3. 课文以叙述为主，对话嵌在叙述中。

每课顺序：课前问题 → 课文 → 生词和短语 → 课文注释 → 俄罗斯知识 → 语法 → 练习 → 参考译文。

生词标注规则、重音规则和编写约束与第一册相同。

练习答案与解析、语法篇幅的原则同第一册：答案附在全册末尾，封闭题有解析，缩写和作文有参考范文；语法讲解不限长度。
