# 俄语教程 第一册基础练习册大纲

## 定位与编排

本练习册按第一册正课 L01–L100 的顺序编排，集中训练每课已经讲授的形式和基本用法。全书练习连续编号（练习 1、练习 2……），每个练习标明适用的课，如“第 11 课”。只给需要单独练的语法点出题，没有必要单独练的课或语法点不出题，不强求每课都有练习。一块知识点在几课里讲完以后，紧接着插入一个综合练习，与普通练习一样接着编号，标作“综合：第 11–19 课”，把这一块分散在各课的内容合起来练。单元复习课同样按需出普通练习，侧重跨知识块混合，不重复刚做过的块内综合。书末设“教材课号—练习”与“语法细项—练习”两份索引。

本大纲已核对第一册课程大纲及全部 100 课“语法”节的小标题；包括课程大纲总表未逐项列出的次要语法点。以下为编写规划，实际出题时还须核对对应课的规则、例词和讲解范围。

## 与教材练习的分工

已核对 exercises/L01.yaml 至 L100.yaml 的题型及题目要求。教材普遍已有选择、句中填词形、句子改写、问答、中译俄、课文理解及开放写作；练习册不把这些题型换一批词后再整组重复，也不设置课文理解、翻译、对话、缩写和作文。逐课表中的“覆盖细项”记录需要练熟的内容，不直接作为题面要求；具体呈现以“练习册形式”列为准。

基础变格变位训练必然仍要求写出词形，但通过批量结构与系统覆盖形成分工。优先采用以下形式：

| 形式 | 学生操作 | 用途 |
| --- | --- | --- |
| 词形矩阵 | 同一行给一个原形，横向写出本课已学的若干性数、人称或时态形式 | 将孤立词形集中到完整的已学形式系统；不提前出现未学列 |
| 分类型词项栏 | 每栏集中一个词尾或词干类型，直接写目标形式；最后一栏混合类型 | 用足量不同单词练同一操作；不嵌入句子同时判断格 |
| 并列对照栏 | 同一词项并列写两种已学形式，圈出发生变化的部分 | 动物性、性数、地点与方向、普通动词与 -ся 形式等对照 |
| 词组配合矩阵 | 固定目标格，将多个修饰语与多类名词交叉组合并写出词组 | 扩展词汇与组合覆盖；同一组只练指定格的共同变化 |
| 单点核查表 | 表中有正确及错误形式，学生标出错误并只修正目标部分 | 检查词尾、词干、重音与配合；不是每课必设的花样题 |
| 意义对应表 | 给出已变好形式的简短材料，标注过程、结果、反复、单向等明确意义 | 单练语义辨别，不同时做变位、造句或长段阅读 |
| 关系标注表 | 给出所有者、说话者、转述者或补语关系，标出所指、格或需要变化的成分 | 单练指代、支配及转述的一个步骤，不要求整句改写 |

词项栏与矩阵是主体，对照、核查和意义表按语法需要使用，不要求每课轮流出现所有形式。逐课编写前须比较对应教材的具体小题：若目标操作和呈现均已重复，优先改为跨词项或跨形式的矩阵；仍无新增训练价值时省略该组。固定表达较多、可扩展词形较少的课不出题，以免为了逐课对齐重复教材。

## 练习设计

每个练习只要求一个明确操作，例如“变成指定格”“按给定主语变位”或“根据明确情境选择动词体”。形式训练与意义选择分别编排。通常先按变化类型分栏，再混合类型；需要辨别意义时另设意义对应表；不要求每课都经历同样的步骤，也不固定每课题量。

新授变化类型可先安排 12–20 个不同词项，跨类型混合安排 20–30 个词项，作为首轮题量参考；特殊类型按常用词数量安排。优先覆盖常用词及不同词尾、拼写和词干类型，不为凑数量加入罕见词。新增词附中文释义与完成本题所需的性、重音、变位类别或词干提示。句子的辅助词汇保持简单，新增名词或动词不能带入尚未讲授的变化规则。词形变化会引起重音移动时，在答案中完整标出。

新词可以放开使用，条件是词形能按已学规则推出：第一变位 -ать / -ять 规则动词、已学词尾类型的名词与形容词都可直接用；第二变位新词给出单数第一、第二人称（交替与重音由这两个形式体现），其余形式可推。真正要避免的是尚未讲授的特殊变化：词干变化的第一变位（писать 类在 L14 之后、-овать / -авать 类在讲授之后才可用）、隐现元音、重音移动、不规则复数等；确需使用时在题面给出决定性形式（如第二格或第二人称）作为提示。-ь 结尾名词标性。每个新词附中文释义，在题中标 `new: true` 和 `gloss`；检查脚本按此标记放行，不另设词表。

词形题可给出目标格、目标性数或变位类型，以集中训练形式；后续练习再撤去提示。单纯形式题不要求学生同时猜词义、判断句意和选择语法类别。动词体、运动动词、所有关系及前置词选择必须提供足以确定答案的语境；有多个合理答案时须列明，不能仅依靠一个时间词判断。

本练习册不设置语音入门、字母书写、朗读或听辨练习。正式题目与答案中的多音节俄语词仍按教材规范标重音并保留 ё。

综合练习和单元复习先按训练点分别检测，再安排混合词形矩阵或单点核查表。答案按练习编号编排；规则题按练习解释规则，特殊形式逐项说明，语义选择题解释当前语境。书末诊断表将错题对应到具体训练点及可回练的练习。

## 索引与编写清单

学生看到的练习编号在构建时按出现顺序自动生成，不写进源文件；源文件里每个练习有内部 id，便于引用和修改。综合练习与复习课记录所回收的原练习。细项标签应细到可单独回练，例如“名词单数第六格：-ия / -ие”“第二变位：第一人称辅音交替”“过去时：阴性重音”，不只使用“变格”“动词”等大类。

练习清单记录：适用课号、内部 id、对应教材已有题型与避重处理、目标操作、变化类型、已学规则范围、新增词及提示、词项数量、答案类型、对应综合练习。语法索引按细项汇集新授与综合位置；教材索引按课列出可做的练习。

第一册仅系统训练名词、形容词和相关代词的单数六格及名词主格复数。数量表达中复数第二格只用教材已给出的 человек、часов、рублей、минут、лет 五个形式（L28、L35、L39、L47、L53），其他名词与 5 以上数词连用的题不出；不提前加入复数各格的系统训练、其他运动动词前缀、形动词、副动词。某课形式上无新规则时，可以少设题，集中练该课固定表达或回收既有规则。

## 实现格式

- 每课一个文件 `workbook/<课号>.yaml`，存本课的练习，列表顺序即出现顺序；综合练习单独一个文件 `workbook/<课号>-综合.yaml`（如 `workbook/L19-综合.yaml`），排在该课之后。不出题的课不建文件。
- 每个练习写内部 `id`（如 `L19-a`、`L19-综合-a`）、`lessons`（适用的课：普通练习 `[L19]`，综合练习列出全部回收的课）、`task`（一个明确操作）、`tags`（细项标签，供语法索引）；综合练习另写 `recycles`，列出回收的原练习 id。结构沿用 `exercises/FORMAT.md`。
- 学生看到的“练习 N”在构建时按顺序自动编号；标题显示为“练习 14　第 19 课”或“练习 15　综合：第 11–19 课”。
- 题型沿用教材已有的 `fill`、`choice`、`rewrite`，另加两种：
  - `matrix`：词形矩阵。`cols` 为目标形式（如六个人称、四种性数、六个格），`rows` 每行给原形和提示，`cells` 按列给答案，可选 `accept` 列可接受形式；`given` 标出已填好的示范格。
  - `classify`：分栏归类。`bins` 为栏目（如阳性／阴性／中性、过程／结果），`items` 为词项或短语，答案为所属栏目。
- `tools/exercises.py` 扩展这两种题型：PDF 排成表格（矩阵每格留写字位置），书末答案按练习编号编排，网页逐格判分（忽略重音、ё/е、大小写，同教材）。
- `tools/check.py` 加 workbook 模式：俄语重音、ё、`[…]{.ru}` 标记；标 `new: true` 的词须有 `gloss`，未标的词须在当课累计词表内；`tags` 只能用语法索引里已有的细项。
- 构建：`python3 tools/book.py --workbook 1` 生成 `dist/第一册练习册.pdf`（正文、书末答案、两份索引）；网页另作一个练习册首页，与教材课页互相链接。

## 校核要求

出题前按目标课逐项确认训练点已经讲授，尤其核对特殊词尾、词干变化与重音。出题后对照教材具体小题，检查目标操作与呈现是否重复，再检查词项覆盖、语境是否足够、答案是否唯一或已列出可接受形式；检查混合题没有额外引入新语法。正式答案中的俄语按教材字体与重音规范处理。本文件是规划文档，表中俄语名称采用检索用词形；不作为学生题面直接排版。
