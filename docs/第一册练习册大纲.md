# 俄语教程 第一册基础练习册大纲

## 定位与编排

本练习册按第一册语音入门 P1–P8、正课 L01–L100 的顺序编排，集中训练每课已经讲授的形式和基本用法。每课内部按具体操作分组，单元复习课回收本单元训练点，并适量加入此前内容。书末设“教材课号—练习组”与“语法细项—练习组”两份索引。

本大纲已核对第一册课程大纲及全部 100 课“语法”节的小标题；包括课程大纲总表未逐项列出的次要语法点。以下为编写规划，实际出题时还须核对对应课的规则、例词和讲解范围。

## 题组设计

每组只要求一个明确操作，例如“变成指定格”“按给定主语变位”或“根据明确情境选择动词体”。形式训练与意义选择分别编排。通常先按变化类型分组，再混合类型，最后放入短句；不要求每课都经历同样的步骤，也不固定每课题量。

新授变化类型可先安排 12–20 个不同词项，跨类型混合安排 20–30 个词项或短句，作为首轮题量参考；特殊类型按常用词数量安排。优先覆盖常用词及不同词尾、拼写和词干类型，不为凑数量加入罕见词。新增词附中文释义与完成本题所需的性、重音、变位类别或词干提示。句子的辅助词汇保持简单，新增名词或动词不能带入尚未讲授的变化规则。词形变化会引起重音移动时，在答案中完整标出。

词形题可给出目标格、目标性数或变位类型，以集中训练形式；后续题组再撤去提示。单纯形式题不要求学生同时猜词义、判断句意和选择语法类别。动词体、运动动词、所有关系及前置词选择必须提供足以确定答案的语境；有多个合理答案时须列明，不能仅依靠一个时间词判断。

语音部分以辨认、书写和朗读为主；听辨题需要另配音频，未配音频时不设置听音作答。多音节俄语词在正式题目与答案中按教材规范标重音并保留 ё。

单元复习先按训练点分别检测，再安排少量混合题。答案按课与题组编排；规则题按组解释规则，特殊形式逐项说明，语义选择题解释当前语境。书末诊断表将错题对应到具体训练点及可回练题组。

## 索引与编写清单

每个正式题组使用稳定编号，例如 L11-01、L11-02；复习课保留自己的编号，并记录所回收的原训练点。细项标签应细到可单独回练，例如“名词单数第六格：-ия / -ие”“第二变位：第一人称辅音交替”“过去时：阴性重音”，不只使用“变格”“动词”等大类。

题组清单记录：课号、题组编号、目标操作、变化类型、已学规则范围、新增词及提示、词项数量、答案类型、对应复习题组。语法索引按细项汇集新授与复习位置；教材索引按课列出可做题组。

第一册仅系统训练名词、形容词和相关代词的单数六格及名词主格复数。数量表达中按课文范围使用少量复数第二格；不提前加入复数各格的系统训练、其他运动动词前缀、形动词、副动词。某课形式上无新规则时，可以少设题，集中练该课固定表达或回收既有规则。

## 校核要求

出题前按目标课逐项确认训练点已经讲授，尤其核对特殊词尾、词干变化与重音。出题后检查词项覆盖、语境是否足够、答案是否唯一或已列出可接受形式；检查混合题没有额外引入新语法。正式答案中的俄语按教材字体与重音规范处理。本文件是规划文档，表中俄语名称采用检索用词形；不作为学生题面直接排版。
