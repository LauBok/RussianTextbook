# 第四册编写说明（各单元通用）

本仓库（RussianTextbook）。你负责第四册的一个单元，写 7 课新授课（复习课以后由主会话安排，你不写）。各单元同时开工。全部写完再汇报，中途不要停下来问。

## 一、先读
1. CLAUDE.md（编写规范，以它为准）。
2. docs/第四册大纲.md：选文、文体与修辞主题、练习都按大纲。
3. 格式样板：第三册定稿课 lessons/B3-L52.md、B3-L57.md 及 exercises/B3-L52.yaml、B3-L57.yaml；exercises/FORMAT.md。
4. 前三册词表就是已学词：用 `python3 tools/check.py <课号>` 判断某词学没学过。

## 二、每课文件与结构
- lessons/B4-Lxx.md + exercises/B4-Lxx.yaml。
- front matter：
  ```
  ---
  book: 俄语教程 第四册
  unit: 第N单元 <大纲单元名：短篇小说 / 诗歌与散文诗 / 长篇与回忆录 / 现代语体 / 经典名著>
  lesson: 课号数字
  title: 俄语标题（不标重音；诗歌课标重音）
  subtitle: 大纲里的中文题目
  source: original   # 原著选文写这一行；第四单元编写组撰写的不写
  ---
  ```
- 结构：`## 课前问题`（`::: question`）→ `## 选文`（第四单元编写组撰写的课文用 `## 课文`；散文 `::: {.prose lang="ru"}`；诗歌 `::: {.poem lang="ru"}`，内用 pandoc 行块 `| ` 逐行、诗节之间空行，首行 `[作者]{.author}`，末行 `[年份]{.year}`）→ `## 作者与作品简介`（100–200 字；第四单元写 `## 文本说明`，介绍文体和写作情境）→ `## 生词和短语`（`::: vocab` + `::: names`）→ `## 课文注释`（`::: notes`）→ `## 文体与修辞`（可分 ###）→ `<!-- EXERCISES -->` → `## 参考译文`（散文 `::: prose-zh`；诗歌逐行直译用 `::: {.poem-zh}` 加行块，行数与原诗对应）。
- 不写 speakers，不要 scene.svg。

## 三、俄语书写
- 散文选文、注释、练习不标重音；生词表标重音（U+0301，多音节都标）。诗歌全文标重音（用于格律分析）。ё 一律写出。
- 所有俄语放 `[…]{.ru}` 里（`lang="ru"` 块内除外）。中文引号全角“”。汉字不用斜体。成品里不写面向编者或读者的旁白。

## 四、生词与注释
- 生词表只收进入积极词汇的核心词，一般约 57 个；专业性强的文章可以多些，不设硬上限。格式同第三册（名词性、gen.、形容词四词尾、动词 impf./pf. + 变位类型 + 一二人称、支配）。旧词新义写“新义：……”。
- 原著里的生僻词、古旧词、方言词不进生词表，在“课文注释”里随文解释：注释条目写成 `**[词形]{.ru}** 解释`。check.py 对原著课把注释里出现的词也算“已解释”。
- 专有名词放 `::: names`（标重音）。

## 五、文体与修辞
分析选文里一到两个有代表性的语言手段，例句一律取自本课选文，注明位置（第几段 / 第几行）。诗歌课给完整的格律分析：每行音步划分、韵式、诗节结构（表格），练习答案里给全划分；另加朗读训练（停顿、重音、语调提示）。

## 六、练习（YAML，格式见 FORMAT.md）
每课 5–8 题：理解问答（open）；词汇释义——用俄语解释俄语（translate 或 open，accept/model 收全合理答法）；概要写作（open，把选文压缩到约 150 词，length 写 130–170）；作文（open，250–300 词）；多项选择（choice）。可加 fill、rewrite。封闭题写 why（题号、词与题目对得上）；每题只有一个正确答案；概要和作文给 model、rubric、notes（注明范文大约多少词）。练习里的俄语不标重音（诗歌课引诗句可标）。YAML 字符串含逗号冒号加引号。

## 七、参考译文
编写组自己翻译，不得照抄或改写已出版的中译本。散文译成通顺的现代汉语，尽量贴近原文句式；诗歌逐行直译、不押韵，行数与原诗对应。

## 八、事实
作者与作品简介、注释里的事实（生卒年、成书年代、人名、地名）登记到 facts 文件（路径见任务说明），格式 `| 课:行 | 内容 | 依据 |`，能联网就查证附链接；查不到可靠依据的改成概括说法。

## 九、检查
每课跑 `python3 tools/check.py B4-Lxx`、`python3 tools/stress.py B4-Lxx`（处理生词表、诗歌重音的报告）、`python3 tools/exercises.py B4-Lxx > /dev/null`。各单元并行，允许留下的问题只有：“重复”且先列的是别的单元的课；“提前使用”且后列的是别的单元的课。其余清零。

## 十、限制
只改你单元的课号文件和你的登记文件；不改 tools/、docs/、CLAUDE.md、别的课；不执行 git 命令；不删 img/ 下文件。

## 汇报（简短）
每课：选文/文本词数、生词数、check 剩余问题；没把握的事实；偏离大纲之处。

## 十一、原文来源（原著单元必读）
- 每篇原著必须先下载原文，不得凭记忆写出或“复原”。首选 ru.wikisource.org：`curl -s "https://ru.wikisource.org/w/index.php?title=<页面名URL编码>&action=raw"` 取维基源码（页面名可先用 `https://ru.wikisource.org/w/api.php?action=opensearch&search=<词>&format=json` 或 `action=query&list=search` 查）；其次 ilibrary.ru（标明版本的现代正字法本）。feb-web.ru、lib.ru 目前不通。
- 原文全文（或所选章节全文）去掉维基标记后存 sources/B4-Lxx.txt，文件开头注明：作者（生卒年）、作品、所据版本（维基页面里的 ИСТОЧНИК）、网址。来源登记写进 facts 文件旁的 sources 登记（路径见任务说明），格式 `| 课 | 作者（生卒年） | 作品 | 所据版本 | 网址 |`。
- 找不到可靠版本的篇目不要写，在汇报和登记里列出“待用户提供”，跳过这一篇。
- 删节处用 `<…>` 标出；保留部分一字不改（词句、标点都照原文），只做两件事：旧字母换现代正字法（ѣ→е、і→и、词末 ъ 删去），按 CLAUDE.md 写出 ё；原文里的旧词形（如 одинокой、скрыпит）保留，在注释里说明。诗歌另加重音。
- 散文节选 600–1000 词，选一个相对完整的段落；诗歌全文。
