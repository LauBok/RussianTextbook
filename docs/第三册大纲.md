# 俄语教程 第三册 课程大纲

## 总体结构

第三册从 B1 起步，目标达到 B2（ТРКИ 二级），新增词汇约 2700，累计约 5000。全册 60 课，分 6 个单元，每单元 9 课新授课加 1 课复习。

| 项目 | 数量 |
| --- | --- |
| 新授课 | 54 |
| 复习课 | 6 |
| 每课新词 | 约 50 |
| 课文长度 | 400–600 词 |

**语法覆盖**：四种形动词及短尾被动形动词；两种副动词；被动结构；无人称句、不定人称句与泛指人称句；构词法（名词、形容词后缀，动词前缀的非运动意义，指小表爱后缀，复合词与缩略词）；简单句语序与实义切分；插入语与独立成分；各类主从复合句与无连接词复合句；准直接引语；五种语体。

**课文题材**：不再沿用故事线，每课是一篇独立短文，按单元分为人物、地理、语言、历史、社会、文学六个主题。文学单元为经典作品的改写本，词汇和句法控制在本册范围内。课文本身就以俄罗斯社会和文化为内容，所以第三册不再单设“俄罗斯知识”一节。

**历史与社会题材**：只陈述事实和各方通行的说法，不做评价。

## 每课构成与写作训练

每课顺序：课前问题 → 课文 → 生词和短语 → 课文注释 → 语法 → 练习 → 参考译文。

练习以写作为主线，题型按课选择：理解问答、词汇释义、关键句型、难点辨析、缩写或作文、多项选择。

**写作进程**

| 单元 | 写作训练 | 长度 |
| --- | --- | --- |
| 一 | 段落缩写：把课文压缩成一段 | 120–150 词 |
| 二 | 缩写 + 句式改写（形动词短语、副动词短语与从句互换） | 120–150 词 |
| 三 | 按给定主题句写段落 | 150 词 |
| 四 | 叙述段落：按时间顺序叙述一段历史 | 150–200 词 |
| 五 | 应用文：申请书、简历、新闻消息、正式书信 | 按文体 |
| 六 | 议论段落：对作品或现象表达看法并说明理由 | 200 词 |

练习答案与解析、语法篇幅的原则同第一册：答案附在全册末尾，封闭题有解析，缩写和作文有参考范文；语法讲解不限长度。

## 第一单元 人物（L1–10）

人物传记适合引入形动词：描述人的经历和成就时，形动词短语自然而频繁。语法核心是四种形动词、短尾被动形动词和被动结构。

| 课 | 课文 | 语法 |
| --- | --- | --- |
| L1 | 罗蒙诺索夫：从渔村到莫斯科大学 | 主动形动词现在时：-ущ-, -ющ-, -ащ-, -ящ- |
| L2 | 门捷列夫与元素周期表 | 主动形动词过去时：-вш-, -ш- |
| L3 | 加加林：第一个进入太空的人 | 被动形动词现在时：-ем-, -им- |
| L4 | 普希金的最后一年 | 被动形动词过去时：-нн-, -ённ-, -т- |
| L5 | 特列季亚科夫和他的画廊 | 短尾被动形动词：постро́ен, со́здан |
| L6 | 柴可夫斯基 | 形动词短语与 кото́рый 从句的互换 |
| L7 | 巴甫洛夫与条件反射 | 形动词的变格与位置 |
| L8 | 乌兰诺娃 | 形容词化与名词化的形动词：бу́дущий, учёный, отдыха́ющие |
| L9 | 科罗廖夫与苏联航天 | 被动结构：-ся 动词、短尾形动词、不定人称句 |
| L10 | 复习 | 形动词总表；单元测试 |

## 第二单元 地理（L11–20）

游记和地理描写适合引入副动词：旅途中的连续动作常用副动词短语串联。语法核心是副动词和各类无主语句。

| 课 | 课文 | 语法 |
| --- | --- | --- |
| L11 | 贝加尔湖 | 未完成体副动词：-я, -а |
| L12 | 伏尔加河：俄罗斯的母亲河 | 完成体副动词：-в, -вши |
| L13 | 圣彼得堡的白夜 | 副动词短语与从句的互换 |
| L14 | 喀山：两种文化交汇的城市 | 副动词表示的时间、原因、条件、方式 |
| L15 | 堪察加的火山 | 固化为前置词或副词的副动词：благодаря́, несмотря́ на, су́дя по |
| L16 | 西伯利亚大铁路上的七天 | 无人称句（系统）：не хвата́ет, удало́сь, ну́жно |
| L17 | 摩尔曼斯克与北极光 | 不定人称句与泛指人称句 |
| L18 | 索契与黑海海岸 | 否定与体：не на́до звони́ть 与 не позвони́л |
| L19 | 符拉迪沃斯托克：太平洋上的港口 | 命令式与假定式的语气差别 |
| L20 | 复习 | 副动词总表；单元测试 |

## 第四单元 历史（L31–40）

按时间顺序讲述俄罗斯历史上的十个节点。历史叙述句子长、结构复杂，适合系统讲解句法。

| 课 | 课文 | 语法 |
| --- | --- | --- |
| L31 | 基辅罗斯与 988 年受洗 | 简单句的语序与实义切分 |
| L32 | 莫斯科公国的兴起 | 同等成分与概括词 |
| L33 | 彼得一世与圣彼得堡的建立 | 插入语：коне́чно, по-мо́ему, во-пе́рвых |
| L34 | 1812 年卫国战争 | 独立成分：同位语与独立形动词短语 |
| L35 | 1861 年废除农奴制 | 复合句的标点 |
| L36 | 1917 年 | 地点、程度、方式从句：где, так … что, насто́лько … что |
| L37 | 列宁格勒围困 | 关联词：тот, кто；то, что；там, где |
| L38 | 航天时代 | 无连接词复合句 |
| L39 | 1991 年苏联解体 | 直接引语、间接引语与准直接引语 |
| L40 | 复习 | 句法总表；单元测试 |
