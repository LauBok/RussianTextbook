# 第四册插图清单

第四册每课至多配一张彩色插图，复习课（B4-L08、L16、L24、L32、L40）不配。构建时插图自动放在“作者与作品简介”右侧（印刷版右侧半栏、文字绕排，网页版占整行）；第四单元的现代语体课没有“作者与作品简介”，插图放在课文第一段右侧。图片按文件名放进 `img/B4-Lxx/` 即可，不用改课文。构建脚本识别 `*GPT.*` 和 `*PD.*` 两种后缀，每课只取一张。

选图原则：

- 作家肖像只用公有领域的真实画像或照片，不用 AI 生成。同一作家出现在多课时，肖像只用一次，其他课改用作品插图或场景。
- 作品插图、名画用 Wikimedia Commons 上的公有领域原作（后缀 `PD`）。下面每个 PD 文件都已用 Commons API 核对过：文件存在，`LicenseShortName` 为 Public domain，`Copyrighted` 为 False；缩略图（宽 1600 像素，原图不足 1600 的取原图）已下载到本地。
- 只有场景、风物类才用 GPT 生成（后缀 `GPT`）。统一要求：写实摄影风格，横幅 3:2（1536×1024），画面里不出现任何文字、招牌、字母和数字；不画真实人物的肖像；画面内容与该课选文一致；真实地标、建筑按提示词里写明的结构特征画。
- 第四单元（现代语体）只给有具体场景的课配图，访谈、演讲、合同、广告四课不配。
