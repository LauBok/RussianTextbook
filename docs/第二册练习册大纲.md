# 俄语教程 第二册基础练习册大纲

## 定位与编排

本练习册按第二册正课 L01–L72 的顺序编排，集中训练每课已经讲授的形式和基本用法。全书按知识点分节，节号连续（练习 1、练习 2……），每节以“练习 N　知识点”为标题并标明适用的课，如“练习 1　名词复数第二格（一）　第 1 课”；节下设若干大题（一、二、三……），大题下是小题（1、2、3……）。只给需要单独练的语法点出题，没有必要单独练的课或语法点写“不出题”，不强求每课都有练习。一块知识点在几课里讲完以后，紧接着插入一节综合练习，与普通各节一样接着编号，标作“练习 N　综合：名词复数各格　第 1–2、10–13 课”，把这一块分散在各课的内容合起来练。单元复习课一般不出题（各块已在综合里回收）；单元最后一块恰好在复习课前讲完时，复习课的位置改为这一块的综合。书末设“教材课号—练习”与“语法细项—练习”两份索引。

## 与教材练习的分工

已核对 `exercises/B2-L01.yaml` 至 `B2-L72.yaml` 的题型及题目要求。第二册教材每课固定有：句中填词形（fill，5–9 题）、选择（choice，4–8 题）、改写（rewrite：变复数、合并句子、换说法、直接—间接引语互换）、中译俄、缩写；第三单元起加作文，第五单元起加书信；复习课是多组选择与填空。练习册不把这些题型换一批词后再整组重复，也不设置课文理解、翻译、改写、缩写、作文和书信。逐课表中的“覆盖细项”记录需要练熟的内容，不直接作为题面要求；具体呈现以“练习册形式”列为准。

| 教材已有的做法 | 练习册的处理 |
| --- | --- |
| 句中填一个词形（“用括号里的词的复数第六格填空”） | 改为按词尾类型分栏的词形矩阵，词项扩到 12–20 个；句中填空只作每节最后一步，且每题只练一个形式、换用教材没有的词 |
| 选择题（体、[что / что́бы]{.ru}、定向 / 不定向、前缀） | 改为意义对应表：给出已变好的形式，按意义归栏（classify），不在同一句里同时选形式、变位、判断语义 |
| 改写（单数句改复数句、两句合并、事实改 [е́сли бы]{.ru}、主动改被动、直接改间接） | 不设整句改写；只抽出其中一个步骤做成矩阵或关系标注表（如“先行词 + 从句还原句 → [кото́рый]{.ru} 的形式”“原话命令式 + 从句主语 → [что́бы]{.ru} 后的过去时形式”） |
| 复习课多组选择 | 复习课一般不出题；需要时改为综合，综合以矩阵和归栏为主 |

基础变格变位训练必然仍要求写出词形，但通过批量结构与系统覆盖形成分工。优先采用以下形式：

| 形式 | 学生操作 | 用途 |
| --- | --- | --- |
| 词形矩阵 | 同一行给一个原形，横向写出本课已学的若干格、人称或时态形式 | 将孤立词形集中到完整的已学形式系统；不提前出现未学列 |
| 分类型词项栏 | 每栏集中一个词尾或词干类型，直接写目标形式；最后一栏混合类型 | 用足量不同单词练同一操作；不嵌入句子同时判断格 |
| 并列对照栏 | 同一词项并列写两种已学形式，圈出发生变化的部分 | 单数—复数、动物—非动物、复数第三格—单数第五格、定向—不定向、肯定—否定命令等对照 |
| 词组配合矩阵 | 固定目标格，将修饰语与名词组合并写出词组 | 复数词组、数量词组、[са́мый]{.ru} + 形容词 + 名词、度量词词组 |
| 单点核查表 | 表中有正确及错误形式，学生标出错误并只修正目标部分 | 检查词尾、词干、重音与配合；用在综合和易错点，不是每课必设 |
| 意义对应表 | 给出已变好形式的简短材料，归入结果、过程、反复、事实、单向、往返、真实、非真实等栏 | 单练语义辨别，不同时做变位、造句或长段阅读 |
| 关系标注表 | 给出主语、所指、动作者、说话者或从句还原句，标出所指、格或该用的形式 | 单练 [себя́]{.ru}、[свой]{.ru}、[кото́рый]{.ru}、不定式 / [что́бы]{.ru}、转述人称中的一个步骤，不要求整句改写 |

词项栏与矩阵是主体，对照、核查和意义表按语法需要使用，不要求每课轮流出现所有形式。逐课编写前须比较对应教材的具体小题：若目标操作和呈现均已重复，优先改为跨词项或跨形式的矩阵；仍无新增训练价值时省略该组。没有可批量训练的词形、只是连接词或语气选择的课不出题，以免为了逐课对齐重复教材。

## 练习设计

### 大题的层次

每个练习只要求一个明确操作，例如“变成复数第三格”“按给定主语写出 [что́бы]{.ru} 后的过去时形式”或“按意义把句子归栏”。形式训练与意义选择分别编排。一节之内大题之间要有区别，通常按三步走：

1. 先分类型练：按词尾、变位或构成类型分栏，每栏一个类型（如“硬变化名词复数第六格（-ах）”“软变化（-ях）”）。
2. 再混合判断：类型混排，或者先归栏判断类型（classify），再写形式（matrix）。
3. 再放进句子或词组：前置词、动词或数词已给出，只写目标形式；需要语义辨别时改用意义对应表。

不要求每课都经历同样的三步，也不固定每课题量。`task` 写清本大题的重点和类型，如“阴性零词尾名词变复数第二格（去掉 [-а]{.ru}；词末两辅音之间插 [о]{.ru} 或 [е]{.ru}）”，不写成笼统的“填空”。

新授变化类型可先安排 12–20 个不同词项，跨类型混合安排 20–30 个词项，作为首轮题量参考；特殊类型按常用词数量安排（不规则复数、[-чь]{.ru} 动词等只有几个常用词的，不凑数）。优先覆盖常用词及不同词尾、拼写和词干类型，不为凑数量加入罕见词。句子的辅助词汇保持简单，新增名词或动词不能带入尚未讲授的变化规则。词形变化会引起重音移动时，在答案中完整标出（[сестра́ — сёстры — сестёр]{.ru}，[хожу́ — хо́дишь]{.ru}）。

词形题可给出目标格、目标形式或变位类型，以集中训练形式；后续练习再撤去提示。单纯形式题不要求学生同时猜词义、判断句意和选择语法类别。动词体、运动动词（定向 / 不定向、前缀）、[что / что́бы]{.ru}、[-то / -нибудь]{.ru}、[из-за́ / благодаря́ / от]{.ru} 等选择必须提供足以确定答案的语境；有多个合理答案时须列明，不能仅依靠一个时间词判断。

本练习册不设置朗读、听辨、语体改写和形动词、副动词的构成练习。正式题目与答案中的多音节俄语词一律标重音（第二册规范），并保留 ё。

综合练习先按训练点分别检测，再安排混合词形矩阵或单点核查表。答案按练习编号编排；规则题按练习解释规则，特殊形式逐项说明，语义选择题解释当前语境。书末诊断表将错题对应到具体训练点及可回练的练习。

### 新词规则

新词可以放开使用，条件是词形能按已学规则推出：第一变位 [-ать / -ять]{.ru} 规则动词、已学词尾类型的名词与形容词都可直接用；第二变位新词给出单数第一、第二人称（交替与重音由这两个形式体现），其余形式可推。真正要避免的是尚未讲授的特殊变化；确需使用时在题面给出决定性形式作为提示：

- 名词：复数第一格不规则或重音移动的（[-а́]{.ru} 复数如 [города́]{.ru}、[учителя́]{.ru}，重音移动如 [сёстры]{.ru}）给出复数第一格，第三、五、六格由它推出；隐现元音不按第 2 课规则插入的（[окно́ → о́кон]{.ru}、[сестра́ → сестёр]{.ru}）给出复数第二格；[-ь]{.ru} 结尾名词标性；[-а]{.ru} 结尾的阳性名词标 m。
- 动词：[-овать / -евать]{.ru}、[-ава́ть]{.ru} 类第 32 课起可直接用，此前给出 [я / ты]{.ru} 形式；第一变位有辅音交替的（[писа́ть]{.ru} 类）一律给 [я / ты]{.ru}；体对新词给出另一体；完成体特殊变位（[дать, сесть]{.ru} 等）给将来时 [я / ты]{.ru}。
- 运动动词只用已讲的八对和已讲前缀的组合（见下表），不自行构成未学的前缀动词。

每个新词附中文释义，在题中标 `new: true` 和 `gloss`；检查脚本按此标记放行，不另设词表。

### 版面规则

版面要紧凑：

- 一对一的变形题排两到三栏，每个小题写成“前置词 ＿＿（原形）”这样的一行，括号里只写原形，没学过的词再加中文释义和性；前置词或支配词印在空线前面，不进括号。
- 答题空线按手写长度留：每个字母约 3 mm，最短 24 mm、最长 70 mm，同一大题的空线一样长；脚本按最宽一格自动选三栏、两栏或一栏。句中填空的空线 26–45 mm，短句排两栏。
- 多列矩阵（人称、格、时态、前缀）只在需要同时写几个形式时使用：序号列 6%，原形列 22%，其余各列等宽，变位表、格表的列宽一致，便于对照竖读。待填列以 4–5 列为限；词组矩阵（三词词组、数量词组、介词短语）待填列不超过 3 列，六个格的词组表拆成两个大题或改为“行 = 格”。
- 归栏题（classify）词项行内连排，栏目表在下面，栏高按每栏词项数留写字格。
- 书末答案用紧凑列表，不重画表格：一对一题写成连排的“1. … 2. …”，多列矩阵每行一条、两栏排。

### 撑满页面

每节练习另起一页，最后一页不留大片空白：空出四分之一页以上时，先给最后一道大题加小题（矩阵加行、填空加题），仍不够再加一道大题补满，补的大题只练本节已有的形式（通常是“放进句子”的句中填空或单点核查），不引入新知识点。`python3 tools/workbook.py --book 2` 排版后会列出最后一页空得多的节；只溢出几行的节脚本自动分两级收紧行距重排，不必删题。

## 索引与编写清单

学生看到的练习编号在构建时按出现顺序自动生成，不写进源文件；源文件里每个大题有内部 id，便于引用和修改。综合练习记录所回收的原练习。细项标签应细到可单独回练，例如“名词复数第二格：零词尾与隐现元音”“形容词复数：拼写规则”“前缀运动动词：[за-]{.ru} 与前置词”“[что́бы]{.ru}：不定式与过去时形式”，不只使用“变格”“动词”等大类。

练习清单记录：适用课号、内部 id、对应教材已有题型与避重处理、目标操作、变化类型、已学规则范围、新增词及提示、词项数量、答案类型、对应综合练习。语法索引按细项汇集新授与综合位置；教材索引按课列出可做的练习，不出题的课注明“见练习 N（综合）”。

第二册按“已学范围”表逐课放开复数各格、数词变格和前缀运动动词；不提前加入第三册才系统讲的形动词与副动词构成、未学前缀的运动动词（[унести́, внести́, перевезти́]{.ru} 等）和带前缀的 [нести́ / вести́]{.ru} 转义。某课形式上无新规则时，可以少设题，集中练该课的核心形式或回收既有规则。

## 实现格式

- 每课一个文件 `workbook/B2-L01.yaml`，存本课的练习，`groups` 列表顺序即大题顺序；综合练习单独一个文件 `workbook/<课号>-综合.yaml`（如 `workbook/B2-L09-综合.yaml`、`workbook/B2-L13-综合.yaml`），排在该课之后。不出题的课不建文件。
- 文件顶层写 `heading`（普通节“第 1 课　名词复数第二格（一）”，综合“综合练习　名词复数第二格”，构建时去掉前缀作节标题）；综合文件另写顶层 `lessons`，列出全部回收的课。
- 每个大题写内部 `id`（普通 `B2-L01-01`、`B2-L01-02`……；综合 `B2-L09-综合-a`、`-b`……）、`lessons`（普通练习 `[B2-L01]`，综合列出回收的课）、`task`（一个明确操作，写清重点）、`type`、`tags`（细项标签，供语法索引）、`why`（解析，按“第 N 题：……”写，相同解析构建时自动合并）；综合练习另写 `recycles`，列出回收的原练习 id。
- 学生看到的“练习 N”在构建时按顺序自动编号；标题显示为“练习 14　名词复数第三格　第 11 课”或“练习 15　综合：名词复数各格　第 1–2、10–13 课”。
- 题型用四种：
  - `matrix`：词形矩阵。`cols` 为列名（如人称、格、时态、前缀），`given` 标出已填好的示范列（默认第 0 列），`rows` 每行写 `base`、`cells`（按列给答案，可选 `accept`）、`hint`（性、格、前置词等提示）、新词的 `new: true` 与 `gloss`。只有一列待填时自动排成两到三栏的“前置词 ＿＿（原形）”。
  - `classify`：分栏归类。`bins` 为栏目（如可数 / 不可数、结果 / 过程 / 反复），`items` 每项写 `text` 和 `answer`（所属栏目），新词同样加 `new` / `gloss`。
  - `fill`：句中填空。`items` 每项写 `stem`（空位写 `___`）、`hint`、`accept`。
  - `choice`：只用于必须给出完整语境的语义选择，且教材该课没有同一选择题时；`items` 写 `stem`、`options`、`answer`。
- 不用 `rewrite`、`translate`、`open`。
- `tools/exercises.py` 已有这几种题型的答案与判分（忽略重音、ё/е、大小写，同教材）；`tools/workbook.py` 排版 PDF，书末答案按练习编号编排。
- `tools/check.py` 的 workbook 模式按第二册规范检查：多音节俄语词全部标重音、ё、`[…]{.ru}` 标记；标 `new: true` 的词须有 `gloss`，未标的词须在第二册当课累计词表内；`tags` 只能用语法索引里已有的细项。
- 构建：`python3 tools/workbook.py --book 2` 生成 `dist/第二册练习册.pdf`（正文、书末答案），并报告最后一页空得多的节；分段样稿 `python3 tools/workbook.py --book 2 L1 L18`，输出到 `build/`。网页另作第二册练习册首页，与第二册课页互相链接。

## 校核要求

出题前按目标课逐项确认训练点已经讲授，对照“已学范围”表核对复数各格、数词变格和前缀运动动词是否已经放开，尤其核对特殊词尾、隐现元音、词干变化与重音。出题后对照教材该课的具体小题，检查目标操作与呈现是否重复，再检查词项覆盖、语境是否足够、答案是否唯一或已列出可接受形式；检查混合题和补满页面的大题没有额外引入新语法。正式答案中的俄语按教材字体与重音规范处理。本文件是规划文档，表中俄语名称采用检索用词形；不作为学生题面直接排版。
