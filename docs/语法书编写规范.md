# 《俄语语法》编写规范

《俄语语法》是《俄语教程》的配套参考语法，按语法体系编排，供学这套教程的中文母语自学者查阅，也能脱离教程单独使用。范围以教程四册讲过的全部语法为底线，按体系补齐 C1 读者需要的内容。大纲见 `docs/语法书大纲.md`，术语见 `docs/语法书术语.md`，教程语法点及课号见 `docs/语法书-教程语法点索引.md`。

## 一、规范依据

1. 形态和用法以《Русская грамматика》（АН СССР，1980，简称 РГ-80）为准。
2. 重音以扎利兹尼亚克《Грамматический словарь русского языка》为准。写完一章运行 `python3 tools/stress.py grammar` 核对；报出的不一致逐条判定：词典里的同形异义词、词典另收的读法可以保留，其余改正。
3. 规范有变体的，写明哪个是标准形式（标准语中性形式），哪个是口语、专业用语或旧式，如 [в о́тпуске]{.ru}（标准）/ [в отпуску́]{.ru}（口语）、[тра́кторы]{.ru}（标准）/ [трактора́]{.ru}（口语、专业用语）。两种都属标准的写“两可”，并说明有无倾向。
4. 与教程的关系：
   - 术语、格的名称（第一格……第六格）、调型名称（ИК-1…ИК-5）、词类缩写和生词标注体例与教程一致。
   - 教程为循序渐进做的简化，这里给出完整规则，但不能与教程矛盾：把完整规则讲全，使教程的说法成为其中的一部分或一个特例。不写“教程只讲了……”之类的话，教程讲到哪里由节末课号体现。
   - 发现教程讲错的地方，记进 `docs/语法书-教程勘误.md`（文件、行号、问题、依据），不改教程文件，语法书里按正确的写。

## 二、编、章、节

1. 全书分编、章、节三级，分层编号：编用汉字序号（第三编）；章在编内编号（第三编第 2 章）；节写成“编.章.节”，如 §3.2.1（第三编第 2 章第 1 节），供交叉引用。跨编提到某章时写“第七编第 3 章”，同一编内可以只写“第 3 章”。编、章、节的划分和节号以大纲为准；写作中需要增删节时先改大纲，不在章内自行编号。
2. 一章一个源文件，放在 `grammar/` 下，文件名为“编号-章号-章名.md”，如 `grammar/03-02-名词单数变格.md`（编号、编内章号各两位数字），排版时按文件名排序。文件开头写 front matter：

   ```yaml
   ---
   part: 3
   part_title: 名词
   chapter: 2
   title: 名词单数变格
   ---
   ```

3. 章内可以先写一段不带节号的导语（几句话，说明本章讲什么、与哪几章相关），然后是各节。节标题写成 `## §3.2.2 阳性名词的变格`。节下的小标题用 `###`、`####`，不编号。

## 三、每节的结构

每节依次包括下列五部分（某部分确实没有内容时省略，不写空标题）。小标题用 `### 形式`、`### 意义和用法`、`### 常见错误`；例句随规则出现，不单设小标题；教程课号写在节末。

a. **形式**：先给完整的变格表或变位表，所有形式标重音，例外列全。表格是“完整的”：不因为教程只讲了一部分就只列一部分。例外形式不写“等”，要列全；数量很多的（如几十个词）列在附录的总表里，本节写明“全部见附录某表”并给出最常用的。

b. **意义和用法**：难点不限篇幅。讲清规则怎样得出（形式之间的关系、规则背后的道理）、每条规则管什么（适用范围、条件、例外）。规则之间有先后或覆盖关系的写明。俄汉表达不同的地方专门说明，如汉语用副词“了”“过”表示的意思在俄语里由体承担。

c. **例句**：每条规则至少两句，句句附汉译。

d. **汉语母语者常见错误**：错句前加 `*`，给出改正和原因。只写中文母语者真会犯的错误，不编造不自然的错误。

e. **教程对应课号**：节末一行，列出教程中讲这一点的课号。

## 四、写法

1. 规则用平实的陈述句。不用“定理”“引理”“规则一”式的包装，不写“非常重要”“一定要牢记”之类的宣传腔。
2. 术语首次出现（全书第一次，以及每章第一次）时附俄语原名：`[第二格]{.term}（[роди́тельный паде́ж]{.ru}）`。术语只用 `docs/语法书术语.md` 里的叫法；需要新术语时先加进术语表，各章并行写作时不各自起名。
3. 讲到别的节已讲的内容，写“见 §3.2.2”，不重复讲。
4. 成品里不写面向编者或读者的旁白（“本节将介绍……”“读者请注意……”“下面我们来看……”）。
5. 数字、单位、标点照教程：中文全角标点、全角引号“”；俄语内部用俄语标点（[«…»]{.ru}、[—]{.ru}）。

## 五、例句

1. 标准、自然，母语者会这样说。不为凑规则造生硬的句子。
2. 讲 A1、A2 内容的节（大纲里标为基础的节）尽量用第一册词汇；讲高级内容的节可以用全部四册的词汇和常用词。
3. 不从受版权保护的现代作品摘句。经典作家（1951 年以前去世）的名句可以引，注明作者。谚语、俗语可以用。
4. 例句中要说明的形式加粗：`[Я чита́ю **кни́гу**.]{.ru}`。

## 六、书写与标记

1. 所有俄语放进 `[…]{.ru}`，多音节词一律标重音（组合重音符 U+0301），单音节词不标；ё 一律写出（ё 不再加重音符）。词尾、后缀等词素写成 `[-а]{.ru}`、`[-ость]{.ru}`，不标重音；需要表示重音落在词尾时写 `[-а́]{.ru}`。
2. 读音写法与教程相同：用西里尔字母转写，写成 `[[…]]{.tr}`，如 [[цъ]]{.tr}、[[шн]]{.tr}、[[каво́]]{.tr}（[[а]]{.tr} 表示重音前第一音节弱化的 [о, а]{.ru}，[[ъ]]{.tr} 表示其余位置的弱化元音），不放进 `{.ru}`；国际音标只在讲元音弱化的一节对照时出现。
3. 汉字不用斜体。强调用粗体。
4. 交叉引用：正文里直接写 `§3.2.2`、`§3.2.2–§3.2.5`，构建时生成链接；引用的节必须在大纲里存在（`tools/check.py grammar/` 会查）。
5. 索引标记：
   - 俄语词索引：`[кни́га]{.ru .ix}`。词条按去掉重音的原形排序；变化形式要归到原形下时写 `[кни́ге]{.ru .ix key="кни́га"}`。每节只标讲解的主要词（规则的典型词、例外词），例句里的普通词不标。
   - 术语索引：`[第二格]{.term}`，标在定义或主要讲解处，文字必须与术语表里的中文术语完全一致。
6. 块：
   - 变格表、变位表：

     ```
     ::: paradigm
     | 格 | 阳性 | 中性 | 阴性 |
     |---|---|---|---|
     | 第一格 | [стол]{.ru} | [окно́]{.ru} | [ко́мната]{.ru} |
     :::
     ```

     第一栏是格名或人称，其余栏的每一格都是俄语。表前用一句话说明表的内容。
   - 例句：

     ```
     ::: ex
     [У меня́ нет **бра́та**.]{.ru}

     [我没有兄弟。]{.gloss}
     :::
     ```

     一个 `::: ex` 里可以放几句，俄语和汉译各占一段，交替排列。
   - 常见错误：

     ```
     ::: err
     \*[Я ви́жу Москва́.]{.ru}　→　[Я ви́жу **Москву́**.]{.ru}

     及物动词的直接补语用第四格。
     :::
     ```

     错句前的星号写成 `\*`。
   - 教程课号：

     ```
     ::: course
     教程：第一册 L22、L23；第二册 L13
     :::
     ```

     课号写法：第一册写 L01–L100、语音课写 P1–P8；第二至四册写“第二册 L01”（不写 B2-）；连续的写 L01–L03。教程没讲、本书补出的内容写“教程：未讲”。
7. 写完一章运行：
   - `python3 tools/check.py grammar/`（重音、ё、{.ru} 标记、§ 引用、术语）；
   - `python3 tools/stress.py grammar`（重音位置）；
   - `python3 tools/grammar_book.py`（生成 `dist/俄语语法.pdf`，含目录、书签、§ 链接、俄语词索引和术语索引）。
