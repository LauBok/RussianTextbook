# 试卷审题标准

《第一册试卷》（`exams/`）写完或改完后，按本标准逐套审一遍。程序检查（`tools/check.py`、`tools/exam.py --check`）只能发现拼写、重音、格式和重复这类表面问题，结果只作参考；一套卷好不好，按下面的标准由人判断。

## 一、目的

读者是自学者，没有老师。一套卷要让他知道：从第 1 课到这个单元学过的东西，哪些真会了，哪些没会。

所以一道题的价值只看一点：**真会的人做对，不会的人做错。**会背课文、会套词尾、会猜题，但不会用的人，不应该拿到分。

## 二、逐题审：以考生身份做一遍

每道题都假装自己是考生做一遍，先回答一个问题：**这道题想考什么？做对它，靠的是不是这个本事？**

题目本身考什么都可以：考词形、考搭配、考读懂全文，都是正当的考法。毛病在于题目想考的和实际考到的对不上，考生能绕过它想考的东西拿分。下面这些是常见的绕过办法，审题时用来找毛病，不是一条条打勾的规则，要结合这道题的目的判断：

- **完形填空想考读懂文章，结果只看本句就能做。**个别空就近取材是正常的，但如果大多数空都不用读全文，这篇完形就没考到阅读。
- **语法题想考规则，结果看词尾一致就能选对。**比如前后的形容词已经给出了格和数，照着抄词尾就行，用不着知道该用哪个格。真正考规则的题，要求考生自己判断：前置词要求哪个格，该用哪个体，用定向还是不定向。
- **题目要考的是运用，结果记得课文就能答。**课文的情节、原句、人物，都能让人不靠理解就答对。
- **题目要求或标题替考生做了判断。**比如“选择正确的体”“在下面的词后加 -ы”。考点本身就是要考生自己看出来的东西。
- **不止一个答案说得通。**母语者会接受的答案都算，不只看教材规则。这条一定要改。

另外再看三点：

- **干扰项像不像真错误？**只学了一半的人会不会被它吸引，比如混淆 уметь / мочь / знать，混淆定向和不定向动词，混淆第四格和第六格。一眼就能排除的干扰项等于没有。
- **答案的依据在不在卷子里？**阅读、完形的答案要能从文中确定，不能靠常识或课文背景。
- **解析能不能教会人？**要讲清为什么选这个、其余几个错在哪里，并注明课号，方便回去复习。

## 三、整卷审：考到了该考的没有

逐题审过以后，整套卷还要回答下面四个问题。

### 1. 考点覆盖

对照 `docs/第一册大纲.md`，列出考试范围内的语法重点。第一册主要有：
- 格：第一格到第六格的用法和词尾，与前置词的搭配；
- 动词：变位，过去时、将来时，体的选择；
- 运动动词：定向与不定向，带 по- 的；
- 数词与名词连用、时间和日期的表达；
- 物主代词、指示代词、人称代词各格；
- 命令式、无人称句、复合句。

再列出常用词和交际用语。然后在卷子里逐项找出考到它的题，单选、完形、语法填空、翻译都算。

- **本单元的新内容**必须考到，而且要考得深：不只考形式，还要考在什么情境下用。
- **以前各单元的重点**要有一定的复现。越基础、越容易忘、越常出错的，越要考，比如格的选择、体、运动动词。
- **漏掉的重点**要补题。补题时换掉考得重复、价值不大的题，不靠加题凑。
- **同一个考点考了好几次、别的重点却没考**，说明分配不当，要调整。

覆盖的判断依据是内容，不是数量。不规定“语法题几道、词汇题几道”。

### 2. 能力搭配

一套卷要同时测出下面几种能力。每种都要有题，具体分配看这套卷的内容和阶段。

- **读懂陌生文章**：阅读理解，以及要读懂全文才能做好的完形填空。
- **词汇的意思和用法**：选词、搭配、前置词。
- **语法在语境里的运用**：语法填空，以及要看情境判断的单选和完形空。
- **交际用语**：在什么场合说什么话。
- **自己产出**：翻译、补全对话、写作。

### 3. 难度

- **套与套之间逐步加难**：文章越来越长；阅读理解从找原文到推断、概括、主旨；主观题从翻译句子到补全对话，再到写作。
- **一套之内有梯度**：有大部分人能做对的题，也有只有真正掌握的人才能做对的题。

### 4. 新材料

- 全卷不用教材的人物和课文情节，不照搬课文、教材练习、练习册里的句子。
- 词以学过的为主。文章需要的生词可以用，在文末注出意思。被注释的词不出题。
- 语法只用范围内学过的。

## 四、审题记录

每套审完，用几段话写下判断：这套卷能不能测出这一阶段该会的东西，哪里考得好，哪里考偏了、漏了，哪些题要改、为什么、怎么改。不用逐题列出合格的题，也不要写成打勾的清单。

上面各节是帮助判断的思路，不是验收条件。审的人要能说出自己的理由。
