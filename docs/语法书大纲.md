# 《俄语语法》大纲

## 书的定位

《俄语语法》是四册《俄语教程》的配套参考语法，供中文母语的自学者按语法体系查阅，也能离开教程单独使用。范围以教程四册讲过的全部语法为底线：教程为循序渐进拆开、简化的内容，在这里合到一处讲成完整的规则；教程没有讲、而 C1 读者阅读原著和写作时需要的内容，按体系补齐。形态和用法以《[Ру́сская грамма́тика]{.ru}》（1980）为准，重音以扎利兹尼亚克《俄语语法词典》为准。全书按编、章、节编排，分层编号：章在编内编号，节写成“编.章.节”（如 §2.2.1）；一节是一个可以独立查阅的语法点；每节末尾注明教程讲到这一点的课号。术语见 `docs/语法书术语.md`，编写体例见 `docs/语法书编写规范.md`。

## 结构说明

以任务给出的参考结构（十四编加附录）为基础，作了下列调整：

1. **诗律放在第一编最后一章。** 判断音步靠的是音节和重音位置，押韵看读音不看拼写，所用的概念（重读与非重读音节、元音弱化、词末清化）都在第一编；教程语法点索引也把诗律归入语音与正字法。诗歌在语法上的特点（旧式词尾、诗歌语序、为格律选用的形式）属于语体，放在第十四编最后一章“旧式形式和诗歌语言”，两处互相引用。
2. **第二编按“类别—单数—复数—专有名词—格的用法”分章。** 单数变格单列一章（样章），重音类型的单数部分放在这一章，复数部分放在复数一章，附录另有重音类型总表，方便按变化查阅。格的用法按格分三章（第一格和第四格、第二格、第三五六格）；第六格只与前置词连用，用法放在第八编，第二编只留一个概说节。教程第三册系统讲了姓名、地名的变格，单立“专有名词的变格”一章。
3. **第四编把代词性副词移到第七编。** [где, туда́, никогда́, не́где]{.ru} 在句中作状语，变化上与副词相同，和不定副词、否定副词放在一起讲；不定代词、否定代词一章交叉引用。关系代词在第四编讲形式，用法放在第十二编定语从句和代词—关联句两节。
4. **第五编增加“序数词和时间、数量的表达”一章。** 钟点、日期、年份、年龄、价格是教程四册反复出现的内容，读者常按这些话题查，集中成一章比分散在数词变格各节好查。
5. **第六编分九章。** 体单立一章（样章）；运动动词单立一章，按前缀分节；“动词的支配和情态”一章收支配、近义动词、情态动词和无人称动词（无人称动词讲词，无人称句放在第十一编讲句）；行为方式放在体的一章，动词前缀的非运动意义放在第十编构词法，两处互相引用。
6. **第七编分副词和谓语副词两章。** 谓语副词（状态词）只作无人称句的谓语，与副词的句法功能不同，教程第一至三册多次专讲。
7. **第八编按意义分章（空间、时间、其他关系），不按格分章。** 读者遇到的问题多是“表示原因用哪个前置词”“时段用 [за]{.ru} 还是 [на]{.ru}”，按意义排便于比较；同一前置词意义多的（[по]{.ru}，[за, с, на]{.ru}）另设专节。按格排列的前置词总表放在附录五。
8. **第十一编增加“不完全句”一章，并把领有句、存在句放在“单部句和存在句”一章。** 口语省略在教程四册中反复出现，单独成章；[у меня́ есть]{.ru} 和 [нет]{.ru} 加第二格与无人称句关系密切，放在一起讲。
9. **第十四编改名“语体与修辞”，分功能语体、修辞手段、旧式形式和诗歌语言三章。** 第四册以“文体与修辞”代替语法，修辞格单设一章；旧式、俗语形式（第五格 [-ою]{.ru}、副动词 [-вши]{.ru}、语气词 [-с]{.ru} 等）在第四册注释中出现最多，集中讲比分散在形态各节清楚，形态各节只作交叉引用。
10. **附录扩充为九项**，除参考结构的变格变位总表、重音类型表、俄汉术语对照、两种索引外，增加例外词表、前置词按格总表、读音规范词表，正文中“全部词表见附录”指向这些表。

样章两章是第二编第 2 章“名词单数变格”和第六编第 3 章“动词的体”。
