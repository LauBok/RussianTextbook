# 俄语教程 第四册 课程大纲

## 总体结构

第四册从 B2 起步，目标达到 C1（ТРКИ 三级），新增词汇约 2000，累计约 7000。全册 40 课，分 5 个单元，每单元 7 课新授课加 1 课复习。

| 项目 | 数量 |
| --- | --- |
| 新授课 | 35 |
| 复习课 | 5 |
| 每课新词 | 约 57 |
| 课文长度 | 600–1000 词；诗歌全文 |

**选文来源**：第一、二、三、五单元选用俄罗斯文学原著，只做删节，不改写词句。第四单元的现代语体课文（新闻、社论、访谈等）由编写组按真实文体撰写。

**版权原则**：原著只选作者 1951 年以前去世的作品。俄罗斯著作权保护期为作者终身加 70 年，卫国战争期间参战或工作的作者再加 4 年，取 1951 年为界可以覆盖这两种情况。现代报刊文章不直接选用。

**重点**：语法已基本学完，本册转向文体、修辞和篇章：作家的用词与句法选择、诗歌的格律与重音、各类语体的篇章结构、概要写作。

## 每课构成与练习

每课顺序：课前问题 → 选文 → 作者与作品简介 → 生词和短语 → 课文注释 → 文体与修辞 → 练习 → 参考译文。

- **作者与作品简介**：100–200 字，交代作者、成书年代和选段在全书中的位置。
- **文体与修辞**：取代前几册的语法一节，分析选文中一到两个有代表性的语言手段。
- **练习**：理解问答、词汇释义（用俄语解释俄语）、概要写作、作文、多项选择。概要写作限定字数，把 600–1000 词的选文压缩到 150 词左右；作文 250–300 词。
- **诗歌课**：增加格律分析和朗读训练，参考译文改为逐行直译。

练习答案与解析的原则同第一册：答案附在全册末尾，格律分析给完整划分，概要和作文有参考范文；文体与修辞一节不限长度。

## 第一单元 短篇小说（L1–8）

篇幅短、可以全文或基本全文收录的短篇，从契诃夫和托尔斯泰的简洁叙事过渡到二十世纪初的抒情与讽刺。

| 课 | 选文 | 文体与修辞 |
| --- | --- | --- |
| L1 | 契诃夫《胖子和瘦子》（全文） | 称呼与语体随人物关系变化 |
| L2 | 契诃夫《一个官员的死》（全文） | 动词体与叙事节奏 |
| L3 | 托尔斯泰《跳水》（全文） | 短句与紧张感 |
| L4 | 库普林《石榴石手镯》（节选） | 书信体与抒情 |
| L5 | 柯罗连科《盲音乐家》（节选） | 声音的描写 |
| L6 | 格林《红帆》（节选） | 比喻与色彩词 |
| L7 | 伊里夫、彼得罗夫《十二把椅子》（节选） | 讽刺与仿拟 |
| L8 | 复习 | 单元测试：选文概要与文体分析 |

## 第四单元 现代语体（L25–32）

编写组撰写的现代文本，覆盖工作和生活中最常读写的七种文体。每课附一篇同题材的写作任务。

| 课 | 课文 | 文体与写作 |
| --- | --- | --- |
| L25 | 新闻报道：一座城市的交通改革 | 新闻的倒金字塔结构；写一则消息 |
| L26 | 评论：城市化的利与弊 | 论点与论据；写一篇短评 |
| L27 | 科普文章：贝加尔湖的生态 | 定义、分类与举例；写一段说明文 |
| L28 | 访谈：一位翻译家谈翻译 | 问答体与转述；把访谈改写为报道 |
| L29 | 演讲：大学毕业典礼致辞 | 演讲的修辞：排比、设问、呼告 |
| L30 | 合同与规章 | 公文语体的被动结构与名词化 |
| L31 | 广告与网络评论 | 口语化、缩略与新词 |
| L32 | 复习 | 单元测试：同一内容改写为三种语体 |
