表示在空间中移动的动词有一批成对的特殊成员：每一对里一个表示朝一个方向的移动（[идти́]{.ru}），一个表示不朝一个方向的移动（[ходи́ть]{.ru}）。两个都是未完成体，它们的对立不是体的对立，而是运动方式的对立；加上前缀以后，这种对立消失，变成普通的体对（[приходи́ть — прийти́]{.ru}）。本章先讲这个体系和变位（§7.6.1），再讲两类动词的用法（§7.6.2–§7.6.4），然后讲 [пойти́]{.ru} 一类动词（§7.6.5）和带前缀的运动动词（§7.6.6–§7.6.9），最后讲转义（§7.6.10）。这些动词的变位类型见 §7.1.4、§7.1.6，体的一般规则见第七编第 3 章，表示空间关系的前置词见第九编第 2 章。

## §7.6.1 运动动词的体系

### 形式

[运动动词]{.term}（[глаго́л движе́ния]{.ru}）在本书里专指下面十四对动词。每对的第一个叫[定向动词]{.term}（[глаго́л однонапра́вленного движе́ния]{.ru}），第二个叫[不定向动词]{.term}（[глаго́л неоднонапра́вленного движе́ния]{.ru}）：

| 定向动词 | 不定向动词 | 意义 | 怎样移动 |
|---|---|---|---|
| [идти́]{.ru .ix} | [ходи́ть]{.ru .ix} | 走，步行 | 自身移动 |
| [е́хать]{.ru .ix} | [е́здить]{.ru .ix} | 乘车（船、飞机）去 | 自身移动 |
| [бежа́ть]{.ru .ix} | [бе́гать]{.ru .ix} | 跑 | 自身移动 |
| [лете́ть]{.ru .ix} | [лета́ть]{.ru .ix} | 飞；乘飞机去 | 自身移动 |
| [плыть]{.ru .ix} | [пла́вать]{.ru .ix} | 游；（船）航行；乘船去 | 自身移动 |
| [ползти́]{.ru .ix} | [по́лзать]{.ru .ix} | 爬（贴着地面） | 自身移动 |
| [лезть]{.ru .ix} | [ла́зить]{.ru .ix} | 攀，爬（手脚并用）；钻 | 自身移动 |
| [брести́]{.ru .ix} | [броди́ть]{.ru .ix} | 慢慢地走，吃力地走；徘徊，闲逛 | 自身移动 |
| [нести́]{.ru .ix} | [носи́ть]{.ru .ix} | 拿着、抱着、背着（步行） | 带着东西或人 |
| [вести́]{.ru .ix} | [води́ть]{.ru .ix} | 领着（步行）；驾驶 | 带着东西或人 |
| [везти́]{.ru .ix} | [вози́ть]{.ru .ix} | 用交通工具运送 | 带着东西或人 |
| [гнать]{.ru .ix} | [гоня́ть]{.ru .ix} | 赶，驱赶；追 | 带着东西或人 |
| [тащи́ть]{.ru .ix} | [таска́ть]{.ru .ix} | 拖，拉；（口语）费力地搬 | 带着东西或人 |
| [кати́ть]{.ru .ix} | [ката́ть]{.ru .ix} | 滚动，推着（有轮子的东西）走 | 带着东西或人 |

### 意义和用法

**定向与不定向不是体的对立。** 每对的两个动词都有现在时，都能和 [бу́ду]{.ru} 构成复合将来时（[бу́ду идти́, бу́ду ходи́ть]{.ru}），所以都是未完成体（判断方法见 §7.3.2）。它们区分的是移动的方式：定向动词把移动表示为朝一个方向、沿一条线进行的过程；不定向动词表示的移动不是朝一个方向的：来回往返、多次、到处、或者只指这种移动的能力和活动本身。两者的具体分工见 §7.6.2。这种成对的区分只有这十四对动词有。意义相近的其他动词没有成对的另一个：[гуля́ть]{.ru}（散步）、[шага́ть]{.ru}（迈步走）、[спеши́ть]{.ru}（赶紧去）、[дви́гаться]{.ru}（移动）、[мча́ться]{.ru}（飞驰）、[путеше́ствовать]{.ru}（旅行）都只有一个未完成体，不分方向。

**两个动词在形式上的关系。** 一对里的两个动词，有的只差后缀：[бежа́ть — бе́гать, лете́ть — лета́ть, ползти́ — по́лзать, тащи́ть — таска́ть, кати́ть — ката́ть, гнать — гоня́ть]{.ru}；有的词根元音或辅音不同：[нести́ — носи́ть, вести́ — води́ть, везти́ — вози́ть, брести́ — броди́ть, лезть — ла́зить]{.ru}；有的完全是两个词根：[идти́ — ходи́ть, е́хать — е́здить, плыть — пла́вать]{.ru}。所以每对都要成对记。

**变位要点。** 定向动词多属非能产类型（§7.1.4），不能从不定式推出现在时，要记单数第一、第二人称：

- [идти́, е́хать, бежа́ть]{.ru} 是不规则变位动词（§7.1.6）：[иду́]{.ru} 和过去时 [шёл]{.ru} 词干不同；[е́хать — е́ду]{.ru}；[бежа́ть]{.ru} 在单数第一人称和复数第三人称是 [бегу́, бегу́т]{.ru}，其余按第二变位（[бежи́шь, бежи́т]{.ru}）。
- [нести́, вести́, везти́, ползти́, брести́, лезть]{.ru} 属 [нести́]{.ru} 类（§7.1.4）：现在时词干以辅音结尾（[нес-, вед-, вез-, полз-, бред-, лез-]{.ru}），过去时阳性没有 [-л]{.ru}（[нёс, вёз, полз, лез]{.ru}）；词干末是 [д]{.ru} 的，[д]{.ru} 在过去时脱落，加 [-л]{.ru}（[вести́ — вёл, брести́ — брёл]{.ru}）。重读的 [е]{.ru} 在阳性过去时里写成 [ё]{.ru}：[нёс, вёз, вёл, брёл]{.ru}，阴性、中性、复数重音在词尾，写 [е]{.ru}：[несла́, везла́, вела́, брела́]{.ru}。
- [плыть]{.ru} 属 [жить]{.ru} 类，现在时词干加 [-в-]{.ru}：[плыву́, плывёшь]{.ru}；过去时阴性重音在词尾：[плыла́]{.ru}，其余在词干：[плыл, плы́ло, плы́ли]{.ru}。
- [лете́ть]{.ru} 是第二变位的 [-еть]{.ru} 动词，单数第一人称 [т — ч]{.ru}：[лечу́, лети́шь]{.ru}；[кати́ть — качу́, ка́тишь]{.ru}（[т — ч]{.ru}），[тащи́ть — тащу́, та́щишь]{.ru}。
- [гнать]{.ru} 是第二变位的 [-ать]{.ru} 动词（§7.1.2），现在时词干是 [гон-]{.ru}：[гоню́, го́нишь, го́нят]{.ru}；过去时 [гнал, гнала́, гна́ло, гна́ли]{.ru}，阴性重音在词尾。

不定向动词都属能产类型：[ходи́ть, е́здить, носи́ть, води́ть, вози́ть, ла́зить, броди́ть]{.ru} 是第二变位的 [-ить]{.ru} 动词，单数第一人称有辅音交替（§7.1.5）：[д — ж]{.ru}（[хожу́, вожу́, брожу́]{.ru}），[з — ж]{.ru}（[вожу́, ла́жу]{.ru}），[с — ш]{.ru}（[ношу́]{.ru}），[зд — зж]{.ru}（[е́зжу]{.ru}，读 [[е́жжу]]{.tr}，见 §1.1.5）。[води́ть]{.ru} 和 [вози́ть]{.ru} 的单数第一人称都是 [вожу́]{.ru}，靠上下文区分。[ла́жу]{.ru} 与 [ла́дить]{.ru}（和睦相处）的 [ла́жу]{.ru} 同形，口语里常避开不用，改说 [я ла́заю]{.ru}：[ла́зать]{.ru}（[ла́заю, ла́заешь]{.ru}，命令式 [ла́зай]{.ru}）按第一变位变，词典作为 [ла́зить]{.ru} 的并存形式收录，带口语色彩；书面语以 [ла́зить]{.ru} 为准。其余的 [бе́гать, лета́ть, пла́вать, по́лзать, гоня́ть, таска́ть, ката́ть]{.ru} 按 [чита́ть]{.ru} 变。

**重音。** 定向动词中，[-ти́]{.ru} 结尾的人称形式重音全在词尾（b 型：[несу́, несёшь, несу́т]{.ru}），[лете́ть, бежа́ть]{.ru} 也是 b 型；[тащи́ть, кати́ть, гнать]{.ru} 是 c 型（[тащу́, та́щишь]{.ru}）；[е́хать, лезть]{.ru} 重音在词干。不定向动词 [ходи́ть, носи́ть, води́ть, вози́ть, броди́ть]{.ru} 是 c 型（[хожу́, хо́дишь]{.ru}），过去时重音在 [-и́-]{.ru} 上（[ходи́л, носи́л]{.ru}）；[е́здить, ла́зить, бе́гать, пла́вать, по́лзать]{.ru} 重音固定在词干。重音类型见 §7.1.7。

**命令式。** [е́хать]{.ru} 没有自己的标准命令式，用 [поезжа́й(те)]{.ru}（§7.1.6）；[лезть]{.ru} 和 [ла́зить]{.ru} 的命令式都是 [лезь]{.ru}、[лазь]{.ru} 这样的零词尾形式；其余按一般规则（§7.4.1）。运动动词命令式的体见 §7.3.9。

**完成体从哪里来。** 运动动词本身没有完成体。成对的完成体靠前缀构成：[по-]{.ru} 加定向动词（[пойти́, пое́хать]{.ru}，§7.6.5），其他前缀加定向动词（[прийти́, уе́хать]{.ru}，§7.6.6）。前缀加在不定向动词上，构成的一般是未完成体（[приходи́ть]{.ru}），只有少数几个前缀构成完成体（[сходи́ть]{.ru} 去一趟，[походи́ть]{.ru} 走一会儿，§7.6.5–§7.6.6）。

::: ex
[Сейча́с Ми́ша **идёт** в шко́лу.]{.ru}

[米沙现在正往学校走。]{.gloss}

[Ми́ша ка́ждый день **хо́дит** в шко́лу.]{.ru}

[米沙每天去上学。]{.gloss}

[Пти́ца **лети́т** к гнезду́.]{.ru}

[鸟往窝那边飞。]{.gloss}

[Над о́зером **лета́ют** пти́цы.]{.ru}

[湖面上飞着鸟。]{.gloss}

[Ко́шка **ле́зет** на де́рево.]{.ru}

[猫正往树上爬。]{.gloss}

[Ма́льчики лю́бят **ла́зить** по дере́вьям.]{.ru}

[男孩子喜欢爬树。]{.gloss}

[Ребёнок **по́лзает** по ковру́.]{.ru}

[小孩在地毯上爬来爬去。]{.gloss}

[Стари́к ме́дленно **брёл** по доро́ге.]{.ru}

[老人沿着大路慢慢地走着。]{.gloss}

[Ле́том мы це́лыми дня́ми **броди́ли** по ле́су.]{.ru}

[夏天我们整天在林子里闲逛。]{.gloss}

[Пасту́х **гнал** коро́в домо́й.]{.ru}

[牧人赶着牛回家。]{.gloss}

[Он с трудо́м **тащи́л** тяжёлый чемода́н.]{.ru}

[他吃力地拖着沉重的箱子。]{.gloss}

[Мать **ка́тит** коля́ску по па́рку.]{.ru}

[母亲推着童车在公园里走。]{.gloss}
:::

### 常见错误

::: err
\*[Я бежу́ на авто́бус!]{.ru}　→　[Я **бегу́** на авто́бус!]{.ru}

[бежа́ть]{.ru} 的单数第一人称和复数第三人称是 [бегу́, бегу́т]{.ru}，其他人称才是 [беж-]{.ru}。
:::

::: err
\*[Я ча́сто е́зду в Петербу́рг.]{.ru}　→　[Я ча́сто **е́зжу** в Петербу́рг.]{.ru}

[е́здить]{.ru} 单数第一人称 [зд]{.ru} 交替为 [зж]{.ru}；[е́ду]{.ru} 是 [е́хать]{.ru} 的形式，两个动词不要混。
:::

::: err
\*[Он идёл домо́й.]{.ru}　→　[Он **шёл** домо́й.]{.ru}

[идти́]{.ru} 的过去时是另一个词干：[шёл, шла, шли]{.ru}。
:::

::: err
\*[Она́ нёсла цветы́.]{.ru}　→　[Она́ **несла́** цветы́.]{.ru}

只有阳性 [нёс, вёз, вёл]{.ru} 重读词干，写 [ё]{.ru}；阴性、中性、复数重音在词尾，词干写 [е]{.ru}。
:::

## §7.6.2 定向动词与不定向动词的用法

### 意义和用法

定向动词说的是一次沿着一个方向的移动，说话人看着这段路程本身；不定向动词说的不是一段有方向的路程，可能是去了又回来，可能是来回多次，可能是到处走，也可能只是“会走、常走”这件事。下面分别列出两类动词的用法。

**定向动词的用法。**

1. 说话时或过去某一时刻正在朝某个方向移动。常带表示去向的 [куда́]{.ru}、[в, на]{.ru} 加第四格、[к]{.ru} 加第三格，或者说明移动的方式、速度：

::: ex
[— Куда́ ты **идёшь**? — В библиоте́ку.]{.ru}

[——你去哪儿？——去图书馆。]{.gloss}

[Смотри́, самолёт **лети́т**!]{.ru}

[看，飞机飞过来了！]{.gloss}

[Мы **е́хали** ме́дленно: на доро́ге был снег.]{.ru}

[我们开得很慢：路上有雪。]{.gloss}
:::

2. 过去的定向动词常给另一件事做背景：“在路上的时候……”。这时句子一般不能到此结束，要说出路上发生的事（§7.3.7）：

::: ex
[Когда́ я **шёл** домо́й, я встре́тил Пье́ра.]{.ru}

[我回家的路上碰见了皮埃尔。]{.gloss}

[Мы **е́хали** в метро́ и разгова́ривали.]{.ru}

[我们坐着地铁，一路聊天。]{.gloss}
:::

3. 现在时表示已经计划好的、马上要进行的一次行程（§7.2.5）：

::: ex
[Ве́чером мы **идём** в теа́тр.]{.ru}

[晚上我们去看戏。]{.gloss}

[За́втра я **лечу́** в Пеки́н.]{.ru}

[明天我飞北京。]{.gloss}
:::

4. 反复的行程中只说单程的一段。去和回分开说、或者一连串先后的动作里说“往……走”这一段时，即使每天如此，也用定向动词：

::: ex
[Ка́ждое у́тро я **иду́** на рабо́ту пешко́м, а обра́тно **е́ду** на авто́бусе.]{.ru}

[我每天早上走着去上班，回来坐公共汽车。]{.gloss}

[Обы́чно он выхо́дит из до́ма в семь и **идёт** к метро́.]{.ru}

[他通常七点出门，往地铁站走。]{.gloss}
:::

5. 复合将来时 [бу́ду идти́]{.ru} 只在说将来某一时刻正在路上时用，多在从句里：[Когда́ бу́дешь идти́ ми́мо апте́ки, купи́ мне лека́рство]{.ru}（你路过药店的时候给我买点药）。说将来去一次，用 [пойду́, пое́ду]{.ru}（§7.6.5）或现在时 [иду́, е́ду]{.ru}。

**不定向动词的用法。**

1. 去了又回来。过去时 [ходи́л, е́здил, лета́л]{.ru} 说的是一次往返，人已经回来，意思和 [быть]{.ru} 加处所相同（[ходи́л в музе́й = был в музе́е]{.ru}）。注意前置词后面的格不同：不定向动词回答 [куда́]{.ru}，用第四格；[быть]{.ru} 回答 [где]{.ru}，用第六格：

::: ex
[Вчера́ я **ходи́л** в музе́й. = Вчера́ я был в музе́е.]{.ru}

[昨天我去了一趟博物馆。]{.gloss}

[Ле́том Ю́ми **лета́ла** домо́й, в То́кио.]{.ru}

[夏天由美坐飞机回了一趟东京的家。]{.gloss}
:::

2. 多次往返，经常、有规律地去某处。常带 [ча́сто, обы́чно, всегда́, ка́ждый день, по суббо́там, иногда́, ре́дко]{.ru}：

::: ex
[Ван Лэй ча́сто **хо́дит** в библиоте́ку.]{.ru}

[王磊常去图书馆。]{.gloss}

[По суббо́там мы **е́здили** на да́чу.]{.ru}

[那时我们每个星期六都去别墅。]{.gloss}
:::

3. 没有固定方向的移动：来回走、到处走、转圈。常带 [по]{.ru} 加第三格（在……里到处）：

::: ex
[Он нерво́вно **ходи́л** по ко́мнате.]{.ru}

[他心神不宁地在屋里走来走去。]{.gloss}

[Де́ти **бе́гают** во дворе́.]{.ru}

[孩子们在院子里跑来跑去。]{.gloss}
:::

4. 移动的能力、习惯，或者这种活动本身，不涉及任何具体的路程：

::: ex
[Ребёнок уже́ **хо́дит**.]{.ru}

[孩子已经会走路了。]{.gloss}

[Пингви́ны не **лета́ют**.]{.ru}

[企鹅不会飞。]{.gloss}

[Я хорошо́ **пла́ваю**.]{.ru}

[我游泳游得很好。]{.gloss}

[Врачи́ сове́туют бо́льше **ходи́ть** пешко́м.]{.ru}

[医生建议多走路。]{.gloss}
:::

**同一个 [по]{.ru} 加第三格，两种意思。** 和定向动词连用，[по]{.ru} 指沿着一条路朝前走：[Мы шли по у́лице]{.ru}（我们沿着街往前走）；和不定向动词连用，指在一个范围里到处走：[Мы ходи́ли по у́лицам]{.ru}（我们在街上到处逛）。

**怎样判断。** 选哪一个，可以按顺序问两个问题：

1. 是一次朝一个方向，还是来回、多次、到处，或者只说能力？前者用定向动词，后者用不定向动词。
2. 说的是路上的过程，还是整件事？说路上（正在路上、路上发生了什么）用定向动词；说整件事（去过、常去、会去）用不定向动词。

两个问题的答案指向同一类时，选择很明确；遇到每天单程的情况，第二个问题决定：说的是路上那一段，用定向动词（上面定向动词第 4 条）。

下表按时间排列两类动词和 [пойти́]{.ru} 的分工：

| | 定向动词 | 不定向动词 | [пойти́]{.ru}（§7.6.5） |
|---|---|---|---|
| 现在 | [Я иду́ в шко́лу.]{.ru} 我正往学校去。 | [Я хожу́ в шко́лу.]{.ru} 我（每天）上学。 | — |
| 过去 | [Я шёл в шко́лу (и уви́дел…).]{.ru} 我去学校的路上（看见了……）。 | [Я ходи́л в шко́лу.]{.ru} 我去了趟学校（回来了）；我那时天天上学。 | [Я пошёл в шко́лу.]{.ru} 我上学去了（动身了）。 |
| 将来 | [За́втра я иду́ в шко́лу.]{.ru} 明天我去学校（已定的安排）。 | [Я бу́ду ходи́ть в шко́лу.]{.ru} 我将（每天）上学。 | [За́втра я пойду́ в шко́лу.]{.ru} 明天我去学校。 |

**不定式。** 不定式按同样的意义选：[уме́ть, люби́ть, учи́ться, нра́виться]{.ru} 后面说的是能力、爱好，用不定向动词（[Я люблю́ ходи́ть пешко́м]{.ru}，[Он у́чится пла́вать]{.ru}）；说马上要动身，用定向动词或 [пойти́]{.ru}（[Мне пора́ идти́]{.ru} 我该走了，[Мне на́до пойти́ в апте́ку]{.ru} 我得去趟药店）；说将来经常去，用不定向动词（[Я хочу́ ходи́ть в бассе́йн]{.ru} 我想常去游泳）。

**否定。** 说“没去（过）”，用不定向动词过去时：[Вчера́ я никуда́ не ходи́л]{.ru}（昨天我哪儿也没去）；[не пошёл]{.ru} 表示本来要去而没有动身（§7.3.11）：[Я не пошёл на ле́кцию, потому́ что заболе́л]{.ru}。否定命令式“别去”用不定向动词：[Не ходи́ туда́!]{.ru}；定向动词的否定命令式只针对正在进行的移动的方式：[Не иди́ так бы́стро!]{.ru}（别走这么快！）

### 汉语的“去、来、走”与俄语的运动动词

汉语按说话人的位置分“来”和“去”，俄语的运动动词不分：[Иди́ сюда́!]{.ru} 是“过来！”，[Я иду́!]{.ru} 是“我来了！”（回答叫唤），[Он идёт к нам]{.ru} 是“他朝我们走过来”。俄语要分的是汉语不分的两件事：步行还是乘交通工具（§7.6.4），一个方向还是不是一个方向。汉语的“去”在俄语里至少有下面几种说法：

| 汉语 | 俄语 | 例句 |
|---|---|---|
| 在去……的路上，正去 | 定向动词现在时、过去时 | [Я иду́ в магази́н.]{.ru} 我正去商店。 |
| 打算去（一次） | 定向动词现在时、[пойти́]{.ru} 将来时 | [Ве́чером я иду́ в кино́. Ве́чером я пойду́ в кино́.]{.ru} 晚上我去看电影。 |
| 去过，去了一趟（回来了） | 不定向动词过去时，[быть]{.ru} | [Вчера́ я ходи́л в кино́.]{.ru} 昨天我去看了场电影。 |
| 去了（还没回来） | [пошёл, пое́хал]{.ru}，[ушёл, уе́хал]{.ru} | [Он пошёл в кино́.]{.ru} 他看电影去了。 |
| 常去 | 不定向动词 | [Я ча́сто хожу́ в кино́.]{.ru} 我常去看电影。 |
| 到了 | [прийти́, прие́хать]{.ru} | [Он пришёл в кино́ ра́но.]{.ru} 他到电影院到得早。 |
| 去一趟（将来，办件事就回来） | [сходи́ть, съе́здить]{.ru} | [Я схожу́ в магази́н.]{.ru} 我去趟商店。 |

### 常见错误

::: err
\*[Вчера́ я шёл в музе́й.]{.ru}（想说“昨天我去了博物馆”）　→　[Вчера́ я **ходи́л** в музе́й.]{.ru}

去了又回来，说的是整件事，用不定向动词。[шёл]{.ru} 是“当时正往博物馆走”，听的人会等着下文。
:::

::: err
\*[Я ка́ждый день иду́ в библиоте́ку.]{.ru}　→　[Я ка́ждый день **хожу́** в библиоте́ку.]{.ru}

每天去，有去有回，是多次往返，用不定向动词。只有专门说单程那一段时才用定向动词。
:::

::: err
\*[Сейча́с я хожу́ в магази́н, подожди́ меня́.]{.ru}　→　[Сейча́с я **иду́** в магази́н, подожди́ меня́.]{.ru}

说话时正在路上，朝一个方向，用定向动词。[хожу́]{.ru} 是“常去”。
:::

::: err
\*[Ребёнку год, он уже́ идёт.]{.ru}　→　[Ребёнку год, он уже́ **хо́дит**.]{.ru}

会走路是能力，不是朝某个方向的一次移动，用不定向动词。
:::

::: err
\*[В воскресе́нье мы два часа́ шли по па́рку.]{.ru}（想说“在公园里逛了两个小时”）　→　[В воскресе́нье мы два часа́ **ходи́ли** по па́рку.]{.ru} / [**гуля́ли** по па́рку.]{.ru}

在一个范围里到处走，没有固定方向，用不定向动词或 [гуля́ть]{.ru}；[шли по па́рку]{.ru} 是“穿过公园往某处走”。
:::

::: err
\*[Я люблю́ идти́ пешко́м.]{.ru}　→　[Я люблю́ **ходи́ть** пешко́м.]{.ru}

[люби́ть]{.ru} 后面说的是爱好，指这种活动本身，用不定向动词。
:::

## §7.6.3 及物运动动词

### 形式

带着东西或人移动的运动动词是及物动词，直接补语用第四格。最常用的是三对，变位见 §7.6.1：

| 定向动词 | 不定向动词 | 带的是什么 | 怎样移动 | 对应的自身移动 |
|---|---|---|---|---|
| [нести́]{.ru .ix} | [носи́ть]{.ru .ix} | 东西，或抱着、背着的人 | 步行 | [идти́ — ходи́ть]{.ru} |
| [вести́]{.ru .ix} | [води́ть]{.ru .ix} | 自己会走的人和动物 | 步行 | [идти́ — ходи́ть]{.ru} |
| [везти́]{.ru .ix} | [вози́ть]{.ru .ix} | 东西或人 | 乘交通工具 | [е́хать — е́здить]{.ru} |

另外三对用得少一些：[гнать — гоня́ть]{.ru}（赶着牲畜或人走，追），[тащи́ть — таска́ть]{.ru}（拖着、拉着沉重的东西），[кати́ть — ката́ть]{.ru}（滚着、推着有轮子的东西走；[ката́ть]{.ru} 又指带人乘车、坐雪橇玩：[ката́ть дете́й на са́нках]{.ru}）。

### 意义和用法

**选哪一对。** 汉语一个“带”字，俄语要回答两个问题：带的是东西还是自己会走的人（或动物），带的人是步行还是乘交通工具。

- 带东西、步行，用 [нести́ — носи́ть]{.ru}：[нести́ су́мку, нести́ цветы́]{.ru}。抱着、背着不会走或不让他走的人，也用 [нести́]{.ru}：[нести́ ребёнка на рука́х]{.ru}（抱着孩子走）。
- 领着自己会走的人或动物，用 [вести́ — води́ть]{.ru}：[вести́ ребёнка в шко́лу]{.ru}（领孩子去学校，孩子自己走），[вести́ соба́ку]{.ru}（牵着狗）。
- 乘交通工具带着人或东西，不管东西是拿在手里还是放在车上，都用 [везти́ — вози́ть]{.ru}：[везти́ пода́рки из Пеки́на]{.ru}，[везти́ дете́й на мо́ре]{.ru}。说话人自己开车送人、坐车带东西，都是 [везти́]{.ru}。

判断的依据是整段路怎样走：在车站拎着箱子走到车旁这一段是 [нести́]{.ru}，坐上车以后整个行程是 [везти́]{.ru}。

**定向与不定向。** 三对动词的定向与不定向的分工和 §7.6.2 完全一样：

::: ex
[Ван Лэй **несёт** чемода́н к такси́.]{.ru}

[王磊提着箱子往出租车那边走。（此刻，一个方向）]{.gloss}

[Почтальо́н **но́сит** пи́сьма по всему́ райо́ну.]{.ru}

[邮递员在整个街区送信。（到处，经常）]{.gloss}

[Ма́ма **ведёт** Ми́шу к врачу́.]{.ru}

[妈妈领着米沙去看病。（正在路上）]{.gloss}

[Ка́ждое у́тро оте́ц **во́дит** сы́на в де́тский сад.]{.ru}

[父亲每天早上送儿子去幼儿园。（经常往返）]{.gloss}

[Я **везу́** вам пода́рки из Пеки́на.]{.ru}

[我从北京给你们带礼物来了。（这一趟行程）]{.gloss}

[Вчера́ я **вози́л** ба́бушку к врачу́.]{.ru}

[昨天我开车带奶奶去看了病。（去了又回来）]{.gloss}
:::

最后一例和 [ходи́л, е́здил]{.ru} 一样，不定向动词过去时表示去了又回来：奶奶已经回到家了。[Вчера́ я носи́л часы́ в ремо́нт]{.ru} 是“昨天我把表送去修了”，人已经回来，表可能还在修理铺。

**[води́ть]{.ru} 和 [вести́]{.ru} 表示“驾驶”。** 说开车的能力和经常开车，用不定向动词：[Па́па во́дит маши́ну два́дцать лет]{.ru}，[Я не уме́ю води́ть]{.ru}（补语可以省去）。说某一次正在驾驶，用定向动词：[Кто ведёт маши́ну?]{.ru}（谁在开车？），[Он вёл маши́ну о́чень осторо́жно]{.ru}。这里 [вести́]{.ru} 也可以换成中性的 [е́хать]{.ru}：[Он е́хал о́чень осторо́жно]{.ru}。

**[носи́ть]{.ru} 表示“穿、戴”。** [носи́ть]{.ru} 有“经常穿着、戴着”的意思：[носи́ть очки́, носи́ть бо́роду, носи́ть фо́рму]{.ru}。这个意思只有不定向动词有，说“穿着”的状态也用 [носи́ть]{.ru}，不用 [нести́]{.ru}：[Ива́н Серге́евич но́сит очки́]{.ru}。[нести́]{.ru} 永远是“拿着走”。说某一次穿着什么，用 [быть в]{.ru} 加第六格或 [на ком]{.ru}：[Она́ была́ в кра́сном пла́тье]{.ru}，[На нём был но́вый костю́м]{.ru}；[ходи́ть в]{.ru} 加第六格表示经常穿着什么出门（[Он всегда́ хо́дит в джи́нсах]{.ru}，§7.6.10）。

**只用定向动词的固定搭配。** [вести́]{.ru} 有一批不表示空间移动的意义，只用定向动词，经常、反复的也是 [вести́]{.ru}：[вести́ уро́к, вести́ заня́тия]{.ru}（上课、讲课），[вести́ себя́]{.ru}（举止），[вести́ дневни́к]{.ru}（记日记），[вести́ перегово́ры]{.ru}（进行谈判），[вести́ хозя́йство]{.ru}（操持家务）：[О́льга Ви́кторовна ведёт заня́тия по понеде́льникам]{.ru}（奥尔加·维克托罗夫娜每星期一上课），不能说 [*во́дит заня́тия]{.ru}。[води́ть по]{.ru} 加第三格表示领着人在某处到处参观：[води́ть тури́стов по Кремлю́]{.ru}。运动动词转义的全面讨论见 §7.6.10。

**带前缀的及物动词。** “带来”“带走”“送去”要用带前缀的完成体：[принести́, привести́, привезти́]{.ru}（带来），[унести́, увести́, увезти́]{.ru}（带走），[отнести́, отвести́, отвезти́]{.ru}（送去），[занести́, завезти́]{.ru}（顺路送去）等，选择 [-нести́, -вести́, -везти́]{.ru} 的规则和上面一样，前缀的意义见 §7.6.7–§7.6.9。

汉语“带、拿、领、送、运”和俄语的大致对应：

| 汉语 | 俄语 | 例句 |
|---|---|---|
| 拿着（走）、提着、捧着 | [нести́ — носи́ть]{.ru} | [Он несёт кни́ги.]{.ru} 他捧着书走。 |
| 领着、带（孩子、客人）去 | [вести́ — води́ть]{.ru} | [Я веду́ госте́й в музе́й.]{.ru} 我带客人去博物馆。 |
| 开车送、运、坐车带去 | [везти́ — вози́ть]{.ru} | [Он везёт сы́на на вокза́л.]{.ru} 他开车送儿子去火车站。 |
| 带来（东西） | [принести́]{.ru}；坐车带来 [привезти́]{.ru} | [Принеси́ слова́рь.]{.ru} 把词典拿来。 |
| 带来（人） | [привести́]{.ru}；开车带来 [привезти́]{.ru} | [Приведи́ дру́га.]{.ru} 把朋友带来。 |
| 送（某人）去某处 | [отвести́]{.ru}；开车送 [отвезти́]{.ru} | [Я отвезу́ тебя́ в аэропо́рт.]{.ru} 我开车送你去机场。 |

### 常见错误

::: err
\*[Ка́ждое у́тро я несу́ сестру́ в шко́лу.]{.ru}　→　[Ка́ждое у́тро я **вожу́** сестру́ в шко́лу.]{.ru}

妹妹自己走，用 [вести́ — води́ть]{.ru}；每天往返，用不定向动词。[нести́]{.ru} 是把她抱着去。
:::

::: err
\*[Я привёл пода́рки из Кита́я.]{.ru}　→　[Я **привёз** пода́рки из Кита́я.]{.ru}

礼物是坐飞机带来的，乘交通工具运送用 [везти́]{.ru} 一组；[вести́]{.ru} 只用于领着自己会走的人或动物。
:::

::: err
\*[Мой брат хорошо́ ведёт маши́ну.]{.ru}　→　[Мой брат хорошо́ **во́дит** маши́ну.]{.ru}

说开车的本事，是能力，用不定向动词 [води́ть]{.ru}。
:::

::: err
\*[Она́ несёт очки́.]{.ru}（想说“她戴眼镜”）　→　[Она́ **но́сит** очки́.]{.ru}

“戴、穿”的意思只有 [носи́ть]{.ru} 有。[несёт очки́]{.ru} 是“拿着眼镜走”。
:::

## §7.6.4 交通工具与运动动词

### 形式

“乘交通工具”有两种说法：前置词 [на]{.ru} 加第六格，不带前置词的第五格。

| 交通工具 | [на]{.ru} 加第六格 | 第五格 |
|---|---|---|
| [авто́бус]{.ru} 公共汽车 | [на авто́бусе]{.ru} | [авто́бусом]{.ru} |
| [тролле́йбус]{.ru} 无轨电车 | [на тролле́йбусе]{.ru} | [тролле́йбусом]{.ru} |
| [трамва́й]{.ru} 有轨电车 | [на трамва́е]{.ru} | [трамва́ем]{.ru} |
| [по́езд]{.ru} 火车 | [на по́езде]{.ru} | [по́ездом]{.ru} |
| [электри́чка]{.ru} 郊区电气列车 | [на электри́чке]{.ru} | [электри́чкой]{.ru} |
| [самолёт]{.ru} 飞机 | [на самолёте]{.ru} | [самолётом]{.ru} |
| [теплохо́д]{.ru} 内燃机船 | [на теплохо́де]{.ru} | [теплохо́дом]{.ru} |
| [маши́на]{.ru} 汽车 | [на маши́не]{.ru} | — |
| [велосипе́д]{.ru} 自行车 | [на велосипе́де]{.ru} | — |
| [ло́дка]{.ru} 小船 | [на ло́дке]{.ru} | — |
| [метро́]{.ru} 地铁（不变格） | [на метро́]{.ru} | — |
| [такси́]{.ru} 出租车（不变格） | [на такси́]{.ru} | — |

问“坐什么去”用 [на чём]{.ru}；步行用副词 [пешко́м]{.ru .ix}，骑马用 [верхо́м]{.ru}。上车、下车、换车的说法：

| 意思 | 说法 | 例 |
|---|---|---|
| 上车 | [сесть на]{.ru} 或 [в]{.ru} 加第四格 | [сесть на авто́бус, сесть в авто́бус]{.ru} |
| 下车 | [вы́йти из]{.ru} 加第二格；[сойти́ с]{.ru} 加第二格 | [вы́йти из авто́буса, сойти́ с по́езда]{.ru} |
| 换车 | [пересе́сть на]{.ru} 加第四格 | [пересе́сть на метро́]{.ru} |
| 错过 | [опозда́ть на]{.ru} 加第四格 | [опозда́ть на по́езд]{.ru} |

### 意义和用法

**用哪个动词。** 人乘交通工具移动，按交通工具分：

- 陆上的车辆（汽车、公共汽车、火车、地铁）用 [е́хать — е́здить]{.ru}；
- 飞机用 [лете́ть — лета́ть]{.ru}，也可以用 [е́хать]{.ru} 泛指出行（[Мы е́дем в Пеки́н]{.ru} 不说明怎么去）；
- 船用 [плыть — пла́вать]{.ru}，也说 [е́хать на теплохо́де]{.ru}；
- 步行用 [идти́ — ходи́ть]{.ru}，可以加 [пешко́м]{.ru} 强调是走着去：[Пойдём пешко́м, тут бли́зко]{.ru}。

“乘车”的意思已经在 [е́хать]{.ru} 里了，交通工具不说出来也可以：[Ско́лько туда́ е́хать?]{.ru}（坐车去那儿要多久？）。

**去别的城市，一定用 [е́хать]{.ru}、[лете́ть]{.ru}。** 步行不可能到别的城市，所以 [*ходи́л в Петербу́рг]{.ru} 不能说，要说 [е́здил в Петербу́рг]{.ru}。在同一个城市里，走着去用 [идти́]{.ru}，坐车去用 [е́хать]{.ru}。不过，说去上班、上学、看戏、看病这类去某个机构、参加某种活动，交通方式不重要的时候，常用 [идти́ — ходи́ть]{.ru}，即使实际上要坐车：[Мне пора́ идти́ на рабо́ту]{.ru}（我该上班去了），[Ми́ша хо́дит в шко́лу]{.ru}（米沙在上中学），[Ве́чером мы идём в теа́тр]{.ru}。说出交通工具或者路远时，用 [е́хать]{.ru}：[Я е́зжу на рабо́ту на метро́]{.ru}。

**[на]{.ru} 加第六格和第五格的分工。** 两种说法意思相同，分工如下：

1. [на]{.ru} 加第六格是最常用的中性说法，任何交通工具都能用，口语里几乎只用它：[Я е́зжу в университе́т на метро́]{.ru}，[Мы е́хали на такси́]{.ru}。[метро́, такси́]{.ru} 不变格，没有第五格；[маши́на, велосипе́д, ло́дка, ло́шадь]{.ru} 也只用 [на]{.ru}：[е́хать на маши́не, на велосипе́де]{.ru}。
2. 第五格多用于公共交通和远程交通，把交通工具当作出行的方式、路线来说，常见于商量怎么走、介绍路线、书面语：[Лу́чше е́хать по́ездом]{.ru}（最好坐火车去），[До це́нтра мо́жно дое́хать тролле́йбусом]{.ru}，[До Ирку́тска быстре́е лете́ть самолётом]{.ru}。

**[в]{.ru} 加第六格：在车里。** [в авто́бусе, в по́езде, в метро́]{.ru} 说的是“在车厢里”这个处所，不是乘车的方式：[В авто́бусе бы́ло мно́го наро́ду]{.ru}（公共汽车上人很多），[Мы е́хали в метро́ и разгова́ривали]{.ru}（我们在地铁里一路聊天）。回答“坐什么去”时只能用 [на]{.ru}：[Я е́зжу на рабо́ту на метро́]{.ru}。

**交通工具作主语。** 交通工具本身移动时，用哪个动词也是固定的：

| 交通工具 | 动词 | 例句 |
|---|---|---|
| 有固定线路的车：公共汽车、电车、火车、地铁 | [идти́ — ходи́ть]{.ru} | [Авто́бус идёт к це́нтру.]{.ru} 公共汽车开往市中心。[Авто́бусы хо́дят ка́ждые де́сять мину́т.]{.ru} 公共汽车每十分钟一班。 |
| 汽车、出租车、自行车 | [е́хать — е́здить]{.ru} | [Маши́на е́дет бы́стро.]{.ru} 汽车开得很快。 |
| 飞机 | [лете́ть — лета́ть]{.ru} | [Самолёт лети́т в Каза́нь.]{.ru} 飞机飞往喀山。 |
| 船 | [идти́ — ходи́ть]{.ru}，[плыть — пла́вать]{.ru} | [Теплохо́д идёт вверх по Во́лге.]{.ru} 船沿伏尔加河往上游开。 |

有固定线路的车用 [идти́]{.ru}，口语里也有人说 [По́езд е́дет]{.ru}，规范说法是 [По́езд идёт]{.ru}。[ходи́ть]{.ru} 说交通工具时常指按班次运行：[Метро́ хо́дит до ча́са но́чи]{.ru}（地铁运营到夜里一点）。[идти́]{.ru} 也说行程用多长时间：[По́езд идёт до Владивосто́ка почти́ неде́лю]{.ru}（火车到符拉迪沃斯托克差不多要走一个星期）。船自身航行，标准语常用 [идти́ — ходи́ть]{.ru}（[Теплохо́д идёт в А́страхань]{.ru}，[Паро́м хо́дит ка́ждый час]{.ru}），按班次运行只用 [ходи́ть]{.ru}；[плыть]{.ru} 着眼于在水面上移动的情景（[По реке́ плывёт парохо́д]{.ru}），说小船、木筏只用 [плыть]{.ru}。车进站、开出用 [подходи́ть, отходи́ть]{.ru}，见 §7.6.8。

::: ex
[— На чём ты е́здишь в университе́т? — **На метро́**.]{.ru}

[——你坐什么去学校？——坐地铁。]{.gloss}

[Ма́ма е́здит на рабо́ту **на авто́бусе**.]{.ru}

[妈妈坐公共汽车上班。]{.gloss}

[В Су́здаль мо́жно дое́хать **авто́бусом** из Влади́мира.]{.ru}

[去苏兹达尔可以从弗拉基米尔坐公共汽车。]{.gloss}

[В Ирку́тск мы **лете́ли самолётом**, а обра́тно **е́хали по́ездом**.]{.ru}

[去伊尔库茨克我们坐的飞机，回来坐的火车。]{.gloss}

[Э́тот трамва́й **идёт** до вокза́ла?]{.ru}

[这趟电车到火车站吗？]{.gloss}

[Мы живём бли́зко, я хожу́ на рабо́ту **пешко́м**.]{.ru}

[我们住得近，我走着去上班。]{.gloss}
:::

### 常见错误

::: err
\*[В про́шлом году́ я ходи́л в Петербу́рг.]{.ru}　→　[В про́шлом году́ я **е́здил** в Петербу́рг.]{.ru}

去别的城市要乘交通工具，用 [е́хать — е́здить]{.ru}。
:::

::: err
\*[Я иду́ на рабо́ту на авто́бусе.]{.ru}　→　[Я **е́ду** на рабо́ту на авто́бусе.]{.ru}

::: err

乘坐的方式用 [на]{.ru} 加第六格；[в метро́]{.ru} 是“在地铁里”。

::: err

## §7.6.5 [пойти́]{.ru}、[пое́хать]{.ru} 一类动词

### 形式

前缀 [по-]{.ru} 加在定向动词上，构成完成体：[пойти́]{.ru .ix}、[пое́хать]{.ru .ix}、[побежа́ть]{.ru .ix}、[полете́ть]{.ru}、[поплы́ть]{.ru}、[понести́]{.ru}、[повести́]{.ru}、[повезти́]{.ru}、[поползти́]{.ru}、[поле́зть]{.ru}、[побрести́]{.ru}、[погна́ть]{.ru}、[потащи́ть]{.ru}、[покати́ть]{.ru}。它们按原来的定向动词变位，人称形式表示将来：

::: paradigm
| 人称 | [пойти́]{.ru} | [пое́хать]{.ru} | [побежа́ть]{.ru} | [понести́]{.ru} |
|---|---|---|---|---|
| 单数第一人称 | [пойду́]{.ru} | [пое́ду]{.ru} | [побегу́]{.ru} | [понесу́]{.ru} |
| 单数第二人称 | [пойдёшь]{.ru} | [пое́дешь]{.ru} | [побежи́шь]{.ru} | [понесёшь]{.ru} |
| 单数第三人称 | [пойдёт]{.ru} | [пое́дет]{.ru} | [побежи́т]{.ru} | [понесёт]{.ru} |
| 复数第一人称 | [пойдём]{.ru} | [пое́дем]{.ru} | [побежи́м]{.ru} | [понесём]{.ru} |
| 复数第二人称 | [пойдёте]{.ru} | [пое́дете]{.ru} | [побежи́те]{.ru} | [понесёте]{.ru} |
| 复数第三人称 | [пойду́т]{.ru} | [пое́дут]{.ru} | [побегу́т]{.ru} | [понесу́т]{.ru} |
| 过去时 | [пошёл, пошла́, пошло́, пошли́]{.ru} | [пое́хал, пое́хала, пое́хали]{.ru} | [побежа́л, побежа́ла, побежа́ли]{.ru} | [понёс, понесла́, понесли́]{.ru} |
| 命令式 | [пойди́(те)]{.ru} | [поезжа́й(те)]{.ru} | [побеги́(те)]{.ru} | [понеси́(те)]{.ru} |
:::

[пойти́]{.ru} 的人称形式里 [и]{.ru} 变成 [й]{.ru}（[пойду́]{.ru}），过去时由 [шёл]{.ru} 加 [по-]{.ru} 构成。[пое́хать]{.ru} 和 [е́хать]{.ru} 共用命令式 [поезжа́й(те)]{.ru}。[поле́зть]{.ru} 的重音随 [лезть]{.ru}：[поле́зу, поле́зешь; поле́з, поле́зла]{.ru}。

[по-]{.ru} 加在不定向动词上，也构成完成体，意思是“……一会儿”：[походи́ть]{.ru .ix}、[пое́здить]{.ru .ix}、[побе́гать]{.ru}、[полета́ть]{.ru}、[попла́вать]{.ru}、[поноси́ть]{.ru}、[поводи́ть]{.ru}、[повози́ть]{.ru}、[попо́лзать]{.ru}。它们按不定向动词变位，重音也和不定向动词相同：[похожу́, похо́дишь]{.ru}；[пое́зжу, пое́здишь]{.ru}；[побе́гаю, побе́гаешь]{.ru}。

### 意义和用法

[пойти́]{.ru} 一类动词表示“朝一个方向的移动开始了”：从原地动身，或者在路上开始朝某个方向走。它们不是 [идти́]{.ru} 等的体对（§7.3.4），属于起始行为方式（§7.3.5）。由这个意义可以推出下面各种用法。

**1. 将来时：将来的一次出行。** 说打算、计划去某处一次，最常用 [пойду́, пое́ду]{.ru}：

::: ex
[За́втра мы **пое́дем** в Петербу́рг.]{.ru}

[明天我们去彼得堡。]{.gloss}

[По́сле заня́тий я **пойду́** в библиоте́ку.]{.ru}

[下课以后我去图书馆。]{.gloss}
:::

和其他说法比较：现在时 [За́втра я е́ду в Петербу́рг]{.ru} 表示行程已经定好（票买好了），比 [пое́ду]{.ru} 更确定；[бу́ду е́здить]{.ru} 表示将来经常去（[Зимо́й я бу́ду ходи́ть в бассе́йн ка́ждую суббо́ту]{.ru}）；[*бу́ду идти́]{.ru} 不表示将来的一次出行（§7.6.2）。

**2. 过去时：已经动身了。** [пошёл, пое́хал]{.ru} 说人已经出发去了某处，言外之意是人还在那里或者在路上，没有回来。这和 [ходи́л, е́здил]{.ru}（去了又回来）正好相反：

::: ex
[— Где па́па? — Он **пое́хал** на рабо́ту.]{.ru}

[——爸爸呢？——他上班去了。（现在不在家）]{.gloss}

[— Где ты был у́тром? — Я **е́здил** на рабо́ту.]{.ru}

[——你早上去哪儿了？——我去了趟单位。（已经回来）]{.gloss}

[Ива́н Серге́евич **пошёл** спать.]{.ru}

[伊万·谢尔盖耶维奇睡觉去了。]{.gloss}
:::

[пошёл]{.ru} 和 [ушёл]{.ru} 都可以说人不在，侧重不同：[пошёл]{.ru} 说的是动身朝哪儿去，常带去向或目的；[ушёл]{.ru} 说的是离开了这里（§7.6.7）。

**3. 叙事中移动的开始。** 讲一连串动作时，[пошёл, пое́хал]{.ru} 表示朝某个方向动身，后面接着的是下一件事；停下以后再走，也用 [пошёл]{.ru}：

::: ex
[Мы вы́шли из до́ма и **пошли́** к метро́.]{.ru}

[我们出了家门，朝地铁站走去。]{.gloss}

[Он останови́лся, посмотре́л на часы́ и **пошёл** да́льше.]{.ru}

[他停下来，看了看表，又往前走了。]{.gloss}
:::

**4. 开始移动、开始某种状态。** [пойти́]{.ru} 一类也表示移动本身的开始或移动方式的改变：[По́езд пошёл]{.ru}（火车开动了），[Он побежа́л]{.ru}（他跑了起来），[Он пошёл быстре́е]{.ru}（他加快了脚步）。由此引申出 [Пошёл дождь]{.ru}（下起雨来了，§7.6.10）；[Ребёнок пошёл в год]{.ru}（孩子一岁就会走了）；[пойти́ в шко́лу]{.ru}（开始上学）。

**5. [пойти́]{.ru} 加不定式：去做某事。** 运动动词后直接用不定式表示目的（§7.1.8）：[Пойдём обе́дать]{.ru}（咱们吃午饭去吧），[Он пошёл покупа́ть биле́ты]{.ru}。口语里第一人称单数常和另一个完成体将来时连用，不加连词，表示“我这就去做……”：[Пойду́ погуля́ю]{.ru}（我去溜达溜达），[Пойду́ узна́ю]{.ru}（我去问问）。

**6. 提议一起去。** [Пойдём! Пое́дем!]{.ru}（咱们走吧！咱们去吧！），对 [вы]{.ru} 说加 [-те]{.ru}：[Пойдёмте!]{.ru}。口语里用过去时形式 [Пошли́! Пое́хали!]{.ru} 表示“走吧！出发！”。不带 [дава́й]{.ru} 的这种说法见 §7.4.3。

**7. 命令式 [пойди́, поезжа́й]{.ru}。** 叫人去某处办一件事：[Пойди́ узна́й, когда́ отхо́дит по́езд]{.ru}（你去打听一下火车几点开）。口语里叫人“去吧”多说 [иди́]{.ru}（[Иди́ спать!]{.ru}）。运动动词命令式的体见 §7.3.9。

**8. [по-]{.ru} 加不定向动词：走一会儿。** [походи́ть, пое́здить, побе́гать, попла́вать]{.ru} 是限时行为方式（§7.3.5），表示做一会儿就停下，常带 [немно́го]{.ru}：

::: ex
[Мы немно́го **походи́ли** по па́рку и пошли́ домо́й.]{.ru}

[我们在公园里走了一会儿就回家了。]{.gloss}

[Ле́том я хочу́ **пое́здить** по Росси́и.]{.ru}

[夏天我想在俄罗斯各地走走。]{.gloss}
:::

[походи́ть]{.ru} 另有一个同形的未完成体，意思是“像”（[походи́ть на кого́]{.ru}：[Он похо́дит на отца́]{.ru}），两者无关。

**汉语“去了”的两种意思。** “他去商店了”可能是“他到商店去了（现在不在）”，也可能是“他去过商店了（已经回来）”。前者是 [Он пошёл в магази́н]{.ru}，后者是 [Он ходи́л в магази́н]{.ru}。汉语靠语境区分，俄语必须选一个动词。

### 常见错误

::: err
\*[Вчера́ я пошёл в теа́тр. Спекта́кль был отли́чный.]{.ru}　→　[Вчера́ я **ходи́л** в теа́тр. Спекта́кль был отли́чный.]{.ru}

讲的是去过、已经回来的一次经历，用不定向动词。[пошёл]{.ru} 只说动身，适合接着讲路上或到了以后的事。
:::

::: err
\*[— Где Ди́ма? — Он ходи́л в магази́н.]{.ru}　→　[— Где Ди́ма? — Он **пошёл** в магази́н.]{.ru}

迪马现在不在，是去了还没回来，用 [пошёл]{.ru}。[ходи́л]{.ru} 表示已经回来了。
:::

::: err
\*[За́втра я бу́ду идти́ в библиоте́ку.]{.ru}　→　[За́втра я **пойду́** в библиоте́ку.]{.ru} / [За́втра я **иду́** в библиоте́ку.]{.ru}

将来的一次出行用 [пойти́]{.ru} 的将来时，或者用定向动词现在时表示已定的安排。
:::

::: err
\*[Ле́том я хочу́ е́здить в Кита́й.]{.ru}（想说“夏天想回一趟中国”）　→　[Ле́том я хочу́ **пое́хать** в Кита́й.]{.ru}

一次出行用完成体 [пое́хать]{.ru}。[е́здить]{.ru} 是经常去或这种活动本身。
:::

## §7.6.6 带前缀的运动动词：构成和体

### 形式

运动动词加上表示方向的前缀，叫[带前缀的运动动词]{.term}（[приста́вочный глаго́л движе́ния]{.ru}）。构成规则只有一条：

- 前缀加不定向动词，构成未完成体：[при- + ходи́ть → приходи́ть]{.ru}；
- 前缀加定向动词，构成完成体：[при- + идти́ → прийти́]{.ru}。

两者构成一个普通的体对：[приходи́ть — прийти́]{.ru .ix key="приходи́ть"}（来到），像 [чита́ть — прочита́ть]{.ru} 一样，没有定向与不定向的区别了。下表以 [при-]{.ru} 为例，列出十四对运动动词带前缀以后的形式。其中几对的不定向词干带前缀时有变化：

**拼写和读音。**

1. [идти́]{.ru} 带前缀写作 [-йти]{.ru}：[уйти́, войти́, вы́йти, пройти́]{.ru}；[при-]{.ru} 后写 [прийти́]{.ru}，将来时 [приду́, придёшь]{.ru} 不写 [й]{.ru}。[придти́]{.ru} 是旧式拼写，现在不用。过去时由 [шёл]{.ru} 加前缀构成：[пришёл, ушёл, вошёл]{.ru}。
2. 以辅音结尾的前缀在 [-йти]{.ru} 前加 [о]{.ru}：[войти́, подойти́, отойти́, обойти́, сойти́, разойти́сь, взойти́]{.ru}（过去时 [вошёл, подошёл, отошёл]{.ru}）；在 [гн-]{.ru} 前也加 [о]{.ru}：[подогна́ть, отогна́ть, обогна́ть, согна́ть, разогна́ть]{.ru}（未完成体不加：[подгоня́ть, обгоня́ть, разгоня́ть]{.ru}）。在其他词根前不加：[подбежа́ть, отнести́, сбежа́ть, разнести́]{.ru}。
3. 以辅音结尾的前缀在 [-е́хать, -езжа́ть]{.ru} 前加硬音符号 [ъ]{.ru}：[въе́хать, подъе́хать, отъе́хать, объе́хать, съе́хать, разъе́хаться]{.ru}，[ъ]{.ru} 表示 [е]{.ru} 读 [[йэ]]{.tr}。
4. [раз-]{.ru}、[вз-]{.ru} 在清辅音前写 [рас-]{.ru}、[вс-]{.ru}：[расходи́ться, всплыть]{.ru}（§1.4.4）。
5. 前缀 [вы́-]{.ru} 构成的完成体重音永远在 [вы́-]{.ru} 上：[вы́йти, вы́йду, вы́шел, вы́нести, вы́нес]{.ru}；[шёл]{.ru} 的 [ё]{.ru} 在 [вы́шел]{.ru} 里不重读，写 [е]{.ru}。未完成体不重读 [вы-]{.ru}：[выходи́ть, выхожу́, выезжа́ть]{.ru}。
6. [-езжа́ть]{.ru} 和 [-е́здить]{.ru} 里的 [зж]{.ru} 读长音 [[жж]]{.tr}（§1.1.5）。

### 意义和用法

**为什么带前缀以后只剩体的对立。** 前缀给运动加上了方向和终点（到达、离开、进入、越过……），这样的移动有了界限，自然是一个可以完成的整体，所以前缀加定向动词构成完成体（§7.3.1）。前缀加不定向动词构成的未完成体，只是这个完成体的未完成体伙伴，“往返、到处、不定方向”的意思没有保留下来：[приходи́ть]{.ru} 不是“到处来”，而是“来到”的未完成体。[-езжа́ть, -плыва́ть, -леза́ть, -та́скивать, -ка́тывать]{.ru} 这些形式也说明了这一点：它们其实是带次生未完成体后缀的形式（§7.3.4），与不定向动词只是词根相同。

**体的用法。** 带前缀的运动动词按一般规则选体（第七编第 3 章）：

1. 一次具体的动作达到结果，用完成体：[Ба́бушка пришла́ ра́но]{.ru}（奶奶今天来得早）。
2. 反复、经常，用未完成体：[Ба́бушка ча́сто прихо́дит к нам по воскресе́ньям]{.ru}。
3. 动作的过程，或者与另一个动作同时进行，用未完成体：[Когда́ я выходи́л из до́ма, зазвони́л телефо́н]{.ru}（我正要出门的时候电话响了）。
4. 去了又走、来了又回，结果已经不在，用未完成体过去时；完成体过去时表示结果还在。这是结果取消意义（主讲见 §7.3.6）：

::: ex
[Ко мне **приходи́л** Пьер.]{.ru}

[皮埃尔来找过我。（已经走了）]{.gloss}

[Ко мне **пришёл** Пьер.]{.ru}

[皮埃尔来找我了。（还在这里）]{.gloss}

[Ле́том к нам **приезжа́ла** тётя из Каза́ни.]{.ru}

[夏天姑姑从喀山来我们家住过一阵。（已经回去了）]{.gloss}

[Кто́-то **приноси́л** тебе́ кни́ги?]{.ru}

[有人给你送过书来吗？（人已经走了）]{.gloss}
:::

5. 未完成体现在时表示计划中的将来，常用于出发、到达、时刻表（§7.2.5）：[Мы уезжа́ем за́втра]{.ru}（我们明天走），[Самолёт прилета́ет в шесть]{.ru}（飞机六点到）。
6. 命令式：邀请用未完成体（[Приходи́те к нам! Заходи́те! Проходи́те, сади́тесь!]{.ru}），具体一次的指示用完成体（[Приди́ за́втра в семь]{.ru}），否定命令式用未完成体（[Не уходи́!]{.ru}），详见 §7.3.9。

**四种“去”的对比。** 不带前缀的不定向动词、[пойти́]{.ru}、带前缀的完成体和未完成体常常要放在一起比较：

| 句子 | 意思 |
|---|---|
| [Пьер ходи́л к врачу́.]{.ru} | 皮埃尔去看过医生（已经回来）。 |
| [Пьер пошёл к врачу́.]{.ru} | 皮埃尔看医生去了（动身了，还没回来）。 |
| [Пьер пришёл к врачу́.]{.ru} | 皮埃尔到了医生那里。 |
| [Пьер приходи́л к врачу́.]{.ru} | 皮埃尔到医生那里去过（又走了）；皮埃尔常到医生那里去。 |
| [Пьер ушёл к врачу́.]{.ru} | 皮埃尔离开这里，去医生那里了。 |

[ходи́л к врачу́]{.ru} 和 [приходи́л к врачу́]{.ru} 都表示往返，观察点不同：[ходи́л]{.ru} 从出发的地方看（他去过医生那里，又回来了），[приходи́л]{.ru} 从到达的地方看（医生那边：他来过，又走了）。所以“朋友来找过我”一般说 [Ко мне приходи́л друг]{.ru}，较少说 [ко мне ходи́л друг]{.ru}。

**[сходи́ть]{.ru}、[съе́здить]{.ru}：去一趟又回来（完成体）。** 前缀 [с-]{.ru} 加在不定向动词上，构成一组特殊的完成体，表示去某处一趟、办完事又回来：[сходи́ть]{.ru .ix}（[схожу́, схо́дишь]{.ru}）、[съе́здить]{.ru .ix}（[съе́зжу, съе́здишь]{.ru}）、[сбе́гать]{.ru .ix}（跑一趟）、[слета́ть]{.ru}（飞一趟）、口语的 [спла́вать]{.ru}（坐船去一趟）。它们是 [ходи́ть, е́здить]{.ru} 表示“往返”这个意义的完成体伙伴：

::: ex
[Я **схожу́** в магази́н за хле́бом.]{.ru}

[我去趟商店买面包。]{.gloss}

[**Сходи́**, пожа́луйста, на по́чту.]{.ru}

[请你去一趟邮局。]{.gloss}

[В суббо́ту мы **съе́здили** в Су́здаль.]{.ru}

[星期六我们去了一趟苏兹达尔。]{.gloss}
:::

[ходи́ть, е́здить]{.ru} 是未完成体，不能用简单将来时说“将来去一趟”，这正是 [сходи́ть, съе́здить]{.ru} 的用处：[За́втра я съе́зжу к ба́бушке]{.ru}（明天我去一趟奶奶家）。过去时 [е́здили]{.ru} 和 [съе́здили]{.ru} 都能说去过一趟，[е́здили]{.ru} 只说有这回事（一般事实意义，§7.3.6），[съе́здили]{.ru} 把这一趟当作完成了的一件事，常带“办成了、顺利”的意味：[Мы съе́здили в Су́здаль, всё ви́дели]{.ru}。[сходи́ть, съе́здить]{.ru} 只说一次，经常往返仍用 [ходи́ть, е́здить]{.ru}。

**前缀加不定向动词构成的其他完成体。** 除 [с-]{.ru} 以外，还有几个前缀加在不定向动词上构成完成体，表示行为方式（§7.3.5），没有成对的未完成体：

| 前缀 | 意义 | 例 |
|---|---|---|
| [по-]{.ru} | 一会儿（限时） | [походи́ть по па́рку, попла́вать]{.ru}（§7.6.5） |
| [за-]{.ru} | 开始来回走动（起始） | [Он заходи́л по ко́мнате.]{.ru} 他在屋里踱起步来。 |
| [из- (ис-)]{.ru} | 走遍 | [исходи́ть весь го́род]{.ru}，[изъе́здить всю страну́]{.ru} |
| [об-]{.ru} | 走遍（各处、各家） | [обе́гать все магази́ны]{.ru}，[объе́здить всю Евро́пу]{.ru} |
| [на- … -ся]{.ru} | 走够了（满足） | [находи́ться, набе́гаться, нае́здиться]{.ru} |
| [про-]{.ru} | 走了一段时间（持续） | [проходи́ть весь день по магази́нам]{.ru} |

**同形词。** 由此产生了几组同形的动词，靠体、支配和上下文区分：

| 词 | 未完成体 | 完成体 |
|---|---|---|
| [сходи́ть]{.ru} | 下来（[сойти́]{.ru} 的未完成体）：[Здесь все схо́дят с по́езда.]{.ru} | 去一趟：[Сходи́ за хле́бом.]{.ru} |
| [заходи́ть]{.ru} | 顺路去（[зайти́]{.ru} 的未完成体）：[Заходи́те к нам.]{.ru} | 开始来回走：[Он заходи́л по ко́мнате.]{.ru} |
| [проходи́ть]{.ru} | 经过（[пройти́]{.ru} 的未完成体）：[Я проходи́л ми́мо.]{.ru} | 走了一段时间：[Мы весь день проходи́ли по го́роду.]{.ru} |
| [сбега́ть / сбе́гать]{.ru} | [сбега́ть]{.ru} 跑下来，逃跑（[сбежа́ть]{.ru} 的未完成体） | [сбе́гать]{.ru} 跑一趟 |
| [избега́ть / избе́гать]{.ru} | [избега́ть]{.ru} 躲避（[избежа́ть]{.ru} 的未完成体） | [избе́гать]{.ru} 跑遍 |
| [проводи́ть]{.ru} | 引导，举行，度过（[провести́]{.ru} 的未完成体） | 送行，陪着走（[провожа́ть]{.ru} 的完成体）：[Я провожу́ тебя́ до метро́.]{.ru} |

### 常见错误

::: err
\*[Я прийду́ в семь.]{.ru}　→　[Я **приду́** в семь.]{.ru}

[прийти́]{.ru} 的将来时不写 [й]{.ru}：[приду́, придёшь]{.ru}。
:::

::: err
\*[Он вышёл из ко́мнаты.]{.ru}　→　[Он **вы́шел** из ко́мнаты.]{.ru}

[вы́-]{.ru} 构成的完成体重音永远在 [вы́-]{.ru} 上，[шёл]{.ru} 的元音不再重读，写 [е]{.ru}。
:::

::: err
\*[Ра́ньше он ка́ждый день пришёл в во́семь.]{.ru}　→　[Ра́ньше он ка́ждый день **приходи́л** в во́семь.]{.ru}

带前缀的运动动词照一般规则选体，反复用未完成体。
:::

::: err
\*[Вчера́ ко мне ходи́л Ди́ма.]{.ru}　→　[Вчера́ ко мне **приходи́л** Ди́ма.]{.ru}

从说话人这里看，迪马是“来过”，用 [приходи́л]{.ru}；[ходи́л]{.ru} 要从迪马出发的地方看：[Ди́ма ходи́л ко мне]{.ru} 也通，但说的是迪马的行程。
:::

::: err
\*[Ле́том я ча́сто съе́здил к ба́бушке.]{.ru}　→　[Ле́том я ча́сто **е́здил** к ба́бушке.]{.ru}

[съе́здить]{.ru} 是完成体，只说一次；经常往返用 [е́здить]{.ru}。
:::

## §7.6.7 前缀 [при-]{.ru}、[у-]{.ru}、[в-]{.ru}、[вы-]{.ru}

### 形式

四个前缀构成的常用动词（未完成体 / 完成体）：

| 原动词 | [при-]{.ru} 来到 | [у-]{.ru} 离开 | [в- (во-)]{.ru} 进入 | [вы-]{.ru} 出去 |
|---|---|---|---|---|
| [ходи́ть / идти́]{.ru} | [приходи́ть / прийти́]{.ru} | [уходи́ть / уйти́]{.ru .ix key="уходи́ть"} | [входи́ть / войти́]{.ru .ix key="входи́ть"} | [выходи́ть / вы́йти]{.ru .ix key="выходи́ть"} |
| [е́здить / е́хать]{.ru} | [приезжа́ть / прие́хать]{.ru} | [уезжа́ть / уе́хать]{.ru .ix key="уезжа́ть"} | [въезжа́ть / въе́хать]{.ru} | [выезжа́ть / вы́ехать]{.ru} |
| [бе́гать / бежа́ть]{.ru} | [прибега́ть / прибежа́ть]{.ru} | [убега́ть / убежа́ть]{.ru} | [вбега́ть / вбежа́ть]{.ru} | [выбега́ть / вы́бежать]{.ru} |
| [лета́ть / лете́ть]{.ru} | [прилета́ть / прилете́ть]{.ru} | [улета́ть / улете́ть]{.ru} | [влета́ть / влете́ть]{.ru} | [вылета́ть / вы́лететь]{.ru} |
| [пла́вать / плыть]{.ru} | [приплыва́ть / приплы́ть]{.ru} | [уплыва́ть / уплы́ть]{.ru} | [вплыва́ть / вплыть]{.ru} | [выплыва́ть / вы́плыть]{.ru} |
| [носи́ть / нести́]{.ru} | [приноси́ть / принести́]{.ru} | [уноси́ть / унести́]{.ru} | [вноси́ть / внести́]{.ru} | [выноси́ть / вы́нести]{.ru} |
| [води́ть / вести́]{.ru} | [приводи́ть / привести́]{.ru} | [уводи́ть / увести́]{.ru} | [вводи́ть / ввести́]{.ru} | [выводи́ть / вы́вести]{.ru} |
| [вози́ть / везти́]{.ru} | [привози́ть / привезти́]{.ru} | [увози́ть / увезти́]{.ru} | [ввози́ть / ввезти́]{.ru} | [вывози́ть / вы́везти]{.ru} |

和这四个前缀连用的前置词：

| 前缀 | 去向（[куда́]{.ru}） | 出发点（[отку́да]{.ru}） |
|---|---|---|
| [при-]{.ru} | [в, на]{.ru} 加第四格；[к]{.ru} 加第三格（人）；[домо́й, сюда́]{.ru} | [из, с]{.ru} 加第二格；[от]{.ru} 加第二格（人） |
| [у-]{.ru} | [в, на]{.ru} 加第四格；[к]{.ru} 加第三格（人） | [из, с]{.ru} 加第二格；[от]{.ru} 加第二格（人）；[отсю́да]{.ru} |
| [в-]{.ru} | [в, на]{.ru} 加第四格 | — |
| [вы-]{.ru} | [в, на]{.ru} 加第四格（出来到哪里） | [из]{.ru} 加第二格（[с]{.ru} 少用）；[от]{.ru} 加第二格（人） |

[в]{.ru} 和 [из]{.ru}、[на]{.ru} 和 [с]{.ru}、[к]{.ru} 和 [от]{.ru} 成对：[прийти́ в шко́лу — уйти́ из шко́лы]{.ru}，[прийти́ на рабо́ту — уйти́ с рабо́ты]{.ru}，[прийти́ к дру́гу — уйти́ от дру́га]{.ru}。名词用 [в]{.ru} 还是 [на]{.ru} 见 §9.2.1，三组前置词的对应见 §9.2.2。

### 意义和用法

**[при-]{.ru}：到达。** [при-]{.ru} 表示到达某处，重点在到达以后人在那里：[Он пришёл]{.ru} 是“他到了，人在这儿了”。

**[у-]{.ru}：离开。** [у-]{.ru} 表示离开某处，重点在离开以后人不在原处：[Он ушёл]{.ru} 是“他走了，不在这儿了”。

::: ex
[Ба́бушка **пришла́** к нам.]{.ru}

[奶奶来我们家了。（现在在这里）]{.gloss}

[Ба́бушка **ушла́** домо́й.]{.ru}

[奶奶回家了。（现在不在这里）]{.gloss}

[Ве́чером па́па **прие́хал** и **привёз** цветы́.]{.ru}

[晚上爸爸回来了，带回了花。]{.gloss}

[Па́па **уе́хал** в командиро́вку на неде́лю.]{.ru}

[爸爸出差去了，要去一个星期。]{.gloss}
:::

**[при-]{.ru} 不等于“来”。** 汉语的“来”指朝说话人移动，俄语的 [при-]{.ru} 指到达目的地，与说话人在哪里无关：[Он пришёл в шко́лу в во́семь]{.ru} 是“他八点到的学校”，说话人可能根本不在学校。同样，[у-]{.ru} 也不等于“去”，它只说离开原处。“明天我来找你”说 [За́втра я приду́ к тебе́]{.ru}（到你那里），“明天我去看医生”说 [За́втра я пойду́ к врачу́]{.ru}（动身去），也可以说 [приду́ к врачу́]{.ru}（到医生那里），只是侧重到达。

**[пошёл]{.ru}、[ушёл]{.ru} 和 [вы́шел]{.ru}。** 三个都能回答“他人呢”：[пошёл]{.ru} 说他动身朝某处去了（侧重去向），[ушёл]{.ru} 说他离开了这里（侧重不在），[вы́шел]{.ru} 说他从屋里出去了，常常一会儿就回来。办公室里回答“他出去一下”说 [Он вы́шел]{.ru}；说“他已经下班走了”说 [Он уже́ ушёл]{.ru}。

**[в-]{.ru}：进入；[вы-]{.ru}：出去。** 两个前缀都是穿过某个封闭空间的边界：[в-]{.ru} 从外到里，[вы-]{.ru} 从里到外。

::: ex
[Учи́тель **вошёл** в класс.]{.ru}

[老师走进教室。]{.gloss}

[Из воро́т **вы́ехала** маши́на.]{.ru}

[一辆汽车从大门里开了出来。]{.gloss}

[Мы **вы́шли** на у́лицу.]{.ru}

[我们走到街上。]{.gloss}

[Ми́ша **вы́нес** му́сор.]{.ru}

[米沙把垃圾拿出去了。]{.gloss}
:::

[вы́йти]{.ru} 还有几个常用的意思：

- 出门：[Мы вы́шли в де́вять]{.ru}（我们九点出的门），后面可以不说从哪儿出来；出去做某事：[вы́йти погуля́ть]{.ru}。
- 下车：[вы́йти из авто́буса]{.ru}；车上问别人下不下车：[Вы выхо́дите на сле́дующей?]{.ru}（您下一站下吗？）。
- [вы́ехать, вы́лететь]{.ru} 表示出发，从一个城市、一个地方动身：[Мы вы́ехали в шесть утра́]{.ru}（我们早上六点出发），[Самолёт вылета́ет в де́сять]{.ru}（飞机十点起飞）。与 [прие́хать, прилете́ть]{.ru}（到达）相对。

**及物动词。** [принести́, привести́, привезти́]{.ru} 是“带来”（东西、领来的人、用车运来的人和东西，选择见 §7.6.3）；[унести́, увести́, увезти́]{.ru} 是“带走”；[внести́]{.ru} 是“拿进来”，[вы́нести]{.ru} 是“拿出去”；[ввезти́]{.ru} 是“运进、进口”，[вы́везти]{.ru} 是“运出、出口”：[Кита́й выво́зит чай]{.ru}。

::: ex
[Принеси́, пожа́луйста, стака́н воды́.]{.ru}

[请拿一杯水来。]{.gloss}

[Кто **увёз** мою́ су́мку?]{.ru}

[谁把我的包带走了？（坐车走了）]{.gloss}

[А́нна **привела́** на пра́здник подру́гу.]{.ru}

[安娜带了个朋友来参加聚会。]{.gloss}
:::

**未完成体现在时表示将来。** 出发和到达常常是事先安排好的，所以这几组动词的未完成体现在时常表示计划中的将来：[Шесто́го ве́чером мы уезжа́ем]{.ru}（我们六号晚上走），[По́езд прихо́дит в Москву́ в семь утра́]{.ru}（火车早上七点到莫斯科）。

### 常见错误

::: err
\*[Я пришёл в Москву́ из Пеки́на в а́вгусте.]{.ru}　→　[Я **прие́хал** в Москву́ из Пеки́на в а́вгусте.]{.ru}

从北京到莫斯科不可能步行，用 [прие́хать]{.ru}（或 [прилете́ть]{.ru}）。带前缀的动词也要分步行和乘交通工具。
:::

::: err
\*[Вчера́ я ушёл из дру́га по́здно.]{.ru}　→　[Вчера́ я ушёл **от дру́га** по́здно.]{.ru}

离开某人用 [от]{.ru} 加第二格；[из]{.ru} 用于离开某个地方。
:::

::: err
\*[Пётр Ива́нович ушёл, подожди́те пять мину́т.]{.ru}　→　[Пётр Ива́нович **вы́шел**, подожди́те пять мину́т.]{.ru}

出去一下、一会儿回来用 [вы́шел]{.ru}；[ушёл]{.ru} 表示走了，今天不会回来了。
:::

::: err
\*[Ка́ждое у́тро я прихожу́ к университе́ту в де́вять.]{.ru}（想说“到学校”）　→　[Ка́ждое у́тро я прихожу́ **в университе́т** в де́вять.]{.ru}

到达某个机构、进到里面用 [в, на]{.ru} 加第四格；[к]{.ru} 加第三格用于人，用于地方时表示到它跟前（[подойти́ к университе́ту]{.ru}，§7.6.8）。
:::

| [пере-]{.ru} | 越过；从一处移到另一处 | 第四格或 [че́рез]{.ru} 加第四格；[из… в…]{.ru}，[на]{.ru} 加第四格 | [перейти́ (че́рез) у́лицу]{.ru}；[перее́хать в но́вую кварти́ру]{.ru} |
| [про-]{.ru} | 经过；穿过；走完一段；走过头 | [ми́мо]{.ru} 加第二格；[че́рез]{.ru} 加第四格，[по]{.ru} 加第三格；第四格 | [пройти́ ми́мо по́чты]{.ru}；[пройти́ че́рез парк]{.ru}；[пройти́ пять киломе́тров]{.ru} |
| [за-]{.ru} | 顺路去一下；去接、去取；绕到后面；走远 | [в, на]{.ru} 加第四格，[к]{.ru} 加第三格；[за]{.ru} 加第五格；[за]{.ru} 加第四格 | [зайти́ в магази́н]{.ru}；[зайти́ за дру́гом]{.ru}；[зайти́ за дом]{.ru} |

### 意义和用法

**[под-]{.ru}：走近。** 移动到某人、某物跟前，用 [к]{.ru} 加第三格：

::: ex
[Ван Лэй **подошёл** к окну́.]{.ru}

[王磊走到窗前。]{.gloss}

[Такси́ **подъе́хало** к до́му.]{.ru}

[出租车开到了楼前。]{.gloss}

[Тебя́ **подвезти́**?]{.ru}

[要不要我顺便捎你一段？]{.gloss}
:::

[подвезти́]{.ru} 是开车顺便捎带一段路，口语常用。[подойти́]{.ru} 还有“合适”的转义（§7.6.10）。

**[от-]{.ru}：离开一段距离。** 从某人、某物身边走开，不走远，用 [от]{.ru} 加第二格：[Отойди́ от окна́]{.ru}（离窗户远点）。地铁里的广播 [Отойди́те от кра́я платфо́рмы]{.ru}（请远离站台边缘）就是这个意思。及物的 [отнести́, отвести́, отвезти́]{.ru} 另有一个常用意义：把东西或人送到应该去的地方，留在那里，后面用 [в, на]{.ru} 加第四格，[к]{.ru} 加第三格：

::: ex
[Ка́ждое у́тро оте́ц **отво́дит** сы́на в де́тский сад.]{.ru}

[父亲每天早上把儿子送到幼儿园。]{.gloss}

[**Отнеси́** кни́ги в библиоте́ку.]{.ru}

[把书还到图书馆去。]{.gloss}

[Больно́го **отвезли́** в больни́цу.]{.ru}

[病人被送到医院去了。]{.gloss}
:::

**[до-]{.ru}：到达终点。** 强调走完一段路，到达了界限，用 [до]{.ru} 加第二格。常用于路远、走得吃力、问路：

::: ex
[Мы **дошли́** до ста́нции за час.]{.ru}

[我们用一个小时走到了车站。]{.gloss}

[Как **дое́хать** до вокза́ла?]{.ru}

[去火车站怎么坐车？]{.gloss}

[**Довези́те** меня́, пожа́луйста, до гости́ницы.]{.ru}

[请把我送到宾馆。]{.gloss}
:::

**[пере-]{.ru}：越过。** 从一边到另一边，直接加第四格或用 [че́рез]{.ru} 加第四格，两者同义，[че́рез]{.ru} 在 [перейти́]{.ru} 后可以省：[перейти́ у́лицу = перейти́ че́рез у́лицу]{.ru}，[переплы́ть ре́ку]{.ru}。[пере-]{.ru} 也表示从一处移到另一处，用 [из]{.ru}（[с]{.ru}）加第二格和 [в]{.ru}（[на]{.ru}）加第四格：[перее́хать из Пеки́на в Москву́]{.ru}，[перейти́ в другу́ю гру́ппу]{.ru}。[перее́хать]{.ru} 不带补语时常指搬家：[Мы перее́хали]{.ru}（我们搬家了）。及物的 [перенести́, перевести́, перевезти́]{.ru} 是把东西或人从一处移到另一处：[перевезти́ ве́щи на но́вую кварти́ру]{.ru}。

::: ex
[Здесь нельзя́ **переходи́ть** у́лицу.]{.ru}

[这里不能过马路。]{.gloss}

[Ле́том на́ша семья́ **перее́хала** на но́вую кварти́ру.]{.ru}

[夏天我们家搬进了新居。]{.gloss}
:::

**[про-]{.ru}：经过、穿过、走完。** [про-]{.ru} 的几个空间意义都和“沿着路线经过某处”有关：

1. 从某物旁边经过，用 [ми́мо]{.ru} 加第二格：[Мы прошли́ ми́мо Кремля́]{.ru}。
2. 从某物中间穿过，用 [че́рез]{.ru} 加第四格或 [по]{.ru} 加第三格：[пройти́ че́рез парк, прое́хать по мосту́]{.ru}；进到里面去，用 [в]{.ru} 加第四格：[Пройди́те в зал]{.ru}（请到大厅里去）。邀请客人进屋说 [Проходи́те!]{.ru}（请进！）。
3. 走完一段距离，加第四格：[Мы прошли́ пять киломе́тров]{.ru}。
4. 走过了头，错过：[Я прое́хал свою́ остано́вку]{.ru}（我坐过站了）。
5. 问路的 [Как пройти́ к…?]{.ru}（到……怎么走）后面用 [к]{.ru} 加第三格或 [в, на]{.ru} 加第四格：[Как пройти́ к метро́? Как пройти́ на по́чту?]{.ru}。[Как дойти́ до…?]{.ru} 和它意思相近，强调走到终点。

::: ex
[Теплохо́д ме́дленно **проплыва́л** ми́мо дере́вни.]{.ru}

[船慢慢地从村子旁边驶过。]{.gloss}

[Извини́те, как **пройти́** к Большо́му теа́тру?]{.ru}

[劳驾，到大剧院怎么走？]{.gloss}
:::

**[за-]{.ru}：顺路去一下。** [за-]{.ru} 的基本意义是在去别处的路上顺便进去一下，时间不长：

1. 去某处用 [в, на]{.ru} 加第四格，去某人那里用 [к]{.ru} 加第三格：[зайти́ в апте́ку, зайти́ к ба́бушке]{.ru}。
2. 去接某人、去取某物，用 [за]{.ru} 加第五格：[зайти́ за дру́гом]{.ru}（顺路叫上朋友），[зае́хать за детьми́ в шко́лу]{.ru}（开车去学校接孩子），[зайти́ за хле́бом]{.ru}（顺路买面包）。
3. 绕到某物后面，用 [за]{.ru} 加第四格：[зайти́ за дом]{.ru}，[Со́лнце зашло́ за ту́чу]{.ru}（太阳躲进了云里）。
4. 走得很远，走到深处：[зайти́ далеко́]{.ru}，[заплы́ть далеко́ от бе́рега]{.ru}，[зае́хать в глухо́й лес]{.ru}。

及物的 [занести́, завезти́]{.ru} 是顺路把东西或人送到某处：[Я занесу́ тебе́ кни́гу]{.ru}（我顺路把书给你送去），[Па́па завёз меня́ в шко́лу]{.ru}（爸爸顺路开车把我送到学校）。

**[прийти́]{.ru}、[зайти́]{.ru}、[подойти́]{.ru}。** 三个动词都能和 [к дру́гу]{.ru} 连用，意思不同：[прийти́ к дру́гу]{.ru} 是专程到朋友那里去；[зайти́ к дру́гу]{.ru} 是顺路去坐一会儿；[подойти́ к дру́гу]{.ru} 是走到朋友跟前（他就在附近）。同样，[уйти́ от дру́га]{.ru} 是从朋友那里离开，[отойти́ от дру́га]{.ru} 是从他身边走开几步。

**交通工具进站、开出。** 火车、公共汽车、船到站用 [подходи́ть — подойти́]{.ru}，开出用 [отходи́ть — отойти́]{.ru}，到达终点或某个城市用 [приходи́ть — прийти́]{.ru}；时刻表上的时间用未完成体现在时：

::: ex
[По́езд **подхо́дит** к платфо́рме.]{.ru}

[火车正在进站。]{.gloss}

[Наш по́езд **отхо́дит** в два́дцать три со́рок.]{.ru}

[我们的火车二十三点四十分开。]{.gloss}

[Мы опозда́ли: авто́бус уже́ **отошёл**.]{.ru}

[我们来晚了：公共汽车已经开走了。]{.gloss}
:::

### 常见错误

::: err
\*[Он подошёл до окна́.]{.ru}　→　[Он подошёл **к окну́**.]{.ru}

[под-]{.ru} 要求 [к]{.ru} 加第三格；[до]{.ru} 和 [до-]{.ru} 连用。
:::

::: err
\*[Как дойти́ к вокза́лу?]{.ru}　→　[Как **дойти́ до** вокза́ла?]{.ru} / [Как **пройти́ к** вокза́лу?]{.ru}

[дойти́]{.ru} 和 [до]{.ru} 加第二格连用，[пройти́]{.ru} 和 [к]{.ru} 加第三格连用。
:::

::: err
\*[Мы прошли́ ми́мо библиоте́ку.]{.ru}　→　[Мы прошли́ ми́мо **библиоте́ки**.]{.ru}

[ми́мо]{.ru} 要求第二格。
:::

::: err
\*[По доро́ге домо́й я зашёл в магази́н за хлеб.]{.ru}　→　[…я зашёл в магази́н **за хле́бом**.]{.ru}

去取某物、去接某人用 [за]{.ru} 加第五格；[за]{.ru} 加第四格表示到某物后面。
:::

::: err
\*[Осторо́жно переезжа́й у́лицу!]{.ru}（对步行的人说）　→　[Осторо́жно **переходи́** у́лицу!]{.ru}

步行过马路用 [переходи́ть — перейти́]{.ru}；[переезжа́ть]{.ru} 是开车、骑车过去。
:::

## §7.6.9 前缀 [об-]{.ru}、[с-]{.ru}、[раз-]{.ru}、[вз-]{.ru}

### 形式

四个前缀构成的常用动词（未完成体 / 完成体）：

| 原动词 | [об- (обо-)]{.ru} | [с- (со-)]{.ru} | [раз- (разо-, рас-) … -ся]{.ru} | [вз- (взо-, вс-)]{.ru} |
|---|---|---|---|---|
| [ходи́ть / идти́]{.ru} | [обходи́ть / обойти́]{.ru .ix key="обходи́ть"} | [сходи́ть / сойти́]{.ru .ix key="сходи́ть"} | [расходи́ться / разойти́сь]{.ru .ix key="расходи́ться"} | [всходи́ть / взойти́]{.ru .ix key="всходи́ть"} |
| [е́здить / е́хать]{.ru} | [объезжа́ть / объе́хать]{.ru} | [съезжа́ть / съе́хать]{.ru} | [разъезжа́ться / разъе́хаться]{.ru} | — |
| [бе́гать / бежа́ть]{.ru} | [обега́ть / обежа́ть]{.ru} | [сбега́ть / сбежа́ть]{.ru} | [разбега́ться / разбежа́ться]{.ru} | [взбега́ть / взбежа́ть]{.ru} |
| [лета́ть / лете́ть]{.ru} | [облета́ть / облете́ть]{.ru} | [слета́ть / слете́ть]{.ru} | [разлета́ться / разлете́ться]{.ru} | [взлета́ть / взлете́ть]{.ru} |
| [пла́вать / плыть]{.ru} | [оплыва́ть / оплы́ть]{.ru} | — | [расплыва́ться / расплы́ться]{.ru} | [всплыва́ть / всплыть]{.ru} |
| [носи́ть / нести́]{.ru} | — | [сноси́ть / снести́]{.ru} | [разноси́ть / разнести́]{.ru}（不加 [-ся]{.ru}） | — |
| [вози́ть / везти́]{.ru} | — | [свози́ть / свезти́]{.ru} | [развози́ть / развезти́]{.ru}（不加 [-ся]{.ru}） | — |

[об-]{.ru} 在 [-йти]{.ru} 前写 [обо-]{.ru}（[обойти́]{.ru}），[оплы́ть]{.ru} 用的是它的变体 [о-]{.ru}；[с-]{.ru} 在 [-йти]{.ru} 前写 [со-]{.ru}；[раз-]{.ru} 在 [-йти]{.ru} 前写 [разо-]{.ru}，在清辅音前写 [рас-]{.ru}；[вз-]{.ru} 在 [-йти]{.ru} 前写 [взо-]{.ru}，在清辅音前写 [вс-]{.ru}（[всплыть, всходи́ть]{.ru}）。在 [-е́хать]{.ru} 前加 [ъ]{.ru}：[объе́хать, съе́хать, разъе́хаться]{.ru}。

### 意义和用法

**[об-]{.ru}：绕。** 后面直接加第四格，有四个意义：

1. 绕过障碍：[обойти́ лу́жу]{.ru}（绕过水洼），[объе́хать про́бку]{.ru}（绕开堵车）。
2. 绕某物一圈：[обойти́ о́зеро]{.ru}，也说 [обойти́ вокру́г о́зера]{.ru}（[вокру́г]{.ru} 加第二格）。
3. 走遍各处、挨个到：[обойти́ все магази́ны]{.ru}，[обойти́ всех сосе́дей]{.ru}，[обойти́ весь музе́й]{.ru}。
4. 超过：[обогна́ть]{.ru}（超车，追过），[обойти́]{.ru}（在比赛中超过）。

::: ex
[**Обойди́** лу́жу, а то промо́чишь но́ги!]{.ru}

[绕过水洼，要不然会把脚弄湿的！]{.gloss}

[Ван Лэй **обошёл** весь Кремль.]{.ru}

[王磊把整个克里姆林都走遍了。]{.gloss}

[Нас **обогнала́** кра́сная маши́на.]{.ru}

[一辆红色汽车超过了我们。]{.gloss}
:::

**[с-]{.ru}：从上面下来；[с- … -ся]{.ru}：聚拢。** [с-]{.ru} 表示从某物的表面、高处下来，用 [с]{.ru} 加第二格：[сойти́ с ле́стницы, сойти́ с по́езда, съе́хать с горы́, слете́ть с ве́тки]{.ru}；沿着楼梯下来也可以用 [по]{.ru} 加第三格：[сбежа́ть по ле́стнице]{.ru}。下车说 [сойти́ с]{.ru}（从车上下来）或 [вы́йти из]{.ru}（从车里出来），两者都常用，[сойти́]{.ru} 多用于火车、轮船：[сойти́ с по́езда]{.ru}，车上也说 [Вы схо́дите на сле́дующей?]{.ru}。

加 [-ся]{.ru} 以后，[с-]{.ru} 表示从各处来到一处、聚到一起，用 [в, на]{.ru} 加第四格、[к]{.ru} 加第三格，出发点用 [из]{.ru}（[со всех концо́в]{.ru}）：[сойти́сь, съе́хаться, сбежа́ться, слете́ться]{.ru}。

::: ex
[Ра́но у́тром друзья́ **сошли́** с по́езда.]{.ru}

[一大早朋友们下了火车。]{.gloss}

[На сва́дьбу **съе́хались** ро́дственники со всей страны́.]{.ru}

[全国各地的亲戚都来参加婚礼了。]{.gloss}

[На крик **сбежа́лись** лю́ди.]{.ru}

[听到喊声，人们都跑了过来。]{.gloss}
:::

及物的 [снести́]{.ru} 是把东西拿下去（[снести́ чемода́н вниз]{.ru}），又指拆除（[снести́ ста́рый дом]{.ru}）。[сходи́ть]{.ru} 作完成体（去一趟）见 §7.6.6。

**[раз- … -ся]{.ru}：散开。** [раз-]{.ru} 加 [-ся]{.ru} 表示从一处向不同方向散开，与 [с- … -ся]{.ru} 正好相反：[сойти́сь — разойти́сь, съе́хаться — разъе́хаться]{.ru}。去向常用 [по]{.ru} 加复数第三格（[разойти́сь по дома́м]{.ru}，各自回家）或 [в ра́зные сто́роны]{.ru}：

::: ex
[По́сле конце́рта все **разошли́сь** по дома́м.]{.ru}

[音乐会以后大家都各自回家了。]{.gloss}

[Уви́дев соба́ку, ко́шки **разбежа́лись**.]{.ru}

[猫一看见狗，都四散跑开了。]{.gloss}
:::

及物的 [разнести́, развезти́]{.ru} 不加 [-ся]{.ru}，表示把东西或人分别送到各处：[разнести́ по́чту]{.ru}（分送信件），[развезти́ госте́й по гости́ницам]{.ru}（分别把客人送到各个宾馆）。[разойти́сь]{.ru} 还有“离婚”“意见分歧”等转义（§7.6.10）。

**[вз-]{.ru}：向上。** [вз-]{.ru} 表示向上移动，用 [на]{.ru} 加第四格：[взойти́ на го́ру, взойти́ на трибу́ну, взбежа́ть по ле́стнице на тре́тий эта́ж]{.ru}；[взлете́ть]{.ru}（飞起来，起飞），[всплыть]{.ru}（浮出水面），[Со́лнце взошло́]{.ru}（太阳升起来了）。

[вз-]{.ru} 带书面色彩，口语里人往上走多用 [подня́ться на]{.ru} 加第四格：[подня́ться на пя́тый эта́ж]{.ru}，[подня́ться на ли́фте]{.ru}。[взлете́ть]{.ru} 和 [вы́лететь]{.ru} 也要分清：[взлете́ть]{.ru} 是离开地面飞起来（[Самолёт взлете́л]{.ru}），[вы́лететь]{.ru} 是从某个城市出发（[Мы вы́летели из Москвы́ в во́семь]{.ru}）。

::: ex
[Мы **взошли́** на верши́ну горы́ к полу́дню.]{.ru}

[我们中午前登上了山顶。]{.gloss}

[Самолёт **взлете́л**, и под на́ми показа́лся го́род.]{.ru}

[飞机起飞了，脚下出现了城市。]{.gloss}
:::

**其他前缀。** [на-]{.ru} 加运动动词表示撞上、碰上，用 [на]{.ru} 加第四格：[Маши́на нае́хала на столб]{.ru}（汽车撞上了电线杆）；[из-]{.ru} 加在 [гнать]{.ru} 等少数动词上表示赶出（[изгна́ть]{.ru}，书面）。前缀的非空间意义（[перечита́ть, доигра́ть]{.ru} 等）见 §7.3.5、§11.3.3。

| [у-]{.ru} | 离开 | [из, с, от]{.ru} 加第二格；[в, на]{.ru} 加第四格，[к]{.ru} 加第三格 | [уйти́ с рабо́ты, уе́хать в Каза́нь]{.ru} | §7.6.7 |
| [в- (во-)]{.ru} | 进入 | [в, на]{.ru} 加第四格 | [войти́ в ко́мнату, въе́хать на мост]{.ru} | §7.6.7 |
| [вы-]{.ru} | 出去，出发 | [из]{.ru} 加第二格；[в, на]{.ru} 加第四格 | [вы́йти из до́ма, вы́йти на у́лицу]{.ru} | §7.6.7 |
| [под- (подо-)]{.ru} | 走近 | [к]{.ru} 加第三格 | [подойти́ к две́ри]{.ru} | §7.6.8 |
| [от- (ото-)]{.ru} | 走开（不远）；送到 | [от]{.ru} 加第二格；[в, на]{.ru} 加第四格 | [отойти́ от окна́, отвести́ сы́на в сад]{.ru} | §7.6.8 |
| [до-]{.ru} | 到达终点 | [до]{.ru} 加第二格 | [дойти́ до угла́]{.ru} | §7.6.8 |
| [пере-]{.ru} | 越过；移到另一处 | 第四格，[че́рез]{.ru} 加第四格；[из… в…]{.ru} | [перейти́ у́лицу, перее́хать в Москву́]{.ru} | §7.6.8 |
| [про-]{.ru} | 经过，穿过，走完，走过头 | [ми́мо]{.ru} 加第二格；[че́рез]{.ru} 加第四格，[по]{.ru} 加第三格；第四格 | [пройти́ ми́мо шко́лы, прое́хать остано́вку]{.ru} | §7.6.8 |
| [за-]{.ru} | 顺路去；去接、去取；绕到后面 | [в, на]{.ru} 加第四格，[к]{.ru} 加第三格；[за]{.ru} 加第五格；[за]{.ru} 加第四格 | [зайти́ к дру́гу, зайти́ за дру́гом, зайти́ за дом]{.ru} | §7.6.8 |
| [об- (обо-)]{.ru} | 绕过，绕一圈，走遍，超过 | 第四格；[вокру́г]{.ru} 加第二格 | [обойти́ лу́жу, обойти́ вокру́г до́ма]{.ru} | §7.6.9 |
| [с- (со-)]{.ru} | 从上面下来 | [с]{.ru} 加第二格；[по]{.ru} 加第三格 | [сойти́ с по́езда]{.ru} | §7.6.9 |
| [с- … -ся]{.ru} | 聚拢 | [в, на]{.ru} 加第四格，[к]{.ru} 加第三格 | [съе́хаться на сва́дьбу]{.ru} | §7.6.9 |
| [раз- … -ся]{.ru} | 散开 | [по]{.ru} 加第三格 | [разойти́сь по дома́м]{.ru} | §7.6.9 |
| [вз- (взо-, вс-)]{.ru} | 向上 | [на]{.ru} 加第四格；[по]{.ru} 加第三格 | [взойти́ на го́ру]{.ru} | §7.6.9 |

表中可以看出一条总的规律：前缀和前置词常常是同一个词或意义相同：[в-]{.ru} 配 [в]{.ru}，[вы-]{.ru} 配 [из]{.ru}，[от-]{.ru} 配 [от]{.ru}，[до-]{.ru} 配 [до]{.ru}，[с-]{.ru} 配 [с]{.ru}，[под-]{.ru} 配表示接近的 [к]{.ru}。表示去向的前置词（[в, на]{.ru} 加第四格，[к]{.ru}）和表示出发点的前置词（[из, с, от]{.ru} 加第二格）可以同时出现：[прие́хать из Пеки́на в Москву́]{.ru}。

### 常见错误

::: err
\*[Мы обошли́ вокру́г дом.]{.ru}　→　[Мы обошли́ **вокру́г до́ма**.]{.ru} / [Мы **обошли́ дом**.]{.ru}

[вокру́г]{.ru} 要求第二格；不用前置词时，[обойти́]{.ru} 直接加第四格。
:::

::: err
\*[Я сошёл из авто́буса.]{.ru}　→　[Я **сошёл с** авто́буса.]{.ru} / [Я **вы́шел из** авто́буса.]{.ru}

[с-]{.ru} 配 [с]{.ru}，[вы-]{.ru} 配 [из]{.ru}，不能交叉。
:::

::: err
\*[По́сле уро́ка все разошли́ по дома́м.]{.ru}　→　[По́сле уро́ка все **разошли́сь** по дома́м.]{.ru}

“散开”的意义由 [раз-]{.ru} 和 [-ся]{.ru} 一起表示，[-ся]{.ru} 不能省。
:::

::: err
\*[Мы взошли́ на пя́тый эта́ж на ли́фте.]{.ru}　→　[Мы **подняли́сь** на пя́тый эта́ж на ли́фте.]{.ru}

[взойти́]{.ru} 是书面语，指自己走上去，日常说上楼、坐电梯上去用 [подня́ться]{.ru}。
:::

## §7.6.10 运动动词的转义

### 意义和用法

运动动词，特别是 [идти́]{.ru} 和带前缀的 [-йти́]{.ru}，有大量不表示空间移动的转义。转义用法有一条共同的规则：**定向与不定向的区别不再起作用，每个转义固定用其中一个动词**，不能换成另一个；即使是经常、反复的事，也不换。

**1. 不带前缀的定向动词。** 下列转义只用定向动词：

| 说什么 | 例句 | 汉译 |
|---|---|---|
| 时间流逝 | [Вре́мя идёт (лети́т, бежи́т).]{.ru} | 时间在流逝（飞逝）。 |
| 雨、雪 | [Идёт дождь. Шёл снег.]{.ru} | 下着雨。（那时）在下雪。 |
| 演出、放映 | [В кинотеа́тре идёт но́вый фильм.]{.ru} | 电影院在放一部新片。 |
| 活动在进行 | [Идёт уро́к. Шла война́.]{.ru} | 正在上课。那时正在打仗。 |
| 事情的进展 | [Как иду́т дела́?]{.ru} | 事情进展得怎么样？ |
| 钟表走 | [Часы́ иду́т пра́вильно.]{.ru} | 表走得准。 |
| 邮件在途 | [Письмо́ идёт неде́лю.]{.ru} | 信要走一个星期。 |
| 话题 | [Речь идёт о ва́шей рабо́те.]{.ru} | 说的是您的工作。 |
| 道路通往 | [Доро́га ведёт к реке́.]{.ru} | 这条路通到河边。 |
| 合适，相称 | [Тебе́ идёт э́то пла́тье.]{.ru} | 这条连衣裙你穿着好看。 |
| 运气 | [Ему́ везёт.]{.ru} | 他运气好。 |

经常、反复的也用定向动词：[Здесь ча́сто иду́т дожди́]{.ru}（这里常下雨），[Э́тот фильм идёт ка́ждый ве́чер]{.ru}。不能说 [*Хо́дит дождь]{.ru}、[*Вре́мя хо́дит]{.ru}。这些转义仍有完整的时：[Шёл дождь]{.ru}，[За́втра бу́дет идти́ дождь]{.ru}（明天会下雨，口语多说 [За́втра бу́дет дождь]{.ru}）。表示开始和结束用带前缀的完成体：

| 句子 | 意思 |
|---|---|
| [Идёт дождь.]{.ru} | 正在下雨。 |
| [Шёл дождь.]{.ru} | 那时正下着雨。 |
| [Весь день шёл дождь.]{.ru} | 下了一整天雨。 |
| [Пошёл дождь.]{.ru} | 下起雨来了。 |
| [Дождь прошёл.]{.ru} | 雨停了。 |

[идёт]{.ru} 表示“合适”时说的是衣着、发型、颜色和人的相貌相称，主体用第三格：[Вам о́чень идёт э́тот цвет]{.ru}（这个颜色很衬您）。说尺寸、条件合适用 [подходи́ть]{.ru}：[Э́тот разме́р мне не подхо́дит]{.ru}（这个尺码我穿不了），[Тако́е вре́мя вам подхо́дит?]{.ru}（这个时间您方便吗？）。[везёт]{.ru} 是无人称用法，人用第三格，完成体是 [повезти́]{.ru}：[Нам повезло́ с пого́дой]{.ru}（我们赶上了好天气）。

**2. 不带前缀的不定向动词。** 不定向动词的转义多和“经常带在身上”有关：[носи́ть очки́, носи́ть бо́роду]{.ru}（戴眼镜，留胡子，§7.6.3），[носи́ть и́мя, носи́ть фами́лию]{.ru}（名叫……，姓……）；[ходи́ть в]{.ru} 加第六格表示经常穿着：[Он всегда́ хо́дит в джи́нсах]{.ru}（他总穿牛仔裤）；[води́ть маши́ну]{.ru}（会开车，§7.6.3）。

**3. 及物定向动词的固定搭配。** [вести́ уро́к, вести́ себя́, вести́ дневни́к, вести́ перегово́ры]{.ru} 等见 §7.6.3；[вести́ к]{.ru} 加第三格表示导致：[Э́то ведёт к оши́бкам]{.ru}；[нести́ отве́тственность]{.ru}（承担责任）是书面语。

**4. 带前缀的运动动词。** 带前缀的动词的转义很多，这里列出最常用的：

| 动词（完成体） | 转义 | 例句 | 汉译 |
|---|---|---|---|
| [пойти́]{.ru} | 开始（雨、雪）；开始上学；像（父母） | [Пошёл снег.]{.ru} [Сын пошёл в шко́лу.]{.ru} [Он пошёл в отца́.]{.ru} | 下起雪来了。儿子上学了。他长得像父亲。 |
| [пройти́]{.ru} | 停止，消失；（时间）过去；经过（某种过程） | [Боль прошла́.]{.ru} [Прошла́ неде́ля.]{.ru} [Как прошёл экза́мен?]{.ru} | 不疼了。一个星期过去了。考试考得怎么样？ |
| [прийти́]{.ru} | （季节）来到；（想法）产生；达到 | [Пришла́ весна́.]{.ru} [Мне пришла́ в го́лову мысль.]{.ru} [Мы пришли́ к вы́воду…]{.ru} | 春天来了。我想到一个主意。我们得出结论…… |
| [прийти́ в себя́]{.ru} | 苏醒，回过神来 | [Он не сра́зу пришёл в себя́.]{.ru} | 他过了一会儿才回过神来。 |
| [прийти́сь]{.ru} | 不得不（无人称，人用第三格） | [Мне пришло́сь уйти́ ра́ньше.]{.ru} | 我不得不早走。 |
| [вы́йти]{.ru} | （书）出版；结果是；（女子）嫁给 | [Кни́га вы́шла в ма́е.]{.ru} [Ничего́ не вы́шло.]{.ru} [Она́ вы́шла за́муж за врача́.]{.ru} | 书五月出版。什么也没做成。她嫁给了一位医生。 |
| [вы́йти на пе́нсию]{.ru} | 退休 | [Оте́ц вы́шел на пе́нсию.]{.ru} | 父亲退休了。 |
| [уйти́]{.ru} | 辞去；（时间、钱）花在…… | [Он ушёл с рабо́ты.]{.ru} [На доро́гу ушло́ три часа́.]{.ru} | 他辞职了。路上花了三个小时。 |
| [провести́]{.ru} | 度过（时间）；举办 | [Где вы провели́ о́тпуск?]{.ru} [Провели́ собра́ние.]{.ru} | 您在哪儿度的假？开了会。 |
| [перевести́]{.ru} | 翻译 | [Переведи́те текст на кита́йский.]{.ru} | 请把课文译成汉语。 |
| [перенести́]{.ru} | 推迟，改期；经受 | [Встре́чу перенесли́ на пя́тницу.]{.ru} [Он тяжело́ перенёс боле́знь.]{.ru} | 会面改到星期五了。他这场病害得很重。 |
| [подойти́]{.ru} | 合适 | [Э́тот вариа́нт нам подойдёт.]{.ru} | 这个方案对我们合适。 |
| [дойти́ до]{.ru} | 发展到（某种程度） | [Де́ло дошло́ до ссо́ры.]{.ru} | 事情闹到吵起来了。 |
| [зайти́]{.ru} | （谈话）涉及；（太阳）落下 | [Разгово́р зашёл о рабо́те.]{.ru} [Со́лнце зашло́.]{.ru} | 话题转到了工作上。太阳落山了。 |
| [произойти́]{.ru} | 发生 | [Что произошло́?]{.ru} | 出什么事了？ |
| [сойти́ с ума́]{.ru} | 发疯 | [Ты сошёл с ума́?]{.ru} | 你疯了吗？ |
| [разойти́сь]{.ru} | 离婚；（意见）分歧 | [Они́ разошли́сь.]{.ru} [На́ши мне́ния разошли́сь.]{.ru} | 他们离婚了。我们的意见不一致。 |
| [обойти́сь]{.ru} | 将就，用不着 | [Мы обойдёмся без такси́.]{.ru} | 我们不用打车也行。 |
| [привести́ к]{.ru} | 导致 | [Э́то привело́ к ава́рии.]{.ru} | 这导致了事故。 |
| [вы́нести]{.ru} | 忍受（多用于否定） | [Я не могу́ э́того вы́нести.]{.ru} | 这我受不了。 |

带前缀的转义动词照常有体对，按一般规则选体：[выходи́ть — вы́йти за́муж]{.ru}，[проводи́ть — провести́ вре́мя]{.ru}，[переводи́ть — перевести́]{.ru}：[Он перево́дит с ру́сского на кита́йский]{.ru}（他做俄译汉的翻译），[Я перевёл э́ту статью́]{.ru}（我把这篇文章译完了）。

**及物和不及物要分清。** [пройти́]{.ru} 说时间自己过去，主语是时间：[Прошло́ два го́да]{.ru}（两年过去了）；[провести́]{.ru} 说人度过时间，主语是人，时间是第四格补语：[Мы провели́ там два го́да]{.ru}（我们在那里过了两年）。汉语都说“过”，俄语要选不同的动词。

**汉语的“下雨”“放电影”。** 汉语说“下雨”“下雪”，俄语说雨雪“走”：[идёт дождь]{.ru}，不用 [па́дать]{.ru}（[па́дать]{.ru} 只用于雪花、雨点飘落的描写：[Ти́хо па́дает снег]{.ru}）。汉语“放电影”“演戏”的主体是人，俄语说电影、戏本身“走”：[идёт фильм]{.ru}，[идёт спекта́кль]{.ru}。

::: ex
[Как бы́стро **идёт** вре́мя!]{.ru}

[时间过得真快！]{.gloss}

[Когда́ мы вы́шли из теа́тра, **шёл** снег.]{.ru}

[我们从剧院出来的时候，正下着雪。]{.gloss}

[По доро́ге домо́й **пошёл** дождь, но ско́ро **прошёл**.]{.ru}

[回家路上下起了雨，不过很快就停了。]{.gloss}

[Тебе́ **идёт** коро́ткая стри́жка.]{.ru}

[你留短发好看。]{.gloss}

[Ле́то **прошло́** незаме́тно.]{.ru}

[夏天不知不觉就过去了。]{.gloss}

[Ле́то мы **провели́** на да́че.]{.ru}

[夏天我们是在别墅过的。]{.gloss}
:::

### 常见错误

::: err
\*[Сего́дня весь день ходи́л дождь.]{.ru}　→　[Сего́дня весь день **шёл** дождь.]{.ru}

下雨、下雪只用定向动词 [идти́]{.ru}，不用 [ходи́ть]{.ru}。
:::

::: err
\*[Как ты прошёл кани́кулы?]{.ru}　→　[Как ты **провёл** кани́кулы?]{.ru}

人度过时间用及物的 [провести́]{.ru}；[пройти́]{.ru} 的主语是时间本身：[Как прошли́ кани́кулы?]{.ru}
:::

::: err
\*[Мне пришло́ в го́лову хоро́шая иде́я.]{.ru}　→　[Мне **пришла́** в го́лову хоро́шая иде́я.]{.ru}

主语是 [иде́я]{.ru}（阴性），过去时要和它一致。这个句子不是无人称句，[мне]{.ru} 不是主语。
:::

::: err
\*[Она́ вы́шла за́муж с ним.]{.ru}　→　[Она́ вы́шла за́муж **за него́**.]{.ru}

[вы́йти за́муж]{.ru} 后面用 [за]{.ru} 加第四格；男子结婚说 [жени́ться на ком]{.ru}。
:::

::: err
\*[Э́ти брю́ки мне не иду́т, они́ мне малы́.]{.ru}　→　[Э́ти брю́ки мне не **подхо́дят**, они́ мне малы́.]{.ru}

尺寸不合适用 [подходи́ть]{.ru}；[идти́]{.ru} 说的是穿上好不好看。
:::
