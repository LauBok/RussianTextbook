叙述中引进别人说的话、想的事，叫转述他人言语。俄语有三种基本方式：原话照录的直接引语（§13.4.1），改成说明从句的间接引语（§13.4.2），介于两者之间、文学作品里常见的准直接引语（§13.4.3）；此外还有插入语、语气词等辅助手段和引用的格式（§13.4.4）。间接引语就是说明从句，说明从句本身的结构见 §13.2.5；直接引语和对话的标点见 §14.2.2，引号的用法见 §14.2.3。

## §13.4.1 直接引语

### 形式

别人的话、想法叫[他人言语]{.term}（[чужа́я речь]{.ru}）。把他人言语一字不改地照录下来，叫[直接引语]{.term}（[пряма́я речь]{.ru}）；交代谁说的、怎样说的那一部分，叫[作者的话]{.term}（[слова́ а́втора]{.ru}）。作者的话的核心是[说话动词]{.term}（[глаго́л ре́чи]{.ru}）：[сказа́ть, спроси́ть, отве́тить]{.ru} 等。

作者的话可以在直接引语之前、之后或中间。下表用 [А]{.ru} 表示作者的话，[П]{.ru} 表示直接引语，大写字母表示该部分以大写字母开头（各种格式的标点细则见 §14.2.2）：

| 作者的话的位置 | 格式 | 例句 | 作者的话的语序 |
|---|---|---|---|
| 在前 | [А: «П».]{.ru} | [А́нна сказа́ла: «Я сего́дня задержу́сь».]{.ru} | 主语—谓语 |
| 在后 | [«П», — а.]{.ru} | [«Я сего́дня задержу́сь», — сказа́ла А́нна.]{.ru} | 谓语—主语（倒装） |
| 在后，引语是问句、感叹句 | [«П?» — а.]{.ru}、[«П!» — а.]{.ru} | [«Ты когда́ вернёшься?» — спроси́ла ма́ма.]{.ru} | 谓语—主语（倒装） |
| 在中间，引语是一句 | [«П, — а, — п».]{.ru} | [«Я ду́маю, — сказа́ла А́нна, — что задержу́сь».]{.ru} | 谓语—主语（倒装） |
| 在中间，引语是两句 | [«П, — а. — П».]{.ru} | [«Не жди́те меня́, — сказа́ла А́нна. — Я сего́дня задержу́сь».]{.ru} | 谓语—主语（倒装） |

对话中每句话另起一行，前面加破折号，不用引号：

::: ex
[— Ты когда́ вернёшься? — спроси́ла ма́ма.]{.ru}

[— По́здно, часо́в в де́сять, — отве́тила А́нна.]{.ru}

[——你什么时候回来？——妈妈问。]{.gloss}

[——很晚，十点钟左右，——安娜回答。]{.gloss}
:::

### 意义和用法

**直接引语保留原话的一切。** 直接引语是原话的照录，原话里的人称、时、式、语调，呼语、感叹词、语气词、口语词，甚至说错的地方，都原样保留：

::: ex
[Ми́ша закрича́л: «Ма́ма, я сдал экза́мен!»]{.ru}

[米沙喊道：“妈妈，我考试及格了！”]{.gloss}

[«Ну, ты даёшь!» — засмея́лся Пьер.]{.ru}

[“嘿，你可真行！”皮埃尔笑了起来。]{.gloss}
:::

所以直接引语使叙述生动，让读者直接听到人物的声音。文学作品里人物的对话，新闻里当事人的原话，论文里引用的名言，都用直接引语。

**作者的话的语序。** 作者的话在直接引语前面时，用正常的语序“主语—谓语”：[А́нна сказа́ла: «…»]{.ru}。作者的话在直接引语后面或中间时，说话动词放在主语前面：[«…», — сказа́ла А́нна]{.ru}；[«…», — сказа́л он]{.ru}。主语是人称代词时也这样倒装。这是因为直接引语已经是句子的出发点，作者的话只是补充交代说话人，说话动词紧接在引语之后，像汉语的“……，他说”。

作者的话里除了说话动词，还可以有说话的对象、方式、伴随的动作：

::: ex
[«Не волну́йся», — ти́хо сказа́л оте́ц до́чери.]{.ru}

[“别担心。”父亲轻声对女儿说。]{.gloss}

[«Не зна́ю», — отве́тил Ван Лэй и пожа́л плеча́ми.]{.ru}

[“不知道。”王磊回答，耸了耸肩。]{.gloss}
:::

**说话动词的选择。** [сказа́ть]{.ru}（[говори́ть]{.ru}）是中性的说话动词，什么话都能引。其他说话动词在“说”之外还表示话的性质（问、答、补充、反驳），说话的方式（喊、低语），或者说话人的意图（请求、建议、承认），选用哪一个，由引语的内容决定。常用的说话动词如下：

| 说话动词（未完成体 / 完成体） | 意义 | 支配 | 用法要点 |
|---|---|---|---|
| [говори́ть / сказа́ть]{.ru .ix} | 说 | [кому́]{.ru} | 中性，任何引语都能用 |
| [спра́шивать / спроси́ть]{.ru .ix} | 问 | [кого́]{.ru}；[у кого́]{.ru} | 引语是问句 |
| [переспра́шивать / переспроси́ть]{.ru} | 再问一遍，追问 | [кого́]{.ru} | 没听清或不相信时 |
| [отвеча́ть / отве́тить]{.ru .ix} | 回答 | [кому́]{.ru} | 引语是对问题的回答 |
| [возража́ть / возрази́ть]{.ru} | 反驳 | [кому́]{.ru} | 引语与对方的话相反 |
| [добавля́ть / доба́вить]{.ru} | 补充 | [кому́]{.ru} | 接着自己或别人的话再说一句 |
| [продолжа́ть / продо́лжить]{.ru} | 接着说 | — | 话被打断后继续 |
| [замеча́ть / заме́тить]{.ru .ix} | （顺便）说一句，指出 | [кому́]{.ru} | 简短的评论；不是“注意到” |
| [отмеча́ть / отме́тить]{.ru} | 指出 | — | 书面、新闻 |
| [подчёркивать / подчеркну́ть]{.ru .ix} | 强调 | — | 书面、新闻 |
| [признава́ться / призна́ться]{.ru .ix} | 承认，坦白 | [кому́ в чём]{.ru} | 说出自己不好说的事 |
| [объясня́ть / объясни́ть]{.ru} | 解释 | [кому́]{.ru} | 说明原因、道理 |
| [сообща́ть / сообщи́ть]{.ru} | 告知，通报 | [кому́]{.ru} | 消息、新闻 |
| [заявля́ть / заяви́ть]{.ru} | 声明，宣布 | — | 正式、公开的话 |
| [восклица́ть / воскли́кнуть]{.ru} | 惊呼，喊道 | — | 引语是感叹句 |
| [крича́ть / закрича́ть, кри́кнуть]{.ru} | 喊 | [кому́]{.ru} | 大声说 |
| [шепта́ть / прошепта́ть]{.ru} | 低声说 | [кому́]{.ru} | 小声说 |
| [бормота́ть / пробормота́ть]{.ru} | 嘟囔 | — | 含糊不清地说 |
| [проси́ть / попроси́ть]{.ru} | 请求 | [кого́]{.ru} | 引语是请求 |
| [предлага́ть / предложи́ть]{.ru} | 建议，提议 | [кому́]{.ru} | 引语是建议 |
| [сове́товать / посове́товать]{.ru} | 劝，建议 | [кому́]{.ru} | 引语是劝告 |
| [напомина́ть / напо́мнить]{.ru} | 提醒 | [кому́]{.ru} | 说对方可能忘了的事 |
| [ду́мать / поду́мать]{.ru} | 想 | — | 引出人物内心的话 |

几个容易用错的词：

- [заме́тить]{.ru} 作说话动词是“说了一句、评论道”，不是“注意到”：[«Ты сего́дня гру́стный», — заме́тила А́нна]{.ru}（“你今天不太高兴啊。”安娜说）。“注意到”的意思不引直接引语。
- [призна́ться]{.ru} 是承认自己的事（“坦白”）：[«Я боя́лся экза́мена», — призна́лся Ми́ша]{.ru}；[призна́ть]{.ru} 是承认别人对、承认某个事实：[«Ты прав», — призна́л оте́ц]{.ru}。
- [рассказа́ть]{.ru} 是“讲述”一件事、一段经历，宾语是 [что]{.ru} 或 [о чём]{.ru}，一般不引一两句短话；引一句话用 [сказа́ть]{.ru}。
- [спроси́ть]{.ru} 支配第四格（[спроси́л меня́]{.ru}）或 [у]{.ru} 加第二格（[спроси́л у меня́]{.ru}），不支配第三格；[отве́тить]{.ru} 支配第三格（[отве́тил мне]{.ru}）。

在文学作品里，作者的话也可以只用一个表示表情、动作的动词：[улыбну́ться, засмея́ться, вздохну́ть, кивну́ть, удиви́ться, обра́доваться]{.ru}。这些动词本身不是说话动词，放在直接引语后面时，读者自然理解为“一边……一边说”：

::: ex
[«Ну что ж, пое́хали», — вздохну́л Ива́н Серге́евич.]{.ru}

[“好吧，走吧。”伊万·谢尔盖耶维奇叹了口气。]{.gloss}

[«Ты уже́ здесь?» — удиви́лась Ю́ми.]{.ru}

[“你已经到了？”由美惊讶地说。]{.gloss}
:::

**说话动词的体和时。** 引一次具体说出的话，作者的话用完成体过去时（[сказа́л, спроси́л, отве́тил]{.ru}），这是叙述中最常见的形式。用未完成体过去时（[говори́л, спра́шивал]{.ru}）有三种情况：话是反复说的；话是在别的动作进行时说的，作背景；十九世纪文学的习惯用法，如 [отвеча́л он]{.ru}，与完成体意思差不多。新闻、访谈和评论里常用现在时：[«…», — говори́т дире́ктор]{.ru}，[— счита́ет экспе́рт]{.ru}，[— подчёркивает а́втор]{.ru}，表示这是当事人一贯的、现在仍然持有的看法。

::: ex
[«Учи́сь, пока́ молодо́й», — не раз говори́л мне оте́ц.]{.ru}

[“趁年轻好好学习。”父亲不止一次对我说。]{.gloss}

[«Спрос на биле́ты растёт ка́ждый год», — отмеча́ет дире́ктор теа́тра.]{.ru}

[“票的需求每年都在增长。”剧院经理指出。]{.gloss}
:::

新闻报道里同一个人的话一再引用时，说话动词要换着用，不连用几个 [сказа́л]{.ru}：先 [заяви́л]{.ru}，再 [доба́вил, подчеркну́л, отме́тил]{.ru}，同时注意动词要与引语的内容相配：引的是解释用 [объясни́л]{.ru}，引的是补充用 [доба́вил]{.ru}。

**内心的话。** 人物没有说出口、只是在心里想的话，也可以用直接引语，说话动词用 [поду́мать, реши́ть, сказа́ть себе́]{.ru}：

::: ex
[«Опя́ть опозда́ю», — поду́мал Ван Лэй.]{.ru}

[“又要迟到了。”王磊想。]{.gloss}

[Она́ реши́ла: «Бо́льше я ему́ звони́ть не бу́ду».]{.ru}

[她打定主意：“我再也不给他打电话了。”]{.gloss}
:::

**俄汉对比。** 汉语直接引语的说话人常放在前面（“他说：……”），放在后面时主语仍在动词前（“……，他说”）；俄语作者的话放在后面或中间时一定倒装成“动词—主语”。汉语对话里“他问”“她回答”常常重复使用“说”；俄语叙述里说话动词的选择更讲究，同一个动词连用显得单调。

### 常见错误

::: err
\*[«Я приду́ за́втра», — он сказа́л.]{.ru}　→　[«Я приду́ за́втра», — **сказа́л он**.]{.ru}

作者的话在直接引语后面时，说话动词放在主语前面，主语是代词也一样。
:::

::: err
\*[Он рассказа́л: «Я уста́л».]{.ru}　→　[Он **сказа́л**: «Я уста́л».]{.ru}

[рассказа́ть]{.ru} 是讲述一件事、一段经历，引一句短话用 [сказа́ть]{.ru}。
:::

::: err
\*[Он спроси́л мне: «Ты студе́нт?»]{.ru}　→　[Он спроси́л **меня́**: «Ты студе́нт?»]{.ru}

[спроси́ть]{.ru} 支配第四格（或 [у]{.ru} 加第二格），汉语“问我”让人想到第三格 [мне]{.ru}。
:::

::: err
\*[Он спроси́л: «Да́йте, пожа́луйста, воды́».]{.ru}　→　[Он **попроси́л**: «Да́йте, пожа́луйста, воды́».]{.ru}

[спроси́ть]{.ru} 是“问”，引出问句；[попроси́ть]{.ru} 是“请求”，引出请求。两个词同根，读音相近，容易混。
:::

## §13.4.2 直接引语改为间接引语

### 形式

用说明从句转述别人的话，叫[间接引语]{.term}（[ко́свенная речь]{.ru}）。间接引语不加引号，作者的话成了主句，原话成了从句。原话的类型决定用什么连接：

| 原话的类型 | 连接手段 | 主句常用的动词 | 直接引语 | 间接引语 |
|---|---|---|---|---|
| 陈述句 | 连词 [что]{.ru .ix} | [сказа́ть, отве́тить, сообщи́ть, написа́ть, объясни́ть]{.ru} | [Ди́ма сказа́л: «Я приду́ в шесть».]{.ru} | [Ди́ма сказа́л, что придёт в шесть.]{.ru} |
| 特殊疑问句 | 原来的疑问词 | [спроси́ть, поинтересова́ться]{.ru} | [Ми́ша спроси́л: «Где ты был?»]{.ru} | [Ми́ша спроси́л, где я был.]{.ru} |
| 一般疑问句 | 语气词 [ли]{.ru .ix} | [спроси́ть, поинтересова́ться]{.ru} | [Она́ спроси́ла: «Вы здоро́вы?»]{.ru} | [Она́ спроси́ла, здоро́в ли я.]{.ru} |
| 选择疑问句 | [ли… и́ли…]{.ru} | [спроси́ть]{.ru} | [Он спроси́л: «Ты пойдёшь и́ли оста́нешься?»]{.ru} | [Он спроси́л, пойду́ ли я и́ли оста́нусь.]{.ru} |
| 请求、命令 | 连词 [что́бы]{.ru .ix} 加过去时形式 | [сказа́ть, попроси́ть, потре́бовать, веле́ть]{.ru} | [Па́па сказа́л Све́те: «Позвони́ ба́бушке!»]{.ru} | [Па́па сказа́л, что́бы Све́та позвони́ла ба́бушке.]{.ru} |
| 请求、命令、建议 | 不定式 | [попроси́ть, посове́товать, предложи́ть, веле́ть]{.ru} | [Ма́ма сказа́ла Ди́ме: «Помоги́ мне».]{.ru} | [Ма́ма попроси́ла Ди́му помо́чь ей.]{.ru} |

此外原话里的人称、物主代词、指示词和时间地点词要按转述人的角度改换，原话的时不变，原话的感叹、语气词等由主句动词或别的词语表达。下面按步骤讲。

### 意义和用法

**第一步：按原话类型选连接手段。** 陈述句用 [что]{.ru}；特殊疑问句保留原来的疑问词（[где, когда́, что, кто, како́й, почему́]{.ru} 等），不加 [что]{.ru}；一般疑问句用 [ли]{.ru}；请求和命令用 [что́бы]{.ru} 或不定式。间接引语是陈述句的一部分，转述问句时句末用句号，不用问号：

::: ex
[Ка́тя спроси́ла: «Когда́ А́ня бу́дет до́ма?»]{.ru}

[→ Ка́тя спроси́ла, когда́ А́ня бу́дет до́ма.]{.ru}

[卡佳问安尼娅什么时候在家。]{.gloss}

[А́нна спроси́ла: «Где бу́дет конце́рт?»]{.ru}

[→ А́нна спроси́ла, где бу́дет конце́рт.]{.ru}

[安娜问音乐会在哪儿举行。]{.gloss}
:::

[ли]{.ru} 的位置：把问题的焦点（被问的词）放在从句开头，[ли]{.ru} 紧跟在它后面。焦点通常是动词，也可以是别的词，焦点不同，问的内容不同。[ли]{.ru} 永远不在从句的第一个位置：

::: ex
[Она́ спроси́ла: «Вы де́лали упражне́ния?»]{.ru}

[→ Она́ спроси́ла, де́лал ли я упражне́ния.]{.ru}

[她问我做没做练习。]{.gloss}

[→ Она́ спроси́ла, упражне́ния ли я де́лал.]{.ru}

[她问我做的是不是练习（而不是别的）。]{.gloss}

[Она́ спроси́ла: «У вас есть спра́вка?»]{.ru}

[→ Она́ спроси́ла, есть ли у меня́ спра́вка.]{.ru}

[她问我有没有证明。]{.gloss}
:::

原话本身带疑问词和不定式时，从句照样用不定式，主体用第三格：

::: ex
[Он спроси́л: «Что мне де́лать?»]{.ru}

[→ Он спроси́л, что ему́ де́лать.]{.ru}

[他问他该怎么办。]{.gloss}
:::

**转述请求和命令。** 原话是命令式时，有两种转述方法：

1. [что́бы]{.ru} 加过去时形式。这里的过去时形式不表示过去，是 [что́бы]{.ru} 要求的形式（见 §13.2.5），性和数跟从句的主语一致；体照原话：原话用完成体，转述也用完成体；原话是否定的未完成体命令式，转述也用 [не]{.ru} 加未完成体。
2. 主句动词加不定式。主句动词是 [проси́ть / попроси́ть]{.ru}（加第四格），[сове́товать / посове́товать, предлага́ть / предложи́ть, веле́ть, приказа́ть, разреша́ть / разреши́ть, запреща́ть / запрети́ть]{.ru}（加第三格），执行动作的人就是主句里这个第四格或第三格的人。

::: ex
[Учи́тель сказа́л нам: «Не опа́здывайте!»]{.ru}

[→ Учи́тель сказа́л, что́бы мы не опа́здывали.]{.ru}

[老师叫我们别迟到。]{.gloss}

[Ма́ма сказа́ла Ди́ме: «Переда́й Све́те поздравле́ния».]{.ru}

[→ Ма́ма попроси́ла, что́бы Ди́ма переда́л Све́те поздравле́ния.]{.ru}

[→ Ма́ма попроси́ла Ди́му переда́ть Све́те поздравле́ния.]{.ru}

[妈妈请迪马向斯韦塔转达祝贺。]{.gloss}

[Врач сказа́л мне: «Бо́льше гуля́йте».]{.ru}

[→ Врач посове́товал мне бо́льше гуля́ть.]{.ru}

[医生劝我多散步。]{.gloss}
:::

[дава́й(те)]{.ru} 加动词表示的提议，用 [предложи́ть]{.ru} 加不定式转述：[Пьер сказа́л: «Дава́йте пойдём в кино́»]{.ru} → [Пьер предложи́л пойти́ в кино́]{.ru}（皮埃尔提议去看电影）。

转述请求不能用 [что]{.ru}：[что]{.ru} 转述的是陈述，[что́бы]{.ru} 转述的是要求，两者意思完全不同：

::: ex
[Он сказа́л, что я позвони́л ба́бушке.]{.ru}

[他说我给奶奶打了电话。（转述陈述）]{.gloss}

[Он сказа́л, что́бы я позвони́л ба́бушке.]{.ru}

[他叫我给奶奶打电话。（转述吩咐）]{.gloss}
:::

**第二步：改人称和物主代词。** 原话里的 [я, ты, мы, вы]{.ru} 和 [мой, твой, наш, ваш]{.ru} 是从原说话人的角度说的，转述时要换成从转述人的角度看它们指谁，动词的人称跟着变。先问自己：原话里的“我”“你”现在是谁，转述的人又是谁、在对谁说：

| 原话 | 谁转述、对谁说 | 间接引语 |
|---|---|---|
| [Ка́тя: «Я купи́ла биле́ты».]{.ru} | 别人转述 | [Ка́тя сказа́ла, что она́ купи́ла биле́ты.]{.ru} |
| [Ка́тя — Ван Лэ́ю: «Когда́ А́ня бу́дет до́ма?»]{.ru} | 王磊对安娜说 | [Она́ спроси́ла, когда́ ты бу́дешь до́ма.]{.ru} |
| [А́нна — Ди́ме: «Ты сказа́л Све́те?»]{.ru} | 迪马对斯韦塔说 | [А́нна спроси́ла, сказа́л ли я тебе́.]{.ru} |
| [Све́та: «Э́то моё пла́тье».]{.ru} | 迪马对大家说 | [Све́та сказа́ла, что э́то её пла́тье.]{.ru} |

物主代词的选择：从句里的“自己的”指从句的主语时用 [свой]{.ru}；指的不是从句的主语（例如指主句的主语，而从句另有主语）时用 [его́, её, их]{.ru}（[свой]{.ru} 的规则见 §5.2.2）：

::: ex
[Ди́ма сказа́л: «Я забы́л свой телефо́н».]{.ru}

[→ Ди́ма сказа́л, что забы́л свой телефо́н.]{.ru}

[迪马说他把手机忘了。（从句主语是迪马本人：[свой]{.ru}）]{.gloss}

[Све́та сказа́ла: «Мой брат живёт в Москве́».]{.ru}

[→ Све́та сказа́ла, что её брат живёт в Москве́.]{.ru}

[斯韦塔说她哥哥住在莫斯科。（从句主语是 [брат]{.ru}：[её]{.ru}）]{.gloss}
:::

从句主语与主句主语相同、是第三人称代词时，常常省去：[Ди́ма сказа́л, что придёт]{.ru}；不省也对，省去更自然。

**第三步：时不后移。** 间接引语里动词的时保持原话的时，不随主句的过去时改变。原因在于俄语从句的时以主句动作（说话那一刻）为准，是时的相对用法（见 §7.2.5）：现在时表示与说话同时，过去时表示在说话以前，将来时表示在说话以后。

| 原话 | 间接引语 | 汉译 |
|---|---|---|
| [«Я живу́ в Москве́».]{.ru} | [Он сказа́л, что **живёт** в Москве́.]{.ru} | 他说他住在莫斯科（说话时住在那里）。 |
| [«Я жил в Москве́».]{.ru} | [Он сказа́л, что **жил** в Москве́.]{.ru} | 他说他（以前）在莫斯科住过。 |
| [«Я бу́ду жить в Москве́».]{.ru} | [Он сказа́л, что **бу́дет** жить в Москве́.]{.ru} | 他说他将来要住在莫斯科。 |

英语转述时要“时态后移”（he said he lived…），俄语不后移。从句里换成过去时，意思就变成了“以前”：[Он сказа́л, что был бо́лен]{.ru} 是“他说他（以前）病过”，不是“他说他病了”。汉语在这一点上和俄语相同（“他说他病了”），中国学生犯这个错误，大多是受了英语的影响。

时不变，式也不变：原话里的假定式在间接引语里仍用假定式：[«Я бы пое́хал с ва́ми»]{.ru} → [Он сказа́л, что пое́хал бы с на́ми]{.ru}。

**第四步：指示词和时间、地点词。** 转述的时间、地点与原话不同时，原话里以说话时刻、说话地点为准的词要换掉：

| 原话 | 转述（换了时间、地点） |
|---|---|
| [сего́дня]{.ru} | [в тот день]{.ru} |
| [вчера́]{.ru} | [накану́не]{.ru} |
| [за́втра]{.ru} | [на сле́дующий день]{.ru} |
| [сейча́с]{.ru} | [тогда́, в тот моме́нт]{.ru} |
| [здесь, сюда́]{.ru} | [там, туда́]{.ru} |
| [э́тот]{.ru} | [тот]{.ru} |

::: ex
[В понеде́льник Ми́ша сказа́л: «Я сего́дня свобо́ден».]{.ru}

[→ В понеде́льник Ми́ша сказа́л, что в тот день он был свобо́ден.]{.ru}

[星期一米沙说那天他有空。]{.gloss}
:::

注意上例从句里用了过去时 [был]{.ru}：这是因为转述人现在是从另一个时间回头讲那天的事，“那天有空”在转述人看来已经过去了。这不是英语那样机械的后移，而是换了参照的时刻。如果转述就在当天，词不必换，时也不变：[Ми́ша сказа́л, что сего́дня он свобо́ден]{.ru}。

**第五步：呼语、感叹词、语气词。** 间接引语是叙述的一部分，原话里只属于口语对话的成分要去掉，它们的意思由主句的动词、补语和状语表达：

- 呼语去掉，被称呼的人成为主句动词的补语：[Ма́ма сказа́ла: «А́нна, помоги́ мне»]{.ru} → [Ма́ма попроси́ла А́нну помо́чь ей]{.ru}。
- 感叹词去掉，感情由动词或状语表示：[«Ой, как бо́льно!» — вскри́кнула Ю́ми]{.ru} → [Ю́ми вскри́кнула от бо́ли]{.ru}。
- 感叹句用 [что]{.ru} 转述，或者保留 [как, како́й]{.ru}：[Пьер сказа́л: «Како́й краси́вый го́род!»]{.ru} → [Пьер сказа́л, что го́род о́чень краси́вый]{.ru}；[Пьер восхища́лся тем, како́й краси́вый э́тот го́род]{.ru}。
- 问句里的 [ра́зве, неуже́ли]{.ru} 表示惊讶、怀疑，转述时一般改成 [пра́вда ли, что…]{.ru}，惊讶由主句动词表示：[«Неуже́ли он уе́хал?»]{.ru} → [Она́ удиви́лась и спроси́ла, пра́вда ли, что он уе́хал]{.ru}。口语里也说 [Она́ спроси́ла, неуже́ли он уе́хал]{.ru}。
- 插入语里表示说话人态度的 [коне́чно, к сожале́нию]{.ru} 等可以保留，它们仍表示原说话人的态度。

**带 [не]{.ru} 的问句。** 原话是带 [не]{.ru} 的问句（委婉的询问、建议、关心），转述时 [не]{.ru} 和动词一起放在 [ли]{.ru} 前面，委婉的口气也保留下来：

::: ex
[Ма́ма спроси́ла Све́ту: «Ты не бои́шься жить одна́?»]{.ru}

[→ Ма́ма спроси́ла, не бои́тся ли Све́та жить одна́.]{.ru}

[妈妈问斯韦塔一个人住怕不怕。]{.gloss}

[Ми́ша спроси́л: «Ди́ма, ты не хо́чешь ча́ю?»]{.ru}

[→ Ми́ша спроси́л, не хо́чет ли Ди́ма ча́ю.]{.ru}

[米沙问迪马想不想喝茶。]{.gloss}
:::

**选主句动词。** 改成间接引语时，主句的说话动词要与原话的类型相配：转述问句用 [спроси́ть]{.ru}，转述请求用 [попроси́ть]{.ru}，转述建议用 [предложи́ть, посове́товать]{.ru}，转述回答用 [отве́тить]{.ru}。原话的语气（惊讶、生气、高兴）在间接引语里没有别的地方表达，常常靠主句动词（[удиви́ться, возмути́ться, обра́доваться]{.ru}）和状语（[с удивле́нием, серди́то]{.ru}）。说话动词的辨析见 §13.4.1。

**完整的转述示例。**

::: ex
[— Ван Лэй, ты не зна́ешь, где А́нна? — спроси́ла О́льга Ви́кторовна. — Пожа́луйста, переда́й ей, что́бы она́ зашла́ ко мне за́втра.]{.ru}

[→ О́льга Ви́кторовна спроси́ла Ван Лэ́я, не зна́ет ли он, где А́нна, и попроси́ла переда́ть А́нне, что́бы та зашла́ к ней на сле́дующий день.]{.ru}

[——王磊，你知道安娜在哪儿吗？——奥尔加·维克托罗夫娜问。——请转告她，让她明天到我这儿来一趟。→ 奥尔加·维克托罗夫娜问王磊知不知道安娜在哪儿，请他转告安娜第二天到她那儿去一趟。]{.gloss}
:::

这一句里用到了上面所有的步骤：带 [не]{.ru} 的问句用 [не… ли]{.ru}；呼语 [Ван Лэй]{.ru} 成了 [спроси́ла]{.ru} 的补语；请求用 [попроси́ть]{.ru} 加不定式，转告的内容是 [что́бы]{.ru} 从句；[ей]{.ru} 换成 [А́нне]{.ru}，从句主语用 [та]{.ru}，免得与 [О́льга Ви́кторовна]{.ru} 混淆；[ко мне]{.ru} 换成 [к ней]{.ru}；[за́втра]{.ru} 换成 [на сле́дующий день]{.ru}。

### 常见错误

::: err
\*[Он сказа́л, что был бо́лен.]{.ru}（想转述 [«Я бо́лен»]{.ru}）　→　[Он сказа́л, что **бо́лен**.]{.ru}

俄语间接引语的时不后移。用过去时，意思是“他说他以前病过”。
:::

::: err
\*[Она́ спроси́ла, е́сли я зна́ю его́ а́дрес.]{.ru} / \*[Она́ спроси́ла, что зна́ю ли я его́ а́дрес.]{.ru}　→　[Она́ спроси́ла, **зна́ю ли** я его́ а́дрес.]{.ru}

英语的 if 在这里是“是否”，俄语用 [ли]{.ru}，不用 [е́сли]{.ru}（“如果”）；[ли]{.ru} 前也不加 [что]{.ru}。
:::

::: err
\*[Она́ спроси́ла, ли я зна́ю его́ а́дрес.]{.ru}　→　[Она́ спроси́ла, **зна́ю ли** я его́ а́дрес.]{.ru}

[ли]{.ru} 不放在从句开头，紧跟在被问的词（这里是动词）后面。
:::

::: err
\*[Ди́ма сказа́л, что я приду́ в шесть.]{.ru}（转述迪马的话 [«Я приду́ в шесть»]{.ru}）　→　[Ди́ма сказа́л, что **он придёт** в шесть.]{.ru}

原话的 [я]{.ru} 指迪马，转述时要换成第三人称，动词也跟着变。
:::

::: err
\*[Ма́ма сказа́ла, что Ми́ша убра́л ко́мнату.]{.ru}（转述 [«Ми́ша, убери́ ко́мнату!»]{.ru}）　→　[Ма́ма сказа́ла, **что́бы** Ми́ша убра́л ко́мнату.]{.ru}

转述命令用 [что́бы]{.ru}；用 [что]{.ru} 就成了“妈妈说米沙收拾了房间”。
:::

::: err
\*[Ма́ма попроси́ла, что́бы Ди́ма переда́ст Све́те поздравле́ния.]{.ru}　→　[…что́бы Ди́ма **переда́л**…]{.ru}

[что́бы]{.ru} 后面的谓语一律用过去时形式，不用将来时。
:::

## §13.4.3 准直接引语

### 形式

[准直接引语]{.term}（[несо́бственно-пряма́я речь]{.ru}）是叙述者用自己的话、却带着人物的声音转述人物的话语和想法。它在形式上是叙述的一部分：没有引号，没有 [сказа́л, поду́мал]{.ru} 一类引导的词，人称和时与叙述一致；在内容和语气上却是人物的：保留人物的问句、感叹句、不完整的句子、语气词和口语词，表达人物的评价和情感。三种转述方式的区别如下：

| 特点 | 直接引语 | 间接引语 | 准直接引语 |
|---|---|---|---|
| 引号、作者的话 | 有 | 有作者的话（主句），无引号 | 都没有 |
| 句法上 | 独立的句子 | 从句 | 独立的句子，属于叙述 |
| 人称 | 人物的角度（[я]{.ru}） | 叙述者的角度（[он]{.ru}） | 叙述者的角度（[он]{.ru}） |
| 时 | 人物说话时的时 | 原话的时 | 一般随叙述用过去时 |
| 问句、感叹、语气词、口语词 | 保留 | 去掉或改写 | 保留 |
| 谁的声音 | 人物 | 叙述者 | 人物与叙述者交融 |

同一个内容的三种说法：

::: ex
[А́нна посмотре́ла на часы́ и поду́мала: «Уже́ де́сять! Где же Ми́ша? Опя́ть, наве́рное, сиди́т у дру́га».]{.ru}

[安娜看了看表，心想：“已经十点了！米沙到底在哪儿？大概又在朋友家坐着呢。”（直接引语）]{.gloss}

[А́нна посмотре́ла на часы́. Она́ не понима́ла, где Ми́ша, и ду́мала, что он, наве́рное, опя́ть сиди́т у дру́га.]{.ru}

[安娜看了看表。她不明白米沙在哪儿，心想他大概又在朋友家坐着。（间接引语）]{.gloss}

[А́нна посмотре́ла на часы́. Уже́ де́сять! Где же Ми́ша? Опя́ть, наве́рное, сиди́т у дру́га и забы́л про всё на све́те.]{.ru}

[安娜看了看表。已经十点了！米沙到底在哪儿？大概又在朋友家坐着，把什么都忘到脑后了。（准直接引语）]{.gloss}
:::

第三种说法里，[Уже́ де́сять! Где же Ми́ша?]{.ru} 既不是叙述者向读者报告时间、提出问题，也没有用引号标明是安娜的话；读者从感叹、问句和语气词 [же]{.ru} 体会出这是安娜心里的焦急。

### 意义和用法

**形式标志。** 准直接引语没有固定的语法标记，要从下列迹象判断：

1. 叙述中突然出现问句、感叹句，而这些问题和感叹不可能是叙述者向读者发出的；
2. 出现语气词（[же, ведь, ну, ра́зве, неуже́ли]{.ru}）、口语词、插入语（[наве́рное, коне́чно]{.ru}）和不完整的句子，带着人物说话的口吻；
3. 出现人物的评价，用的是人物而不是叙述者的眼光；
4. 人称仍是第三人称，时仍随叙述（叙述用过去时，准直接引语一般也用过去时；但人物此刻的想法也常用现在时，如上例的 [сиди́т]{.ru}）。

**在叙述中的作用。** 准直接引语让叙述者“钻进”人物的意识，用人物的眼光看事情，读者不知不觉地从外部的叙述转到人物的内心，又不必打断叙述去加引号、写“他想”。它的效果是：

- 人物的内心活动显得真实、直接，又不像直接引语那样把人物的话和叙述截然分开；
- 叙述者的声音和人物的声音交融，叙述者可以同情人物，也可以借人物的话流露出讽刺；
- 叙述节奏紧凑，几句短促的问句、感叹就能写出人物的情绪。

所以准直接引语是十九世纪以来俄国小说最重要的叙述手段之一，在普希金、托尔斯泰、契诃夫、布尔加科夫的作品里随处可见。下面是布尔加科夫《白卫军》里的一段，前两句是叙述，后面三个问句是少年尼科尔卡在母亲葬礼上的想法：

::: ex
[И́зредка он возводи́л их на иконоста́с, на то́нущий в полумра́ке свод алтаря́, где возноси́лся печа́льный и зага́дочный стари́к-бог, морга́л. За что така́я оби́да? Несправедли́вость? Заче́м пона́добилось отня́ть мать, когда́ все съе́хались, когда́ наступи́ло облегче́ние?]{.ru}（[М. Булга́ков]{.ru}）

[他偶尔抬眼望望圣像壁，望望沉在昏暗中的祭坛穹顶——那里高高升起一位忧郁而神秘的老者上帝——眨着眼睛。为什么要受这样的委屈？不公平？大家刚刚团聚，日子刚刚松快一些，为什么偏偏要把母亲夺走？（布尔加科夫）]{.gloss}
:::

**在非文学文本里。** 历史叙述、纪实文章里也偶尔用准直接引语，让读者感受到当事人的心情：

::: ex
[У́тром 19 а́вгуста 1991 го́да лю́ди включи́ли телеви́зоры и уви́дели бале́т «Лебеди́ное о́зеро». Его́ пока́зывали по всем кана́лам. Что случи́лось? Почему́ нет новосте́й?]{.ru}

[1991 年 8 月 19 日早上，人们打开电视，看到的是芭蕾舞《天鹅湖》。所有频道都在播它。出什么事了？为什么没有新闻？]{.gloss}
:::

后两个问句是当时守在电视机前的人们心里的疑问。在叙述事实的文本里，这种写法不宜多用：读者需要分清哪些是事实，哪些是人物的感受。

**读准直接引语的方法。** 阅读时遇到叙述中的问句、感叹和带感情的评价，先问：这是谁的声音？如果是人物的，就把它当作人物的想法来理解，不要当作叙述者（或作者本人）的观点。翻译成汉语时，可以照原样保留，也可以加上“他想”“她心里说”，使汉语读者看得明白。

### 常见错误

::: err
\*[А́нна посмотре́ла на часы́. Уже́ де́сять! Где же я Ми́шу найду́?]{.ru}　→　[…Где же она́ Ми́шу найдёт?]{.ru}

准直接引语用叙述者的人称（第三人称）；用了 [я]{.ru}，就成了没加引号的直接引语，与叙述混在一起。
:::

::: err
\*[Пьер поду́мал: где же А́нна?]{.ru}　→　[Пьер поду́мал: «Где же А́нна?»]{.ru}（直接引语） / [Пьер огляну́лся. Где же А́нна?]{.ru}（准直接引语）

有了引导词 [поду́мал]{.ru}，后面的话要用直接引语的格式，加引号；准直接引语不用引导词。
:::

## §13.4.4 其他转述方式

### 形式

除了直接引语、间接引语和准直接引语，俄语还有几种转述他人言语的手段：

| 手段 | 例子 | 语体 | 意义 |
|---|---|---|---|
| 插入语 | [по слова́м кого́, по мне́нию кого́, по да́нным чего́, по сообще́нию чего́]{.ru} | 中性、书面 | 注明消息来源或看法的主人 |
| 插入句、比较从句 | [как говори́т кто, как сообща́ет что, как пи́шет кто]{.ru} | 中性、书面 | 注明出处 |
| 前置词 [согла́сно]{.ru} | [согла́сно заявле́нию, согла́сно да́нным]{.ru} | 公文 | 依据 |
| 语气词 | [мол]{.ru}；[де, де́скать]{.ru} | 口语；旧式、俗语 | 转述，常带讥讽 |
| 连词和语气词 | [бу́дто, бу́дто бы, я́кобы]{.ru} | 中性 | 转述而对内容有怀疑 |
| 引用 | 引文加引号或不加引号，注明出处 | 书面 | 原文照录 |

### 意义和用法

**[по слова́м]{.ru}、[по мне́нию]{.ru} 一类插入语。** 它们把一句话标明为别人说的或别人认为的，句子本身仍是叙述者的陈述。这是新闻和学术文本里注明消息来源最常用的手段：

- [по слова́м]{.ru .ix} [кого́]{.ru}：据某人说（转述话语）；
- [по мне́нию]{.ru .ix} [кого́]{.ru}：在某人看来（转述看法）；
- [по да́нным]{.ru} [чего́]{.ru}：据某机构的数据；
- [по сообще́нию]{.ru} [чего́]{.ru}：据某媒体、机构报道。

后面的名词用第二格；指人时也常用物主代词：[по его́ слова́м, по её мне́нию, по их да́нным]{.ru}。[по-мо́ему, по-тво́ему]{.ru} 只表示说话人自己或对方的看法，转述第三者的看法用 [по его́ мне́нию]{.ru}。这些插入语的标点见 §14.1.2，插入语的总体分类见 §12.5.2。

::: ex
[По слова́м врача́, Ми́ша ско́ро попра́вится.]{.ru}

[据医生说，米沙很快就会好的。]{.gloss}

[По мне́нию исто́риков, го́род был осно́ван в XII ве́ке.]{.ru}

[历史学家认为，这座城市建于十二世纪。]{.gloss}

[По да́нным мэ́рии, в э́том году́ в го́роде посади́ли пять ты́сяч дере́вьев.]{.ru}

[据市政府的数据，今年城里种了五千棵树。]{.gloss}
:::

[как говори́т, как пи́шет, как сообща́ет]{.ru} 引出的插入句同样注明出处，后面接的是转述的内容：[Как сообща́ет аге́нтство ТАСС, перегово́ры зако́нчились]{.ru}（据塔斯社报道，谈判已经结束）。[согла́сно]{.ru} 加第三格是公文的说法：[согла́сно прика́зу дире́ктора]{.ru}（根据经理的命令）。

**语气词 [мол]{.ru}、[де]{.ru}。** 口语转述时，不用 [сказа́л, что]{.ru}，而在转述的话前面或中间加 [мол]{.ru}，相当于汉语的“说是”：[Он позвони́л, мол, не придёт]{.ru}。[де, де́скать]{.ru} 是旧式和俗语，常带讥讽。它们的意义和来源见 §10.2.6。用 [мол]{.ru} 转述时，人称可以保留原话的，也可以换成转述人的：[Говори́т, мол, я за́нят]{.ru} / [Говори́т, мол, он за́нят]{.ru}。

**[бу́дто]{.ru}、[бу́дто бы]{.ru}、[я́кобы]{.ru}：转述而有怀疑。** 转述别人的话而说话人不相信、不负责，用连词 [бу́дто]{.ru .ix}（[бу́дто бы]{.ru}）代替 [что]{.ru} 引出说明从句（§13.2.5），或者用语气词 [я́кобы]{.ru .ix} 放在被怀疑的部分前面：

::: ex
[Он говори́т, что был бо́лен.]{.ru}

[他说他病了。（中性的转述）]{.gloss}

[Он говори́т, бу́дто был бо́лен.]{.ru}

[他说他病了，好像是吧。（说话人不太相信）]{.gloss}

[Говоря́т, бу́дто бы он уе́хал за грани́цу.]{.ru}

[听说他好像出国了。（传闻，不可靠）]{.gloss}

[Он я́кобы был бо́лен, но его́ ви́дели в кино́.]{.ru}

[据说他病了，可有人看见他在电影院。]{.gloss}
:::

[я́кобы]{.ru} 是书面和中性的，多用于新闻和法律文本，表示“据称”“所谓”，说话人对内容保持距离：[Письмо́ я́кобы бы́ло отпра́влено ещё в ма́е]{.ru}（据称信早在五月就寄出了）。[бу́дто]{.ru} 引出的从句前面的主句是 [говори́ть, утвержда́ть, расска́зывать, писа́ть]{.ru} 一类词，或者是 [ду́мать, каза́ться, сни́ться]{.ru}（这时 [бу́дто]{.ru} 表示不真实的印象：[Мне показа́лось, бу́дто кто́-то постуча́л]{.ru}）。

**引用。** 一字不改地录下别人的书面文字，叫[引文]{.term}（[цита́та]{.ru}）。引文的格式有三种：

1. 引文像直接引语一样，前面有作者的话：作者的话后加冒号，引文放在引号里，第一个字母大写。
2. 引文成为作者句子的一部分，前面没有冒号，常在连词 [что]{.ru} 后或 [как писа́л…]{.ru} 后：引文放在引号里，第一个字母小写（即使原文是句首）。
3. 诗句引文单独成行时不加引号，后面注明作者。

::: ex
[Че́хов писа́л: «Кра́ткость — сестра́ тала́нта».]{.ru}

[契诃夫写道：“简洁是才能的姊妹。”]{.gloss}

[Че́хов счита́л, что «кра́ткость — сестра́ тала́нта».]{.ru}

[契诃夫认为“简洁是才能的姊妹”。]{.gloss}

[Как писа́л Тю́тчев, «умо́м — Росси́ю не поня́ть».]{.ru}

[正如丘特切夫所写，“用理智无法理解俄罗斯”。]{.gloss}
:::

引文必须与原文一字不差。省略引文中的一部分时，在省略处用省略号；学术著作里写成尖括号或圆括号里的省略号 [<…>]{.ru}、[(…)]{.ru}，表明是引用者删去的，而不是原文自带的省略号。引文的出处写在引文后的括号里，句号放在括号后面：

::: ex
[«Все счастли́вые се́мьи похо́жи друг на дру́га <…>» (Л. Толсто́й).]{.ru}

[“幸福的家庭都是相似的……”（列夫·托尔斯泰）]{.gloss}
:::

引文、引号和括号的标点细则见 §14.2.2、§14.2.3。

**转述方式的选择。** 写报道、论文、读书报告时，几种方式各有用处：最关键、最有分量的一句保留直接引语；一般内容用间接引语，转述得简练；只交代出处的用 [по слова́м, по мне́нию]{.ru}；对内容有保留时用 [я́кобы, бу́дто]{.ru}。写内容提要（[изложе́ние]{.ru}）时，直接引语一般都改成间接引语。

::: ex
[«Мы пока́ не мо́жем назва́ть то́чную да́ту откры́тия», — сказа́л дире́ктор музе́я.]{.ru}

[Дире́ктор музе́я сказа́л, что пока́ не мо́жет назва́ть то́чную да́ту откры́тия.]{.ru}

[По слова́м дире́ктора музе́я, то́чная да́та откры́тия пока́ неизве́стна.]{.ru}

[“我们暂时还不能说出开馆的确切日期。”博物馆馆长说。/ 博物馆馆长说，他暂时还不能说出开馆的确切日期。/ 据博物馆馆长说，开馆的确切日期暂时还不清楚。]{.gloss}
:::

### 常见错误

::: err
\*[По-мо́ему профе́ссора, э́то оши́бка.]{.ru}　→　[**По мне́нию** профе́ссора, э́то оши́бка.]{.ru}

[по-мо́ему]{.ru} 是副词，只表示说话人自己的看法，不能带第二格；转述别人的看法用 [по мне́нию]{.ru} 加第二格。
:::

::: err
\*[По его́ слова́м, он сказа́л, что опозда́ет.]{.ru}　→　[По его́ слова́м, он опозда́ет.]{.ru} / [Он сказа́л, что опозда́ет.]{.ru}

[по его́ слова́м]{.ru} 已经表示“据他说”，后面再用 [сказа́л, что]{.ru} 就重复了。
:::

::: err
\*[Он я́кобы сказа́л, что был бо́лен.]{.ru}（想说“他说他病了，可不一定是真的”）　→　[Он сказа́л, бу́дто был бо́лен.]{.ru} / [Он я́кобы был бо́лен.]{.ru}

[я́кобы]{.ru} 放在被怀疑的内容前面；放在 [сказа́л]{.ru} 前，怀疑的就成了“他说过没有”。
:::
