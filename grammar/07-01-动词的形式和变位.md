动词是俄语形式最多的词类：一个动词有人称形式、过去时、命令式、假定式、不定式、形动词和副动词，加起来一百多个形式。这些形式都由两个词干构成，规律性很强。本章先总览动词的形式体系和两个词干（§7.1.1），再讲两种变位的人称词尾（§7.1.2），然后按变位类型讲现在时词干怎样从不定式得出（§7.1.3–§7.1.4），讲变位中的辅音交替（§7.1.5）、不规则变位动词（§7.1.6）和人称形式的重音（§7.1.7），最后讲不定式及其用法（§7.1.8）。时的构成和意义见第七编第 2 章，体见第 3 章，命令式和假定式见第 4 章，形动词、副动词见第 8、9 章。全部变位类型的代表词、辅音交替表和不规则变位动词全表见附录三。

## §7.1.1 动词的形式体系

### 形式

[动词]{.term}（[глаго́л]{.ru}）表示动作、状态或过程。俄语动词的形式分两大类：一类按人称或性、数变化，在句中作谓语，叫[变位形式]{.term}（[спряга́емая фо́рма глаго́ла]{.ru}）；另一类不按人称变化，叫[非变位形式]{.term}（[неспряга́емая фо́рма глаго́ла]{.ru}）。下表以 [чита́ть]{.ru .ix}（未完成体）为例列出动词的全部形式：

| 形式 | 例 | 按什么变化 | 详见 |
|---|---|---|---|
| 现在时 | [я чита́ю, ты чита́ешь, они́ чита́ют]{.ru} | 人称、数 | §7.1.2、§7.2.1 |
| 过去时 | [он чита́л, она́ чита́ла, оно́ чита́ло, они́ чита́ли]{.ru} | 单数分性，复数不分 | §7.2.2 |
| 将来时 | [я бу́ду чита́ть]{.ru}；完成体 [я прочита́ю]{.ru} | 人称、数 | §7.2.4 |
| 命令式 | [чита́й, чита́йте]{.ru} | 数 | §7.4.1 |
| 假定式 | [чита́л бы, чита́ла бы, чита́ли бы]{.ru} | 单数分性，复数不分 | §7.4.4 |
| 不定式 | [чита́ть]{.ru} | 不变 | §7.1.8 |
| 形动词 | [чита́ющий, чита́вший, чита́емый]{.ru} | 性、数、格（像形容词） | §7.8.1 |
| 副动词 | [чита́я]{.ru} | 不变 | §7.9.1 |

前五种是变位形式，后三种是非变位形式。变位形式分属三种[式]{.term}（[наклоне́ние]{.ru}）：现在时、过去时、将来时属于[陈述式]{.term}（[изъяви́тельное наклоне́ние]{.ru}），叙述实际发生的事；[命令式]{.term}（[повели́тельное наклоне́ние]{.ru}）表示请求、命令；[假定式]{.term}（[сослага́тельное наклоне́ние]{.ru}）表示假设和愿望。三种式的意义见第七编第 4 章。

**人称形式。** 说话人是第一[人称]{.term}（[лицо́]{.ru}），听话人是第二人称，其余的人和事物是第三人称；每个人称又分单数和复数，共六个形式，叫[人称形式]{.term}（[ли́чная фо́рма глаго́ла]{.ru}）。未完成体的人称形式是现在时，完成体的人称形式变法完全相同，意义却是将来，叫[简单将来时]{.term}（[просто́е бу́дущее вре́мя]{.ru}，教程叫“完成体将来时”，见 §7.2.4）：

::: paradigm
| 人称 | 代词 | 现在时（未完成体） | 简单将来时（完成体） |
|---|---|---|---|
| 单数第一人称 | [я]{.ru} | [чита́ю]{.ru} | [прочита́ю]{.ru} |
| 单数第二人称 | [ты]{.ru} | [чита́ешь]{.ru} | [прочита́ешь]{.ru} |
| 单数第三人称 | [он, она́, оно́]{.ru} | [чита́ет]{.ru} | [прочита́ет]{.ru} |
| 复数第一人称 | [мы]{.ru} | [чита́ем]{.ru} | [прочита́ем]{.ru} |
| 复数第二人称 | [вы]{.ru} | [чита́ете]{.ru} | [прочита́ете]{.ru} |
| 复数第三人称 | [они́]{.ru} | [чита́ют]{.ru} | [прочита́ют]{.ru} |
:::

**两个词干。** 动词的全部形式由两个[词干]{.term}（[осно́ва]{.ru}）构成。去掉不定式的 [-ть, -ти]{.ru}，得到[不定式词干]{.term}（[осно́ва инфинити́ва]{.ru}）；去掉复数第三人称的词尾 [-ут, -ют, -ат, -ят]{.ru}，得到[现在时词干]{.term}（[осно́ва настоя́щего вре́мени]{.ru}）。完成体没有现在时，它的这个词干就是简单将来时的词干，名称照用。两个词干有的相同，有的差别很大：

| 不定式 | 不定式词干 | 复数第三人称 | 现在时词干 |
|---|---|---|---|
| [чита́ть]{.ru} | [чита-]{.ru} | [чита́ют]{.ru} [[чʼита́йут]]{.tr} | [читай-]{.ru} |
| [уме́ть]{.ru} | [уме-]{.ru} | [уме́ют]{.ru} | [умей-]{.ru} |
| [говори́ть]{.ru} | [говори-]{.ru} | [говоря́т]{.ru} | [говор-]{.ru} |
| [нести́]{.ru} | [нес-]{.ru} | [несу́т]{.ru} | [нес-]{.ru} |
| [писа́ть]{.ru} | [писа-]{.ru} | [пи́шут]{.ru} | [пиш-]{.ru} |
| [жить]{.ru} | [жи-]{.ru} | [живу́т]{.ru} | [жив-]{.ru} |
| [дава́ть]{.ru} | [дава-]{.ru} | [даю́т]{.ru} | [дай-]{.ru} |
| [рисова́ть]{.ru} | [рисова-]{.ru} | [рису́ют]{.ru} | [рисуй-]{.ru} |
| [мочь]{.ru} | [мог-]{.ru}（见过去时 [мог]{.ru}） | [мо́гут]{.ru} | [мог-]{.ru}，交替为 [мож-]{.ru} |

[чита́ют]{.ru} 里的 [ю]{.ru} 在元音后读 [[йу]]{.tr}，一个字母写出了“词干末的 [[й]]{.tr} + 词尾 [у]{.ru}”，所以 [чита́ть]{.ru} 的现在时词干是 [читай-]{.ru}，以辅音 [[й]]{.tr} 结尾，词尾和 [несу́т]{.ru} 的 [-ут]{.ru} 是同一个。这个看不见的 [[й]]{.tr} 是理解变位的关键：[чита́ю, уме́ю, даю́, рису́ю]{.ru} 写 [ю]{.ru}，[несу́, живу́, пишу́]{.ru} 写 [у]{.ru}，词尾其实相同，只是 [[й]]{.tr} 藏在字母 [ю]{.ru} 里。

各形式由哪个词干构成：

| 由不定式词干构成 | 由现在时词干构成 |
|---|---|
| 不定式 [писа́ть]{.ru} | 现在时 [пишу́, пи́шешь]{.ru}（完成体为简单将来时 [напишу́]{.ru}） |
| 过去时 [писа́л, писа́ла]{.ru} | 命令式 [пиши́]{.ru} |
| 假定式 [писа́л бы]{.ru} | 主动形动词现在时 [пи́шущий]{.ru} |
| 主动形动词过去时 [писа́вший]{.ru} | 被动形动词现在时（[чита́емый]{.ru}；[писа́ть]{.ru} 没有这个形式） |
| 被动形动词过去时 [напи́санный]{.ru} | 未完成体副动词 [чита́я]{.ru} |
| 完成体副动词 [написа́в]{.ru} | |

[писа́ть]{.ru} 的过去时是 [писа́л]{.ru}，不带 [ш]{.ru}，[жить]{.ru} 的过去时是 [жил]{.ru}，不带 [в]{.ru}，原因就在这里：过去时由不定式词干构成，与现在时的变化无关。只有 [дава́ть]{.ru} 一类动词的命令式和副动词例外地由不定式词干构成（[дава́й, дава́я]{.ru}，见 §7.1.4）。

**生词表的变位标注怎样推出全部形式。** 教程生词表给动词注出体、变位（I 表示第一变位，II 表示第二变位）和单数第一、第二人称，过去时不规则的再注出过去时，如 [писа́ть]{.ru} impf. I ([пишу́, пи́шешь]{.ru})，[нести́]{.ru} impf. I ([несу́, несёшь]{.ru}; past [нёс, несла́]{.ru})。词典的标注大同小异。由这几个形式可以推出全部形式：

1. 单数第一人称直接注出。它可能有别的人称没有的辅音交替（[люблю́]{.ru}，§7.1.5），也可能有别的人称没有的重音（[пишу́]{.ru}，§7.1.7）。
2. 单数第二人称给出其余各人称的词干、重音和变位：[-ешь, -ёшь]{.ru} 是第一变位，[-ишь]{.ru} 是第二变位。把 [-шь]{.ru} 换成 [-т]{.ru}、[-м]{.ru}、[-те]{.ru}，得到单数第三人称和复数第一、二人称：[пи́шешь → пи́шет, пи́шем, пи́шете]{.ru}。
3. 复数第三人称：第一变位在单数第一人称后加 [-т]{.ru}（[пишу́ → пи́шут]{.ru}，[могу́ → мо́гут]{.ru}），重音和单数第二人称相同；第二变位把单数第二人称的 [-ишь]{.ru} 换成 [-ят]{.ru}（[ж, ш, ч, щ]{.ru} 后为 [-ат]{.ru}）：[лю́бишь → лю́бят]{.ru}，[лежи́шь → лежа́т]{.ru}。
4. 过去时没有注出的，由不定式去 [-ть]{.ru} 加 [-л, -ла, -ло, -ли]{.ru}（§7.2.2）。
5. 命令式由复数第三人称的词干和单数第一人称的重音构成（§7.4.1）。

两个例子：

::: paradigm
| 人称 | [пла́кать]{.ru .ix} I ([пла́чу, пла́чешь]{.ru}) | [люби́ть]{.ru .ix} II ([люблю́, лю́бишь]{.ru}) |
|---|---|---|
| 单数第一人称 | [пла́чу]{.ru} | [люблю́]{.ru} |
| 单数第二人称 | [пла́чешь]{.ru} | [лю́бишь]{.ru} |
| 单数第三人称 | [пла́чет]{.ru} | [лю́бит]{.ru} |
| 复数第一人称 | [пла́чем]{.ru} | [лю́бим]{.ru} |
| 复数第二人称 | [пла́чете]{.ru} | [лю́бите]{.ru} |
| 复数第三人称 | [пла́чут]{.ru} | [лю́бят]{.ru} |
| 过去时 | [пла́кал, пла́кала, пла́кали]{.ru} | [люби́л, люби́ла, люби́ли]{.ru} |
| 命令式 | [плачь, пла́чьте]{.ru} | [люби́, люби́те]{.ru} |
:::

[пла́кать]{.ru} 是第一变位，交替 [к — ч]{.ru} 出现在所有人称里；[люби́ть]{.ru} 是第二变位，交替只出现在单数第一人称（§7.1.5）。不规则变位动词（§7.1.6）的形式不能这样推出，词典逐个注出。

### 意义和用法

**变位形式作谓语。** 人称形式和主语在人称、数上一致：[я чита́ю, А́нна чита́ет, мы чита́ем]{.ru}。单数名词作主语配单数第三人称，复数名词和用 [и]{.ru} 连起来的几个名词配复数第三人称：[Ива́н Серге́евич и Мари́я Никола́евна гуля́ют]{.ru}。用 [вы]{.ru} 尊称一个人，动词也用复数：[Ива́н Серге́евич, вы рабо́таете?]{.ru} 过去时和假定式没有人称，只和主语在性、数上一致（§7.2.2）。主谓一致的复杂情况（数词、集合名词作主语等）见 §12.2.5。

**人称代词的省略。** 人称形式的词尾已经表明了人称，所以对话中第一、第二人称代词常常省去，尤其在回答里：[— Что де́лаешь? — Чита́ю.]{.ru} 不过俄语一般的叙述里代词照常说出，不像有些语言那样经常省略；过去时不分人称，代词更不能省：[я чита́л]{.ru}、[он чита́л]{.ru} 只靠代词区分。不说主语、谓语用复数第三人称，表示不确定的行为者（[Тебе́ звоня́т]{.ru}，有人给你打电话），见 §12.4.2；用单数第二人称泛指任何人，见 §12.4.3。

**一个形式同时表示几个范畴。** 汉语动词没有形态变化，“我读、你读、他读、昨天读、明天读”里的“读”都一样，人称靠代词，时间靠“昨天、明天”和“了、过、要”等词。俄语动词的一个形式同时表明人称（或性）、数、时、式，还带着体（第七编第 3 章）：[прочита́ла]{.ru} 一个词就说明了“主语是一个女性或阴性名词、动作在过去、作为整体完成了”。所以说俄语时每个动词都要同时作出几项选择，不能像汉语那样只把动词原形放进句子。

**现在时与简单将来时同形。** 未完成体和完成体的人称形式变法一样，意义不同：[чита́ю]{.ru} 是“我在读、我常读”，[прочита́ю]{.ru} 是“我将读完”。区分全靠动词的体，见 §7.3.1、§7.2.4。

::: ex
[— Что ты **де́лаешь**? — **Чита́ю**.]{.ru}

[——你在干什么？——看书。]{.gloss}

[Мари́я Никола́евна, вы **рабо́таете** за́втра?]{.ru}

[玛丽亚·尼古拉耶夫娜，您明天上班吗？]{.gloss}

[Вчера́ А́нна **чита́ла** весь ве́чер.]{.ru}

[昨天安娜看了一晚上书。]{.gloss}

[За́втра я **прочита́ю** э́ту статью́.]{.ru}

[明天我把这篇文章看完。]{.gloss}
:::

### 常见错误

::: err
\*[Я чита́ть кни́гу.]{.ru}　→　[Я **чита́ю** кни́гу.]{.ru}

汉语动词不变，初学者常把词典里的形式（不定式）原样放进句子。作谓语要用变位形式，和主语一致。
:::

::: err
\*[Вчера́ я чита́ю.]{.ru}　→　[Вчера́ я **чита́л**.]{.ru}

汉语靠“昨天”表示过去，动词不变；俄语有了 [вчера́]{.ru}，动词本身还要用过去时。
:::

::: err
\*[А́нна, ты чита́л э́ту кни́гу?]{.ru}　→　[А́нна, ты **чита́ла** э́ту кни́гу?]{.ru}

过去时按主语的性变化，[ты]{.ru} 指女性时用阴性形式。
:::

::: err
\*[Ива́н Серге́евич, вы чита́ешь?]{.ru}　→　[Ива́н Серге́евич, вы **чита́ете**?]{.ru}

尊称的 [вы]{.ru} 即使指一个人，动词也用复数形式。
:::

## §7.1.2 第一变位和第二变位

### 形式

现在时和简单将来时的人称形式由现在时词干加[人称词尾]{.term}（[ли́чное оконча́ние]{.ru}）构成。人称词尾有两套，分别叫[第一变位]{.term}（[пе́рвое спряже́ние]{.ru}，生词表标 I）和[第二变位]{.term}（[второ́е спряже́ние]{.ru}，生词表标 II）：

::: paradigm
| 人称 | 第一变位 | 第二变位 |
|---|---|---|
| 单数第一人称 | [-у, -ю]{.ru} | [-у, -ю]{.ru} |
| 单数第二人称 | [-ешь (-ёшь)]{.ru} | [-ишь]{.ru} |
| 单数第三人称 | [-ет (-ёт)]{.ru} | [-ит]{.ru} |
| 复数第一人称 | [-ем (-ём)]{.ru} | [-им]{.ru} |
| 复数第二人称 | [-ете (-ёте)]{.ru} | [-ите]{.ru} |
| 复数第三人称 | [-ут, -ют]{.ru} | [-ат, -ят]{.ru} |
:::

第一变位的代表词：

::: paradigm
| 人称 | [чита́ть]{.ru .ix} | [писа́ть]{.ru .ix} | [жить]{.ru .ix} | [нести́]{.ru .ix} |
|---|---|---|---|---|
| 单数第一人称 | [чита́ю]{.ru} | [пишу́]{.ru} | [живу́]{.ru} | [несу́]{.ru} |
| 单数第二人称 | [чита́ешь]{.ru} | [пи́шешь]{.ru} | [живёшь]{.ru} | [несёшь]{.ru} |
| 单数第三人称 | [чита́ет]{.ru} | [пи́шет]{.ru} | [живёт]{.ru} | [несёт]{.ru} |
| 复数第一人称 | [чита́ем]{.ru} | [пи́шем]{.ru} | [живём]{.ru} | [несём]{.ru} |
| 复数第二人称 | [чита́ете]{.ru} | [пи́шете]{.ru} | [живёте]{.ru} | [несёте]{.ru} |
| 复数第三人称 | [чита́ют]{.ru} | [пи́шут]{.ru} | [живу́т]{.ru} | [несу́т]{.ru} |
:::

第二变位的代表词：

::: paradigm
| 人称 | [говори́ть]{.ru .ix} | [смотре́ть]{.ru .ix} | [лежа́ть]{.ru .ix} | [ви́деть]{.ru .ix} |
|---|---|---|---|---|
| 单数第一人称 | [говорю́]{.ru} | [смотрю́]{.ru} | [лежу́]{.ru} | [ви́жу]{.ru} |
| 单数第二人称 | [говори́шь]{.ru} | [смо́тришь]{.ru} | [лежи́шь]{.ru} | [ви́дишь]{.ru} |
| 单数第三人称 | [говори́т]{.ru} | [смо́трит]{.ru} | [лежи́т]{.ru} | [ви́дит]{.ru} |
| 复数第一人称 | [говори́м]{.ru} | [смо́трим]{.ru} | [лежи́м]{.ru} | [ви́дим]{.ru} |
| 复数第二人称 | [говори́те]{.ru} | [смо́трите]{.ru} | [лежи́те]{.ru} | [ви́дите]{.ru} |
| 复数第三人称 | [говоря́т]{.ru} | [смо́трят]{.ru} | [лежа́т]{.ru} | [ви́дят]{.ru} |
:::

带 [-ся]{.ru} 的动词照常变位，再在辅音后加 [-ся]{.ru}、元音后加 [-сь]{.ru}（构成见 §7.5.2，[-тся, -ться]{.ru} 读 [[цъ]]{.tr}，见 §1.2.5）：

::: paradigm
| 人称 | [занима́ться]{.ru .ix}（第一变位） | [учи́ться]{.ru .ix}（第二变位） |
|---|---|---|
| 单数第一人称 | [занима́юсь]{.ru} | [учу́сь]{.ru} |
| 单数第二人称 | [занима́ешься]{.ru} | [у́чишься]{.ru} |
| 单数第三人称 | [занима́ется]{.ru} | [у́чится]{.ru} |
| 复数第一人称 | [занима́емся]{.ru} | [у́чимся]{.ru} |
| 复数第二人称 | [занима́етесь]{.ru} | [у́читесь]{.ru} |
| 复数第三人称 | [занима́ются]{.ru} | [у́чатся]{.ru} |
:::

### 意义和用法

**两套词尾的区别。** 两种变位只有词尾元音不同：第一变位是 [е]{.ru}，复数第三人称是 [-ут, -ют]{.ru}；第二变位是 [и]{.ru}，复数第三人称是 [-ат, -ят]{.ru}。单数第一人称两种变位相同。

**重读的 [е]{.ru} 写 [ё]{.ru}。** 第一变位的词尾重读时，[е]{.ru} 一律写成 [ё]{.ru}：[живёшь, несёшь, пьёшь, даёшь, идёт, берём, поёте]{.ru}。第二变位的 [и]{.ru} 重读也不变：[говори́шь, лежи́м]{.ru}。

**[-у, -ут]{.ru} 还是 [-ю, -ют]{.ru}。** 这是写法问题，看词干末的音：

- 第一变位：词干以 [[й]]{.tr} 结尾（元音字母后写 [ю]{.ru}）或以软辅音结尾，写 [-ю, -ют]{.ru}：[чита́ю — чита́ют, уме́ю, рису́ю, пою́ — пою́т]{.ru}，[колю́ — ко́лют, борю́сь — бо́рются, стелю́ — сте́лют]{.ru}；词干以硬辅音或 [ж, ш, ч, щ]{.ru} 结尾，写 [-у, -ут]{.ru}：[несу́ — несу́т, живу́ — живу́т, иду́, жму, пишу́ — пи́шут, ищу́, пла́чу, могу́ — мо́гут]{.ru}。
- 第二变位的词干一律以软辅音或 [ж, ш, ч, щ]{.ru} 结尾。软辅音后写 [-ю, -ят]{.ru}：[говорю́ — говоря́т, смотрю́ — смо́трят, стою́ — стоя́т]{.ru}；[ж, ш, ч, щ]{.ru} 后按[拼写规则]{.term}（[орфографи́ческое пра́вило]{.ru}，§1.4.1）写 [-у, -ат]{.ru}：[лежу́ — лежа́т, слы́шу — слы́шат, кричу́ — крича́т, ви́жу]{.ru}（[ви́дят]{.ru} 词干末是软辅音 [д]{.ru}，写 [-ят]{.ru}）。

教程说“第一变位辅音词干的 [я]{.ru}、[они́]{.ru} 用 [-у, -ут]{.ru}”，指的就是硬辅音和 [ж, ш, ч, щ]{.ru} 结尾的词干；以软辅音 [л, р]{.ru} 结尾的少数词干（[коло́ть, боро́ться, стели́ть]{.ru}，§7.1.4）写 [-ю, -ют]{.ru}。

**为什么需要判断变位。** 词尾重读时，[-ёшь]{.ru} 和 [-и́шь]{.ru} 听得出来，写法没有疑问。词尾不重读时，[е]{.ru} 和 [и]{.ru} 都弱化成 [[и]]{.tr}：[де́лаешь]{.ru} 和 [ви́дишь]{.ru} 的词尾读音相同，复数第三人称不重读的 [-ят]{.ru} 也读成 [[ът]]{.tr}，和 [-ют]{.ru} 的 [[ут]]{.tr} 不同（[де́лают]{.ru} [[дʼе́лъйут]]{.tr}，[ви́дят]{.ru} [[вʼи́дʼът]]{.tr}）。所以写不重读的词尾时必须先知道动词属于哪种变位。

**从不定式判断变位：只管人称词尾不重读的动词。** 人称词尾不重读的动词，可以从不定式判断：

1. 以 [-ить]{.ru} 结尾的是第二变位：[ста́вить — ста́вишь, ве́рить — ве́ришь, гото́вить — гото́вишь, ко́нчить — ко́нчишь]{.ru}。例外：[брить]{.ru .ix}（[бре́ю, бре́ешь]{.ru}）、[стели́ть]{.ru .ix}（[стелю́, сте́лешь]{.ru}）是第一变位。
2. 以其他字母组合（[-ать, -ять, -еть, -оть, -уть, -ыть]{.ru}）结尾的是第一变位：[де́лать — де́лаешь, пла́кать — пла́чешь, се́ять — се́ешь, ре́зать — ре́жешь, коло́ть — ко́лешь]{.ru}。
3. 例外是十一个第二变位动词，以及由它们加前缀构成的动词：七个 [-еть]{.ru}：[смотре́ть]{.ru .ix}（[смо́тришь]{.ru}）、[ви́деть]{.ru .ix}（[ви́дишь]{.ru}）、[ненави́деть]{.ru .ix}、[оби́деть]{.ru .ix}、[зави́сеть]{.ru .ix}、[терпе́ть]{.ru .ix}（[те́рпишь]{.ru}）、[верте́ть]{.ru .ix}（[ве́ртишь]{.ru}）；四个 [-ать]{.ru}：[слы́шать]{.ru .ix}（[слы́шишь]{.ru}）、[дыша́ть]{.ru .ix}（[ды́шишь]{.ru}）、[держа́ть]{.ru .ix}（[де́ржишь]{.ru}）、[гнать]{.ru .ix}（[го́нишь]{.ru}）。加前缀的如 [уви́деть, посмотре́ть, услы́шать, задержа́ть, вы́гнать, потерпе́ть]{.ru}。

**人称词尾重读的动词不能从不定式判断。** 词尾重读时规则不管，因为读音已经表明了变位，而不定式的样子并不可靠：[лежа́ть, крича́ть, молча́ть]{.ru} 是第二变位，[писа́ть, иска́ть]{.ru} 是第一变位；[жить, пить]{.ru} 以 [-ить]{.ru} 结尾却是第一变位。这类动词要看生词表的标注（I / II 和单数第二人称）逐词记住。常用的人称词尾重读的第二变位动词：

| 不定式 | 第二变位的形式 |
|---|---|
| [-ать, -ять]{.ru} | [лежа́ть]{.ru .ix}（[лежи́шь]{.ru}），[крича́ть]{.ru .ix}，[молча́ть]{.ru .ix}，[стуча́ть, звуча́ть, дрожа́ть, пища́ть, мча́ться]{.ru}；[стоя́ть]{.ru .ix}（[стои́шь]{.ru}），[боя́ться]{.ru .ix}（[бои́шься]{.ru}）；[спать]{.ru .ix}（[спишь]{.ru}） |
| [-еть]{.ru} | [сиде́ть]{.ru .ix}（[сиди́шь]{.ru}），[лете́ть]{.ru .ix}（[лети́шь]{.ru}），[висе́ть, горе́ть, шуме́ть, свисте́ть, храпе́ть, звене́ть, кипе́ть, веле́ть]{.ru}，[боле́ть]{.ru}（疼：[боли́т]{.ru}） |

人称词尾重读的第一变位动词中，以 [-ить]{.ru} 结尾的只有单音节的 [жить, пить, бить, лить, шить, вить, гнить]{.ru}（[живёшь, пьёшь, бьёшь]{.ru}）和 [ошиби́ться]{.ru .ix}（[ошибу́сь, ошибёшься]{.ru}）。全部词表见附录三。

还有三个动词一部分形式按第一变位、一部分按第二变位：[хоте́ть, бежа́ть, чтить]{.ru}，见 §7.1.6。

**同形的两个动词变位不同。** 不定式相同、变位不同的动词意义也不同，要分清：

| 第一变位 | 第二变位 |
|---|---|
| [боле́ть]{.ru}（生病）：[Он боле́ет.]{.ru} | [боле́ть]{.ru}（疼）：[У меня́ боли́т голова́.]{.ru} |
| [слу́шать]{.ru .ix}（听，有意地听）：[слу́шаешь]{.ru} | [слы́шать]{.ru}（听见）：[слы́шишь]{.ru} |

**两种变位各管多少动词。** 第一变位的动词占绝大多数，能产的 [-ать, -ять, -еть, -овать, -нуть]{.ru} 各类都属第一变位（§7.1.3）。第二变位包括几乎全部 [-ить]{.ru} 动词（能产的一类）和数量有限的 [-еть, -ать, -ять]{.ru} 动词，后者不再增加。

[我们住在莫斯科，父母住在北京。]{.gloss}

[— Что вы **смо́трите**? — Мы **смо́трим** но́вости.]{.ru}

[——你们在看什么？——我们在看新闻。]{.gloss}

[— Ты меня́ **слы́шишь**? — **Слы́шу**, но пло́хо.]{.ru}

[——你听得见我说话吗？——听得见，不过听不清。]{.gloss}

[Ко́шка **лежи́т** на дива́не, а соба́ки **лежа́т** у две́ри.]{.ru}

### 常见错误

::: err
\*[Они́ смо́трют телеви́зор.]{.ru}　→　[Они́ **смо́трят** телеви́зор.]{.ru}

[смотре́ть]{.ru} 是第二变位的例外，复数第三人称是 [-ят]{.ru}。词尾不重读，听起来像 [[ът]]{.tr}，写的时候要靠规则。
:::

::: err
\*[Ты слы́шешь му́зыку?]{.ru}　→　[Ты **слы́шишь** му́зыку?]{.ru}

[слы́шать]{.ru} 是第二变位，不要和第一变位的 [слу́шать — слу́шаешь]{.ru} 混。
:::

::: err
\*[Он де́ржет ру́чку.]{.ru}　→　[Он **де́ржит** ру́чку.]{.ru}

[держа́ть]{.ru} 以 [-ать]{.ru} 结尾，却是第二变位：[держу́, де́ржишь, де́ржат]{.ru}。
:::

::: err
\*[Ты лежёшь на дива́не?]{.ru}　→　[Ты **лежи́шь** на дива́не?]{.ru}

[лежа́ть]{.ru} 的词尾重读，从不定式看不出变位，要按生词表的 II 记。
:::

::: err
\*[Он бре́ит бо́роду.]{.ru}　→　[Он **бре́ет** бо́роду.]{.ru}

[брить]{.ru} 是 [-ить]{.ru} 动词中的例外，属第一变位：[бре́ю, бре́ешь, бре́ет]{.ru}。
:::

::: err
\*[Я учу́ся в шко́ле.]{.ru}　→　[Я **учу́сь** в шко́ле.]{.ru}

[-ся]{.ru} 在元音后写 [-сь]{.ru}。
:::

## §7.1.3 能产的变位类型

### 形式

按不定式词干和现在时词干之间的关系，动词分为若干[变位类型]{.term}（[глаго́льный класс]{.ru}）。其中五类叫[能产类型]{.term}（[продукти́вный класс]{.ru}）：它们包括了俄语动词的绝大多数，新产生的动词、借来的动词都按这几类变位，由不定式就能推出现在时词干。

| 类型 | 不定式 | 现在时词干 | 变位 | 常用词 |
|---|---|---|---|---|
| 1. [-ать, -ять]{.ru} | [чита́ть, гуля́ть]{.ru} | [читай-, гуляй-]{.ru} | 第一 | [де́лать, знать, рабо́тать, понима́ть, отвеча́ть, слу́шать, игра́ть, повторя́ть, проверя́ть, стреля́ть]{.ru} |
| 2. [-еть]{.ru} | [уме́ть]{.ru} | [умей-]{.ru} | 第一 | [име́ть, успе́ть, боле́ть（生病）, красне́ть, бледне́ть, худе́ть, жале́ть, темне́ть]{.ru} |
| 3. [-овать, -евать]{.ru} | [рисова́ть, танцева́ть]{.ru} | [рисуй-, танцуй-]{.ru} | 第一 | [интересова́ться, сове́товать, чу́вствовать, тре́бовать, пра́здновать, фотографи́ровать, путеше́ствовать, ночева́ть]{.ru} |
| 4. [-нуть]{.ru} | [кри́кнуть, отдохну́ть]{.ru} | [крикн-, отдохн-]{.ru} | 第一 | [верну́ть, улыбну́ться, толкну́ть, махну́ть, пры́гнуть, тяну́ть]{.ru} |
| 5. [-ить]{.ru} | [говори́ть, ста́вить]{.ru} | [говор-, став-]{.ru} | 第二 | [ве́рить, звони́ть, реши́ть, учи́ть, люби́ть, гото́вить, ходи́ть, плати́ть]{.ru} |

### 意义和用法

**能产与非能产。** 能产类型的不定式词干和现在时词干之间只有一种简单的、可以推出的关系；非能产类型（§7.1.4）每一类的词数有限，不再增加，现在时词干要随词记。判断一个动词属于哪一类，最可靠的是看词典给出的单数第一人称：[-аю, -яю, -ею, -ую, -ну]{.ru} 和第二变位的 [-ю (-у)]{.ru} 指向五个能产类型，其余的到 §7.1.4 去查。

**1. [-ать, -ять]{.ru}：[чита́ть]{.ru} 类。** 现在时词干在不定式词干后加 [[й]]{.tr}：[чита- → читай-]{.ru}，[гуля- → гуляй-]{.ru}。第一变位，重音在各形式里不动，与不定式相同。命令式加 [-й]{.ru}：[чита́й, гуля́й]{.ru}。不是所有 [-ать]{.ru} 动词都属这一类：[писа́ть, пла́кать, брать, ждать]{.ru} 等属非能产类型（§7.1.4），[спать, держа́ть, слы́шать]{.ru} 属第二变位（§7.1.2）；词典给出 [-аю, -яю]{.ru} 的才属这一类。由完成体加 [-ыва-, -ива-]{.ru} 构成的次生未完成体（[расска́зывать, пока́зывать, переде́лывать]{.ru}，§7.3.4）也都属这一类：[расска́зываю, расска́зываешь]{.ru}，[-ыва-]{.ru} 不变。

**2. [-еть]{.ru}：[уме́ть]{.ru} 类。** 同样加 [[й]]{.tr}：[уме- → умей-]{.ru}，第一变位，重音不动。这一类有许多由形容词构成、表示“变得……”的动词：[красне́ть]{.ru}（变红）、[бледне́ть]{.ru}（变白）、[худе́ть]{.ru}（变瘦）、[полне́ть]{.ru}（发胖）、[темне́ть]{.ru}（变暗，[Темне́ет.]{.ru} 天黑下来了）。不要和第二变位的 [смотре́ть, сиде́ть]{.ru} 一类混：[уме́ю]{.ru} 和 [смотрю́]{.ru} 一看单数第一人称就能分清。

**3. [-овать, -евать]{.ru}：[рисова́ть]{.ru} 类。** 现在时里后缀 [-ова-, -ева-]{.ru} 换成 [-у-]{.ru}，再加 [[й]]{.tr}：[рисова- → рисуй-]{.ru}。不定式和过去时保留 [-ова-]{.ru}（[рисова́ть, рисова́л]{.ru}），现在时（简单将来时）和命令式用 [-у-]{.ru}（[рису́ю, рису́й]{.ru}）。

- 写法：词干末是硬辅音时写 [-ова-]{.ru}，是软辅音或 [ж, ш, ч, щ, ц]{.ru} 时写 [-ева-]{.ru}：[танцева́ть, ночева́ть, воева́ть, горева́ть]{.ru}。现在时 [у]{.ru} 前是软辅音或元音时写 [ю]{.ru}：[воева́ть — вою́ю]{.ru}，[горева́ть — горю́ю]{.ru}；[ц, ж, ш, ч, щ]{.ru} 后写 [у]{.ru}：[танцева́ть — танцу́ю]{.ru}，[ночева́ть — ночу́ю]{.ru}。
- 重音：不定式重音在 [-ова́-]{.ru} 上的，现在时重音在 [-у́-]{.ru} 上：[рисова́ть — рису́ю]{.ru}，[интересова́ться — интересу́юсь]{.ru}，[танцева́ть — танцу́ю]{.ru}，[рекомендова́ть — рекоменду́ю]{.ru}，[организова́ть — организу́ю]{.ru}；不定式重音在 [-ова-]{.ru} 前的，各形式重音不动：[сове́товать — сове́тую]{.ru}，[чу́вствовать — чу́вствую]{.ru}，[тре́бовать — тре́бую]{.ru}，[испо́льзовать — испо́льзую]{.ru}，[фотографи́ровать — фотографи́рую]{.ru}。
- 词尾重读的例外：几个词根很短的动词，[-у-]{.ru} 后的词尾重读：[кова́ть]{.ru .ix}（[кую́, куёшь]{.ru}），[жева́ть]{.ru .ix}（[жую́, жуёшь]{.ru}），[плева́ть]{.ru .ix}（[плюю́, плюёшь]{.ru}），[клева́ть]{.ru .ix}（[клюю́, клюёшь]{.ru}），[сова́ть]{.ru .ix}（[сую́, суёшь]{.ru}）。
- 不属于这一类的 [-вать]{.ru} 动词：[-ова-, -ева-]{.ru} 必须是加在词根后面的后缀。下面几种 [-вать]{.ru} 动词不变 [-у-]{.ru}：次生未完成体 [-ывать, -ивать]{.ru}（[расска́зывать — расска́зываю]{.ru}）；由完成体加 [-ва-]{.ru} 构成的未完成体（[одева́ть — одева́ю, успева́ть — успева́ю, открыва́ть — открыва́ю]{.ru}，§7.3.4）；[здоро́ваться]{.ru .ix}（[здоро́ваюсь, здоро́ваешься]{.ru}），其中 [-ва-]{.ru} 不是 [-ова-]{.ru} 后缀的一部分；[-ава́ть]{.ru} 动词（[дава́ть — даю́]{.ru}，§7.1.4）。生词表给出 [-ую, -юю]{.ru} 的才属这一类。

这一类是现代俄语吸收新动词的主要渠道，外来动词多带 [-ировать]{.ru}：[копи́ровать — копи́рую]{.ru}，[скани́ровать — скани́рую]{.ru}，[регистри́ровать — регистри́рую]{.ru}。

**4. [-нуть]{.ru}：[кри́кнуть]{.ru} 类。** 现在时词干是不定式词干去掉 [-у-]{.ru}：[крикну- → крикн-]{.ru}，第一变位：[кри́кну, кри́кнешь]{.ru}。过去时保留 [-ну-]{.ru}：[кри́кнул, отдохну́л, верну́лся]{.ru}。能产的 [-ну-]{.ru} 动词多是完成体，许多表示一次的动作（[кри́кнуть]{.ru} 喊一声，[пры́гнуть]{.ru} 跳一下，见 §7.3.4–§7.3.5）。重音有三种：固定在词干（[кри́кнуть — кри́кну, кри́кнешь]{.ru}）；固定在词尾（[отдохну́ть — отдохну́, отдохнёшь]{.ru}，[верну́ть — верну́, вернёшь]{.ru}，[улыбну́ться — улыбну́сь, улыбнёшься]{.ru}）；单数第一人称在词尾、其余在词干（[тяну́ть — тяну́, тя́нешь]{.ru}，[тону́ть — тону́, то́нешь]{.ru}，[взгляну́ть — взгляну́, взгля́нешь]{.ru}，[обману́ть — обману́, обма́нешь]{.ru}）。

另有一批 [-нуть]{.ru} 动词多表示状态的逐渐变化（[мёрзнуть]{.ru} 受冻，[привы́кнуть]{.ru} 习惯，[исче́знуть]{.ru} 消失，[со́хнуть]{.ru} 变干），现在时与 [кри́кнуть]{.ru} 相同（[мёрзну, мёрзнешь]{.ru}），过去时却去掉 [-ну-]{.ru}（[мёрз, привы́к, исче́з]{.ru}）。这一批是非能产的，过去时见 §7.2.2。

**5. [-ить]{.ru}：[говори́ть]{.ru} 类。** 现在时词干是不定式词干去掉 [-и-]{.ru}：[говори- → говор-]{.ru}，第二变位。词干末是 [д, т, з, с, ст]{.ru} 或唇音 [б, п, в, ф, м]{.ru} 的，单数第一人称发生辅音交替（[ста́вить — ста́влю]{.ru}，[ходи́ть — хожу́]{.ru}），见 §7.1.5。重音有三种（[ста́вить — ста́влю, ста́вишь]{.ru}；[говори́ть — говорю́, говори́шь]{.ru}；[люби́ть — люблю́, лю́бишь]{.ru}），见 §7.1.7。命令式见 §7.4.1。几乎所有 [-ить]{.ru} 动词都属这一类，例外只有单音节的 [пить, бить]{.ru} 等（§7.1.4）、[брить, стели́ть, ошиби́ться]{.ru}（§7.1.2）。

### 常见错误

::: err
\*[Он рисова́ет портре́т.]{.ru}　→　[Он **рису́ет** портре́т.]{.ru}

[-ова-]{.ru} 动词的现在时里 [-ова-]{.ru} 换成 [-у-]{.ru}，不能照 [чита́ть]{.ru} 类直接加词尾。
:::

::: err
\*[Мы танцева́ем.]{.ru}　→　[Мы **танцу́ем**.]{.ru}

[-ева-]{.ru} 同样换成 [-у-]{.ru}，[ц]{.ru} 后写 [у]{.ru}。
:::

::: err
\*[Он расска́зует о пое́здке.]{.ru}　→　[Он **расска́зывает** о пое́здке.]{.ru}

[-ывать, -ивать]{.ru} 动词不属于 [-ова-]{.ru} 类，后缀在现在时里不变。
:::

::: err
\*[Мы здоро́вуемся.]{.ru}　→　[Мы **здоро́ваемся**.]{.ru}

[здоро́ваться]{.ru} 不带 [-ова-]{.ru} 后缀，按 [чита́ть]{.ru} 类变位。
:::

::: err
\*[Он ста́вит, а я ста́вю.]{.ru}　→　[Он ста́вит, а я **ста́влю**.]{.ru}

[-ить]{.ru} 动词词干末是唇音的，单数第一人称加 [л]{.ru}（§7.1.5）。
:::

## §7.1.4 非能产的变位类型

### 形式

[非能产类型]{.term}（[непродукти́вный класс]{.ru}）的动词不多，但大都是最常用的动词。它们的现在时词干和不定式词干的关系各类不同，要按类记住。下面各表列出单数第一、第二人称和复数第三人称，过去时（阳性、阴性），命令式；全部类型和词表见附录三。除特别注明的以外，都属第一变位。

**1. [-ава́ть]{.ru}：[дава́ть]{.ru} 类。** 词根为 [-да-, -зна-, -ста-]{.ru} 的未完成体。现在时去掉 [-ва-]{.ru}，词尾重读；命令式、未完成体副动词和被动形动词现在时保留 [-ва-]{.ru}：

| 不定式 | 现在时 | 过去时 | 命令式 |
|---|---|---|---|
| [дава́ть]{.ru .ix} | [даю́, даёшь, даю́т]{.ru} | [дава́л, дава́ла]{.ru} | [дава́й]{.ru} |
| [узнава́ть]{.ru .ix} | [узнаю́, узнаёшь, узнаю́т]{.ru} | [узнава́л, узнава́ла]{.ru} | [узнава́й]{.ru} |
| [встава́ть]{.ru .ix} | [встаю́, встаёшь, встаю́т]{.ru} | [встава́л, встава́ла]{.ru} | [встава́й]{.ru} |

同类的有 [передава́ть, продава́ть, отдава́ть, создава́ть, сдава́ть, задава́ть, издава́ть, раздава́ть, подава́ть, преподава́ть, признава́ть, признава́ться, устава́ть, остава́ться, перестава́ть, достава́ть, отстава́ть]{.ru}。副动词 [дава́я, встава́я]{.ru}，被动形动词 [передава́емый]{.ru}；主动形动词现在时由现在时词干构成，没有 [-ва-]{.ru}：[даю́щий, встаю́щий]{.ru}。

**2. [-ать, -ять]{.ru} 去掉 [-а-]{.ru}：[писа́ть]{.ru} 类。** 现在时词干是不定式词干去掉 [-а-]{.ru}，末尾辅音在所有人称里交替（交替表见 §7.1.5）；词干以元音结尾的，去掉 [-а-]{.ru} 后加 [[й]]{.tr}：

| 不定式 | 现在时 | 过去时 | 命令式 |
|---|---|---|---|
| [писа́ть]{.ru} | [пишу́, пи́шешь, пи́шут]{.ru} | [писа́л, писа́ла]{.ru} | [пиши́]{.ru} |
| [сказа́ть]{.ru .ix} | [скажу́, ска́жешь, ска́жут]{.ru} | [сказа́л, сказа́ла]{.ru} | [скажи́]{.ru} |
| [иска́ть]{.ru .ix} | [ищу́, и́щешь, и́щут]{.ru} | [иска́л, иска́ла]{.ru} | [ищи́]{.ru} |
| [пла́кать]{.ru} | [пла́чу, пла́чешь, пла́чут]{.ru} | [пла́кал, пла́кала]{.ru} | [плачь]{.ru} |
| [маха́ть]{.ru .ix} | [машу́, ма́шешь, ма́шут]{.ru} | [маха́л, маха́ла]{.ru} | [маши́]{.ru} |
| [ре́зать]{.ru .ix} | [ре́жу, ре́жешь, ре́жут]{.ru} | [ре́зал, ре́зала]{.ru} | [режь]{.ru} |
| [пря́тать]{.ru .ix} | [пря́чу, пря́чешь, пря́чут]{.ru} | [пря́тал, пря́тала]{.ru} | [прячь]{.ru} |
| [сы́пать]{.ru .ix} | [сы́плю, сы́плешь, сы́плют]{.ru} | [сы́пал, сы́пала]{.ru} | [сыпь]{.ru} |
| [се́ять]{.ru .ix} | [се́ю, се́ешь, се́ют]{.ru} | [се́ял, се́яла]{.ru} | [сей]{.ru} |
| [смея́ться]{.ru .ix} | [смею́сь, смеёшься, смею́тся]{.ru} | [смея́лся, смея́лась]{.ru} | [сме́йся]{.ru} |

同类的有 [показа́ть, рассказа́ть, заказа́ть, каза́ться, вяза́ть, ма́зать]{.ru}（[з — ж]{.ru}），[чеса́ть, пляса́ть]{.ru}（[с — ш]{.ru}），[паха́ть]{.ru}（[х — ш]{.ru}），[скака́ть]{.ru}（[к — ч]{.ru}），[шепта́ть, хохота́ть, щекота́ть, бормота́ть, топта́ть]{.ru}（[т — ч]{.ru}），[клевета́ть, трепета́ть]{.ru}（[т — щ]{.ru}），[полоска́ть]{.ru}（[ск — щ]{.ru}），[свиста́ть, хлеста́ть]{.ru}（[ст — щ]{.ru}），[щипа́ть, трепа́ть]{.ru}（[п — пл]{.ru}），[колеба́ться]{.ru}（[б — бл]{.ru}），[дрема́ть]{.ru}（[м — мл]{.ru}）；元音词干的 [ла́ять, та́ять, ве́ять, наде́яться]{.ru}。[стона́ть]{.ru}（[стону́, сто́нешь]{.ru}）去掉 [-а-]{.ru} 而不交替。

这一类有几个动词另有按 [чита́ть]{.ru} 类变位的形式，规范程度不同：

| 动词 | 标准形式 | 另一种形式 |
|---|---|---|
| [маха́ть]{.ru} | [ма́шет]{.ru} | [маха́ет]{.ru}：口语、俗语 |
| [полоска́ть]{.ru} | [поло́щет]{.ru} | [полоска́ет]{.ru}：两可，口语多用 |
| [ка́пать]{.ru} | [ка́плет]{.ru}（滴下） | [ка́пает]{.ru}：两可，现在更常用 |
| [мета́ть]{.ru} | [ме́чет]{.ru}（投掷，[мета́ть икру́]{.ru} 产卵） | [мета́ет]{.ru}：另一个词，“绷线、粗缝” |
| [щекота́ть]{.ru} | [щеко́чет]{.ru} | [щеко́тит]{.ru}：旧式、俗语 |

旧式和俗语的变位见 §15.2.2。

**3. [брать, звать, ждать]{.ru} 类。** 单音节不定式，现在时词干里元音脱落或插入，词尾重读：

| 不定式 | 现在时 | 过去时 | 命令式 |
|---|---|---|---|
| [брать]{.ru .ix} | [беру́, берёшь, беру́т]{.ru} | [брал, брала́]{.ru} | [бери́]{.ru} |
| [звать]{.ru .ix} | [зову́, зовёшь, зову́т]{.ru} | [звал, звала́]{.ru} | [зови́]{.ru} |
| [ждать]{.ru .ix} | [жду, ждёшь, ждут]{.ru} | [ждал, ждала́]{.ru} | [жди]{.ru} |
| [рвать]{.ru .ix} | [рву, рвёшь, рвут]{.ru} | [рвал, рвала́]{.ru} | [рви]{.ru} |
| [врать]{.ru .ix} | [вру, врёшь, врут]{.ru} | [врал, врала́]{.ru} | [ври]{.ru} |
| [лгать]{.ru .ix} | [лгу, лжёшь, лгут]{.ru} | [лгал, лгала́]{.ru} | [лги]{.ru} |
| [драть]{.ru .ix} | [деру́, дерёшь, деру́т]{.ru} | [драл, драла́]{.ru} | [дери́]{.ru} |
| [ткать]{.ru .ix} | [тку, ткёшь, ткут]{.ru} | [ткал, ткала́]{.ru} | [тки]{.ru} |

带前缀的同样变位：[собра́ть — соберу́, выбира́ть]{.ru}（未完成体按 [чита́ть]{.ru} 类），[позва́ть — позову́, назва́ть — назову́, подожда́ть — подожду́]{.ru}。[лгать]{.ru} 的 [г — ж]{.ru} 交替和 [-чь]{.ru} 动词一样只在单数第一人称和复数第三人称以外出现；[ткать]{.ru} 的 [к]{.ru} 不交替（[ткёшь]{.ru}）。

**4. [нача́ть, взять]{.ru} 类。** 不定式词干以 [-а-, -я-]{.ru} 结尾，现在时词干里换成 [-н-]{.ru} 或 [-м-]{.ru}（[-им-]{.ru}）：

| 不定式 | 简单将来时 | 过去时 | 命令式 |
|---|---|---|---|
| [нача́ть]{.ru .ix} | [начну́, начнёшь, начну́т]{.ru} | [на́чал, начала́, на́чали]{.ru} | [начни́]{.ru} |
| [взять]{.ru .ix} | [возьму́, возьмёшь, возьму́т]{.ru} | [взял, взяла́, взя́ли]{.ru} | [возьми́]{.ru} |
| [поня́ть]{.ru .ix} | [пойму́, поймёшь, пойму́т]{.ru} | [по́нял, поняла́, по́няли]{.ru} | [пойми́]{.ru} |
| [заня́ть]{.ru .ix} | [займу́, займёшь, займу́т]{.ru} | [за́нял, заняла́, за́няли]{.ru} | [займи́]{.ru} |
| [приня́ть]{.ru .ix} | [приму́, при́мешь, при́мут]{.ru} | [при́нял, приняла́, при́няли]{.ru} | [прими́]{.ru} |
| [снять]{.ru .ix} | [сниму́, сни́мешь, сни́мут]{.ru} | [снял, сняла́, сня́ли]{.ru} | [сними́]{.ru} |

| [оде́ть]{.ru .ix} | [оде́ну, оде́нешь, оде́нут]{.ru} | [оде́л, оде́ла]{.ru} | [оде́нь]{.ru} |

### 意义和用法

**非能产类型为什么要逐类记。** 能产类型的现在时词干可以从不定式推出来；非能产类型不行，因为不定式和现在时在历史上经历了不同的语音变化：[жить]{.ru} 的词根本来就带 [в]{.ru}，在不定式里脱落了；[нести́, вести́, мести́]{.ru} 的不定式都是 [-сти]{.ru}，词根末的 [с, д, т]{.ru} 只在现在时里露出来（[несу́, веду́, мету́]{.ru}）；[стать]{.ru} 的 [н]{.ru} 只出现在现在时里。所以学这些动词时，单数第一、第二人称和不定式一样是必须记的形式，生词表一律注出。好在每一类内部是有规律的：记住 [вести́ — веду́]{.ru}，[цвести́ — цвету́]{.ru} 就要查一查是 [д]{.ru} 还是 [т]{.ru}，变法却不用再学。

**带前缀的动词随原动词变位。** 前缀不改变变位类型：[написа́ть]{.ru} 和 [писа́ть]{.ru}、[прода́ть]{.ru} 和 [дать]{.ru}、[уви́деть]{.ru} 和 [ви́деть]{.ru} 变法相同（[вы́-]{.ru} 前缀永远重读，见 §7.1.7）。所以认出词根就能认出变位：[поня́ть, приня́ть, заня́ть, снять, подня́ть]{.ru} 都有词根 [-ня-]{.ru}（[-я-]{.ru}），都属本节第 4 类；[узна́ть]{.ru} 是能产类型 1（[узна́ю]{.ru}），而它的未完成体 [узнава́ть]{.ru} 属本节第 1 类（[узнаю́]{.ru}），两个形式只差重音（见 §7.1.7）。

**体对中的两个动词常属不同类型。** 完成体和由它构成的未完成体往往分属两类：[дать]{.ru}（不规则）— [дава́ть]{.ru}（本节第 1 类）；[встать]{.ru}（本节第 12 类）— [встава́ть]{.ru}（本节第 1 类）；[нача́ть]{.ru}（本节第 4 类）— [начина́ть]{.ru}（能产类型 1）；[откры́ть]{.ru}（本节第 6 类）— [открыва́ть]{.ru}（能产类型 1）；[помо́чь]{.ru}（本节第 9 类）— [помога́ть]{.ru}（能产类型 1）。由后缀构成的未完成体几乎都属能产类型 1（§7.3.4），变位最简单；完成体反倒常常是非能产的。

**[-ава́ть]{.ru} 动词的三个特点。** 现在时去掉 [-ва-]{.ru}（[даю́]{.ru}，不说 [дава́ю]{.ru}）；词尾重读，[е]{.ru} 写 [ё]{.ru}（[даёшь, встаёт]{.ru}）；命令式和副动词保留 [-ва-]{.ru}（[дава́й, встава́я]{.ru}）。这是由现在时词干构成的形式中唯一的例外。其他 [-ва-]{.ru} 动词（[открыва́ть, одева́ть, забыва́ть, успева́ть]{.ru}）各形式都保留 [-ва-]{.ru}：[открыва́ю, открыва́й]{.ru}。

### 常见错误

::: err
\*[Я дава́ю тебе́ кни́гу.]{.ru}　→　[Я **даю́** тебе́ кни́гу.]{.ru}

[-ава́ть]{.ru} 动词的现在时去掉 [-ва-]{.ru}。只有命令式、副动词保留：[дава́й]{.ru}。
:::

::: err
\*[Я иска́ю слова́рь.]{.ru}　→　[Я **ищу́** слова́рь.]{.ru}

[иска́ть]{.ru} 属去掉 [-а-]{.ru} 的一类，不能按 [чита́ть]{.ru} 加 [-ю]{.ru}；[ск]{.ru} 交替为 [щ]{.ru}。
:::

::: err
\*[Ребёнок пла́кает.]{.ru}　→　[Ребёнок **пла́чет**.]{.ru}

同上：[пла́кать — пла́чу, пла́чешь]{.ru}，[к — ч]{.ru} 出现在所有人称里。
:::

::: err
\*[Я мы́ю ру́ки.]{.ru}　→　[Я **мо́ю** ру́ки.]{.ru}

[мыть]{.ru} 的现在时词根元音变 [о]{.ru}：[мо́ю, мо́ешь]{.ru}。
:::

::: err
\*[Я взя́ю э́ту кни́гу.]{.ru}　→　[Я **возьму́** э́ту кни́гу.]{.ru}

[взять]{.ru} 的将来时词干是 [возьм-]{.ru}，与不定式差别很大，要整体记住。
:::

::: err
\*[Он ведёл нас в музе́й.]{.ru}　→　[Он **вёл** нас в музе́й.]{.ru}

[вести́]{.ru} 的过去时由不定式词干构成，[д]{.ru} 在 [-л]{.ru} 前脱落（§7.2.2），不能用现在时词干 [вед-]{.ru}。
:::

## §7.1.5 辅音交替

### 形式

变位时词干末尾的辅音换成另一个辅音，叫[辅音交替]{.term}（[чередова́ние согла́сных]{.ru}）。动词的辅音交替有三种分布：第二变位只在单数第一人称交替；第一变位在所有人称交替；[-чь]{.ru} 动词在单数第一人称和复数第三人称以外交替。

**1. 第二变位：只在单数第一人称交替。**

| 交替 | 例词 | 单数第一人称 | 单数第二人称 | 复数第三人称 |
|---|---|---|---|---|
| [д — ж]{.ru} | [ви́деть, сиде́ть, ходи́ть, води́ть, буди́ть]{.ru} | [ви́жу, сижу́, хожу́, вожу́, бужу́]{.ru} | [ви́дишь, сиди́шь, хо́дишь, во́дишь, бу́дишь]{.ru} | [ви́дят, сидя́т, хо́дят, во́дят, бу́дят]{.ru} |
| [з — ж]{.ru} | [вози́ть, вы́разить, грози́ть]{.ru}；[е́здить]{.ru}（[зд — зж]{.ru}） | [вожу́, вы́ражу, грожу́, е́зжу]{.ru} | [во́зишь, вы́разишь, грози́шь, е́здишь]{.ru} | [во́зят, вы́разят, грозя́т, е́здят]{.ru} |

### 意义和用法

**为什么分布不同。** 交替来自古代辅音和 [[й]]{.tr} 的融合。第二变位只有单数第一人称的词尾前曾经有 [[й]]{.tr}（[ход-]{.ru} 加 [[йу]]{.tr} 变成 [хожу́]{.ru}），所以只有这一个形式交替；第一变位的 [писа́ть]{.ru} 类整个现在时词干都曾带 [[й]]{.tr}，所以所有人称都交替。[-чь]{.ru} 动词的 [ж, ч]{.ru} 出现在古代词尾为 [е]{.ru} 的形式（[-ешь, -ет, -ем, -ете]{.ru}）里，单数第一人称和复数第三人称的词尾是 [у]{.ru}，保留 [г, к]{.ru}。规则按变位分，不必按动词一个个记：

- 第二变位动词，词干末是 [д, з, с, т, ст]{.ru} 的，单数第一人称换成 [ж, ж, ш, ч (щ), щ]{.ru}；是唇音 [б, п, в, ф, м]{.ru} 的，单数第一人称加 [л]{.ru}。其余五个人称一律不交替。
- 第一变位动词有交替的，现在时（简单将来时）的六个人称都交替。
- [-чь]{.ru} 动词：[г — ж, к — ч]{.ru}，单数第一人称和复数第三人称不交替。

**[т — ч]{.ru} 还是 [т — щ]{.ru}。** 俄语固有的词根交替为 [ч]{.ru}：[плати́ть — плачу́, отве́тить — отве́чу, лете́ть — лечу́, хоте́ть — хочу́]{.ru}。来自古教会斯拉夫语的书面词根交替为 [щ]{.ru}：[посети́ть — посещу́, защити́ть — защищу́, прекрати́ть — прекращу́, возврати́ть — возвращу́, обрати́ть — обращу́]{.ru}。同一个词根可以两种都有：[свети́ть — свечу́]{.ru}（照亮），[освети́ть — освещу́]{.ru}（照明，书面）。

**[д — ж]{.ru} 和 [д — жд]{.ru}。** 单数第一人称一律是 [д — ж]{.ru}：[ходи́ть — хожу́, освободи́ть — освобожу́, предупреди́ть — предупрежу́]{.ru}。[жд]{.ru} 只出现在书面词根的被动形动词过去时和未完成体里：[освобождённый, освобожда́ть]{.ru}，[предупреждённый, предупрежда́ть]{.ru}（§7.3.4、§7.8.5）。

**没有单数第一人称的动词。** 少数第二变位动词交替后的单数第一人称听起来别扭，标准语不用：[победи́ть]{.ru .ix}、[убеди́ть]{.ru .ix}、[разубеди́ть]{.ru}、[очути́ться]{.ru .ix} 没有单数第一人称，要用别的说法：[Я одержу́ побе́ду]{.ru}，[Я смогу́ победи́ть]{.ru}，[Я постара́юсь убеди́ть его́]{.ru}。全部词表见附录三。

**交替与重音移动常一起出现。** 许多第二变位动词的单数第一人称重读词尾，其余人称重读词干：[хожу́ — хо́дишь, прошу́ — про́сишь, куплю́ — ку́пишь, кормлю́ — ко́рмишь]{.ru}（重音类型 c，§7.1.7）。所以记动词时单数第一人称和第二人称两个形式缺一不可：第一个给出交替，第二个给出重音。

**交替在其他形式里的保留和消失。** 各形式由哪个词干构成（§7.1.1），决定它有没有交替：

1. 过去时、不定式由不定式词干构成，没有交替：[ходи́л, писа́л, пла́кал]{.ru}；[-чь]{.ru} 动词的过去时露出词干末的 [г, к]{.ru}：[мог, берёг, пёк, жёг]{.ru}。
2. 命令式由复数第三人称的词干构成，跟随复数第三人称：第二变位不交替（[ходи́, купи́, люби́, гото́вь]{.ru}，不说 [хожи́]{.ru}）；第一变位交替（[пиши́, скажи́, ищи́, плачь]{.ru}）；[-чь]{.ru} 动词用 [г, к]{.ru}（[береги́, помоги́, пеки́, ляг]{.ru}；[жечь]{.ru} 的命令式是 [жги]{.ru}）。见 §7.4.1。
3. 主动形动词现在时、未完成体副动词同样跟随复数第三人称：[хо́дят — ходя́щий, ходя́]{.ru}；[пи́шут — пи́шущий]{.ru}；[живу́т — живу́щий]{.ru}（重音例外 [могу́щий]{.ru} 等见 §7.8.2）。
4. [-ить]{.ru} 动词的被动形动词过去时和次生未完成体有与单数第一人称相同的交替：[купи́ть — куплю́ — ку́пленный]{.ru}，[спроси́ть — спрошу́ — спро́шенный, спра́шивать]{.ru}，[встре́тить — встре́чу — встре́ченный, встреча́ть]{.ru}，书面词根用 [щ, жд]{.ru}（[посещённый, освобождённый]{.ru}），见 §7.3.4、§7.8.5。[-чь]{.ru} 动词的被动形动词过去时用 [ж, ч]{.ru}：[испечённый, сбережённый]{.ru}。

### 常见错误

::: err
\*[Я ви́дю его́ ка́ждый день.]{.ru}　→　[Я **ви́жу** его́ ка́ждый день.]{.ru}

第二变位动词词干末是 [д]{.ru} 的，单数第一人称换成 [ж]{.ru}。
:::

::: err
\*[Я гото́вю обе́д.]{.ru}　→　[Я **гото́влю** обе́д.]{.ru}

唇音 [в]{.ru} 后加 [л]{.ru}。
:::

::: err
\*[Ты хо́жишь в библиоте́ку?]{.ru}　→　[Ты **хо́дишь** в библиоте́ку?]{.ru}

第二变位的交替只在单数第一人称，不能类推到其他人称。
:::

::: err
\*[Он пи́сет письмо́.]{.ru}　→　[Он **пи́шет** письмо́.]{.ru}

第一变位的交替正相反，所有人称都有：[пишу́, пи́шешь, пи́шет]{.ru}。
:::

::: err
\*[Они́ мо́жут прийти́.]{.ru}　→　[Они́ **мо́гут** прийти́.]{.ru}

[-чь]{.ru} 动词的复数第三人称和单数第一人称一样保留 [г]{.ru}。俄罗斯人口语中的 [мо́жут]{.ru}、[могёшь]{.ru} 是俗语，不合标准。
:::

::: err
\*[Вчера́ он пиша́л письмо́.]{.ru}　→　[Вчера́ он **писа́л** письмо́.]{.ru}

过去时由不定式词干构成，没有现在时的交替：[пишу́]{.ru}，但 [писа́л]{.ru}。
:::

## §7.1.6 不规则变位动词

### 形式

有几个动词的形式不能归入任何变位类型，叫[不规则变位动词]{.term}（[разноспряга́емый глаго́л]{.ru}，教程叫“不规则动词”）。它们分三种情况：[быть, есть, дать]{.ru} 保留了古代特殊的词尾；[хоте́ть, бежа́ть, чтить]{.ru} 一部分形式按第一变位、一部分按第二变位；[идти́, е́хать]{.ru} 的词干不规则。这几个动词都是最常用的词，带前缀的派生词也很多，按原动词变位。

**[быть]{.ru .ix}。** 现在时一般不用（§7.2.1），将来时按第一变位，过去时按一般规则：

::: paradigm
| 人称 | 将来时 | 现在时（只在特定用法中出现） |
|---|---|---|
| 单数第一人称 | [бу́ду]{.ru} | [есть]{.ru} |
| 单数第二人称 | [бу́дешь]{.ru} | [есть]{.ru} |
| 单数第三人称 | [бу́дет]{.ru} | [есть]{.ru} |
| 复数第一人称 | [бу́дем]{.ru} | [есть]{.ru} |
| 复数第二人称 | [бу́дете]{.ru} | [есть]{.ru} |
| 复数第三人称 | [бу́дут]{.ru} | [есть]{.ru}（旧式 [суть]{.ru}） |
| 过去时 | [был, была́, бы́ло, бы́ли]{.ru} | |
| 命令式 | [будь, бу́дьте]{.ru} | |
:::

副动词 [бу́дучи]{.ru}，形动词 [бы́вший]{.ru}（[бу́дущий]{.ru} 已成形容词，“将来的”）。

**[есть]{.ru .ix}（吃）和 [дать]{.ru .ix}（给）。** 单数三个人称是古老的无元音词尾 [-м, -шь, -ст]{.ru}，复数的词干加 [д]{.ru}，词尾像第二变位（[дать]{.ru} 的复数第三人称是 [-у́т]{.ru}）：

| 复数第二人称 | [еди́те]{.ru} | [съеди́те]{.ru} | [дади́те]{.ru} | [передади́те]{.ru} |
| 复数第三人称 | [едя́т]{.ru} | [съедя́т]{.ru} | [даду́т]{.ru} | [передаду́т]{.ru} |
| 过去时 | [ел, е́ла, е́ли]{.ru} | [съел, съе́ла, съе́ли]{.ru} | [дал, дала́, да́ли]{.ru} | [переда́л, передала́, переда́ли]{.ru} |
| 命令式 | [ешь, е́шьте]{.ru} | [съешь, съе́шьте]{.ru} | [дай, да́йте]{.ru} | [переда́й, переда́йте]{.ru} |
:::

按 [есть]{.ru} 变位的还有 [пое́сть, надое́сть]{.ru}（[надое́м, надое́шь]{.ru}），[объе́сться]{.ru}；按 [дать]{.ru} 变位的有 [прода́ть, отда́ть, созда́ть, сдать, зада́ть, изда́ть, разда́ть, пода́ть, преда́ть, вы́дать]{.ru}（[вы́дам, вы́дашь, вы́даст, вы́дадим, вы́дадите, вы́дадут]{.ru}）。过去时的重音见 §7.2.3。这些动词都是完成体，人称形式是简单将来时；它们的未完成体 [дава́ть, передава́ть, продава́ть]{.ru} 见 §7.1.4。

**[хоте́ть]{.ru .ix}、[бежа́ть]{.ru .ix}、[чтить]{.ru .ix}。** 两种变位混合：

::: paradigm
| 人称 | [хоте́ть]{.ru} | [бежа́ть]{.ru} | [чтить]{.ru} |
|---|---|---|---|
| 单数第一人称 | [хочу́]{.ru} | [бегу́]{.ru} | [чту]{.ru} |
| 单数第二人称 | [хо́чешь]{.ru} | [бежи́шь]{.ru} | [чтишь]{.ru} |
| 单数第三人称 | [хо́чет]{.ru} | [бежи́т]{.ru} | [чтит]{.ru} |
| 复数第一人称 | [хоти́м]{.ru} | [бежи́м]{.ru} | [чтим]{.ru} |
| 复数第二人称 | [хоти́те]{.ru} | [бежи́те]{.ru} | [чти́те]{.ru} |
| 复数第三人称 | [хотя́т]{.ru} | [бегу́т]{.ru} | [чтят]{.ru}，[чтут]{.ru} |
| 过去时 | [хоте́л, хоте́ла]{.ru} | [бежа́л, бежа́ла]{.ru} | [чтил, чти́ла]{.ru} |
| 命令式 | — | [беги́, беги́те]{.ru} | [чти, чти́те]{.ru} |
:::

- [хоте́ть]{.ru}：单数按第一变位（[-у, -ешь, -ет]{.ru}，[т — ч]{.ru} 交替），复数按第二变位（[-им, -ите, -ят]{.ru}，不交替）。重音也特殊：单数第二、三人称在词干，其余在词尾（§7.1.7）。按它变位的有 [захоте́ть]{.ru}，以及 [-ся]{.ru} 动词 [хоте́ться]{.ru}（[хо́чется]{.ru}，无人称，见 §7.7.2）。没有命令式。
- [бежа́ть]{.ru}：单数第二、三人称和复数第一、二人称按第二变位（[бежи́шь, бежи́т]{.ru}），单数第一人称和复数第三人称是 [г]{.ru} 和第一变位的词尾（[бегу́, бегу́т]{.ru}）。按它变位的有 [прибежа́ть, убежа́ть, побежа́ть, сбежа́ть]{.ru}。
- 【补】[чтить]{.ru}（尊敬，书面）按第二变位，复数第三人称有两个形式：[чтят]{.ru} 和第一变位的 [чтут]{.ru}，两可。

**[идти́]{.ru .ix} 和 [е́хать]{.ru .ix}。** 变位按第一变位，现在时词干是 [ид-]{.ru}、[е́д-]{.ru}，与不定式不同；[идти́]{.ru} 的过去时是另一个词干：

::: paradigm
| 人称 | [идти́]{.ru} | [прийти́]{.ru .ix} | [е́хать]{.ru} | [пое́хать]{.ru .ix} |
|---|---|---|---|---|
| 单数第一人称 | [иду́]{.ru} | [приду́]{.ru} | [е́ду]{.ru} | [пое́ду]{.ru} |
| 单数第二人称 | [идёшь]{.ru} | [придёшь]{.ru} | [е́дешь]{.ru} | [пое́дешь]{.ru} |
| 单数第三人称 | [идёт]{.ru} | [придёт]{.ru} | [е́дет]{.ru} | [пое́дет]{.ru} |
| 复数第一人称 | [идём]{.ru} | [придём]{.ru} | [е́дем]{.ru} | [пое́дем]{.ru} |
| 复数第二人称 | [идёте]{.ru} | [придёте]{.ru} | [е́дете]{.ru} | [пое́дете]{.ru} |
| 复数第三人称 | [иду́т]{.ru} | [приду́т]{.ru} | [е́дут]{.ru} | [пое́дут]{.ru} |
| 过去时 | [шёл, шла, шло, шли]{.ru} | [пришёл, пришла́, пришли́]{.ru} | [е́хал, е́хала]{.ru} | [пое́хал, пое́хала]{.ru} |
| 命令式 | [иди́]{.ru} | [приди́]{.ru} | [поезжа́й]{.ru} | [поезжа́й]{.ru} |
:::

带前缀的 [идти́]{.ru} 写作 [-йти]{.ru}：[уйти́ — уйду́, войти́ — войду́, найти́ — найду́, пойти́ — пойду́, зайти́, подойти́, обойти́, произойти́]{.ru}（[произошло́]{.ru}），过去时 [ушёл, вошёл, нашёл, пошёл]{.ru}；前缀 [при-]{.ru} 加 [идти́]{.ru} 写作 [прийти́]{.ru}，现在时 [приду́]{.ru} 不带 [й]{.ru}；[вы́йти — вы́йду, вы́йдешь]{.ru}，过去时 [вы́шел, вы́шла]{.ru}，命令式 [вы́йди]{.ru}。带前缀的 [е́хать]{.ru}：[прие́хать — прие́ду, уе́хать — уе́ду, въе́хать — въе́ду, вы́ехать — вы́еду]{.ru}。

[е́хать]{.ru} 本身没有标准的命令式，用 [поезжа́й(те)]{.ru}（来自已经不用的未完成体 [поезжа́ть]{.ru}）；带前缀的也是 [-езжа́й]{.ru}：[приезжа́й, уезжа́й, заезжа́й]{.ru}。[езжа́й]{.ru} 是口语；[едь]{.ru}、[е́хай]{.ru} 是俗语。

### 意义和用法

**为什么这几个动词不规则。** [быть, есть, дать]{.ru} 和古代的 [ве́дать]{.ru}（知道）在古俄语里属于一个特殊的变位，单数直接加 [-мь, -си, -сть]{.ru}，没有连接元音。现代的 [ем, дам, ест, даст]{.ru} 就是这种词尾的遗迹；[есть]{.ru}（是、有）是 [быть]{.ru} 的古代单数第三人称。[хоте́ть]{.ru} 和 [бежа́ть]{.ru} 的单复数原来属于不同的词干，后来合成一个动词。这些动词用得最频繁，所以在语言的演变中没有被规则化。

**[есть]{.ru} 的三个同形词。** [есть]{.ru} 可能是：动词 [есть]{.ru}（吃）的不定式；它的单数第三人称是 [ест]{.ru}，不要混；[быть]{.ru} 的现在时，用于“有”“存在”：[У меня́ есть брат]{.ru}（领有句，§12.4.7）；书面语中的系词“是”：[Челове́к есть ме́ра всех веще́й]{.ru}（§12.2.4）。命令式 [ешь]{.ru}（吃吧）又和单数第二人称同形：[Ешь, пока́ горя́чее!]{.ru}（趁热吃！）

**前缀派生词随原词变位。** [съесть, надое́сть]{.ru} 随 [есть]{.ru}；[прода́ть, созда́ть]{.ru} 随 [дать]{.ru}；[прийти́, уйти́, найти́]{.ru} 随 [идти́]{.ru}；[убежа́ть]{.ru} 随 [бежа́ть]{.ru}。认出原动词，就知道整个变位。注意 [перее́хать]{.ru}（搬家）是 [е́хать]{.ru} 的派生词，[перее́сть]{.ru}（吃撑了）才是 [есть]{.ru} 的派生词。

**[дать]{.ru} 和 [дава́ть]{.ru}。** [дам, дашь]{.ru} 是完成体的简单将来时，“将要给”；未完成体 [дава́ть]{.ru} 的现在时是 [даю́, даёшь]{.ru}。两者容易混：[Я дам тебе́ кни́гу]{.ru} 是“我（一会儿）把书给你”，[Я даю́ тебе́ кни́гу]{.ru} 是“我（正在）把书给你”。

::: ex
[За́втра я **бу́ду** до́ма.]{.ru}

[明天我在家。]{.gloss}

[**Бу́дьте** добры́, переда́йте соль.]{.ru}

[劳驾，把盐递过来。]{.gloss}

[— Что вы **еди́те** на за́втрак? — Я **ем** ка́шу, а Ми́ша **ест** бутербро́ды.]{.ru}

[——你们早饭吃什么？——我吃粥，米沙吃三明治。]{.gloss}

[Кто **съел** мой торт?]{.ru}

[谁把我的蛋糕吃了？]{.gloss}

[**Дай** мне, пожа́луйста, ру́чку. — Сейча́с **дам**.]{.ru}

[请把笔给我。——马上给你。]{.gloss}

[Мы **дади́м** вам отве́т за́втра.]{.ru}

[我们明天给您答复。]{.gloss}

[— Что вы **хоти́те**? — Я **хочу́** чай, а де́ти **хотя́т** сок.]{.ru}

[——你们想要什么？——我想要茶，孩子们想要果汁。]{.gloss}

[Куда́ ты **бежи́шь**? — Я **бегу́** на авто́бус.]{.ru}

[——你跑哪儿去？——我去赶公共汽车。]{.gloss}

[Ру́сские **чтят** па́мять Пу́шкина.]{.ru}

[俄罗斯人缅怀普希金。]{.gloss}

[— Куда́ ты **идёшь**? — Я **иду́** в библиоте́ку. Вчера́ я то́же **шёл** туда́, но встре́тил дру́га.]{.ru}

[——你去哪儿？——我去图书馆。昨天我也是往那儿去，可是遇见了朋友。]{.gloss}

[**Приходи́те** к нам в суббо́ту. — Спаси́бо, **придём**.]{.ru}

[星期六到我们家来吧。——谢谢，我们一定来。]{.gloss}

[Ты **е́дешь** на мо́ре? **Поезжа́й**, отдохни́!]{.ru}

[你要去海边？去吧，好好休息！]{.gloss}
:::

### 常见错误

::: err
\*[Они́ хо́чут пить.]{.ru}　→　[Они́ **хотя́т** пить.]{.ru}

[хоте́ть]{.ru} 的复数按第二变位：[хоти́м, хоти́те, хотя́т]{.ru}。
:::

::: err
\*[Мы хо́чем в кино́.]{.ru}　→　[Мы **хоти́м** в кино́.]{.ru}

同上。单数的 [ч]{.ru} 和词干重音不能带到复数里。
:::

::: err
\*[Они́ бежа́т на авто́бус.]{.ru}　→　[Они́ **бегу́т** на авто́бус.]{.ru}

[бежа́ть]{.ru} 的单数第一人称和复数第三人称是 [бегу́, бегу́т]{.ru}。
:::

::: err
\*[Я есть студе́нт.]{.ru}　→　[Я студе́нт.]{.ru}

现在时不用系词；[есть]{.ru} 不是英语的 am / is，只在“有”“存在”的意义上用（§7.2.1）。
:::

::: err
\*[Он идёл в шко́лу.]{.ru}　→　[Он **шёл** в шко́лу.]{.ru}

[идти́]{.ru} 的过去时是另一个词干：[шёл, шла, шло, шли]{.ru}。
:::

::: err
\*[Едь ме́дленно!]{.ru}　→　[**Поезжа́й** ме́дленно!]{.ru}

[е́хать]{.ru} 的命令式借用 [поезжа́й]{.ru}，[едь]{.ru} 是俗语。
:::

::: err
\*[Я даю́ тебе́ кни́гу за́втра.]{.ru}　→　[Я **дам** тебе́ кни́гу за́втра.]{.ru}

将来一次具体的“给”用完成体 [дать]{.ru} 的简单将来时。[даю́]{.ru} 是未完成体 [дава́ть]{.ru} 的现在时。
:::

## §7.1.7 现在时和简单将来时的重音

### 形式

人称形式的重音有三种主要类型：固定在词干上，固定在词尾上，单数第一人称在词尾、其余人称移到词干。扎利兹尼亚克用字母 a、b、c 表示，叫[现在时重音类型]{.term}（[схе́ма ударе́ния в настоя́щем вре́мени]{.ru}）；另有一个只属于 [хоте́ть]{.ru} 的 c′：

::: paradigm
| 人称 | a：[чита́ть]{.ru} | b：[нести́]{.ru} | c：[писа́ть]{.ru} | c′：[хоте́ть]{.ru} |
|---|---|---|---|---|
| 单数第一人称 | [чита́ю]{.ru} | [несу́]{.ru} | [пишу́]{.ru} | [хочу́]{.ru} |
| 单数第二人称 | [чита́ешь]{.ru} | [несёшь]{.ru} | [пи́шешь]{.ru} | [хо́чешь]{.ru} |
| 单数第三人称 | [чита́ет]{.ru} | [несёт]{.ru} | [пи́шет]{.ru} | [хо́чет]{.ru} |
| 复数第一人称 | [чита́ем]{.ru} | [несём]{.ru} | [пи́шем]{.ru} | [хоти́м]{.ru} |
| 复数第二人称 | [чита́ете]{.ru} | [несёте]{.ru} | [пи́шете]{.ru} | [хоти́те]{.ru} |
| 复数第三人称 | [чита́ют]{.ru} | [несу́т]{.ru} | [пи́шут]{.ru} | [хотя́т]{.ru} |
:::

各类型的常用词：

| 类型 | 重音 | 常用词 |
|---|---|---|
| a | 全部在词干，与不定式同一音节 | 能产类型 1–3 的全部动词（[чита́ть, уме́ть, рисова́ть, сове́товать]{.ru}）；[кри́кнуть, ста́вить, ве́рить, ви́деть, слы́шать, пла́кать, ре́зать, е́хать, сесть, стать]{.ru}；全部带 [вы́-]{.ru} 的完成体 |
| b | 全部在词尾 | [говори́ть, звони́ть, реши́ть, лежа́ть, стоя́ть, спать, жить, пить, нести́, вести́, идти́, печь, ждать, брать, нача́ть, взять, дава́ть, встава́ть, отдохну́ть, верну́ть, петь]{.ru} |
| c | 单数第一人称在词尾，其余在词干 | [писа́ть, сказа́ть, показа́ть, иска́ть, маха́ть, люби́ть, ходи́ть, носи́ть, проси́ть, учи́ть, купи́ть, плати́ть, смотре́ть, держа́ть, дыша́ть, терпе́ть, мочь, приня́ть, снять, подня́ть, тяну́ть, коло́ть]{.ru} |
| c′ | 单数第一人称和复数在词尾，单数第二、三人称在词干 | 只有 [хоте́ть, захоте́ть]{.ru} |

### 意义和用法

**由生词表的两个形式判断类型。** 生词表给出单数第一、第二人称，正好能看出类型：两个都重读词干是 a（[ве́рю, ве́ришь]{.ru}），两个都重读词尾是 b（[говорю́, говори́шь]{.ru}），第一个重读词尾、第二个重读词干是 c（[люблю́, лю́бишь]{.ru}）。单数第二人称的重音就是其余四个人称的重音。不存在单数第一人称重读词干而其余重读词尾的类型。

**从不定式能看出什么。** 不定式的重音不在最后一个音节的（[ста́вить, ви́деть, пла́кать, ре́зать, е́хать, сове́товать]{.ru}），几乎都是 a，重音始终在不定式重读的那个音节上（[ста́влю, ста́вишь]{.ru}；[пла́чу, пла́чешь]{.ru}）。不定式重读最后一个音节的（[говори́ть, люби́ть, писа́ть, чита́ть, нести́]{.ru}），三种类型都有可能，要看生词表：

- [-а́ть, -я́ть, -е́ть]{.ru} 的能产类型（[чита́ть, гуля́ть, уме́ть]{.ru}）是 a，重音在 [-а́-, -я́-, -е́-]{.ru} 上；[-ова́ть]{.ru} 动词是 a，重音在 [-у́-]{.ru} 上（[рису́ю, рису́ешь]{.ru}），[кова́ть, жева́ть]{.ru} 等少数是 b（§7.1.3）。
- [-и́ть]{.ru} 动词 b 和 c 都很多：[говори́ть, звони́ть, реши́ть, включи́ть]{.ru} 是 b；[люби́ть, ходи́ть, учи́ть, купи́ть, плати́ть, кури́ть, вари́ть, дари́ть]{.ru} 是 c。
- [-сти́, -зти́]{.ru} 动词、单音节的 [жить, пить, ждать, брать]{.ru} 等几乎都是 b。
- [-а́ть]{.ru} 的非能产动词多是 c（[писа́ть, сказа́ть, иска́ть]{.ru}）。

**[-ся]{.ru} 和前缀不改变重音。** [учи́ться — учу́сь, у́чишься]{.ru} 和 [учи́ть — учу́, у́чишь]{.ru} 一样是 c；[написа́ть — напишу́, напи́шешь]{.ru} 和 [писа́ть]{.ru} 一样，[подари́ть — подарю́, пода́ришь]{.ru} 和 [дари́ть]{.ru} 一样。唯一的例外是前缀 [вы́-]{.ru}：带 [вы́-]{.ru} 的完成体所有形式都重读 [вы́-]{.ru}，一律是 a：[вы́пить — вы́пью, вы́пьешь]{.ru}，[вы́учить — вы́учу, вы́учишь]{.ru}，[вы́йти — вы́йду, вы́йдешь]{.ru}，[вы́брать — вы́беру, вы́берешь]{.ru}。

**重读的词尾 [е]{.ru} 写 [ё]{.ru}。** b 类第一变位的词尾都写 [ё]{.ru}：[несёшь, живёшь, берёшь, даёшь, начнёшь, поёшь]{.ru}；c 类的词尾不重读，写 [е]{.ru}：[пи́шешь, мо́жешь]{.ru}。

**重音区别意义。** 有些形式只靠重音区别是哪个动词：

| 形式 | 意义 | 形式 | 意义 |
|---|---|---|---|
| [узнаю́]{.ru}（[узнава́ть]{.ru}） | 认出；（正在）打听到 | [узна́ю]{.ru}（[узна́ть]{.ru}） | （将要）打听到 |
| [плачу́]{.ru}（[плати́ть]{.ru}） | 我付钱 | [пла́чу]{.ru}（[пла́кать]{.ru}） | 我哭 |
| [заплачу́]{.ru}（[заплати́ть]{.ru}） | 我将付钱 | [запла́чу]{.ru}（[запла́кать]{.ru}） | 我会哭起来 |
| [стои́т]{.ru}（[стоя́ть]{.ru}） | 站着；立着 | [сто́ит]{.ru}（[сто́ить]{.ru}） | 值，价钱是 |

**口语中的重音移动和标准。** 一些 b 类 [-и́ть]{.ru} 动词在口语里有把重音移到词干的倾向，标准语仍以词尾重音为准：[звони́ть]{.ru .ix} 的标准形式是 [звони́шь, звони́т, звоня́т]{.ru}，[зво́нишь, зво́нит]{.ru} 是口语、俗语；同样，[включи́ть]{.ru .ix} 是 [включу́, включи́шь, включи́т]{.ru}，[вручи́ть]{.ru} 是 [вручи́т]{.ru}，[облегчи́ть]{.ru} 是 [облегчи́т]{.ru}。这些词的重音常被用来衡量说话人的语言修养，要说标准形式。有些动词经过同样的移动，现在的标准已经是 c：[вари́ть — ва́ришь]{.ru}，[дари́ть — да́ришь]{.ru}，[кури́ть — ку́ришь]{.ru}。各动词的重音以词典为准，全部词表见附录六。

**完成体将来时里 c 类特别多。** 许多常用的完成体是 c 类，单数第一人称和其余人称重音不同：[скажу́ — ска́жешь, покажу́ — пока́жешь, куплю́ — ку́пишь, спрошу́ — спро́сишь, подарю́ — пода́ришь]{.ru}；同样常用的 [отве́тить, пригото́вить, уви́деть]{.ru} 却是 a：[отве́чу, отве́тишь; пригото́влю, пригото́вишь]{.ru}。所以每个动词都要连同生词表的两个形式一起记，不能类推。

::: ex
[— Что ты **пи́шешь**? — **Пишу́** письмо́ ба́бушке.]{.ru}

[——你在写什么？——在给奶奶写信。]{.gloss}

[Я **люблю́** джаз, а ты что **лю́бишь**?]{.ru}

[我喜欢爵士乐，你喜欢什么？]{.gloss}

[— Ты мне **позвони́шь**? — Да, **позвоню́** ве́чером.]{.ru}

[——你会给我打电话吗？——会，晚上打。]{.gloss}

[Я не **пла́чу**, я смею́сь!]{.ru}

[我不是在哭，我在笑！]{.gloss}

[Не беспоко́йся, я **плачу́**.]{.ru}

[别操心，我来付钱。]{.gloss}

[Ско́лько **сто́ит** биле́т? — Вон там **стои́т** ка́сса, спроси́те.]{.ru}

[——票多少钱？——售票处就在那边，问一问吧。]{.gloss}

[Я тебя́ сра́зу **узнаю́** по го́лосу.]{.ru}

[我一听声音就认出你来了。]{.gloss}

[Я **узна́ю**, когда́ экза́мен, и **скажу́** тебе́.]{.ru}

[我去打听考试是什么时候，再告诉你。]{.gloss}
:::

### 常见错误

::: err
\*[Он ча́сто мне зво́нит.]{.ru}　→　[Он ча́сто мне **звони́т**.]{.ru}

[звони́ть]{.ru} 的标准重音在词尾。[зво́нит]{.ru} 在口语中常听到，但不合规范。
:::

::: err
\*[Ты хорошо́ смотри́шь?]{.ru}　→　[Ты хорошо́ **смо́тришь**?]{.ru}

[смотре́ть]{.ru} 是 c 类：[смотрю́, смо́тришь]{.ru}，不要按 [говори́шь]{.ru} 读。
:::

::: err
\*[Я пи́шу письмо́.]{.ru}　→　[Я **пишу́** письмо́.]{.ru}

c 类的单数第一人称重读词尾，不能按其余人称类推。
:::

::: err
\*[Сего́дня я пла́чу за обе́д.]{.ru}　→　[Сего́дня я **плачу́** за обе́д.]{.ru}

[пла́чу]{.ru} 是“哭”，[плачу́]{.ru} 是“付钱”。重音读错，意思就变了。
:::

::: err
\*[Я выпью́ ко́фе.]{.ru}（重音读在词尾）　→　[Я **вы́пью** ко́фе.]{.ru}

带 [вы́-]{.ru} 的完成体所有形式都重读 [вы́-]{.ru}，词尾不重读：[вы́пью, вы́пьешь]{.ru}。
:::

## §7.1.8 不定式及其用法

### 形式

[不定式]{.term}（[инфинити́в]{.ru}）是动词的非变位形式，不表示人称、数和时，只带着体（[чита́ть — прочита́ть]{.ru}）和态（[стро́ить — стро́иться]{.ru}）。词典用不定式作动词的原形。不定式有三种词尾：

| 词尾 | 出现在 | 例 |
|---|---|---|
| [-ть]{.ru} | 元音后，绝大多数动词 | [чита́ть, говори́ть, уме́ть, мыть, тяну́ть, коло́ть]{.ru}；[класть, сесть, лезть]{.ru}（[-сть]{.ru}，见 §7.1.4） |
| [-ти]{.ru} | 辅音后，词尾重读 | [нести́, везти́, вести́, идти́, расти́, грести́]{.ru} |
| [-ти]{.ru}（不重读） | 只在带 [вы́-]{.ru} 的派生词里 | [вы́нести, вы́йти, вы́расти, вы́вести]{.ru} |
| [-чь]{.ru} | 词干末为 [г, к]{.ru} 的动词 | [мочь, печь, бере́чь, лечь, жечь, помо́чь]{.ru} |

[-ся]{.ru} 动词的不定式：[-ть]{.ru} 后加 [-ся]{.ru}（[учи́ться, занима́ться]{.ru}，[-ться]{.ru} 读 [[цъ]]{.tr}），[-ти]{.ru} 后加 [-сь]{.ru}（[нести́сь, спасти́сь]{.ru}），[-чь]{.ru} 后加 [-ся]{.ru}（[бере́чься, увле́чься]{.ru}）。

### 意义和用法

不定式只说出动作本身，不说是谁、在什么时候做的，所以它在句中常和别的词合在一起表示意思。它的用法有以下几种。

**1. 作主语。** 不定式表示一种活动，作主语，谓语多是谓语副词、名词或 [э́то]{.ru} 句：[Кури́ть вре́дно]{.ru}（吸烟有害），[Учи́ть язы́к — э́то интере́сно]{.ru}。不定式作主语时，谓语的形容词、过去时用中性：[Отказа́ться бы́ло тру́дно]{.ru}。不定式前后都可以有 [э́то]{.ru} 复指：[Отдыха́ть на мо́ре — э́то большо́е удово́льствие]{.ru}。

**2. 作合成动词谓语的一部分。** 不定式和情态动词（[мочь, уме́ть, хоте́ть, люби́ть, собира́ться]{.ru}）、阶段动词（[начина́ть, конча́ть, продолжа́ть, стать]{.ru}）、短尾形容词（[до́лжен, гото́в, рад]{.ru}）、谓语副词（[на́до, мо́жно, нельзя́]{.ru}）一起构成谓语：[Я уме́ю пла́вать]{.ru}，[Он на́чал рабо́тать]{.ru}，[Мне на́до идти́]{.ru}。这是不定式最常见的用法，主语就是不定式动作的主体。各类情态词的意义见 §12.2.3，谓语副词见 §8.2.2，体的选择见 §7.3.10。

**3. 作补语。** 不定式的动作由另一个人完成：[Я попроси́л его́ помо́чь]{.ru}（我请他帮忙），[Ма́ма веле́ла Ми́ше убра́ть ко́мнату]{.ru}，[Учи́тель сове́тует нам чита́ть вслух]{.ru}，[Мы пригласи́ли их пообе́дать]{.ru}。这样用的是 [проси́ть, сове́товать, разреша́ть, запреща́ть, помога́ть, учи́ть, веле́ть, приглаша́ть, угова́ривать, заставля́ть]{.ru} 一类表示请求、命令、允许、帮助的动词，不定式的主体就是这些动词的补语（[его́, Ми́ше, нам]{.ru}）。

**4. 作定语。** 不定式说明名词的内容，回答“什么样的”：[жела́ние учи́ться]{.ru}（学习的愿望），[привы́чка встава́ть ра́но]{.ru}（早起的习惯），[возмо́жность отдохну́ть]{.ru}，[спо́соб реши́ть зада́чу]{.ru}，[пра́во голосова́ть]{.ru}，[про́сьба не кури́ть]{.ru}。这些名词多与可以接不定式的动词、形容词同根（[жела́ть — жела́ние]{.ru}，[привы́кнуть — привы́чка]{.ru}，[возмо́жно — возмо́жность]{.ru}）。汉语把这种定语放在名词前加“的”，俄语放在名词后，不加任何词。

**5. 作目的状语。** 运动动词后直接用不定式表示目的：[Он пришёл помо́чь]{.ru}（他来帮忙），[Пойдём обе́дать]{.ru}（咱们去吃午饭吧），[Ма́ма пое́хала в го́род купи́ть пода́рок]{.ru}，[Я зашёл попроща́ться]{.ru}。这种用法只限于运动动词（[идти́, пойти́, прийти́, е́хать, зайти́, приезжа́ть, бежа́ть]{.ru} 等）和 [сесть, лечь, оста́ться, встать]{.ru} 一类表示位置变化的动词（[Сади́сь у́жинать]{.ru}，[Он лёг спать]{.ru}）。其他动词后表示目的用 [что́бы]{.ru}：[Я рабо́таю, что́бы помо́чь роди́телям]{.ru}。运动动词后也可以用 [что́бы]{.ru}，强调目的，分工见 §13.2.10。

**6. 作独立句的谓语。** 不定式可以单独构成句子，表示必要、命令、疑问、不可能等（[Что де́лать?]{.ru}，[Молча́ть!]{.ru}，[Мне за́втра ра́но встава́ть]{.ru}），见 §12.4.5。

**不定式的主体。** 不定式本身不表示人称，它的主体按句子结构确定：在合成谓语里是句子的主语（[Я хочу́ поспа́ть]{.ru}，想睡的是“我”）；在第 3 种用法里是补语（[Я прошу́ тебя́ помо́чь]{.ru}，帮忙的是“你”）；在无人称句里是第三格（[Мне на́до рабо́тать]{.ru}，§12.4.4）。主语想要别人做某事时，[хоте́ть]{.ru} 后不能接不定式，要用 [что́бы]{.ru} 从句：[Я хочу́, что́бы ты пришёл]{.ru}（§13.2.10）。

**不定式保持动词的支配。** 不定式后的补语按不定式本身的要求用格：[Я хочу́ купи́ть **кни́гу**]{.ru}（[купи́ть что]{.ru}，第四格），[Я хочу́ помо́чь **дру́гу**]{.ru}（[помо́чь кому́]{.ru}，第三格），[Он мечта́ет стать **врачо́м**]{.ru}（[стать кем]{.ru}，第五格）。前面的 [хоте́ть, мечта́ть]{.ru} 不影响后面补语的格。

**俄汉差异。** 汉语的动词可以直接连用：“我想睡觉”“他去买东西”“学习的愿望”，动词形式都不变。俄语只有不定式能这样接在另一个词后面，前面的动词要变位，后面的动词用不定式：“我喜欢看书”是 [Я люблю́ чита́ть]{.ru}，不能两个都变位。反过来，汉语里的“去买”“来帮忙”在俄语里只有运动动词能直接接不定式；“我工作是为了帮父母”这类非运动动词后的目的要用 [что́бы]{.ru}。不定式的体见 §7.3.10。

::: ex
[**Учи́ть** иностра́нный язы́к нелегко́, но интере́сно.]{.ru}

[学外语不容易，但是有意思。]{.gloss}

[**Опозда́ть** на экза́мен бы́ло бы глу́по.]{.ru}

[考试迟到就太傻了。]{.gloss}

[Ми́ша уме́ет **игра́ть** в ша́хматы.]{.ru}

[米沙会下国际象棋。]{.gloss}

[Мы собира́емся **пое́хать** в Петербу́рг.]{.ru}

[我们打算去彼得堡。]{.gloss}

[Ма́ма попроси́ла меня́ **купи́ть** хлеб.]{.ru}

[妈妈让我去买面包。]{.gloss}

[Врач сове́тует ба́бушке бо́льше **гуля́ть**.]{.ru}

[医生建议奶奶多散散步。]{.gloss}

[У меня́ есть жела́ние **поступи́ть** в аспиранту́ру.]{.ru}

[我想考研究生。]{.gloss}

[Э́то хоро́шая возмо́жность **попрактикова́ться** в ру́сском языке́.]{.ru}

[这是练习俄语的好机会。]{.gloss}

[Ван Лэй пришёл **попроща́ться**: за́втра он уезжа́ет домо́й.]{.ru}

### 常见错误

::: err
\*[Я люблю́ чита́ю.]{.ru}　→　[Я люблю́ **чита́ть**.]{.ru}

两个动词连用时，只有前一个变位，后一个用不定式。
:::

::: err
\*[Я хочу́ ты пришёл.]{.ru}　→　[Я хочу́, **что́бы** ты пришёл.]{.ru}

希望别人做某事，[хоте́ть]{.ru} 后用 [что́бы]{.ru} 从句，从句谓语用过去时形式（§13.2.5）。汉语“我想你来”不加任何词，俄语必须加。
:::

::: err
\*[Я учу́ ру́сский язы́к понима́ть ру́сские фи́льмы.]{.ru}　→　[Я учу́ ру́сский язы́к, **что́бы** понима́ть ру́сские фи́льмы.]{.ru}

只有运动动词后才能直接用不定式表示目的，[учи́ть]{.ru} 后要用 [что́бы]{.ru}。
:::

::: err
\*[Я хочу́ помо́чь дру́га.]{.ru}　→　[Я хочу́ помо́чь **дру́гу**.]{.ru}

补语的格由不定式 [помо́чь]{.ru}（[кому́]{.ru}）决定，与前面的 [хоте́ть]{.ru} 无关。
:::

::: err
\*[У меня́ есть жела́ние, что учи́ться в Москве́.]{.ru}　→　[У меня́ есть жела́ние **учи́ться** в Москве́.]{.ru}

名词后的不定式定语直接放在名词后面，不加连接词。
:::
