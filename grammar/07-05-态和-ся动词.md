本章讲动词与补语的关系：能不能带直接补语（§7.5.1），以及由此而来的 [-ся]{.ru} 动词——它的构成和类别（§7.5.2）、意义（§7.5.3）、被动结构（§7.5.4）和无人称用法（§7.5.5）。[-ся]{.ru} 动词的变位见 §7.1.2，读音见 §1.2.5，过去时重音见 §7.2.3；[-ся]{.ru} 与 [себя́]{.ru}、[друг дру́га]{.ru} 的分工见 §5.1.4、§5.1.5；被动形动词的构成见 §7.8.4–§7.8.6；施事的第五格见 §3.7.3；无人称动词总的情况见 §7.7.2。

## §7.5.1 及物动词与不及物动词

### 形式

能带不加前置词的第四格补语的动词叫[及物动词]{.term}（[перехо́дный глаго́л]{.ru}），这个补语就是直接补语，表示动作直接涉及的对象（§3.5.2）：[чита́ть кни́гу, писа́ть письмо́, стро́ить дом, люби́ть ма́му]{.ru}。及物动词带否定时，直接补语可以改用第二格（[не чита́л э́той кни́ги]{.ru}，§3.6.3）；表示部分时也用第二格（[купи́ть хле́ба]{.ru}，§3.6.2）。这两种第二格都是直接补语的变体，动词仍是及物的。

不能带直接补语的动词叫[不及物动词]{.term}（[неперехо́дный глаго́л]{.ru}）。不及物动词可以带别的格或前置词短语，那不是直接补语：

| 类 | 例 |
|---|---|
| 不带补语 | [спать, жить, сиде́ть, идти́, расти́]{.ru} |
| 带第二格 | [боя́ться соба́ки, достига́ть це́ли]{.ru} |
| 带第三格 | [помога́ть дру́гу, звони́ть ма́ме, ве́рить отцу́]{.ru} |
| 带第五格 | [занима́ться спо́ртом, руководи́ть заво́дом]{.ru} |
| 带前置词 | [ду́мать о бра́те, наде́яться на успе́х, жени́ться на ней]{.ru} |
| 所有 [-ся]{.ru} 动词 | [учи́ться, встреча́ться, начина́ться]{.ru} |

判断及物与否只看形式：不加前置词的第四格补语。[ждать неде́лю]{.ru}、[рабо́тать всю ночь]{.ru} 里的第四格表示时间，不是补语，[рабо́тать]{.ru} 仍是不及物动词；[наде́яться на по́мощь]{.ru} 里的第四格带前置词，也不算直接补语。

**[-ся]{.ru} 动词都是不及物的。** [-ся]{.ru} 原是反身代词第四格的古老形式（相当于 [себя́]{.ru}），加在动词上就占了直接补语的位置，所以 [-ся]{.ru} 动词不能再带第四格补语。口语里个别 [-ся]{.ru} 动词带指人的第四格：[боя́ться ба́бушку]{.ru}、[слу́шаться ма́му]{.ru}，标准语用第二格：[боя́ться ба́бушки]{.ru}、[слу́шаться ма́мы]{.ru}。

**及物动词的独立用法。** 及物动词不带补语时仍是及物动词，只是把动作本身当作说话的重点：[Он чита́ет]{.ru}（他在看书），[Она́ хорошо́ пи́шет]{.ru}（她文章写得好），[Ребёнок уже́ хорошо́ говори́т]{.ru}。

### 意义和用法

**【补】态的范畴。** [态]{.term}（[зало́г]{.ru}）是动词表示主语与动作的关系的语法范畴：主语是动作的发出者，还是动作的承受者。[主动态]{.term}（[действи́тельный зало́г]{.ru}）的句子里主语是施事，及物动词的直接补语是承受者：[Рабо́чие стро́ят дом.]{.ru} [被动态]{.term}（[страда́тельный зало́г]{.ru}）的句子里，承受者变成主语，施事退到第五格或不说出来：[Дом стро́ится рабо́чими.]{.ru} [Дом постро́ен рабо́чими.]{.ru}

俄语的被动态有两种表示方法：未完成体及物动词加 [-ся]{.ru}（[стро́ится]{.ru}），完成体[被动形动词]{.term}（[страда́тельное прича́стие]{.ru}）的短尾（[постро́ен]{.ru}）。用法见 §7.5.4，被动形动词的构成见 §7.8.4–§7.8.6。由此可以推出：

1. 只有及物动词有被动态，不及物动词（[спать, помога́ть, занима́ться]{.ru}）无所谓主动和被动。
2. [-ся]{.ru} 动词只在一部分意义上是被动的（[Дом стро́ится]{.ru}），大部分 [-ся]{.ru} 动词表示反身、相互、自发等意义（§7.5.3），只是不及物，不是被动。

俄罗斯较早的语法书和学校语法曾把非被动的 [-ся]{.ru} 动词另立为一种“反身中动态”（[возвра́тно-сре́дний зало́г]{.ru}）；本书按 [РГ-80]{.ru} 只分主动、被动两种态，[-ся]{.ru} 的各种非被动意义归入 [-ся]{.ru} 动词的词汇语法类别（§7.5.3）。

**与位置有关的及物和不及物动词。** “放”和“在”在俄语里是成对的两套动词，及物的表示“使处于某种位置”，不及物的表示“处于某种位置”：

| 及物（使……） | 不及物（处于……） | 不及物（进入位置） |
|---|---|---|
| [ста́вить — поста́вить]{.ru}（竖着放） | [стоя́ть]{.ru}（立着） | [встава́ть — встать]{.ru}（站起来） |
| [класть — положи́ть]{.ru}（平放） | [лежа́ть]{.ru}（躺着） | [ложи́ться — лечь]{.ru}（躺下） |
| [сажа́ть — посади́ть]{.ru}（使坐） | [сиде́ть]{.ru}（坐着） | [сади́ться — сесть]{.ru}（坐下） |
| [ве́шать — пове́сить]{.ru}（挂） | [висе́ть]{.ru}（挂着） | — |

::: ex
[Я **положи́л** кни́гу на стол. Кни́га **лежи́т** на столе́.]{.ru}

[我把书放在桌上。书在桌上放着。]{.gloss}

[Ма́ма **посади́ла** Ми́шу у окна́. Ми́ша **сиди́т** у окна́.]{.ru}

[妈妈让米沙坐在窗边。米沙坐在窗边。]{.gloss}
:::

**俄汉差异。** 汉语的“宾语”比俄语的直接补语宽得多：“帮助朋友”“给妈妈打电话”“想他”“娶她”“学俄语”在汉语里都是动词加宾语，俄语却分别是第三格（[помога́ть дру́гу, звони́ть ма́ме]{.ru}）、前置词短语（[ду́мать о нём, жени́ться на ней]{.ru}）和第四格（[учи́ть ру́сский язы́к]{.ru}）。所以学动词时要连同它的支配一起记（支配见 §12.1.2，全表见附录五），不能按汉语的“动词加宾语”一律用第四格。

::: ex
[А́нна **чита́ет** **письмо́**.]{.ru}

[安娜在读信。（及物，第四格）]{.gloss}

[Я не **получа́л** **письма́**.]{.ru}

[我没收到过信。（及物，否定时第二格）]{.gloss}

[Ван Лэй **помога́ет** **Ми́ше**.]{.ru}

[王磊在帮米沙。（不及物，第三格）]{.gloss}

[Ми́ша **занима́ется** **футбо́лом**.]{.ru}

[米沙在练足球。（不及物，第五格）]{.gloss}

[Ле́кция **начина́ется** в де́вять.]{.ru}

[讲座九点开始。（[-ся]{.ru} 动词，不及物）]{.gloss}

[Э́тот мост **постро́или** в про́шлом ве́ке. — Э́тот мост **был постро́ен** в про́шлом ве́ке.]{.ru}

[这座桥是上个世纪建的。（主动态的不定人称句——被动态）]{.gloss}
:::

### 常见错误

::: err
\*[Я помога́ю дру́га.]{.ru}　→　[Я помога́ю **дру́гу**.]{.ru}

汉语“帮助朋友”是动宾结构，俄语 [помога́ть]{.ru} 不及物，要求第三格。
:::

::: err
\*[Он жени́лся её.]{.ru}　→　[Он жени́лся **на ней**.]{.ru}

汉语“娶她”，俄语用 [жени́ться на ком]{.ru}；[-ся]{.ru} 动词不能带第四格。
:::

::: err
\*[Я учу́сь ру́сский язы́к.]{.ru}　→　[Я **учу́** ру́сский язы́к.]{.ru} / [Я **учу́сь ру́сскому языку́**.]{.ru}

[учи́ть]{.ru} 及物，带第四格；[учи́ться]{.ru} 不及物，学的东西用第三格。
:::

::: err
\*[Я ду́маю его́.]{.ru}　→　[Я ду́маю **о нём**.]{.ru}

“想他”的“他”在俄语里是带 [о]{.ru} 的第六格。
:::

## §7.5.2 [-ся]{.ru} 动词的构成和类别

### 形式

在动词的各个形式后面加后缀 [-ся]{.ru} 或 [-сь]{.ru}，构成[[-ся]{.ru} 动词]{.term}（[возвра́тный глаго́л]{.ru}）。[-ся]{.ru} 加在词尾之后，是词的最后一个成分。写法：

- 辅音后加 [-ся]{.ru}，元音后加 [-сь]{.ru}：[занима́юсь, занима́ешься, занима́лся, занима́лась]{.ru}；
- [й]{.ru}、[ь]{.ru} 后加 [-ся]{.ru}：[занима́йся, познако́мься, встре́ться]{.ru}；
- 形动词不论前面是什么音，一律加 [-ся]{.ru}：[занима́ющийся, занима́ющаяся, занима́ющееся, занима́ющиеся]{.ru}，[верну́вшийся]{.ru}。

下表列出未完成体 [одева́ться]{.ru .ix} 和完成体 [верну́ться]{.ru .ix} 的全部形式：

::: paradigm
| 形式 | [одева́ться]{.ru}（未完成体） | [верну́ться]{.ru}（完成体） |
|---|---|---|
| 单数第一人称 | [одева́юсь]{.ru} | [верну́сь]{.ru} |
| 单数第二人称 | [одева́ешься]{.ru} | [вернёшься]{.ru} |
| 单数第三人称 | [одева́ется]{.ru} | [вернётся]{.ru} |
| 复数第一人称 | [одева́емся]{.ru} | [вернёмся]{.ru} |
| 复数第二人称 | [одева́етесь]{.ru} | [вернётесь]{.ru} |
| 复数第三人称 | [одева́ются]{.ru} | [верну́тся]{.ru} |
| 过去时 | [одева́лся, одева́лась, одева́лось, одева́лись]{.ru} | [верну́лся, верну́лась, верну́лось, верну́лись]{.ru} |
| 将来时 | [бу́ду одева́ться]{.ru} | （见人称形式） |
| 命令式 | [одева́йся, одева́йтесь]{.ru} | [верни́сь, верни́тесь]{.ru} |
| 假定式 | [одева́лся бы]{.ru} | [верну́лся бы]{.ru} |
| 不定式 | [одева́ться]{.ru} | [верну́ться]{.ru} |
| 主动形动词 | [одева́ющийся, одева́вшийся]{.ru} | [верну́вшийся]{.ru} |
| 副动词 | [одева́ясь]{.ru} | [верну́вшись]{.ru} |
:::

[-ся]{.ru} 动词没有被动形动词，因为它们都不及物。复合将来时里 [-ся]{.ru} 留在不定式上：[бу́ду занима́ться]{.ru}，不加在 [бу́ду]{.ru} 上。

**读音和写法：[-тся]{.ru} 与 [-ться]{.ru}。** [-тся, -ться]{.ru} 都读 [[цъ]]{.tr}，所以单数第三人称 [ложи́тся]{.ru} 和不定式 [ложи́ться]{.ru} 读音完全相同，[у́чится]{.ru} 和 [учи́ться]{.ru} 只差重音。写的时候要分清：回答 [что де́лает?]{.ru}（人称形式）的写 [-тся]{.ru}，没有 [ь]{.ru}；回答 [что де́лать?]{.ru}（不定式）的写 [-ться]{.ru}，带 [ь]{.ru}，因为不定式本来就以 [-ть]{.ru} 结尾。[-ся, -сь]{.ru} 中的 [с]{.ru} 标准读软音 [[сʼъ]]{.tr}，读硬音是旧莫斯科读法。详见 §1.2.5。

**重音。** 现在时的重音与不带 [-ся]{.ru} 的动词相同；一部分动词过去时的重音与不带 [-ся]{.ru} 的不同，移到 [-ся]{.ru} 前的词尾上：[на́чал — начался́, начала́сь]{.ru}，[роди́лся, родила́сь]{.ru}，[подня́лся, подняла́сь]{.ru}，见 §7.2.3。

**类别。** 按与不带 [-ся]{.ru} 的动词的关系，[-ся]{.ru} 动词分四类：

| 类 | 例 | 说明 |
|---|---|---|
| 1. 与不带 [-ся]{.ru} 的动词成对，意义相关 | [мыть — мы́ться]{.ru}，[начина́ть — начина́ться]{.ru}，[встре́тить кого́ — встре́титься с кем]{.ru}，[ра́довать — ра́доваться]{.ru}，[верну́ть — верну́ться]{.ru}，[учи́ть — учи́ться]{.ru} | [-ся]{.ru} 表示反身、相互、被动等意义（§7.5.3） |
| 2. 只有 [-ся]{.ru} 形式 | [боя́ться]{.ru .ix}、[смея́ться]{.ru .ix}、[наде́яться]{.ru .ix}、[улыба́ться]{.ru .ix}、[нра́виться]{.ru .ix}、[стара́ться]{.ru}、[горди́ться]{.ru}、[сомнева́ться]{.ru}、[здоро́ваться]{.ru}、[ложи́ться]{.ru}、[очути́ться]{.ru} | 去掉 [-ся]{.ru} 就不成词，[-ся]{.ru} 没有单独的意义 |
| 3. 与不带 [-ся]{.ru} 的动词意义相差较远 | [находи́ть]{.ru}（找到）— [находи́ться]{.ru .ix}（位于）；[занима́ть]{.ru}（占）— [занима́ться]{.ru .ix}（从事，学习）；[проща́ть]{.ru}（原谅）— [проща́ться]{.ru}（告别）；[сдава́ть]{.ru}（交，考）— [сдава́ться]{.ru}（投降）；[явля́ть]{.ru}（显示，书面）— [явля́ться]{.ru}（是） | 当作两个词记 |
| 4. 前缀与 [-ся]{.ru} 同时加上 | [нае́сться]{.ru}（吃饱），[договори́ться]{.ru}（商定），[разойти́сь]{.ru}（散开），[заговори́ться]{.ru}（说得忘了时间） | 前缀和 [-ся]{.ru} 合起来表示一个意义，去掉其中一个就不成词（[разойти́]{.ru} 不单用）或意义不同（[договори́ть]{.ru} 是“说完”）；见 §7.3.5、§7.6.9、§11.3.3 |

### 意义和用法

**[-ся]{.ru} 不改变体。** [-ся]{.ru} 动词的体和不带 [-ся]{.ru} 的动词相同，体对也照常：[одева́ться — оде́ться]{.ru}，[встреча́ться — встре́титься]{.ru}，[начина́ться — нача́ться]{.ru}，[ра́доваться — обра́доваться]{.ru}。

**[-ся]{.ru} 只能代替第四格。** [-ся]{.ru} 原来就是第四格的 [себя́]{.ru}，所以只有动作对象是第四格时才能用 [-ся]{.ru}：[мыть себя́ → мы́ться]{.ru}。动作对象是别的格时只能用 [себя́]{.ru}：[купи́ть себе́]{.ru}，不说 [*купи́ться]{.ru}；[ду́мать о себе́]{.ru}。[-ся]{.ru} 与 [себя́]{.ru} 的分工见 §5.1.4。

**同一个 [-ся]{.ru} 动词可以有几种意义。** [-ся]{.ru} 本身没有固定的意义，[-ся]{.ru} 动词表示什么，要看动词的词义、主语是人还是事物、句子里有没有施事，见 §7.5.3。

**别处讲到的 [-ся]{.ru} 动词。** 带前缀又带 [-ся]{.ru} 的行为方式（[нае́сться, наговори́ться]{.ru}）见 §7.3.5；运动动词的 [сойти́сь, разойти́сь, съе́хаться]{.ru} 见 §7.6.9；前缀与 [-ся]{.ru} 的组合见 §11.3.3。

**俄汉差异。** 汉语没有和 [-ся]{.ru} 对应的形式，“开”“见面”“高兴”“学习”在汉语里都是一个动词，俄语却要分清带不带 [-ся]{.ru}：[Он открыва́ет дверь]{.ru}（他开门）/ [Дверь открыва́ется]{.ru}（门开了）。学动词时要把 [-ся]{.ru} 当成词的一部分来记，不能随意加减。

::: ex
[Ми́ша **умыва́ется** и **одева́ется**.]{.ru}

[米沙在洗脸、穿衣服。]{.gloss}

[Ма́ма **одева́ет** ма́ленького сы́на.]{.ru}

[妈妈在给小儿子穿衣服。]{.gloss}

[Я **бою́сь** соба́к.]{.ru}

[我怕狗。]{.gloss}

[Ле́на **улыбну́лась**, и все **засмея́лись**.]{.ru}

[列娜笑了笑，大家都笑了起来。]{.gloss}

[На́ша шко́ла **нахо́дится** ря́дом с па́рком.]{.ru}

[我们学校在公园旁边。]{.gloss}

[Мы **договори́лись** встре́титься в шесть.]{.ru}

[我们约好六点见面。]{.gloss}
:::

### 常见错误

::: err
\*[Он занима́лсь в библиоте́ке.]{.ru}　→　[Он **занима́лся** в библиоте́ке.]{.ru}

[л]{.ru} 是辅音，后面加 [-ся]{.ru}；[-сь]{.ru} 只加在元音后（[занима́лась]{.ru}）。
:::

::: err
\*[студе́нты, занима́ющиесь спо́ртом]{.ru}　→　[студе́нты, **занима́ющиеся** спо́ртом]{.ru}

形动词一律加 [-ся]{.ru}，即使前面是元音。
:::

::: err
\*[Я встре́тился его́ в метро́.]{.ru}　→　[Я **встре́тил** его́ в метро́.]{.ru} / [Я **встре́тился с ним** в метро́.]{.ru}

[-ся]{.ru} 动词不带第四格：“碰见他”用 [встре́тить]{.ru}，“和他见面”用 [встре́титься с кем]{.ru}。
:::

::: err
\*[Он у́читься в шко́ле.]{.ru}　→　[Он **у́чится** в шко́ле.]{.ru}

人称形式（[что де́лает?]{.ru}）写 [-тся]{.ru}；[-ться]{.ru} 只用于不定式（[Он хо́чет учи́ться]{.ru}）。两者读音相同，只能靠语法判断。
:::

::: err
\*[Я бу́дусь занима́ть.]{.ru}　→　[Я **бу́ду занима́ться**.]{.ru}

复合将来时里 [-ся]{.ru} 留在不定式上。
:::

## §7.5.3 [-ся]{.ru} 动词的意义

### 意义和用法

与不带 [-ся]{.ru} 的动词成对的 [-ся]{.ru} 动词（§7.5.2 第 1 类），按 [-ся]{.ru} 带来的意义分为下面几类。被动意义见 §7.5.4，无人称意义见 §7.5.5。

**1. 反身意义：动作回到主语自己身上。** 主语对自己做某个动作，[-ся]{.ru} 相当于 [себя́]{.ru}，这叫[反身意义]{.term}（[со́бственно-возвра́тное значе́ние]{.ru}）。只限于少数表示照料身体、穿戴、姿势的动词：

[мы́ться, умыва́ться, вытира́ться, бри́ться, причёсываться, одева́ться, раздева́ться, обува́ться, наряжа́ться, защища́ться, пря́таться]{.ru}

::: ex
[Ми́ша **мо́ется**.]{.ru} — [Ма́ма **мо́ет** Ми́шу.]{.ru}

[米沙在洗澡。——妈妈在给米沙洗澡。]{.gloss}

[Оте́ц **бре́ется** ка́ждое у́тро.]{.ru}

[父亲每天早上刮脸。]{.gloss}
:::

**2. 相互意义：互相。** 两个或几个人互相对对方做某事，这叫[相互意义]{.term}（[взаи́мное значе́ние]{.ru}）。主语是复数，或者用 [кто с кем]{.ru} 表示参与的双方：

[встреча́ться, ви́деться, знако́миться, здоро́ваться, проща́ться, целова́ться, обнима́ться, ссо́риться, мири́ться, перепи́сываться, сове́товаться, догова́риваться, расстава́ться]{.ru}

::: ex
[Мы с Ди́мой **ви́димся** ка́ждый день.]{.ru}

[我和季马每天见面。]{.gloss}

[Ста́рые друзья́ **обняли́сь**.]{.ru}

[老朋友们拥抱在一起。]{.gloss}
:::

与不带 [-ся]{.ru} 的动词对比：[Я встре́тил Ди́му в метро́]{.ru}（我在地铁里碰见了季马，单方面的）/ [Я встре́тился с Ди́мой в кафе́]{.ru}（我和季马在咖啡馆见了面，双方约好的）。大多数动词没有表相互意义的 [-ся]{.ru} 形式，要用 [друг дру́га]{.ru}（[Они́ лю́бят друг дру́га]{.ru}），分工见 §5.1.5。

**3. 【补】为自己做。** 主语为了自己的利益做某事，动作的对象是主语的东西，不说出来：[собира́ться]{.ru .ix}（收拾自己的东西，准备动身），[стро́иться]{.ru}（给自己盖房子），[укла́дываться]{.ru}（收拾行装），[запаса́ться]{.ru}（给自己储备），[устра́иваться]{.ru}（安顿下来）。

::: ex
[Подожди́, я ещё **собира́юсь**.]{.ru}

[等一下，我还在收拾东西。]{.gloss}

[Сосе́ди **стро́ятся**: у них бу́дет но́вый дом.]{.ru}

[邻居在盖房子：他们要有新房子了。]{.gloss}
:::

[собира́ться]{.ru} 加不定式表示“打算”，见 §7.7.1。

**4. 心理活动和状态。** 不带 [-ся]{.ru} 的动词表示“使某人产生某种感情”，[-ся]{.ru} 动词表示主语自己产生这种感情：[ра́довать — ра́доваться]{.ru}（使高兴——高兴），[волнова́ть — волнова́ться]{.ru}，[удивля́ть — удивля́ться]{.ru}，[серди́ть — серди́ться]{.ru}，[беспоко́ить — беспоко́иться]{.ru}，[интересова́ть — интересова́ться]{.ru}，[обижа́ть — обижа́ться]{.ru}，[огорча́ть — огорча́ться]{.ru}，[увлека́ть — увлека́ться]{.ru}。原来的主语（引起感情的事物）在 [-ся]{.ru} 动词句里变成间接补语，格由动词决定：

| 不带 [-ся]{.ru} | 带 [-ся]{.ru} |
|---|---|
| [Пода́рок ра́дует Ми́шу.]{.ru} 礼物使米沙高兴。 | [Ми́ша ра́дуется пода́рку.]{.ru} 米沙为礼物高兴。（第三格） |
| [Его́ поведе́ние удивля́ет нас.]{.ru} | [Мы удивля́емся его́ поведе́нию.]{.ru}（第三格） |
| [Меня́ интересу́ет му́зыка.]{.ru} | [Я интересу́юсь му́зыкой.]{.ru}（第五格） |
| [Его́ слова́ оби́дели меня́.]{.ru} | [Я оби́делся на его́ слова́.]{.ru}（[на]{.ru} 加第四格） |
| [Э́то волну́ет ма́му.]{.ru} | [Ма́ма волну́ется за сы́на.]{.ru}（[за]{.ru} 加第四格） |

同类的还有表示位置和运动状态变化的 [-ся]{.ru} 动词：[верну́ться, останови́ться, подня́ться, опусти́ться, поверну́ться, дви́гаться]{.ru}。

**5. 自发意义：事物自己发生变化。** 及物动词说“人使事物变化”，加 [-ся]{.ru} 后说“事物自己变化”，主语多是事物，不说施事：

[начина́ться, конча́ться, открыва́ться, закрыва́ться, измени́ться, улу́чшиться, разби́ться, слома́ться, порва́ться, зажига́ться]{.ru}

::: ex
[Учи́тель **начина́ет** уро́к.]{.ru} — [Уро́к **начина́ется** в де́вять.]{.ru}

[老师开始上课。——课九点开始。]{.gloss}

[Ча́шка упа́ла и **разби́лась**.]{.ru}

[杯子掉下去摔碎了。]{.gloss}

[Ве́тер **откры́л** окно́.]{.ru} — [Окно́ **откры́лось**.]{.ru}

[风把窗户吹开了。——窗户开了。]{.gloss}
:::

汉语“门开了”“杯子碎了”“课开始了”用的就是“开”“碎”“开始”，动词不变；俄语必须用 [-ся]{.ru} 形式，否则 [Дверь откры́ла…]{.ru} 就成了“门打开了（什么东西）”。

**6. 【补】经常的特性。** 未完成体现在时的 [-ся]{.ru} 动词不带补语，表示人或动物惯有的、一般是令人不快的特性：[Соба́ка куса́ется]{.ru}（这条狗咬人），[Ко́шка цара́пается]{.ru}（猫抓人），[Коро́ва бода́ется]{.ru}（牛顶人），[Крапи́ва жжётся]{.ru}（荨麻蜇人），[Ма́льчик дерётся]{.ru}（男孩爱打架），[Он руга́ется]{.ru}（他爱骂人）。这里 [-ся]{.ru} 不表示“对自己”，而是表示动作不针对某个具体对象，只说主语有这种习性。比较：[Соба́ка укуси́ла Ми́шу]{.ru}（狗咬了米沙，一次具体的动作）。

与此相近的是事物的被动特性：[Стекло́ легко́ бьётся]{.ru}（玻璃容易碎），[Э́та ткань хорошо́ стира́ется]{.ru}（这种布好洗），[Кни́га чита́ется легко́]{.ru}（这本书读起来轻松）。这类句子总带 [легко́, хорошо́, пло́хо, с трудо́м]{.ru} 一类状语，说的是事物的性质，见 §7.5.4。

**判断 [-ся]{.ru} 动词在句中的意义。** 可以依次看：

| 看什么 | 结果 | 意义 |
|---|---|---|
| 词典里有没有不带 [-ся]{.ru} 的动词 | 没有（[боя́ться]{.ru}）或意义差得远（[находи́ться]{.ru}） | 整个当作一个词，不分析 |
| 主语是人，动作是对身体做的 | [Он одева́ется]{.ru} | 反身 |
| 主语是复数或有 [с кем]{.ru} | [Мы встре́тились]{.ru}，[Я встре́тился с ним]{.ru} | 相互 |
| 主语是人，动词表示感情 | [Ми́ша ра́дуется]{.ru} | 心理状态 |
| 主语是事物，没有施事 | [Дверь откры́лась]{.ru}（完成体），[Магази́н открыва́ется в де́вять]{.ru} | 自发 |
| 主语是事物，未完成体，有第五格施事或明显有人做 | [Дом стро́ится рабо́чими]{.ru}，[Здесь продаю́тся биле́ты]{.ru} | 被动（§7.5.4） |
| 没有主语，主体是第三格 | [Мне не спи́тся]{.ru} | 无人称（§7.5.5） |

**[-ся]{.ru} 动词能带哪些补语。** [-ся]{.ru} 动词都不带第四格，但可以带别的补语：[встре́титься с кем]{.ru}，[ра́доваться чему́]{.ru}，[боя́ться чего́]{.ru}，[занима́ться чем]{.ru}，[учи́ться чему́]{.ru}，[наде́яться на что]{.ru}，[собира́ться]{.ru} 加不定式。补语的格往往和不带 [-ся]{.ru} 的动词不同，要一起记（附录五）。

### 常见错误

::: err
\*[Уро́к начина́ет в де́вять.]{.ru}　→　[Уро́к **начина́ется** в де́вять.]{.ru}

主语是事物、自己开始，用 [-ся]{.ru} 动词。[начина́ть]{.ru} 要有人开始某件事：[Учи́тель начина́ет уро́к]{.ru}。
:::

::: err
\*[Мы встре́тили в кафе́.]{.ru}（想说“我们在咖啡馆见了面”）　→　[Мы **встре́тились** в кафе́.]{.ru}

相互意义用 [-ся]{.ru} 动词；[встре́тить]{.ru} 必须带第四格补语。
:::

::: err
\*[Я интересу́юсь о му́зыке.]{.ru}　→　[Я интересу́юсь **му́зыкой**.]{.ru}

[интересова́ться]{.ru} 要求第五格，不按汉语“对……感兴趣”加前置词。
:::

::: err
\*[Я ра́дуюсь твой пода́рок.]{.ru}　→　[Я ра́дуюсь **твоему́ пода́рку**.]{.ru}

[-ся]{.ru} 动词不带第四格；[ра́доваться]{.ru} 要求第三格。
:::

::: err
\*[Э́та соба́ка куса́ет.]{.ru}（想说“这条狗咬人”）　→　[Э́та соба́ка **куса́ется**.]{.ru}

说动物的习性，不指具体对象，用 [-ся]{.ru} 动词。[куса́ть]{.ru} 要带补语：[Соба́ка куса́ет кость]{.ru}（狗在啃骨头）。
:::

## §7.5.4 被动结构

### 形式

[被动结构]{.term}（[пасси́вная констру́кция]{.ru}）以动作的承受者为主语，动词用被动形式，[施事]{.term}（[производи́тель де́йствия]{.ru}）用第五格（§3.7.3）或不说出来。被动形式按体分为两种：

| | 未完成体：加 [-ся]{.ru} | 完成体：被动形动词短尾 |
|---|---|---|
| 意义 | 动作在进行或反复发生 | 动作已经完成，结果存在 |
| 现在 | [Дом стро́ится.]{.ru} 房子在建。 | [Дом постро́ен.]{.ru} 房子建好了。 |
| 过去 | [Дом стро́ился два го́да.]{.ru} 房子建了两年。 | [Дом был постро́ен в 1990 году́.]{.ru} 房子是一九九〇年建成的。 |
| 将来 | [Дом бу́дет стро́иться два го́да.]{.ru} | [Дом бу́дет постро́ен к ле́ту.]{.ru} |
| 施事 | [Дом стро́ится рабо́чими.]{.ru} | [Дом постро́ен рабо́чими.]{.ru} |

1. **未完成体加 [-ся]{.ru}。** 由未完成体及物动词构成，主要用第三人称：[стро́ится, стро́ятся, стро́ился]{.ru}。
2. **完成体被动形动词短尾。** 由完成体及物动词构成：[постро́ен, постро́ена, постро́ено, постро́ены]{.ru}，与主语的性、数一致；现在时不用系词，过去时、将来时加 [быть]{.ru} 的过去时、将来时（[был постро́ен, бу́дет постро́ен]{.ru}）。构成见 §7.8.5，短尾的形式和重音见 §7.8.6。
3. **未完成体被动形动词现在时。** [чита́емый, люби́мый, уважа́емый]{.ru} 主要作定语（§7.8.4）；短尾作谓语是书面语，用于少数动词：[Он люби́м все́ми]{.ru}（大家都爱他）。

完成体动词加 [-ся]{.ru} 一般不表示被动，而表示自发或反身：[Дверь откры́лась]{.ru}（门开了，自己开的），[Дом постро́ился]{.ru} 不说。所以“完成了的被动”只能用短尾形动词。

### 意义和用法

**怎样由主动句变成被动句。**

1. 主动句的直接补语（第四格）变成主语（第一格）；
2. 主动句的主语变成第五格，或者省去；
3. 未完成体动词加 [-ся]{.ru}，完成体动词换成被动形动词短尾，与新的主语一致。

::: ex
[Студе́нты **реша́ют** зада́чу.]{.ru} → [Зада́ча **реша́ется** студе́нтами.]{.ru}

[学生们在解题。→ 题正由学生们解答。]{.gloss}

[Студе́нты **реши́ли** зада́чу.]{.ru} → [Зада́ча **решена́** студе́нтами.]{.ru}

[学生们把题解出来了。→ 题已被学生们解出来了。]{.gloss}
:::

**[стро́ится]{.ru} 与 [постро́ен]{.ru}。** 两种被动形式的区别就是体的区别：[стро́ится]{.ru} 说的是建造的过程或反复（[В го́роде стро́ится но́вая шко́ла]{.ru} 城里在建一所新学校；[Таки́е дома́ стро́ятся за год]{.ru} 这样的房子一年就能建成），[постро́ен]{.ru} 说的是结果（[Шко́ла уже́ постро́ена]{.ru} 学校已经建好了）。[Музе́й стро́ился в 1950 году́]{.ru} 只是说那一年在建，没说建成；说“是哪年建成的”要用 [Музе́й был постро́ен в 1950 году́]{.ru}。

**短尾的时间。** 短尾被动形动词表示的是动作完成后留下的状态，所以现在时的 [Дверь откры́та]{.ru} 是“门开着”，[Магази́н закры́т]{.ru} 是“商店关着门”，相当于汉语的“着”；过去时 [Дверь была́ откры́та]{.ru} 是“门那时开着”；用作叙述一件事时，[был постро́ен]{.ru} 说的是“建成”这个事件。

**施事说不说。** 被动句多数不说施事，因为施事不明、不重要或不言而喻：[Э́то сло́во пи́шется че́рез «о»]{.ru}，[Биле́ты продаю́тся в ка́ссе]{.ru}，[Магази́н закры́т на ремо́нт]{.ru}。说出施事时用不带前置词的第五格：[Рома́н напи́сан Толсты́м]{.ru}，[Зако́н при́нят парла́ментом]{.ru}。施事是人、用 [-ся]{.ru} 被动的句子（[Зада́ча реша́ется студе́нтами]{.ru}）只见于书面语、公文和科学语体；口语里有人做的动作不用 [-ся]{.ru} 被动，改用主动句或不定人称句。

**【补】[-ся]{.ru} 被动的人称限制。** 用 [-ся]{.ru} 表示被动的句子，主语一般是事物，动词用第三人称。主语是人时，[-ся]{.ru} 动词会被理解成反身或相互意义：[Де́ти мо́ются]{.ru} 是“孩子们在洗澡”，不是“孩子们被洗”。所以第一、第二人称指人时不用 [-ся]{.ru} 被动：不说 [*Я приглаша́юсь на конфере́нцию]{.ru}，要说 [Меня́ приглаша́ют на конфере́нцию]{.ru}（不定人称句），或用短尾 [Я приглашён на конфере́нцию]{.ru}。公文里第三人称指人可以用：[Студе́нты допуска́ются к экза́мену по́сле сда́чи зачётов]{.ru}（学生通过考查后方可参加考试）。

**主动句、不定人称句、被动句。** 同一件事有三种说法，各有语体分工：

| 句式 | 例 | 用于 |
|---|---|---|
| 主动句 | [Архите́кторы постро́или э́то зда́ние в 1953 году́.]{.ru} | 施事是话题或新信息 |
| [不定人称句]{.term}（[неопределённо-ли́чное предложе́ние]{.ru}） | [Э́то зда́ние постро́или в 1953 году́.]{.ru} | 口语中最常用：施事不明或不重要 |
| 被动句 | [Э́то зда́ние бы́ло постро́ено в 1953 году́.]{.ru} | 书面语、新闻、公文、科学语体 |

不定人称句的谓语用复数第三人称或过去时复数，不说主语，见 §12.4.2。口语里不说 [Кни́га была́ про́дана мной]{.ru}，而说 [Я прода́л кни́гу]{.ru}；不说 [Мне бы́ло сообщено́…]{.ru}，而说 [Мне сказа́ли…]{.ru}。书面语里被动句便于把承受者放在句首作话题（§12.6.1），公文、科学语体多用被动结构（§15.1.3、§15.1.4）。

**俄汉差异。** 汉语的“被”字句多用于不如意的事（“被雨淋了”“被偷了”），中性的被动常不用“被”，而是让承受者直接作主语（“房子建好了”“信写完了”）或用“是……的”（“这本书是托尔斯泰写的”）。俄语的被动结构没有不如意的色彩，汉语这些意念上的被动句译成俄语，口语多用不定人称句，书面语用被动结构：“信写完了”[Письмо́ напи́сано]{.ru}；“票卖完了”[Биле́ты распро́даны]{.ru}；“这本书是托尔斯泰写的”[Э́та кни́га напи́сана Толсты́м]{.ru}。汉语“被”“由”后面的施事，俄语用不带前置词的第五格。

::: ex
[Ря́дом с па́рком **стро́ится** спорти́вный центр.]{.ru}

[公园旁边正在建一个体育中心。]{.gloss}

[Как **пи́шется** ва́ше и́мя?]{.ru}

[您的名字怎么写？]{.gloss}

[Э́тот расска́з **напи́сан** Че́ховым.]{.ru}

[这篇小说是契诃夫写的。]{.gloss}

[Галере́я **была́ осно́вана** в 1856 году́.]{.ru}

[画廊建于一八五六年。]{.gloss}

[Рабо́та **бу́дет зако́нчена** к пя́тнице.]{.ru}

[工作将在星期五以前完成。]{.gloss}

[Окно́ **откры́то**, закро́й его́, пожа́луйста.]{.ru}

[窗户开着，请把它关上。]{.gloss}
:::

### 常见错误

::: err
\*[Зда́ние бы́ло постро́ен.]{.ru}　→　[Зда́ние бы́ло **постро́ено**.]{.ru}

短尾被动形动词与主语的性、数一致，[зда́ние]{.ru} 是中性。
:::

::: err
\*[Рома́н напи́сан от Толсто́го.]{.ru}　→　[Рома́н напи́сан **Толсты́м**.]{.ru}

施事用不带前置词的第五格，不按汉语“由”“被”加前置词。
:::

::: err
\*[Э́тот музе́й стро́ился в 1950 году́.]{.ru}（想说“这座博物馆是一九五〇年建成的”）　→　[Э́тот музе́й **был постро́ен** в 1950 году́.]{.ru}

说建成的事件，用完成体短尾；[стро́ился]{.ru} 只说那时在建。
:::

::: err
\*[Э́тот дом постро́ился в про́шлом году́.]{.ru}　→　[Э́тот дом **постро́или** / **был постро́ен** в про́шлом году́.]{.ru}

完成体加 [-ся]{.ru} 一般不表示被动。
:::

::: err
\*[Я приглаша́юсь на сва́дьбу.]{.ru}　→　[**Меня́ приглаша́ют** на сва́дьбу.]{.ru} / [**Я приглашён** на сва́дьбу.]{.ru}

指人的第一、二人称不用 [-ся]{.ru} 被动。
:::

## §7.5.5 无人称的 [-ся]{.ru} 动词

### 形式

有些 [-ся]{.ru} 动词用于没有主语的无人称句（§12.4.4），感受状态的人用第三格。动词只用单数第三人称和过去时中性，将来时用单数第三人称：

::: paradigm
| 时 | [хоте́ться]{.ru} | [спа́ться]{.ru} | [рабо́таться]{.ru} |
|---|---|---|---|
| 现在时 | [мне хо́чется]{.ru} | [мне не спи́тся]{.ru} | [мне не рабо́тается]{.ru} |
| 过去时 | [мне хоте́лось]{.ru} | [мне не спа́лось]{.ru} | [мне не рабо́талось]{.ru} |
| 将来时 | [мне захо́чется]{.ru} | [мне не бу́дет спа́ться]{.ru} | [мне не бу́дет рабо́таться]{.ru} |
| 假定式 | [мне хоте́лось бы]{.ru} | [мне не спа́лось бы]{.ru} | [мне не рабо́талось бы]{.ru} |
:::

这类动词分两种：

1. **只用于无人称的 [-ся]{.ru} 动词。** [хо́чется]{.ru .ix key="хоте́ться"}（想）、[нездоро́вится]{.ru .ix key="нездоро́виться"}（不舒服）、[смерка́ется]{.ru}（天黑下来）；[ка́жется]{.ru}、[ду́мается]{.ru}、[по́мнится]{.ru}、[ве́рится]{.ru} 在“觉得、想来、记得、相信”的意义上只用无人称形式；[прихо́дится, удаётся]{.ru} 也属此类。它们的意义和用法见 §7.7.2。
2. **【补】由人称动词加 [-ся]{.ru} 构成的无人称用法。** 不及物的人称动词（[спать, сиде́ть, рабо́тать, жить, чита́ть, писа́ть, ду́мать, е́хать]{.ru} 等）加 [-ся]{.ru}，用于无人称句，主体用第三格：[Мне не спи́тся]{.ru .ix key="спа́ться"}（我睡不着），[Ему́ не сиди́тся]{.ru .ix key="сиде́ться"}（他坐不住），[Сего́дня мне не рабо́тается]{.ru}（我今天干不下活儿去），[Хорошо́ рабо́тается]{.ru}（干活儿很顺手），[Как вам живётся?]{.ru}（您过得怎么样？）。这是一种能产的格式，几乎所有表示活动的不及物动词都可以这样用。

### 意义和用法

**不由自主的状态。** 无人称的 [-ся]{.ru} 动词把动作说成不由人的意志决定的事：主体不是动作的发出者，而是感受者，用第三格，动作好像自己发生或不发生。比较：

| 人称句 | 无人称句 |
|---|---|
| [Я не сплю.]{.ru} 我没睡（醒着，也许是自己不想睡）。 | [Мне не спи́тся.]{.ru} 我睡不着（想睡，可就是睡不着）。 |
| [Я не рабо́таю.]{.ru} 我不工作，我没在干活。 | [Мне не рабо́тается.]{.ru} 我（想干活，可）干不进去。 |
| [Он не сиди́т на ме́сте.]{.ru} 他不在座位上坐着。 | [Ему́ не сиди́тся на ме́сте.]{.ru} 他坐不住。 |
| [Я хочу́ пить.]{.ru} 我要喝水（有意识的愿望）。 | [Мне хо́чется пить.]{.ru} 我想喝水（身体的感觉），见 §7.7.2。 |

**多带否定或评价词。** 人称动词构成的无人称用法多带否定（[не спи́тся, не сиди́тся, не чита́ется, не пи́шется]{.ru}），表示想做而做不成，或者没有心思做；不带否定时常带 [хорошо́, легко́, споко́йно, ве́село]{.ru} 一类评价词，表示做起来顺利、舒服：[Здесь легко́ ды́шится]{.ru}（这里呼吸很畅快），[Как вам спа́лось?]{.ru}（您睡得好吗？）。不带否定也不带评价词的 [*Мне рабо́тается]{.ru} 不说。

**句子成分。** 无人称的 [-ся]{.ru} 动词不能有第一格主语，不能加 [оно́]{.ru}；主体用第三格，可以省去（[Не спи́тся]{.ru}）；地点、时间、原因状语照常：[Но́чью в по́езде мне не спа́лось]{.ru}。这些动词不带直接补语，[хоте́ться]{.ru} 的补语用第二格或不定式（[Мне хо́чется ча́ю]{.ru}，[Мне хо́чется спать]{.ru}）。

**俄汉差异。** 汉语用可能补语表示同样的意思：“睡不着”“坐不住”“写不出来”“看不进去”，主语仍是人；俄语把人放在第三格，动词用无人称的 [-ся]{.ru} 形式。反过来，“我睡得很好”在俄语里可以是人称句 [Я хорошо́ спал]{.ru}，也可以是 [Мне хорошо́ спа́лось]{.ru}，后者更强调感受。

::: ex
[Всю ночь **мне не спа́лось**: я ду́мал об экза́мене.]{.ru}

[我一夜睡不着，一直在想考试的事。]{.gloss}

[Де́тям **не сиди́тся** до́ма, они́ хотя́т на у́лицу.]{.ru}

[孩子们在家里待不住，想到外面去。]{.gloss}

[Сего́дня **мне** что́-то **не чита́ется**.]{.ru}

[今天我不知怎么看不进书去。]{.gloss}

[В дере́вне **рабо́тается** хорошо́, никто́ не меша́ет.]{.ru}

[在乡下干活儿很顺手，没人打扰。]{.gloss}

[**Мне не ве́рится**, что ле́то уже́ ко́нчилось.]{.ru}

[我真不敢相信夏天已经过去了。]{.gloss}
:::

### 常见错误

::: err
\*[Я не спи́тся.]{.ru}　→　[**Мне** не спи́тся.]{.ru}

无人称句的主体用第三格，不能用第一格。
:::

::: err
\*[Мне не спа́лась всю ночь.]{.ru}　→　[Мне не **спа́лось** всю ночь.]{.ru}

无人称句的过去时一律用中性。
:::

::: err
\*[Сего́дня я не рабо́таю: голова́ боли́т.]{.ru}（想说“我今天干不进去活儿”）　→　[Сего́дня **мне не рабо́тается**: голова́ боли́т.]{.ru}

[я не рабо́таю]{.ru} 是“我不上班、我没干活”，说的是事实；想干却干不下去用无人称形式。
:::
