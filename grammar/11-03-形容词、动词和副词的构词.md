形容词主要用后缀法和合成法构成，动词主要用前缀法，副词主要用后缀法和前缀后缀法（构词方式见 §11.1.2）。本章 §11.3.1、§11.3.2 讲形容词的后缀、复合形容词和带前缀的形容词；§11.3.3、§11.3.4 讲动词的前缀和后缀；§11.3.5 讲副词的构词；§11.3.6 讲作家按构词规则造出的新词和罕见的派生词，以及读书时怎样分析它们。形容词的类别见 §4.1.1，动词前缀与体的关系见 §7.3.3–§7.3.5，带前缀的运动动词见 §7.6.6。

## §11.3.1 形容词的后缀

### 形式

形容词大多由名词、动词或副词加后缀构成。常用的后缀：

| 后缀 | 生产词 | 意义 | 例 |
|---|---|---|---|
| [-н-]{.ru .ix}（[-ен-]{.ru}） | 名词 | 与某物有关；时间、地点；材料 | [кни́га → кни́жный]{.ru}，[лес → лесно́й]{.ru}，[ночь → ночно́й]{.ru}，[рука́ → ручно́й]{.ru}，[молоко́ → моло́чный]{.ru}，[лицо́ → ли́чный]{.ru}，[со́лнце → со́лнечный]{.ru}，[желе́зо → желе́зный]{.ru}，[война́ → вое́нный]{.ru} |
| 软的 [-н-]{.ru}（[-ний]{.ru}） | 名词、副词 | 时间、地点 | [ле́то → ле́тний]{.ru}，[зима́ → зи́мний]{.ru}，[весна́ → весе́нний]{.ru}，[о́сень → осе́нний]{.ru}，[у́тро → у́тренний]{.ru}，[ве́чер → вече́рний]{.ru}，[сосе́д → сосе́дний]{.ru} |
| [-шн-]{.ru .ix}（[-шний]{.ru}） | 副词 | 时间、地点 | [сего́дня → сего́дняшний]{.ru}，[вчера́ → вчера́шний]{.ru}，[за́втра → за́втрашний]{.ru}，[до́ма → дома́шний]{.ru}，[здесь → зде́шний]{.ru}，[тогда́ → тогда́шний]{.ru}，[ны́не → ны́нешний]{.ru}，[пре́жде → пре́жний]{.ru} |
| [-ан-, -ян-]{.ru}；[-анн-, -янн-]{.ru} | 名词 | 材料 | [ко́жа → ко́жаный]{.ru}；[де́рево → деревя́нный]{.ru}，[стекло́ → стекля́нный]{.ru}，[о́лово → оловя́нный]{.ru} |
| [-енн-]{.ru} | 名词 | 与某物有关 | [клю́ква → клю́квенный]{.ru}，[госуда́рство → госуда́рственный]{.ru}，[родство́ → ро́дственный]{.ru} |
| [-ск-]{.ru .ix}（[-еск-, -ическ-]{.ru}） | 名词（人、地名、机构） | 属于某人、某地、某民族；具有某人特点 | [Москва́ → моско́вский]{.ru}，[го́род → городско́й]{.ru}，[муж → мужско́й]{.ru}，[де́ти → де́тский]{.ru}，[друг → дру́жеский]{.ru}，[челове́к → челове́ческий]{.ru}，[исто́рия → истори́ческий]{.ru}，[Пу́шкин → пу́шкинский]{.ru} |
| [-ов-, -ев-]{.ru .ix} | 名词 | 材料；属于某物；植物、果实、颜色 | [берёза → берёзовый]{.ru}，[де́ло → делово́й]{.ru}，[ключ → ключево́й]{.ru}，[речь → речево́й]{.ru}，[бана́н → бана́новый]{.ru}，[фру́кты → фрукто́вый]{.ru}，[ро́за → ро́зовый]{.ru}，[сире́нь → сире́невый]{.ru}，[рубль → рублёвый]{.ru} |
| [-ин-]{.ru .ix} | 动物名称 | 属于某种动物 | [лебеди́ный, орли́ный, соловьи́ный, муравьи́ный, гуси́ный, голуби́ный]{.ru} |
| [-лив-]{.ru .ix}（[-чив-]{.ru}） | 名词、动词 | 经常具有的特点、倾向 | [молча́ть → молчали́вый]{.ru}，[терпе́ть → терпели́вый]{.ru}，[дождь → дождли́вый]{.ru}，[сча́стье → счастли́вый]{.ru}，[пуга́ть → пугли́вый]{.ru}，[шути́ть → шутли́вый]{.ru}，[забо́та → забо́тливый]{.ru}；[разгово́р → разгово́рчивый]{.ru}，[дове́рие → дове́рчивый]{.ru}，[оби́да → оби́дчивый]{.ru} |
| [-ист-]{.ru .ix} | 名词 | 多有某物；像某物 | [ка́мень → камени́стый]{.ru}，[тень → тени́стый]{.ru}，[пух → пуши́стый]{.ru}，[волна́ → волни́стый]{.ru}，[серебро́ → серебри́стый]{.ru}，[зо́лото → золоти́стый]{.ru}，[го́лос → голоси́стый]{.ru}，[плечо́ → плечи́стый]{.ru} |
| [-ат-]{.ru .ix} | 名词（身体部位等） | 有显著的某物 | [борода́ → борода́тый]{.ru}，[усы́ → уса́тый]{.ru}，[рог → рога́тый]{.ru}，[крыло́ → крыла́тый]{.ru}，[полоса́ → полоса́тый]{.ru} |
| [-тельн-]{.ru .ix}；[-льн-]{.ru} | 动词 | 能做某事的；用来做某事的 | [замеча́ть → замеча́тельный]{.ru}，[внима́ние → внима́тельный]{.ru}，[удиви́ть → удиви́тельный]{.ru}，[наблюда́ть → наблюда́тельный]{.ru}，[увлека́ть → увлека́тельный]{.ru}；[чита́ть → чита́льный]{.ru}（[зал]{.ru}），[спать → спа́льный]{.ru}，[стира́ть → стира́льный]{.ru} |
| [-ова́т-, -ева́т-]{.ru .ix} | 形容词 | 程度弱：有点儿 | [бе́лый → белова́тый]{.ru}，[си́ний → синева́тый]{.ru}，[се́рый → серова́тый]{.ru}，[ки́слый → кислова́тый]{.ru}，[гру́бый → грубова́тый]{.ru}，[глу́пый → глупова́тый]{.ru}，[ры́жий → рыжева́тый]{.ru} |
| [-еньк-, -оньк-]{.ru .ix} | 形容词 | 表爱；程度 | [бе́лый → бе́ленький]{.ru}，[хоро́ший → хоро́шенький]{.ru}，[но́вый → но́венький]{.ru}，[тёплый → тёпленький]{.ru}，[све́жий → све́женький]{.ru}，[ми́лый → ми́ленький]{.ru}，[кре́пкий → кре́пенький]{.ru}；[лёгкий → лёгонький]{.ru} |
| [-ёхоньк-, -ёшеньк-]{.ru} | 形容词 | 强调：十足地（民间、诗歌） | [бе́лый → белёхонький, белёшенький]{.ru}；[оди́н → одинёшенек]{.ru} |
| [-ущ-, -ющ-]{.ru}；[-енн-]{.ru} | 形容词 | 强调：极大、极（口语） | [большо́й → большу́щий]{.ru}，[то́лстый → толсту́щий]{.ru}，[злой → злю́щий]{.ru}，[дли́нный → длинню́щий]{.ru}；[широ́кий → широче́нный]{.ru}，[высо́кий → высоче́нный]{.ru}，[здоро́вый → здорове́нный]{.ru} |

物主形容词的后缀 [-ин, -ов]{.ru}（[ма́мин, отцо́в]{.ru}）和 [-ий]{.ru}（[во́лчий, ры́бий]{.ru}）见 §4.1.4。

### 意义和用法

**关系形容词和性质形容词。** 按意义，形容词分为[性质形容词]{.term}（[ка́чественное прилага́тельное]{.ru}）和[关系形容词]{.term}（[относи́тельное прилага́тельное]{.ru}），区分标准和语法差别见 §4.1.1。两类形容词的后缀大体不同：[-н-, -ск-, -ов-, -ин-, -ан-]{.ru} 构成的多是关系形容词，相当于“名词第二格”或“前置词加名词”（[деревя́нный стол = стол из де́рева]{.ru}，[моско́вские у́лицы = у́лицы Москвы́]{.ru}），没有比较级和短尾；[-лив-, -чив-, -ист-, -ат-, -тельн-, -оват-]{.ru} 构成的多是性质形容词，有比较级、短尾，能构成 [-о]{.ru} 副词（[терпели́вее, терпели́в, терпели́во]{.ru}）。

关系形容词用于转义时常变成性质形容词：[золото́е кольцо́]{.ru}（金戒指，关系）— [золоты́е ру́ки]{.ru}（巧手，性质）；[желе́зная дверь]{.ru}（铁门）— [желе́зная во́ля]{.ru}（钢铁意志，可以说 [о́чень желе́зная]{.ru}）；[делово́е письмо́]{.ru}（公函）— [о́чень делово́й челове́к]{.ru}（很干练的人）。

**[-н-]{.ru}：最常用的后缀。** [-н-]{.ru} 前常有辅音交替：[г → ж]{.ru}（[кни́жный]{.ru}），[к → ч]{.ru}（[ручно́й, моло́чный]{.ru}），[ц → ч]{.ru}（[ли́чный, со́лнечный]{.ru}），[х → ш]{.ru}（[смешно́й]{.ru}，见 §11.1.3）。表示时间、地点的形容词多用软的 [-н-]{.ru}，按软变化变（[ле́тний, зи́мний, у́тренний, вече́рний, сосе́дний, ни́жний, ве́рхний, вну́тренний, пере́дний, за́дний, да́льний]{.ru}，变格见 §4.1.2）；由时间、地点副词构成的用 [-шний]{.ru}：[сего́дняшний, вчера́шний, за́втрашний, дома́шний, зде́шний, ны́нешний]{.ru}。所以软变化的形容词大都和时间、地点有关，记住这一点，遇到 [-ний]{.ru} 形容词就不会按硬变化去变。

表示材料用 [-ян-, -ан-]{.ru}，写法有一个 [н]{.ru} 和两个 [н]{.ru} 之分：[ко́жаный, песча́ный, гли́няный]{.ru} 一个 [н]{.ru}；[деревя́нный, стекля́нный, оловя́нный]{.ru} 两个 [н]{.ru}（[-н- / -нн-]{.ru} 的写法见 §1.4.5）。

**[-ск-]{.ru} 和它的变体。** [-ск-]{.ru} 表示属于人、地方、民族、机构：[моско́вский, городско́й, де́тский, студе́нческий]{.ru}。词尾重读写 [-ско́й]{.ru}（[городско́й, мужско́й, морско́й]{.ru}），不重读写 [-ский]{.ru}。[-еск-]{.ru} 前 [г, к]{.ru} 变 [ж, ч]{.ru}（[дру́жеский, челове́ческий]{.ru}）；[-ическ-]{.ru} 用于外来词根（[истори́ческий, хими́ческий, экономи́ческий]{.ru}）。词干末的 [к, ч, ц]{.ru} 与 [ск]{.ru} 合成 [цк]{.ru}：[не́мец → неме́цкий, ткач → тка́цкий, рыба́к → рыба́цкий]{.ru}；[з, с]{.ru} 保留：[францу́з → францу́зский, Оде́сса → оде́сский, Кавка́з → кавка́зский]{.ru}；[г]{.ru} 变 [ж]{.ru}：[Пра́га → пра́жский, Ри́га → ри́жский]{.ru}（写法见 §1.4.5）。由 [-ск-]{.ru} 形容词可构成 [по-…-ски]{.ru} 副词（§11.3.5）。

**[-ов- / -ев-]{.ru}。** 硬辅音后写 [-ов-]{.ru}，软辅音和 [ж, ш, ч, щ, ц]{.ru} 后，后缀不重读写 [-ев-]{.ru}（[си́тцевый, гру́шевый, ключево́й, речево́й, полево́й]{.ru}），重读写 [-о́в-]{.ru}（[ж, ш, ч, щ, ц]{.ru} 后：[ежо́вый, холщо́вый, свинцо́вый]{.ru}）或 [-ёв-]{.ru}（软辅音后：[рублёвый]{.ru}）。[ключево́й]{.ru} 的重音在词尾上，后缀本身不重读，所以写 [е]{.ru}。

**[-лив-]{.ru}、[-ист-]{.ru}、[-ат-]{.ru}。** 三个后缀都构成性质形容词，表示人或事物的特征。[-лив-]{.ru}（[-чив-]{.ru}）表示经常有某种倾向，一般重读：[молчали́вый]{.ru}（沉默寡言的），[пугли́вый]{.ru}（胆小的）；[забо́тливый, засте́нчивый, разгово́рчивый, дове́рчивый]{.ru} 的后缀不重读。[-ист-]{.ru} 表示“多有某物”或“像某物”，总是重读：[камени́стый бе́рег]{.ru}（石头多的岸），[серебри́стый]{.ru}（银白色的），[пуши́стый снег]{.ru}（蓬松的雪）。[-ат-]{.ru} 表示“有显著的某物”：[борода́тый]{.ru}（大胡子的），[крыла́тый]{.ru}（有翅膀的），[полоса́тый]{.ru}（有条纹的）。

**[-ическ-]{.ru} 和 [-ичн-]{.ru}。** 一批外来词根同时有两个形容词，[-ическ-]{.ru} 是关系形容词，[-ичн-]{.ru} 是性质形容词：

| [-ическ-]{.ru}（关系） | [-ичн-]{.ru}（性质） |
|---|---|
| [экономи́ческий]{.ru .ix} 经济的：[экономи́ческий кри́зис]{.ru} | [экономи́чный]{.ru .ix} 节省的，省油的：[экономи́чный автомоби́ль]{.ru} |
| [практи́ческий]{.ru} 实践的，实用的：[практи́ческие заня́тия]{.ru} | [практи́чный]{.ru} 会过日子的，实惠的：[практи́чный челове́к]{.ru} |
| [дипломати́ческий]{.ru} 外交的：[дипломати́ческие отноше́ния]{.ru} | [дипломати́чный]{.ru} 圆滑的，有分寸的：[дипломати́чный отве́т]{.ru} |
| [логи́ческий]{.ru} 逻辑的：[логи́ческая оши́бка]{.ru} | [логи́чный]{.ru} 合乎逻辑的：[логи́чный вы́вод]{.ru} |
| [техни́ческий]{.ru} 技术的：[техни́ческий университе́т]{.ru} | [техни́чный]{.ru} 技术好的：[техни́чный футболи́ст]{.ru} |

同一个词根带不同后缀而意义不同的，还有 [дру́жеский]{.ru}（友好的：[дру́жеский разгово́р]{.ru}）— [дру́жный]{.ru}（和睦的，齐心的：[дру́жная семья́]{.ru}）；[ры́бный]{.ru}（作食物的鱼的：[ры́бный суп, ры́бный магази́н]{.ru}）— [ры́бий]{.ru}（鱼身上的：[ры́бий жир]{.ru}）。

**表示程度的后缀。** [-оват-]{.ru} 表示特征程度弱，“有点儿”，后缀总是重读：[белова́тый]{.ru}（发白的），[грубова́тый]{.ru}（有点粗鲁的）；短尾常用来表示“有点儿嫌……”：[Брю́ки мне великова́ты]{.ru}（裤子我穿有点大）。[-еньк-, -оньк-]{.ru} 不一定表示小，主要表示说话人的好感：[хоро́шенький]{.ru}（漂亮可爱的），[све́женький]{.ru}（新鲜的），[но́венький]{.ru}（崭新的）；[г, к, х]{.ru} 后用 [-оньк-]{.ru}（[лёгонький]{.ru}）。[ма́ленький]{.ru} 历史上也是这样构成的，今天已是普通的“小的”。[-ёхоньк-, -ёшеньк-]{.ru} 带民间色彩，表示“十足地”：[белёхонький]{.ru}（雪白雪白的），[одинёшенек]{.ru}（孤零零的，只用短尾）。[-ущ-]{.ru}、[-енн-]{.ru} 表示“极”，是口语：[большу́щий]{.ru}（老大老大的），[высоче́нный]{.ru}（高高的）。

**俄汉差异。** 汉语名词可以直接作定语：“木头桌子”“城市生活”“经济危机”，俄语要把名词换成形容词（[деревя́нный стол, городска́я жизнь, экономи́ческий кри́зис]{.ru}）或用名词第二格（[жизнь го́рода]{.ru}）。哪个名词有现成的关系形容词、用哪个后缀，要随词记。汉语“有点儿白”“白白的”“雪白”靠副词、重叠和复合表示程度，俄语靠后缀 [-оват-, -еньк-, -ёхоньк-]{.ru}。

关系形容词：

::: ex
[В на́шем до́ме есть **деревя́нная** ле́стница.]{.ru}

[我们家有一道木楼梯。]{.gloss}

[Ван Лэй купи́л **вчера́шнюю** газе́ту.]{.ru}

[王磊买了昨天的报纸。]{.gloss}

[Мы гуля́ли в **берёзовой** ро́ще.]{.ru}

[我们在白桦林里散步。]{.gloss}
:::

性质形容词：

::: ex
[Ива́н Серге́евич — челове́к **молчали́вый**, но **забо́тливый**.]{.ru}

[伊万·谢尔盖耶维奇话不多，却很体贴。]{.gloss}

[У ко́шки дли́нный **пуши́стый** хвост.]{.ru}

[猫有一条又长又蓬松的尾巴。]{.gloss}

[Э́то **замеча́тельная** кни́га.]{.ru}

[这是一本好极了的书。]{.gloss}
:::

[-ическ-]{.ru} 和 [-ичн-]{.ru}：

::: ex
[В стране́ начался́ **экономи́ческий** кри́зис.]{.ru}

[国家开始了经济危机。]{.gloss}

[Мы хоти́м купи́ть **экономи́чную** маши́ну.]{.ru}

[我们想买一辆省油的车。]{.gloss}
:::

表示程度：

::: ex
[Вода́ в о́зере была́ **синева́тая**.]{.ru}

[湖水有点发蓝。]{.gloss}

[Ми́ша пришёл в шко́лу в **но́веньком** костю́ме.]{.ru}

[米沙穿着崭新的西装来上学。]{.gloss}
:::

### 常见错误

::: err
\*[Мы купи́ли о́чень экономи́ческую маши́ну.]{.ru}　→　[Мы купи́ли о́чень **экономи́чную** маши́ну.]{.ru}

[экономи́ческий]{.ru} 是关系形容词“经济（方面）的”，不能加 [о́чень]{.ru}；“省钱、省油的”是性质形容词 [экономи́чный]{.ru}。
:::

::: err
\*[Он говори́т по-францу́ски, у него́ францу́ский па́спорт.]{.ru}　→　[Он говори́т **по-францу́зски**, у него́ **францу́зский** па́спорт.]{.ru}

词干末的 [з]{.ru} 在 [-ск-]{.ru} 前保留：[францу́з → францу́зский]{.ru}。读音里 [зс]{.ru} 合成一个 [[с]]{.tr}，写的时候不能丢。
:::

::: err
\*[Э́то ключово́й вопро́с.]{.ru}　→　[Э́то **ключево́й** вопро́с.]{.ru}

[ч]{.ru} 后的后缀 [-ев-]{.ru} 不重读时写 [е]{.ru}，重音在词尾 [-о́й]{.ru} 上，不在后缀上。
:::

## §11.3.2 复合形容词和带前缀的形容词

### 形式

复合形容词的主要类型：

| 类型 | 构成 | 写法 | 例 |
|---|---|---|---|
| 数词 + 名词 + 后缀 | 数词用第二格形式，不加连接元音；1 用 [одно-]{.ru}，2 用 [двух-]{.ru}（少数用 [дву-]{.ru}），40、90、100 用 [сорока-, девяносто-, сто-]{.ru} | 连写 | [двадцатиле́тний, девятнадцатиле́тний, пятиле́тний, сорокале́тний, девяностоле́тний, столе́тний, тысячеле́тний]{.ru}；[одноэта́жный, двухэта́жный, пятиэта́жный, многоэта́жный, одноко́мнатный, трёхко́мнатный]{.ru}；[двухчасово́й, пятимину́тный, трёхдне́вный]{.ru}；[двусторо́нний, двуязы́чный]{.ru} |

| 两个平等的形容词 | 第一个用 [-о]{.ru} 结尾的词干 | 连字符 | [ру́сско-кита́йский, нау́чно-иссле́довательский, вое́нно-морско́й, се́веро-за́падный]{.ru} |
| 由“形容词 + 名词”的词组构成 | 第一个词干加 [-о- / -е-]{.ru} | 连写 | [желе́зная доро́га → железнодоро́жный]{.ru}，[се́льское хозя́йство → сельскохозя́йственный]{.ru}，[За́падная Евро́па → западноевропе́йский]{.ru}，[дре́вняя Русь → древнеру́сский]{.ru} |
| 形容词词根 + 名词词根 + 后缀 | 连接元音 [-о- / -е-]{.ru} | 连写 | [голубогла́зый, черноволо́сый, длинноно́гий, редкозу́бый]{.ru} |
| 名词词根 + 动词词根 + 后缀 | 连接元音 | 连写 | [трудолюби́вый, миролюби́вый, свободолюби́вый, гостеприи́мный]{.ru} |

带前缀的形容词：

| 前缀 | 意义 | 例 |
|---|---|---|
| [не-]{.ru .ix} | 反义（比反义词缓和） | [неплохо́й, недорого́й, некраси́вый, незнако́мый, неве́жливый]{.ru}；不带 [не-]{.ru} 不单用：[неле́пый, неуклю́жий, небре́жный, невзра́чный, невреди́мый]{.ru} |
| [без-, бес-]{.ru .ix} | 没有……的（多为前缀后缀法，由名词构成） | [бесконе́чный, безопа́сный, беспла́тный, безрабо́тный, безо́блачный, бесполе́зный, бессмы́сленный, безгра́мотный]{.ru} |
| [пре-]{.ru .ix} | 非常（书面或口语带感情） | [преми́лый, предо́брый, прехоро́шенький]{.ru}；[прекра́сный]{.ru}（已成独立的词） |
| [наи-]{.ru .ix} | 加在最高级上，加强 | [наилу́чший, наибо́льший, наиме́ньший, наиху́дший, наивы́сший]{.ru} |
| [сверх-]{.ru .ix} | 超出 | [сверхзвуково́й, сверхсро́чный, сверхмо́щный, сверхъесте́ственный]{.ru} |
| [все-]{.ru .ix} | 全体的 | [всеми́рный, всеросси́йский, всенаро́дный, всео́бщий]{.ru} |
| [анти-, ультра-, пра-]{.ru} | 反；极端；原始 | [антивое́нный, ультрамо́дный, праславя́нский]{.ru} |
| 前置词来源的前缀（前缀后缀法） | 由“前置词 + 名词”构成 | [до войны́ → довое́нный]{.ru}，[по́сле войны́ → послевое́нный]{.ru}，[под Москво́й → подмоско́вный]{.ru}，[за грани́цей → заграни́чный]{.ru}，[ме́жду наро́дами → междунаро́дный]{.ru}，[вне кла́сса → внекла́ссный]{.ru}，[до револю́ции → дореволюцио́нный]{.ru} |

### 意义和用法

**数词开头的复合形容词。** 数词放在前一部分时用第二格形式：[пять → пяти-]{.ru}，[два́дцать → двадцати-]{.ru}，[девятна́дцать → девятнадцати-]{.ru}，[три → трёх-]{.ru}，[два → двух-]{.ru}；复合数词每一部分都用第二格：[двадцатитрёхле́тний, двадцатидвухле́тний]{.ru}。例外是 [одно-]{.ru}（[одноэта́жный]{.ru}）、[сорока-]{.ru}、[девяносто-]{.ru}、[сто-]{.ru}（[сорокале́тний, девяностоле́тний, столе́тний]{.ru}）。[дву-]{.ru} 只用于少数书面词（[двусторо́нний, двуязы́чный]{.ru}），一般用 [двух-]{.ru}。复合形容词的重音只有一个，在后一部分。

这类形容词只作定语，不作谓语：“十九岁的姑娘”是 [девятнадцатиле́тняя де́вушка]{.ru}，“她十九岁”说 [Ей девятна́дцать лет]{.ru}（年龄的表达见 §6.4.3）。由它们构成的名词表示周年和期限：[двадцатиле́тие]{.ru}（二十周年），[столе́тие]{.ru}（一百周年；世纪），[пятиле́тка]{.ru}（五年计划）。婴幼儿的年龄常用 [-годова́лый]{.ru}：[годова́лый ребёнок, двухгодова́лый сын]{.ru}。

**颜色形容词。** [тёмно-, светло-, я́рко-, бле́дно-]{.ru} 表示色调，和颜色之间用连字符：[тёмно-си́ний]{.ru}（深蓝）。两种颜色并列或混合也用连字符：[бе́ло-си́не-кра́сный флаг]{.ru}（白蓝红三色旗），[жёлто-зелёный]{.ru}（黄绿色）。第二个词还可以是 [-оват-]{.ru} 形容词作第一部分：[серова́то-си́ний]{.ru}（灰蓝色的）。

**连写还是用连字符。** 两部分地位平等（中间可以加 [и]{.ru}）的用连字符：[ру́сско-кита́йский слова́рь]{.ru}（俄汉词典），[нау́чно-иссле́довательский институ́т]{.ru}（科学研究所）。前一部分修饰后一部分、整个词由“形容词 + 名词”的词组构成的连写：[железнодоро́жный]{.ru}（铁路的，来自 [желе́зная доро́га]{.ru}），[сельскохозя́йственный]{.ru}（农业的）。颜色和方位（[се́веро-за́падный, ю́го-восто́чный]{.ru}）用连字符。详细的规则见 §1.4.6。

**[не-]{.ru}。** [не-]{.ru} 构成的形容词表示一种性质，比反义词缓和：[недорого́й]{.ru}“不贵”不等于 [дешёвый]{.ru}“便宜”，[неплохо́й]{.ru}“还不错”比 [хоро́ший]{.ru} 弱。有对比或加强否定时 [не]{.ru} 分写，是否定语气词（[Кни́ги здесь не дороги́е, а дешёвые]{.ru}），见 §1.4.6。有些词不带 [не-]{.ru} 不单用（[неле́пый, неуклю́жий]{.ru}），[не-]{.ru} 只是词的一部分。“[не-]{.ru} + [без-]{.ru}”的双重否定表示肯定，是书面语的委婉说法：[небезызве́стный]{.ru}（颇有名气的），[небезынтере́сный]{.ru}（相当有意思的）。

**[без-]{.ru} 和前置词来源的前缀。** [без-]{.ru} 形容词多不是由形容词加前缀构成的，而是由“[без]{.ru} + 名词”的词组用前缀后缀法构成：[без конца́ → бесконе́чный]{.ru}，[без рабо́ты → безрабо́тный]{.ru}，[без пла́ты → беспла́тный]{.ru}（§11.1.2）。[без-]{.ru} 在清辅音前写 [бес-]{.ru}，在 [и]{.ru} 前把 [и]{.ru} 写成 [ы]{.ru}（[безыде́йный]{.ru}），见 §1.4.4。同类的还有 [до-, по́сле-, под-, за-, ме́жду-, вне-]{.ru}：[довое́нный]{.ru}（战前的），[подмоско́вный]{.ru}（莫斯科近郊的），[междунаро́дный]{.ru}（国际的）。这类形容词等于一个前置词短语：[довое́нная Москва́ = Москва́ до войны́]{.ru}。

**[пре-]{.ru}、[наи-]{.ru}、[сверх-]{.ru}。** [пре-]{.ru} 加在性质形容词上表示“非常”，口语里带感情（[преми́лый]{.ru}），书面语里显得古雅；[прекра́сный]{.ru} 已经是独立的词。[наи-]{.ru} 只加在最高级上，书面色彩：[наилу́чший результа́т]{.ru}，副词 [наибо́лее]{.ru} 见 §4.3.4。[сверх-]{.ru} 表示超出常规：[сверхзвуково́й самолёт]{.ru}（超音速飞机）；[сверхъесте́ственный]{.ru}（超自然的）里前缀后写 [ъ]{.ru}。

**俄汉差异。** 汉语的“十九岁的”“两层的”“三室的”是数量词组加“的”，俄语合成一个形容词，数词部分还要变成第二格。汉语“中俄”“中俄关系”的顺序和俄语 [ру́сско-кита́йские отноше́ния]{.ru} 不一定一致，俄语一般把说话人一方放在前面。

数词开头的复合形容词：

::: ex
[**Девятнадцатиле́тняя** А́нна у́чится на второ́м ку́рсе.]{.ru}

[十九岁的安娜在读二年级。]{.gloss}

[Петро́вы живу́т в **трёхко́мнатной** кварти́ре в **пятиэта́жном** до́ме.]{.ru}

[彼得罗夫一家住在一座五层楼里的三居室。]{.gloss}

[В э́том году́ на́ша шко́ла пра́зднует **столе́тие**.]{.ru}

[今年我们学校庆祝建校一百周年。]{.gloss}
:::

颜色和其他复合形容词：

::: ex
[Ю́ми купи́ла **тёмно-си́нее** пла́тье.]{.ru}

[由美买了一条深蓝色的连衣裙。]{.gloss}

[У Ми́ши есть **ру́сско-кита́йский** слова́рь.]{.ru}

[米沙有一本俄汉词典。]{.gloss}

[Он рабо́тает на **железнодоро́жном** вокза́ле.]{.ru}

[他在火车站工作。]{.gloss}
:::

带前缀的形容词：

::: ex
[Э́то **неплохо́й** фильм, но я ви́дел и лу́чше.]{.ru}

[这部电影还不错，不过我看过更好的。]{.gloss}

[Вход в музе́й **беспла́тный**.]{.ru}

[博物馆免费入场。]{.gloss}

[Мы снима́ем да́чу в **подмоско́вном** посёлке.]{.ru}

[我们在莫斯科郊区的一个镇上租了一座别墅。]{.gloss}
:::

### 常见错误

::: err
\*[Мой брат — двадцатьле́тний студе́нт.]{.ru}　→　[Мой брат — **двадцатиле́тний** студе́нт.]{.ru}

复合形容词里的数词用第二格形式：[два́дцать → двадцати-]{.ru}。
:::

::: err
\*[Мне девятнадцатиле́тний.]{.ru}　→　[Мне **девятна́дцать лет**.]{.ru}

[-ле́тний]{.ru} 形容词只作定语；说年龄用第三格加数词加 [год / го́да / лет]{.ru}。
:::

::: err
\*[У неё тёмно си́нее пла́тье.]{.ru}　→　[У неё **тёмно-си́нее** пла́тье.]{.ru}

表示色调的复合形容词写连字符；分写的 [тёмно]{.ru} 会被当成副词。
:::

::: err
\*[Вход в музе́й безпла́тный.]{.ru}　→　[Вход в музе́й **беспла́тный**.]{.ru}

[без-]{.ru} 在清辅音前写 [бес-]{.ru}。
:::

## §11.3.3 动词前缀的意义

### 形式

前缀加在动词上有两种作用：一是只把未完成体变成完成体，不增加意义（纯体前缀，§7.3.3）；二是给动词增加新的意义，构成新动词。新的意义有空间的（[войти́, вы́йти, перейти́]{.ru}，运动动词见 §7.6.6、§7.6.7），也有非空间的：结果、程度、时间、数量等。下表列出常用前缀的主要意义。表中带 [-ся]{.ru} 的组合见后文“前缀和 [-ся]{.ru}”。

| 前缀 | 空间意义 | 非空间意义 | 例 |
|---|---|---|---|
| [в- (во-)]{.ru .ix} | 进入 | 深入（带 [-ся]{.ru}） | [вчита́ться, вслу́шаться, вду́маться]{.ru} |
| [вз- (вс-, взо-), вос- (воз-)]{.ru .ix} | 向上 | 突然、猛烈；恢复 | [взлете́ть, вскочи́ть]{.ru}；[вспы́хнуть]{.ru}；[восстанови́ть]{.ru} |
| [вы́-]{.ru .ix} | 向外 | 达到结果、取得；彻底；做足（带 [-ся]{.ru}） | [вы́учить, вы́играть, вы́просить]{.ru}；[вы́чистить, вы́стирать]{.ru}；[вы́спаться]{.ru} |
| [до-]{.ru .ix} | 到达 | 做到底；补足；弄出不好的结果（带 [-ся]{.ru}）；终于做到（带 [-ся]{.ru}） | [дочита́ть, дописа́ть]{.ru}；[доплати́ть, докупи́ть]{.ru}；[доигра́ться, догуля́ться]{.ru}；[дожда́ться, дозвони́ться]{.ru} |
| [за-]{.ru .ix} | 到后面；顺路 | 开始；覆盖、封闭；固定下来；过于投入（带 [-ся]{.ru}） | [запла́кать, запе́ть]{.ru}；[закры́ть, закле́ить]{.ru}；[записа́ть, запо́мнить]{.ru}；[зачита́ться, заговори́ться, засиде́ться]{.ru} |
| [из- (ис-, изо-)]{.ru .ix} | 从里面出来（书面） | 遍及；用尽、用坏 | [исходи́ть весь го́род, исписа́ть тетра́дь]{.ru}；[износи́ть, изму́читься]{.ru} |
| [на-]{.ru .ix} | 到上面 | 做出许多；做到满足（带 [-ся]{.ru}） | [напе́чь пирого́в, наговори́ть]{.ru}；[нае́сться, наговори́ться]{.ru} |
| [над-]{.ru .ix} | 在上面 | 加在上面；做一小部分 | [надписа́ть, надстро́ить]{.ru}；[надре́зать, надкуси́ть, надломи́ть]{.ru} |
| [недо-]{.ru .ix} | — | 不足，没达到应有的程度 | [недоспа́ть, недооцени́ть, недосоли́ть, недоплати́ть, недосмотре́ть]{.ru} |
| [о-, об- (обо-)]{.ru .ix} | 围绕；绕过 | 遍及表面；使具有某种性质；失误（带 [-ся]{.ru}） | [осмотре́ть, обсуди́ть]{.ru}；[облегчи́ть, охлади́ть, осчастли́вить]{.ru}；[оговори́ться, ослы́шаться, обсчита́ться]{.ru} |
| [от- (ото-)]{.ru .ix} | 离开 | 结束；回报；分下一部分；摆脱、恢复（带 [-ся]{.ru}） | [отцвести́, отрабо́тать]{.ru}；[отве́тить, отплати́ть]{.ru}；[отре́зать, отломи́ть]{.ru}；[отоспа́ться, отговори́ться]{.ru} |
| [пере-]{.ru .ix} | 越过；转移 | 重做；过度；胜过；遍及；相互（带 [-ся]{.ru}） | [переписа́ть, переде́лать]{.ru}；[перее́сть, пересоли́ть, переплати́ть, переоцени́ть]{.ru}；[перекрича́ть, переспо́рить]{.ru}；[перепро́бовать]{.ru}；[перепи́сываться, перегляну́ться]{.ru} |
| [по-]{.ru .ix} | 开始运动 | 一会儿；时不时；逐一（见 §7.3.5） | [посиде́ть]{.ru}；[погля́дывать]{.ru}；[позакрыва́ть]{.ru} |

| [при-]{.ru .ix} | 到来；靠近 | 附加；稍稍；附着 | [приписа́ть, пристро́ить, приба́вить]{.ru}；[приоткры́ть, присе́сть, приподня́ть, призаду́маться]{.ru}；[прикле́ить, привяза́ть]{.ru} |
| [про-]{.ru .ix} | 穿过；经过 | 整整一段时间；错过、失误；彻底；失去 | [проспа́ть весь день]{.ru}；[проспа́ть уро́к, прозева́ть, просчита́ться, проговори́ться]{.ru}；[проду́мать, прогре́ть]{.ru}；[проигра́ть]{.ru} |
| [раз- (рас-, разо-)]{.ru .ix} | 向各处 | 分开；变成；取消、反向；加强（带 [-ся]{.ru}） | [разре́зать, разби́ть, раздели́ть]{.ru}；[разбогате́ть]{.ru}；[разлюби́ть, разду́мать, разучи́ться, разморо́зить]{.ru}；[разговори́ться, распла́каться]{.ru} |
| [с- (со-, съ-)]{.ru .ix} | 从上面下来；聚到一起 | 聚合；缩小；照样做；去一趟（见 §7.6.6） | [собра́ть, созва́ть, сложи́ть]{.ru}；[сжа́ться, су́зиться, съёжиться]{.ru}；[списа́ть, срисова́ть]{.ru}；[сходи́ть, съе́здить]{.ru} |
| [у-]{.ru .ix} | 离开 | 使成为；容纳；设法做到 | [упрости́ть, улу́чшить, увели́чить, удлини́ть]{.ru}；[умести́ть]{.ru}；[уговори́ть]{.ru} |

带新义的前缀动词是完成体，它的未完成体用后缀 [-ыва-, -ива-, -ва-, -а-]{.ru} 构成（[переписа́ть — перепи́сывать, отре́зать — отреза́ть, разби́ть — разбива́ть]{.ru}，见 §7.3.4）；表示行为方式的前缀动词多半没有成对的未完成体（[посиде́ть, запла́кать, нае́сться]{.ru}，见 §7.3.5）。[вы́-]{.ru} 在完成体里永远重读，在未完成体里不重读（[вы́учить — выу́чивать]{.ru}）。前缀的写法（[раз- / рас-]{.ru}，[с- / съ-]{.ru}，前缀后的 [ы]{.ru}）见 §1.4.4。

### 意义和用法

**空间意义怎样引申出非空间意义。** 前缀的非空间意义大多由空间意义引申而来，懂得这个联系，许多意义就不必死记：

1. [про-]{.ru}“穿过”：穿过一段空间（[пройти́ лес]{.ru}）→ 穿过一段时间（[проспа́ть весь день]{.ru}，睡了一整天）→ 穿过了要停下的地方，即错过（[проспа́ть уро́к]{.ru}，睡过了头误了课）→ 失误（[просчита́ться]{.ru}，算错）。
2. [пере-]{.ru}“越过”：越过一个界限 → 重新再做一遍（[переписа́ть]{.ru}）→ 超过了应有的量，即过度（[пересоли́ть]{.ru}，放盐太多）→ 超过对手（[перекрича́ть]{.ru}，喊声压过别人）。
3. [до-]{.ru}“到达”：动作一直进行到终点（[дочита́ть]{.ru}，读到底）→ 补到应有的量（[доплати́ть]{.ru}，补交钱）。[недо-]{.ru} 就是“没到”：[недосоли́ть]{.ru}（盐放少了），[недоспа́ть]{.ru}（没睡够）。[пере-]{.ru} 与 [недо-]{.ru} 正好相对：[переплати́ть — недоплати́ть]{.ru}，[переоцени́ть — недооцени́ть]{.ru}（高估—低估）。
4. [раз-]{.ru}“向各处”：分开（[разре́зать]{.ru}，切开）→ 原来的状态被拆散，即取消（[разлюби́ть]{.ru}，不再爱；[разду́мать]{.ru}，改变主意）。
5. [за-]{.ru}“到后面、到边界外”：进入一个新的阶段，即开始（[запе́ть]{.ru}）→ 走得太远，即过于投入（[зачита́ться]{.ru}，看书入了迷）。
6. [при-]{.ru}“靠近、附加”：加上一点（[приба́вить]{.ru}）→ 只做一点，即稍稍（[приоткры́ть]{.ru}，打开一点，[присе́сть]{.ru}，坐一下、蹲下）。
7. [у-]{.ru}“离开”：离开原来的状态，变成另一种（[упрости́ть]{.ru}，使简单，[увели́чить]{.ru}，使变大）。
8. [о-, об-]{.ru}“围绕”：动作遍及整个对象（[осмотре́ть]{.ru}，察看一遍，[обсуди́ть]{.ru}，讨论）；绕过了目标，即失误（[оговори́ться]{.ru}，说走了嘴，[ослы́шаться]{.ru}，听错）。

**同一个前缀的几种意义。** 同一个前缀加在不同的动词上意义不同，要结合动词的意义判断：[переписа́ть]{.ru} 是“重写”，[перее́сть]{.ru} 是“吃多了”，[перейти́]{.ru} 是“走过去”；[проспа́ть]{.ru} 可以是“睡了（一段时间）”，也可以是“睡过了头”，要看后面带不带时段（[проспа́л весь день]{.ru} / [проспа́л ле́кцию]{.ru}）。同一个前缀的意义还要和纯体前缀区分：[за-]{.ru} 在 [заплати́ть]{.ru} 里只构成体对，在 [запла́кать]{.ru} 里表示开始（§7.3.3）。

**前缀和 [-ся]{.ru}。** 许多非空间意义要求前缀和 [-ся]{.ru} 同时出现，这时不加 [-ся]{.ru} 的动词不存在或意义不同（前缀后缀法，§11.1.2）：

| 组合 | 意义 | 例 |
|---|---|---|
| [на-…-ся]{.ru} | 做够了，满足了 | [нае́сться, напи́ться, наговори́ться, нагуля́ться, насмотре́ться]{.ru} |
| [вы́-…-ся]{.ru} | 做足了 | [вы́спаться]{.ru} |
| [раз-…-ся]{.ru} | 向四处；越来越起劲 | [разойти́сь, разбежа́ться]{.ru}；[разговори́ться, распла́каться, разыгра́ться]{.ru} |
| [за-…-ся]{.ru} | 过于投入，忘了时间 | [зачита́ться, заговори́ться, засиде́ться]{.ru} |
| [до-…-ся]{.ru} | 终于做到；做到出了坏结果 | [дожда́ться, дозвони́ться]{.ru}；[доигра́ться]{.ru} |
| [о-, об-…-ся]{.ru} | 做错 | [оговори́ться, ослы́шаться, обсчита́ться]{.ru} |
| [про-…-ся]{.ru} | 说漏、做错 | [проговори́ться, просчита́ться]{.ru} |
| [от-…-ся]{.ru} | 补回来；推脱掉 | [отоспа́ться]{.ru}；[отговори́ться]{.ru} |
| [пере-…-ся]{.ru} | 相互 | [перепи́сываться, перегова́риваться, перегляну́ться]{.ru} |
| [с-…-ся]{.ru} | 聚到一起 | [сойти́сь, съе́хаться, сбежа́ться]{.ru} |

[нае́сться]{.ru} 和 [пое́сть]{.ru}、[съесть]{.ru} 不同：[пое́л]{.ru} 只是吃了点东西，[съел]{.ru} 是把某样东西吃掉，[нае́лся]{.ru} 是吃饱了。

**俄汉差异：前缀和汉语的补语。** 汉语用结果补语和趋向补语表示的意思，俄语多由前缀表示。对应关系大致如下，但不是一一对应，选词时要看俄语动词本身：

| 汉语 | 俄语 | 例 |
|---|---|---|
| 读完、写完（剩下的部分） | [до-]{.ru} | [дочита́ть, дописа́ть]{.ru} |
| 读完、写完（一般地） | 纯体前缀 | [прочита́ть, написа́ть]{.ru} |
| 吃饱、睡够、看够 | [на-…-ся]{.ru}，[вы́-…-ся]{.ru} | [нае́сться, вы́спаться, насмотре́ться]{.ru} |
| 睡过头、坐过站 | [про-]{.ru} | [проспа́ть, прое́хать свою́ остано́вку]{.ru} |
| 说错、听错、算错 | [о- (об-)…-ся]{.ru}，[про-…-ся]{.ru} | [оговори́ться, ослы́шаться, обсчита́ться, просчита́ться]{.ru} |
| 切开、打碎、分开 | [раз-]{.ru} | [разре́зать, разби́ть, раздели́ть]{.ru} |
| 记下、关上、封住 | [за-]{.ru} | [записа́ть, закры́ть, закле́ить]{.ru} |
| 重写、改做 | [пере-]{.ru} | [переписа́ть, переде́лать]{.ru} |
| 吃多了、盐放多了 | [пере-]{.ru} | [перее́сть, пересоли́ть]{.ru} |
| 没睡够、盐放少了 | [недо-]{.ru} | [недоспа́ть, недосоли́ть]{.ru} |
| 稍微打开、稍微抬起 | [при-]{.ru} | [приоткры́ть, приподня́ть]{.ru} |
| 哭起来、唱起来 | [за-]{.ru} | [запла́кать, запе́ть]{.ru} |

汉语说“读完了”，多数情况下俄语用纯体前缀的 [прочита́л]{.ru}；只有强调“把剩下的读完”时才用 [дочита́л]{.ru}。汉语的“过”有“过头”的意思（“睡过了”），俄语的“过头”是 [про-]{.ru}，不是 [пере-]{.ru}。

**作家的特殊用法。** 诗人和作家常按前缀的意义自己造词，或者把两个前缀叠用，增加表现力。叶赛宁的诗里 [принакры́лась]{.ru} 同时用了 [при-]{.ru}（稍稍）和 [на-]{.ru}（覆盖在上面）：白桦“轻轻地披上了”一层雪。马雅可夫斯基的 [изъиздева́юсь]{.ru} 是 [издева́ться]{.ru}（嘲弄）再加一个 [изъ-]{.ru}（[из-]{.ru} 的变体，“做尽”）：“把嘲弄做个够”。口语里也有双前缀动词，如 [понае́хать]{.ru}（[по-]{.ru} 逐一 + [на-]{.ru} 许多，“一个个都来了很多”），带不满的口气。这类词在词典里不一定查得到，按前缀的意义去理解（§11.3.6）。

::: ex
[Бе́лая берёза / Под мои́м окно́м / **Принакры́лась** сне́гом, / То́чно серебро́м.]{.ru}（[Есе́нин]{.ru}）

[白色的白桦，在我的窗前，轻轻披上了一层雪，像披上了白银。（叶赛宁）]{.gloss}
:::

前缀的非空间意义：

::: ex
[Ми́ша **дочита́л** кни́гу до конца́ и лёг спать.]{.ru}

[米沙把书读到最后一页，就睡觉了。]{.gloss}

[Я **проспа́л** и опозда́л на пе́рвую па́ру.]{.ru}

[我睡过头了，第一节课迟到了。]{.gloss}

[Ма́ма **пересоли́ла** суп, и мы пи́ли мно́го воды́.]{.ru}

[妈妈汤里盐放多了，我们喝了好多水。]{.gloss}

[Он всегда́ **недооце́нивает** свои́ си́лы.]{.ru}

[他总是低估自己的能力。]{.gloss}

[А́нна **приоткры́ла** окно́: в ко́мнате бы́ло ду́шно.]{.ru}

[安娜把窗户打开了一点：屋里很闷。]{.gloss}
:::

前缀和 [-ся]{.ru}：

::: ex
[В суббо́ту я наконе́ц **вы́спался**.]{.ru}

[星期六我终于睡够了。]{.gloss}

[Ван Лэй **зачита́лся** и не заме́тил, что уже́ час но́чи.]{.ru}

[王磊看书入了迷，没发现已经夜里一点了。]{.gloss}

[Извини́те, я **оговори́лся**: не в сре́ду, а в четве́рг.]{.ru}

[对不起，我说错了：不是星期三，是星期四。]{.gloss}

[По́сле конце́рта лю́ди ме́дленно **расходи́лись**.]{.ru}

[音乐会结束后，人们慢慢散去。]{.gloss}
:::

### 常见错误

::: err
\*[Сего́дня я переспа́л и опозда́л на уро́к.]{.ru}　→　[Сего́дня я **проспа́л** и опозда́л на уро́к.]{.ru}

“睡过头”是 [проспа́ть]{.ru}：[про-]{.ru} 表示错过了该停下的时候。[пере-]{.ru} 的“过度”意义不用在 [спать]{.ru} 上。
:::

::: err
\*[Вчера́ я дописа́л письмо́ ма́ме.]{.ru}（只想说“写了一封信”）　→　[Вчера́ я **написа́л** письмо́ ма́ме.]{.ru}

汉语的“写完了”一般对应纯体前缀的完成体 [написа́ть]{.ru}；[дописа́ть]{.ru} 是“把没写完的部分写完”，用于前面已经写了一部分的情况。
:::

::: err
\*[Я нае́л мно́го пирого́в.]{.ru}　→　[Я **нае́лся** пирого́в.]{.ru}（我吃馅饼吃饱了）或 [Я **съел** мно́го пирого́в.]{.ru}（我吃了很多馅饼）

“吃饱”的 [на-]{.ru} 必须和 [-ся]{.ru} 一起用；不带 [-ся]{.ru} 的 [нае́сть]{.ru} 不单用。
:::

::: err
\*[Я ослы́шал, что ты сказа́л.]{.ru}　→　[Я **ослы́шался**.]{.ru}（我听错了）或 [Я не **расслы́шал**, что ты сказа́л.]{.ru}（我没听清你说什么）

[ослы́шаться]{.ru} 只有带 [-ся]{.ru} 的形式，不带补语；“没听清”是 [не расслы́шать]{.ru}。
:::

## §11.3.4 动词后缀

### 形式

动词主要靠前缀构成，但由名词、形容词构成动词要靠后缀。构成新动词的后缀：

| 后缀 | 生产词 | 意义 | 变位 | 例 |
|---|---|---|---|---|
| [-и-]{.ru .ix}（[-ить]{.ru}） | 形容词、名词 | 使具有某种性质（及物）；用某物做、做某事 | 第二变位 | [бе́лый → бели́ть]{.ru}，[чёрный → черни́ть]{.ru}，[весёлый → весели́ть]{.ru}，[сухо́й → суши́ть]{.ru}，[ста́рый → ста́рить]{.ru}，[гото́вый → гото́вить]{.ru}；[соль → соли́ть]{.ru}，[мы́ло → мы́лить]{.ru}，[шу́тка → шути́ть]{.ru}，[грусть → грусти́ть]{.ru}，[звон → звони́ть]{.ru} |
| [-е-]{.ru .ix}（[-еть]{.ru}） | 形容词 | 变得具有某种性质（不及物）；显出某种颜色 | 第一变位（[беле́ю, беле́ешь]{.ru}） | [бе́лый → беле́ть]{.ru}，[кра́сный → красне́ть]{.ru}，[бле́дный → бледне́ть]{.ru}，[сла́бый → слабе́ть]{.ru}，[бога́тый → богате́ть]{.ru}，[ста́рый → старе́ть]{.ru}，[молодо́й → молоде́ть]{.ru}，[у́мный → умне́ть]{.ru}，[пусто́й → пусте́ть]{.ru}，[седо́й → седе́ть]{.ru}，[то́лстый → толсте́ть]{.ru}，[худо́й → худе́ть]{.ru}，[тёмный → темне́ть]{.ru}，[зелёный → зелене́ть]{.ru} |
| [-ну-]{.ru .ix}（变成） | 形容词 | 变得具有某种性质（不及物） | 第一变位；过去时多丢掉 [-ну-]{.ru}（[сох, мёрз]{.ru}） | [сухо́й → со́хнуть]{.ru}，[мо́крый → мо́кнуть]{.ru}，[слепо́й → сле́пнуть]{.ru}，[глухо́й → гло́хнуть]{.ru}，[кре́пкий → кре́пнуть]{.ru}，[ки́слый → ки́снуть]{.ru}，[сла́бый → сла́бнуть]{.ru} |
| [-а-, -я-]{.ru .ix} | 名词、感叹词 | 做与某物有关的事；发出某种声音 | 第一变位 | [обе́д → обе́дать]{.ru}，[у́жин → у́жинать]{.ru}，[за́втрак → за́втракать]{.ru}，[мечта́ → мечта́ть]{.ru}，[игра́ → игра́ть]{.ru}；[ах → а́хать]{.ru}，[ох → о́хать]{.ru}，[мя́у → мяу́кать]{.ru}，[ты → ты́кать]{.ru}，[вы → вы́кать]{.ru} |
| [-ова-, -ева-]{.ru .ix} | 名词、形容词 | 做某事，从事某种活动 | 第一变位，现在时 [-у-]{.ru}（§7.1.3） | [сове́т → сове́товать]{.ru}，[бесе́да → бесе́довать]{.ru}，[ночь → ночева́ть]{.ru}，[го́ре → горева́ть]{.ru}，[та́нец → танцева́ть]{.ru} |
| [-ирова-, -изова-, -изирова-]{.ru .ix} | 外来名词 | 同上（外来词根） | 同上 | [фотогра́фия → фотографи́ровать]{.ru}，[ремо́нт → ремонти́ровать]{.ru}，[ко́пия → копи́ровать]{.ru}，[ана́лиз → анализи́ровать]{.ru}，[организа́ция → организова́ть]{.ru}，[реа́льный → реализова́ть]{.ru}，[станда́рт → стандартизи́ровать]{.ru} |
| [-нича-]{.ru .ix} | 名词（多为 [-ник]{.ru} 名词）、形容词 | 从事某种活动（多非正式职业）；表现出某种（多为不好的）行为 | 第一变位 | [столя́р → столя́рничать]{.ru}，[пло́тник → пло́тничать]{.ru}，[сапо́жник → сапо́жничать]{.ru}；[хозя́ин → хозя́йничать]{.ru}，[безде́льник → безде́льничать]{.ru}，[моше́нник → моше́нничать]{.ru}，[я́беда → я́бедничать]{.ru}，[скро́мный → скро́мничать]{.ru}，[жа́дный → жа́дничать]{.ru}，[вре́дный → вре́дничать]{.ru} |
| [-ствова-]{.ru .ix} | 名词、形容词 | 处于某种身份、状态（多为书面） | 第一变位 | [учи́тель → учи́тельствовать]{.ru}，[царь → ца́рствовать]{.ru}，[господи́н → госпо́дствовать]{.ru}，[путеше́ствие → путеше́ствовать]{.ru} |

体的后缀不构成新词，只构成体对或行为方式：次生未完成体的 [-ыва-, -ива-, -ва-, -а-]{.ru} 和表示一次的 [-ну-]{.ru} 见 §7.3.4、§7.3.5；尾缀 [-ся]{.ru} 见 §7.5.2。

### 意义和用法

**[-и-]{.ru} 和 [-е-]{.ru}：使变成和变成。** 由同一个形容词构成的 [-ить]{.ru} 动词和 [-еть]{.ru} 动词成对，意义的区别是及物和不及物：[-ить]{.ru} 动词表示“使（别的东西）具有某种性质”，带第四格补语；[-еть]{.ru} 动词表示“（自己）变得具有某种性质”，不带补语。

| 形容词 | [-ить]{.ru}：使变成（及物，第二变位） | [-еть]{.ru}：自己变成（不及物，第一变位） |
|---|---|---|
| [бе́лый]{.ru} | [бели́ть]{.ru .ix} 刷白：[бели́ть потоло́к]{.ru} | [беле́ть]{.ru .ix} 变白；显出白色：[Лицо́ беле́ет]{.ru} |
| [чёрный]{.ru} | [черни́ть]{.ru} 涂黑；诋毁 | [черне́ть]{.ru} 变黑；显出黑色 |
| [ста́рый]{.ru} | [ста́рить]{.ru} 使显老：[Э́то пла́тье тебя́ ста́рит]{.ru} | [старе́ть]{.ru} 变老 |
| [молодо́й]{.ru} | [молоди́ть]{.ru} 使显年轻 | [молоде́ть]{.ru} 变年轻 |
| [весёлый]{.ru} | [весели́ть]{.ru} 逗乐 | [повеселе́ть]{.ru} 高兴起来 |
| [си́льный]{.ru} | [обесси́лить]{.ru} 使无力 | [обесси́леть]{.ru} 变得无力 |

两个动词的变位不同：[бели́ть]{.ru} 是第二变位（[белю́, бе́лишь, бе́лит]{.ru}），[беле́ть]{.ru} 是第一变位（[беле́ю, беле́ешь, беле́ет]{.ru}）。加前缀构成完成体时差别照样保留：[побели́ть сте́ну]{.ru}（把墙刷白）— [побеле́ть от стра́ха]{.ru}（吓得脸色发白）。不定式只差一个字母，过去时也只差一个字母（[обесси́лил — обесси́лел]{.ru}），要看句子里有没有补语来区分。

[-еть]{.ru} 动词表示颜色时还有一个意思：“显出某种颜色”，远远地看得见：[Вдали́ беле́ет па́рус]{.ru}（远处有一片白帆）。这个意思在描写景物的文学作品里很常见。

“变成”的意思也可以用 [-ну-]{.ru} 动词表示：[со́хнуть]{.ru}（变干），[кре́пнуть]{.ru}（变强），[сле́пнуть]{.ru}（变瞎），[гло́хнуть]{.ru}（变聋）。这个 [-ну-]{.ru} 和表示一次的 [-ну-]{.ru}（[кри́кнуть]{.ru}）同形不同义：它构成未完成体，过去时常常丢掉 [-ну-]{.ru}（[со́хнуть — сох, со́хла]{.ru}，变位见 §7.1.4）。与它们相对的及物动词用 [-и-]{.ru}：

| 不及物：变成 | 及物：使变成 |
|---|---|
| [вы́сохнуть]{.ru} 干了：[Бельё вы́сохло]{.ru} | [вы́сушить]{.ru} 弄干：[вы́сушить бельё]{.ru} |
| [замёрзнуть]{.ru} 冻了 | [заморо́зить]{.ru} 冷冻 |
| [осле́пнуть]{.ru} 瞎了 | [ослепи́ть]{.ru} 使目眩 |
| [огло́хнуть]{.ru} 聋了 | [оглуши́ть]{.ru} 震聋 |
| [окре́пнуть]{.ru} 强壮起来 | [укрепи́ть]{.ru} 加强 |
| [разбогате́ть]{.ru} 发财 | [обогати́ть]{.ru} 使富裕；丰富 |

**[-ова-]{.ru} 和 [-ирова-]{.ru}：最能产的后缀。** 由名词构成表示活动的动词，最常用 [-ова-]{.ru}：[сове́т → сове́товать]{.ru}（出主意），[бесе́да → бесе́довать]{.ru}（交谈）。外来词根多用 [-ирова-]{.ru}，它是今天构成新动词最主要的后缀：[фотографи́ровать, ремонти́ровать, копи́ровать, анализи́ровать, регистри́ровать]{.ru}。这些动词常和 [-ация]{.ru} 名词成对（[регистри́ровать — регистра́ция]{.ru}，§11.2.2）。[-ова-, -ирова-]{.ru} 动词在现在时里变成 [-у-]{.ru}（[сове́тую, фотографи́рую]{.ru}，§7.1.3）；不少是两体动词（[организова́ть, иссле́довать]{.ru}，§7.3.2），完成体也常加前缀 [с-, про-, за-]{.ru}（[сфотографи́ровать, проанализи́ровать, зарегистри́ровать]{.ru}，§7.3.3）。

口语里由英语借来的新动词多用 [-и-]{.ru}、[-а-]{.ru} 和表示一次的 [-ну-]{.ru}：[гу́глить]{.ru}（用谷歌搜索），[кли́кнуть]{.ru}（点一下鼠标），[ла́йкнуть]{.ru}（点个赞）。这些词是口语或俚语。

**[-нича-]{.ru}。** [-нича-]{.ru} 由名词（多为带 [-ник]{.ru} 的指人名词：[-ник + -а- → -нича-]{.ru}）和形容词构成，有两种意义：一是从事某种手艺，多指不是正式职业、做一做（[столя́рничать]{.ru}，干木匠活儿）；二是表现出某种行为，多是不好的（[безде́льничать]{.ru}，游手好闲，[жа́дничать]{.ru}，小气，[скро́мничать]{.ru}，故作谦虚，[хозя́йничать]{.ru}，当家作主，也指自作主张）。这类动词都是未完成体，带口语色彩。

**[-ствова-]{.ru}。** [-ствова-]{.ru} 表示处于某种身份或状态，多为书面语：[учи́тельствовать]{.ru}（当教师），[ца́рствовать]{.ru}（在位，统治），[госпо́дствовать]{.ru}（统治，占优势）。许多 [-ствовать]{.ru} 动词和 [-ство, -ствие]{.ru} 名词同根：[путеше́ствие — путеше́ствовать]{.ru}，[чу́вство — чу́вствовать]{.ru}。

**由感叹词构成的动词。** 感叹词和拟声词加 [-а-]{.ru}（常带 [-к-]{.ru}）构成动词：[а́хать, о́хать]{.ru}（唉声叹气），[мяу́кать]{.ru}（猫叫），[ты́кать]{.ru}（对人称“你”），[вы́кать]{.ru}（对人称“您”）。表示一次的形式用 [-ну-]{.ru}：[а́хнуть, о́хнуть]{.ru}。拟声词与动词的关系见 §10.3.2。

**俄汉差异。** 汉语用“使、让、把……弄”和“变、变得”区分“使变成”和“自己变成”（“把墙刷白”—“脸变白了”），形容词本身不变。俄语用两个不同的动词：[-ить]{.ru} 动词和 [-еть]{.ru}（[-нуть]{.ru}）动词。按汉语一个“白”字去用一个俄语动词，就会把及物和不及物弄混。

[-ить]{.ru} 和 [-еть]{.ru}：

::: ex
[Ле́том мы **бели́ли** потоло́к на да́че.]{.ru}

[夏天我们在别墅里粉刷了天花板。]{.gloss}

[Услы́шав но́вость, она́ **побледне́ла**.]{.ru}

[她听到消息，脸色发白了。]{.gloss}

[**Беле́ет** па́рус одино́кий / В тума́не мо́ря голубо́м!..]{.ru}（[Ле́рмонтов]{.ru}）

[一片孤帆在蓝色的海雾里闪着白光！……（莱蒙托夫）]{.gloss}

[Ба́бушка **старе́ет**, ей уже́ во́семьдесят лет.]{.ru}

[奶奶老了，她已经八十岁了。]{.gloss}
:::

[-нуть]{.ru} 和 [-ить]{.ru}：

::: ex
[Бельё уже́ **вы́сохло**.]{.ru}

[衣服已经干了。]{.gloss}

[Ма́ма **вы́сушила** бельё на балко́не.]{.ru}

[妈妈把衣服晾在阳台上晒干了。]{.gloss}
:::

[-ирова-]{.ru} 和 [-нича-]{.ru}：

::: ex
[Пьер лю́бит **фотографи́ровать** ста́рые дома́.]{.ru}

[皮埃尔喜欢拍老房子。]{.gloss}

[Не **безде́льничай**, помоги́ мне!]{.ru}

[别闲着，来帮帮我！]{.gloss}
:::

### 常见错误

::: err
\*[Он бе́лит от стра́ха.]{.ru}　→　[Он **беле́ет** от стра́ха.]{.ru}（或 [Он **побледне́л** от стра́ха.]{.ru}）

“（自己）变白”是不及物的 [беле́ть]{.ru}（第一变位）；[бели́ть]{.ru} 是“把别的东西刷白”，要带补语。
:::

::: err
\*[Мои́ ту́фли вы́сушились.]{.ru}　→　[Мои́ ту́фли **вы́сохли**.]{.ru}

“干了”是不及物的 [вы́сохнуть]{.ru}；[вы́сушить]{.ru} 是“把……弄干”，用 [-ся]{.ru} 也不能表示“自己干了”。
:::

::: err
\*[Он ста́рит.]{.ru}（想说“他变老了”）　→　[Он **старе́ет**.]{.ru}

[ста́рить]{.ru} 是“使显老”，必须带补语：[Э́та причёска тебя́ ста́рит]{.ru}（这个发型显得你老）。
:::

::: err
\*[Я люблю́ фотографова́ть.]{.ru}　→　[Я люблю́ **фотографи́ровать**.]{.ru}

外来词根的动词多用 [-ирова-]{.ru}：[фотогра́фия → фотографи́ровать]{.ru}，[ремо́нт → ремонти́ровать]{.ru}。
:::

## §11.3.5 副词的构词

### 形式

副词由形容词、名词、代词、数词和副动词构成。主要的构词方式：

| 方式 | 构成 | 例 |
|---|---|---|
| 后缀 [-о, -е]{.ru .ix} | 性质形容词的词干加 [-о]{.ru}；软变化形容词和形动词加 [-е]{.ru} | [бы́стрый → бы́стро]{.ru}，[хоро́ший → хорошо́]{.ru}，[плохо́й → пло́хо]{.ru}，[весёлый → ве́село]{.ru}，[горя́чий → горячо́]{.ru}，[све́жий → свежо́]{.ru}；[и́скренний → и́скренне]{.ru}，[певу́чий → певу́че]{.ru}，[блестя́щий → блестя́ще]{.ru}，[угрожа́ющий → угрожа́юще]{.ru}，[понима́ющий → понима́юще]{.ru} |
| 后缀 [-и]{.ru .ix}（[-ски, -цки, -ьи]{.ru}） | [-ский, -цкий, -ий]{.ru} 形容词，多加前缀 [по-]{.ru}（连字符） | [по-ру́сски, по-кита́йски, по-дру́жески, по-де́тски, по-челове́чески, по-неме́цки, по-во́лчьи]{.ru}；不加 [по-]{.ru}：[практи́чески, истори́чески, физи́чески, дру́жески]{.ru} |
| [по-…-ому, -ему]{.ru .ix} | [по-]{.ru} 加形容词、物主代词的阳性第三格（连字符） | [по-но́вому, по-ста́рому, по-друго́му, по-ра́зному, по-пре́жнему, по-ле́тнему, по-хоро́шему]{.ru}；[по-мо́ему, по-тво́ему, по-на́шему, по-сво́ему]{.ru} |
| 前缀 + 形容词（短尾形式的旧格） | [в-, на-]{.ru} 加 [-о]{.ru}；[с-, из-, до-]{.ru} 加 [-а]{.ru}；[по-]{.ru} 加 [-у]{.ru}；[в-]{.ru} 加 [-ую]{.ru}；[за-, на-]{.ru} 加 [-о]{.ru} | [впра́во, вле́во, напра́во, нале́во, надо́лго, навсегда́]{.ru}；[спра́ва, сле́ва, сно́ва, издалека́, и́здали, и́зредка, сгоряча́, слегка́, до́суха, до́чиста, до́сыта, допоздна́]{.ru}；[понемно́гу, помале́ньку]{.ru}；[вручну́ю, вслепу́ю, вплотну́ю, вкруту́ю]{.ru}；[за́ново, за́светло, на́скоро, на́сухо]{.ru} |
| 前置词 + 名词（凝固成一个词） | [в, на, с, до]{.ru} 等加名词的某一格 | [вдали́, вблизи́, вверху́, внизу́, наверху́, впереди́, внача́ле, све́рху, сни́зу, вдоба́вок, наконе́ц, впосле́дствии, подря́д]{.ru} |
| 名词的格转为副词 | 多为第五格 | [у́тром, днём, ве́чером, но́чью, зимо́й, весно́й, ле́том, о́сенью, пешко́м, шёпотом, ря́дом]{.ru} |
| 数词构成的副词 | [в-…-ём]{.ru}；[-жды]{.ru}；[в-…-ые]{.ru} | [вдвоём, втроём]{.ru}；[два́жды, три́жды, четы́режды]{.ru}；[впервы́е]{.ru} |
| 副动词转为副词 | 形式不变 | [мо́лча, сто́я, лёжа, си́дя, шутя́, не́хотя]{.ru} |

### 意义和用法

**[-о]{.ru} 和 [-е]{.ru}。** 由性质形容词构成副词，是副词最主要的来源：词干加 [-о]{.ru}（[бы́стро, пра́вильно, внима́тельно]{.ru}）。软变化形容词加 [-е]{.ru}（[и́скренне]{.ru}）；由形动词构成的副词也用 [-е]{.ru}（[блестя́ще, угрожа́юще, вызыва́юще]{.ru}），带书面色彩。[ж, ш, ч, щ]{.ru} 后，后缀重读写 [-о́]{.ru}（[хорошо́, горячо́, свежо́]{.ru}），不重读写 [-е]{.ru}（[певу́че, блестя́ще]{.ru}）。[-о]{.ru} 副词和短尾中性同形，重音也可能和形容词不同（[хоро́ший → хорошо́, весёлый → ве́село]{.ru}），作状语与作谓语的区别见 §8.1.2。关系形容词一般不构成 [-о]{.ru} 副词。

**[по-…-ски]{.ru}。** [-ский, -цкий]{.ru} 形容词去掉词尾加 [-и]{.ru}，前面加 [по-]{.ru}，表示“按……的方式”：[говори́ть по-ру́сски]{.ru}（说俄语），[поступи́ть по-дру́жески]{.ru}（像朋友那样做）。动物名称的 [-ий]{.ru} 形容词同样：[по-во́лчьи]{.ru}（像狼一样）。不加 [по-]{.ru} 的 [-ически]{.ru} 副词表示“在……方面”，是书面语：[практи́чески]{.ru}（实际上；几乎），[физи́чески]{.ru}（在体力上），[истори́чески]{.ru}（从历史上看）。

**[по-…-ому]{.ru}。** [по-]{.ru} 加形容词或物主代词的阳性第三格形式，表示“按……的样子”：[по-но́вому]{.ru}（用新的方式），[по-пре́жнему]{.ru}（照旧），[по-ра́зному]{.ru}（各不相同地）。由物主代词构成的 [по-мо́ему, по-тво́ему, по-на́шему]{.ru} 多作插入语，表示“依我看”（§12.5.2）；[по-сво́ему]{.ru} 是“按自己的方式”。

**前缀加形容词的副词。** 这类副词来自“前置词 + 短尾形容词的某一格”，短尾形容词的变格在现代俄语里已经消失，只在副词里留下了格的词尾：[в]{.ru}、[на]{.ru} 加第四格（[-о]{.ru}），[с]{.ru}、[из]{.ru}、[до]{.ru} 加第二格（[-а]{.ru}），[по]{.ru} 加第三格（[-у]{.ru}）。了解这一点，就能理解它们的意义和成对的关系：

1. “往哪里”和“在哪里”：[впра́во, напра́во]{.ru}（往右）— [спра́ва]{.ru}（在右边，从右边来）；[вле́во, нале́во]{.ru} — [сле́ва]{.ru}。[с-]{.ru} 原是“从”，所以 [спра́ва]{.ru} 既是“在右边”，也是“从右边”。地点和方向副词的对应见 §8.1.3。
2. [до-]{.ru} 表示达到某种程度：[до́чиста]{.ru}（干干净净地），[до́суха]{.ru}（干干地），[до́сыта]{.ru}（饱饱地），[допоздна́]{.ru}（直到很晚）。
3. [за-]{.ru} 表示“在……之前”：[за́светло]{.ru}（天黑以前）；[за́ново]{.ru}（重新）。
4. [в-…-ую]{.ru} 来自阴性长尾第四格：[вручну́ю]{.ru}（用手工），[вслепу́ю]{.ru}（盲目地），[вплотну́ю]{.ru}（紧挨着）。

这类副词的重音常落在前缀上（[до́сыта, за́ново, на́скоро, и́здали, и́зредка]{.ru}），要随词记。

**前置词加名词的副词。** 前置词和名词凝固成一个词，失去了名词的性质：[вдали́]{.ru}（在远处），[наверху́]{.ru}（在上面），[впереди́]{.ru}（在前面），[внача́ле]{.ru}（起初）。它们连写；名词带定语或保留名词意义时仍是前置词短语，分写：[вдали́ видне́лся лес]{.ru}（远处隐约可见树林）— [в дали́ тума́нной]{.ru}（在雾蒙蒙的远方）；[Внача́ле бы́ло тру́дно]{.ru}（起初很难）— [в нача́ле го́да]{.ru}（在年初）。连写还是分写见 §1.4.6。

**名词的格和副动词转为副词。** [у́тром, зимо́й, пешко́м]{.ru} 由名词第五格转化而来（§11.1.2），用法在 §8.1.4 讲；带定语时仍是名词（[ра́нним у́тром]{.ru}）。[мо́лча, сто́я, лёжа]{.ru} 由副动词转来，失去了动词的意义（§7.9.6）。

**俄汉差异。** 汉语形容词直接作状语，或加“地”：“快走”“认真地听”；俄语必须把形容词换成副词：[бы́стро идти́, внима́тельно слу́шать]{.ru}。汉语“说汉语”“按中国的方式”在俄语里都是 [по-кита́йски]{.ru}，[кита́йский]{.ru} 只作定语（[кита́йский язы́к]{.ru}）。汉语“右边”一个词兼表“在右边”和“往右边”，俄语分 [спра́ва]{.ru} 和 [напра́во]{.ru}。

[-о]{.ru}、[-е]{.ru} 和 [по-]{.ru} 副词：

::: ex
[Ю́ми поёт о́чень **краси́во**.]{.ru}

[由美唱歌很好听。]{.gloss}

[Он **и́скренне** благодари́л нас.]{.ru}

[他真诚地感谢了我们。]{.gloss}

[Пьер уже́ непло́хо говори́т **по-ру́сски**.]{.ru}

[皮埃尔俄语已经说得不错了。]{.gloss}

[**По-мо́ему**, э́то хоро́шая иде́я.]{.ru}

[依我看，这是个好主意。]{.gloss}

[Она́ **по-пре́жнему** живёт в Москве́.]{.ru}

[她仍旧住在莫斯科。]{.gloss}
:::

前缀加形容词、前置词加名词的副词：

::: ex
[Иди́те пря́мо, пото́м **напра́во**.]{.ru}

[您往前直走，然后往右拐。]{.gloss}

[Апте́ка — **спра́ва** от магази́на.]{.ru}

[药店在商店右边。]{.gloss}

[Мы гуля́ли **допоздна́**.]{.ru}

[我们一直散步到很晚。]{.gloss}

[**Вдали́** видне́лись го́ры.]{.ru}

[远处隐约可见群山。]{.gloss}
:::

### 常见错误

::: err
\*[Она́ поёт о́чень краси́вая.]{.ru}　→　[Она́ поёт о́чень **краси́во**.]{.ru}

修饰动词用副词 [краси́во]{.ru}，不用形容词。汉语“唱得好听”里的“好听”不变形，俄语要换成副词。
:::

::: err
\*[Он говори́т по-кита́йскому.]{.ru}　→　[Он говори́т **по-кита́йски**.]{.ru}

[-ский]{.ru} 形容词构成副词用 [по-…-ски]{.ru}；[по-…-ому]{.ru} 用于其他形容词（[по-но́вому]{.ru}）。
:::

::: err
\*[Он говори́т по ру́сски.]{.ru}　→　[Он говори́т **по-ру́сски**.]{.ru}

[по-…-ски]{.ru}、[по-…-ому]{.ru} 副词写连字符。
:::

::: err
\*[Магази́н нахо́дится напра́во от шко́лы.]{.ru}　→　[Магази́н нахо́дится **спра́ва** от шко́лы.]{.ru}

[напра́во]{.ru}、[впра́во]{.ru} 回答“往哪里”，[спра́ва]{.ru} 回答“在哪里”。指路时 [Поверни́те напра́во]{.ru} 是对的。

## §11.3.6 偶创词与罕见派生词

### 形式

作家按现有的构词规则临时造出、只用于一个文本的词，叫[偶创词]{.term}（[окказионали́зм]{.ru}）。它们用的都是普通的构词方式，下表是教程选文中的例子：

| 词 | 作者 | 构成 | 意思 |
|---|---|---|---|
| [громокипя́щий]{.ru .ix} | 丘特切夫 | 合成法：[гром]{.ru} + [-о-]{.ru} + [кипе́ть]{.ru} 的主动形动词 [кипя́щий]{.ru} | 雷声沸腾的 |
| [изъиздева́юсь]{.ru .ix} | 马雅可夫斯基 | 前缀法：[изъ-]{.ru}（做尽）+ [издева́ться]{.ru} | 嘲弄个够 |
| [огро́мив]{.ru .ix} | 马雅可夫斯基 | 后缀法：[огро́мный]{.ru} → 动词 [-и-]{.ru}（使变成）→ 副动词 [-в]{.ru} | 使变得巨大以后 |
| [любёночек]{.ru .ix} | 马雅可夫斯基 | 后缀法：[любо́вь]{.ru} 的词根 + 指小后缀 [-ён-]{.ru} + [-очек]{.ru} | 小小的爱情 |
| [двадцатидвухле́тний]{.ru} | 马雅可夫斯基 | 合成法（数词 + 名词 + 后缀，§11.3.2） | 二十二岁的 |
| [воспи́тывающе]{.ru .ix} | 契诃夫 | 后缀法：形动词 [воспи́тывающий]{.ru} + [-е]{.ru}（§11.3.5） | 以教育的方式 |
| [всечелове́к]{.ru .ix} | 陀思妥耶夫斯基 | 前缀法：[все-]{.ru} + [челове́к]{.ru} | “全人类的人” |

另一类词不是作家自造的，词典里查得到，只是很少用，叫罕见派生词：[уга́дчик]{.ru .ix}（猜中的人，预见者），[удесятеря́ться]{.ru .ix}（增加到十倍）。它们同样按普通的规则构成：[уга́дчик]{.ru} 是 [угада́ть]{.ru} 加 [-чик]{.ru}（§11.2.1），[удесятеря́ться]{.ru} 是 [де́сять]{.ru} 用前缀后缀法 [у-…-я-…-ся]{.ru} 构成的（比较 [увели́чить]{.ru}，§11.3.3）。

### 意义和用法

**偶创词和新词的区别。** 新词（[ноутбу́к, гу́глить]{.ru}）进入了语言，大家都用，词典迟早要收；偶创词只属于一个作家、一个文本，离开这个文本就不再用。偶创词的作用在于新鲜：读者看到一个从没见过、却一下就能懂的词，会停下来体会它。[громокипя́щий]{.ru} 用一个词同时写出了雷声和沸腾的酒；[изъиздева́юсь]{.ru} 叠用两个“做尽”意义的前缀，写出了嘲弄的猛烈。

偶创词所以能懂，是因为它们用的是语言里现成的构词方式和词缀，意思由各部分加起来。俄语的构词手段很多，规则又有规律，所以俄语文学中偶创词特别多，19 世纪的诗歌和 20 世纪初的未来派诗歌里尤其常见。

**能构成的词和实有的词。** 构词规则说明一个词“可能”怎样构成，但语言里实际有没有这个词，要由习惯决定。[до́брый]{.ru} 按规则可以构成 \*[до́брость]{.ru}，实际用的却是 [доброта́]{.ru}；[чита́ть]{.ru} 可以构成 \*[чита́ние]{.ru}，实际用的是 [чте́ние]{.ru}。作家有意打破这种习惯是修辞手段，学习者自己造的词则是错误。读书时可以用构词规则去理解生词，写作时用的词要在词典里查得到。

**阅读时的分析方法。** 遇到词典里查不到的词，按下面的步骤分析：

1. 找出词尾，确定词类：[-ющий]{.ru} 是形动词，[-ться]{.ru} 是动词，[-е]{.ru} 结尾、不变化的可能是副词。
2. 找出认识的词根，注意语音交替（§11.1.3）和全元音、非全元音的对应。
3. 一层一层剥去前缀和后缀，按本编各节确定每个词缀的意义：[изъ-]{.ru} 是 [из-]{.ru}“做尽”，[-ёночек]{.ru} 是两层指小，[-и-]{.ru} 动词是“使变成”。
4. 把各部分的意义合起来，再放回上下文检验。
5. 19 世纪的作品里，看起来生僻的词可能是旧词或方言词，可查达里（[Даль]{.ru}）的《详解词典》；分析出来的意义和词典不合时，以词典为准。

以 [огро́мив]{.ru} 为例：[-в]{.ru} 是完成体副动词的后缀（§7.9.3），所以前面是一个完成体动词 [огроми́ть]{.ru}；这个动词词典里没有，词根是 [огро́м-]{.ru}，即形容词 [огро́мный]{.ru}；形容词加 [-и-]{.ru} 构成“使具有某种性质”的动词（§11.3.4），所以 [огроми́ть]{.ru} 是“使变得巨大”；放回诗句 [Мир огро́мив мо́щью го́лоса]{.ru}，就是“用声音的威力使世界变得巨大”。

同根词重复的修辞用法（[Ды́мом дыми́тся]{.ru}）见附录十二。

::: ex
[Ты ска́жешь: ве́треная Ге́ба, / Кормя́ Зеве́сова орла́, / **Громокипя́щий** ку́бок с не́ба, / Смея́сь, на зе́млю пролила́.]{.ru}（[Тю́тчев]{.ru}）

[你会说：是轻浮的赫柏，在喂宙斯的神鹰时，笑着把雷声沸腾的酒杯，从天上洒向了人间。（丘特切夫）]{.gloss}

[Мир **огро́мив** мо́щью го́лоса, / иду́ — краси́вый, / **двадцатидвухле́тний**.]{.ru}（[Маяко́вский]{.ru}）

[我用声音的威力把世界变得巨大，我走来——漂亮，二十二岁。（马雅可夫斯基）]{.gloss}
:::

按规则能构成，语言里却不用的词：

::: ex
[Всех удиви́ла его́ **доброта́**.]{.ru}

[他的善良让大家吃惊。]{.gloss}

[**Чте́ние** — моё люби́мое заня́тие.]{.ru}

[读书是我最喜欢的事。]{.gloss}
:::

### 常见错误

::: err
\*[Всех удиви́ла его́ до́брость.]{.ru}　→　[Всех удиви́ла его́ **доброта́**.]{.ru}

[-ость]{.ru} 虽然是最能产的后缀，[до́брый]{.ru} 的抽象名词却是 [доброта́]{.ru}。自己按规则造的词不一定存在，写作时要查词典。
:::

::: err
\*[Э́тот фильм безынтере́сный.]{.ru}　→　[Э́тот фильм **неинтере́сный**.]{.ru}

“没意思的”用 [не-]{.ru}：[неинтере́сный]{.ru}。[без-]{.ru} 加 [интере́с]{.ru} 按规则可以构成形容词，但语言里不用；[небезынтере́сный]{.ru} 是另一个词，意思是“颇有意思的”。
:::
