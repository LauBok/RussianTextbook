性质形容词有比较的等级：原级（[но́вый]{.ru}）、比较级（[нове́е, бо́лее но́вый]{.ru}）和最高级（[са́мый но́вый, нове́йший]{.ru}）。§4.3.1 讲单一式比较级的构成和重音；§4.3.2 讲复合式比较级（[бо́лее, ме́нее]{.ru} 加原级）和 [лу́чший, бо́льший]{.ru} 一类的长尾比较级；§4.3.3 讲比较级的用法：比较对象、程度、表示最高和递增的说法；§4.3.4 讲最高级。副词的比较级与形容词同形，见 §8.1.2；比较从句见 §13.2.12。

## §4.3.1 单一式比较级的构成

### 形式

[比较级]{.term}（[сравни́тельная сте́пень]{.ru}）表示事物的性质比别的事物强或弱，与它相对的普通形式叫[原级]{.term}（[положи́тельная сте́пень]{.ru}）。由形容词词干直接加后缀构成的比较级叫[单一式比较级]{.term}（[проста́я сравни́тельная сте́пень]{.ru}）。单一式比较级不分性、数、格，只有一个形式。构成方法有三种。

**一、词干加 [-ее]{.ru}。** 大多数性质形容词这样构成。口语和诗歌里也说 [-ей]{.ru}（[нове́й, краси́вей]{.ru}）。

| 原级 | 比较级 | 原级 | 比较级 |
|---|---|---|---|
| [краси́вый]{.ru .ix} | [краси́вее]{.ru} | [но́вый]{.ru .ix} | [нове́е]{.ru} |
| [интере́сный]{.ru} | [интере́снее]{.ru} | [тёплый]{.ru} | [тепле́е]{.ru} |
| [поле́зный]{.ru} | [поле́знее]{.ru} | [холо́дный]{.ru} | [холодне́е]{.ru} |
| [серьёзный]{.ru} | [серьёзнее]{.ru} | [дли́нный]{.ru} | [длинне́е]{.ru} |
| [ве́жливый]{.ru} | [ве́жливее]{.ru} | [у́мный]{.ru} | [умне́е]{.ru} |
| [опа́сный]{.ru} | [опа́снее]{.ru} | [весёлый]{.ru} | [веселе́е]{.ru} |
| [свобо́дный]{.ru} | [свобо́днее]{.ru} | [бы́стрый]{.ru} | [быстре́е]{.ru} |
| [и́скренний]{.ru} | [и́скреннее]{.ru} | [си́ний]{.ru} | [сине́е]{.ru} |

**二、词干末辅音交替加 [-е]{.ru}。** 词干以 [г, к, х, д, т, ст]{.ru} 和 [-зк-, -дк-]{.ru} 结尾的形容词，末尾的辅音交替，后缀是不重读的 [-е]{.ru}，重音落在它前面的音节上：

| 交替 | 例词 |
|---|---|
| [г — ж]{.ru} | [дорого́й — доро́же]{.ru .ix key="доро́же"}，[стро́гий — стро́же]{.ru} |
| [к — ч]{.ru} | [лёгкий — ле́гче]{.ru .ix key="ле́гче"}，[кре́пкий — кре́пче]{.ru}，[мя́гкий — мя́гче]{.ru}，[гро́мкий — гро́мче]{.ru}，[жа́ркий — жа́рче]{.ru}，[я́ркий — я́рче]{.ru}，[ме́лкий — ме́льче]{.ru} |
| [х — ш]{.ru} | [ти́хий — ти́ше]{.ru}，[сухо́й — су́ше]{.ru} |
| [д — ж]{.ru} | [молодо́й — моло́же]{.ru .ix key="моло́же"}，[твёрдый — твёрже]{.ru} |
| [т — ч]{.ru} | [бога́тый — бога́че]{.ru}，[круто́й — кру́че]{.ru}，[коро́ткий — коро́че]{.ru} |
| [ст — щ]{.ru} | [просто́й — про́ще]{.ru .ix key="про́ще"}，[чи́стый — чи́ще]{.ru}，[то́лстый — то́лще]{.ru}，[густо́й — гу́ще]{.ru}，[ча́стый — ча́ще]{.ru} |
| [зк — ж]{.ru} | [бли́зкий — бли́же]{.ru}，[ни́зкий — ни́же]{.ru}，[у́зкий — у́же]{.ru} |
| [дк — ж]{.ru}、[дк — щ]{.ru} | [ре́дкий — ре́же]{.ru}，[гла́дкий — гла́же]{.ru}，[жи́дкий — жи́же]{.ru}；[сла́дкий — сла́ще]{.ru} |

有几个词去掉词干的后缀 [-к-, -ок-]{.ru} 再交替：[высо́кий — вы́ше]{.ru .ix key="вы́ше"}，[широ́кий — ши́ре]{.ru}，[глубо́кий — глу́бже]{.ru}；[дешёвый — деше́вле]{.ru} 在 [в]{.ru} 后加 [л]{.ru}。

**三、[-ше]{.ru}。** 少数词加 [-ше]{.ru}：[ра́нний — ра́ньше]{.ru}，[по́здний — по́зже]{.ru}（写作 [-же]{.ru}，也作 [поздне́е]{.ru}），[далёкий — да́льше]{.ru}，[то́нкий — то́ньше]{.ru}，[до́лгий — до́льше]{.ru}，[го́рький — го́рше]{.ru}（“更痛苦”；说味道用 [го́рче]{.ru}）。

**特殊形式。** 下列比较级与原级不同根，或构成不规则，要单独记：

| 原级 | 比较级 | 说明 |
|---|---|---|
| [хоро́ший]{.ru} | [лу́чше]{.ru .ix} | |
| [плохо́й]{.ru} | [ху́же]{.ru .ix} | |
| [большо́й]{.ru} | [бо́льше]{.ru .ix} | 也是 [мно́го]{.ru} 的比较级 |
| [ма́ленький]{.ru} | [ме́ньше]{.ru .ix} | 也是 [ма́ло]{.ru} 的比较级 |
| [ста́рый]{.ru} | [ста́рше]{.ru .ix}；[старе́е]{.ru} | [ста́рше]{.ru} 说年龄、资历，[старе́е]{.ru} 说陈旧 |
| [молодо́й]{.ru} | [моло́же]{.ru}；[мла́дше]{.ru .ix} | [мла́дше]{.ru} 说职位、等级，口语也说年龄 |

各类的全部词表见附录二。

### 意义和用法

**三种构成方法的分工。** [-ее]{.ru} 是能产的构成方法，新的形容词、不常用的形容词都用它（[эффекти́внее, акти́внее, популя́рнее]{.ru}）。[-е]{.ru} 加[辅音交替]{.term}（[чередова́ние согла́сных]{.ru}）只限于词干以 [г, к, х, д, т, ст]{.ru} 结尾的一批常用词，交替的规律与动词变位中的交替相同（[дорого́й — доро́же]{.ru} 像 [бере́чь — бережёшь]{.ru}，[ти́хий — ти́ше]{.ru} 像 [паха́ть — пашу́]{.ru}，见 §7.1.5）。词干以 [г, к, х]{.ru} 结尾的形容词并不都这样变：有的只加 [-ее]{.ru} 或没有单一式（见下文），有的两种形式并存，如 [ло́вкий — ловче́е]{.ru} 和 [ло́вче]{.ru}，[бо́йкий — бойче́е]{.ru} 和 [бо́йче]{.ru}。

**比较级的重音。** 比较级的重音和短尾阴性的重音对应（短尾重音见 §4.2.4）：

1. 短尾阴性重音在词尾的形容词，[-ее]{.ru} 重读：[нова́ — нове́е, умна́ — умне́е, тепла́ — тепле́е, холодна́ — холодне́е, длинна́ — длинне́е, весела́ — веселе́е, быстра́ — быстре́е]{.ru}。
2. 短尾阴性重音在词干的，比较级保留原级的重音：[краси́ва — краси́вее, интере́сна — интере́снее, серьёзна — серьёзнее, ве́жлива — ве́жливее]{.ru}。
3. 例外：少数短尾阴性重音在词干的词，比较级仍重读 [-е́е]{.ru}，如 [здоро́вый — здорове́е]{.ru}，[дре́вний — древне́е]{.ru}，[сро́чный — срочне́е]{.ru}，[ро́зовый — розове́е]{.ru}。
4. [-е]{.ru}、[-ше]{.ru} 两种比较级的重音总在词干上，落在后缀前的音节：[доро́же, ле́гче, моло́же, про́ще, вы́ше, ши́ре, ра́ньше, да́льше]{.ru}。原级重音在词尾的（[дорого́й, молодо́й, просто́й, сухо́й]{.ru}）比较级也移到词干。

**[-ей]{.ru}。** [-ей]{.ru} 和 [-ее]{.ru} 意义相同，重音也相同（[быстре́й, краси́вей]{.ru}），用于口语和诗歌，诗歌里常为凑格律用它（见 §15.3.8）。书面语里写 [-ее]{.ru}。

**前缀 [по-]{.ru}。** 单一式比较级加 [по-]{.ru} 表示“稍微……一点”，多用于口语：[побо́льше, поме́ньше, полу́чше, подеше́вле, поскоре́е, поинтере́снее]{.ru}。这种形式常放在名词后面作定语：[Да́йте мне ко́мнату подеше́вле]{.ru}（给我一间便宜点的房间）。带 [по-]{.ru} 的形式不能与比较对象连用，不说 [\*побо́льше, чем…]{.ru}。

**没有单一式比较级的形容词。** 关系形容词没有比较级（见 §4.1.1）。性质形容词里也有一些没有单一式比较级，或者单一式很少用，比较时用复合式（[бо́лее, ме́нее]{.ru}，见 §4.3.2）：

1. 带后缀 [-ск-]{.ru}、[-ов-]{.ru} 的性质形容词：[дру́жеский, делово́й]{.ru}（[бо́лее дру́жеский]{.ru}）。
2. 由动词过去时构成的 [-лый]{.ru} 形容词：[уста́лый]{.ru}（[бо́лее уста́лый]{.ru}）。
3. 一部分带后缀 [-к-]{.ru} 的形容词：[ро́бкий, кро́ткий, ве́тхий, жесто́кий]{.ru}。

表示绝对性质、本身没有程度差别的词（[босо́й, слепо́й]{.ru}）一般不构成比较级。

**比较级不变化。** 单一式比较级只有一个形式，不随性、数、格变化：[Э́тот дом вы́ше. Э́та ба́шня вы́ше. Э́ти дома́ вы́ше.]{.ru} 它主要作谓语（[Он ста́рше]{.ru}），也作状语修饰动词（[говори́ть ти́ше]{.ru}，这时是副词的比较级，见 §8.1.2），作定语时放在名词后面（[Купи́ кни́гу поинтере́снее]{.ru}，[Я не встреча́л челове́ка добре́е]{.ru}）。放在名词前面作定语要用复合式或长尾比较级，见 §4.3.2。

**俄汉差异。** 汉语没有比较级形式，靠“更”“比……”表示比较：“这本书更有意思”“这本书比那本有意思”。俄语靠形容词本身的形式，不加 [бо́лее]{.ru} 一类的词：[Э́та кни́га интере́снее]{.ru}，不说 [\*Э́та кни́га бо́лее интере́снее]{.ru}。

[-ее]{.ru} 和它的重音：

::: ex
[Сего́дня **холодне́е**, чем вчера́.]{.ru}

[今天比昨天冷。]{.gloss}

[Э́тот фильм **интере́снее**.]{.ru}

[这部电影更有意思。]{.gloss}

[Ле́том в Москве́ **тепле́е**, чем в Петербу́рге.]{.ru}

[夏天莫斯科比彼得堡暖和。]{.gloss}
:::

辅音交替：

::: ex
[В Пеки́не жизнь **доро́же**, чем у нас в го́роде.]{.ru}

[北京的生活比我们城市贵。]{.gloss}

[Говори́те, пожа́луйста, **гро́мче**.]{.ru}

[请大点声说。]{.gloss}

[Э́та зада́ча **про́ще**.]{.ru}

[这道题简单些。]{.gloss}

[Шко́ла **бли́же**, чем университе́т.]{.ru}

[中学比大学近。]{.gloss}
:::

[-ше]{.ru} 和特殊形式：

::: ex
[За́втра я приду́ **ра́ньше**.]{.ru}

[明天我早点来。]{.gloss}

[А́нна **ста́рше** Ми́ши.]{.ru}

[安娜比米沙大。]{.gloss}

[Сего́дня мне **лу́чше**.]{.ru}

[我今天好些了。]{.gloss}

[Э́тот дом **ста́рше** на́шего на сто лет.]{.ru}

[这座房子比我们的房子老一百年。]{.gloss}
:::

[по-]{.ru}：

::: ex
[Да́йте, пожа́луйста, ча́шку **побо́льше**.]{.ru}

[请给我一个大点的杯子。]{.gloss}

[Приходи́ **пора́ньше**.]{.ru}

[早点来。]{.gloss}
:::

### 常见错误

::: err
\*[Э́та кни́га бо́лее интере́снее.]{.ru}　→　[Э́та кни́га **интере́снее**.]{.ru}　或　[Э́та кни́га **бо́лее интере́сная**.]{.ru}

单一式比较级本身就表示“更”，不再加 [бо́лее]{.ru}；[бо́лее]{.ru} 只加在原级上，见 §4.3.2。
:::

::: err
\*[Сего́дня холо́днее.]{.ru}　→　[Сего́дня **холодне́е**.]{.ru}

[холо́дный]{.ru} 的短尾阴性是 [холодна́]{.ru}，比较级重读 [-е́е]{.ru}。
:::

::: err
\*[Э́та у́лица широче́е.]{.ru}　→　[Э́та у́лица **ши́ре**.]{.ru}

[широ́кий]{.ru} 去掉后缀 [-ок-]{.ru}，比较级是 [ши́ре]{.ru}；同样 [высо́кий — вы́ше]{.ru}，[глубо́кий — глу́бже]{.ru}。
:::

::: err
\*[Он старе́е меня́.]{.ru}　→　[Он **ста́рше** меня́.]{.ru}

说人的年龄用 [ста́рше]{.ru}。[старе́е]{.ru} 说东西更旧。
:::

## §4.3.2 复合式比较级与长尾比较级

### 形式

[复合式比较级]{.term}（[составна́я сравни́тельная сте́пень]{.ru}）由 [бо́лее]{.ru .ix}（更）或 [ме́нее]{.ru .ix}（较不）加原级构成。[бо́лее, ме́нее]{.ru} 不变，形容词照常变化，可以是长尾，也可以是短尾：

::: paradigm
| 格 | 阳性 | 阴性 | 中性 | 复数 |
|---|---|---|---|---|
| 第一格 | [бо́лее интере́сный]{.ru} | [бо́лее интере́сная]{.ru} | [бо́лее интере́сное]{.ru} | [бо́лее интере́сные]{.ru} |
| 第二格 | [бо́лее интере́сного]{.ru} | [бо́лее интере́сной]{.ru} | [бо́лее интере́сного]{.ru} | [бо́лее интере́сных]{.ru} |
| 第六格 | [о бо́лее интере́сном]{.ru} | [о бо́лее интере́сной]{.ru} | [о бо́лее интере́сном]{.ru} | [о бо́лее интере́сных]{.ru} |
| 短尾 | [бо́лее интере́сен]{.ru} | [бо́лее интере́сна]{.ru} | [бо́лее интере́сно]{.ru} | [бо́лее интере́сны]{.ru} |
:::

其余各格依此类推。[ме́нее]{.ru} 同样：[ме́нее интере́сный, ме́нее интере́сна]{.ru}。

有八个形容词另有按长尾变格的比较级，即[长尾比较级]{.term}（[по́лная фо́рма сравни́тельной сте́пени]{.ru}）：

| 原级 | 单一式比较级 | 长尾比较级 |
|---|---|---|
| [большо́й]{.ru} | [бо́льше]{.ru} | [бо́льший]{.ru .ix} |
| [ма́ленький]{.ru} | [ме́ньше]{.ru} | [ме́ньший]{.ru .ix} |
| [хоро́ший]{.ru} | [лу́чше]{.ru} | [лу́чший]{.ru .ix} |
| [плохо́й]{.ru} | [ху́же]{.ru} | [ху́дший]{.ru .ix} |
| [ста́рый]{.ru} | [ста́рше]{.ru} | [ста́рший]{.ru .ix} |
| [молодо́й]{.ru} | [мла́дше]{.ru} | [мла́дший]{.ru .ix} |
| [высо́кий]{.ru} | [вы́ше]{.ru} | [вы́сший]{.ru .ix} |
| [ни́зкий]{.ru} | [ни́же]{.ru} | [ни́зший]{.ru .ix} |

长尾比较级按 [хоро́ший]{.ru} 一类的混合变化变格（见 §4.1.2），重音固定在词干：[бо́льшего, бо́льшей, бо́льшим; лу́чшего, лу́чшей, лу́чшие]{.ru}。

### 意义和用法

**复合式比较级的用法。** 复合式比较级和单一式意义相同，区别在用法和语体：

1. **作定语。** 单一式不变格，不能放在名词前作定语；需要“更……的”作定语时用复合式：[бо́лее интере́сная кни́га]{.ru}，[в бо́лее тёплом кли́мате]{.ru}，[для бо́лее серьёзной рабо́ты]{.ru}。
2. **语体。** 作谓语时两种都可以用，复合式带书面色彩：口语说 [Э́та кни́га интере́снее]{.ru}，书面也写 [Э́та кни́га бо́лее интере́сна]{.ru}。
3. **没有单一式或单一式少用的形容词**用复合式：[бо́лее дру́жеский, бо́лее уста́лый]{.ru}（见 §4.3.1）。
4. **[ме́нее]{.ru}。** “较不……”只能用 [ме́нее]{.ru} 表示，没有单一式的对应形式：[ме́нее изве́стный а́втор]{.ru}（不那么出名的作者），[Э́тот путь ме́нее опа́сен]{.ru}。口语里常改说 [не тако́й…]{.ru} 或换用反义词的比较级：[Э́тот путь не тако́й опа́сный]{.ru}，[Э́тот путь безопа́снее]{.ru}。
5. **比较对象只用 [чем]{.ru}**，不用第二格：[Э́та кни́га бо́лее интере́сна, чем та]{.ru}，不说 [\*бо́лее интере́сна той]{.ru}（见 §4.3.3）。

**[бо́лее]{.ru} 与 [бо́льше]{.ru}。** [бо́льше]{.ru} 是 [большо́й]{.ru} 和 [мно́го]{.ru} 的比较级，意思是“更大”“更多”：[Наш дом бо́льше]{.ru}，[Он рабо́тает бо́льше меня́]{.ru}，[бо́льше де́нег]{.ru}。[бо́лее]{.ru} 主要是构成复合式比较级的虚化成分，放在形容词、副词前面：[бо́лее ва́жный, бо́лее подро́бно]{.ru}。用在数词前表示“……以上”时两个都可以，[бо́лее]{.ru} 是书面的，[бо́льше]{.ru} 是中性的：[бо́лее ста челове́к]{.ru} 和 [бо́льше ста челове́к]{.ru}。[бо́лее]{.ru} 还用在固定的说法里：[бо́лее и́ли ме́нее]{.ru}（多多少少），[тем бо́лее]{.ru}（何况，尤其），[бо́лее того́]{.ru}（不仅如此），[не бо́лее чем]{.ru}（不过是），[сто и бо́лее]{.ru}（一百以上）。口语把 [бо́льше]{.ru} 放在形容词前（[\*бо́льше ва́жный]{.ru}）是俗语，规范的说法是 [бо́лее ва́жный]{.ru} 或 [важне́е]{.ru}。

**长尾比较级。** 这八个词是古代比较级的长尾形式，现在的意义各不相同：

- [бо́льший, ме́ньший]{.ru} 只表示比较级：“更大的”“更小的”：[с бо́льшим интере́сом]{.ru}（带着更大的兴趣），[бо́льшая часть]{.ru}（大部分），[по ме́ньшей ме́ре]{.ru}（至少），[ме́ньшее зло]{.ru}（两害之轻者）。注意重音：[бо́льшая]{.ru}（更大的）和 [больша́я]{.ru}（大的）只靠重音区分。
- [лу́чший, ху́дший]{.ru} 既表示比较级“更好的”（[в по́исках лу́чшей жи́зни]{.ru}，寻求更好的生活），也表示最高级“最好的”（[мой лу́чший друг]{.ru}），后一种更常用，见 §4.3.4。
- [ста́рший, мла́дший]{.ru} 表示年龄、辈分、职位上“较大的、较小的”，在多个人里则是“最大的、最小的”：[ста́рший брат]{.ru}（哥哥），[мла́дшая сестра́]{.ru}（妹妹），[ста́рший сын]{.ru}（长子），[ста́рший нау́чный сотру́дник]{.ru}（高级研究员），[мла́дшие кла́ссы]{.ru}（低年级）。
- [вы́сший, ни́зший]{.ru} 多用于“高级的、低级的”“最高的、最低的”：[вы́сшее образова́ние]{.ru}（高等教育），[вы́сшая шко́ла]{.ru}（高等学校），[вы́сшая то́чка]{.ru}（最高点），[ни́зшие органи́змы]{.ru}（低等生物）。说具体的高低用 [бо́лее высо́кий]{.ru}：[бо́лее высо́кий дом]{.ru}，不说 [\*вы́сший дом]{.ru}。

**叠用是错误。** 比较的意思只表示一次：复合式由 [бо́лее]{.ru} 加原级构成，不能加在单一式比较级上（[\*бо́лее краси́вее, \*бо́лее лу́чше]{.ru}），也不能加在长尾比较级上：[бо́лее вы́сший]{.ru} 一类的叠用见于旧时的作品和俗语，现代规范不用，应说 [вы́сший]{.ru} 或 [бо́лее высо́кий]{.ru}。

**俄汉差异。** 汉语的“更”可以放在任何形容词前面；俄语的比较级有单一式和复合式两套，单一式不能作前置定语，复合式和单一式不能叠用。汉语“不那么……”“没有……那么……”，俄语书面用 [ме́нее]{.ru}，口语多用 [не тако́й…, как…]{.ru}。

作定语：

::: ex
[Нам ну́жен **бо́лее просто́рный** зал.]{.ru}

[我们需要一个更宽敞的大厅。]{.gloss}

[Мы перее́хали в **бо́лее тёплый** го́род.]{.ru}

[我们搬到了一个更暖和的城市。]{.gloss}
:::

作谓语和 [ме́нее]{.ru}：

::: ex
[Второ́й ме́тод **бо́лее эффекти́вен**, чем пе́рвый.]{.ru}

[第二种方法比第一种有效。]{.gloss}

[Э́тот рома́н **ме́нее изве́стен**.]{.ru}

[这部长篇小说没那么出名。]{.gloss}
:::

[бо́лее]{.ru} 与 [бо́льше]{.ru}：

::: ex
[На конце́рт пришло́ **бо́льше** ста челове́к.]{.ru}

[音乐会来了一百多人。]{.gloss}

[Он не пришёл, и, **бо́лее того́**, да́же не позвони́л.]{.ru}

[他没来，不仅如此，连电话都没打。]{.gloss}
:::

长尾比较级：

::: ex
[**Бо́льшая** часть студе́нтов живёт в общежи́тии.]{.ru}

[大部分学生住在宿舍里。]{.gloss}

[Э́то мой **ста́рший** брат, а э́то **мла́дшая** сестра́.]{.ru}

[这是我哥哥，这是我妹妹。]{.gloss}

[У него́ **вы́сшее** образова́ние.]{.ru}

[他受过高等教育。]{.gloss}

[Мы наде́емся на **лу́чшее**.]{.ru}

[我们希望情况会好起来。]{.gloss}
:::

### 常见错误

::: err
\*[Она́ ста́ла бо́лее краси́вее.]{.ru}　→　[Она́ ста́ла **краси́вее**.]{.ru}　或　[Она́ ста́ла **бо́лее краси́вой**.]{.ru}

[краси́вее]{.ru} 已经是比较级，不能再加 [бо́лее]{.ru}。
:::

::: err
\*[Я хочу́ купи́ть деше́вле телефо́н.]{.ru}　→　[Я хочу́ купи́ть телефо́н **подеше́вле**.]{.ru}　或　[…**бо́лее дешёвый** телефо́н.]{.ru}

单一式比较级不能放在名词前作定语；放在名词后（常加 [по-]{.ru}）或改用复合式。
:::

::: err
\*[Э́то бо́лее лу́чший вариа́нт.]{.ru}　→　[Э́то **лу́чший** вариа́нт.]{.ru}

[лу́чший]{.ru} 本身就是比较级（最高级），前面不加 [бо́лее]{.ru}。同样不说 [\*бо́лее вы́сший]{.ru}。
:::

::: err
\*[Он прочита́л больши́ую часть кни́ги.]{.ru}　→　[Он прочита́л **бо́льшую** часть кни́ги.]{.ru}

“大部分”是 [бо́льшая часть]{.ru}，长尾比较级重音在词干，按 [хоро́ший]{.ru} 一类变：[бо́льшую]{.ru}。
:::

## §4.3.3 比较级的用法

### 意义和用法

**比较对象的两种表示法。** 比较级后面说出“和谁比”的部分叫[比较对象]{.term}（[предме́т сравне́ния]{.ru}）。比较对象有两种表示法：

1. **[чем]{.ru} 加与被比较的词同格的形式**，[чем]{.ru} 前加逗号：[Москва́ бо́льше, чем Петербу́рг]{.ru}（两个第一格），[В Пеки́не тепле́е, чем в Москве́]{.ru}（两个 [в]{.ru} 加第六格），[Ле́том здесь лу́чше, чем зимо́й]{.ru}（两个副词）。[чем]{.ru} 引出的部分实际上是一个省略了谓语的[比较从句]{.term}（[прида́точное сравни́тельное]{.ru}），所以也可以是完整的分句：[Он сде́лал бо́льше, чем мы ду́мали]{.ru}（见 §13.2.12）。
2. **第二格**，不用 [чем]{.ru}，不加逗号：[Москва́ бо́льше Петербу́рга]{.ru}，[Брат ста́рше сестры́]{.ru}。

**什么时候能用第二格。** 第二格只能代替 [чем]{.ru} 加第一格（有时加不带前置词的第四格）的比较对象，其余情况都用 [чем]{.ru}：

| 被比较的成分 | 用第二格 | 用 [чем]{.ru} |
|---|---|---|
| 第一格（主语） | [Брат ста́рше сестры́.]{.ru} | [Брат ста́рше, чем сестра́.]{.ru} |
| 不带前置词的第四格 | [Я люблю́ чай бо́льше ко́фе.]{.ru}（可用，但可能有歧义） | [Я люблю́ чай бо́льше, чем ко́фе.]{.ru} |
| 其他格、前置词短语 | — | [Мне трудне́е, чем тебе́.]{.ru}　[В Москве́ холодне́е, чем в Пеки́не.]{.ru} |
| 副词、不定式、分句 | — | [Сего́дня лу́чше, чем вчера́.]{.ru}　[Лу́чше по́здно, чем никогда́.]{.ru} |
| 复合式比较级 | — | [Э́тот путь бо́лее опа́сен, чем тот.]{.ru} |

被比较的是第四格时用第二格容易产生歧义（[Он лю́бит сестру́ бо́льше бра́та]{.ru}：是“他爱妹妹胜过爱弟弟”，还是“他比弟弟更爱妹妹”？），所以第四格的比较多用 [чем]{.ru}，并且由同格显出意思：[бо́льше, чем бра́та]{.ru}（胜过爱弟弟）和 [бо́льше, чем брат]{.ru}（比弟弟爱得多）。被比较的两个都是第一格时，第二格和 [чем]{.ru} 都可以用，第二格更简洁，口语和书面语都很常用。

第二格还用于比较级后面的数量：[бо́льше ста рубле́й]{.ru}（一百多卢布），[не бо́льше ча́са]{.ru}（不超过一小时），[глу́бже ста ме́тров]{.ru}（深过一百米），[ме́ньше го́да]{.ru}（不到一年）。

**比较级后的人称代词不加 [н-]{.ru}。** 比较对象是第三人称代词时用第二格 [его́, её, их]{.ru}，不加 [н-]{.ru}：[Ми́ша моло́же её]{.ru}，[Я ста́рше его́ на год]{.ru}。比较级不是前置词，所以按规范不加 [н-]{.ru}（加 [н-]{.ru} 的规则见 §5.1.2）；口语里也能听到 [ста́рше него́]{.ru}，书面上不用。

**表示程度。** 比较级前面不能用 [о́чень]{.ru}。表示“……得多”“稍微……”等程度用下面的词：

| 说法 | 意义 | 例子 |
|---|---|---|
| [гора́здо, намно́го]{.ru} | ……得多 | [гора́здо лу́чше, намно́го доро́же]{.ru} |
| [куда́]{.ru}（口语） | ……得多 | [Здесь куда́ ти́ше]{.ru} |
| [значи́тельно]{.ru}（书面） | 明显地 | [значи́тельно вы́ше]{.ru} |
| [ещё]{.ru} | 更加，还要 | [А Пеки́н ещё бо́льше]{.ru} |
| [немно́го, чуть, чуть-чу́ть]{.ru} | 稍微 | [немно́го ста́рше, чуть быстре́е]{.ru} |
| [ничу́ть не, ниско́лько не]{.ru} | 一点也不 | [ничу́ть не ху́же]{.ru} |
| [на]{.ru} 加第四格 | 差额 | [на два го́да ста́рше, на пять сантиме́тров вы́ше]{.ru} |
| [в]{.ru} 加 [раз]{.ru} | 倍数 | [в два ра́за бо́льше]{.ru}（见 §6.3.4） |

[ещё]{.ru} 和 [гора́здо]{.ru} 不同：[ещё]{.ru} 预先承认被比较的一方也具有这种性质（[Москва́ больша́я, а Пеки́н ещё бо́льше]{.ru}，莫斯科大，北京更大），[гора́здо]{.ru} 只说差别大。差额用 [на]{.ru} 加第四格，对应汉语“大两岁”“高五厘米”的数量补语。

**比较级加 [всех, всего́]{.ru} 表示最高。** 比较级加 [всех]{.ru}（和所有的人、物比）、[всего́]{.ru}（和一切比）表示“最……”：[Ми́ша бе́гает быстре́е всех]{.ru}（米沙跑得最快），[Здоро́вье доро́же всего́]{.ru}（健康比什么都宝贵），[Бо́льше всего́ я люблю́ футбо́л]{.ru}（我最喜欢足球）。[всех]{.ru} 指同类的人或物，[всего́]{.ru} 指一切事物或情况。这是副词和动词表示“最”的主要手段，因为 [са́мый]{.ru} 只能修饰形容词（见 §4.3.4）。

**[как мо́жно]{.ru} 加比较级。** 表示“尽可能……”：[как мо́жно скоре́е]{.ru}（尽快），[Приходи́ как мо́жно ра́ньше]{.ru}，[Пиши́те как мо́жно подро́бнее]{.ru}。

**[всё]{.ru} 加比较级。** 表示“越来越……”：[Стано́вится всё холодне́е]{.ru}，[Он прихо́дит всё ре́же]{.ru}。加强时重复比较级：[всё бо́льше и бо́льше]{.ru}。汉语的“越来越”对应 [всё]{.ru}（加比较级），“越……越……”对应 [чем…, тем…]{.ru}（[Чем ра́ньше, тем лу́чше]{.ru}，越早越好），后者见 §13.2.12。

**比较级的其他用法。** 比较级作无人称句的谓语：[Сего́дня тепле́е]{.ru}，[Больно́му ста́ло лу́чше]{.ru}。[лу́чше]{.ru} 还构成插入语 [лу́чше сказа́ть]{.ru}（确切些说）和表示愿望、建议的说法：[Лу́чше бы ты пришёл ра́ньше]{.ru}（你要是早点来就好了），[Лу́чше спроси́ преподава́теля]{.ru}（最好问问老师）。

**俄汉差异。** 汉语的比较句是“A 比 B + 形容词”，“比 B”放在形容词前；俄语比较对象放在比较级后面：[А́нна ста́рше Ми́ши]{.ru}。汉语“我没有他高”，俄语一般说 [Я ни́же его́]{.ru} 或 [Я не тако́й высо́кий, как он]{.ru}。

比较对象：

::: ex
[Во́лга длинне́е, чем Днепр.]{.ru}

[伏尔加河比第聂伯河长。]{.gloss}

[Во́лга длинне́е **Днепра́**.]{.ru}

[伏尔加河比第聂伯河长。]{.gloss}

[У нас в го́роде зимо́й холодне́е, **чем в Москве́**.]{.ru}

[我们城市冬天比莫斯科冷。]{.gloss}

[А́нна говори́т по-ру́сски лу́чше, **чем я**.]{.ru}

[安娜俄语说得比我好。]{.gloss}
:::

人称代词：

::: ex
[Ми́ша моло́же **её**.]{.ru}

[米沙比她小。]{.gloss}

[Он зараба́тывает бо́льше **их**.]{.ru}

[他挣得比他们多。]{.gloss}
:::

程度：

::: ex
[Сего́дня мне **гора́здо** лу́чше.]{.ru}

[我今天好多了。]{.gloss}

[Брат ста́рше меня́ **на три го́да**.]{.ru}

[哥哥比我大三岁。]{.gloss}

[Ле́кция ко́нчилась **чуть** ра́ньше.]{.ru}

[讲座结束得稍早一点。]{.gloss}
:::

[всех, всего́]{.ru}：

::: ex
[Ю́ми пи́шет дикта́нты лу́чше **всех**.]{.ru}

[由美听写写得最好。]{.gloss}

[Бо́льше **всего́** Ван Лэй лю́бит пельме́ни.]{.ru}

[王磊最爱吃饺子。]{.gloss}
:::

[как мо́жно]{.ru} 和 [всё]{.ru}：

::: ex
[Позвони́ мне **как мо́жно** скоре́е.]{.ru}

[尽快给我打电话。]{.gloss}

[Дни стано́вятся **всё** коро́че.]{.ru}

[白天越来越短。]{.gloss}
:::

### 常见错误

::: err
\*[Сего́дня о́чень холодне́е.]{.ru}　→　[Сего́дня **гора́здо** холодне́е.]{.ru}

[о́чень]{.ru} 不修饰比较级；“……得多”用 [гора́здо, намно́го]{.ru}。
:::

::: err
\*[В Пеки́не тепле́е Москвы́.]{.ru}　→　[В Пеки́не тепле́е, **чем в Москве́**.]{.ru}

被比较的是 [в Пеки́не]{.ru}（前置词短语），比较对象也要用 [в]{.ru} 加第六格，只能用 [чем]{.ru}。
:::

::: err
\*[Он ста́рше меня́ два го́да.]{.ru}　→　[Он ста́рше меня́ **на** два го́да.]{.ru}

差额用 [на]{.ru} 加第四格，不能像汉语“大两岁”那样直接接数量。
:::

::: err
\*[Мой брат вы́ше, чем него́.]{.ru}　→　[Мой брат вы́ше, **чем он**.]{.ru}　或　[Мой брат вы́ше **его́**.]{.ru}

[чем]{.ru} 后用与被比较的词同格的形式（这里是第一格）；用第二格时不加 [чем]{.ru}，也不加 [н-]{.ru}。
:::

## §4.3.4 最高级

### 形式

[最高级]{.term}（[превосхо́дная сте́пень]{.ru}）表示性质在一群事物中最强。最高级分复合式和单一式两种。

[复合式最高级]{.term}（[составна́я превосхо́дная сте́пень]{.ru}）由 [са́мый]{.ru .ix} 加原级构成；[са́мый]{.ru} 和形容词一起与名词在性、数、格上一致：

::: paradigm
| 格 | 阳性 | 阴性 | 复数 |
|---|---|---|---|
| 第一格 | [са́мый большо́й го́род]{.ru} | [са́мая высо́кая гора́]{.ru} | [са́мые бли́зкие лю́ди]{.ru} |
| 第二格 | [са́мого большо́го го́рода]{.ru} | [са́мой высо́кой горы́]{.ru} | [са́мых бли́зких люде́й]{.ru} |
| 第六格 | [в са́мом большо́м го́роде]{.ru} | [на са́мой высо́кой горе́]{.ru} | [о са́мых бли́зких лю́дях]{.ru} |
:::

书面语也用 [наибо́лее]{.ru .ix}（最）、[наиме́нее]{.ru}（最不）加原级，[наибо́лее]{.ru} 不变：[наибо́лее ва́жная зада́ча, наибо́лее ва́жные зада́чи]{.ru}。

[单一式最高级]{.term}（[проста́я превосхо́дная сте́пень]{.ru}）由词干加后缀 [-ейш-]{.ru}、[-айш-]{.ru} 构成，按 [хоро́ший]{.ru} 一类的混合变化变格（见 §4.1.2）：

| 原级 | 单一式最高级 | 原级 | 单一式最高级 |
|---|---|---|---|
| [но́вый]{.ru} | [нове́йший]{.ru .ix} | [интере́сный]{.ru} | [интере́снейший]{.ru .ix} |
| [ва́жный]{.ru} | [важне́йший]{.ru} | [краси́вый]{.ru} | [краси́вейший]{.ru} |
| [у́мный]{.ru} | [умне́йший]{.ru} | [бога́тый]{.ru} | [богате́йший]{.ru} |
| [кру́пный]{.ru} | [крупне́йший]{.ru} | [ма́лый]{.ru} | [мале́йший]{.ru} |
| [сло́жный]{.ru} | [сложне́йший]{.ru} | [просто́й]{.ru} | [просте́йший]{.ru} |
| [вели́кий]{.ru} | [велича́йший]{.ru .ix} | [высо́кий]{.ru} | [высоча́йший]{.ru} |
| [глубо́кий]{.ru} | [глубоча́йший]{.ru} | [широ́кий]{.ru} | [широча́йший]{.ru} |
| [стро́гий]{.ru} | [строжа́йший]{.ru} | [ти́хий]{.ru} | [тиша́йший]{.ru} |
| [бли́зкий]{.ru} | [ближа́йший]{.ru} | [кра́ткий]{.ru} | [кратча́йший]{.ru} |

此外，[лу́чший, ху́дший, вы́сший, ни́зший]{.ru}（见 §4.3.2）也作最高级用；书面语加前缀 [наи-]{.ru} 加强：[наилу́чший, наивы́сший, наиху́дший, наиважне́йший]{.ru}。

### 意义和用法

**[са́мый]{.ru} 加原级。** 这是最常用、语体上中性的最高级，作定语和谓语都可以：[са́мый тру́дный ме́сяц]{.ru}，[Э́тот ме́сяц — са́мый тру́дный]{.ru}。[са́мый]{.ru} 只能加在长尾形容词上，不能加在短尾、副词和动词上。[са́мый]{.ru} 作代词表示“正是、紧挨”的意义见 §5.4.2。

**[наибо́лее]{.ru} 加原级。** 书面语，多见于科学、公文语体：[наибо́лее распространённая оши́бка]{.ru}（最常见的错误）。[наибо́лее]{.ru} 和 [са́мый]{.ru} 不同，可以加在短尾和副词上：[Э́тот вариа́нт наибо́лее удо́бен]{.ru}，[наибо́лее по́лно]{.ru}。

**单一式最高级的构成和重音。** [-ейш-]{.ru} 加在大多数词干上；词干以 [г, к, х]{.ru} 结尾的，交替为 [ж, ч, ш]{.ru}，后缀用 [-айш-]{.ru}。重音规律：

1. [-а́йш-]{.ru} 总是重读：[велича́йший, высоча́йший, строжа́йший]{.ru}。
2. [-ейш-]{.ru} 的重音与比较级 [-ее]{.ru} 对应：比较级重读 [-е́е]{.ru} 的，最高级重读 [-е́йш-]{.ru}（[нове́е — нове́йший, умне́е — умне́йший]{.ru}）；比较级重音在词干的，最高级也在词干（[интере́снее — интере́снейший, краси́вее — краси́вейший]{.ru}）。个别例外：[бога́че — богате́йший]{.ru}。

单一式最高级不是每个形容词都有，能不能构成要查词典；没有的就用 [са́мый]{.ru} 或 [наибо́лее]{.ru}。

**单一式最高级的意义。** 单一式最高级多半不是在一群事物中比较，而是表示程度极高，相当于汉语“极其……”“非常……”：[интере́снейшая кни́га]{.ru}（一本极有意思的书），[Э́то важне́йший вопро́с]{.ru}（这是个极其重要的问题），[добре́йший челове́к]{.ru}（非常善良的人）。带范围时它也表示真正的最高：[крупне́йший го́род страны́]{.ru}（全国最大的城市），[оди́н из крупне́йших учёных]{.ru}（最大的学者之一）。单一式最高级有书面色彩，口语里用得少，固定说法除外：[в кратча́йший срок]{.ru}（以最短的时间），[ближа́йшая апте́ка]{.ru}（最近的药店），[не име́ть ни мале́йшего поня́тия]{.ru}（一点概念也没有）。

**[лу́чший, ху́дший, вы́сший, ни́зший]{.ru}。** 作最高级用时不加 [са́мый]{.ru}：[мой лу́чший друг]{.ru}，[ху́дший вариа́нт]{.ru}，[вы́сшая награ́да]{.ru}。口语加强说 [са́мый лу́чший, са́мый ху́дший]{.ru}，是通行的说法，书面语一般不用。[са́мый]{.ru} 不加在单一式最高级上：[са́мый интере́снейший]{.ru} 是俗语，规范里不用。

**比较级加 [всех, всего́]{.ru}。** 见 §4.3.3：[Он умне́е всех]{.ru}（他最聪明）。副词和动词没有 [са́мый]{.ru} 式的最高级，“跑得最快”“最喜欢”只能这样说：[бе́гает быстре́е всех]{.ru}，[бо́льше всего́ лю́бит]{.ru}。

**范围。** 在什么范围里“最”，用：

1. [из]{.ru} 加复数第二格：[са́мый высо́кий из нас]{.ru}，[лу́чший из всех]{.ru}。
2. [в]{.ru}（[на]{.ru}）加第六格：[са́мое глубо́кое о́зеро в ми́ре]{.ru}，[лу́чший студе́нт в гру́ппе]{.ru}，[лу́чший на све́те]{.ru}。
3. [среди́]{.ru} 加第二格：[са́мый изве́стный среди́ ру́сских поэ́тов]{.ru}。
4. 不带前置词的第二格：[са́мый жа́ркий день го́да]{.ru}，[крупне́йший го́род страны́]{.ru}。

“……之一”用 [оди́н из]{.ru} 加最高级的复数第二格：[оди́н из са́мых краси́вых городо́в Росси́и]{.ru}，[оди́н]{.ru} 与所指的名词性别一致，谓语用单数，见 §5.4.4。

**俄汉差异。** 汉语的“最”可以修饰形容词、动词和副词（“最高”“最喜欢”“跑得最快”）；俄语 [са́мый]{.ru} 只修饰长尾形容词，动词和副词用比较级加 [всех, всего́]{.ru}。汉语“极其”“非常”有时对应俄语的单一式最高级，书面语里用得较多。

[са́мый]{.ru} 和范围：

::: ex
[Байка́л — **са́мое глубо́кое** о́зеро в ми́ре.]{.ru}

[贝加尔湖是世界上最深的湖。]{.gloss}

[Мы живём в **са́мом большо́м** до́ме на у́лице.]{.ru}

[我们住在这条街上最大的楼里。]{.gloss}

[Пьер — **са́мый высо́кий** из нас.]{.ru}

[皮埃尔是我们当中个子最高的。]{.gloss}
:::

[наибо́лее]{.ru}：

::: ex
[Э́то **наибо́лее** ва́жная часть рабо́ты.]{.ru}

[这是工作中最重要的部分。]{.gloss}

[Тако́е реше́ние **наибо́лее** удо́бно для всех.]{.ru}

[这样的决定对大家最方便。]{.gloss}
:::

单一式最高级：

::: ex
[Э́то **интере́снейшая** кни́га.]{.ru}

[这是一本极有意思的书。]{.gloss}

[Шанха́й — **крупне́йший** порт Кита́я.]{.ru}

[上海是中国最大的港口。]{.gloss}

[Где **ближа́йшая** апте́ка?]{.ru}

[最近的药店在哪儿？]{.gloss}
:::

[лу́чший]{.ru} 作最高级：

::: ex
[Ми́ша — мой **лу́чший** друг.]{.ru}

[米沙是我最好的朋友。]{.gloss}

[Ле́то — **са́мое лу́чшее** вре́мя го́да!]{.ru}

[夏天是一年中最好的季节！]{.gloss}
:::

动词和副词的“最”：

::: ex
[Кто в ва́шей гру́ппе говори́т по-ру́сски **лу́чше всех**?]{.ru}

[你们班谁俄语说得最好？]{.gloss}

[Я **бо́льше всего́** люблю́ о́сень.]{.ru}

[我最喜欢秋天。]{.gloss}
:::

### 常见错误

::: err
\*[Я са́мый люблю́ футбо́л.]{.ru}　→　[Я **бо́льше всего́** люблю́ футбо́л.]{.ru}

汉语“最喜欢”的“最”修饰动词；俄语 [са́мый]{.ru} 只修饰形容词，动词用 [бо́льше всего́]{.ru}。
:::

::: err
\*[Он бе́гает са́мый бы́стро.]{.ru}　→　[Он бе́гает **быстре́е всех**.]{.ru}

副词没有 [са́мый]{.ru} 式的最高级，用比较级加 [всех]{.ru}。
:::

::: err
\*[Э́то са́мый краси́вее парк.]{.ru}　→　[Э́то **са́мый краси́вый** парк.]{.ru}

[са́мый]{.ru} 加原级，不加比较级。
:::

::: err
\*[Пьер — са́мый высо́кий в нас.]{.ru}　→　[Пьер — са́мый высо́кий **из нас**.]{.ru}

在一群人、物当中“最”，用 [из]{.ru} 加复数第二格；[в]{.ru} 加第六格说的是在某个处所、集体里（[в ми́ре, в гру́ппе]{.ru}）。
:::
