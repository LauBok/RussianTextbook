[派生前置词]{.term}（[произво́дный предло́г]{.ru}）是由副词、副动词、名词转来的前置词，形式上还看得出原来的词，意义也比原生前置词具体、单一。按来源分为[副词性前置词]{.term}（[отнаре́чный предло́г]{.ru}）、[副动词性前置词]{.term}（[отглаго́льный предло́г]{.ru}）和[名词性前置词]{.term}（[отымённый предло́г]{.ru}）三类（§9.1.1）；按构成，有的是一个词，叫[简单前置词]{.term}（[просто́й предло́г]{.ru}），如 [ввиду́, благодаря́]{.ru}，有的由几个词组成，叫[复合前置词]{.term}（[составно́й предло́г]{.ru}），如 [в тече́ние, несмотря́ на, по сравне́нию с]{.ru}。本章 §9.5.1 讲副词性和副动词性前置词，§9.5.2 讲名词性前置词。它们的意义大多已在第 2–4 章按意义讲过，本章讲它们作为一类词的共同特点：怎样与原来的词区分，要求什么格，怎样写，用在什么语体里。

## §9.5.1 副词性前置词和副动词性前置词

### 形式

副词性前置词按所要求的格列出如下。有些前置词由副词加一个原生前置词构成，格由后面的原生前置词决定。

| 格 | 前置词 | 意义 |
|---|---|---|
| 第二格 | [о́коло, во́зле, вокру́г, напро́тив]{.ru} | 附近，旁边，周围，对面（§9.2.3） |
| | [ми́мо, вдоль]{.ru} | 经过，沿着（§9.2.5） |
| | [вблизи́]{.ru .ix} | 在……附近（书面） |
| | [впереди́]{.ru .ix}，[позади́]{.ru .ix} | 在……前面，在……后面 |
| | [внутри́]{.ru .ix}，[внутрь]{.ru .ix} | 在……里面，到……里面去 |
| | [среди́]{.ru .ix}，[посреди́]{.ru .ix} | 在……中间，在……正中 |
| | [по́сле, накану́не]{.ru} | 以后，前夕（§9.3.3） |
| | [кро́ме, поми́мо, вме́сто, вне]{.ru} | 除了，代替，在……以外（§9.4.4） |
| | [сверх]{.ru .ix}，[свы́ше]{.ru .ix} | 超出，……以上 |
| 第三格 | [навстре́чу]{.ru .ix} | 迎着，迎面 |
| | [вслед]{.ru .ix} | 跟在……后面（目送） |
| | [согла́сно, соотве́тственно, вопреки́]{.ru} | 按照，相应于，违反（§9.4.3） |
| | [подо́бно]{.ru .ix} | 像……一样（书面） |
| 第五格（[с, за]{.ru}） | [ря́дом с]{.ru} | 在……旁边（§9.2.3） |
| | [вме́сте с]{.ru .ix}，[наряду́ с]{.ru .ix} | 和……一起，与……并列 |
| | [вслед за]{.ru .ix} | 紧跟着…… |
| 第二格（[от]{.ru}） | [недалеко́ от, далеко́ от, бли́зко от]{.ru} | 离……不远、远、近（§9.2.2） |
| | [спра́ва от]{.ru .ix}，[сле́ва от]{.ru .ix} | 在……右边、左边 |
| | [незави́симо от]{.ru .ix} | 不管，不论 |

| 前置词 | 格 | 意义 | 来源 |
|---|---|---|---|
| [благодаря́]{.ru .ix} | 第三格 | 多亏，由于（§9.4.1） | [благодари́ть]{.ru} 感谢 |
| [несмотря́ на]{.ru .ix} | 第四格 | 尽管（§9.4.3） | [смотре́ть]{.ru} 看 |
| [су́дя по]{.ru .ix} | 第三格 | 根据……来看 | [суди́ть]{.ru} 判断 |
| [включа́я]{.ru .ix} | 第四格 | 包括 | [включа́ть]{.ru} 包括，打开 |
| [исключа́я]{.ru .ix} | 第四格 | 除……以外 | [исключа́ть]{.ru} 排除 |
| [начина́я с]{.ru .ix} | 第二格 | 从……开始 | [начина́ть]{.ru} 开始 |
| [конча́я]{.ru .ix} | 第五格 | 直到……（与 [начина́я с]{.ru} 配合） | [конча́ть]{.ru} 结束 |
| [исходя́ из]{.ru .ix} | 第二格 | 从……出发，根据 | [исходи́ть]{.ru} 出发 |
| [спустя́]{.ru .ix} | 第四格 | 过了……以后（§9.3.2） | [спусти́ть]{.ru} 放下 |

### 意义和用法

**前置词和原来的词。** 副词性前置词和副动词性前置词与原来的副词、副动词同形，判断它是不是前置词，要看后面有没有它支配的名词：

- 副词单独作状语，后面没有依附的名词：[Впереди́ шли де́ти]{.ru}（前面走着孩子们），[Вокру́г бы́ло ти́хо]{.ru}（周围很安静），[Он живёт напро́тив]{.ru}（他住在对面）。
- 前置词后面一定有名词或代词，而且用一定的格：[впереди́ коло́нны]{.ru}（在队伍前面），[вокру́г до́ма]{.ru}，[напро́тив шко́лы]{.ru}。

副动词性前置词和副动词的区别在于是否保留动词意义、是否与句子的主语相连。副动词表示主语的一个次要动作，前置词只表示原因、根据、范围等关系，与主语无关：

| 前置词 | 副动词 |
|---|---|
| [Благодаря́ дру́гу я нашёл рабо́ту.]{.ru} 多亏朋友我找到了工作（第三格，“多亏”） | [Благодаря́ дру́га за по́мощь, я пожа́л ему́ ру́ку.]{.ru} 我一面感谢朋友的帮助，一面握他的手（第四格，“感谢”，主语是“我”） |
| [Су́дя по всему́, дождя́ не бу́дет.]{.ru} 看样子不会下雨 | [Су́дя о лю́дях по пе́рвому впечатле́нию, мы ча́сто ошиба́емся.]{.ru} 我们凭第一印象评判人，常常出错（“评判”的是主语 [мы]{.ru}） |
| [Все, включа́я дете́й, пошли́ в лес.]{.ru} 所有人，包括孩子，都去树林了 | [Включа́я свет, он уви́дел письмо́.]{.ru} 他开灯的时候看见了信（“开”的是主语） |
| [Начина́я с понеде́льника, магази́н рабо́тает до десяти́.]{.ru} 从星期一起商店营业到十点 | [Начина́я рабо́ту, он всегда́ составля́ет план.]{.ru} 他开始工作时总要先订计划 |

前置词用法的句子即使主语和“动作”对不上也是正确的：[Су́дя по его́ лицу́, он уста́л]{.ru}（从他的脸色看，他累了）里“判断”的不是 [он]{.ru}，这正说明 [су́дя по]{.ru} 已经不是副动词。副动词的主语规则见 §7.9.5，副动词变为副词、前置词的过程见 §7.9.6。

**写法。** [несмотря́]{.ru} 作前置词连写：[несмотря́ на дождь]{.ru}；分写的 [не смотря́]{.ru} 是副动词“不看”：[Он шёл, не смотря́ по́д ноги]{.ru} 一类句子里还保留“看”的意思。可以用这个办法检验：能换成 [хотя́]{.ru} 或“尽管”的连写，能换成“不看着”的分写。

**格。** 前置词保留或改变了原来的词的支配：[благодаря́]{.ru} 作动词要求第四格（[благодари́ть дру́га]{.ru}），作前置词要求第三格（[благодаря́ дру́гу]{.ru}），这是中国学生最容易错的地方。[включа́я, исключа́я]{.ru} 保留第四格。带原生前置词的，格由原生前置词决定：[несмотря́ на]{.ru} 第四格，[су́дя по]{.ru} 第三格，[начина́я с]{.ru} 第二格，[вме́сте с]{.ru} 第五格，[незави́симо от]{.ru} 第二格。

**[н-]{.ru} 形式。** 第三人称代词在要求第二格的副词性前置词后加 [н-]{.ru}：[вокру́г него́, впереди́ них, среди́ них, вме́сто неё]{.ru}；在要求第三格的派生前置词后不加：[благодаря́ ему́, навстре́чу ей, согла́сно им, подо́бно ему́]{.ru}。规则见 §5.1.2。

**几个前置词的意义。**

- [вблизи́]{.ru}：“在……附近”，比 [о́коло]{.ru} 书面：[вблизи́ го́рода]{.ru}。
- [впереди́, позади́]{.ru}：在空间上的前后，常指队列、行进中的位置：[впереди́ всех]{.ru}（走在最前面）。静止的“在房子前面、后面”多用 [пе́ред, за]{.ru}（§9.2.4）。
- [внутри́, внутрь]{.ru}：[внутри́]{.ru} 回答 [где?]{.ru}，[внутрь]{.ru} 回答 [куда́?]{.ru}，与 [в]{.ru} 加第六格、第四格平行：[внутри́ до́ма]{.ru}（在房子里面），[войти́ внутрь до́ма]{.ru}（走进房子里面）。
- [среди́, посреди́]{.ru}：[среди́]{.ru} 是“在……之中”，后面多是复数（[среди́ друзе́й]{.ru} 在朋友们中间，[оди́н среди́ мно́гих]{.ru}），也表示时间“在……当中”（[среди́ но́чи]{.ru} 半夜里）；[посреди́]{.ru} 是“在……正中”（[посреди́ ко́мнаты]{.ru} 在屋子中央）。
- [сверх, свы́ше]{.ru}：[сверх]{.ru} 是“超出”：[сверх пла́на]{.ru}（计划外），[сверх ожида́ний]{.ru}（出乎意料）；[свы́ше]{.ru} 是“……以上”，用于数量：[свы́ше ста челове́к]{.ru}（见 §6.2.5）。
- [навстре́чу]{.ru}：“迎着”：[идти́ навстре́чу дру́гу]{.ru}（迎着朋友走去），[навстре́чу ве́тру]{.ru}；“满足（要求）”：[пойти́ навстре́чу]{.ru}（迁就，通融）。
- [вслед, вслед за]{.ru}：[смотре́ть вслед по́езду]{.ru}（目送火车），[вслед за ним]{.ru}（紧跟着他）。
- [подо́бно]{.ru}：“像……一样”，书面：[подо́бно отцу́]{.ru}（像父亲一样）。
- [вме́сте с, наряду́ с]{.ru}：[вме́сте с]{.ru} 强调共同行动；[наряду́ с]{.ru} 是“与……并列，同时还有”，书面：[наряду́ с успе́хами есть и пробле́мы]{.ru}。
- [спра́ва от, сле́ва от]{.ru}：[спра́ва от две́ри]{.ru}（门的右边）。
- [незави́симо от]{.ru}：“不管、不论”：[незави́симо от пого́ды]{.ru}（不论天气如何）。
- [су́дя по]{.ru}：根据某种迹象推断：[су́дя по всему́]{.ru}（看样子），[су́дя по го́лосу]{.ru}。
- [включа́я, исключа́я]{.ru}：包括、不包括：[все, включа́я меня́]{.ru}，[ка́ждый день, исключа́я воскресе́нье]{.ru}。
- [начина́я с… и конча́я…]{.ru}：列举范围的两端：[начина́я с дете́й и конча́я старика́ми]{.ru}（从孩子到老人）。
- [исходя́ из]{.ru}：“从……出发、根据”，书面：[исходя́ из о́пыта]{.ru}。

**语体和标点。** 副词性前置词中的 [вблизи́, внутри́, посреди́, сверх, подо́бно, наряду́ с]{.ru} 和副动词性前置词中的 [исходя́ из, исключа́я, спустя́]{.ru} 带书面色彩。带 [су́дя по]{.ru} 的短语作插入语时用逗号隔开，[включа́я, исключа́я]{.ru} 的短语放在句中补充说明时也常用逗号隔开，见 §14.1.2。

副词性前置词：

::: ex
[**Вблизи́** го́рода есть большо́е о́зеро.]{.ru}

[城市附近有一个大湖。]{.gloss}

[**Среди́** мои́х друзе́й мно́го иностра́нцев.]{.ru}

[我的朋友中有很多外国人。]{.gloss}

[**Посреди́** пло́щади стои́т па́мятник.]{.ru}

[广场中央立着一座纪念碑。]{.gloss}

[Ма́ма вы́шла **навстре́чу** гостя́м.]{.ru}

[妈妈出来迎接客人。]{.gloss}

[**Незави́симо от** пого́ды мы пое́дем на да́чу.]{.ru}

[不管天气怎样，我们都去别墅。]{.gloss}
:::

副动词性前置词：

::: ex
[**Благодаря́** хоро́шей пого́де мы мно́го гуля́ли.]{.ru}

[多亏天气好，我们散了很多步。]{.gloss}

[**Су́дя по** прогно́зу, за́втра бу́дет тепло́.]{.ru}

[从天气预报看，明天会暖和。]{.gloss}

[Все, **включа́я** Ми́шу, получи́ли пода́рки.]{.ru}

[所有人，包括米沙，都收到了礼物。]{.gloss}

[**Начина́я с** сентября́, заня́тия начина́ются в де́вять.]{.ru}

[从九月起，课九点开始。]{.gloss}

[**Исходя́ из** э́тих да́нных, мо́жно сде́лать вы́вод.]{.ru}

[根据这些数据可以得出结论。]{.gloss}
:::

### 常见错误

::: err
\*[Благодаря́ дру́га я нашёл рабо́ту.]{.ru}　→　[Благодаря́ **дру́гу** я нашёл рабо́ту.]{.ru}

前置词 [благодаря́]{.ru} 要求第三格；第四格是动词 [благодари́ть]{.ru} 的支配。
:::

::: err
\*[Не смотря́ на дождь, мы пошли́ гуля́ть.]{.ru}　→　[**Несмотря́** на дождь, мы пошли́ гуля́ть.]{.ru}

前置词连写。
:::

::: err
\*[Все пришли́, включа́я его́ бра́тья.]{.ru}　→　[Все пришли́, включа́я его́ **бра́тьев**.]{.ru}

[включа́я]{.ru} 要求第四格，动物名词复数第四格同第二格。
:::

## §9.5.2 名词性前置词

### 形式

名词性前置词由名词的某个格（有时前面带原生前置词，后面带另一个原生前置词）转来，多数要求第二格。下表按构成分为两类。

简单的名词性前置词（一个词）：

| 前置词 | 格 | 意义 | 来源 | 语体 |
|---|---|---|---|---|
| [ввиду́]{.ru .ix} | 第二格 | 鉴于，由于 | [в ви́ду]{.ru} 在眼前 | 书面 |
| [всле́дствие]{.ru .ix} | 第二格 | 由于（结果） | [сле́дствие]{.ru} 结果 | 书面 |
| [путём]{.ru .ix} | 第二格 | 通过……的办法 | [путь]{.ru} 道路 | 书面 |
| [посре́дством]{.ru .ix} | 第二格 | 借助于 | [посре́дство]{.ru} 中介 | 书面 |
| [насчёт]{.ru} | 第二格 | 关于（§9.4.2） | [счёт]{.ru} 账 | 口语、中性 |
| [вро́де]{.ru .ix} | 第二格 | 像……那样的 | [род]{.ru} 种类 | 口语 |

### 意义和用法

**名词变成了前置词。** 名词性前置词里的名词已经失去了独立的名词意义，整个组合当作一个前置词用。可以从三点看出来：

1. 名词的形式固定，不随句子变化：只能说 [в тече́ние]{.ru}，不能变成复数或别的格。
2. 名词前不能加定语：不能说 [в до́лгом тече́нии]{.ru}；要说明时段的长短，定语加在后面的名词上：[в тече́ние до́лгого вре́мени]{.ru}。
3. 意义已经与名词本义疏远：[в тече́ние ме́сяца]{.ru} 和“水流”[тече́ние]{.ru} 无关，[ввиду́]{.ru}（鉴于）和“视线”无关。

同样的组合也可以是普通的名词词组，这时名词保持本义，可以带定语：[в тече́нии реки́]{.ru}（在河的水流中），[в бы́стром тече́нии]{.ru}；[Я име́ю в виду́ друго́е]{.ru}（我指的是别的），[в виду́ бе́рега]{.ru}（在望得见岸的地方）。

**格。** 名词性前置词后面的名词多用第二格，因为它本来是这个名词的非一致定语：[в тече́ние неде́ли]{.ru} 原意是“在一周的流程中”。末尾带原生前置词的，格由这个原生前置词决定：[в связи́ с]{.ru}、[по сравне́нию с]{.ru}、[в соотве́тствии с]{.ru} 要求第五格，[в отли́чие от]{.ru}、[в зави́симости от]{.ru} 要求第二格，[по отноше́нию к]{.ru} 要求第三格。末尾的原生前置词不能省掉：不说 [в связи́ боле́зни]{.ru}。

**写法。** 名词性前置词的写法要按名词原来的格判断：

- 名词是第四格的写 [-е]{.ru}：[в тече́ние, в продолже́ние, в отли́чие от]{.ru}，副词 [в заключе́ние]{.ru}（最后）也是这样（见 §1.4.5）。
- 名词是第六格的写 [-и]{.ru} 或 [-е]{.ru}，与普通的第六格相同：[в связи́ с, в зави́симости от, в соотве́тствии с, по ме́ре, в результа́те, в слу́чае, в ка́честве]{.ru}。
- 连写和分写：[ввиду́]{.ru}（鉴于）连写，与 [име́ть в виду́]{.ru}（指的是）不同；[всле́дствие]{.ru}（由于）连写，与 [в сле́дствии]{.ru}（在侦查中）不同；[насчёт]{.ru}（关于）连写，与 [на счёт]{.ru}（存入账户：[перевести́ де́ньги на счёт]{.ru}）不同；[в тече́ние, в продолже́ние, в связи́ с, в ви́де]{.ru} 分写。

[в тече́нии]{.ru}、[в отли́чии от]{.ru} 一类错误，俄罗斯人自己也常写，必须注意。

**语体。** 名词性前置词大多带书面或公文色彩，在口语里常用简单的前置词或从句代替：

| 名词性前置词 | 口语、中性的说法 |
|---|---|
| [в связи́ с боле́знью]{.ru} | [из-за́ боле́зни]{.ru}，[потому́ что заболе́л]{.ru} |
| [в результа́те ава́рии]{.ru} | [из-за́ ава́рии]{.ru}，[по́сле ава́рии]{.ru} |
| [ввиду́ плохо́й пого́ды]{.ru} | [из-за́ плохо́й пого́ды]{.ru} |
| [в тече́ние неде́ли]{.ru} | [неде́лю, за неде́лю]{.ru} |
| [путём перегово́ров]{.ru} | [с по́мощью перегово́ров]{.ru}，[договори́вшись]{.ru} |
| [на основа́нии пра́вил]{.ru} | [по пра́вилам]{.ru} |
| [за исключе́нием Ми́ши]{.ru} | [кро́ме Ми́ши]{.ru} |
| [с це́лью изуче́ния языка́]{.ru} | [что́бы изучи́ть язы́к]{.ru} |

公文、新闻、科学语体里，名词性前置词常和动名词连用，构成一连串第二格：[в связи́ с проведе́нием ремо́нта]{.ru}（因进行维修），[по ме́ре повыше́ния температу́ры]{.ru}（随着温度升高），见 §15.1.3。

**几个前置词的意义。**

- 原因：[в связи́ с]{.ru} 中性，不带好坏评价，多用于通知（[в связи́ с ремо́нтом]{.ru} 因维修）；[в результа́те]{.ru} 着重结果（[в результа́те ава́рии]{.ru}）；[всле́дствие]{.ru} 同 [в результа́те]{.ru}，更书面；[ввиду́]{.ru} 说的是考虑到某个现存的或预料中的情况而采取行动（[Ввиду́ плохо́й пого́ды вы́лет отло́жен]{.ru} 鉴于天气不好，起飞推迟）；[по причи́не]{.ru} 公文。它们和 [из-за́, благодаря́]{.ru} 的比较见 §9.4.1。
- 时间：[в тече́ние]{.ru} 和 [во вре́мя]{.ru} 的区别见 §9.3.2、§9.3.3；[в продолже́ние]{.ru} 意思同 [в тече́ние]{.ru}，强调整个过程，更书面；[на протяже́нии]{.ru} 多用于较长的时期（[на протяже́нии ве́ка]{.ru}）。
- 身份和形式：[в ка́честве перево́дчика]{.ru}（作为翻译），[в ка́честве приме́ра]{.ru}（作为例子）；[в ви́де табли́цы]{.ru}（以表格的形式）。
- 手段：[с по́мощью словаря́]{.ru}（借助词典），[с по́мощью дру́га]{.ru}；[путём]{.ru} 多加动名词（[путём перегово́ров]{.ru} 通过谈判）；[посре́дством]{.ru} 很书面。
- 变化和条件：[по ме́ре]{.ru}（随着：[по ме́ре приближе́ния к го́роду]{.ru}），[в зави́симости от]{.ru}（视……而定：[в зави́симости от пого́ды]{.ru}）。
- 依据：[на основа́нии]{.ru}（根据文件、数据：[на основа́нии прика́за]{.ru}），[в соотве́тствии с]{.ru}（依照规定：[в соотве́тствии с зако́ном]{.ru}）。
- 排除和缺少：[за исключе́нием]{.ru}（除……以外，排除义），[за неиме́нием]{.ru}（因为没有：[за неиме́нием лу́чшего]{.ru} 没有更好的，只好将就）。
- 其他：[от и́мени]{.ru}（代表：[от и́мени всех студе́нтов]{.ru}），[в честь]{.ru}（为纪念：[у́лица в честь Пу́шкина]{.ru}，[в честь пра́здника]{.ru}），[по по́воду]{.ru}（关于某事；因为某件事：[по по́воду ва́шего письма́]{.ru}，[пра́здник по по́воду юбиле́я]{.ru}），[в разме́ре]{.ru}（数额为：[штраф в разме́ре пяти́ ты́сяч рубле́й]{.ru}），[по отноше́нию к]{.ru}（对于：[несправедли́вость по отноше́нию к нему́]{.ru}），[в направле́нии]{.ru}（朝……方向：[в направле́нии це́нтра]{.ru}），[вро́де]{.ru}（像……那样的，口语：[что́-то вро́де пирога́]{.ru}）。

**与从句的对应。** 名词性前置词后面要说一个句子时，加 [того́, что]{.ru} 一类构成复合连词：[в связи́ с тем, что…]{.ru}，[в результа́те того́, что…]{.ru}，[ввиду́ того́, что…]{.ru}，[по ме́ре того́ как…]{.ru}，[в зави́симости от того́, …]{.ru}，见第十三编第 2 章各类从句。

::: ex
[**В тече́ние** двух неде́ль шёл дождь.]{.ru}

[**Ввиду́** плохо́й пого́ды экску́рсию перенесли́ на суббо́ту.]{.ru}

[Ван Лэй рабо́тал ле́том **в ка́честве** перево́дчика.]{.ru}

[王磊夏天当翻译。]{.gloss}

[Я прочита́л статью́ **с по́мощью** словаря́.]{.ru}

[**По ме́ре** приближе́ния к Москве́ дере́вни станови́лись всё ча́ще.]{.ru}

### 常见错误

::: err
\*[в тече́нии ме́сяца]{.ru}；\*[в отли́чии от бра́та]{.ru}　→　[**в тече́ние** ме́сяца]{.ru}；[**в отли́чие** от бра́та]{.ru}

这两个前置词里的名词是第四格，写 [-е]{.ru}。
:::

::: err
\*[в связи́ с боле́зни]{.ru}　→　[в связи́ с **боле́знью**]{.ru}

末尾是 [с]{.ru}，要求第五格。
:::

::: err
\*[Он рабо́тает в ка́честве перево́дчик.]{.ru}　→　[Он рабо́тает в ка́честве **перево́дчика**.]{.ru}

[в ка́честве]{.ru} 要求第二格，也可以说 [Он рабо́тает перево́дчиком]{.ru}（第五格，见 §3.7.4）。
:::

::: err
\*[Всле́дствии дождя́ матч отмени́ли.]{.ru}　→　[**Всле́дствие** дождя́ матч отмени́ли.]{.ru}

前置词 [всле́дствие]{.ru} 连写，词尾是 [-е]{.ru}。
:::
