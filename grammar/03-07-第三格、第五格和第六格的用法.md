本章讲[第三格]{.term}（[да́тельный паде́ж]{.ru}）、[第五格]{.term}（[твори́тельный паде́ж]{.ru}）和[第六格]{.term}（[предло́жный паде́ж]{.ru}）的用法。第三格不带前置词时表示动作所向的对象（§3.7.1）和状态、感受的主体（§3.7.2）；第五格表示工具、方式、施事等（§3.7.3），作表语和某些动词的补语（§3.7.4）；第六格只和前置词连用，§3.7.5 按前置词总览它的意义。前两格带前置词的用法（[к, по]{.ru} 加第三格，[с, над, под, пе́ред, за, ме́жду]{.ru} 加第五格）见第九编。各格的形式见第三编第 2、3 章。

## §3.7.1 第三格表示对象

### 形式

第三格回答 [кому́? чему́?]{.ru} 的问题。不带前置词的第三格表示对象时，有以下几种用法：

| 用法 | 例子 |
|---|---|
| 及物动词的间接补语：给谁、对谁 | [дать **дру́гу** кни́гу]{.ru}，[написа́ть **ма́ме** письмо́]{.ru} |
| 只带第三格的动词的补语 | [помога́ть **дру́гу**]{.ru}，[звони́ть **ма́ме**]{.ru}，[ве́рить **сло́вам**]{.ru} |
| 名词后 | [па́мятник **Пу́шкину**]{.ru}，[пода́рок **дру́гу**]{.ru} |
| 形容词（多为短尾）后 | [благода́рен **дру́гу**]{.ru}，[ве́рен **сло́ву**]{.ru} |

第三格作主体的用法（[Мне хо́лодно]{.ru}）见 §3.7.2。

### 意义和用法

**间接补语。** 表示给予、传达、展示一类意义的及物动词带两个补语：第四格是直接补语（给什么），第三格是间接补语（给谁），后者表示的是[间接客体]{.term}（[ко́свенный объе́кт]{.ru}）：[дать дру́гу кни́гу, подари́ть сестре́ цветы́, показа́ть го́стю го́род, объясни́ть студе́нтам пра́вило, сказа́ть ма́ме пра́вду, обеща́ть сы́ну велосипе́д, посла́ть бра́ту письмо́]{.ru}。属于这一类的主要有：

- 给予：[дава́ть / дать, дари́ть / подари́ть, передава́ть / переда́ть, посыла́ть / посла́ть, плати́ть / заплати́ть, продава́ть / прода́ть, возвраща́ть / верну́ть]{.ru}；
- 传达：[говори́ть / сказа́ть, писа́ть / написа́ть, расска́зывать / рассказа́ть, объясня́ть / объясни́ть, сообща́ть / сообщи́ть, обеща́ть]{.ru}；
- 展示：[пока́зывать / показа́ть]{.ru}。

第三格还可以表示动作为谁做、对谁有利或不利：[купи́ть сы́ну велосипе́д]{.ru}（给儿子买自行车），[испе́чь де́тям пиро́г]{.ru}，[открыва́ть го́стю дверь]{.ru}，[испо́ртить всем настрое́ние]{.ru}（败了大家的兴）。这种第三格不是动词要求的，许多及物动词都能加上。带两个补语的动词全表见 §12.1.3。

**只带第三格的动词。** 一批不及物动词的补语用第三格。只举典型的，全表见附录五：

| 意义 | 动词 |
|---|---|
| 帮助、妨碍 | [помога́ть / помо́чь, меша́ть / помеша́ть, сопротивля́ться]{.ru} |
| 联系、回应 | [звони́ть / позвони́ть, отвеча́ть / отве́тить, кива́ть / кивну́ть, улыба́ться / улыбну́ться, кла́няться / поклони́ться]{.ru} |
| 信任、服从 | [ве́рить / пове́рить, доверя́ть, подчиня́ться, служи́ть, принадлежа́ть]{.ru} |
| 感情 | [ра́доваться / обра́доваться, удивля́ться / удиви́ться, зави́довать, сочу́вствовать]{.ru} |
| 劝说、命令、禁止、允许 | [сове́товать / посове́товать, веле́ть, запреща́ть / запрети́ть, разреша́ть / разреши́ть, позволя́ть / позво́лить]{.ru}（后面常接不定式） |
| 学、教的内容 | [учи́ться / научи́ться]{.ru}（学会什么技能），[учи́ть / научи́ть кого́]{.ru}（教谁什么） |
| 其他 | [подража́ть, грози́ть, мстить, изменя́ть / измени́ть, надоеда́ть / надое́сть]{.ru} |

[ра́доваться, удивля́ться]{.ru} 的第三格表示引起这种感情的事物：[ра́доваться весне́]{.ru}（为春天高兴），[удивля́ться его́ сме́лости]{.ru}（对他的勇气感到惊奇）。[учи́ться]{.ru} 加第三格表示学会一门技能：[учи́ться му́зыке, учи́ться пла́ванию]{.ru}；学一门课程、一种语言更常说 [изуча́ть]{.ru} 加第四格（见 §3.5.2）。[ве́рить]{.ru} 加第三格是“相信（某人的话、某种说法）”，加 [в]{.ru} 和第四格是“信仰、对……有信心”：[ве́рить дру́гу]{.ru}（相信朋友的话）—[ве́рить в дру́га]{.ru}（信得过朋友，相信他能行），[ве́рить в бо́га]{.ru}，见 §12.1.2。

**名词后的第三格。** 少数名词带第三格，多半与要求第三格的动词同根，或者含有“给予、献给”的意思：[па́мятник Пу́шкину]{.ru}（普希金纪念碑），[пода́рок дру́гу]{.ru}，[письмо́ ма́ме]{.ru}，[по́мощь пострада́вшим]{.ru}，[отве́т дру́гу]{.ru}，[приве́т роди́телям]{.ru}，[сове́т молоды́м]{.ru}。也用于口号、感叹：[Сла́ва геро́ям!]{.ru}，[Приве́т ма́ме!]{.ru}。[па́мятник Пу́шкину]{.ru} 是“为普希金立的纪念碑”，[па́мятник Пу́шкина]{.ru} 只能理解为“普希金所有的纪念碑”，一般不这样说。名词的支配见 §12.1.5。

**形容词后的第三格。** 一部分形容词（多用短尾）带第三格：[благода́рен]{.ru}（感激），[ве́рен]{.ru}（忠于），[рад]{.ru}（高兴见到、对……感到高兴），[бли́зок]{.ru}（亲近），[знако́м]{.ru}（熟悉），[изве́стен]{.ru}（为……所知），[поле́зен, вре́ден]{.ru}（对……有益、有害），[поня́тен]{.ru}（明白），[свойстве́н]{.ru}（是……所特有的），[ра́вен]{.ru}（等于），[подо́бен]{.ru}（类似于）。[Я вам о́чень благода́рен]{.ru}，[Он ве́рен сво́ему сло́ву]{.ru}，[Мы ра́ды го́стям]{.ru}，[Её лицо́ мне знако́мо]{.ru}，[Э́то и́мя изве́стно ка́ждому]{.ru}。短尾形容词的用法见 §4.2.2，形容词的支配见 §12.1.5。

**俄汉差异。** 汉语“帮助他”“相信他”“妨碍他”“羡慕他”“给他打电话”在形式上都是动词加宾语或介词加宾语，俄语都用第三格；而汉语同样形式的“问他”“请他”“感谢他”“祝贺他”，俄语用第四格（[спроси́ть, попроси́ть, поблагодари́ть, поздра́вить кого́]{.ru}）。不能按汉语的说法推，要随动词记住所带的格。另外，汉语的间接宾语只能放在直接宾语前面（“给朋友一本书”），俄语两个补语的次序比较自由，新信息放在后面：[Я дал кни́гу дру́гу]{.ru}（书给了朋友），[Я дал дру́гу кни́гу]{.ru}（给朋友的是一本书）。

间接补语：

::: ex
[Ван Лэй подари́л **А́нне** цветы́.]{.ru}

[王磊送给安娜一束花。]{.gloss}

[О́льга Ви́кторовна объясни́ла **студе́нтам** но́вое пра́вило.]{.ru}

[奥莉加·维克托罗夫娜给学生们讲解了新规则。]{.gloss}

[Ма́ма купи́ла **Ми́ше** но́вый портфе́ль.]{.ru}

[妈妈给米沙买了一个新书包。]{.gloss}
:::

只带第三格的动词：

::: ex
[Ми́ша ча́сто помога́ет **ба́бушке**.]{.ru}

[米沙经常帮奶奶干活。]{.gloss}

[Ве́чером я позвони́л **роди́телям**.]{.ru}

[晚上我给父母打了电话。]{.gloss}

[Врач посове́товал **отцу́** бо́льше гуля́ть.]{.ru}

[医生建议父亲多散步。]{.gloss}

[Де́ти ра́дуются **сне́гу**.]{.ru}

[孩子们看见下雪很高兴。]{.gloss}

[Не меша́й **бра́ту**, он занима́ется.]{.ru}

[别打扰哥哥，他在学习。]{.gloss}
:::

名词和形容词后：

::: ex
[На пло́щади стои́т па́мятник **Пу́шкину**.]{.ru}

[广场上有一座普希金纪念碑。]{.gloss}

[Переда́й приве́т **роди́телям**!]{.ru}

[替我问候你父母！]{.gloss}

[Я вам о́чень благода́рен за по́мощь.]{.ru}

[非常感谢您的帮助。]{.gloss}

[Э́тот го́лос мне знако́м.]{.ru}

[这个声音我很熟悉。]{.gloss}
:::

### 常见错误

::: err
\*[Я помога́ю ма́му.]{.ru}　→　[Я помога́ю **ма́ме**.]{.ru}

汉语“帮助妈妈”是动宾结构，俄语 [помога́ть]{.ru} 要求第三格。
:::

::: err
\*[Я позвони́л А́нну.]{.ru}　→　[Я позвони́л **А́нне**.]{.ru}

[звони́ть]{.ru} 要求第三格。
:::

::: err
\*[Поздравля́ю тебе́ с днём рожде́ния!]{.ru}　→　[Поздравля́ю **тебя́** с днём рожде́ния!]{.ru}

与上面两句相反：[поздравля́ть, благодари́ть, спра́шивать, проси́ть]{.ru} 要求第四格，不能因为汉语里像“对某人说”就用第三格。
:::

::: err
\*[Я ве́рю в его́ слова́.]{.ru}　→　[Я ве́рю **его́ слова́м**.]{.ru}

相信某人说的话用 [ве́рить]{.ru} 加第三格；[ве́рить в]{.ru} 加第四格是“信仰、对……有信心”。
:::

## §3.7.2 第三格表示主体

### 形式

第三格可以表示状态、感受、需要、年龄的承受者，即句子所说的人。这时句子里或者没有第一格主语，或者第一格主语表示的是别的东西，汉语里作主语的“我”在俄语里是第三格：

| 句型 | 例子 | 汉语 | 详见 |
|---|---|---|---|
| 第三格 + 谓语副词 | [**Мне** хо́лодно.]{.ru} [**Ему́** ну́жно уйти́.]{.ru} | 我冷。他得走了。 | §8.2.1、§8.2.2 |
| 第三格 + [нра́виться]{.ru} + 第一格 | [**Мне** нра́вится э́та кни́га.]{.ru} | 我喜欢这本书。 | 本节 |
| 第三格 + [ну́жен]{.ru} + 第一格 | [**Мне** нужна́ ру́чка.]{.ru} | 我需要一支笔。 | 本节；§4.2.2 |
| 第三格 + 年龄 | [**Мне** два́дцать лет.]{.ru} | 我二十岁。 | §6.4.3 |
| 第三格 + 无人称动词 | [**Мне** хо́чется спать.]{.ru} [**Мне** не спи́тся.]{.ru} | 我想睡觉。我睡不着。 | §7.7.2、§7.5.5 |
| 第三格 + 不定式 | [**Мне** за́втра ра́но встава́ть.]{.ru} | 我明天得早起。 | §12.4.5 |

这些句型的总汇见 §12.4.4（“人用第三格”的句子）。

### 意义和用法

**主体用第三格的道理。** 用第一格作主语的人是动作的发出者，他主动做什么。第三格表示的[主体]{.term}（[субъе́кт]{.ru}）不发出动作，而是处于某种状态、感到某种感受、有某种需要：冷不冷、喜不喜欢、需不需要，都不由人自主，状态“落到”人身上。所以俄语把这个人放在第三格（“对谁来说”），句子不用第一格的人作主语。

**谓语副词句。** 以 [-о]{.ru} 结尾的谓语副词表示人的感受时，感受者用第三格，构成[无人称句]{.term}（[безли́чное предложе́ние]{.ru}）：[Мне хо́лодно / тепло́ / жа́рко]{.ru}，[Нам ве́село]{.ru}，[Ему́ ску́чно]{.ru}，[Тебе́ не тру́дно?]{.ru}，[Мне сты́дно]{.ru}，[Ей бо́льно]{.ru}。情态谓语副词 [на́до, ну́жно, мо́жно, нельзя́, пора́]{.ru} 加[不定式]{.term}（[инфинити́в]{.ru}）也一样：[Мне на́до рабо́тать]{.ru}，[Тебе́ нельзя́ кури́ть]{.ru}，[Нам пора́ идти́]{.ru}。过去时、将来时用中性的 [бы́ло, бу́дет]{.ru}：[Мне бы́ло хо́лодно]{.ru}，[Тебе́ бу́дет ску́чно]{.ru}，[Ему́ на́до бы́ло уйти́]{.ru}。谓语副词见第八编第 2 章。

**[нра́виться]{.ru} 句型。** 汉语“我喜欢这本书”，俄语说 [Мне нра́вится э́та кни́га]{.ru}：喜欢的人用第三格，被喜欢的东西作主语，用第一格，动词与它一致：

- [Мне нра́вится э́та кни́га. Мне нра́вятся э́ти кни́ги.]{.ru}
- [Мне понра́вился фильм. Мне понра́вилась пье́са. Мне понра́вилось письмо́. Мне понра́вились стихи́.]{.ru}
- [Мне нра́вится чита́ть.]{.ru}（主语是不定式，动词用第三人称单数，过去时用中性 [понра́вилось]{.ru}）

因为第一格是被喜欢的人，[Я ему́ нра́влюсь]{.ru} 的意思是“他喜欢我”。[нра́виться]{.ru} 与 [люби́ть]{.ru} 的区别：[нра́виться]{.ru} 多表示对具体事物的印象，完成体 [понра́виться]{.ru} 表示第一次见到时的好感；[люби́ть]{.ru} 表示稳定的爱好和感情，人是第一格主语，喜欢的东西用第四格（[Я люблю́ му́зыку]{.ru}）。同样结构的动词还有 [надое́сть]{.ru}（[Мне надое́л дождь]{.ru} 我讨厌这雨了）、[удава́ться / уда́ться]{.ru}（[Мне удало́сь купи́ть биле́ты]{.ru} 我买到了票）、[хвата́ть]{.ru}（[Мне не хвата́ет вре́мени]{.ru}）、[каза́ться]{.ru}（[Мне ка́жется, что…]{.ru}），见 §7.7.2。

**[ну́жен]{.ru} 句型。** “我需要一支笔”说 [Мне нужна́ ру́чка]{.ru}：需要的人用第三格，需要的东西是主语，短尾形容词 [ну́жен, нужна́, ну́жно, нужны́]{.ru} 与它的性、数一致：[Мне ну́жен слова́рь]{.ru}，[Мне ну́жно молоко́]{.ru}，[Мне нужны́ де́ньги]{.ru}。过去时、将来时的 [быть]{.ru} 也与主语一致：[Мне нужна́ была́ ру́чка]{.ru}，[Мне бу́дут нужны́ де́ньги]{.ru}。需要的是动作时用谓语副词 [ну́жно]{.ru} 加不定式：[Мне ну́жно купи́ть ру́чку]{.ru}，过去时 [Мне ну́жно бы́ло купи́ть]{.ru}。

**年龄。** 年龄的主体用第三格：[Мне два́дцать лет]{.ru}，[Ско́лько тебе́ лет?]{.ru}，[Ба́бушке бы́ло се́мьдесят лет]{.ru}，[Сы́ну ско́ро бу́дет пять]{.ru}。年龄的各种说法见 §6.4.3。

**无人称动词和不定式句。** 无人称动词的主体用第三格：[Мне хо́чется пить]{.ru}，[Ему́ не везёт]{.ru}，[Нам повезло́]{.ru}，[Мне не спи́тся]{.ru}（[-ся]{.ru} 构成的无人称用法见 §7.5.5，无人称动词见 §7.7.2）。不定式句表示必须做、注定要做的事，行为者也用第三格：[Мне за́втра ра́но встава́ть]{.ru}（我明天得早起），[Что мне де́лать?]{.ru}（我该怎么办？），[Тебе́ не поня́ть]{.ru}（你是不会明白的），见 §12.4.5。

**第三格加 [быть]{.ru} 表示必然。** 书面语、民间文学里，不定式 [быть]{.ru} 加名词第三格，表示某件事必然要发生，多是不好的事：[Быть грозе́]{.ru}（要有一场雷雨了），[Быть беде́]{.ru}（要出事了）。否定形式表示某事不可能实现：[Не быть тебе́ певцо́м]{.ru}（你当不成歌唱家）。谚语 [Чему́ быть, того́ не минова́ть]{.ru}（该来的躲不过）也是这个结构。

**俄汉差异。** 汉语的这些句子都以人为主语（“我冷”“我喜欢”“我需要”“我二十岁”），俄语都以第三格表示人。要先想清楚俄语句子里的主语是谁（被喜欢的东西、需要的东西），还是根本没有主语（冷、要做的事），然后定动词和形容词的形式。

谓语副词句：

::: ex
[**Ми́ше** ску́чно до́ма.]{.ru}

[米沙在家里觉得无聊。]{.gloss}

[Вчера́ **мне** бы́ло о́чень хо́лодно.]{.ru}

[昨天我很冷。]{.gloss}

[**Тебе́** на́до отдохну́ть.]{.ru}

[你得休息一下。]{.gloss}
:::

[нра́виться]{.ru} 和 [ну́жен]{.ru}：

::: ex
[**Ван Лэ́ю** о́чень нра́вится Москва́.]{.ru}

[王磊很喜欢莫斯科。]{.gloss}

[**А́нне** понра́вились э́ти цветы́.]{.ru}

[安娜喜欢这些花。]{.gloss}

[**Мне** нужна́ ва́ша по́мощь.]{.ru}

[我需要您的帮助。]{.gloss}

[**Студе́нтам** бы́ли нужны́ но́вые словари́.]{.ru}

[学生们需要新词典。]{.gloss}
:::

年龄、无人称动词和不定式句：

::: ex
[**Ми́ше** четы́рнадцать лет.]{.ru}

[米沙十四岁。]{.gloss}

[**Мне** не хо́чется никуда́ идти́.]{.ru}

[我哪儿也不想去。]{.gloss}

[**Нам** ещё до́лго е́хать.]{.ru}

[我们还要走很久。]{.gloss}
:::

必然：

::: ex
[Не́бо потемне́ло. **Быть грозе́**.]{.ru}

[天黑下来了，要有一场雷雨。]{.gloss}

[**Не быть** **тебе́** врачо́м, е́сли ты бои́шься кро́ви.]{.ru}

[你要是怕血，就当不成医生。]{.gloss}
:::

### 常见错误

::: err
\*[Я нра́вится э́та кни́га.]{.ru}　→　[**Мне** нра́вится э́та кни́га.]{.ru}

照汉语以“我”为主语。[нра́виться]{.ru} 句里人用第三格，书是主语。
:::

::: err
\*[Мне нра́вится э́ти цветы́.]{.ru}　→　[Мне **нра́вятся** э́ти цветы́.]{.ru}

动词与第一格主语 [цветы́]{.ru} 一致，用复数。
:::

::: err
\*[Мне ну́жно ру́чка.]{.ru}　→　[Мне **нужна́** ру́чка.]{.ru}

需要的东西是主语时，[ну́жен]{.ru} 与它一致；[ну́жно]{.ru} 只用于不定式前或没有主语的句子。
:::

::: err
\*[Я два́дцать лет.]{.ru}　→　[**Мне** два́дцать лет.]{.ru}

年龄的主体用第三格。
:::

::: err
\*[Мне был ску́чно.]{.ru}　→　[Мне **бы́ло** ску́чно.]{.ru}

无人称句没有主语，[быть]{.ru} 用中性。
:::

## §3.7.3 第五格的状语用法和施事

### 形式

第五格回答 [кем? чем?]{.ru}，不带前置词时有以下几种状语意义，还可以表示被动结构和无人称句中的施事：

| 意义 | 问题 | 例子 |
|---|---|---|
| 工具 | [чем?]{.ru} | [писа́ть **ру́чкой**]{.ru}，[ре́зать **ножо́м**]{.ru} |
| 方式 | [как?]{.ru} | [говори́ть **шёпотом**]{.ru}，[идти́ **бы́стрым ша́гом**]{.ru} |
| 路径 | [где? каки́м путём?]{.ru} | [идти́ **ле́сом**]{.ru}，[е́хать **бе́регом**]{.ru} |
| 交通工具 | [чем? как?]{.ru} | [е́хать **по́ездом**]{.ru}，[лете́ть **самолётом**]{.ru} |
| 比较：像……一样 | [как?]{.ru} | [лете́ть **стрело́й**]{.ru} |
| 施事、原因 | [кем? чем?]{.ru} | [постро́ен **рабо́чими**]{.ru}，[занесло́ **сне́гом**]{.ru} |
| 限定方面、尺寸 | [чем? како́й?]{.ru} | [высото́й сто ме́тров]{.ru}，[си́льный **ду́хом**]{.ru} |
| 时间 | [когда́? как до́лго?]{.ru} | [ра́нним **у́тром**]{.ru}，[**часа́ми**]{.ru} |
| 顺序 | [каки́м?]{.ru} | [пришёл **пе́рвым**]{.ru} |
| 全体、集体 | [как?]{.ru} | [всей **семьёй**]{.ru}，[**толпо́й**]{.ru} |

### 意义和用法

**工具。** 第五格最基本的意义是做事用的工具和手段：[писа́ть ру́чкой, ре́зать ножо́м, есть ло́жкой, мыть мы́лом, рисова́ть карандашо́м, плати́ть креди́тной ка́ртой]{.ru}。身体部位作为“工具”也用第五格：[кива́ть голово́й]{.ru}（点头），[маха́ть руко́й]{.ru}（挥手），[пожа́ть плеча́ми]{.ru}（耸肩），[ви́деть свои́ми глаза́ми]{.ru}（亲眼看见）。工具不加前置词：[с]{.ru} 加第五格表示“和……一起”“带着”（[чай с лимо́ном]{.ru}，见 §9.4.7），不表示工具。

**方式。** 第五格说明动作怎样进行：[говори́ть шёпотом]{.ru}（小声说），[говори́ть гро́мким го́лосом]{.ru}，[петь ба́сом]{.ru}，[идти́ бы́стрым ша́гом]{.ru}，[писа́ть кру́пным по́черком]{.ru}。有一些这样的第五格已经变成副词：[пешко́м, бего́м, верхо́м, ша́гом, круго́м]{.ru}（步行、跑着、骑着马、慢步、四周），见 §8.1.2。

**路径。** 运动动词加表示地方的名词第五格，表示经过的路线：[Мы шли ле́сом]{.ru}（我们穿过树林走），[е́хать бе́регом]{.ru}（沿着岸边走），[идти́ по́лем]{.ru}。带前置词的说法（[по ле́су, че́рез лес]{.ru}）见 §9.2.5。

**交通工具。** [е́хать по́ездом, лете́ть самолётом, плыть парохо́дом, отпра́вить письмо́ авиапо́чтой]{.ru}。这种第五格把交通工具当作手段，多用于长途旅行和书面语；日常说乘什么车更常用 [на]{.ru} 加第六格（[е́хать на авто́бусе]{.ru}）。两者的分工见 §7.6.4。

**比较：像……一样。** 第五格可以表示动作的样子像某种东西：[лете́ть стрело́й]{.ru}（箭一样飞），[выть во́лком]{.ru}（狼一样嚎），[Слёзы ли́лись ручьём]{.ru}（眼泪像小河一样流），[Пыль стоя́ла столбо́м]{.ru}（尘土扬成一根柱子）。这种比较简洁、形象，多见于文学语言；中性的说法用 [как]{.ru}（[лете́ть, как стрела́]{.ru}），见 §12.5.4、§15.1.6。

**施事和原因。** [被动结构]{.term}（[пасси́вная констру́кция]{.ru}）里，动作的发出者——[施事]{.term}（[производи́тель де́йствия]{.ru}）——用第五格：[Дом постро́ен рабо́чими]{.ru}（房子是工人们盖的），[Рома́н «Война́ и мир» напи́сан Толсты́м]{.ru}，[Зада́ча реша́ется студе́нтами]{.ru}，[Галере́я была́ осно́вана Третьяко́вым]{.ru}。被动结构的构成见 §7.5.4、§7.8.6。无人称句里，造成某种结果的自然力量也用第五格：[Доро́гу занесло́ сне́гом]{.ru}（路被雪埋了），[Ло́дку унесло́ ве́тром]{.ru}（船被风刮走了），[Его́ уби́ло мо́лнией]{.ru}（他被雷击死了），见 §7.7.2。汉语“被”字后面的施事，俄语用第五格，不用前置词 [от]{.ru} 或 [из]{.ru}。

**限定方面和尺寸。** 第五格说明在哪一方面：[Он си́лен ду́хом]{.ru}（他精神坚强），[Он ста́рше меня́ года́ми, но не умо́м]{.ru}，[Э́тот край бога́т ле́сом]{.ru}（[бога́т]{.ru} 见 §3.7.4）。说事物的尺寸时，[высота́, длина́, ширина́, глубина́, вес, пло́щадь, рост, во́зраст]{.ru} 的第五格放在名词后面，数量照常用第一格（第四格）形式：[ба́шня высото́й сто ме́тров]{.ru}（高一百米的塔），[река́ длино́й две ты́сячи киломе́тров]{.ru}，[ко́мната пло́щадью два́дцать квадра́тных ме́тров]{.ru}，[ма́льчик ро́стом с отца́]{.ru}（和父亲一样高的男孩）。也可以在数量前加 [в]{.ru}：[высото́й в сто ме́тров]{.ru}。

**时间。** 表示一天中的时段和季节的名词，第五格作时间状语：[у́тром, днём, ве́чером, но́чью; весно́й, ле́том, о́сенью, зимо́й]{.ru}，这些已经变成副词，在 §8.1.4 讲。带定语时它们仍是名词第五格：[ра́нним у́тром]{.ru}（清晨），[по́здним ве́чером]{.ru}，[про́шлой зимо́й]{.ru}，[тёплым ле́тним ве́чером]{.ru}。复数第五格 [часа́ми, дня́ми, неде́лями, года́ми, века́ми]{.ru} 表示“一连几个小时、一连几天……”，有“很长时间”的意味：[Он мо́жет часа́ми сиде́ть за компью́тером]{.ru}。

**顺序。** 序数词和 [после́дний]{.ru} 的第五格表示做某事的先后：[Пе́рвым расска́зывал Ван Лэй]{.ru}（第一个讲的是王磊），[Она́ пришла́ после́дней]{.ru}（她最后一个到）。形容词与主语的性、数一致：[Пе́рвой вы́шла А́нна]{.ru}，[Пе́рвыми пришли́ студе́нты]{.ru}。

**全体、集体。** [всей семьёй]{.ru}（全家一起），[всем кла́ссом]{.ru}（全班一起），[всей гру́ппой]{.ru}；复数第五格表示以什么方式成群：[толпо́й, толпа́ми, гру́ппами, па́рами, деся́тками, ты́сячами]{.ru}：[Лю́ди шли толпа́ми]{.ru}，[Пти́цы летя́т ста́ями]{.ru}。

**俄汉差异。** 汉语用“用”“拿”“坐”“被”“像……一样”“一起”等词表达的关系，俄语许多由第五格单独表示。最常见的错误是给第五格加上前置词：把“用笔写”说成 \*[писа́ть с ру́чкой]{.ru}，把“被托尔斯泰写的”说成 \*[напи́сан от Толсто́го]{.ru}。

工具和方式：

::: ex
[Ми́ша пи́шет **карандашо́м**.]{.ru}

[米沙用铅笔写字。]{.gloss}

[Ба́бушка ре́жет хлеб **ножо́м**.]{.ru}

[奶奶用刀切面包。]{.gloss}

[Ван Лэй кивну́л **голово́й**.]{.ru}

[王磊点了点头。]{.gloss}

[В библиоте́ке говоря́т **шёпотом**.]{.ru}

[在图书馆里说话要小声。]{.gloss}
:::

路径和交通工具：

::: ex
[До дере́вни мы шли **ле́сом**.]{.ru}

[我们穿过树林走到村子。]{.gloss}

[Ле́том Ван Лэй е́дет домо́й **по́ездом**: так интере́снее, чем самолётом.]{.ru}

[夏天王磊坐火车回国：这比坐飞机有意思。]{.gloss}
:::

比较、施事和原因：

::: ex
[Ми́ша **стрело́й** вы́летел из ко́мнаты.]{.ru}

[米沙箭一样冲出了房间。]{.gloss}

[Э́тот собо́р был постро́ен **италья́нскими мастера́ми**.]{.ru}

[这座大教堂是意大利工匠建造的。]{.gloss}

[Но́чью все доро́ги занесло́ **сне́гом**.]{.ru}

[夜里所有的路都被雪埋了。]{.gloss}
:::

限定方面、尺寸、时间、顺序、全体：

::: ex
[Москва́-река́ — река́ **длино́й** о́коло пятисо́т киломе́тров.]{.ru}

[莫斯科河是一条长约五百公里的河。]{.gloss}

[**Ра́нним у́тром** мы вы́ехали на да́чу.]{.ru}

[一大早我们就出发去别墅了。]{.gloss}

[Ми́ша мо́жет **часа́ми** игра́ть в футбо́л.]{.ru}

[米沙可以一连几个小时踢足球。]{.gloss}

[На экза́мен А́нна пришла́ **пе́рвой**.]{.ru}

[安娜第一个来参加考试。]{.gloss}

[В воскресе́нье мы **всей семьёй** е́здили за́ город.]{.ru}

[星期天我们全家去了郊外。]{.gloss}
:::

### 常见错误

::: err
\*[Он пи́шет с ру́чкой.]{.ru}　→　[Он пи́шет **ру́чкой**.]{.ru}

工具用不带前置词的第五格。[с]{.ru} 加第五格表示伴随：[Он пришёл с дру́гом]{.ru}。
:::

::: err
\*[Рома́н напи́сан от Толсто́го.]{.ru}　→　[Рома́н напи́сан **Толсты́м**.]{.ru}

被动结构的施事用第五格，不按汉语“被”“由”加前置词。
:::

::: err
\*[Ра́ннее у́тро мы вы́ехали.]{.ru}　→　[**Ра́нним у́тром** мы вы́ехали.]{.ru}

带定语的时间名词作状语用第五格，形容词跟着变。
:::

::: err
\*[Мы е́здили за́ город с всей семьёй.]{.ru}　→　[Мы е́здили за́ город **всей семьёй**.]{.ru}

“全家一起”用不带前置词的第五格；要用前置词时说 [со всей семьёй]{.ru}（和全家人一起），[с]{.ru} 在 [вс-]{.ru} 前写 [со]{.ru}。
:::

## §3.7.4 第五格作表语和补语

### 形式

第五格作表语和补语的场合：

| 用法 | 典型的词 | 例子 |
|---|---|---|
| 表语（系词、半系词后） | [быть]{.ru}（过去时、将来时、不定式）, [стать, станови́ться, явля́ться, счита́ться, каза́ться, оказа́ться, остава́ться, рабо́тать]{.ru} | [Он был **студе́нтом**.]{.ru} [Она́ ста́ла **врачо́м**.]{.ru} |
| 动词的补语 | [занима́ться, интересова́ться, увлека́ться, руководи́ть, управля́ть, по́льзоваться, владе́ть, горди́ться]{.ru} | [занима́ться **спо́ртом**]{.ru} |
| 双重支配：[кого́ кем / что чем]{.ru} | [называ́ть, счита́ть, выбира́ть, назнача́ть]{.ru}；[угоща́ть, корми́ть, награжда́ть]{.ru} | [Его́ вы́брали **ста́ростой**.]{.ru} |
| 形容词的补语 | [дово́лен, бога́т, изве́стен, знамени́т, горд, за́нят]{.ru} | [дово́лен **рабо́той**]{.ru} |
| 无人称的 [па́хнет]{.ru} | [па́хнет, па́хло]{.ru} | [па́хнет **ро́зами**]{.ru} |

### 意义和用法

**表语。** 系词 [быть]{.ru} 在过去时、将来时、不定式、命令式里，表语名词规范上用第五格：[Он был инжене́ром]{.ru}，[Я бу́ду перево́дчиком]{.ru}，[Я хочу́ быть врачо́м]{.ru}，[Будь дру́гом!]{.ru}。现在时不用系词，表语用第一格（[Он инжене́р]{.ru}，见 §3.5.1）。半系词后的表语总用第五格：[стать / станови́ться]{.ru}（成为），[явля́ться]{.ru}（是，书面语），[счита́ться]{.ru}（被认为是），[каза́ться / показа́ться]{.ru}（看起来是），[оказа́ться]{.ru}（原来是），[оста́ться / остава́ться]{.ru}（仍是），[рабо́тать, служи́ть]{.ru}（当……）：[Москва́ явля́ется столи́цей Росси́и]{.ru}，[Он счита́ется лу́чшим врачо́м го́рода]{.ru}。表语第一格与第五格的分工、系词和半系词的全部问题在 §12.2.4 讲。

**要求第五格的动词。** 只举典型的，全表见附录五：

| 意义 | 动词 | 例子 |
|---|---|---|
| 从事、兴趣 | [занима́ться, интересова́ться, увлека́ться, восхища́ться, любова́ться, наслажда́ться]{.ru} | [занима́ться му́зыкой]{.ru}，[интересова́ться исто́рией]{.ru}，[любова́ться зака́том]{.ru} |
| 领导、管理 | [руководи́ть, управля́ть, кома́ндовать, заве́довать]{.ru} | [руководи́ть заво́дом]{.ru}，[управля́ть маши́ной]{.ru} |
| 使用、掌握 | [по́льзоваться, владе́ть, облада́ть, располага́ть]{.ru} | [по́льзоваться словарём]{.ru}，[владе́ть тремя́ языка́ми]{.ru} |
| 态度 | [горди́ться, дорожи́ть, же́ртвовать, рискова́ть, пренебрега́ть]{.ru} | [горди́ться сы́ном]{.ru}，[рискова́ть жи́знью]{.ru} |
| 病 | [боле́ть / заболе́ть]{.ru}（患……病） | [боле́ть гри́ппом]{.ru} |
| 交换、分享 | [обме́ниваться, де́литься]{.ru}（[с кем]{.ru}） | [обме́ниваться о́пытом]{.ru}，[де́литься впечатле́ниями]{.ru} |

[занима́ться]{.ru} 除了“从事、搞”，不带补语时还表示“学习、用功”（[Ми́ша занима́ется в свое́й ко́мнате]{.ru}）；[интересова́ться]{.ru} 和 [нра́виться]{.ru}、[люби́ть]{.ru} 表达的意思相近，结构各不相同：[Я интересу́юсь му́зыкой]{.ru}，[Мне нра́вится му́зыка]{.ru}，[Я люблю́ му́зыку]{.ru}。

**双重支配。** 有些及物动词除第四格外还带一个第五格：

- 称作、认作、选作、任命为：[называ́ть кого́ кем / что чем]{.ru}（[Его́ на́звали Ива́ном]{.ru}，[Э́то нельзя́ назва́ть успе́хом]{.ru}），[счита́ть кого́ кем]{.ru}（[Я счита́ю его́ дру́гом]{.ru}），[выбира́ть / вы́брать кого́ кем]{.ru}（[Её вы́брали ста́ростой]{.ru}），[назнача́ть / назна́чить кого́ кем]{.ru}（[Его́ назна́чили дире́ктором]{.ru}），[де́лать кого́ кем]{.ru}。这里的第五格是说明第四格补语的表语。
- 用什么招待、喂、奖励、填满：[угоща́ть кого́ чем]{.ru}（[Ма́ма угоща́ет госте́й пирого́м]{.ru}），[корми́ть кого́ чем]{.ru}，[награжда́ть кого́ чем]{.ru}，[заполня́ть что чем]{.ru}，见 §12.1.3。

[называ́ться]{.ru} 后普通名词用第五格（[Э́то называ́ется дру́жбой]{.ru}），专有名称用第一格（[Ста́нция называ́ется «Арба́тская»]{.ru}），见 §3.5.1。

**要求第五格的形容词。** [дово́лен]{.ru}（满意），[бога́т]{.ru}（富于），[изве́стен, знамени́т]{.ru}（以……闻名），[горд]{.ru}（为……骄傲），[за́нят]{.ru}（忙于），[си́лен, слаб]{.ru}（在……方面强、弱）：[Я дово́лен рабо́той]{.ru}，[Росси́я бога́та леса́ми]{.ru}，[Го́род изве́стен свои́ми теа́трами]{.ru}，[Он за́нят де́лом]{.ru}。长尾形容词也能带第五格（[бога́тая не́фтью страна́]{.ru}）。短尾形容词的用法见 §4.2.2，形容词的支配见 §12.1.5。

**[па́хнет]{.ru}。** [па́хнуть]{.ru}（散发气味）后面的气味来源用第五格：[Цветы́ па́хнут мёдом]{.ru}；常用无人称形式 [па́хнет, па́хло]{.ru}：[В ко́мнате па́хнет ро́зами]{.ru}，[Па́хло дождём и се́ном]{.ru}，[Чем э́то па́хнет?]{.ru}。

**俄汉差异。** 这些动词在汉语里多用“对……感兴趣”“为……自豪”“领导……”“使用……”表示，俄语的格要随动词记。受汉语影响，常给 [интересова́ться]{.ru} 加 [к]{.ru} 或 [в]{.ru}，给 [горди́ться]{.ru} 加 [за]{.ru}，或者把 [руководи́ть, по́льзоваться]{.ru} 当作普通及物动词带第四格。

表语：

::: ex
[По́сле университе́та А́нна ста́нет **перево́дчицей**.]{.ru}

[大学毕业后安娜会当翻译。]{.gloss}

[Пу́шкин счита́ется **основополо́жником** ру́сского литерату́рного языка́.]{.ru}

[普希金被认为是俄语标准语的奠基人。]{.gloss}
:::

动词的补语：

::: ex
[Ми́ша занима́ется **футбо́лом**, а А́нна интересу́ется **жи́вописью**.]{.ru}

[米沙踢足球，安娜对绘画感兴趣。]{.gloss}

[Ива́н Серге́евич руководи́т **отде́лом** на заво́де.]{.ru}

[伊万·谢尔盖耶维奇在工厂领导一个科室。]{.gloss}

[На экза́мене мо́жно по́льзоваться **словарём**.]{.ru}

[考试时可以用词典。]{.gloss}

[Роди́тели гордя́тся **сы́ном**.]{.ru}

[父母为儿子感到骄傲。]{.gloss}
:::

双重支配、形容词和 [па́хнет]{.ru}：

::: ex
[Студе́нты вы́брали Пье́ра **ста́ростой**.]{.ru}

[同学们选皮埃尔当班长。]{.gloss}

[Мари́я Никола́евна угости́ла нас **блина́ми**.]{.ru}

[玛丽亚·尼古拉耶芙娜请我们吃了薄饼。]{.gloss}

[Преподава́тель дово́лен на́шими **успе́хами**.]{.ru}

[老师对我们的进步很满意。]{.gloss}

[В ку́хне вку́сно па́хнет **пирога́ми**.]{.ru}

[厨房里飘着馅饼的香味。]{.gloss}
:::

### 常见错误

::: err
\*[Он интересу́ется к исто́рии.]{.ru}　→　[Он интересу́ется **исто́рией**.]{.ru}

按汉语“对……感兴趣”加了前置词。[интересова́ться]{.ru} 带不加前置词的第五格；名词 [интере́с]{.ru} 才用 [к]{.ru}：[интере́с к исто́рии]{.ru}。
:::

::: err
\*[Я по́льзуюсь компью́тер ка́ждый день.]{.ru}　→　[Я по́льзуюсь **компью́тером** ка́ждый день.]{.ru}

[по́льзоваться]{.ru} 要求第五格，不是及物动词。
:::

::: err
\*[Мы горди́мся за на́шу страну́.]{.ru}　→　[Мы горди́мся **на́шей страно́й**.]{.ru}

[горди́ться]{.ru} 的对象用第五格。[горди́ться за кого́]{.ru}（替别人感到骄傲）口语里也说，但不是规范用法。
:::

::: err
\*[Его́ вы́брали ста́роста.]{.ru}　→　[Его́ вы́брали **ста́ростой**.]{.ru}

“选谁当什么”的“什么”用第五格。
:::

## §3.7.5 第六格的用法

### 形式

第六格只和前置词连用，所以又叫前置格；它的问题是 [о ком? о чём?]{.ru}、[где?]{.ru}（带 [в, на]{.ru}）。要求第六格的前置词只有五个：[в (во), на, о (об, обо), при, по]{.ru}。下表按前置词列出第六格的全部意义，各意义的规则在“详见”栏的节里讲：

| 前置词 | 意义 | 例子 | 详见 |
|---|---|---|---|
| [в]{.ru} | 处所：在……里面 | [в ко́мнате, в Москве́, в шко́ле]{.ru} | §9.2.1 |
| | 时间：月份、年、世纪、年龄段 | [в январе́, в э́том году́, в XX ве́ке, в де́тстве]{.ru} | §9.3.1 |
| | 穿着 | [в пальто́, в очка́х, в бе́лом пла́тье]{.ru} | §9.2.1 |
| | 状态、范围、距离 | [в восто́рге, в о́бласти фи́зики, в двух киломе́трах от го́рода]{.ru} | §9.4.8 |
| [на]{.ru} | 处所：在……上面；在某些地方、活动中 | [на столе́, на у́лице, на рабо́те, на конце́рте]{.ru} | §9.2.1 |
| | 时间：星期、某些时期 | [на э́той неде́ле, на кани́кулах]{.ru} | §9.3.1 |
| | 交通工具 | [на авто́бусе, на метро́]{.ru} | §7.6.4 |
| | 乐器、语言、其他 | [игра́ть на гита́ре, говори́ть на ру́сском языке́, жени́ться на ней]{.ru} | §9.4.6、§12.1.4 |
| [о (об, обо)]{.ru} | 涉及：关于 | [говори́ть о кни́ге, ду́мать об э́том, обо мне]{.ru} | §9.4.2 |
| [при]{.ru} | 时期：在……时代、在……的时候 | [при Петре́ Пе́рвом, при встре́че]{.ru} | §9.3.3 |
| | 条件、在场、附属 | [при жела́нии, при свиде́телях, шко́ла при университе́те]{.ru} | §9.4.3 |
| [по]{.ru} | ……之后（书面） | [по прие́зде, по оконча́нии университе́та]{.ru} | §9.4.5 |

前置词按格的总表见附录七。

### 意义和用法

**只和前置词连用。** 第一格以外的四个间接格都能不带前置词使用，第六格不能：它总跟在 [в, на, о, при, по]{.ru} 中的一个后面，意义也主要由前置词表示。同一个前置词带不同的格意义不同：[в]{.ru}、[на]{.ru} 加第六格表示在哪里（[где?]{.ru}），加第四格表示到哪里去（[куда́?]{.ru}）：[Он в шко́ле — Он идёт в шко́лу]{.ru}，[Кни́га на столе́ — Положи́ кни́гу на стол]{.ru}；[по]{.ru} 加第六格是“……之后”，加第三格是“沿着、按照”等（见 §9.4.5）。所以学第六格要和前置词一起学。

**处所和时间。** [в]{.ru} 和 [на]{.ru} 表示处所是第六格最常用的意义：[в]{.ru} 指在立体空间的内部，[на]{.ru} 指在表面上；许多名词习惯用 [на]{.ru}（[на рабо́те, на ку́хне, на по́чте, на вокза́ле, на заво́де, на ры́нке]{.ru}），要逐词记，见 §9.2.1。表示时间时，月份、年、世纪用 [в]{.ru} 加第六格（[в ма́е, в про́шлом году́]{.ru}），星期用 [на]{.ru} 加第六格（[на сле́дующей неде́ле]{.ru}），星期几、钟点用 [в]{.ru} 加第四格，总表见 §9.3.1。

**[-у́]{.ru} 形式只用于 [в, на]{.ru} 后。** 少数阳性名词在 [в, на]{.ru} 后表示处所、时间时第六格是重读的 [-у́, -ю́]{.ru}：[в лесу́, в саду́, на берегу́, в году́, в краю́]{.ru}；在 [о]{.ru} 等前置词后用普通的 [-е]{.ru}：[о ле́се, о са́де, о бе́реге]{.ru}。这类名词的词表和规则见 §3.2.8。[-ь]{.ru} 阴性名词在 [в, на]{.ru} 后的重读 [-и́]{.ru}（[в тени́, в степи́]{.ru}）也在那里讲。

**[о, об, обо]{.ru}。** [о]{.ru} 表示说、想、写、问的内容：[говори́ть, ду́мать, писа́ть, расска́зывать, спра́шивать, мечта́ть, забо́титься, сожале́ть, по́мнить о ком-чём]{.ru}；名词也可以带：[расска́з о войне́, кни́га о Москве́, мечта́ о мо́ре]{.ru}。在元音开头的词前写 [об]{.ru}（[об Ива́не, об э́том, об о́тпуске]{.ru}），在 [мне, всём, всех]{.ru} 前写 [обо]{.ru}（[обо мне, обо всём]{.ru}），见 §9.1.2。带 [о]{.ru} 的涉及意义和近义的 [про]{.ru} 加第四格、[насчёт]{.ru} 加第二格见 §9.4.2。

**要求第六格的动词。** 有些动词要求 [в]{.ru} 或 [на]{.ru} 加第六格的补语，这时前置词不再表示处所：[сомнева́ться в чём]{.ru}（怀疑），[уча́ствовать в чём]{.ru}（参加），[нужда́ться в чём]{.ru}（需要），[убежда́ться в чём]{.ru}（确信），[обвиня́ть кого́ в чём]{.ru}（指控），[признава́ться в чём]{.ru}（承认），[разбира́ться в чём]{.ru}（懂得）；[игра́ть на чём]{.ru}（演奏），[жени́ться на ком]{.ru}（娶），[наста́ивать на чём]{.ru}（坚持），[осно́вываться на чём]{.ru}（以……为根据）。带前置词的补语见 §12.1.4。

**俄汉差异。** 汉语的“在……里”“在……上”是介词加方位词，俄语用前置词加第六格，方位词的意思由前置词承担，名词本身要变格。“关于……”在汉语里多放在名词前作定语（“关于莫斯科的书”），俄语放在名词后：[кни́га о Москве́]{.ru}。

处所、时间、穿着：

::: ex
[Ван Лэй у́чится в **университе́те**, а живёт в **семье́** Петро́вых.]{.ru}

[王磊在大学学习，住在彼得罗夫家。]{.gloss}

[Кни́ги лежа́т на **по́лке** в **шкафу́**.]{.ru}

[书放在柜子的搁板上。]{.gloss}

[Ми́ша роди́лся в **ма́е**.]{.ru}

[米沙是五月出生的。]{.gloss}

[На **э́той неде́ле** у нас экза́мены.]{.ru}

[这个星期我们有考试。]{.gloss}

[Пришла́ де́вушка в **си́нем пальто́**.]{.ru}

[来了一个穿蓝大衣的姑娘。]{.gloss}
:::

[о]{.ru}、[при]{.ru}、[по]{.ru}：

::: ex
[Мы говори́ли о **рабо́те** и об **о́тпуске**.]{.ru}

[我们谈了工作和休假的事。]{.gloss}

[Расскажи́ мне о **себе́**.]{.ru}

[跟我讲讲你自己。]{.gloss}

[Петербу́рг был осно́ван при **Петре́** Пе́рвом.]{.ru}

[彼得堡是在彼得一世时建立的。]{.gloss}

[По **оконча́нии** университе́та она́ уе́хала в Сиби́рь.]{.ru}

[大学毕业后她去了西伯利亚。]{.gloss}
:::

要求第六格的动词：

::: ex
[Ми́ша уча́ствует в **шко́льном конце́рте**.]{.ru}

[米沙参加学校的音乐会。]{.gloss}

[Я не сомнева́юсь в **успе́хе**.]{.ru}

[我对成功毫不怀疑。]{.gloss}

[А́нна хорошо́ игра́ет на **роя́ле**.]{.ru}

[安娜钢琴弹得很好。]{.gloss}
:::

### 常见错误

::: err
\*[Он живёт Москве́.]{.ru}　→　[Он живёт **в** Москве́.]{.ru}

第六格不能离开前置词单独使用。
:::

::: err
\*[Мы гуля́ли в ле́се.]{.ru}　→　[Мы гуля́ли **в лесу́**.]{.ru}；\*[Расскажи́ о лесу́.]{.ru}　→　[Расскажи́ **о ле́се**.]{.ru}

[-у́]{.ru} 形式只用于 [в, на]{.ru} 后表示处所，[о]{.ru} 后用普通的 [-е]{.ru}。
:::

::: err
\*[Он говори́т на ру́сский язы́к.]{.ru}　→　[Он говори́т **на ру́сском языке́**.]{.ru}（[**по-ру́сски**]{.ru}）

“用某种语言”是 [на]{.ru} 加第六格。[на]{.ru} 加第四格是“译成某种语言”：[перевести́ на ру́сский язы́к]{.ru}。
:::

::: err
\*[по прие́зду]{.ru}　→　[**по прие́зде**]{.ru}

“……之后”的 [по]{.ru} 要求第六格；受 [по]{.ru} 加第三格（[по го́роду]{.ru}）的影响，常写成第三格。
:::
