本附录汇总第七编第 8、9 章讲的四种形动词和两种副动词的构成：后缀，由哪个词干构成，代表词，重音，以及不能构成的情况。各表注明讲解的节。

## 一、总表

六种非变位形式的构成（§7.8.1、§7.9.1）。“词干”一栏指 §7.1.1 的两个词干：

| 形式 | 由什么构成 | 后缀 | 能构成的动词 | 代表词 | 节 |
|---|---|---|---|---|---|
| 主动形动词现在时 | 复数第三人称去 [-т]{.ru} | [-ущ-, -ющ-]{.ru}（第一变位），[-ащ-, -ящ-]{.ru}（第二变位） | 未完成体 | [чита́ющий, несу́щий, говоря́щий, лежа́щий]{.ru} | §7.8.2 |
| 主动形动词过去时 | 过去时阳性 | [-вш-]{.ru}（[-л]{.ru} 后），[-ш-]{.ru}（辅音后） | 两种体 | [чита́вший, прочита́вший, нёсший, вы́росший]{.ru} | §7.8.3 |
| 被动形动词现在时 | 复数第一人称 | [-ем-, -им-]{.ru}；书面 [-ом-]{.ru} | 未完成体及物动词 | [чита́емый, люби́мый, иско́мый]{.ru} | §7.8.4 |
| 被动形动词过去时 | 不定式词干；[-ить]{.ru} 等由单数第一人称的词干 | [-нн-, -енн- (-ённ-), -т-]{.ru} | 主要是完成体及物动词 | [прочи́танный, ку́пленный, решённый, откры́тый]{.ru} | §7.8.5 |
| 未完成体副动词 | 复数第三人称去词尾 | [-я]{.ru}（[ж, ш, ч, щ]{.ru} 后 [-а]{.ru}） | 未完成体 | [чита́я, говоря́, слы́ша, занима́ясь]{.ru} | §7.9.2 |
| 完成体副动词 | 不定式词干；[-йти, -сти, -зти]{.ru} 由将来时词干 | [-в, -вшись, -ши]{.ru}；[-я]{.ru} | 完成体 | [прочита́в, верну́вшись, вы́росши, придя́]{.ru} | §7.9.3 |

所有形动词都按长尾形容词变格（§7.8.1）：主动形动词按 [хоро́ший]{.ru}，被动形动词按 [но́вый]{.ru}；[-ся]{.ru} 在形动词里一律写 [-ся]{.ru}（[занима́ющаяся]{.ru}），在副动词里写 [-сь]{.ru}（[занима́ясь, верну́вшись]{.ru}）。被动形动词有短尾（§7.8.6），主动形动词没有。

## 三、主动形动词现在时

### 构成

把现在时复数第三人称的 [-т]{.ru} 换成 [-щий]{.ru}，后缀的元音与复数第三人称一致（§7.8.2）：

| 复数第三人称 | 后缀 | 例 |
|---|---|---|
| [-ут]{.ru}（第一变位） | [-ущ-]{.ru} | [иду́т → иду́щий, несу́т → несу́щий, пи́шут → пи́шущий, и́щут → и́щущий, пла́чут → пла́чущий, беру́т → беру́щий, мо́гут → могу́щий, пеку́т → пеку́щий, бегу́т → бегу́щий]{.ru} |
| [-ют]{.ru}（第一变位） | [-ющ-]{.ru} | [чита́ют → чита́ющий, уме́ют → уме́ющий, рису́ют → рису́ющий, даю́т → даю́щий, пьют → пью́щий, пою́т → пою́щий, мо́ют → мо́ющий, ко́лют → ко́лющий]{.ru} |
| [-ат]{.ru}（第二变位） | [-ащ-]{.ru} | [крича́т → крича́щий, лежа́т → лежа́щий, слы́шат → слы́шащий, де́ржат → держа́щий, слу́жат → слу́жащий, у́чатся → уча́щийся]{.ru} |
| [-ят]{.ru}（第二变位） | [-ящ-]{.ru} | [говоря́т → говоря́щий, стоя́т → стоя́щий, хо́дят → ходя́щий, лю́бят → лю́бящий, ви́дят → ви́дящий, хотя́т → хотя́щий, едя́т → едя́щий]{.ru} |

构成上要注意的几类动词：

| 情况 | 规则 | 例 |
|---|---|---|
| [-ава́ть]{.ru} 动词 | 由现在时构成，没有 [-ва-]{.ru} | [даю́щий, встаю́щий, узнаю́щий, продаю́щий]{.ru} |
| 第一变位全部人称交替 | 形动词也交替 | [пи́шущий, и́щущий, пла́чущий, ре́жущий]{.ru} |
| 第二变位单数第一人称交替 | 形动词不交替 | [ходя́щий, прося́щий, лю́бящий, ви́дящий]{.ru} |
| [-чь]{.ru} 动词 | 保留 [г, к]{.ru} | [могу́щий, пеку́щий, берегу́щий, теку́щий]{.ru} |
| 不规则变位动词 | 以复数第三人称为准 | [хотя́щий, бегу́щий, едя́щий, иду́щий, е́дущий]{.ru} |
| [-ся]{.ru} 动词 | 一律加 [-ся]{.ru} | [занима́ющийся, уча́щийся, смею́щийся]{.ru} |

### 重音

主动形动词现在时的重音由现在时的重音决定（§7.8.2）：

| 动词 | 重音 | 例 |
|---|---|---|
| 第一变位 | 同复数第三人称 | [пи́шущий, и́щущий, ко́лющий, иду́щий, живу́щий, тя́нущий]{.ru} |
| 第一变位的例外 | 重读词尾 | [могу́щий]{.ru}（[мо́гут]{.ru}） |
| 第二变位，重音不移动（a、b） | 同各人称 | [говоря́щий, крича́щий, лежа́щий, ви́дящий, слы́шащий, ве́рящий, гото́вящий]{.ru} |
| 第二变位，重音移动（c） | 多数同单数第一人称，重读后缀 | [ходя́щий, прося́щий, куря́щий, держа́щий, кормя́щий, платя́щий, дыша́щий, смотря́щий, уча́щийся]{.ru} |
| 第二变位，重音移动（c）的例外 | 同复数第三人称，重读词干 | [лю́бящий]{.ru}（[лю́бят]{.ru}），[слу́жащий]{.ru}（[слу́жат]{.ru}），[ле́чащий]{.ru}（[ле́чат]{.ru}） |

[стоя́щий]{.ru}（[стоя́ть]{.ru}，站着的）和 [сто́ящий]{.ru}（[сто́ить]{.ru}，值得的）靠重音区分。[слу́жащий]{.ru} 作名词是“职员”，[ле́чащий врач]{.ru} 是“主治医生”（§7.8.8）。

### 不能构成的情况

| 情况 | 动词 |
|---|---|
| 完成体动词 | 全部：[\*прочита́ющий]{.ru} 不存在，用 [прочита́вший]{.ru} 或从句 |
| 无人称动词 | [света́ть, смерка́ться, нездоро́виться, вечере́ть]{.ru} |
| [быть]{.ru} | 没有；[су́щий]{.ru} 今天是形容词（[су́щая пра́вда]{.ru}） |
| 能构成而很少用 | [могу́щий, хотя́щий, лгу́щий, жду́щий, зову́щий]{.ru}；书面语改用从句或别的动词（[хотя́щий → жела́ющий]{.ru}） |

## 四、主动形动词过去时

### 构成

由过去时阳性构成，未完成体和完成体都有（§7.8.3）：

| 过去时阳性 | 后缀 | 例 |
|---|---|---|
| 以 [-л]{.ru} 结尾 | 去 [-л]{.ru} 加 [-вший]{.ru} | [чита́л → чита́вший, говори́л → говори́вший, сказа́л → сказа́вший, был → бы́вший, дал → да́вший, взял → взя́вший, е́хал → е́хавший, ел → е́вший]{.ru} |
| 以辅音结尾 | 加 [-ший]{.ru} | [нёс → нёсший, вёз → вёзший, рос → ро́сший, мог → мо́гший, пёк → пёкший, берёг → берёгший, лёг → лёгший, у́мер → уме́рший, тёр → тёрший]{.ru} |

不从过去时构成的两类（§7.8.3）：

| 类别 | 构成 | 动词 |
|---|---|---|
| [идти́]{.ru} 及带前缀的 [-йти]{.ru} | 词干 [шед-]{.ru} 加 [-ший]{.ru} | [ше́дший, прише́дший, уше́дший, вы́шедший, проше́дший, наше́дший, произоше́дший, подоше́дший]{.ru} |
| [-сти]{.ru} 动词，现在时词干末是 [д, т]{.ru} | 现在时词干加 [-ший]{.ru} | [вести́ — ве́дший, мести́ — мётший, плести́ — плётший, цвести́ — цве́тший, брести́ — бре́дший, изобрести́ — изобре́тший, приобрести́ — приобре́тший]{.ru}；带前缀的 [переве́дший, приве́дший]{.ru} |

不定式以 [-сть]{.ru} 结尾的动词按一般规则由过去时构成：[сесть — се́вший, упа́сть — упа́вший, укра́сть — укра́вший, съесть — съе́вший, класть — кла́вший]{.ru}。

### 过去时去掉 [-ну-]{.ru} 的 [-нуть]{.ru} 动词

这些动词（词表见附录三第六部分）的主动形动词过去时有两种构成：由过去时加 [-ший]{.ru}，或由不定式词干加 [-вший]{.ru}（§7.8.3）：

| 情况 | 形动词 | 例 |
|---|---|---|
| 带前缀的完成体 | 一般由过去时构成，[-ший]{.ru} | [привы́кший, отвы́кший, поги́бший, замёрзший, возни́кший, прони́кший, вы́сохший, промо́кший, исся́кший, пога́сший, осле́пший, огло́хший, окре́пший, све́ргший]{.ru} |
| 例外 | 保留 [-ну-]{.ru} | [исче́знувший]{.ru} |
| 两可 | 两种都用 | [дости́гший]{.ru} / [дости́гнувший]{.ru}，[избе́гший]{.ru} / [избе́гнувший]{.ru} |
| 不带前缀的未完成体 | 常保留 [-ну-]{.ru}，不带 [-ну-]{.ru} 的形式也用 | [со́хнувший, мо́кнувший, мёрзнувший, ги́бнувший, ки́снувший, кре́пнувший]{.ru}；[со́хший, мо́кший]{.ru} |

能产的 [-нуть]{.ru} 动词（过去时保留 [-ну-]{.ru}）照一般规则：[кри́кнувший, отдохну́вший, верну́вшийся]{.ru}。

由 [-л]{.ru} 过去时构成的形动词，重音同不定式，不随过去时的重音移动（§7.8.3）；由辅音词干构成的，重音同过去时阳性：

| [приня́ть]{.ru} | [при́нял]{.ru} | [приня́вший]{.ru} |
| [заня́ть]{.ru} | [за́нял]{.ru} | [заня́вший]{.ru} |
| [подня́ть]{.ru} | [по́днял]{.ru} | [подня́вший]{.ru} |
| [отда́ть]{.ru} | [о́тдал]{.ru} | [отда́вший]{.ru} |
| [прода́ть]{.ru} | [про́дал]{.ru} | [прода́вший]{.ru} |
| [умере́ть]{.ru} | [у́мер]{.ru} | [уме́рший]{.ru} |
| [запере́ть]{.ru} | [за́пер]{.ru} | [запе́рший]{.ru} |

### 不能构成的情况

几乎所有动词都有主动形动词过去时；没有的只是无人称动词（[света́ть, смерка́ться]{.ru}）。[мо́гший, помо́гший, лёгший]{.ru} 一类能构成而少用，书面语多改用 [кото́рый]{.ru} 从句（§7.8.3）。

## 五、被动形动词现在时

### 构成

由未完成体及物动词的复数第一人称加 [-ый]{.ru}（§7.8.4）：

| 情况 | 构成 | 例 |
|---|---|---|
| 第一变位 | [-ем]{.ru} → [-емый]{.ru} | [чита́емый, изуча́емый, уважа́емый, называ́емый, рису́емый, организу́емый, иссле́дуемый]{.ru} |
| 第二变位 | [-им]{.ru} → [-имый]{.ru} | [люби́мый, ви́димый, слы́шимый, проводи́мый, производи́мый, храни́мый, гони́мый]{.ru} |
| [-ава́ть]{.ru} 动词 | 不定式词干加 [-емый]{.ru}，保留 [-ва-]{.ru} | [дава́емый, издава́емый, передава́емый, признава́емый, узнава́емый, преподава́емый]{.ru} |
| 第一变位，例外用 [-им-]{.ru} | 保留交替 | [дви́гать — дви́жимый]{.ru} |
| 书面、旧式 [-ом-]{.ru}（辅音词干的第一变位动词） | [-ём]{.ru} → [-о́мый]{.ru} | [вести́ — ведо́мый, нести́ — несо́мый, иска́ть — иско́мый, влечь — влеко́мый]{.ru} |

### 重音

| 动词 | 重音 | 例 |
|---|---|---|

| [-йти, -сти, -зти]{.ru} | [-я]{.ru}，由将来时词干构成 | [придя́, войдя́, вы́йдя, уйдя́, найдя́, пройдя́, перейдя́; принеся́, унеся́, привезя́, увезя́, приведя́, переведя́, изобретя́; разойдя́сь]{.ru} |

不定式以 [-сть]{.ru} 结尾的动词按第一种用 [-в]{.ru}：[сесть → сев, укра́сть → укра́в, упа́сть → упа́в]{.ru}，不说 [\*ся́дя]{.ru}。

### 变体

| 形式 | 语体 | 例 |
|---|---|---|
| [-вши]{.ru}（不带 [-ся]{.ru} 的元音词干动词） | 口语、旧式，书面语不用 | [прочита́вши, сказа́вши]{.ru}（= [прочита́в, сказа́в]{.ru}）；十九世纪作品中常见，见 §15.2.2 |
| [-ши]{.ru}（辅音词干动词） | 少用，一般改用从句 | [помо́гши, лёгши]{.ru} |
| 旧式 [-я, -ясь]{.ru}，由将来时词干构成 | 十九世纪作品；今只在固定说法中，已成副词 | [уви́дя]{.ru}（= [уви́дев]{.ru}），[услы́ша]{.ru}，[взгромоздя́сь]{.ru}，[пону́ря го́лову]{.ru} |

### 重音

同不定式，不随过去时移动：[купи́в, верну́вшись, прочита́в; поня́в]{.ru}（[по́нял]{.ru}），[нача́в]{.ru}（[на́чал]{.ru}），[приня́в]{.ru}（[при́нял]{.ru}），[прода́в]{.ru}（[про́дал]{.ru}）。[-я]{.ru} 形式重读词尾（[придя́, принеся́]{.ru}），带 [вы́-]{.ru} 的例外（[вы́йдя, вы́неся]{.ru}）；[-ши]{.ru} 形式同过去时阳性（[вы́росши, стёрши]{.ru}）（§7.9.3）。

### 不能构成的情况

完成体动词几乎都有；无人称动词（[рассвести́]{.ru}）没有（§7.9.3）。
