名词主要用后缀法构成，也用零后缀法、合成法和缩略法（构词方式见 §11.1.2）。本章按意义分四节：§11.2.1 讲指人名词的后缀，包括阴性形式和国籍、居民名词；§11.2.2 讲抽象名词和动名词，以及动名词怎样改变动词的支配；§11.2.3 讲指小、表爱和指大、轻蔑的后缀；§11.2.4 讲复合名词、缩略词和截短词。名词的性见 §3.1.2、§3.1.3，后缀的写法见 §1.4.5，形容词、形动词转成的名词见 §4.1.6、§7.8.8。

## §11.2.1 指人名词的后缀

### 形式

[指人名词]{.term}（[существи́тельное со значе́нием лица́]{.ru}）大多由动词、名词或形容词加后缀构成，表示做某事的人、从事某种职业的人、具有某种特征的人或某地的人。下表是常用的后缀，所有这些名词都是阳性；阴性形式见第二张表。

| 后缀 | 生产词 | 例 | 变格、重音 |
|---|---|---|---|
| [-тель]{.ru .ix} | 动词（去掉 [-ть]{.ru}） | [учи́ть → учи́тель]{.ru}，[писа́ть → писа́тель]{.ru}，[чита́ть → чита́тель]{.ru}，[слу́шать → слу́шатель]{.ru}，[води́ть → води́тель]{.ru}，[покупа́ть → покупа́тель]{.ru}，[преподава́ть → преподава́тель]{.ru}，[иссле́довать → иссле́дователь]{.ru}，[жить → жи́тель]{.ru}，[люби́ть → люби́тель]{.ru}，[руководи́ть → руководи́тель]{.ru} | 按 [учи́тель]{.ru} 软变化；重音同不定式 |
| [-ник]{.ru .ix} | 名词、形容词 | [шко́ла → шко́льник]{.ru}，[отли́чный → отли́чник]{.ru}，[по́мощь → помо́щник]{.ru}，[рабо́та → рабо́тник]{.ru}，[уча́стие → уча́стник]{.ru}，[ро́дственный → ро́дственник]{.ru}，[совреме́нный → совреме́нник]{.ru} | 规则变化 |
| [-чик]{.ru .ix} | 动词、名词（词干末是 [д, т, з, с, ж]{.ru}） | [переводи́ть → перево́дчик]{.ru}，[лета́ть → лётчик]{.ru}，[рассказа́ть → расска́зчик]{.ru}，[разве́дать → разве́дчик]{.ru}，[подписа́ться → подпи́счик]{.ru}，[заказа́ть → зака́зчик]{.ru}，[перебежа́ть → перебе́жчик]{.ru} | 规则变化 |
| [-щик]{.ru .ix} | 动词、名词（其余辅音后） | [ка́мень → ка́менщик]{.ru}，[носи́ть → носи́льщик]{.ru}，[свари́ть → сва́рщик]{.ru}，[гардеро́б → гардеро́бщик]{.ru}，[убо́рка → убо́рщик]{.ru}，[кран → крановщи́к]{.ru}，[часы́ → часовщи́к]{.ru} | 规则变化 |
| [-ец]{.ru .ix} | 动词、形容词、名词（地名） | [продава́ть → продаве́ц]{.ru}，[петь → певе́ц]{.ru}，[боро́ться → боре́ц]{.ru}，[му́дрый → мудре́ц]{.ru}，[хра́брый → храбре́ц]{.ru}，[Кита́й → кита́ец]{.ru}，[Япо́ния → япо́нец]{.ru}，[иностра́нный → иностра́нец]{.ru} | [е]{.ru} 多半脱落（[продавца́, кита́йца]{.ru}）；后缀重读的，变格时重音移到词尾 |
| [-ист]{.ru .ix} | 外来名词 | [журна́л → журнали́ст]{.ru}，[футбо́л → футболи́ст]{.ru}，[пиани́но → пиани́ст]{.ru}，[гита́ра → гитари́ст]{.ru}，[тури́зм → тури́ст]{.ru}，[специали́ст, арти́ст, программи́ст, экономи́ст, оптими́ст]{.ru} | 后缀总是重读，重音不移 |
| [-ор, -ёр, -ер]{.ru .ix} | 外来词 | [дире́ктор, профе́ссор, а́втор, реда́ктор, организа́тор, регистра́тор]{.ru}；[актёр, шофёр, режиссёр, боксёр]{.ru}；[инжене́р, офице́р, ли́дер]{.ru} | [-ор]{.ru} 多不重读（[ревизо́р]{.ru} 重读）；[-ёр]{.ru} 重读；复数见 §3.3.1 |
| [-ант, -ент]{.ru .ix} | 外来词 | [аспира́нт, эмигра́нт, музыка́нт, практика́нт]{.ru}；[студе́нт, доце́нт, конкуре́нт, пацие́нт]{.ru} | 后缀重读，重音不移 |
| [-анин, -янин]{.ru .ix} | 地名、名词 | [А́нглия → англича́нин]{.ru}，[го́род → горожа́нин]{.ru}，[крестья́нин]{.ru}，[граждани́н]{.ru}，[Ки́ев → киевля́нин]{.ru}，[Рим → ри́млянин]{.ru}，[Пари́ж → парижа́нин]{.ru}，[юг → южа́нин]{.ru}，[се́вер → северя́нин]{.ru}，[Росси́я → россия́нин]{.ru} | 复数去掉 [-ин]{.ru}：[англича́не, горожа́не, киевля́не]{.ru}（§3.2.6、§3.3.1） |

### 意义和用法

**怎样选择后缀。** 后缀和生产词的词类、来源有大致的对应：由动词构成的多用 [-тель]{.ru}、[-чик / -щик]{.ru}、[-ец]{.ru}；由名词、形容词构成的多用 [-ник]{.ru}、[-ец]{.ru}、[-щик]{.ru}；外来词根用 [-ист, -ор, -ант]{.ru}。但同一类生产词用哪个后缀，由习惯定下来：[чита́ть → чита́тель]{.ru}，[переводи́ть → перево́дчик]{.ru}，[продава́ть → продаве́ц]{.ru}，三个动词三个后缀，不能互换。新词能按规则推出意思，不能按规则自己造。

**各后缀的特点。**

1. [-тель]{.ru} 名词带书面色彩，常和第二格连用：[чита́тель газе́ты, люби́тель му́зыки, жи́тель Москвы́, руководи́тель гру́ппы]{.ru}。[-ова-]{.ru} 动词保留 [-ова-]{.ru}：[иссле́довать → иссле́дователь]{.ru}。重音一般同不定式：[чита́ть → чита́тель]{.ru}；[-ить]{.ru} 动词的重音在 [-и́-]{.ru} 上：[учи́ть → учи́тель, води́ть → води́тель]{.ru}。[-тель]{.ru} 也构成表示器具的名词：[выключа́тель]{.ru}（开关）、[дви́гатель]{.ru}（发动机）、[измери́тель]{.ru}（测量仪）。
2. [-ник]{.ru} 名词多由带 [-н-]{.ru} 的形容词或由名词构成：[шко́льный → шко́льник]{.ru}，[отли́чный → отли́чник]{.ru}。[-ник]{.ru} 也构成表示物品、处所的名词：[ча́йник]{.ru}（水壶）、[уче́бник]{.ru}（课本）、[подоко́нник]{.ru}（窗台）、[бума́жник]{.ru}（钱包）。
3. [-чик]{.ru} 和 [-щик]{.ru} 是同一个后缀的两种写法：词干末是 [д, т, з, с, ж]{.ru} 时写 [-чик]{.ru}，其余辅音后写 [-щик]{.ru}；[л]{.ru} 后写 [-льщик]{.ru}（[носи́льщик, кро́вельщик]{.ru}）。[зч, сч, жч]{.ru} 读 [[щ]]{.tr}，[дч, тч]{.ru} 读长的 [[чʼ]]{.tr}，所以 [расска́зчик]{.ru}、[перебе́жчик]{.ru} 听起来和 [-щик]{.ru} 一样，写时要看后缀前的辅音（§1.4.5）。[-чик / -щик]{.ru} 多表示手艺和服务性职业。[-чик]{.ru} 还是指小后缀（[стака́нчик]{.ru}，§11.2.3），同形不同义。
4. [-ец]{.ru} 的 [е]{.ru} 是隐现元音：[продаве́ц — продавца́, певе́ц — певца́, боре́ц — борца́]{.ru}；元音后脱落时写 [й]{.ru}：[кита́ец — кита́йца, коре́ец — коре́йца]{.ru}（§3.2.9）。[мудре́ц — мудреца́]{.ru} 的 [е]{.ru} 不脱落。后缀重读时，变格的各格重音都在词尾：[певе́ц, певца́, певцу́; певцы́]{.ru}。
5. [-ист]{.ru} 名词常和 [-изм]{.ru} 名词成对：[тури́ст — тури́зм, оптими́ст — оптими́зм, реали́ст — реали́зм]{.ru}（§11.2.2）。
6. [-анин, -янин]{.ru} 名词复数去掉 [-ин]{.ru}：[англича́нин — англича́не, граждани́н — гра́ждане]{.ru}，复数第二格是零词尾：[англича́н, горожа́н, крестья́н]{.ru}（§3.3.2）。

**阴性形式。** 阴性后缀的选择大致跟着阳性后缀走：[-тель → -тельница]{.ru}，[-ник → -ница]{.ru}，[-чик → -чица]{.ru}，[-щик → -щица]{.ru}，[-ист → -истка]{.ru}，[-анин → -анка]{.ru}。[-ец]{.ru} 名词的阴性最不规则：[певе́ц → певи́ца]{.ru}，[продаве́ц → продавщи́ца]{.ru}，[кита́ец → китая́нка]{.ru}，[япо́нец → япо́нка]{.ru}，[не́мец → не́мка]{.ru}，要逐词记。

很多职业名词没有通用的阴性形式：[врач, инжене́р, профе́ссор, дире́ктор, доце́нт, мини́стр]{.ru}。指女性时用阳性名词，定语用阳性，过去时谓语可以用阴性（[Наш врач пришла́]{.ru}），详见 §3.1.3。有阴性形式的，用不用也看语体：[учи́тельница, писа́тельница, студе́нтка, журнали́стка]{.ru} 是中性的常用词；[-ша]{.ru}、[-иха]{.ru} 的形式（[секрета́рша, касси́рша, врачи́ха, повари́ха]{.ru}）是口语，有的带随便甚至轻视的口气，正式场合用阳性：[Она́ рабо́тает секретарём]{.ru}。[-ша]{.ru}、[-иха]{.ru} 在旧时还表示“某人的妻子”：[генера́льша]{.ru}（将军夫人）、[купчи́ха]{.ru}（商人的妻子，也指女商人），读 19 世纪作品时要注意。

**国籍名词和居民名词。** 表示国籍、民族的名词，男性多用 [-ец]{.ru}，女性多用 [-ка]{.ru}，少数用 [-анин / -анка]{.ru}（[англича́нин]{.ru}）或不带后缀（[францу́з, швед, каза́х, грузи́н]{.ru}）；“俄罗斯人”用形容词转成的名词 [ру́сский, ру́сская]{.ru}（§4.1.6），[россия́нин]{.ru}（俄罗斯公民，不论民族）是另一个词。民族、国籍和居民名词小写（§1.4.3）。

城市居民的名称最不规则：同一个后缀 [-ец]{.ru}，有的城市用（[петербу́ржец, ло́ндонец, новгоро́дец]{.ru}），有的城市用 [-ич]{.ru}（[москви́ч]{.ru}）、[-анин]{.ru}（[киевля́нин, парижа́нин]{.ru}）、[-ит]{.ru}（[одесси́т]{.ru}）、[-як]{.ru}（[туля́к]{.ru}）。拿不准时可以用 [жи́тель]{.ru} 加第二格：[жи́тель Пеки́на, жи́тели Шанха́я]{.ru}，这在任何情况下都对。

**俄汉差异。** 汉语用“者”“家”“员”“师”“手”“人”等构成指人名词（“读者、作家、演员、教师、歌手、中国人”），一般不分性别，需要时加“女”字。俄语靠后缀，而且大多数指人名词有阳性和阴性两种形式；没有阴性形式的职业名词指女性时，用阳性名词，而谓语和代词跟着实际的性别走。

动词构成的指人名词：

::: ex
[Э́тот **писа́тель** изве́стен всем **чита́телям**.]{.ru}

[这位作家所有的读者都知道。]{.gloss}

[Ван Лэй хо́чет стать **перево́дчиком**.]{.ru}

[王磊想当翻译。]{.gloss}

[**Продаве́ц** показа́л нам но́вые часы́.]{.ru}

[售货员给我们看了几块新手表。]{.gloss}
:::

阴性形式：

::: ex
[На́ша **учи́тельница** о́чень лю́бит свой предме́т.]{.ru}

[我们的女老师非常喜欢她教的课。]{.gloss}

[Ю́ми — **япо́нка**, а Пьер — **францу́з**.]{.ru}

### 常见错误

::: err
\*[Она́ рабо́тает перево́дщицей.]{.ru}　→　[Она́ рабо́тает **перево́дчицей**.]{.ru}

[-чик / -щик]{.ru} 按后缀前的辅音写：[перево́д-]{.ru} 末尾是 [д]{.ru}，写 [-чик]{.ru}，阴性 [-чица]{.ru}。[дч]{.ru} 读长的 [[чʼ]]{.tr}，听起来容易和 [-щик]{.ru} 混淆，不能按读音写。
:::

::: err
\*[Его́ жена́ — кита́ица.]{.ru}　→　[Его́ жена́ — **китая́нка**.]{.ru}

[-ец]{.ru} 名词的阴性形式不规则，[кита́ец]{.ru} 的阴性是 [китая́нка]{.ru}，要逐词记。
:::

::: err
\*[Моя́ сестра́ — врачи́ца.]{.ru}　→　[Моя́ сестра́ — **врач**.]{.ru}

[врач]{.ru} 没有规范的阴性形式，指女性也用 [врач]{.ru}。口语的 [врачи́ха]{.ru} 带随便的口气，不宜用来介绍自己的亲人。
:::

::: err
\*[В гру́ппе пять англича́нинов.]{.ru}　→　[В гру́ппе пять **англича́н**.]{.ru}

[-анин]{.ru} 名词的复数去掉 [-ин]{.ru}：[англича́не]{.ru}，复数第二格是 [англича́н]{.ru}。

## §11.2.2 抽象名词与动名词

### 形式

[抽象名词]{.term}（[отвлечённое существи́тельное]{.ru}）表示性质、状态、行为、学说等，主要由形容词、名词和动词加后缀构成。常用的后缀：

| 后缀 | 生产词 | 意义 | 性、变格 | 例 |
|---|---|---|---|---|
| [-ость, -есть]{.ru .ix} | 形容词 | 性质、状态 | 阴性，按 [тетра́дь]{.ru} | [но́вый → но́вость]{.ru}，[ско́рый → ско́рость]{.ru}，[сме́лый → сме́лость]{.ru}，[молодо́й → мо́лодость]{.ru}，[бли́зкий → бли́зость]{.ru}，[гото́вый → гото́вность]{.ru}，[гра́мотный → гра́мотность]{.ru}，[све́жий → све́жесть]{.ru} |
| [-ство, -ество]{.ru .ix} | 名词、形容词、动词 | 状态、关系、身份、活动；集体；机构 | 中性，按 [сло́во]{.ru} | [де́ти → де́тство]{.ru}，[ма́стер → мастерство́]{.ru}，[еди́ный → еди́нство]{.ru}，[бога́тый → бога́тство]{.ru}，[геро́й → геро́йство]{.ru}，[челове́к → челове́чество]{.ru}，[руководи́ть → руково́дство]{.ru}，[производи́ть → произво́дство]{.ru}，[знако́мый → знако́мство]{.ru} |
| [-изм]{.ru .ix} | 外来词根 | 学说、流派、倾向 | 阳性 | [реали́зм, тури́зм, оптими́зм, патриоти́зм, капитали́зм]{.ru} |
| [-аци(я)]{.ru .ix} | 外来词根（对应 [-ирова-, -изова-]{.ru} 动词） | 动作、过程；机构 | 阴性，按 [ста́нция]{.ru} | [организова́ть → организа́ция]{.ru}，[регистри́ровать → регистра́ция]{.ru}，[демонстри́ровать → демонстра́ция]{.ru}，[информи́ровать → информа́ция]{.ru}，[консульти́ровать → консульта́ция]{.ru} |
| [-от(а)]{.ru .ix} | 形容词 | 性质 | 阴性，重音多在词尾 | [красота́, доброта́, чистота́, простота́, теплота́, высота́, широта́, долгота́]{.ru} |
| [-ин(а)]{.ru .ix} | 形容词 | 性质；尺寸 | 阴性，重音在词尾 | [глубина́, тишина́, ширина́, длина́, величина́, седина́]{.ru} |
| [-изн(а)]{.ru} | 形容词 | 性质 | 阴性 | [белизна́, новизна́, желтизна́, дешеви́зна]{.ru} |
| 零后缀 | 形容词 | 性质；具有这种性质的地方 | 阴性，按 [тетра́дь]{.ru} | [синь, глушь, тишь, гладь, ширь, высь]{.ru}（书面、诗歌） |

[动名词]{.term}（[отглаго́льное существи́тельное]{.ru}）由动词构成，表示动作、过程或结果：

| 后缀 | 生产词 | 规则 | 例 |
|---|---|---|---|
| [-ани(е), -яни(е)]{.ru .ix} | [-ать, -ять]{.ru} 动词 | 不定式词干加 [-ние]{.ru} | [жела́ть → жела́ние]{.ru}，[понима́ть → понима́ние]{.ru}，[созда́ть → созда́ние]{.ru}，[призна́ть → призна́ние]{.ru}，[влия́ть → влия́ние]{.ru}，[написа́ть → написа́ние]{.ru}，[перепи́сывать → перепи́сывание]{.ru} |
| [-овани(е)]{.ru} | [-овать]{.ru} 动词 | 同上 | [образова́ть → образова́ние]{.ru}，[иссле́довать → иссле́дование]{.ru}，[голосова́ть → голосова́ние]{.ru}，[существова́ть → существова́ние]{.ru} |
| [-ени(е)]{.ru .ix} | [-ить, -еть]{.ru} 动词和辅音词干动词 | 交替同被动形动词过去时 | [реши́ть → реше́ние]{.ru}，[пригласи́ть → приглаше́ние]{.ru}，[освободи́ть → освобожде́ние]{.ru}，[употреби́ть → употребле́ние]{.ru}，[предста́вить → представле́ние]{.ru}，[произноси́ть → произноше́ние]{.ru}，[терпе́ть → терпе́ние]{.ru}，[спасти́ → спасе́ние]{.ru}，[произнести́ → произнесе́ние]{.ru} |
| [-ти(е)]{.ru .ix} | 单音节词根的 [-ыть, -ить, -ять]{.ru} 动词 | 对应 [-тый]{.ru} 形动词 | [откры́ть → откры́тие]{.ru}，[заня́ть → заня́тие]{.ru}，[приня́ть → приня́тие]{.ru}，[разви́ть → разви́тие]{.ru}，[взять → взя́тие]{.ru}，[прибы́ть → прибы́тие]{.ru} |
| [-к(а)]{.ru .ix} | 多为带前缀的动词 | 去掉动词后缀加 [-ка]{.ru} | [подгото́вить → подгото́вка]{.ru}，[прове́рить → прове́рка]{.ru}，[останови́ться → остано́вка]{.ru}，[покупа́ть → поку́пка]{.ru}，[пересе́сть → переса́дка]{.ru}，[доста́вить → доста́вка]{.ru}，[тренирова́ть → трениро́вка]{.ru}，[пое́хать → пое́здка]{.ru}，[стира́ть → сти́рка]{.ru} |
| 零后缀 | 多为带前缀的动词 | 去掉动词后缀 | [вы́йти → вы́ход]{.ru}，[перейти́ → перехо́д]{.ru}，[показа́ть → пока́з]{.ru}，[распа́сться → распа́д]{.ru}，[отдыха́ть → о́тдых]{.ru}，[прие́хать → прие́зд]{.ru}，[отъе́хать → отъе́зд]{.ru}，[осмотре́ть → осмо́тр]{.ru}，[обменя́ть → обме́н]{.ru}，[запусти́ть → за́пуск]{.ru} |
| 其他 | | | [-ба]{.ru}：[ходи́ть → ходьба́, боро́ться → борьба́, проси́ть → про́сьба, стреля́ть → стрельба́]{.ru}；[-тьба]{.ru}：[жени́ться → жени́тьба]{.ru}；[-ёж]{.ru}：[грабёж, платёж]{.ru}；[-ня]{.ru}（口语）：[беготня́, болтовня́, возня́]{.ru}；[-ок]{.ru}（一次）：[прыжо́к, толчо́к, рыво́к]{.ru} |

动名词的性和变格：[-ние, -тие]{.ru} 名词是中性，按 [зда́ние]{.ru} 变（单数第六格 [-ии]{.ru}：[в созда́нии]{.ru}，§3.2.3）；[-ка]{.ru} 名词是阴性；零后缀名词多是阳性。

### 意义和用法

**[-ость]{.ru} 名词的构成。** 形容词去掉词尾加 [-ость]{.ru}；[ж, ш, ч, щ]{.ru} 后写 [-есть]{.ru}（[све́жий → све́жесть]{.ru}）。重音一般留在形容词词干原来的位置（[сме́лый → сме́лость, гото́вый → гото́вность]{.ru}）；词尾重读的形容词，名词的重音多半移到词干第一个音节：[молодо́й → мо́лодость, живо́й → жи́вость, тупо́й → ту́пость]{.ru}。以 [-зкий]{.ru} 结尾的形容词，[-к-]{.ru} 构成名词时多半脱落：[бли́зкий → бли́зость, ни́зкий → ни́зость, у́зкий → у́зость]{.ru}（但 [ре́зкий → ре́зкость]{.ru}）；其他 [-кий]{.ru} 形容词一般保留 [-к-]{.ru}：[лёгкий → лёгкость, ре́дкий → ре́дкость, ги́бкий → ги́бкость]{.ru}。拿不准时查词典。

**抽象名词的分工。** 同一个形容词常常只用一个后缀构成抽象名词，用哪一个由习惯定下来：[но́вость]{.ru} 和 [новизна́]{.ru} 都由 [но́вый]{.ru} 构成，却是两个词，[но́вость]{.ru} 是“新闻，消息”，[новизна́]{.ru} 是“新颖”。[-ота]{.ru} 和 [-ина]{.ru} 有时意义分化：[ширина́]{.ru}（宽度）— [широта́]{.ru}（纬度；广阔），[длина́]{.ru}（长度）— [долгота́]{.ru}（经度），[высота́]{.ru}（高度）— [вышина́]{.ru}（高处，书面）。表示尺寸、度量的多用 [-ина]{.ru}（[высота́]{.ru} 例外）：[глубина́ о́зера, ширина́ доро́ги, длина́ моста́]{.ru}。[-ость]{.ru} 能产性最强，新的性质形容词几乎都能加 [-ость]{.ru}，而 [-ота, -ина, -изна]{.ru} 已经不再构成新词。但能产不等于可以随便用：“善良”是 [доброта́]{.ru}，没有 \*[до́брость]{.ru}（§11.3.6）。

**[-ство]{.ru} 的几种意义。** [-ство]{.ru} 由名词、形容词、动词构成，意义比较杂：状态、身份（[де́тство, ра́венство, геро́йство, мастерство́]{.ru}）；集体（[челове́чество, студе́нчество, крестья́нство]{.ru}）；活动（[произво́дство, руково́дство, строи́тельство, хозя́йство]{.ru}）；机构（[посо́льство, ко́нсульство, министе́рство]{.ru}）。[-ество]{.ru} 是它的变体，多在 [ч]{.ru} 和软辅音后（[челове́чество, студе́нчество]{.ru}）。

**动名词的构成。** 动名词的后缀由动词的类型决定：

1. [-ать, -ять, -овать]{.ru} 动词：不定式词干加 [-ние]{.ru}，得 [-ание, -яние, -ование]{.ru}：[жела́ть → жела́ние]{.ru}，[образова́ть → образова́ние]{.ru}。
2. [-ить]{.ru}、部分 [-еть]{.ru} 动词和以辅音为词干的动词：加 [-ение]{.ru}。[-ить]{.ru} 动词的词干末辅音交替，交替和被动形动词过去时 [-енный]{.ru} 相同（§7.8.5）：[приглаше́ние — приглашённый, освобожде́ние — освобождённый, употребле́ние — употреблённый]{.ru}；没有被动形动词的未完成体动词也按这个规则交替：[произноси́ть → произноше́ние]{.ru}。[-еть]{.ru} 动词多半不交替：[терпе́ть → терпе́ние]{.ru}，[ви́деть → ви́дение]{.ru}。和第一人称单数的交替多半一致（[приглашу́ — приглаше́ние]{.ru}），但 [-дить]{.ru} 动词是 [ж]{.ru} 对 [жд]{.ru}（[освобожу́ — освобожде́ние, рожу́ — рожде́ние]{.ru}），唇音的 [-еть]{.ru} 动词第一人称加 [л]{.ru} 而名词不加（[терплю́ — терпе́ние]{.ru}），所以以形动词为准。
3. 单音节词根的 [-ыть, -ить, -ять]{.ru} 动词：加 [-тие]{.ru}，和被动形动词 [-тый]{.ru} 对应：[откры́тый — откры́тие, при́нятый — приня́тие]{.ru}。
4. [-ся]{.ru} 在名词里去掉：[развива́ться → разви́тие, появи́ться → появле́ние, роди́ться → рожде́ние]{.ru}。

动名词多半不区分体：[изуче́ние]{.ru} 既对应 [изуча́ть]{.ru}，也对应 [изучи́ть]{.ru}；[реше́ние]{.ru} 既是“解决（的过程）”也是“决定”。由次生未完成体构成的 [-ывание]{.ru} 名词强调过程：[перепи́сывание те́кста]{.ru}（抄写文本这件事），[перепи́ска]{.ru} 则另有“通信”的意思。

**[-ка]{.ru} 和零后缀名词。** [-ка]{.ru} 名词多由带前缀的动词构成，常表示具体的、日常的动作：[подгото́вка к экза́мену, прове́рка рабо́т, переса́дка на другу́ю ли́нию, пое́здка на да́чу]{.ru}，语体中性，口语和书面语都用。零后缀名词多由带前缀的运动动词和 [-смотре́ть, -каза́ть]{.ru} 等构成：[вход, вы́ход, перехо́д, прие́зд, отъе́зд, осмо́тр, пока́з]{.ru}。一个动词由哪种方式构成名词，由习惯定下来：[прие́хать → прие́зд]{.ru}，不是 \*[прие́зжание]{.ru}；[отдыха́ть → о́тдых]{.ru}，不是 \*[отдыха́ние]{.ru}；[помога́ть → по́мощь]{.ru}，不是 \*[помога́ние]{.ru}；[чита́ть → чте́ние]{.ru}（来自古词根 [чт-]{.ru}），不是 \*[чита́ние]{.ru}。

**动名词的意义具体化。** 动名词常由“动作”转指动作的结果、地点、用具等，成为具体名词：[заня́тие]{.ru}（课；活动），[расписа́ние]{.ru}（时刻表），[упражне́ние]{.ru}（练习），[сочине́ние]{.ru}（作文），[зда́ние]{.ru}（楼房），[учрежде́ние]{.ru}（机关），[украше́ние]{.ru}（装饰品），[остано́вка]{.ru}（车站），[перехо́д]{.ru}（人行横道），[вы́ход]{.ru}（出口），[поку́пка]{.ru}（买的东西）。这些词可以有复数：[заня́тия, поку́пки, упражне́ния]{.ru}。

**动名词的支配。** 动词变成动名词，补语和主语的形式要跟着变：

1. 动词的第四格补语变成第二格：[изуча́ть исто́рию → изуче́ние исто́рии]{.ru}，[чита́ть стихи́ → чте́ние стихо́в]{.ru}，[стро́ить мост → строи́тельство моста́]{.ru}。
2. 不及物动词的主语变成第二格：[По́езд при́был → прибы́тие по́езда]{.ru}，[Студе́нты выступа́ют → выступле́ние студе́нтов]{.ru}。及物动词同时有主语和补语时，补语用第二格，主语用第五格：[Учёные изуча́ют кли́мат → изуче́ние кли́мата учёными]{.ru}。主语也常用物主代词表示：[его́ прие́зд, на́ше реше́ние]{.ru}。只有一个第二格时可能两读：[приглаше́ние дру́га]{.ru} 可以是“朋友发出的邀请”，也可以是“对朋友的邀请”（§3.6.1）。
3. 动词的其他支配不变：[помога́ть дру́гу → по́мощь дру́гу]{.ru}，[гото́виться к экза́мену → подгото́вка к экза́мену]{.ru}，[занима́ться спо́ртом → заня́тия спо́ртом]{.ru}，[руководи́ть заво́дом → руково́дство заво́дом]{.ru}，[уча́ствовать в конфере́нции → уча́стие в конфере́нции]{.ru}，[влия́ть на язы́к → влия́ние на язы́к]{.ru}。少数名词的支配和动词不同（[интересова́ться чем → интере́с к чему́]{.ru}），见 §12.1.5。
4. 修饰动词的副词变成修饰名词的形容词：[бы́стро реши́ть → бы́строе реше́ние]{.ru}，[ча́сто опа́здывать → ча́стые опозда́ния]{.ru}。

**书面色彩和名词性结构。** 动名词使句子紧凑，用得多就有书面色彩。科学、公文和新闻语体常把动词结构改成以动名词为中心的名词结构：[По́сле того́ как око́нчила шко́лу…]{.ru} → [По́сле оконча́ния шко́лы…]{.ru}；[Когда́ откро́ют ста́нцию…]{.ru} → [По́сле откры́тия ста́нции…]{.ru}。口语里一般用动词。名词性结构在公文语体中的用法见 §15.1.3。

**俄汉差异。** 汉语的“研究”“学习”“发展”名动同形，俄语必须换成动名词（[иссле́дование, изуче́ние, разви́тие]{.ru}），动名词的补语还要从第四格改成第二格：“研究历史”是 [изуча́ть исто́рию]{.ru}，“历史研究”“对历史的研究”是 [изуче́ние исто́рии]{.ru}。汉语“的”字结构的语序（“历史的研究”）和俄语相反，俄语第二格放在动名词后面。

抽象名词：

::: ex
[У меня́ для вас хоро́шая **но́вость**.]{.ru}

[我有个好消息告诉你们。]{.gloss}

[Ба́бушка ча́сто вспомина́ет свою́ **мо́лодость**.]{.ru}

[奶奶常常回忆自己的青春时代。]{.gloss}

[**Глубина́** о́зера — сто ме́тров.]{.ru}

[湖深一百米。]{.gloss}

[Его́ **доброта́** удиви́ла всех.]{.ru}

[他的善良让大家吃惊。]{.gloss}

动名词的构成和支配：

### 常见错误

::: err
\*[Изуче́ние исто́рию — интере́сное де́ло.]{.ru}　→　[**Изуче́ние исто́рии** — интере́сное де́ло.]{.ru}

动名词不能带第四格补语，动词的第四格补语变成第二格。
:::

::: err
\*[Э́то был большо́й ра́дость для нас.]{.ru}　→　[Э́то была́ **больша́я ра́дость** для нас.]{.ru}

[-ость]{.ru} 名词都是阴性，形容词和过去时谓语要用阴性。以 [-ь]{.ru} 结尾容易让人当成阳性名词。
:::

::: err
\*[Мы говори́ли о созда́не но́вого клу́ба.]{.ru}　→　[Мы говори́ли о **созда́нии** но́вого клу́ба.]{.ru}

[-ние, -тие]{.ru} 名词单数第六格是 [-ии]{.ru}，不写 [-е]{.ru}。[-ация]{.ru} 名词同样：[об организа́ции]{.ru}。
:::

::: err
\*[Спаси́бо за ва́ше помога́ние.]{.ru}　→　[Спаси́бо за ва́шу **по́мощь**.]{.ru}

不是每个动词都用 [-ние]{.ru} 构成名词：[помога́ть]{.ru} 的名词是 [по́мощь]{.ru}，[отдыха́ть]{.ru} 的是 [о́тдых]{.ru}，[чита́ть]{.ru} 的是 [чте́ние]{.ru}。
:::

## §11.2.3 指小、表爱和指大、轻蔑后缀

### 形式

名词加后缀可以表示“小”和说话人的感情（亲昵、温柔、客气），或者表示“大”和粗鲁、轻视。前一类叫[指小表爱后缀]{.term}（[уменьши́тельно-ласка́тельный су́ффикс]{.ru}），后一类有[指大后缀]{.term}（[увеличи́тельный су́ффикс]{.ru}）和表示轻蔑的后缀。加了这些后缀，名词的性不变。

### 意义和用法

**“小”和“感情”。** 指小表爱后缀有两种意义：一是实际的小（[до́мик]{.ru} 小房子，[сто́лик]{.ru} 小桌子），二是说话人的感情。后一种在口语里常常更重要：[Пода́й мне ло́жечку]{.ru} 不一定指小勺子，是说话随和；[Подожди́те мину́точку!]{.ru} 不是“小分钟”，是客气的“稍等”。服务行业、对孩子说话、亲人之间常用指小形式：[Ваш сто́лик у окна́]{.ru}，[Мо́жно ча́йку?]{.ru}。

**一次指小和二次指小。** [мину́та → мину́тка → мину́точка]{.ru}，[окно́ → око́шко → око́шечко]{.ru}，[сын → сыно́к → сыно́чек]{.ru}：第二次指小的感情色彩更浓。第一次指小的形式常常已经失去“小”的意思，成了独立的词（见下文），要表示“小”只能再指小一次：[ча́шка]{.ru}（杯子，已经是普通的词）→ [ча́шечка]{.ru}（小杯子）。

**后缀的选择。** 阳性名词用 [-ик]{.ru} 还是 [-ок]{.ru}，由习惯定下来，要逐词记：[дом → до́мик]{.ru}，[го́род → городо́к]{.ru}，不能互换。大致的倾向是：单音节的硬辅音词干多用 [-ик]{.ru}（[до́мик, сто́лик, но́сик]{.ru}），以 [г, к, х]{.ru} 结尾的多用 [-ок]{.ru}（[дружо́к, пирожо́к, петушо́к]{.ru}），多音节词干多用 [-чик]{.ru}（[стака́нчик, чемода́нчик]{.ru}）。阴性名词最常用 [-к-]{.ru}，再指小用 [-очк- / -ечк-]{.ru}；[-оньк- / -еньк-]{.ru} 和 [-ушк-]{.ru} 带民间、诗歌色彩。

**指小后缀与变格。** [-ок, -ёк, -ец, -очек]{.ru} 的 [о, е]{.ru} 是隐现元音：[сыно́к — сынка́, огонёк — огонька́, цвето́чек — цвето́чка]{.ru}，重读的 [-ок, -ёк]{.ru} 变格时重音移到词尾（[сынку́, сынки́]{.ru}）。[-ка, -очка]{.ru} 名词复数第二格出现隐现元音：[ру́чка — ру́чек, мину́точка — мину́точек]{.ru}。[-ушка, -юшка]{.ru} 构成的阳性名词（[де́душка, дя́дюшка]{.ru}）按第二变格法变，一致用阳性（§3.1.3）。

**意义分化和独立成词。** 许多指小形式已经有了自己的意义，成为独立的词：

| 原词 | 指小形式 | 独立的意义 |
|---|---|---|
| [рука́]{.ru} 手 | [ру́чка]{.ru .ix} | 小手；笔；把手 |
| [нога́]{.ru} 脚 | [но́жка]{.ru} | 小脚；（桌、椅）腿 |
| [голова́]{.ru} 头 | [голо́вка]{.ru} | 小脑袋；（蒜、葱）头 |
| [лист]{.ru} 叶子；页 | [листо́к]{.ru} | 小叶子；一张纸 |
| [ла́мпа]{.ru} 灯 | [ла́мпочка]{.ru} | 灯泡 |
| [звезда́]{.ru} 星 | [звёздочка]{.ru} | 小星星；星号 |
| [глаз]{.ru} 眼睛 | [глазо́к]{.ru} | 小眼睛；（门上的）猫眼 |
| [ба́ба]{.ru} 农妇（口语） | [ба́бушка]{.ru} | 奶奶，外婆 |
| [де́ва]{.ru} 少女（旧） | [де́вочка]{.ru} | 小女孩 |

**指大和轻蔑。** [-ищ-]{.ru} 表示大，常带粗野、吓人或戏谑的口气：[Вот так доми́ще!]{.ru}（好大一座房子！）；[дружи́ще]{.ru}（老兄）是亲热的称呼。[-ищ-]{.ru} 与表示处所的后缀 [-ищ(е)]{.ru} 同形：[учи́лище, жили́ще, храни́лище]{.ru} 不是指大形式。[-ишк-]{.ru}、[-онк-]{.ru} 表示又小又差，带轻视：[доми́шко]{.ru}（破旧的小房子），[лошадёнка]{.ru}（瘦弱的马），[книжо́нка]{.ru}（没价值的书）。同样的后缀加在亲属名称上却表示亲热：[брати́шка, сестрёнка]{.ru}（小弟弟，小妹妹）。19 世纪作品里常用这些后缀刻画人物的态度。

**名字的形式。** 名字的选择表示说话人和对方的关系（§3.4.1）：名字加父称（[Алекса́ндр Серге́евич]{.ru}）用于正式场合、对长辈和上级；简称（[Са́ша]{.ru}）用于朋友、同学、同事之间；[-еньк-, -очк-]{.ru} 的形式（[Са́шенька, Ле́ночка]{.ru}）用于亲人之间、对孩子；带 [-к-]{.ru} 的形式（[Са́шка, Ма́шка]{.ru}）带随便甚至粗鲁的口气，只用于很亲近的同龄人之间或对孩子，对生人、对长辈用是失礼的。

**语体。** 指小表爱形式属于口语和文学语言，公文、科学文章不用。在民间文学和诗歌里，指小形式常常不表示小，只表示亲切：[Со́лнышко-вёдрышко, вы́гляни в око́шко!]{.ru}（童谣：太阳啊，晴天啊，从窗口露露脸吧！）

**俄汉差异。** 汉语用“小”“儿”“子”和重叠表示小和亲切（“小桌子”“小鸟儿”“宝宝”），俄语用后缀，而且后缀种类多，感情色彩各不相同。俄语里一个名字可以有十几种形式，每一种都表示一种关系；汉语称呼人时用“小王”“老王”“王老师”区分亲疏，俄语用全名加父称、简称、表爱形式区分。汉语学习者容易只记住名字的一种形式，看小说时认不出 [Ма́шенька]{.ru} 和 [Ма́ша]{.ru} 是同一个人。

“小”和感情：

::: ex
[Мы сня́ли **до́мик** у мо́ря.]{.ru}

[我们在海边租了一座小房子。]{.gloss}

[Подожди́те, пожа́луйста, **мину́точку**!]{.ru}

[请稍等一下！]{.gloss}

[Ма́ма, обраща́ясь к сы́ну, говори́т: «**Са́шенька**, иди́ у́жинать!»]{.ru}

[妈妈对儿子说：“萨申卡，来吃晚饭！”]{.gloss}
:::

意义分化：

::: ex
[Дай мне, пожа́луйста, **ру́чку**: на́до записа́ть телефо́н.]{.ru}

[请把笔给我，我得记个电话号码。]{.gloss}

[У ла́мпы перегоре́ла **ла́мпочка**.]{.ru}

[台灯的灯泡烧坏了。]{.gloss}

[**Ба́бушка** испекла́ пирожки́.]{.ru}

[奶奶烤了小馅饼。]{.gloss}
:::

### 常见错误

::: err
\*[Сыно́ку уже́ два го́да.]{.ru}　→　[**Сынку́** уже́ два го́да.]{.ru}

[-ок]{.ru} 的 [о]{.ru} 是隐现元音，变格时脱落，重音移到词尾：[сыно́к — сынка́ — сынку́]{.ru}。
:::

::: err
\*[Наш де́душка вчера́ пришла́ к нам.]{.ru}　→　[Наш де́душка вчера́ **пришёл** к нам.]{.ru}

[де́душка]{.ru}、[дя́дюшка]{.ru} 以 [-а]{.ru} 结尾，按第二变格法变，但指男人，是阳性，过去时用阳性。
:::

::: err
\*[Прошу́ предоста́вить мне ко́мнатку в общежи́тии.]{.ru}　→　[Прошу́ предоста́вить мне **ко́мнату** в общежи́тии.]{.ru}

申请书属于公文，不用指小形式。指小形式在口语里表示客气，在公文里显得随便。
:::

::: err
\*[Здра́вствуйте, Са́шка!]{.ru}（对不熟悉的成年人）　→　[Здра́вствуйте, **Алекса́ндр Серге́евич**!]{.ru}（或熟人之间 [Приве́т, **Са́ша**!]{.ru}）

带 [-к-]{.ru} 的名字形式口气随便，对生人和长辈用是失礼的。
:::

## §11.2.4 复合名词、缩略词和截短词

### 形式

[复合词]{.term}（[сло́жное сло́во]{.ru}）由两个以上的词根构成。复合名词的主要类型：

| 类型 | 构成 | 例 |
|---|---|---|
| 词根 + 连接元音 + 词根 | 硬辅音后 [-о-]{.ru}，软辅音和 [ж, ш, ч, щ, ц]{.ru} 后 [-е-]{.ru} | [сам-о-лёт, пар-о-хо́д, тепл-о-хо́д, вод-о-па́д, сам-о-ва́р, снег-о-па́д, лист-о-па́д, лед-о-ко́л, вод-о-прово́д, газ-о-прово́д]{.ru}；[пыл-е-со́с, пеш-е-хо́д, земл-е-трясе́ние, пут-е-ше́ствие]{.ru} |
| 不加连接元音 | 第一部分是以元音结尾的词干或数词第二格 | [кинотеа́тр, фотоаппара́т, мотоци́кл]{.ru}；[сороконо́жка, пятиле́тка, пятиэта́жка]{.ru} |
| 复合加后缀 | 两个词根，同时加后缀 | [одногру́ппник]{.ru}（[оди́н]{.ru} + [гру́ппа]{.ru} + [-ник]{.ru}），[мясору́бка]{.ru}，[пятиле́тка]{.ru} |
| [пол-, полу-]{.ru .ix} | [пол-]{.ru} 加名词单数第二格：“半个”；[полу-]{.ru} 加名词：“半……” | [полчаса́, полго́да, полкило́, пол-я́блока, пол-ли́тра, пол-Москвы́]{.ru}；[полуо́стров, полукру́г, полуфина́л, полуфабрика́т]{.ru}；[по́лдень, по́лночь]{.ru} |
| 两个名词用连字符连写 | 每个部分都保留重音 | [дива́н-крова́ть, ваго́н-рестора́н, интерне́т-магази́н, би́знес-це́нтр]{.ru} |

[缩略词]{.term}（[аббревиату́ра]{.ru}）按构成分四类（读法、写法见 §1.4.7，性和变格见 §3.4.5）：

| 类型 | 构成 | 例 |
|---|---|---|
| 字母型 | 各词的第一个字母，按字母名称读 | [МГУ]{.ru}（[Моско́вский госуда́рственный университе́т]{.ru}），[РФ, США, ЦСКА, ДТП]{.ru} |
| 音素型 | 各词的第一个字母，像一个词那样拼读 | [вуз]{.ru}（[вы́сшее уче́бное заведе́ние]{.ru}），[МИД, ГУМ, ЕГЭ́, загс]{.ru} |
| 音节型 | 各词的开头部分 | [универма́г]{.ru}（[универса́льный магази́н]{.ru}），[колхо́з, спецна́з, филфа́к, истфа́к, журфа́к, профко́м, Минздра́в]{.ru} |
| 混合型 | 前面词的开头部分加后一个整词（或整词的第二格） | [зарпла́та]{.ru}（[за́работная пла́та]{.ru}），[медсестра́, физкульту́ра, запча́сти, госэкза́мен, турба́за, соцсе́ть, Сберба́нк]{.ru}；[завка́федрой]{.ru}（[заве́дующий ка́федрой]{.ru}），[замдире́ктора]{.ru}（[замести́тель дире́ктора]{.ru}） |

[截短词]{.term}（[усечённое сло́во]{.ru}）是截去词的后一部分构成的词：

| 截短词 | 原词 | 语体 |
|---|---|---|
| [метро́]{.ru} | [метрополите́н]{.ru} | 中性 |
| [кино́]{.ru} | [кинемато́граф]{.ru} | 中性 |
| [фо́то]{.ru} | [фотогра́фия]{.ru} | 中性 |
| [зам, зав]{.ru} | [замести́тель, заве́дующий]{.ru} | 中性偏口语 |
| [спец]{.ru} | [специали́ст]{.ru} | 口语 |
| [препо́д]{.ru} | [преподава́тель]{.ru} | 学生俚语 |
| [униве́р]{.ru} | [университе́т]{.ru} | 学生俚语 |
| [комп]{.ru} | [компью́тер]{.ru} | 俚语 |
| [инфа́]{.ru} | [информа́ция]{.ru} | 俚语 |

口语里还有一种常见的构词：把“形容词加名词”的词组压成一个带 [-к(а)]{.ru} 的名词：

| 词组 | 名词 |
|---|---|
| [электри́ческий по́езд]{.ru} | [электри́чка]{.ru .ix} 电气列车，市郊列车 |
| [маршру́тное такси́]{.ru} | [маршру́тка]{.ru} 小公共汽车 |
| [зачётная кни́жка]{.ru} | [зачётка]{.ru} 记分册 |
| [минера́льная вода́]{.ru} | [минера́лка]{.ru} 矿泉水 |
| [газиро́ванная вода́]{.ru} | [газиро́вка]{.ru} 汽水 |
| [Третьяко́вская галере́я]{.ru} | [Третьяко́вка]{.ru} 特列季亚科夫画廊 |

### 意义和用法

**连接元音。** 复合词的两个词根之间加连接元音 [-о-]{.ru} 或 [-е-]{.ru}，选择看前一个词根末尾的辅音：硬辅音后 [-о-]{.ru}（[пар-о-хо́д]{.ru}），软辅音和 [ж, ш, ч, щ, ц]{.ru} 后 [-е-]{.ru}（[пыл-е-со́с]{.ru}，[пыль]{.ru} 的 [л]{.ru} 是软的；[пеш-е-хо́д]{.ru}）。连接元音不表示意义，它不是前一个词的词尾：[самолёт]{.ru} 的 [о]{.ru} 不是 [само́]{.ru} 的 [о]{.ru}，[водопа́д]{.ru} 的 [о]{.ru} 也不是 [вода́]{.ru} 的 [а]{.ru} 变来的。第一部分以元音结尾或是外来的 [кино-, фото-, авто-, мото-, радио-, теле-]{.ru} 时不加连接元音（[кинотеа́тр, телеба́шня]{.ru}）。第一部分是数词时用第二格形式，不加连接元音：[пятиле́тка, сороконо́жка]{.ru}（形容词同此，见 §11.3.2）。

**复合词的重音和词义。** 复合词一般只有一个重音，多在第二部分：[парохо́д, водопа́д, самолёт]{.ru}；第一部分里不重读的 [ё]{.ru} 写成 [е]{.ru}：[лёд → ледоко́л, ледохо́д]{.ru}。长的复合词第一部分可以有次重音，不标出。复合词的意思往往可以由两部分猜出：[пылесо́с]{.ru} 是“吸尘的”，[водопа́д]{.ru} 是“水落下”，[снегопа́д]{.ru} 是“下雪”，[пешехо́д]{.ru} 是“步行的人”。第二部分常是动词词根加零后缀（[-ход, -вод, -воз, -пад, -лёт, -кол]{.ru}），表示“做这件事的东西或人”或“这个动作”。

**[пол-]{.ru} 和 [полу-]{.ru}。** [пол-]{.ru} 来自 [пол]{.ru}（“半”的旧词），加名词单数第二格，表示“半个”：[полчаса́]{.ru} 是“半个小时”，[полго́да]{.ru} 是“半年”。它在元音、[л]{.ru} 和大写字母前写连字符（[пол-я́блока, пол-ли́тра, пол-Москвы́]{.ru}），其余连写（§1.4.6）；间接格把 [пол-]{.ru} 换成 [полу-]{.ru}（[получа́са, полуго́да]{.ru}），作主语时谓语用中性（[Прошло́ полчаса́]{.ru}），见 §6.3.2。[полу-]{.ru} 构成的是普通的复合名词，表示“半……，不完全的……”：[полуо́стров]{.ru}（半岛），[полукру́г]{.ru}（半圆），[полуфина́л]{.ru}（半决赛），[полуфабрика́т]{.ru}（半成品），按第二部分正常变格。[по́лдень, по́лночь]{.ru}（中午、半夜）已经是独立的词。

**连字符复合名词。** 两个名词用连字符连成一个词，前一个是主要的，后一个说明它的种类或用途：[дива́н-крова́ть]{.ru}（沙发床），[ваго́н-рестора́н]{.ru}（餐车）。两部分都是俄语名词时都变格：[в ваго́не-рестора́не]{.ru}；前一部分是不变化的外来词时只变后一部分：[в интерне́т-магази́не, в би́знес-це́нтре]{.ru}。这类词现在增长很快，多来自英语。

**缩略词的构成和语体。** 缩略词多用于机构、组织、职务、学科的名称，带公文色彩，20 世纪大量产生（[колхо́з, профко́м, вуз]{.ru}）。字母型和音素型用大写字母书写，只有少数已经成为普通名词的写小写（[вуз, загс]{.ru}）；音节型、混合型多已成为普通的词，小写，按普通名词变格（[в универма́ге, без зарпла́ты]{.ru}）。大学生口语里的 [филфа́к]{.ru}（语文系）、[истфа́к]{.ru}（历史系）、[журфа́к]{.ru}（新闻系）是由 [факульте́т]{.ru} 的前一部分构成的音节型缩略词。网络和广告里常见新的字母型、混合型缩略词（[ТЦ]{.ru}“购物中心”，[соцсе́ть]{.ru}“社交网络”）。

**截短词。** 截短词由一个长词截去后一部分构成，大多是口语或俚语。少数已经是中性的普通词：[метро́, кино́, фо́то]{.ru} 是不变格的中性名词（§3.1.4）。学生俚语里的 [препо́д, униве́р]{.ru}，网络俚语里的 [комп, инфа́]{.ru}，只用于朋友之间的随便谈话，书面上不用。截短词按截短后的形式确定性和变格：[зам]{.ru} 是阳性，变格（[у за́ма]{.ru}）；[инфа́]{.ru} 是阴性。

**形容词加名词压缩成 [-ка]{.ru} 名词。** [электри́чка, маршру́тка, зачётка]{.ru} 一类词由“形容词加名词”的词组构成：取形容词的词干，加后缀 [-к(а)]{.ru}，得到一个阴性名词，意思等于整个词组。这类词是口语，其中常用的（[электри́чка, маршру́тка, зачётка]{.ru}）已经是中性的日常用词；书面语用完整的词组。

**新外来词和旧词新义。** 新事物的名称常直接借自英语：[компью́тер, ноутбу́к, смартфо́н, интерне́т]{.ru}。借进来的词按俄语的规则变格（[в смартфо́не]{.ru}），也包括指人名词（[бло́гер]{.ru} 博主）；借进来的词根还能加俄语后缀构成新词：[гу́глить]{.ru}（用谷歌搜索），[ла́йкнуть]{.ru}（点赞）（动词后缀见 §11.3.4）。另一种办法是给旧词加上新义：[мышь]{.ru}（鼠标），[окно́]{.ru}（窗口），[па́пка]{.ru}（文件夹），[сеть]{.ru}（网络），[ви́рус]{.ru}（病毒）。旧词新义不改变词形，只扩大了意义。

**俄汉差异。** 汉语的复合词极多（“飞机、轮船、吸尘器”），俄语的复合名词则少得多，同样的意思多用后缀派生词或“形容词加名词”的词组表示：“火车站”是 [вокза́л]{.ru} 或 [железнодоро́жная ста́нция]{.ru}，“图书馆”是 [библиоте́ка]{.ru}。汉语缩略语（“北大”“高考”）和俄语缩略词作用相近，但俄语缩略词有性，按性和变格规则进入句子（§3.4.5），使用时要知道它的全称。

::: ex
[**Самолёт** лети́т из Москвы́ в Пеки́н во́семь часо́в.]{.ru}

### 常见错误

::: err
\*[У нас но́вый пылосо́с.]{.ru}　→　[У нас но́вый **пылесо́с**.]{.ru}

[пыль]{.ru} 的 [л]{.ru} 是软辅音，连接元音写 [-е-]{.ru}。连接元音按前一个词根末尾的辅音选，不按读音写。
:::

::: err
\*[Я ждал пол часа́.]{.ru}　→　[Я ждал **полчаса́**.]{.ru}

[полчаса́]{.ru} 是一个词，连写；只在元音、[л]{.ru} 和大写字母前写连字符（[пол-я́блока]{.ru}）。
:::

::: err
\*[Он рабо́тает зам в на́шей фи́рме.]{.ru}　→　[Он рабо́тает **замести́телем дире́ктора** в на́шей фи́рме.]{.ru}

一是职业名词在 [рабо́тать]{.ru} 后用第五格；二是 [зам]{.ru} 是截短词，口语色彩，正式介绍时用全称。
:::

::: err
\*[Прошу́ приня́ть меня́ на филфа́к униве́ра.]{.ru}（申请书）　→　[Прошу́ приня́ть меня́ на **филологи́ческий факульте́т университе́та**.]{.ru}

[филфа́к]{.ru}、[униве́р]{.ru} 是学生口语，公文要用全称。
:::
