副动词是动词的一种非变位形式，不变化，在句中说明谓语的动作，表示同一个主体的另一个动作。副动词分未完成体和完成体两种。本章先讲副动词的特征（§7.9.1），再讲两种副动词的构成、重音、不能构成的情况和基本意义（§7.9.2–§7.9.3），然后讲副动词短语表示的时间、原因、条件等意义（§7.9.4）和使用规则（§7.9.5），再讲变成副词和前置词的副动词（§7.9.6），最后讲形动词和副动词的综合运用（§7.9.7）。形动词见第 8 章；副动词短语的标点见 §12.5.4、§14.1.2；副动词变成的前置词的用法见 §9.5.1；旧式副动词见 §15.2.2。两种副动词的全部构成规则、代表词、重音和不能构成的动词见附录四。

## §7.9.1 副动词的特征

### 形式

[副动词]{.term}（[дееприча́стие]{.ru}）是动词的非变位形式之一（§7.1.1），没有性、数、格、人称、时的变化。副动词连同它的补语、状语，叫[副动词短语]{.term}（[дееприча́стный оборо́т]{.ru}）：[чита́я письмо́]{.ru}，[верну́вшись домо́й]{.ru}。按体分两种：

| 种类 | 后缀 | 由什么构成 | 例 | 详见 |
|---|---|---|---|---|
| [未完成体副动词]{.term}（[дееприча́стие несоверше́нного ви́да]{.ru}） | [-я]{.ru}（[ж, ш, ч, щ]{.ru} 后 [-а]{.ru}）；[-ясь, -ась]{.ru} | 现在时词干 | [чита́я, говоря́, слы́ша, занима́ясь]{.ru} | §7.9.2 |
| [完成体副动词]{.term}（[дееприча́стие соверше́нного ви́да]{.ru}） | [-в]{.ru}，[-вшись]{.ru}；[-ши]{.ru}；[-я]{.ru} | 不定式词干；[-йти, -сти, -зти]{.ru} 类用将来时词干 | [прочита́в, верну́вшись, вы́росши, придя́]{.ru} | §7.9.3 |

一个动词最多有一个副动词：未完成体动词构成未完成体副动词，完成体动词构成完成体副动词；两体动词（§7.3.2）两种都有：[испо́льзовать → испо́льзуя]{.ru}（未完成体）、[испо́льзовав]{.ru}（完成体）。

[-ся]{.ru} 动词的副动词，[-ся]{.ru} 按一般规则在元音后变成 [-сь]{.ru}：[занима́ясь, улыба́ясь, верну́вшись]{.ru}。这一点与形动词相反，形动词的 [-ся]{.ru} 一律不变（[занима́ющийся]{.ru}，§7.8.2）。

### 意义和用法

**兼有动词和副词的特征。**

| 动词的特征 | 例 | 副词的特征 | 例 |
|---|---|---|---|
| 有体 | [чита́я]{.ru}（一边读）— [прочита́в]{.ru}（读完以后） | 不变化 | [Чита́я, он улыба́лся. Чита́я, она́ улыба́лась.]{.ru} |
| 保留支配 | [чита́я газе́ту]{.ru}，[занима́ясь спо́ртом]{.ru}，[помога́я роди́телям]{.ru} | 说明谓语的动作，作状语 | [Он отве́тил, улыба́ясь]{.ru}（[как отве́тил?]{.ru}） |
| 被副词修饰，可以否定 | [бы́стро чита́я]{.ru}，[не зна́я]{.ru} | 回答 [как? когда́? почему́? при како́м усло́вии?]{.ru} | |
| 保留 [-ся]{.ru} | [улыба́ясь, верну́вшись]{.ru} | | |

**表示主语的次要动作。** 一个主体同时做两件事，或者先后做两件事，俄语常把主要的动作用作谓语，次要的、伴随的或先行的动作用副动词表示。副动词的主体就是句子的主语（使用规则见 §7.9.5）：

::: ex
[А́нна сиде́ла у окна́, **чита́я** письмо́.]{.ru}

[安娜坐在窗前读信。（同时）]{.gloss}

[**Прочита́в** письмо́, А́нна запла́кала.]{.ru}

[安娜读完信就哭了。（先后）]{.gloss}
:::

汉语表达同样的关系，常用连动式（“坐在窗前读信”“读完信哭了”），或者用“着”“一边……一边……”“……以后”“……了就……”。汉语的两个动词形式上地位相同，俄语要分出主次：谓语用变位形式，次要的动作用副动词。

**副动词本身没有时。** 副动词不表示动作在说话以前、现在还是以后，只表示它与谓语的动作是同时（未完成体）还是在先（完成体），时间由谓语决定（时的相对用法，§7.2.5）：

::: ex
[**Гуля́я** по па́рку, мы разгова́риваем.]{.ru}

[我们一边在公园散步一边聊天。（现在）]{.gloss}

[**Гуля́я** по па́рку, мы разгова́ривали.]{.ru}

[我们在公园散步的时候聊着天。（过去）]{.gloss}

[**Сдав** экза́мены, мы пое́дем на мо́ре.]{.ru}

[考完试以后我们去海边。（将来）]{.gloss}

[**Сдав** экза́мены, мы пое́хали на мо́ре.]{.ru}

[考完试以后我们去了海边。（过去）]{.gloss}
:::

**副动词与形动词的区别。** 两者都由动词构成，都可以带补语，用法完全不同：

| | 形动词（§7.8.1） | 副动词 |
|---|---|---|
| 像什么词 | 形容词 | 副词 |
| 说明什么 | 名词（人或事物） | 谓语动词（动作） |
| 变化 | 与名词一致，变性、数、格 | 不变化 |
| 回答问题 | [како́й?]{.ru} | [как? когда́? почему́?]{.ru} |
| 时 | 有现在时、过去时 | 没有，只有与谓语的同时、先后关系 |
| 动作的主体 | 被说明的名词 | 句子的主语 |
| [-ся]{.ru} | 一律 [-ся]{.ru}：[занима́ющийся]{.ru} | 元音后 [-сь]{.ru}：[занима́ясь]{.ru} |

::: ex
[Тури́сты, **гуля́ющие** по о́строву, фотографи́руют ска́лы.]{.ru}

[在岛上散步的游客在拍岩石。（形动词，说明 [тури́сты]{.ru}）]{.gloss}

[**Гуля́я** по о́строву, тури́сты фотографи́руют ска́лы.]{.ru}

[游客们一边在岛上散步，一边拍岩石。（副动词，说明 [фотографи́руют]{.ru}）]{.gloss}
:::

**语体。** 副动词短语主要用于书面语，在描写和叙述里尤其多；口语里同样的意思多用从句或并列的谓语（§7.9.4）。不过一些短的副动词口语里也常用：[Уходя́, гаси́те свет]{.ru}（离开时请关灯），[Он чита́л лёжа]{.ru}（他躺着看书），[Подожди́те, не уходи́те, не попроща́вшись!]{.ru}

### 常见错误

::: err
\*[Чита́ющая письмо́, А́нна улыба́лась.]{.ru}　→　[**Чита́я** письмо́, А́нна улыба́лась.]{.ru}

说明的是“微笑”这个动作怎样进行，用副动词。形动词要说明名词，而且要紧挨着它（[А́нна, чита́ющая письмо́, …]{.ru} 是“正在读信的安娜”）。
:::

::: err
\*[Студе́нт, чита́я кни́гу у окна́, — мой друг.]{.ru}　→　[Студе́нт, **чита́ющий** кни́гу у окна́, — мой друг.]{.ru}

“在窗前看书的学生”是名词的定语，用形动词；副动词不能说明名词。
:::

::: err
\*[занима́ясья]{.ru}，\*[занима́ющийсь]{.ru}　→　[**занима́ясь**]{.ru}（副动词），[**занима́ющийся**]{.ru}（形动词）

副动词的 [-ся]{.ru} 在元音后作 [-сь]{.ru}，形动词一律作 [-ся]{.ru}。
:::

教程：第二册 L71；第三册 L11
:::

## §7.9.2 未完成体副动词

### 形式

未完成体副动词由现在时词干构成：去掉现在时复数第三人称的词尾 [-ут, -ют, -ат, -ят]{.ru}，加 [-я]{.ru}；在 [ж, ш, ч, щ]{.ru} 后写 [-а]{.ru}（§1.4.1）。[-ся]{.ru} 动词加 [-ясь, -ась]{.ru}：

| 动词 | 复数第三人称 | 副动词 |
|---|---|---|
| [чита́ть]{.ru} | [чита́ют]{.ru} | [чита́я]{.ru} |
| [гуля́ть]{.ru} | [гуля́ют]{.ru} | [гуля́я]{.ru} |
| [уме́ть]{.ru} | [уме́ют]{.ru} | [уме́я]{.ru} |
| [рисова́ть]{.ru} | [рису́ют]{.ru} | [рису́я]{.ru} |
| [путеше́ствовать]{.ru} | [путеше́ствуют]{.ru} | [путеше́ствуя]{.ru} |
| [говори́ть]{.ru} | [говоря́т]{.ru} | [говоря́]{.ru} |
| [ходи́ть]{.ru} | [хо́дят]{.ru} | [ходя́]{.ru} |
| [люби́ть]{.ru} | [лю́бят]{.ru} | [любя́]{.ru} |
| [ви́деть]{.ru} | [ви́дят]{.ru} | [ви́дя]{.ru} |
| [идти́]{.ru} | [иду́т]{.ru} | [идя́]{.ru .ix} |
| [нести́]{.ru} | [несу́т]{.ru} | [неся́]{.ru} |
| [вести́]{.ru} | [веду́т]{.ru} | [ведя́]{.ru} |
| [жить]{.ru} | [живу́т]{.ru} | [живя́]{.ru} |
| [иска́ть]{.ru} | [и́щут]{.ru} | [ища́]{.ru} |
| [пла́кать]{.ru} | [пла́чут]{.ru} | [пла́ча]{.ru} |
| [слы́шать]{.ru} | [слы́шат]{.ru} | [слы́ша]{.ru} |
| [держа́ть]{.ru} | [де́ржат]{.ru} | [держа́]{.ru} |
| [крича́ть]{.ru} | [крича́т]{.ru} | [крича́]{.ru} |
| [занима́ться]{.ru} | [занима́ются]{.ru} | [занима́ясь]{.ru} |
| [учи́ться]{.ru} | [у́чатся]{.ru} | [уча́сь]{.ru} |
| [смея́ться]{.ru} | [смею́тся]{.ru} | [смея́сь]{.ru} |
| [забо́титься]{.ru} | [забо́тятся]{.ru} | [забо́тясь]{.ru} |

几点说明：

1. [-ава́ть]{.ru} 动词由不定式词干构成，保留 [-ва-]{.ru}：[дава́ть → дава́я]{.ru .ix}，[встава́ть → встава́я]{.ru}，[узнава́ть → узнава́я]{.ru}，[создава́ть → создава́я]{.ru}（§7.1.4）。
2. [быть]{.ru} 的副动词是 [бу́дучи]{.ru .ix}。
3. 交替跟随复数第三人称：第一变位全部人称交替的，副动词也交替（[ища́, пла́ча]{.ru}）；第二变位不交替（[ходя́]{.ru}，不说 [*хожа́]{.ru}）。
4. 诗歌和旧式作品里 [-ясь]{.ru} 有时写作 [-яся]{.ru}，多一个音节：[резвя́ся]{.ru}（= [резвя́сь]{.ru}），见 §15.3.8。

**重音。** 未完成体副动词的重音一般同单数第一人称：[говорю́ → говоря́]{.ru}，[хожу́ → ходя́]{.ru}，[прошу́ → прося́]{.ru}，[держу́ → держа́]{.ru}，[ищу́ → ища́]{.ru}，[люблю́ → любя́]{.ru}，[пла́чу → пла́ча]{.ru}，[чита́ю → чита́я]{.ru}。注意 [любя́]{.ru} 与形动词 [лю́бящий]{.ru} 重音不同。例外是几个表示姿态和状态的常用动词，重音在词干：

| 动词 | 单数第一人称 | 副动词 |
|---|---|---|
| [сиде́ть]{.ru} | [сижу́]{.ru} | [си́дя]{.ru .ix} |
| [стоя́ть]{.ru} | [стою́]{.ru} | [сто́я]{.ru .ix} |
| [лежа́ть]{.ru} | [лежу́]{.ru} | [лёжа]{.ru .ix} |
| [молча́ть]{.ru} | [молчу́]{.ru} | [мо́лча]{.ru .ix} |
| [гляде́ть]{.ru} | [гляжу́]{.ru} | [гля́дя]{.ru .ix} |

这几个词同时也是副词（§7.9.6）。全部例外见附录四。

**哪些动词没有未完成体副动词。** 能产类型（§7.1.3）的未完成体动词都有，缺这个形式的是一部分非能产类型的动词：

| 类型 | 动词 |
|---|---|
| 现在时词干没有元音的单音节动词 | [пить]{.ru}（[пьют]{.ru}）、[бить, лить, шить, вить, ждать, рвать, врать, лгать, ткать, мять, жать]{.ru} |
| [-чь]{.ru} 动词 | [мочь, печь, бере́чь, жечь, стричь, течь]{.ru} |
| 过去时去掉 [-ну-]{.ru} 的不带前缀的 [-нуть]{.ru} 动词 | [со́хнуть, мо́кнуть, мёрзнуть, ги́бнуть, гло́хнуть]{.ru} |
| 全部人称交替的部分 [-ать]{.ru} 动词 | [писа́ть, ре́зать, вяза́ть]{.ru} |
| 个别动词 | [хоте́ть]{.ru}（[хотя́]{.ru} 已变成连词“虽然”）、[бежа́ть, е́хать, есть, петь]{.ru} |

这些动词需要副动词时，用意思相近的另一个动词，或者用带前缀的次生未完成体：[ждать → ожида́я, дожида́ясь]{.ru}，[хоте́ть → жела́я]{.ru}，[пить → выпива́я]{.ru}，[писа́ть → запи́сывая]{.ru}，[е́хать]{.ru} 经过某处 [→ проезжа́я]{.ru}，[бежа́ть]{.ru} 离开 [→ убега́я]{.ru}；都不合适时改用从句（§7.9.5）。全部词表见附录四。

**【补】民间形式 [-учи, -ючи]{.ru}。** 由现在时词干加 [-учи, -ючи]{.ru} 构成的副动词是旧式和民间口语的形式，今天只见于民间文学、方言色彩的叙述和固定说法：[гуля́ючи]{.ru .ix}（散着步），[е́дучи]{.ru}（坐车走着），[уме́ючи]{.ru}（会做地，在行地）。标准语里保留的只有 [бу́дучи]{.ru}，以及变成副词的 [игра́ючи]{.ru}（轻而易举地）、[кра́дучись]{.ru}（悄悄地，来自 [кра́сться]{.ru}）。

### 意义和用法

**表示与谓语同时的动作。** 未完成体副动词表示与谓语的动作同时进行的动作，相当于汉语的“一边……一边……”“……着”“……的时候”。谓语可以是任何时，也可以是命令式：

::: ex
[Ми́ша де́лал уро́ки, **слу́шая** му́зыку.]{.ru}

[米沙一边听音乐一边做功课。]{.gloss}

[**Возвраща́ясь** домо́й, я встре́тил Пье́ра.]{.ru}

[我回家的路上遇见了皮埃尔。]{.gloss}

[**Уходя́**, гаси́те свет.]{.ru}

[离开时请关灯。（谓语是命令式）]{.gloss}
:::

**同时的范围。** “同时”可以是两个动作完全重合，也可以是副动词的动作构成谓语动作的背景：[Живя́ в Москве́, Ван Лэй мно́го путеше́ствовал по Росси́и]{.ru}（住在莫斯科期间，王磊在俄罗斯各地游历了很多地方）。副动词表示的动作也可以只与谓语动作的开始或某一刻重合：[Входя́ в ко́мнату, он поздоро́вался]{.ru}（他一进屋就打了招呼）。

**体的意义照常保留。** 未完成体副动词表示过程或反复，不表示完成；“读完了以后”要用完成体副动词（§7.9.3）：

::: ex
[**Чита́я** письмо́, она́ улыба́лась.]{.ru}

[她读信的时候一直在微笑。]{.gloss}

[**Прочита́в** письмо́, она́ улыбну́лась.]{.ru}

[她读完信，笑了一下。]{.gloss}
:::

**[бу́дучи]{.ru} 加第五格或短尾。** [бу́дучи]{.ru} 是 [быть]{.ru} 的副动词，书面语用，后面接第五格或短尾形容词、短尾被动形动词，多表示原因或让步：

::: ex
[**Бу́дучи** студе́нтом, он рабо́тал по вечера́м.]{.ru}

[他当学生的时候晚上打工。]{.gloss}

[Мно́гие, да́же не **бу́дучи** суеве́рными, стуча́т по де́реву.]{.ru}

[很多人即使不迷信，也会敲敲木头。]{.gloss}

[**Бу́дучи** уве́рен в успе́хе, он не гото́вился.]{.ru}

[他确信会成功，所以没有准备。]{.gloss}
:::

[бу́дучи студе́нтом]{.ru}（作为一个学生的时候、因为是学生）与 [как студе́нт]{.ru}（以学生的身份）不同：[Как студе́нт, он име́ет пра́во на стипе́ндию]{.ru} 不能换成 [бу́дучи]{.ru}。口语里一般不用 [бу́дучи]{.ru}，改用从句：[Когда́ он был студе́нтом, …]{.ru}

### 常见错误

::: err
\*[Пиша́ письмо́, он ду́мал о ма́ме.]{.ru}　→　[**Когда́ он писа́л** письмо́, он ду́мал о ма́ме.]{.ru}

[писа́ть]{.ru} 没有未完成体副动词，只能改用从句。
:::

::: err
\*[Ждя авто́бус, мы разгова́ривали.]{.ru}　→　[**Ожида́я** авто́бус, мы разгова́ривали.]{.ru} / [Пока́ мы жда́ли авто́бус, …]{.ru}

[ждать]{.ru} 没有副动词，用 [ожида́ть]{.ru} 的副动词或从句。
:::

::: err
\*[Даю́я сове́ты, он улыба́лся.]{.ru}　→　[**Дава́я** сове́ты, он улыба́лся.]{.ru}

[-ава́ть]{.ru} 动词的副动词保留 [-ва-]{.ru}。
:::

::: err
\*[сидя́, стоя́]{.ru}　→　[**си́дя**, **сто́я**]{.ru}

这几个副动词的重音在词干上，与单数第一人称 [сижу́, стою́]{.ru} 不同。
:::

::: err
\*[Хотя́ пое́хать в Росси́ю, он учи́л ру́сский язы́к.]{.ru}　→　[**Жела́я** пое́хать в Росси́ю, он учи́л ру́сский язы́к.]{.ru}

[хотя́]{.ru} 今天只是连词“虽然”，不作 [хоте́ть]{.ru} 的副动词，“想要”用 [жела́я]{.ru}。
:::

## §7.9.3 完成体副动词

### 形式

完成体副动词主要由不定式词干构成（与过去时同一个词干，§7.1.1），按词干的结尾分四种：

| 词干 | 后缀 | 例 |
|---|---|---|
| 以元音结尾 | [-в]{.ru} | [прочита́ть → прочита́в]{.ru .ix}，[написа́ть → написа́в]{.ru}，[сказа́ть → сказа́в]{.ru}，[купи́ть → купи́в]{.ru}，[уви́деть → уви́дев]{.ru}，[верну́ть → верну́в]{.ru}，[откры́ть → откры́в]{.ru}，[поня́ть → поня́в]{.ru}，[нача́ть → нача́в]{.ru}，[взять → взяв]{.ru}，[дать → дав]{.ru}，[сесть → сев]{.ru}，[упа́сть → упа́в]{.ru}，[съесть → съев]{.ru} |
| 以元音结尾，[-ся]{.ru} 动词 | [-вшись]{.ru} | [верну́ться → верну́вшись]{.ru .ix}，[просну́ться → просну́вшись]{.ru}，[умы́ться → умы́вшись]{.ru}，[оде́ться → оде́вшись]{.ru}，[познако́миться → познако́мившись]{.ru}，[нача́ться → нача́вшись]{.ru} |
| 以辅音结尾（过去时阳性没有 [-л]{.ru}） | [-в]{.ru} 或 [-ши]{.ru} | [привы́кнуть → привы́кнув]{.ru}，[исче́знуть → исче́знув]{.ru}，[дости́гнуть → дости́гнув]{.ru}；[вы́расти → вы́росши]{.ru}，[запере́ть → запере́в]{.ru} / [за́перши]{.ru}，[стере́ть → стере́в]{.ru} / [стёрши]{.ru}，[помо́чь → помо́гши]{.ru}，[лечь → лёгши]{.ru} |
| [-йти, -сти, -зти]{.ru} | [-я]{.ru}（由将来时词干构成） | [прийти́ → придя́]{.ru .ix}，[войти́ → войдя́]{.ru}，[вы́йти → вы́йдя]{.ru}，[уйти́ → уйдя́]{.ru}，[найти́ → найдя́]{.ru}，[пройти́ → пройдя́]{.ru}，[перейти́ → перейдя́]{.ru}，[принести́ → принеся́]{.ru}，[привезти́ → привезя́]{.ru}，[привести́ → приведя́]{.ru}，[перевести́ → переведя́]{.ru}；[-ся]{.ru}：[разойти́сь → разойдя́сь]{.ru} |

几点说明：

1. 不带 [-ся]{.ru} 的元音词干动词，除 [-в]{.ru} 外还有 [-вши]{.ru} 的形式（[прочита́вши, сказа́вши]{.ru}），今天是口语和旧式色彩，书面语不用；十九世纪作品里常见（[поборо́вши, опереди́вши, прижа́вши]{.ru}，见 §15.2.2）。[-ся]{.ru} 动词只能用 [-вшись]{.ru}。
2. 辅音词干的动词，[-нуть]{.ru} 类一般用 [-в]{.ru}，由不定式词干构成（[привы́кнув]{.ru}，少用 [привы́кши]{.ru}）；其余用 [-ши]{.ru}，由过去时构成（[вы́росши]{.ru}）。[-ереть]{.ru} 动词两种都有，[-в]{.ru} 更常用。[помо́гши, лёгши]{.ru} 一类很少用，一般改用从句。
3. [-йти, -сти, -зти]{.ru} 类的 [-я]{.ru} 由将来时词干构成，样子像未完成体副动词，其实是完成体：[идя́]{.ru}（[идти́]{.ru}，未完成体，走着）— [придя́]{.ru}（[прийти́]{.ru}，完成体，来到以后）。不定式以 [-сть]{.ru} 结尾的动词不属于这一类，按第一种用 [-в]{.ru}：[сесть → сев]{.ru}，[укра́сть → укра́в]{.ru}，不说 [*ся́дя]{.ru}。
4. 旧式的完成体副动词也用 [-я, -ясь]{.ru}，由将来时词干构成，见于十九世纪的作品：[уви́дя]{.ru}（= [уви́дев]{.ru}），[услы́ша]{.ru}（= [услы́шав]{.ru}），[взгромоздя́сь]{.ru}（= [взгромозди́вшись]{.ru}），[пону́ря го́лову]{.ru}（= [пону́рив]{.ru}，耷拉着脑袋）。现代标准语只在固定说法里保留这种形式，它们已经变成副词（§7.9.6）。

**重音。** 完成体副动词的重音同不定式：[купи́в, верну́вшись, прочита́в]{.ru}；过去时重音移动的动词也不随过去时变化：[поня́в]{.ru}（[по́нял]{.ru}），[нача́в]{.ru}（[на́чал]{.ru}），[приня́в]{.ru}（[при́нял]{.ru}），[прода́в]{.ru}（[про́дал]{.ru}）。[-я]{.ru} 形式重读词尾（[придя́, принеся́]{.ru}；前缀 [вы́-]{.ru} 例外：[вы́йдя]{.ru}）。[-ши]{.ru} 形式同过去时阳性（[вы́росши, стёрши]{.ru}）。

**哪些动词没有完成体副动词。** 完成体动词几乎都有。[-ши]{.ru} 一类很少用的形式见上；无人称动词（[рассвести́]{.ru}）没有副动词。

### 意义和用法

**表示先于谓语完成的动作。** 这是完成体副动词最常见的意义，相当于汉语的“……以后”“……了，就……”。谓语可以是任何时，也可以是命令式；谓语是现在时，表示经常重复的先后两个动作：

::: ex
[**Сдав** после́дний экза́мен, Ван Лэй пое́хал домо́й.]{.ru}

[王磊考完最后一门，就回国了。]{.gloss}

[**Верну́вшись** домо́й, Ми́ша сра́зу сади́тся за уро́ки.]{.ru}

[米沙每天一回到家就坐下来做功课。（反复）]{.gloss}

[**Прочита́в** кни́гу, верни́те её в библиоте́ку.]{.ru}

[书读完以后，请还给图书馆。（命令式）]{.gloss}

[**Придя́** домо́й, я тебе́ позвоню́.]{.ru}

[我到家以后给你打电话。（将来）]{.gloss}
:::

**表示结果与谓语并存的状态。** 完成体副动词也可以表示动作完成后留下的状态，这个状态与谓语的动作同时存在。这时汉语常用“着”，中国学生容易错用未完成体：

::: ex
[Он сиде́л, **закры́в** глаза́.]{.ru}

[他闭着眼睛坐着。（眼睛闭上以后一直闭着）]{.gloss}

[Она́ стоя́ла, **прислони́вшись** к стене́.]{.ru}

[她靠着墙站着。]{.gloss}

[**Соедини́вшись** с Ка́мой, Во́лга течёт да́льше на юг.]{.ru}

[伏尔加河与卡马河汇合以后，继续向南流去。]{.gloss}
:::

**放在谓语后，表示随之发生的动作。** 书面语里完成体副动词放在谓语后，可以表示紧接着谓语发生、作为谓语结果的动作：

::: ex
[Мяч попа́л в окно́, **разби́в** стекло́.]{.ru}

[球打到窗户上，把玻璃打碎了。]{.gloss}

[Он вы́шел из ко́мнаты, **хло́пнув** две́рью.]{.ru}

[他砰的一声带上门，走出了房间。]{.gloss}
:::

**两种副动词的对比。** 未完成体副动词说同时，完成体副动词说先后或结果，与变位形式的体完全一致：

| | 未完成体副动词 | 完成体副动词 |
|---|---|---|
| 词干 | 现在时词干 | 不定式词干（[-йти]{.ru} 类为将来时词干） |
| 后缀 | [-я, -а, -ясь, -ась]{.ru} | [-в, -вшись, -ши, -я]{.ru} |
| 与谓语的关系 | 同时 | 先于谓语；结果并存；随后发生 |
| 汉语 | “一边……”“……着”“……的时候” | “……以后”“……了就……”；状态的“……着” |
| 例 | [Гуля́я по го́роду, мы фотографи́ровали це́ркви.]{.ru} | [Осмотре́в го́род, мы верну́лись на теплохо́д.]{.ru} |

### 常见错误

::: err
\*[Прие́дя в Москву́, он позвони́л ма́ме.]{.ru}　→　[**Прие́хав** в Москву́, он позвони́л ма́ме.]{.ru}

[-я]{.ru} 只用于 [-йти, -сти, -зти]{.ru} 类。[прие́хать]{.ru} 的不定式词干以元音结尾，用 [-в]{.ru}。
:::

::: err
\*[Прочита́я письмо́, она́ запла́кала.]{.ru}　→　[**Прочита́в** письмо́, она́ запла́кала.]{.ru}

完成体副动词由不定式词干加 [-в]{.ru} 构成，不由将来时 [прочита́ют]{.ru} 构成。
:::

::: err
\*[Верну́в домо́й, он лёг спать.]{.ru}　→　[**Верну́вшись** домо́й, он лёг спать.]{.ru}

[верну́ться]{.ru}（回来）是 [-ся]{.ru} 动词，副动词是 [верну́вшись]{.ru}；[верну́в]{.ru} 是 [верну́ть]{.ru}（还回）的副动词，意思不同。
:::

::: err
\*[Он сиде́л, закрыва́я глаза́.]{.ru}（想说“他闭着眼睛坐着”）　→　[Он сиде́л, **закры́в** глаза́.]{.ru}

汉语的“着”在这里表示动作留下的状态，用完成体副动词；[закрыва́я]{.ru} 是“一直在闭眼睛”，说的是动作的过程。
:::

::: err
\*[по́няв]{.ru}，\*[на́чав]{.ru}　→　[**поня́в**]{.ru}，[**нача́в**]{.ru}

完成体副动词的重音同不定式，不随过去时 [по́нял, на́чал]{.ru} 移动。
:::

## §7.9.4 副动词短语的意义

### 意义和用法

副动词本身只表示它的动作与谓语同时还是在先。副动词短语在句中具体表示时间、原因、条件、让步还是方式，要看词汇意义、谓语的形式和上下文。判断出意义，也就知道它能改写成哪种从句（改写的步骤见本节末）：

| 意义 | 回答 | 改写成 | 判断线索 |
|---|---|---|---|
| 时间 | [когда́?]{.ru} | [когда́, пока́, по́сле того́ как]{.ru} 从句 | 最常见；没有其他线索时多理解为时间 |
| 原因 | [почему́?]{.ru} | [так как, потому́ что]{.ru} 从句 | 表示心理、知识、意愿的副动词 |
| 条件 | [при како́м усло́вии?]{.ru} | [е́сли]{.ru} 从句 | 谓语是将来时、命令式，或有 [мо́жно, ну́жно]{.ru} 加不定式 |
| 让步 | 虽然…… | [хотя́]{.ru} 从句 | 副动词前有 [да́же, хоть и]{.ru}，主句有 [всё-таки, всё же]{.ru}，或意思相对 |
| 方式、伴随 | [как?]{.ru} | 并列谓语 | 副动词在谓语后，说明动作怎样进行 |

**时间。** 未完成体副动词表示同时，改写成 [когда́, пока́]{.ru}；完成体副动词表示在先，改写成 [когда́, по́сле того́ как]{.ru}：

::: ex
[**Гуля́я** по це́нтру Каза́ни, легко́ заме́тить, что здесь встреча́ются две культу́ры.]{.ru}

[在喀山市中心散步，很容易发现这里有两种文化交汇。]{.gloss}

[**Спусти́вшись** из кремля́, мы пошли́ на у́лицу Ба́умана.]{.ru}

[= По́сле того́ как мы спусти́лись из кремля́, мы пошли́ на у́лицу Ба́умана.]{.ru}

[我们从克里姆林下来以后，去了鲍曼街。]{.gloss}
:::

**原因。** 表示心理状态、知识、意愿的副动词常表示原因：[зна́я, не зна́я, понима́я, жела́я, не жела́я, боя́сь, наде́ясь, чу́вствуя, по́мня]{.ru}；完成体的 [уста́в, заболе́в, испуга́вшись, узна́в, реши́в]{.ru} 等也常这样用：

::: ex
[**Не зна́я** доро́ги, мы спроси́ли прохо́жего.]{.ru}

[= Так как мы не зна́ли доро́ги, мы спроси́ли прохо́жего.]{.ru}

[我们不认识路，就问了一个过路人。]{.gloss}

[**Боя́сь** опозда́ть, А́нна взяла́ такси́.]{.ru}

[安娜怕迟到，叫了一辆出租车。]{.gloss}

[**Си́льно уста́в**, он ра́но лёг спать.]{.ru}

[他累坏了，早早就睡了。]{.gloss}
:::

**条件。** 谓语是将来时、命令式、假定式，或者句中有 [мо́жно, ну́жно, на́до]{.ru} 加不定式时，副动词短语常表示条件，改写成 [е́сли]{.ru}：

::: ex
[**Прие́хав** в Каза́нь в ию́не, мо́жно попа́сть на Сабанту́й.]{.ru}

[= Е́сли вы прие́дете в Каза́нь в ию́не, вы смо́жете попа́сть на Сабанту́й.]{.ru}

[六月来喀山，就能赶上撒班节。]{.gloss}

[**Занима́ясь** ка́ждый день, ты бы́стро вы́учишь язы́к.]{.ru}

[每天学习的话，你很快就能学会这门语言。]{.gloss}
:::

**让步。** 副动词的动作本该妨碍谓语的动作，谓语却照样发生了，这时副动词短语表示让步，改写成 [хотя́]{.ru}。常见的标志是副动词前的 [да́же]{.ru} 或 [хоть и]{.ru}，主句里的 [всё-таки, всё же]{.ru}：

::: ex
[**Да́же не зна́я** тата́рского языка́, гость бы́стро запомина́ет не́сколько тата́рских слов.]{.ru}

[= Хотя́ гость не зна́ет тата́рского языка́, он бы́стро запомина́ет…]{.ru}

[客人即使不懂鞑靼语，也很快就记住了几个鞑靼词。]{.gloss}

[**Зна́я** пра́вду, он всё-таки промолча́л.]{.ru}

[他虽然知道真相，却还是没有作声。]{.gloss}
:::

**方式和伴随。** 副动词说明谓语的动作怎样进行，或伴随着什么动作，多放在谓语后。这类副动词短语不能改写成从句，只能改成并列谓语，或者译成汉语的“……着”“……地”：

::: ex
[Она́ отве́тила, **не поднима́я** глаз.]{.ru}

[她没抬眼睛就回答了。]{.gloss}

[Мы до́лго шли по у́лице, **разгова́ривая** о Каза́ни.]{.ru}

[= Мы до́лго шли по у́лице и разгова́ривали о Каза́ни.]{.ru}

[我们沿着街走了很久，一路聊着喀山。]{.gloss}
:::

**同一个短语的两种理解。** 意义的界限并不总是清楚的，同一个副动词短语可以有两种理解，两种改法都对：[**Живя́** ря́дом мно́го веко́в, тата́ры и ру́сские мно́гое взя́ли друг у дру́га]{.ru} 既可以理解为时间（几百年来住在一起的时候），也可以理解为原因（因为住在一起）。副动词短语比从句含糊，书面语常利用这一点，不必说明确切的逻辑关系。

**改写成从句的步骤。**

1. 按意义选连词：同时用 [когда́, пока́]{.ru}，在先用 [когда́, по́сле того́ как]{.ru}，原因用 [так как, потому́ что]{.ru}，条件用 [е́сли]{.ru}，让步用 [хотя́]{.ru}。
2. 补出主语：副动词没有人称，从句要有自己的主语，就是主句的主语。名词主语通常移进从句，主句改用代词。
3. 定动词的体和时：体与副动词相同；时以主句为准。完成体副动词加现在时谓语表示反复的，改写成两个并列谓语最自然。

::: ex
[**Вы́йдя** из теа́тра, зри́тели уви́дели, что на у́лице светло́.]{.ru}

[→ Когда́ зри́тели вы́шли из теа́тра, они́ уви́дели, что на у́лице светло́.]{.ru}

[观众们走出剧院，看见外面天还亮着。]{.gloss}

[**Вы́йдя** ве́чером из до́ма, они́ гуля́ют по на́бережным до утра́.]{.ru}

[→ Они́ выхо́дят ве́чером из до́ма и гуля́ют по на́бережным до утра́.]{.ru}

[他们晚上出门，沿着河岸一直散步到天亮。（反复，改成并列谓语）]{.gloss}
:::

反过来，从句和主句的主语相同时，从句可以压缩成副动词短语；主语不同等不能压缩的情况见 §7.9.5。从句的体决定副动词的体：从句是未完成体（任何时），用未完成体副动词；从句是完成体，用完成体副动词。[Когда́ он посмотре́л на мост, …]{.ru} 只能改成 [Посмотре́в на мост, …]{.ru}，不能改成 [Смотря́ на мост, …]{.ru}。

### 常见错误

::: err
\*[Смотря́ на часы́, он вскочи́л и побежа́л.]{.ru}（想说“他看了一眼表，就跳起来跑了”）　→　[**Посмотре́в** на часы́, он вскочи́л и побежа́л.]{.ru}

先看表、后跳起来，是先后关系，用完成体副动词。
:::

::: err
\*[Хотя́ не зна́я языка́, он всё по́нял.]{.ru}　→　[**Да́же не зна́я** языка́, он всё по́нял.]{.ru} / [**Хотя́ он не знал** языка́, он всё по́нял.]{.ru}

连词 [хотя́]{.ru} 引出从句，后面要有变位动词；副动词表示让步时前面加 [да́же]{.ru}。
:::

## §7.9.5 副动词的使用规则

### 意义和用法

**一、副动词的主体必须是句子的主语。** 这是副动词最重要的规则。副动词的动作和谓语的动作必须由同一个人或事物发出，而这个人或事物在句中作主语（第一格）。副动词的主体不是主语，或者句子根本没有主语，句子就是错的：

::: ex
[\*Гуля́я по о́строву, мне понра́вились ска́лы.]{.ru}

[（散步的是“我”，句子的主语却是 [ска́лы]{.ru}，[мне]{.ru} 是第三格）]{.gloss}

[Гуля́я по о́строву, **я** фотографи́ровал ска́лы.]{.ru}

[我在岛上散步，拍了岩石。（主语相同）]{.gloss}

[**Когда́ я гуля́л** по о́строву, мне понра́вились ска́лы.]{.ru}

[我在岛上散步时，很喜欢那些岩石。（主语不同，改用从句）]{.gloss}
:::

契诃夫在《意见簿》（[«Жа́лобная кни́га»]{.ru}，1884）里故意让一位旅客写下这样一句话，嘲笑不通文墨的人：[«Подъезжа́я к сие́й ста́нции и гля́дя на приро́ду в окно́, у меня́ слете́ла шля́па»]{.ru}（“当驶近本站、望着窗外景色时，我的帽子被吹掉了”）。“驶近”的是旅客，句子的主语却是 [шля́па]{.ru}。这个句子在俄罗斯常被用作副动词误用的典型例子。

汉语没有这条限制：“散步的时候，岩石让我很喜欢”“下了课，雨停了”都通。所以汉译俄时，先找出副动词动作的主体，看它是不是句子的主语，不是就要改用从句。

**二、各类句子中的副动词。** 主语之外的句子成分不能作副动词的主体，由此得出下面几条：

| 句子 | 能否用副动词 | 例 |
|---|---|---|
| 双部句，副动词的主体是主语 | 能 | [Прочита́в письмо́, А́нна улыбну́лась.]{.ru} |
| 命令式句（主体是听话人） | 能 | [Уходя́, гаси́те свет.]{.ru} |
| 无人称句，有不定式，副动词的主体就是不定式的主体 | 能 | [Гуля́я по о́строву, мо́жно уви́деть и степь, и тайгу́.]{.ru}　[Уезжа́я, на́до вы́ключить свет.]{.ru} |
| 无人称句，没有不定式（主体用第三格或不出现） | 不能 | [\*Возвраща́ясь домо́й, мне ста́ло гру́стно.]{.ru} |
| 泛指人称句（第二人称单数泛指任何人，§12.4.3） | 能 | [Сто́я на э́том берегу́, чу́вствуешь себя́ на краю́ земли́.]{.ru} |
| 不定人称句（§12.4.2） | 一般不用 | [\*Прие́хав в Му́рманск, тури́стов повезли́ за́ город.]{.ru} |
| 被动句，副动词的主体是动作的发出者 | 不能 | [\*Прочита́в статью́, она́ была́ переведена́ студе́нтом.]{.ru} |

被动句里，副动词的主体如果正是被动句的主语，句子是通的：[Возвраща́ясь домо́й, он был заде́ржан полице́йскими]{.ru}（他在回家路上被警察拦住了：回家的是“他”）。但这种句子显得生硬，最好改成从句。

**三、否定和第二格。** 副动词的否定用 [не]{.ru}，分写：[не зна́я, не ду́мая, не сказа́в]{.ru}。只有本身不带 [не]{.ru} 就不用的词连写：[ненави́дя, негоду́я]{.ru}（§1.4.6）。否定的副动词后，直接补语常用第二格，尤其在书面语和有 [ни]{.ru} 时：[не сказа́в ни сло́ва]{.ru}，[не име́я вре́мени]{.ru}，[не теря́я ни рабо́ты, ни ка́чества жи́зни]{.ru}（§3.6.3）。

**四、标点。** 副动词短语和单个的副动词，不论位置，前后都用逗号隔开（§14.1.2）。副动词短语紧跟在连词后面时，逗号放在连词后面：[Лёд быва́ет таки́м прозра́чным, что, идя́ по нему́, ви́дишь под нога́ми глубину́]{.ru}；[Он встал и, не сказа́в ни сло́ва, вы́шел]{.ru}。已经变成副词的副动词不加逗号（§7.9.6）。

**五、位置。** 表示先后的完成体副动词短语一般放在谓语前，与事情发生的顺序一致；表示方式、伴随的副动词短语多放在谓语后；表示原因、条件、让步的多放在句首。副动词短语不能与谓语用 [и]{.ru} 连接成同等成分：

::: ex
[Он сиде́л в кре́сле, **чита́я** газе́ту.]{.ru} / [Он сиде́л в кре́сле **и чита́л** газе́ту.]{.ru}

[他坐在扶手椅上看报。（不说 [*Он сиде́л в кре́сле и чита́я газе́ту]{.ru}）]{.gloss}

[**Улыба́ясь и шутя́**, учи́тельница раздала́ тетра́ди.]{.ru}

[老师又说又笑地把本子发了下去。（两个副动词可以用 [и]{.ru} 连接）]{.gloss}
:::

**六、不能用副动词时怎样改写。** 遇到上面这些不能用副动词的情况，或动词没有副动词（§7.9.2），可以：

1. 改用从句：[Когда́ я возвраща́лся домо́й, мне ста́ло гру́стно.]{.ru}
2. 改用并列谓语：[Он сиде́л в кре́сле и чита́л газе́ту.]{.ru}
3. 改换主语，使两个动作的主体一致：[Возвраща́ясь домо́й, я загрусти́л.]{.ru}
4. 改用前置词加动名词（书面）：[По́сле возвраще́ния домо́й…]{.ru}，[При чте́нии статьи́…]{.ru}

::: ex
[\*Сдав экза́мены, нам да́ли кани́кулы.]{.ru}

[（“考完试”的是“我们”，句子是不定人称句，没有可作副动词主体的主语）]{.gloss}

[**Когда́ мы сда́ли** экза́мены, нам да́ли кани́кулы.]{.ru}

[我们考完试，就放假了。]{.gloss}

[**Сдав** экза́мены, мы ушли́ на кани́кулы.]{.ru}

[我们考完试就放假了。（换成主语相同的谓语）]{.gloss}
:::

### 常见错误

::: err
\*[Подъезжа́я к Москве́, у меня́ заболе́ла голова́.]{.ru}　→　[**Когда́ я подъезжа́л** к Москве́, у меня́ заболе́ла голова́.]{.ru}

“快到莫斯科”的是“我”，句子的主语是 [голова́]{.ru}，主语不同，不能用副动词。
:::

::: err
\*[Чита́я э́ту кни́гу, мне ста́ло ску́чно.]{.ru}　→　[**Когда́ я чита́л** э́ту кни́гу, мне ста́ло ску́чно.]{.ru}

无人称句里没有不定式，[мне]{.ru} 是第三格，不能作副动词的主体。
:::

::: err
\*[Возвраща́ясь домо́й, пошёл дождь.]{.ru}　→　[**Когда́ я возвраща́лся** домо́й, пошёл дождь.]{.ru}

下雨的不是回家的人。汉语“回家的时候下起雨来”不必说出主语，俄语的副动词却必须有同一个主语。
:::

::: err
\*[Он ушёл незна́я, что де́лать.]{.ru}　→　[Он ушёл, **не зна́я**, что де́лать.]{.ru}

副动词的 [не]{.ru} 分写；副动词短语前要加逗号。
:::

## §7.9.6 副动词化的副词和前置词

### 意义和用法

一部分副动词常用以后失去了动词的意义，变成副词或前置词。它们的样子仍是副动词，用法已经不同：不再表示主语的另一个动作，不受“主体必须是主语”的限制（§7.9.5）。

**变成副词的副动词。** 副动词转成副词，叫[副词化]{.term}（[адвербиализа́ция]{.ru}）。这类副词不再带补语，单独说明谓语的方式，不用逗号隔开：

| 副词 | 意义 | 例 |
|---|---|---|
| [сто́я]{.ru .ix} | 站着 | [Он чита́л сто́я.]{.ru} |
| [си́дя]{.ru .ix} | 坐着 | [Спать си́дя неудо́бно.]{.ru} |
| [лёжа]{.ru .ix} | 躺着 | [Не чита́й лёжа!]{.ru} |
| [мо́лча]{.ru .ix} | 默默地，不作声地 | [Тури́сты мо́лча смотре́ли на кра́тер.]{.ru} |
| [шутя́]{.ru .ix} | 轻而易举地；开玩笑地 | [Он шутя́ реши́л зада́чу.]{.ru} |
| [не́хотя]{.ru .ix} | 不情愿地 | [Ми́ша не́хотя сел за уро́ки.]{.ru} |
| [игра́ючи]{.ru} | 毫不费力地 | [Он игра́ючи подня́л тяжёлый чемода́н.]{.ru} |
| [кра́дучись]{.ru} | 悄悄地，蹑手蹑脚地 | [Ко́шка кра́дучись подошла́ к пти́це.]{.ru} |

由旧式完成体副动词（§7.9.3）变来的副词性固定说法：[сломя́ го́лову]{.ru}（拼命地，飞快地），[спустя́ рукава́]{.ru}（马马虎虎地），[сложа́ ру́ки]{.ru}（袖手旁观），[положа́ ру́ку на се́рдце]{.ru}（说句心里话），[скрепя́ се́рдце]{.ru}（勉强地，忍痛），[немно́го погодя́]{.ru}（过一会儿）。

副词与副动词的区别：同一个词，带补语、表示主语的另一个动作时是副动词，用逗号隔开；单独说明谓语的方式时是副词，不加逗号。副词化的 [шутя́, не́хотя]{.ru} 意义已经和原来的动词不同：

::: ex
[Он чита́л **лёжа**.]{.ru}

[他躺着看书。（副词）]{.gloss}

[**Лёжа** на дива́не, он чита́л газе́ту.]{.ru}

[他躺在沙发上看报。（副动词，带状语 [на дива́не]{.ru}）]{.gloss}

[Он реши́л зада́чу **шутя́**.]{.ru}

[他轻轻松松就把题解出来了。（副词）]{.gloss}

[**Шутя́** и смея́сь, де́ти игра́ли во дворе́.]{.ru}

[孩子们在院子里说说笑笑地玩。（副动词）]{.gloss}
:::

**[хотя́]{.ru} 变成连词。** [хоте́ть]{.ru} 的旧副动词 [хотя́]{.ru .ix} 早已变成让步连词“虽然”（§10.1.6），所以 [хоте́ть]{.ru} 今天没有副动词（§7.9.2）。

**变成前置词的副动词。** 一部分副动词变成了派生前置词（§9.1.1），后面要求固定的格，不再要求与主语一致。它们的意义和用法在 §9.5.1 讲全，这里列出常用的几个和它们与副动词本义的区别：

| 前置词 | 支配 | 意义 | 原来的副动词 |
|---|---|---|---|
| [благодаря́]{.ru .ix} | 第三格 | 多亏，由于 | [благодаря́ кого́]{.ru}（感谢某人，第四格） |
| [несмотря́ на]{.ru .ix} | 第四格 | 尽管 | [не смотря́ на что]{.ru}（不看着，分写） |
| [су́дя по]{.ru .ix} | 第三格 | 根据……来看 | [суди́ть]{.ru} 判断 |
| [включа́я]{.ru .ix} | 第四格 | 包括 | [включа́я что]{.ru}（打开，接通） |
| [начина́я с]{.ru .ix} | 第二格 | 从……开始 | [начина́я что]{.ru}（开始做） |
| [спустя́]{.ru .ix} | 第四格 | 过了……以后 | [спусти́ть]{.ru} 放下 |
| [смотря́ по]{.ru} | 第三格 | 根据，视……而定 | [смотре́ть]{.ru} 看 |
| [не счита́я]{.ru} | 第二格 | 不算，除……以外 | [счита́ть]{.ru} 数 |

区别的办法：副动词表示句子主语的动作，前置词不表示任何人的动作。

::: ex
[**Благодаря́** вулка́нам на Камча́тке мно́го горя́чих исто́чников.]{.ru}

[多亏有火山，堪察加有很多温泉。（前置词，加第三格）]{.gloss}

[**Благодаря́** дру́га за по́мощь, Ван Лэй пожа́л ему́ ру́ку.]{.ru}

[王磊一边感谢朋友的帮助，一边和他握手。（副动词，加第四格，主体是 [Ван Лэй]{.ru}）]{.gloss}

[**Несмотря́ на** дождь, мы пошли́ гуля́ть.]{.ru}

[尽管下雨，我们还是出去散步了。（前置词，连写）]{.gloss}

[Он шёл, **не смотря́** под но́ги.]{.ru}

[他走路不看脚下。（副动词，分写）]{.gloss}

[**Су́дя по** всему́, он уже́ уе́хал.]{.ru}

[看样子，他已经走了。（前置词，不要求主语一致）]{.gloss}

[**Включа́я** свет, она́ уви́дела на столе́ письмо́.]{.ru}

[她开灯的时候看见桌上有一封信。（副动词）]{.gloss}

[В пое́здке бы́ло два́дцать челове́к, **включа́я** дете́й.]{.ru}

[参加旅行的有二十个人，包括孩子在内。（前置词）]{.gloss}
:::

### 常见错误

::: err
\*[Благодаря́ дождю́ мы не пошли́ гуля́ть.]{.ru}　→　[**Из-за** дождя́ мы не пошли́ гуля́ть.]{.ru}

前置词 [благодаря́]{.ru} 用于带来好结果的原因，坏结果用 [из-за]{.ru}（§9.4.1）。
:::

::: err
\*[Не смотря́ на уста́лость, он рабо́тал до утра́.]{.ru}　→　[**Несмотря́** на уста́лость, он рабо́тал до утра́.]{.ru}

前置词 [несмотря́ на]{.ru} 连写；分写的 [не смотря́]{.ru} 是副动词“不看”。
:::

::: err
\*[Он, мо́лча, слу́шал нас.]{.ru}　→　[Он **мо́лча** слу́шал нас.]{.ru}

变成副词的 [мо́лча]{.ru} 单独说明谓语，不用逗号隔开。
:::

教程：第三册 L11、L14、L15、L20

## §7.9.7 形动词和副动词的综合运用

### 意义和用法

**分工。** 形动词和副动词都是动词的非变位形式，都能把一个从句压缩成短语，作用却不同：形动词说明名词，是定语；副动词说明谓语的动作，是状语。一个及物动词的体对可以构成下面这些非变位形式，各自的意义和替换的从句不同：

| 形式 | 例 | 相当于 | 意义 |
|---|---|---|---|
| 主动形动词现在时 | [студе́нт, сдаю́щий экза́мен]{.ru} | [кото́рый сдаёт]{.ru} | 正在考试的学生 |
| 主动形动词过去时（未完成体） | [студе́нт, сдава́вший экза́мен]{.ru} | [кото́рый сдава́л]{.ru} | 当时在考试的学生 |
| 主动形动词过去时（完成体） | [студе́нт, сда́вший экза́мен]{.ru} | [кото́рый сдал]{.ru} | 考试通过了的学生 |
| 被动形动词现在时 | [экза́мен, сдава́емый студе́нтами]{.ru} | [кото́рый сдаю́т]{.ru} | 学生们正在参加的考试 |
| 被动形动词过去时 | [экза́мен, сда́нный студе́нтами]{.ru} | [кото́рый сда́ли]{.ru} | 学生们通过了的考试 |
| 未完成体副动词 | [Сдава́я экза́мен, студе́нт волнова́лся.]{.ru} | [Когда́ студе́нт сдава́л…]{.ru} | 考试的时候，学生很紧张 |
| 完成体副动词 | [Сдав экза́мен, студе́нт пое́хал домо́й.]{.ru} | [По́сле того́ как студе́нт сдал…]{.ru} | 考完试，学生回家了 |

**选择形式的步骤。** 要把一个意思用非变位形式表达，依次回答三个问题：

1. 说明的是名词还是动作？说明名词（[како́й?]{.ru}）用形动词，说明谓语的动作（[как? когда́? почему́?]{.ru}）用副动词。
2. 用副动词时，它的主体是不是句子的主语？是，才能用副动词（§7.9.5）；不是，用从句，或者把那个人或事物作为名词，用形动词说明它。
3. 时间和态：同时用未完成体，在先用完成体；被说明的名词是发出者用主动形动词，是对象用被动形动词，发出者用第五格。

::: ex
[Мы уви́дели ма́льчика, **игра́ющего** в футбо́л.]{.ru}

[我们看见一个踢足球的男孩。（踢球的是男孩，说明 [ма́льчика]{.ru}，用形动词）]{.gloss}

[**Игра́я** в футбо́л, мы уви́дели ма́льчика.]{.ru}

[我们踢球的时候看见了一个男孩。（踢球的是“我们”，即主语，用副动词）]{.gloss}
:::

**一句中同时用形动词短语和副动词短语。** 书面语，尤其是描写，常在一个句子里同时用两种短语，把人物的样子、动作和环境都写进去。分析这样的句子，先找主语和谓语，再看每个短语说明谁：形动词短语与哪个名词一致，就说明哪个名词；副动词短语说明谓语，主体是主语：

::: ex
[**Подня́в** ру́ки, **похо́жие** на кры́лья, балери́на на мгнове́ние остана́вливается.]{.ru}

[芭蕾舞演员举起像翅膀一样的双臂，停了一刹那。（[подня́в]{.ru} 的主体是 [балери́на]{.ru}；[похо́жие]{.ru} 是形容词短语，说明 [ру́ки]{.ru}）]{.gloss}

[Принц, **уви́девший** её у о́зера, влюбля́ется в неё с пе́рвого взгля́да.]{.ru}

[在湖边看见她的王子对她一见钟情。]{.gloss}

[Зри́тели, **запо́лнившие** огро́мный зал, затиха́ют, **ожида́я** нача́ла спекта́кля.]{.ru}

[坐满大厅的观众安静下来，等着演出开始。]{.gloss}
:::

**在书面语中的作用。** 形动词短语和副动词短语使句子紧凑，能在一个句子里交代几个动作和特征，是书面叙述、描写、科学和公文语体的重要手段（§15.1.1、§15.1.6）。但一个句子里的短语不宜超过两三个，太多就显得笨重；描写中常在一个带短语的长句后接一个短句，形成节奏：[Зри́тели, запо́лнившие огро́мный зал, затиха́ют. Га́снет свет.]{.ru} 口语和随便的书信里，同样的意思多用从句和并列谓语。

**俄译汉时的拆分。** 汉语没有形动词、副动词，长定语只能放在名词前，副动词短语也没有现成的对应形式。俄译汉时一般把形动词短语译成“……的”或拆成单独的句子，把副动词短语译成连动式、“……着”“……以后”或因果、条件复句：[Ива́н Серге́евич, всю жизнь рабо́тавший инжене́ром, прекра́сно понима́л, что сын, мечта́я о ко́смосе, вы́берет нелёгкий путь]{.ru}——伊万·谢尔盖耶维奇一辈子当工程师，他非常清楚，儿子向往太空，选的会是一条艰难的路。

### 常见错误

::: err
\*[Поднима́ясь, пе́ред зри́телями появля́ется о́зеро.]{.ru}（想说“幕升起，观众面前出现了湖”）　→　[**Когда́ за́навес поднима́ется**, пе́ред зри́телями появля́ется о́зеро.]{.ru}

升起的是幕，句子的主语是 [о́зеро]{.ru}，主语不同，不能用副动词。
:::

::: err
\*[Мы уви́дели ма́льчика, игра́я в футбо́л.]{.ru}（想说“我们看见一个在踢足球的男孩”）　→　[Мы уви́дели ма́льчика, **игра́ющего** в футбо́л.]{.ru}

副动词的主体只能是主语 [мы]{.ru}，原句的意思成了“我们踢足球时看见了男孩”。说明 [ма́льчика]{.ru} 要用形动词。
:::

::: err
\*[Прочита́вший письмо́, А́нна позвони́ла ма́ме.]{.ru}　→　[**Прочита́в** письмо́, А́нна позвони́ла ма́ме.]{.ru}

读完信再打电话，说的是两个动作的先后，用副动词。形动词 [прочита́вшая]{.ru} 说明名词，表示“读完了信的（安娜）”，而且要和 [А́нна]{.ru} 一致。
:::
