副动词是动词的一种非变位形式，不变化，在句中说明谓语的动作，表示同一个主体的另一个动作。副动词分未完成体和完成体两种。本章先讲副动词的特征（§7.9.1），再讲两种副动词的构成、重音、不能构成的情况和基本意义（§7.9.2–§7.9.3），然后讲副动词短语表示的时间、原因、条件等意义（§7.9.4）和使用规则（§7.9.5），再讲变成副词和前置词的副动词（§7.9.6），最后讲形动词和副动词的综合运用（§7.9.7）。形动词见第 8 章；副动词短语的标点见 §12.5.4、§14.1.2；副动词变成的前置词的用法见 §9.5.1；旧式副动词见 §15.2.2。两种副动词的全部构成规则、代表词、重音和不能构成的动词见附录四。

## §7.9.1 副动词的特征

### 形式

[副动词]{.term}（[дееприча́стие]{.ru}）是动词的非变位形式之一（§7.1.1），没有性、数、格、人称、时的变化。副动词连同它的补语、状语，叫[副动词短语]{.term}（[дееприча́стный оборо́т]{.ru}）：[чита́я письмо́]{.ru}，[верну́вшись домо́й]{.ru}。按体分两种：

| 种类 | 后缀 | 由什么构成 | 例 | 详见 |
|---|---|---|---|---|
| [未完成体副动词]{.term}（[дееприча́стие несоверше́нного ви́да]{.ru}） | [-я]{.ru}（[ж, ш, ч, щ]{.ru} 后 [-а]{.ru}）；[-ясь, -ась]{.ru} | 现在时词干 | [чита́я, говоря́, слы́ша, занима́ясь]{.ru} | §7.9.2 |
| [完成体副动词]{.term}（[дееприча́стие соверше́нного ви́да]{.ru}） | [-в]{.ru}，[-вшись]{.ru}；[-ши]{.ru}；[-я]{.ru} | 不定式词干；[-йти, -сти, -зти]{.ru} 类用将来时词干 | [прочита́в, верну́вшись, вы́росши, придя́]{.ru} | §7.9.3 |

一个动词最多有一个副动词：未完成体动词构成未完成体副动词，完成体动词构成完成体副动词；两体动词（§7.3.2）两种都有：[испо́льзовать → испо́льзуя]{.ru}（未完成体）、[испо́льзовав]{.ru}（完成体）。

[-ся]{.ru} 动词的副动词，[-ся]{.ru} 按一般规则在元音后变成 [-сь]{.ru}：[занима́ясь, улыба́ясь, верну́вшись]{.ru}。这一点与形动词相反，形动词的 [-ся]{.ru} 一律不变（[занима́ющийся]{.ru}，§7.8.2）。

### 意义和用法

**兼有动词和副词的特征。**

| 动词的特征 | 例 | 副词的特征 | 例 |
|---|---|---|---|
| 有体 | [чита́я]{.ru}（一边读）— [прочита́в]{.ru}（读完以后） | 不变化 | [Чита́я, он улыба́лся. Чита́я, она́ улыба́лась.]{.ru} |
| 保留支配 | [чита́я газе́ту]{.ru}，[занима́ясь спо́ртом]{.ru}，[помога́я роди́телям]{.ru} | 说明谓语的动作，作状语 | [Он отве́тил, улыба́ясь]{.ru}（[как отве́тил?]{.ru}） |
| 被副词修饰，可以否定 | [бы́стро чита́я]{.ru}，[не зна́я]{.ru} | 回答 [как? когда́? почему́? при како́м усло́вии?]{.ru} | |
| 保留 [-ся]{.ru} | [улыба́ясь, верну́вшись]{.ru} | | |

**表示主语的次要动作。** 一个主体同时做两件事，或者先后做两件事，俄语常把主要的动作用作谓语，次要的、伴随的或先行的动作用副动词表示。副动词的主体就是句子的主语（使用规则见 §7.9.5）：

::: ex
[А́нна сиде́ла у окна́, **чита́я** письмо́.]{.ru}

[安娜坐在窗前读信。（同时）]{.gloss}

[**Прочита́в** письмо́, А́нна запла́кала.]{.ru}

[安娜读完信就哭了。（先后）]{.gloss}
:::

汉语表达同样的关系，常用连动式（“坐在窗前读信”“读完信哭了”），或者用“着”“一边……一边……”“……以后”“……了就……”。汉语的两个动词形式上地位相同，俄语要分出主次：谓语用变位形式，次要的动作用副动词。

**副动词本身没有时。** 副动词不表示动作在说话以前、现在还是以后，只表示它与谓语的动作是同时（未完成体）还是在先（完成体），时间由谓语决定（时的相对用法，§7.2.5）：

::: ex
[**Гуля́я** по па́рку, мы разгова́риваем.]{.ru}

[我们一边在公园散步一边聊天。（现在）]{.gloss}

[**Гуля́я** по па́рку, мы разгова́ривали.]{.ru}

[我们在公园散步的时候聊着天。（过去）]{.gloss}

[**Сдав** экза́мены, мы пое́дем на мо́ре.]{.ru}

[考完试以后我们去海边。（将来）]{.gloss}

[**Сдав** экза́мены, мы пое́хали на мо́ре.]{.ru}

[考完试以后我们去了海边。（过去）]{.gloss}
:::

**副动词与形动词的区别。** 两者都由动词构成，都可以带补语，用法完全不同：

| | 形动词（§7.8.1） | 副动词 |
|---|---|---|
| 像什么词 | 形容词 | 副词 |
| 说明什么 | 名词（人或事物） | 谓语动词（动作） |
| 变化 | 与名词一致，变性、数、格 | 不变化 |
| 回答问题 | [како́й?]{.ru} | [как? когда́? почему́?]{.ru} |
| 时 | 有现在时、过去时 | 没有，只有与谓语的同时、先后关系 |
| 动作的主体 | 被说明的名词 | 句子的主语 |
| [-ся]{.ru} | 一律 [-ся]{.ru}：[занима́ющийся]{.ru} | 元音后 [-сь]{.ru}：[занима́ясь]{.ru} |

::: ex
[Тури́сты, **гуля́ющие** по о́строву, фотографи́руют ска́лы.]{.ru}

[在岛上散步的游客在拍岩石。（形动词，说明 [тури́сты]{.ru}）]{.gloss}

[**Гуля́я** по о́строву, тури́сты фотографи́руют ска́лы.]{.ru}

[游客们一边在岛上散步，一边拍岩石。（副动词，说明 [фотографи́руют]{.ru}）]{.gloss}
:::

**语体。** 副动词短语主要用于书面语，在描写和叙述里尤其多；口语里同样的意思多用从句或并列的谓语（§7.9.4）。不过一些短的副动词口语里也常用：[Уходя́, гаси́те свет]{.ru}（离开时请关灯），[Он чита́л лёжа]{.ru}（他躺着看书），[Подожди́те, не уходи́те, не попроща́вшись!]{.ru}

### 常见错误

::: err
\*[Чита́ющая письмо́, А́нна улыба́лась.]{.ru}　→　[**Чита́я** письмо́, А́нна улыба́лась.]{.ru}

说明的是“微笑”这个动作怎样进行，用副动词。形动词要说明名词，而且要紧挨着它（[А́нна, чита́ющая письмо́, …]{.ru} 是“正在读信的安娜”）。
:::

::: err
\*[Студе́нт, чита́я кни́гу у окна́, — мой друг.]{.ru}　→　[Студе́нт, **чита́ющий** кни́гу у окна́, — мой друг.]{.ru}

“在窗前看书的学生”是名词的定语，用形动词；副动词不能说明名词。
:::

::: err
\*[занима́ясья]{.ru}，\*[занима́ющийсь]{.ru}　→　[**занима́ясь**]{.ru}（副动词），[**занима́ющийся**]{.ru}（形动词）

副动词的 [-ся]{.ru} 在元音后作 [-сь]{.ru}，形动词一律作 [-ся]{.ru}。
:::

:::

## §7.9.2 未完成体副动词

### 形式

未完成体副动词由现在时词干构成：去掉现在时复数第三人称的词尾 [-ут, -ют, -ат, -ят]{.ru}，加 [-я]{.ru}；在 [ж, ш, ч, щ]{.ru} 后写 [-а]{.ru}（§1.4.1）。[-ся]{.ru} 动词加 [-ясь, -ась]{.ru}：

| 动词 | 复数第三人称 | 副动词 |
|---|---|---|
| [чита́ть]{.ru} | [чита́ют]{.ru} | [чита́я]{.ru} |
| [гуля́ть]{.ru} | [гуля́ют]{.ru} | [гуля́я]{.ru} |
| [уме́ть]{.ru} | [уме́ют]{.ru} | [уме́я]{.ru} |
| [рисова́ть]{.ru} | [рису́ют]{.ru} | [рису́я]{.ru} |
| [путеше́ствовать]{.ru} | [путеше́ствуют]{.ru} | [путеше́ствуя]{.ru} |
| [говори́ть]{.ru} | [говоря́т]{.ru} | [говоря́]{.ru} |
| [ходи́ть]{.ru} | [хо́дят]{.ru} | [ходя́]{.ru} |
| [люби́ть]{.ru} | [лю́бят]{.ru} | [любя́]{.ru} |
| [ви́деть]{.ru} | [ви́дят]{.ru} | [ви́дя]{.ru} |
| [идти́]{.ru} | [иду́т]{.ru} | [идя́]{.ru .ix} |
| [нести́]{.ru} | [несу́т]{.ru} | [неся́]{.ru} |
| [вести́]{.ru} | [веду́т]{.ru} | [ведя́]{.ru} |
| [жить]{.ru} | [живу́т]{.ru} | [живя́]{.ru} |
| [иска́ть]{.ru} | [и́щут]{.ru} | [ища́]{.ru} |
| [пла́кать]{.ru} | [пла́чут]{.ru} | [пла́ча]{.ru} |
| [слы́шать]{.ru} | [слы́шат]{.ru} | [слы́ша]{.ru} |
| [держа́ть]{.ru} | [де́ржат]{.ru} | [держа́]{.ru} |
| [крича́ть]{.ru} | [крича́т]{.ru} | [крича́]{.ru} |
| [занима́ться]{.ru} | [занима́ются]{.ru} | [занима́ясь]{.ru} |
| [учи́ться]{.ru} | [у́чатся]{.ru} | [уча́сь]{.ru} |
| [смея́ться]{.ru} | [смею́тся]{.ru} | [смея́сь]{.ru} |
| [забо́титься]{.ru} | [забо́тятся]{.ru} | [забо́тясь]{.ru} |

几点说明：

1. [-ава́ть]{.ru} 动词由不定式词干构成，保留 [-ва-]{.ru}：[дава́ть → дава́я]{.ru .ix}，[встава́ть → встава́я]{.ru}，[узнава́ть → узнава́я]{.ru}，[создава́ть → создава́я]{.ru}（§7.1.4）。
2. [быть]{.ru} 的副动词是 [бу́дучи]{.ru .ix}。
3. 交替跟随复数第三人称：第一变位全部人称交替的，副动词也交替（[ища́, пла́ча]{.ru}）；第二变位不交替（[ходя́]{.ru}，不说 [*хожа́]{.ru}）。
4. 诗歌和旧式作品里 [-ясь]{.ru} 有时写作 [-яся]{.ru}，多一个音节：[резвя́ся]{.ru}（= [резвя́сь]{.ru}），见 §15.3.8。

**重音。** 未完成体副动词的重音一般同单数第一人称：[говорю́ → говоря́]{.ru}，[хожу́ → ходя́]{.ru}，[прошу́ → прося́]{.ru}，[держу́ → держа́]{.ru}，[ищу́ → ища́]{.ru}，[люблю́ → любя́]{.ru}，[пла́чу → пла́ча]{.ru}，[чита́ю → чита́я]{.ru}。注意 [любя́]{.ru} 与形动词 [лю́бящий]{.ru} 重音不同。例外是几个表示姿态和状态的常用动词，重音在词干：

| 动词 | 单数第一人称 | 副动词 |
|---|---|---|
| [сиде́ть]{.ru} | [сижу́]{.ru} | [си́дя]{.ru .ix} |
| [стоя́ть]{.ru} | [стою́]{.ru} | [сто́я]{.ru .ix} |
| [лежа́ть]{.ru} | [лежу́]{.ru} | [лёжа]{.ru .ix} |
| [молча́ть]{.ru} | [молчу́]{.ru} | [мо́лча]{.ru .ix} |
| [гляде́ть]{.ru} | [гляжу́]{.ru} | [гля́дя]{.ru .ix} |

这几个词同时也是副词（§7.9.6）。全部例外见附录四。

**哪些动词没有未完成体副动词。** 能产类型（§7.1.3）的未完成体动词都有，缺这个形式的是一部分非能产类型的动词：

| 类型 | 动词 |
|---|---|
| 现在时词干没有元音的单音节动词 | [пить]{.ru}（[пьют]{.ru}）、[бить, лить, шить, вить, ждать, рвать, врать, лгать, ткать, мять, жать]{.ru} |
| [-чь]{.ru} 动词 | [мочь, печь, бере́чь, жечь, стричь, течь]{.ru} |
| 过去时去掉 [-ну-]{.ru} 的不带前缀的 [-нуть]{.ru} 动词 | [со́хнуть, мо́кнуть, мёрзнуть, ги́бнуть, гло́хнуть]{.ru} |
| 全部人称交替的部分 [-ать]{.ru} 动词 | [писа́ть, ре́зать, вяза́ть]{.ru} |
| 个别动词 | [хоте́ть]{.ru}（[хотя́]{.ru} 已变成连词“虽然”）、[бежа́ть, е́хать, есть, петь]{.ru} |

这些动词需要副动词时，用意思相近的另一个动词，或者用带前缀的次生未完成体：[ждать → ожида́я, дожида́ясь]{.ru}，[хоте́ть → жела́я]{.ru}，[пить → выпива́я]{.ru}，[писа́ть → запи́сывая]{.ru}，[е́хать]{.ru} 经过某处 [→ проезжа́я]{.ru}，[бежа́ть]{.ru} 离开 [→ убега́я]{.ru}；都不合适时改用从句（§7.9.5）。全部词表见附录四。

**【补】民间形式 [-учи, -ючи]{.ru}。** 由现在时词干加 [-учи, -ючи]{.ru} 构成的副动词是旧式和民间口语的形式，今天只见于民间文学、方言色彩的叙述和固定说法：[гуля́ючи]{.ru .ix}（散着步），[е́дучи]{.ru}（坐车走着），[уме́ючи]{.ru}（会做地，在行地）。标准语里保留的只有 [бу́дучи]{.ru}，以及变成副词的 [игра́ючи]{.ru}（轻而易举地）、[кра́дучись]{.ru}（悄悄地，来自 [кра́сться]{.ru}）。

### 意义和用法

**表示与谓语同时的动作。** 未完成体副动词表示与谓语的动作同时进行的动作，相当于汉语的“一边……一边……”“……着”“……的时候”。谓语可以是任何时，也可以是命令式：

::: ex
[Ми́ша де́лал уро́ки, **слу́шая** му́зыку.]{.ru}

[米沙一边听音乐一边做功课。]{.gloss}

[**Возвраща́ясь** домо́й, я встре́тил Пье́ра.]{.ru}

[我回家的路上遇见了皮埃尔。]{.gloss}

[**Уходя́**, гаси́те свет.]{.ru}

[离开时请关灯。（谓语是命令式）]{.gloss}
:::

**同时的范围。** “同时”可以是两个动作完全重合，也可以是副动词的动作构成谓语动作的背景：[Живя́ в Москве́, Ван Лэй мно́го путеше́ствовал по Росси́и]{.ru}（住在莫斯科期间，王磊在俄罗斯各地游历了很多地方）。副动词表示的动作也可以只与谓语动作的开始或某一刻重合：[Входя́ в ко́мнату, он поздоро́вался]{.ru}（他一进屋就打了招呼）。

**体的意义照常保留。** 未完成体副动词表示过程或反复，不表示完成；“读完了以后”要用完成体副动词（§7.9.3）：

::: ex
[**Чита́я** письмо́, она́ улыба́лась.]{.ru}

[她读信的时候一直在微笑。]{.gloss}

[**Прочита́в** письмо́, она́ улыбну́лась.]{.ru}

[她读完信，笑了一下。]{.gloss}
:::

**[бу́дучи]{.ru} 加第五格或短尾。** [бу́дучи]{.ru} 是 [быть]{.ru} 的副动词，书面语用，后面接第五格或短尾形容词、短尾被动形动词，多表示原因或让步：

::: ex
[**Бу́дучи** студе́нтом, он рабо́тал по вечера́м.]{.ru}

[他当学生的时候晚上打工。]{.gloss}

[Мно́гие, да́же не **бу́дучи** суеве́рными, стуча́т по де́реву.]{.ru}

[很多人即使不迷信，也会敲敲木头。]{.gloss}

[**Бу́дучи** уве́рен в успе́хе, он не гото́вился.]{.ru}

[他确信会成功，所以没有准备。]{.gloss}
:::

[бу́дучи студе́нтом]{.ru}（作为一个学生的时候、因为是学生）与 [как студе́нт]{.ru}（以学生的身份）不同：[Как студе́нт, он име́ет пра́во на стипе́ндию]{.ru} 不能换成 [бу́дучи]{.ru}。口语里一般不用 [бу́дучи]{.ru}，改用从句：[Когда́ он был студе́нтом, …]{.ru}

### 常见错误

::: err
\*[Пиша́ письмо́, он ду́мал о ма́ме.]{.ru}　→　[**Когда́ он писа́л** письмо́, он ду́мал о ма́ме.]{.ru}

[писа́ть]{.ru} 没有未完成体副动词，只能改用从句。
:::

::: err
\*[Ждя авто́бус, мы разгова́ривали.]{.ru}　→　[**Ожида́я** авто́бус, мы разгова́ривали.]{.ru} / [Пока́ мы жда́ли авто́бус, …]{.ru}

[ждать]{.ru} 没有副动词，用 [ожида́ть]{.ru} 的副动词或从句。
:::

::: err
\*[Даю́я сове́ты, он улыба́лся.]{.ru}　→　[**Дава́я** сове́ты, он улыба́лся.]{.ru}

[-ава́ть]{.ru} 动词的副动词保留 [-ва-]{.ru}。
:::

::: err
\*[сидя́, стоя́]{.ru}　→　[**си́дя**, **сто́я**]{.ru}

这几个副动词的重音在词干上，与单数第一人称 [сижу́, стою́]{.ru} 不同。
:::

::: err
\*[Хотя́ пое́хать в Росси́ю, он учи́л ру́сский язы́к.]{.ru}　→　[**Жела́я** пое́хать в Росси́ю, он учи́л ру́сский язы́к.]{.ru}

[хотя́]{.ru} 今天只是连词“虽然”，不作 [хоте́ть]{.ru} 的副动词，“想要”用 [жела́я]{.ru}。
:::
