## 课文

::: {.prose lang="ru"}
В суббо́ту ве́чером А́нна и Ван Лэй хотя́т посмотре́ть но́вую ру́сскую коме́дию. Они́ одева́ются в прихо́жей. Ми́ша ви́дит их.
:::

::: {.dialogue lang="ru"}
[Ми́ша]{.sp} Вы идёте в кино́? Мо́жно с ва́ми?

[А́нна]{.sp} С на́ми? А уро́ки?

[Ми́ша]{.sp} Уро́ки я уже́ сде́лал. Ну пожа́луйста!

[Ван Лэй]{.sp} А́нна, я не про́тив.

[А́нна]{.sp} Ну хорошо́, ты идёшь с на́ми. То́лько одева́йся бы́стро!

[Ми́ша]{.sp} А фильм не стра́шный?

[А́нна]{.sp} Нет, не стра́шный. Э́то коме́дия.
:::

::: {.prose lang="ru"}
В кинотеа́тре А́нна встреча́ет подру́гу Ка́тю. Ка́тя то́же в кино́ с бра́том.
:::

::: {.dialogue lang="ru"}
[Ка́тя]{.sp} Приве́т, А́нна! А ты с кем?

[А́нна]{.sp} С Ми́шей. А э́то Ван Лэй, мы с ним у́чимся вме́сте.

[Ка́тя]{.sp} О́чень прия́тно! А́нна ча́сто говори́т о вас. Вам нра́вится Москва́?

[Ван Лэй]{.sp} Да, о́чень.

[Ка́тя]{.sp} А ру́сское кино́ вы лю́бите?

[Ван Лэй]{.sp} Люблю́, но я ещё пло́хо понима́ю. А́нна сиди́т со мной и помога́ет мне.

[Ка́тя]{.sp} А мы с бра́том всегда́ сиди́м в после́днем ряду́. Ну, до свида́ния!
:::

::: {.prose lang="ru"}
Фильм о́чень весёлый, и Ми́ше он о́чень нра́вится. По́сле фи́льма они́ иду́т домо́й.
:::

::: {.dialogue lang="ru"}
[Ми́ша]{.sp} Спаси́бо вам! С ва́ми о́чень ве́село.

[А́нна]{.sp} С тобо́й то́же. В сле́дующую суббо́ту мы опя́ть возьмём тебя́ с собо́й.
:::

## 课文注释

::: notes
1. **[Мо́жно с ва́ми?]{.ru}** 口语省略句，完整的说法是 [Мо́жно мне идти́ с ва́ми?]{.ru}，意思是“我可以跟你们一起去吗？”
2. **[А уро́ки?]{.ru}** 中学生的家庭作业俄语叫 [уро́ки]{.ru}，[де́лать уро́ки]{.ru} 是“做作业”。
3. **[Я не про́тив.]{.ru}** “我不反对”，即“我同意”，口语中很常用。
4. **[мы с ним]{.ru}** 意思是“我和他”，不是“我们和他”，一共两个人。见语法第二点。
5. **[в после́днем ряду́]{.ru}** [ряд]{.ru} 和 [в]{.ru} 连用时第六格是 [ряду́]{.ru}，重音在词尾，和 [в саду́]{.ru}、[в лесу́]{.ru} 一样。
6. **[Ми́ше он о́чень нра́вится]{.ru}** [он]{.ru} 指电影。[нра́виться]{.ru} 的主语是被喜欢的事物，喜欢的人用第三格。
7. **[возьмём тебя́ с собо́й]{.ru}** “带你一起去”。[взять кого́ с собо́й]{.ru} 是固定说法，“带上谁”，[собо́й]{.ru} 指主语自己。
:::

## 俄罗斯知识

### 去电影院

课文里卡佳和弟弟总坐在最后一排。俄罗斯的电影票上印着排 [ряд]{.ru} 和座位 [ме́сто]{.ru}，对号入座。

进场找座位也有讲究：从已经坐好的观众面前经过时，要面朝他们，而不是用背对着人家，同时说一声 [Извини́те]{.ru}。这条规矩剧院、音乐厅里同样适用。

苏联时期，看电影是最普及的娱乐，几乎每个居民区都有电影院。莫斯科新阿尔巴特街上的“十月”电影院 [«Октя́брь»]{.ru} 1967 年开业，至今仍是首都最有名的电影院之一，许多首映式和电影节活动在这里举行。

现在大城市的电影院多设在商场里，票可以在售票处 [ка́сса]{.ru} 买，也可以在网上买。外国电影大多配俄语音，带字幕的原声场次要专门找。白天和工作日的票往往比周末晚上便宜，所以学生常挑早场。

## 语法

### 一、人称代词第五格

| 第一格 | 第五格 | 带 [с]{.ru} |
|---|---|---|
| [я]{.ru} | [мной]{.ru} | [со мной]{.ru} |
| [ты]{.ru} | [тобо́й]{.ru} | [с тобо́й]{.ru} |
| [он]{.ru}、[оно́]{.ru} | [им]{.ru} | [с ним]{.ru} |
| [она́]{.ru} | [ей]{.ru} | [с ней]{.ru} |
| [мы]{.ru} | [на́ми]{.ru} | [с на́ми]{.ru} |
| [вы]{.ru} | [ва́ми]{.ru} | [с ва́ми]{.ru} |
| [они́]{.ru} | [и́ми]{.ru} | [с ни́ми]{.ru} |
| [кто]{.ru} | [кем]{.ru} | [с кем]{.ru} |
| [что]{.ru} | [чем]{.ru} | [с чем]{.ru} |
| [себя́]{.ru} | [собо́й]{.ru} | [с собо́й]{.ru} |

1. 第三人称代词在前置词后面要加 [н-]{.ru}：[с ним, с ней, с ни́ми]{.ru}，和第二格（[у него́]{.ru}）、第三格（[к нему́]{.ru}）一样。
2. “和我”写成 [со мной]{.ru}，不写 [с мной]{.ru}。
3. 物主代词 [его́, её, их]{.ru}（他的、她的、他们的）前面不加 [н-]{.ru}：[с его́ бра́том]{.ru}“和他的哥哥”，[с ним]{.ru}“和他”，两者要分清。
4. [себя́]{.ru} 没有第一格，指主语本人：[Я беру́ кни́гу с собо́й.]{.ru}“我随身带着书。”

### 二、[мы с …]{.ru} 句型

汉语说“我和安娜”，俄语常说 [мы с А́нной]{.ru}：

::: ex
[Мы с А́нной идём в кино́.]{.ru}[我和安娜去看电影。]{.gloss}

[Мы с ним у́чимся вме́сте.]{.ru}[我和他一起上学。]{.gloss}

[Вы с бра́том лю́бите кино́?]{.ru}[你和你弟弟喜欢电影吗？]{.gloss}
:::

要点：

1. [мы]{.ru} 包括说话人在内，[мы с А́нной]{.ru} 一共是两个人：我和安娜。不要理解成“我们和安娜”。
2. 同理，[вы с бра́том]{.ru} 是“你和（你的）弟弟”，[они́ с ма́мой]{.ru} 是“他（她）和妈妈”。
3. 谓语动词用复数：[Мы с А́нной идём]{.ru}。[Я с А́нной иду́]{.ru} 语法上也对，但主语只是“我”，意思是“我跟安娜一起去”，侧重点在“我”。
4. [Я и А́нна]{.ru} 语法上也对，但听起来生硬，口语里几乎总说 [мы с А́нной]{.ru}。

## 语音·语调

### 一、[со мной]{.ru} 与 [с ним]{.ru} 的读法

[со]{.ru} 不重读，[о]{.ru} 弱化，[со мной]{.ru} 读作 [[самно́й]]{.tr}。[с ним]{.ru}、[с ней]{.ru} 里的 [с]{.ru} 受后面软辅音影响，读得稍软：[[сʼнʼим]]{.tr}、[[сʼнʼэй]]{.tr}。前置词和代词同样连成一个词读，中间不停：

::: ex
[со мной]{.ru} [[самно́й]]{.tr}

[с тобо́й]{.ru} [[стабо́й]]{.tr}

[с на́ми]{.ru} [[сна́мʼи]]{.tr}

[с ва́ми]{.ru} [[сва́мʼи]]{.tr}
:::

### 二、简短问句的调心

省略句里，[ИК-3]{.ru} 落在要问的那个词上；带疑问词时用 [ИК-2]{.ru}，调心在疑问词上：

::: ex
[Мо́жно с [ва́ми]{.ic data-n="3"}?]{.ru}

[С [на́ми]{.ic data-n="3"}?]{.ru}

[А ты с [кем]{.ic data-n="2"}?]{.ru}

[Мы с ним у́чимся [вме́сте]{.ic data-n="1"}.]{.ru}
:::
