## 课文

::: {.prose lang="ru"}
В воскресе́нье ве́чером А́нна и Ка́тя пьют чай на ку́хне. Ка́тя — лу́чшая подру́га А́нны. Ра́ньше они́ вме́сте ходи́ли в шко́лу. Ван Лэй то́же идёт на ку́хню. Он уже́ зна́ет Ка́тю: неда́вно он ви́дел её в метро́.
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} Приве́т, Ка́тя!

[Ка́тя]{.sp} Приве́т! Ван Лэй, ты студе́нт филологи́ческого факульте́та, как А́нна?

[Ван Лэй]{.sp} Да. А ты?

[Ка́тя]{.sp} А я студе́нтка медици́нского институ́та. Ма́ма А́нны — врач, моя́ ма́ма то́же врач, а я бу́дущий врач.

[Ван Лэй]{.sp} А где ты живёшь?

[Ка́тя]{.sp} Недалеко́, на сосе́дней у́лице. А в суббо́ту я ча́сто е́зжу на да́чу моего́ де́душки.

[Ван Лэй]{.sp} А что э́то на фо́то?

[Ка́тя]{.sp} Э́то дом моего́ ста́ршего бра́та. Он живёт в Каза́ни.

[А́нна]{.sp} У Ка́ти нет сестры́, но есть ста́рший брат. А у тебя́, Ван Лэй, то́лько двою́родный брат.

[Ван Лэй]{.sp} Да. Вот фо́то его́ соба́ки!
:::

::: {.prose lang="ru"}
Ка́тя и А́нна смо́трят фо́то весёлой ма́ленькой соба́ки. «Кака́я хоро́шая!» — говори́т Ка́тя.
:::

## 课文注释

::: notes
1. **[пьют чай]{.ru}** “喝茶”，[пить]{.ru} 的变位是 [пью, пьёшь, пьют]{.ru}。
2. **[лу́чшая подру́га]{.ru}** “最好的朋友”。[подру́га]{.ru} 指女性朋友；男性朋友是 [друг]{.ru}。
3. **[Ван Лэй то́же идёт на ку́хню.]{.ru}** [идти́ на ку́хню]{.ru}“去厨房”，[на]{.ru} + 第四格表示去向。
4. **[Он уже́ зна́ет Ка́тю]{.ru}** 王磊在第 22 课里在地铁站遇见过卡佳。
5. **[я бу́дущий врач]{.ru}** “我是未来的医生”，即“我将来要当医生”。卡佳是女性，但 [врач]{.ru} 没有阴性形式，形容词仍用阳性。
6. **[на сосе́дней у́лице]{.ru}** “在旁边那条街上”。[сосе́дний, -яя, -ее, -ие]{.ru} 是软变化形容词，由 [сосе́д]{.ru} 构成。
7. **[«Кака́я хоро́шая!»]{.ru}** 省去了 [соба́ка]{.ru}：“多可爱的狗啊！”
:::

## 俄罗斯知识

### 俄罗斯人的友谊观

安娜和卡佳从中学起就是朋友。俄语区分 [друг]{.ru}（[подру́га]{.ru}）和 [знако́мый]{.ru}（[знако́мая]{.ru}）：[знако́мый]{.ru} 是“认识的人、熟人”，[друг]{.ru} 则是真正亲近、可以托付的人。俄罗斯人不轻易把一个人称作 [друг]{.ru}，一个人通常只有不多的几个朋友，但友情往往能维持几十年。

朋友之间说话直率，可以不客气地批评，也可以深夜打电话求助。俄罗斯有句谚语：[Не име́й сто рубле́й, а име́й сто друзе́й.]{.ru}“与其有一百卢布，不如有一百个朋友。”

还要注意，[подру́га]{.ru} 一般指女性之间的朋友；男性说 [моя́ подру́га]{.ru} 时，常被理解为“我的女朋友”。要说普通的女性朋友，男性多说 [мой друг]{.ru} 或 [моя́ знако́мая]{.ru}。

## 语法

### 一、形容词单数第二格

| | 阳性、中性 | 阴性 |
|---|---|---|
| 硬变化 | [но́вый, но́вое → но́вого]{.ru} | [но́вая → но́вой]{.ru} |
| 软变化 | [си́ний, си́нее → си́него]{.ru} | [си́няя → си́ней]{.ru} |
| 重音在词尾 | [большо́й, большо́е → большо́го]{.ru} | [больша́я → большо́й]{.ru} |
| [ж、ш、ч、щ]{.ru} 后 | [хоро́ший, хоро́шее → хоро́шего]{.ru} | [хоро́шая → хоро́шей]{.ru} |

阳性和中性第二格同形，词尾 [-ого]{.ru} / [-его]{.ru}；阴性词尾 [-ой]{.ru} / [-ей]{.ru}。

**拼写规则。** [ж、ш、ч、щ、ц]{.ru} 后面不重读的 [о]{.ru} 写成 [е]{.ru}：[хоро́шего, хоро́шей]{.ru}，[ста́ршего, ста́ршей]{.ru}，[бу́дущего]{.ru}。重读时仍写 [о]{.ru}：[большо́го]{.ru}。

::: ex
[студе́нтка медици́нского институ́та]{.ru}[医学院的学生]{.gloss}

[дом ста́ршего бра́та]{.ru}[哥哥的房子]{.gloss}

[фо́то весёлой соба́ки]{.ru}[那条快乐的狗的照片]{.gloss}
:::

### 二、物主代词和指示代词单数第二格

| 第一格 | 阳性、中性第二格 | 阴性第二格 |
|---|---|---|
| [мой, моё / моя́]{.ru} | [моего́]{.ru} | [мое́й]{.ru} |
| [твой, твоё / твоя́]{.ru} | [твоего́]{.ru} | [твое́й]{.ru} |
| [наш, на́ше / на́ша]{.ru} | [на́шего]{.ru} | [на́шей]{.ru} |
| [ваш, ва́ше / ва́ша]{.ru} | [ва́шего]{.ru} | [ва́шей]{.ru} |
| [чей, чьё / чья]{.ru} | [чьего́]{.ru} | [чьей]{.ru} |
| [э́тот, э́то / э́та]{.ru} | [э́того]{.ru} | [э́той]{.ru} |
| [его́, её, их]{.ru} | 不变 | 不变 |

::: ex
[Э́то дом моего́ ста́ршего бра́та.]{.ru}[这是我哥哥的房子。]{.gloss}

[Вот окно́ мое́й ко́мнаты.]{.ru}[这是我房间的窗户。]{.gloss}

[У на́шей сосе́дки есть соба́ка.]{.ru}[我们的女邻居有一条狗。]{.gloss}
:::

**要点：**

1. 形容词、代词跟名词的**性**一致，不看名词的词尾。[па́па, де́душка]{.ru} 是阳性，所以说 [моего́ па́пы]{.ru}、[на́шего де́душки]{.ru}，不说 [мое́й па́пы]{.ru}。
2. [его́, её, их]{.ru}（他的、她的、他们的）永远不变：[дом её бра́та]{.ru}，[фо́то его́ соба́ки]{.ru}。
3. 问“谁的”可以用 [чей]{.ru} 的第二格：[— Э́то фо́то чьего́ бра́та? — Моего́.]{.ru}

## 语音·语调

### [-ого]{.ru}、[-его]{.ru} 里的 [г]{.ru} 读 [[в]]{.tr}

形容词、代词第二格词尾 [-ого]{.ru}、[-его]{.ru} 中的 [г]{.ru} 一律读 [[в]]{.tr}。第 31 课学过的 [его́]{.ru}、[кого́]{.ru} 也是这样。

::: ex
[моего́]{.ru} [[маиво́]]{.tr}　[большо́го]{.ru} [[бальшо́въ]]{.tr}　[но́вого]{.ru} [[но́въвъ]]{.tr}　[э́того]{.ru} [[э́тъвъ]]{.tr}
:::

### [ж]{.ru}、[ш]{.ru}、[ц]{.ru} 后的 [и]{.ru} 读 [[ы]]{.tr}

[ж、ш、ц]{.ru} 永远是硬辅音，后面写 [и]{.ru}，实际读 [[ы]]{.tr}；后面写 [е]{.ru}，读得接近 [[ы]]{.tr} 或 [[э]]{.tr}。对比软辅音后的 [и]{.ru}：

::: ex
[ста́рший]{.ru} [[ста́ршый]]{.tr}　[хоро́ший]{.ru} [[харо́шый]]{.tr}　[маши́на]{.ru} [[машы́нъ]]{.tr}

[ста́ршего]{.ru} [[ста́ршывъ]]{.tr}　[бу́дущего]{.ru} [[бу́дущывъ]]{.tr}
:::

::: ex
[Э́то дом моего́ [ста́ршего]{.ic data-n="1"} бра́та.]{.ru}

[Кака́я [хоро́шая]{.ic data-n="5"}!]{.ru}
:::

## 参考译文

::: prose-zh
星期天晚上，安娜和卡佳在厨房里喝茶。卡佳是安娜最好的朋友。她们以前一起上中学。王磊也往厨房走去。他已经认识卡佳了：不久前他在地铁里见过她。
:::

::: translation
[王磊]{.sp} 你好，卡佳！

[卡佳]{.sp} 你好！王磊，你和安娜一样，是语文系的学生吧？

[王磊]{.sp} 对。你呢？

[卡佳]{.sp} 我是医学院的学生。安娜的妈妈是医生，我妈妈也是医生，我是未来的医生。

[王磊]{.sp} 你住在哪儿？

[卡佳]{.sp} 不远，就在旁边那条街上。星期六我常去我爷爷的别墅。

[王磊]{.sp} 照片上这是什么？

[卡佳]{.sp} 这是我哥哥的房子。他住在喀山。

[安娜]{.sp} 卡佳没有姐妹，但是有个哥哥。王磊，你只有一个表哥。

[王磊]{.sp} 对。这是他的狗的照片！
:::

::: prose-zh
卡佳和安娜看着那条快乐的小狗的照片。“多可爱的狗啊！”卡佳说。
:::
