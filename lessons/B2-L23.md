## 课前问题

::: question
听录音，回答问题：

[Како́е о́зеро глу́бже всех озёр на све́те?]{.ru}
:::

## 课文

::: {.prose lang="ru"}
В сре́ду на уро́ке О́льга Ви́кторовна пове́сила на доску́ большу́ю ка́рту Росси́и. Те́ма уро́ка была́ «Ре́ки и озёра».

— Вот Во́лга, — сказа́ла она́. — Она́ течёт че́рез всю европе́йскую часть Росси́и и впада́ет в Каспи́йское мо́ре. Её длина́ — три ты́сячи пятьсо́т три́дцать киломе́тров. На Во́лге стоя́т мно́гие ста́рые города́: Ни́жний Но́вгород, Каза́нь, Сама́ра, Волгогра́д. А у вас до́ма каки́е ре́ки? Чьи ре́ки длинне́е?
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} Янцзы́ длинне́е и ши́ре Во́лги. Её длина́ — почти́ шесть ты́сяч три́ста киломе́тров.

[Пьер]{.sp} А на́ша Се́на намно́го коро́че. Но, по-мо́ему, она́ краси́вее!

[Ю́ми]{.sp} В Япо́нии ре́ки коро́ткие. Зато́ у нас есть Фу́дзи, она́ вы́ше всех гор в Япо́нии.

[О́льга Ви́кторовна]{.sp} А Эльбру́с ещё вы́ше. Э́то гора́ на Кавка́зе, её высота́ — пять ты́сяч шестьсо́т со́рок два ме́тра.

[Хосе́]{.sp} А у нас на Ку́бе таки́х гор нет. Зато́ там гора́здо тепле́е, чем в Москве́!
:::

::: {.prose lang="ru"}
Все засмея́лись: в тот день в Москве́ шёл мо́крый снег. Пото́м О́льга Ви́кторовна спроси́ла: «А како́е о́зеро глу́бже всех озёр на све́те?» Ван Лэй отве́тил пе́рвым: «Байка́л!» Глубина́ Байка́ла — ты́сяча шестьсо́т со́рок два ме́тра. О Байка́ле Ван Лэй зна́ет мно́го: в а́вгусте Петро́вы пое́дут туда́ всей семьёй, и Ива́н Серге́евич ча́сто расска́зывает о нём.

По́сле уро́ка Ван Лэй позвони́л Ди́ме.

— Ты зна́ешь, что Янцзы́ длинне́е Во́лги почти́ в два ра́за?

— Зна́ю, — отве́тил Ди́ма. — Но Во́лга краси́вее всех рек на све́те. Сам уви́дишь!
:::

## 课文注释

::: notes
1. **[пове́сила на доску́]{.ru}** [доска́]{.ru} 的第四格 [до́ску]{.ru}，和前置词 [на]{.ru} 连用时重音常移到词尾：[на доску́]{.ru}。
2. **[течёт че́рез всю европе́йскую часть Росси́и]{.ru}** [че́рез]{.ru} + 第四格：穿过。[течь]{.ru} 变位特殊：[теку́, течёшь, течёт, теку́т]{.ru}，过去时 [тёк, текла́]{.ru}。
3. **[впада́ет в Каспи́йское мо́ре]{.ru}** [впада́ть в]{.ru} + 第四格：（河）流入（海、湖、别的河）。
4. **[Её длина́ — три ты́сячи пятьсо́т три́дцать киломе́тров.]{.ru}** 说长、高、深多少时常用 [длина́ / высота́ / глубина́ — …]{.ru} 的句式，破折号代替 [есть]{.ru}。
5. **[Чьи ре́ки длинне́е?]{.ru}** [чей]{.ru} 和复数 [ре́ки]{.ru} 一致，见第 21 课。
6. **[Янцзы́ длинне́е и ши́ре Во́лги.]{.ru}** 比较级后面直接用第二格表示比较的对象，相当于 [длинне́е, чем Во́лга]{.ru}。[Янцзы́]{.ru} 是不变格的阴性名词（[река́]{.ru}），所以用 [её]{.ru} 指代。
7. **[Зато́ у нас есть Фу́дзи]{.ru}** [зато́]{.ru} 表示“虽然……，但另一方面有可以弥补的长处”。
8. **[вы́ше всех гор]{.ru}** 比较级 + [всех]{.ru} 表示“比所有的都……”，也就是“最……”。[краси́вее всех рек]{.ru} 同理。
9. **[пое́дут туда́ всей семьёй]{.ru}** [всей семьёй]{.ru} 用第五格，表示“全家一起”。
10. **[почти́ в два ра́за]{.ru}** [в]{.ru} + 数词 + [ра́за / раз]{.ru} 表示倍数：[в два ра́за длинне́е]{.ru} 长一倍（是……的两倍）。
:::

## 俄罗斯知识

### 俄罗斯之最：最长的河、最深的湖

奥尔加·维克托罗夫娜的地图上，最显眼的是伏尔加河。它全长约 3530 公里，是欧洲最长的河，从莫斯科西北的瓦尔代丘陵流出，一直流进里海。俄罗斯人亲切地叫它 [ма́тушка-Во́лга]{.ru}（伏尔加母亲河）。

可伏尔加河并不是俄罗斯最长的河。西伯利亚的大河要长得多：鄂毕河连同它的支流额尔齐斯河长约 5400 公里，是俄罗斯最长的水系；如果只算全部流经俄罗斯境内的河，最长的是勒拿河，约 4400 公里。叶尼塞河是俄罗斯水量最大的河。西伯利亚的大河大多由南向北，注入北冰洋，冬天要封冻半年。

贝加尔湖在东西伯利亚，最深处 1642 米，是世界上最深的湖，也是最古老的湖之一，已有两千五百万年以上的历史。它的淡水约占全世界湖泊、河流淡水总量的五分之一。湖里生活着贝加尔海豹（[не́рпа]{.ru}）和一种只产在这里的鱼 [о́муль]{.ru}（秋白鲑）。欧洲最大的湖则是圣彼得堡附近的拉多加湖。

俄罗斯的最高峰是北高加索的厄尔布鲁士山，海拔 5642 米，是一座死火山，有东西两个峰顶。

## 语法

### 一、形容词比较级的构成

第一册第 86 课学过 [бо́льше, ме́ньше, лу́чше, ху́же]{.ru} 和几个 [-ее]{.ru} 形式。比较级有三种构成方法。

**1. 词干 + [-ее]{.ru}**：大多数形容词都这样构成。

| 原级 | 比较级 | 原级 | 比较级 |
|---|---|---|---|
| [дли́нный]{.ru} | [длинне́е]{.ru} | [краси́вый]{.ru} | [краси́вее]{.ru} |
| [тёплый]{.ru} | [тепле́е]{.ru} | [интере́сный]{.ru} | [интере́снее]{.ru} |
| [холо́дный]{.ru} | [холодне́е]{.ru} | [серьёзный]{.ru} | [серьёзнее]{.ru} |
| [но́вый]{.ru} | [нове́е]{.ru} | [ве́жливый]{.ru} | [ве́жливее]{.ru} |
| [бы́стрый]{.ru} | [быстре́е]{.ru} | [поле́зный]{.ru} | [поле́знее]{.ru} |

重音：短尾阴性重音在词尾的形容词（[длинна́, тепла́, нова́]{.ru}），比较级重音在 [-е́е]{.ru} 上；其余保留原级词干上的重音。口语里 [-ее]{.ru} 也说成 [-ей]{.ru}：[длинне́й, краси́вей]{.ru}。

**2. 词干末辅音交替 + [-е]{.ru}**：词干以 [г, к, х, д]{.ru} 和 [-ст]{.ru} 结尾的常用形容词，比较级只加 [-е]{.ru}，词干末尾的辅音发生交替，重音在词干上。

| 交替 | 原级 → 比较级 |
|---|---|
| [г → ж]{.ru} | [дорого́й → доро́же]{.ru} |
| [к → ч]{.ru} | [лёгкий → ле́гче]{.ru}，[коро́ткий → коро́че]{.ru} |
| [х → ш]{.ru} | [ти́хий → ти́ше]{.ru} |
| [д → ж]{.ru} | [молодо́й → моло́же]{.ru} |
| [-ст → -щ]{.ru} | [просто́й → про́ще]{.ru}，[чи́стый → чи́ще]{.ru} |
| [-зк → -ж]{.ru} | [бли́зкий → бли́же]{.ru}，[ни́зкий → ни́же]{.ru} |

**3. 特殊形式**：要单独记住。

| 原级 | 比较级 | 原级 | 比较级 |
|---|---|---|---|
| [хоро́ший]{.ru} | [лу́чше]{.ru} | [высо́кий]{.ru} | [вы́ше]{.ru} |
| [плохо́й]{.ru} | [ху́же]{.ru} | [широ́кий]{.ru} | [ши́ре]{.ru} |
| [большо́й]{.ru} | [бо́льше]{.ru} | [глубо́кий]{.ru} | [глу́бже]{.ru} |
| [ма́ленький]{.ru} | [ме́ньше]{.ru} | [далёкий]{.ru} | [да́льше]{.ru} |
| [ста́рый]{.ru}（指年龄） | [ста́рше]{.ru} | [дешёвый]{.ru} | [деше́вле]{.ru} |

比较级没有性、数、格的变化，常作谓语：[Река́ длинне́е. Мо́ре глу́бже. Го́ры вы́ше.]{.ru}

### 二、比较的对象：[чем]{.ru} 或第二格

比较的对象有两种说法：

::: ex
[Янцзы́ длинне́е, чем Во́лга.]{.ru}[长江比伏尔加河长。]{.gloss}

[Янцзы́ длинне́е Во́лги.]{.ru}[长江比伏尔加河长。]{.gloss}
:::

用第二格更简洁，口语和书面语都很常用。但只有在被比较的两个词都是第一格时才能用第二格。其余情况只能用 [чем]{.ru}，[чем]{.ru} 后面的词和前面的词同格：

::: ex
[На Ку́бе тепле́е, чем в Москве́.]{.ru}[古巴比莫斯科暖和。（两个 [в / на]{.ru} + 第六格）]{.gloss}

[Ле́том здесь лу́чше, чем зимо́й.]{.ru}[这里夏天比冬天好。（两个副词）]{.gloss}
:::

人称代词放在比较级后面用第二格，**不加 [н-]{.ru}**，这一点和前置词后面不同：

::: ex
[Ди́ма ста́рше меня́.]{.ru}[迪马比我大。]{.gloss}

[А́нна моло́же его́.]{.ru}[安娜比他小。]{.gloss}
:::

### 三、程度的说法

| 说法 | 意思 | 例子 |
|---|---|---|
| [гора́здо, намно́го]{.ru} + 比较级 | ……得多 | [Се́на намно́го коро́че.]{.ru} |
| [ещё]{.ru} + 比较级 | 更加，还要…… | [А Эльбру́с ещё вы́ше.]{.ru} |
| [в два (три…) ра́за]{.ru} + 比较级 | ……一倍（两倍……） | [Янцзы́ длинне́е Во́лги почти́ в два ра́за.]{.ru} |
| 比较级 + [всех]{.ru} | 比所有人（物）都…… | [Байка́л глу́бже всех озёр.]{.ru} |
| 比较级 + [всего́]{.ru} | 比一切都…… | [Здоро́вье доро́же всего́.]{.ru} |

注意：[о́чень]{.ru} 不能修饰比较级。不能说 [о́чень длинне́е]{.ru}，要说 [гора́здо длинне́е]{.ru} 或 [намно́го длинне́е]{.ru}。

## 参考译文

::: prose-zh
星期三上课时，奥尔加·维克托罗夫娜在黑板上挂了一张大大的俄罗斯地图。这节课的题目是“河流与湖泊”。

“这是伏尔加河，”她说，“它流过整个欧洲部分的俄罗斯，注入里海。它全长三千五百三十公里。伏尔加河边有很多古城：下诺夫哥罗德、喀山、萨马拉、伏尔加格勒。那么你们家乡有哪些河？谁家乡的河更长？”
:::

::: translation
[王磊]{.sp} 长江比伏尔加河长，也比它宽。长江全长将近六千三百公里。

[皮埃尔]{.sp} 我们的塞纳河可短多了。不过依我看，它更美！

[由美]{.sp} 日本的河都很短。可我们有富士山，它比日本所有的山都高。

[奥尔加·维克托罗夫娜]{.sp} 厄尔布鲁士山还要高。这是高加索的一座山，海拔五千六百四十二米。

[何塞]{.sp} 我们古巴没有这么高的山。不过那儿比莫斯科暖和多了！
:::

::: prose-zh
大家都笑了：那天莫斯科正下着雨夹雪。接着奥尔加·维克托罗夫娜问：“世界上哪个湖最深？”王磊第一个回答：“贝加尔湖！”贝加尔湖深一千六百四十二米。王磊对贝加尔湖知道得很多：八月彼得罗夫一家要全家去那儿，伊万·谢尔盖耶维奇常常讲起它。

下课后王磊给迪马打电话。

“你知道长江差不多是伏尔加河的两倍长吗？”

“知道，”迪马回答，“可伏尔加河比世界上所有的河都美。你自己会看到的！”
:::
