## 课前问题

## 课文

::: {.prose lang="ru"}
Сего́дня воскресе́нье. В Москве́ три часа́ дня, а в Пеки́не уже́ во́семь часо́в ве́чера. Ка́ждое воскресе́нье Ван Лэй звони́т домо́й. Сего́дня он то́же звони́т ма́ме и па́пе. Он до́лго расска́зывает ма́ме о Москве́ и об университе́те. Па́па сове́тует сы́ну: «Чита́й и говори́ по-ру́сски ка́ждый день!» А ма́ма передаёт приве́т Мари́и Никола́евне и Ива́ну Серге́евичу.
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} А́нна, ма́ма передаёт приве́т Мари́и Никола́евне.

[А́нна]{.sp} Спаси́бо! А я пишу́ сообще́ние ба́бушке.

[Ван Лэй]{.sp} Ба́бушке? А почему́ ты не звони́шь?

[А́нна]{.sp} Ба́бушка не лю́бит до́лго говори́ть по телефо́ну. Но сообще́ния она́ чита́ет. А вчера́ я отпра́вила ба́бушке ви́део: Му́рка спит на компью́тере.
:::

::: {.prose lang="ru"}
Звони́т телефо́н.
:::

::: {.dialogue lang="ru"}
[А́нна]{.sp} Алло́! Ба́бушка, приве́т! … Па́па, ба́бушка звони́т!

[Ван Лэй]{.sp} А говори́шь, не лю́бит звони́ть!

[А́нна]{.sp} Па́пе она́ звони́т ка́ждый день. Э́то друго́е де́ло.

[Ван Лэй]{.sp} А о чём ты пи́шешь ба́бушке?

[А́нна]{.sp} О Ми́ше. Двадца́того ноября́ у Ми́ши день рожде́ния. Что мы пода́рим бра́ту? Я спра́шиваю ба́бушку.
:::

## 课文注释

::: notes
1. **[три часа́ дня, во́семь часо́в ве́чера]{.ru}** 说钟点时，后面加 [дня]{.ru}（白天的）、[ве́чера]{.ru}（晚上的）、[утра́]{.ru}（早上的），区分上午和下午。莫斯科和北京相差五个小时。
2. **[Па́па сове́тует сы́ну: «Чита́й…»]{.ru}** [сове́товать]{.ru} 的对象用第三格，表示劝谁、给谁出主意，后面常接命令式或不定式。
3. **[передава́ть приве́т]{.ru}** 托人问候第三方时说 [Ма́ма передаёт приве́т Мари́и Никола́евне]{.ru}，被问候的人用第三格。
4. **[говори́ть по телефо́ну]{.ru}** 打电话、在电话里说话。[по]{.ru} 和后面的第三格在第 57 课讲，这里先当作固定短语记住。
5. **[А говори́шь, не лю́бит звони́ть!]{.ru}** 口语里省去了主语 [ты]{.ru}，意思是“你还说她不爱打电话呢！”，带有打趣的口气。
6. **[Э́то друго́е де́ло.]{.ru}** “那是另一回事。”常用来说明两种情况不能相提并论。
7. **[день рожде́ния]{.ru}** 生日。[рожде́ния]{.ru} 是 [рожде́ние]{.ru}（出生）的第二格，只变 [день]{.ru}，[рожде́ния]{.ru} 不变。
:::

## 俄罗斯知识

### [Алло́]{.ru} 与通话礼仪

安娜拿起电话，第一句话是 [Алло́!]{.ru} 这个词一般认为借自法语或英语，19 世纪末随电话一起传入俄国，书面上写作 [алло́]{.ru}，口语里多读成 [[алё]]{.tr}。接电话的人也常说 [Да!]{.ru} 或 [Слу́шаю!]{.ru}（我在听），在单位里则说 [Вас слу́шают]{.ru} 或报出单位名称。

打电话的一方先问好，再说明找谁。如果接电话的不是要找的人，要说 [Позови́те, пожа́луйста, А́нну]{.ru}（请叫一下安娜），关系熟的也可以说 [А́ню мо́жно?]{.ru}。打错了电话，对方会说 [Вы не туда́ попа́ли]{.ru}（您打错了）。

往别人家里打电话，一般不早于上午九点、不晚于晚上十点，周末早上更要晚一些。和长辈、老师通话结束时，常说 [Всего́ хоро́шего!]{.ru}（祝您一切都好）或 [До свида́ния!]{.ru}。现在年轻人更多发短信和用手机应用聊天，但给长辈打电话、在电话里互致问候，仍是很多家庭的习惯，就像课文里奶奶每天给儿子打电话一样。

## 语法

### 一、名词第三格的意义

第三格（与格）回答 [кому́?]{.ru}（给谁？）和 [чему́?]{.ru}（给什么？）的问题。它最基本的用法是表示动作的间接对象，也就是动作“给谁”“对谁”而做：

::: ex
[Ван Лэй звони́т ма́ме.]{.ru}[王磊给妈妈打电话。]{.gloss}

[Он расска́зывает ма́ме о Москве́.]{.ru}[他给妈妈讲莫斯科的事。]{.gloss}

[А́нна пи́шет сообще́ние ба́бушке.]{.ru}[安娜给奶奶写短信。]{.gloss}

[Что мы пода́рим бра́ту?]{.ru}[我们送弟弟什么？]{.gloss}
:::

后两句里，[сообще́ние]{.ru}、[что]{.ru} 是直接对象（第四格），[ба́бушке]{.ru}、[бра́ту]{.ru} 是间接对象（第三格）。一个动词可以同时带这两种对象：送什么（第四格）给谁（第三格）。

### 二、名词第三格单数的词尾

| 性 | 第一格词尾 | 第三格词尾 | 例词 |
|---|---|---|---|
| 阳性 | 硬辅音 | [-у]{.ru} | [брат → бра́ту]{.ru}，[студе́нт → студе́нту]{.ru} |
| 阳性 | [-й]{.ru}、[-ь]{.ru} | [-ю]{.ru} | [Серге́й → Серге́ю]{.ru}，[учи́тель → учи́телю]{.ru} |
| 中性 | [-о]{.ru} | [-у]{.ru} | [окно́ → окну́]{.ru} |
| 中性 | [-е]{.ru} | [-ю]{.ru} | [мо́ре → мо́рю]{.ru} |
| 阴性 | [-а]{.ru}、[-я]{.ru} | [-е]{.ru} | [ма́ма → ма́ме]{.ru}，[Та́ня → Та́не]{.ru} |
| 阴性 | [-ия]{.ru} | [-ии]{.ru} | [Мари́я → Мари́и]{.ru} |
| 阴性 | [-ь]{.ru} | [-и]{.ru} | [тетра́дь → тетра́ди]{.ru} |

记忆要点：

1. 阳性和中性名词词尾相同：硬的变 [-у]{.ru}，软的变 [-ю]{.ru}。
2. 阴性名词的第三格和第六格同形：[ма́ме]{.ru}、[о ма́ме]{.ru}；[Мари́и]{.ru}、[о Мари́и]{.ru}；[тетра́ди]{.ru}、[в тетра́ди]{.ru}。已经掌握第六格的，阴性第三格几乎不用另记。
3. 以 [-а]{.ru}、[-я]{.ru} 结尾的阳性名词，如 [па́па]{.ru}、[Ми́ша]{.ru}、[де́душка]{.ru}，按阴性变化：[па́пе]{.ru}、[Ми́ше]{.ru}、[де́душке]{.ru}。
4. 有隐现元音的词，变格时 [о]{.ru}、[е]{.ru} 脱落，和第二格一样：[оте́ц → отцу́]{.ru}。
5. [мать]{.ru}、[дочь]{.ru} 变格时词干加 [-ер-]{.ru}：[ма́тери]{.ru}、[до́чери]{.ru}。
6. 名字和父称各自变格：[Ива́ну Серге́евичу]{.ru}，[Мари́и Никола́евне]{.ru}，[А́нне Ива́новне]{.ru}。

疑问代词 [кто]{.ru}、[что]{.ru} 的第三格是 [кому́]{.ru}、[чему́]{.ru}：

::: ex
[— Кому́ ты пи́шешь? — Ба́бушке.]{.ru}[——你给谁写信？——给奶奶。]{.gloss}
:::

### 三、要求第三格的动词

下面这些动词的对象用第三格，汉语里多半说成“给某人……”“对某人……”：

| 动词 | 例句 |
|---|---|
| [звони́ть]{.ru} 打电话 | [Я звоню́ ма́ме.]{.ru} |
| [писа́ть]{.ru} 写 | [Он пи́шет бра́ту.]{.ru} |
| [расска́зывать]{.ru} 讲述 | [Она́ расска́зывает па́пе о шко́ле.]{.ru} |
| [говори́ть]{.ru} 说 | [Что ты говори́шь Ми́ше?]{.ru} |
| [дари́ть / подари́ть]{.ru} 送 | [Что вы пода́рите А́нне?]{.ru} |
| [сове́товать]{.ru} 劝，建议 | [Па́па сове́тует сы́ну чита́ть.]{.ru} |
| [передава́ть приве́т]{.ru} 问好 | [Ма́ма передаёт приве́т Ива́ну Серге́евичу.]{.ru} |

**容易错的地方**：[звони́ть]{.ru} 后面用第三格，不用第四格。汉语说“给妈妈打电话”，有人受“打”字影响写成 *[звони́ть ма́му]{.ru}*，这是错的。反过来，[спра́шивать]{.ru}（问）的对象用第四格：[Я спра́шиваю ба́бушку]{.ru}，不能说 *[спра́шиваю ба́бушке]{.ru}*。

### 四、[передава́ть]{.ru} 的变位

[передава́ть]{.ru} 和 [дава́ть]{.ru} 一样，现在时去掉 [-ва-]{.ru}，重音在词尾：

| 人称 | 现在时 |
|---|---|
| [я]{.ru} | [передаю́]{.ru} |
| [ты]{.ru} | [передаёшь]{.ru} |
| [он, она́]{.ru} | [передаёт]{.ru} |
| [мы]{.ru} | [передаём]{.ru} |
| [вы]{.ru} | [передаёте]{.ru} |
| [они́]{.ru} | [передаю́т]{.ru} |

## 语音·语调

### 第三格词尾 [-е]{.ru} 的读音

阴性名词第三格词尾 [-е]{.ru} 前面的辅音读软音；[-е]{.ru} 不带重音时弱化，接近 [и]{.ru}：

::: ex
[ма́ме]{.ru} [[ма́мʼи]]{.tr}　[па́пе]{.ru} [[па́пʼи]]{.tr}　[ба́бушке]{.ru} [[ба́бушкʼи]]{.tr}　[А́нне]{.ru} [[а́нʼи]]{.tr}
:::

[Мари́и]{.ru} 读作 [[мари́и]]{.tr}，两个 [и]{.ru} 都要读出来，第二个轻而短。

### 问“给谁”：[ИК-2]{.ru} 与 [ИК-3]{.ru}

带疑问词 [кому́]{.ru} 的问句用 [ИК-2]{.ru}，调心在 [кому́]{.ru} 上；不带疑问词、问“是不是给某人”的问句用 [ИК-3]{.ru}，调心落在要确认的那个词上：

::: ex
[[Кому́]{.ic data-n="2"} ты звони́шь?]{.ru}

[Ты звони́шь [ма́ме]{.ic data-n="3"}?]{.ru}

[Да, я звоню́ [ма́ме]{.ic data-n="1"}.]{.ru}

[Ты [звони́шь]{.ic data-n="3"} ба́бушке?]{.ru}

[Нет, я [пишу́]{.ic data-n="1"} ба́бушке.]{.ru}
:::

## 参考译文

::: prose-zh
今天是星期天。莫斯科是下午三点，北京已经是晚上八点了。每个星期天王磊都往家里打电话。今天他也给妈妈和爸爸打电话。他给妈妈讲了很久莫斯科和大学的事。爸爸劝儿子：“每天都要读俄语、说俄语！”妈妈则向玛丽亚·尼古拉耶夫娜和伊万·谢尔盖耶维奇问好。
:::

::: translation
[王磊]{.sp} 安娜，我妈妈向玛丽亚·尼古拉耶夫娜问好。

[安娜]{.sp} 谢谢！我在给奶奶写短信。

[王磊]{.sp} 给奶奶？那你为什么不打电话？

[安娜]{.sp} 奶奶不喜欢在电话里说很久。不过短信她是看的。昨天我还给奶奶发了一段视频：穆尔卡在电脑上睡觉。
:::

电话响了。
:::

[王磊]{.sp} 你还说她不爱打电话呢！

[安娜]{.sp} 给爸爸她每天都打。那是另一回事。

[王磊]{.sp} 那你给奶奶写什么呢？
