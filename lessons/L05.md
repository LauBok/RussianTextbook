## 课文

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} Где мои́ кни́ги?

[А́нна]{.sp} Вот они́. А э́то что? Тетра́ди?

[Ван Лэй]{.sp} Да, тетра́ди. А вот ру́чки и карандаши́.

[А́нна]{.sp} А э́то что?

[Ван Лэй]{.sp} А э́то мои́ фо́то. Вот мои́ роди́тели.

[А́нна]{.sp} А э́то кто? Ты?

[Ван Лэй]{.sp} Да, я. А вот пода́рки. Э́то чай, а э́то па́лочки.

[А́нна]{.sp} Пода́рки? Спаси́бо!
:::

## 课文注释

::: notes
1. **[Где мои́ кни́ги?]{.ru}** 王磊在房间里打开箱子收拾东西。[кни́ги]{.ru} 是复数，所以“我的”用复数 [мои́]{.ru}，回答时用 [они́]{.ru}。
2. **[А э́то кто? Ты?]{.ru}** 安娜和王磊是同学，年龄相近，用 [ты]{.ru}。
3. **[мои́ фо́то]{.ru}** [фо́то]{.ru} 不变格，复数和单数同形。这里有好几张照片，从 [мои́]{.ru} 可以看出是复数。
4. **[роди́тели]{.ru}** 意思是“父母”，只有复数形式，相当于 [ма́ма и па́па]{.ru}。
5. **[па́лочки]{.ru}** 筷子。俄语用 [па́лочки]{.ru}（小棍儿）来称呼筷子，一般用复数。
6. **[Пода́рки? Спаси́бо!]{.ru}** 到别人家借住，带一点家乡的小礼物是礼貌，中国的茶叶和筷子在俄罗斯很受欢迎。
:::

## 俄罗斯知识

### [фо́то]{.ru}、[метро́]{.ru}：不变格的外来词

课文里王磊说 [мои́ фо́то]{.ru}，复数和单数一样都是 [фо́то]{.ru}，因为这是一个外来词。俄语从其他语言借来了大量词汇，多数借入后和俄语固有词一样变化：[журна́л]{.ru} 来自法语，复数是 [журна́лы]{.ru}；[чемода́н]{.ru} 源自波斯语，复数是 [чемода́ны]{.ru}。

但是以元音 [о]{.ru}、[е]{.ru}、[и]{.ru}、[у]{.ru} 结尾的外来名词一般不变格，单数复数同形，例如 [фо́то]{.ru}（照片）、[метро́]{.ru}（地铁）、[кино́]{.ru}（电影）、[кафе́]{.ru}（咖啡馆）、[ра́дио]{.ru}（收音机）、[такси́]{.ru}（出租车）。这些词多半是中性，有一个常用词例外：[ко́фе]{.ru}（咖啡）是阳性。

王磊送的 [чай]{.ru} 也是外来词。一般认为它来自北方汉语的“茶”，十七世纪经蒙古、西伯利亚的陆路随茶叶贸易传入俄国。今天茶仍然是俄罗斯人每天必喝的饮料。

## 语法

### 一、名词复数第一格

名词复数第一格按单数的词尾构成：

| 单数词尾 | 复数词尾 | 例 |
|---|---|---|
| 硬辅音（阳性） | 加 [-ы]{.ru} | [чемода́н → чемода́ны]{.ru}，[журна́л → журна́лы]{.ru}，[студе́нт → студе́нты]{.ru} |
| [-ь]{.ru}（阳性、阴性） | [-ь]{.ru} 改 [-и]{.ru} | [слова́рь → словари́]{.ru}，[тетра́дь → тетра́ди]{.ru}，[крова́ть → крова́ти]{.ru} |
| [-а]{.ru}（阴性） | [-а]{.ru} 改 [-ы]{.ru} | [ко́мната → ко́мнаты]{.ru}，[ла́мпа → ла́мпы]{.ru}，[газе́та → газе́ты]{.ru} |
| [-я]{.ru}（阴性） | [-я]{.ru} 改 [-и]{.ru} | [фами́лия → фами́лии]{.ru} |
| [-о]{.ru}（中性） | [-о]{.ru} 改 [-а]{.ru} | [окно́ → о́кна]{.ru}，[кре́сло → кре́сла]{.ru}，[письмо́ → пи́сьма]{.ru} |

简单地说，阳性和阴性名词的复数词尾是 [-ы]{.ru} 或 [-и]{.ru}，中性名词是 [-а]{.ru}。硬辅音和 [-а]{.ru} 后用硬元音 [-ы]{.ru}，[-ь]{.ru} 和 [-я]{.ru} 后用软元音 [-и]{.ru}。

### 二、拼写规则：[г, к, х, ж, ш, щ, ч]{.ru} 后面写 [и]{.ru}

俄语有一条拼写规则：在 [г, к, х]{.ru} 和 [ж, ш, щ, ч]{.ru} 后面，不写 [ы]{.ru}，一律写 [и]{.ru}。所以下面这些词按上表本该加 [-ы]{.ru}，实际都写 [-и]{.ru}：

| 词干末尾 | 例 |
|---|---|
| [г]{.ru} | [кни́га → кни́ги]{.ru} |
| [к]{.ru} | [ру́чка → ру́чки]{.ru}，[су́мка → су́мки]{.ru}，[шко́льник → шко́льники]{.ru}，[па́лочка → па́лочки]{.ru} |
| [ш]{.ru} | [каранда́ш → карандаши́]{.ru} |
| [ч]{.ru} | [ключ → ключи́]{.ru}，[врач → врачи́]{.ru} |

这条规则管的是写法，不仅用在复数上，以后学别的词形时也一样要遵守，要牢牢记住这七个字母。

### 三、要特别记的复数

1. **重音移动。** 不少名词变成复数后重音移位：[стол → столы́]{.ru}，[шкаф → шкафы́]{.ru}，[слова́рь → словари́]{.ru}，[каранда́ш → карандаши́]{.ru}，[окно́ → о́кна]{.ru}，[письмо́ → пи́сьма]{.ru}。生词表里给出了这些复数，要连同重音一起记。
2. **元音脱落。** [пода́рок → пода́рки]{.ru}：词干里的 [о]{.ru} 在复数里消失。生词表里给出第二格 [пода́рка]{.ru}，就是为了提示这种变化，复数也按这个词干构成。
3. **不规则复数。** [дом → дома́]{.ru}，[сын → сыновья́]{.ru}，[и́мя → имена́]{.ru}。这类词只能逐个记住。
4. **不变格名词。** [фо́то]{.ru} 的复数还是 [фо́то]{.ru}。
5. **只有复数的名词。** [роди́тели]{.ru} 没有单数形式。

### 四、复数与 [они́]{.ru}、[мои́]{.ru}

复数名词用 [они́]{.ru} 代替，前面的“我的”用 [мои́]{.ru}，不分阳性、阴性、中性：

::: ex
[— Где мои́ кни́ги? — Вот они́.]{.ru}[——我的书在哪儿？——在这儿。]{.gloss}

[— Где мои́ ключи́? — Они́ там.]{.ru}[——我的钥匙在哪儿？——在那儿。]{.gloss}

[Э́то мои́ пи́сьма.]{.ru}[这是我的信。]{.gloss}
:::

[э́то]{.ru} 不变，后面接复数名词也还是 [э́то]{.ru}：[Э́то тетра́ди.]{.ru}（这些是本子。）

## 语音·语调

### 一、复数的重音

单数和复数重音不同的词，要成对朗读，把重音的位置读准：

::: ex
[стол — столы́]{.ru}

[шкаф — шкафы́]{.ru}

[слова́рь — словари́]{.ru}

[окно́ — о́кна]{.ru}

[письмо́ — пи́сьма]{.ru}

[дом — дома́]{.ru}
:::

重音位置一变，元音的读法也跟着变。[окно́]{.ru} 的 [о]{.ru} 不重读，读作 [[акно́]]{.tr}；[о́кна]{.ru} 的 [о]{.ru} 重读，读清楚，末尾的 [а]{.ru} 反而弱化：[[о́кнъ]]{.tr}。

### 二、[ш]{.ru} 后面的 [и]{.ru} 读作 [ы]{.ru}

[ш]{.ru} 永远是硬辅音（语音第 4 课）。按拼写规则它后面写 [и]{.ru}，但读的时候仍然读成 [ы]{.ru}：

::: ex
[карандаши́]{.ru} [[карандашы́]]{.tr}

[Вот ру́чки и карандаши́.]{.ru}
:::

[ч]{.ru} 永远是软辅音，[ключи́]{.ru}、[врачи́]{.ru} 里的 [и]{.ru} 照常读 [и]{.ru}。
