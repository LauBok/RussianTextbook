## 课文

::: {.prose lang="ru"}
В пя́тницу по́сле уро́ка Ван Лэй и А́нна иду́т в кафе́ напро́тив университе́та. На у́лице хо́лодно и темно́, а в кафе́ тепло́ и ую́тно. На по́лке стои́т большо́й ста́рый самова́р.
:::

::: {.dialogue lang="ru"}
[Официа́нтка]{.sp} До́брый ве́чер! Что вы бу́дете пить?

[А́нна]{.sp} Мне ко́фе с молоко́м, пожа́луйста.

[Ван Лэй]{.sp} А мне чай с лимо́ном.

[Официа́нтка]{.sp} С са́харом?

[Ван Лэй]{.sp} Нет, без са́хара.

[Официа́нтка]{.sp} А что вы бу́дете есть? Сего́дня у нас о́чень вку́сные пирожки́: с мя́сом, с капу́стой и с я́блоком.

[А́нна]{.sp} Мне пирожо́к с я́блоком.

[Ван Лэй]{.sp} А мне с капу́стой. Я ещё не про́бовал пирожо́к с капу́стой.
:::

::: {.prose lang="ru"}
Официа́нтка ста́вит на стол ча́шки и таре́лки. Ван Лэй смо́трит на самова́р.
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} А́нна, э́тот самова́р настоя́щий?

[А́нна]{.sp} Да, он о́чень ста́рый. Ра́ньше в ка́ждом до́ме был самова́р, и ру́сские пи́ли из него́ чай ка́ждый день.

[Ван Лэй]{.sp} У нас в Кита́е то́же лю́бят чай, но мы пьём его́ без са́хара и без лимо́на.

[А́нна]{.sp} А ру́сские пьют чай с лимо́ном, с мёдом и́ли с варе́ньем. Моя́ ба́бушка всегда́ пьёт чай с варе́ньем.

[Ван Лэй]{.sp} Чай с варе́ньем? Как интере́сно! В суббо́ту я обяза́тельно попро́бую.
:::

## 课文注释

::: notes
1. **[Мне ко́фе с молоко́м, пожа́луйста.]{.ru}** 点餐时常用的省略句，省去了动词，完整的说法是 [Мне, пожа́луйста, ко́фе с молоко́м]{.ru} 或 [Я бу́ду ко́фе с молоко́м]{.ru}。[мне]{.ru} 是第三格，表示“给我”。
2. **[ко́фе]{.ru}** 不变格，是阳性名词：[чёрный ко́фе]{.ru}（黑咖啡）。口语里有人把它当中性，但规范用法是阳性。
3. **[кафе́]{.ru}** 不变格的中性名词，[е]{.ru} 前的 [ф]{.ru} 读硬音，所以注音为 [[кафэ́]]{.tr}。
4. **[А мне с капу́стой.]{.ru}** 承接上句，省略了 [пирожо́к]{.ru}，意思是“我要白菜馅的”。
5. **[пирожо́к]{.ru}** 是 [пиро́г]{.ru}（大馅饼）的指小形式，复数是 [пирожки́]{.ru}，变格时 [о]{.ru} 脱落：[пирожка́]{.ru}。
6. **[в ка́ждом до́ме]{.ru}** [ка́ждый]{.ru} 和形容词一样变格，这里是第六格。
7. **[Как интере́сно!]{.ru}** [как]{.ru} 加副词表示感叹：“真有意思！”
:::

## 俄罗斯知识

### 茶炊与喝茶

课文里的咖啡馆把一只旧茶炊摆在架子上做装饰。茶炊 [самова́р]{.ru} 字面意思是“自己煮”：金属壶身中间有一根竖管，管里烧木炭或松果，热量把四周的水烧开，底部有龙头放水。18 世纪起，图拉 [Ту́ла]{.ru} 成了茶炊最有名的产地，俄语有句俗话 [В Ту́лу со свои́м самова́ром не е́здят]{.ru}，意思是“不要带着茶炊去图拉”，相当于汉语的“班门弄斧”。

俄罗斯人泡茶分两步：先在小茶壶里泡出很浓的茶汁 [зава́рка]{.ru}，放在茶炊顶上保温；喝的时候倒一点茶汁到杯里，再从茶炊里接开水冲淡，浓淡各随所好。茶里常放糖、柠檬，或者就着果酱、蜂蜜喝。

今天城市家庭大多用电水壶，茶炊多半成了纪念品，或者在别墅、节日时才用。但“喝茶” [пить чай]{.ru} 仍是待客的习惯说法：请人 [на чай]{.ru}，往往意味着一桌点心和一场长谈。

## 语法

### 一、名词单数第五格

第五格（工具格）回答 [кем?]{.ru}（谁）、[чем?]{.ru}（什么）的问题。本单元学习它的各种用法，这一课先学最常用的一种：前置词 [с]{.ru} 加第五格。

| 性 | 第一格词尾 | 第五格词尾 | 例词 |
|---|---|---|---|
| 阳性 | 硬辅音 | [-ом]{.ru} | [лимо́н → лимо́ном]{.ru}，[брат → бра́том]{.ru} |
| 阳性 | [-й]{.ru}、[-ь]{.ru} | [-ем]{.ru}（重读 [-ём]{.ru}） | [музе́й → музе́ем]{.ru}，[слова́рь → словарём]{.ru} |
| 阴性 | [-а]{.ru} | [-ой]{.ru} | [капу́ста → капу́стой]{.ru}，[ма́ма → ма́мой]{.ru} |
| 阴性 | [-я]{.ru} | [-ей]{.ru}（重读 [-ёй]{.ru}） | [Та́ня → Та́ней]{.ru}，[семья́ → семьёй]{.ru} |
| 阴性 | [-ь]{.ru} | [-ью]{.ru} | [тетра́дь → тетра́дью]{.ru} |
| 中性 | [-о]{.ru} | [-ом]{.ru} | [молоко́ → молоко́м]{.ru}，[мя́со → мя́сом]{.ru} |
| 中性 | [-е]{.ru} | [-ем]{.ru} | [варе́нье → варе́ньем]{.ru} |

几点要注意：

1. **拼写规则**：[ж、ш、ч、щ、ц]{.ru} 后面，不重读时写 [е]{.ru}，重读时写 [о]{.ru}：[ба́бушка → ба́бушкой]{.ru}（[к]{.ru} 后照常写 [о]{.ru}），[да́ча → да́чей]{.ru}，[оте́ц → отцо́м]{.ru}。
2. **词干变化**：第二格脱落 [о]{.ru}、[е]{.ru} 的词，第五格同样脱落：[пирожо́к → пирожко́м]{.ru}，[оте́ц → отцо́м]{.ru}。
3. **以 [-а]{.ru} 结尾的阳性名词**按阴性变：[па́па → па́пой]{.ru}，[Ми́ша → Ми́шей]{.ru}。
4. **不变格名词**第五格不变：[пирожо́к с ко́фе]{.ru}（馅饼配咖啡）。
5. [мать]{.ru}、[дочь]{.ru} 的第五格是 [ма́терью]{.ru}、[до́черью]{.ru}，要单独记。

### 二、前置词 [с]{.ru} + 第五格

**1. 表示“和……一起”**

::: ex
[Ван Лэй говори́т с А́нной.]{.ru}[王磊和安娜说话。]{.gloss}

[Ми́ша игра́ет в футбо́л с па́пой.]{.ru}[米沙和爸爸踢足球。]{.gloss}
:::

**2. 表示食物、饮料里加了什么、带着什么馅**

::: ex
[ко́фе с молоко́м]{.ru}[加奶的咖啡]{.gloss}

[чай с лимо́ном]{.ru}[柠檬茶]{.gloss}

[пирожо́к с капу́стой]{.ru}[白菜馅饼]{.gloss}
:::

问的时候说 [с чем?]{.ru}（带什么的？）、[с кем?]{.ru}（和谁？）：

::: ex
[— С чем пирожо́к? — С мя́сом.]{.ru}[——什么馅的？——肉馅的。]{.gloss}

[— С кем ты говори́шь? — С ма́мой.]{.ru}[——你在和谁说话？——和妈妈。]{.gloss}
:::

**3. [с]{.ru} 与 [без]{.ru} 相对**

“加”用 [с]{.ru} + 第五格，“不加”用 [без]{.ru} + 第二格（第 37 课）。两个前置词后面的格不一样，最容易混：

| 加 | 不加 |
|---|---|
| [чай с са́харом]{.ru} | [чай без са́хара]{.ru} |
| [ко́фе с молоко́м]{.ru} | [ко́фе без молока́]{.ru} |
| [чай с лимо́ном]{.ru} | [чай без лимо́на]{.ru} |

**4. [со]{.ru}**

[с]{.ru} 在某些辅音组合前写成 [со]{.ru}，如 [со мной]{.ru}（和我），下一课学。

## 语音·语调

### 前置词 [с]{.ru} 与后面的词连读

前置词没有自己的重音，和后面的名词读成一个词，中间不停顿：[с молоко́м]{.ru} 读作 [[смалако́м]]{.tr}，[с лимо́ном]{.ru} 读作 [[сл'имо́нам]]{.tr}。

[с]{.ru} 遇到后面的浊辅音 [б、г、д、з、ж]{.ru} 时被同化，读成浊音 [[з]]{.tr}（在 [ж]{.ru} 前读 [[ж]]{.tr}）：

| 写法 | 读音 |
|---|---|
| [с бра́том]{.ru} | [[збра́там]]{.tr} |
| [с ба́бушкой]{.ru} | [[зба́бушкай]]{.tr} |
| [с газе́той]{.ru} | [[згазе́тай]]{.tr} |
| [с до́мом]{.ru} | [[здо́мам]]{.tr} |

在元音和 [м、н、л、р、в]{.ru} 前不发生同化，仍读 [[с]]{.tr}：[с А́нной]{.ru}、[с молоко́м]{.ru}、[с варе́ньем]{.ru}。在 [с]{.ru} 前则合成一个长的 [[с]]{.tr}：[с са́харом]{.ru} 读作 [[сса́харам]]{.tr}。

### 点餐时的语调

点餐的省略句用 [ИК-1]{.ru}，调心在最后一个词上；服务员追问时用 [ИК-3]{.ru}。

::: ex
[Мне ко́фе с [молоко́м]{.ic data-n="1"}.]{.ru}

[С [са́харом]{.ic data-n="3"}?]{.ru}

[Нет, без [са́хара]{.ic data-n="1"}.]{.ru}

[Что вы бу́дете [пить]{.ic data-n="2"}?]{.ru}
:::

## 参考译文

::: prose-zh
星期五下课以后，王磊和安娜去大学对面的一家咖啡馆。外面又冷又黑，咖啡馆里却暖和、舒适。架子上摆着一只很大的旧茶炊。
:::

::: translation
[服务员]{.sp} 晚上好！你们喝点什么？

[安娜]{.sp} 我要一杯加奶的咖啡，谢谢。

[王磊]{.sp} 我要柠檬茶。

[服务员]{.sp} 加糖吗？

[王磊]{.sp} 不，不加糖。

[服务员]{.sp} 你们吃点什么？我们今天的小馅饼很好吃：有肉馅的、白菜馅的和苹果馅的。

[安娜]{.sp} 我要一个苹果馅饼。

[王磊]{.sp} 我要白菜馅的。我还没尝过白菜馅饼呢。
:::

::: prose-zh
服务员把杯子和盘子放到桌上。王磊看着那只茶炊。
:::

::: translation
[王磊]{.sp} 安娜，这只茶炊是真的吗？

[安娜]{.sp} 是的，它很旧了。从前家家都有茶炊，俄罗斯人每天都用它烧水喝茶。

[王磊]{.sp} 我们中国人也爱喝茶，可是我们喝茶不加糖，也不加柠檬。

[安娜]{.sp} 俄罗斯人喝茶要加柠檬、蜂蜜或者就着果酱。我奶奶总是就着果酱喝茶。

[王磊]{.sp} 就着果酱喝茶？真有意思！星期六我一定尝尝。
:::
