## 课文

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} Ми́ша, приве́т! А где все?

[Ми́ша]{.sp} Приве́т! Ма́ма на рабо́те. Она́ в поликли́нике.

[Ван Лэй]{.sp} А па́па?

[Ми́ша]{.sp} Па́па то́же на рабо́те, на заво́де.

[Ван Лэй]{.sp} А где А́нна? Она́ в университе́те?

[Ми́ша]{.sp} Да, в университе́те. Она́ сейча́с в библиоте́ке.

[Ван Лэй]{.sp} А ты? Ты сего́дня не в шко́ле?

[Ми́ша]{.sp} Нет, я уже́ до́ма. Вот, де́лаю уро́ки.

[Ван Лэй]{.sp} А где Му́рка?

[Ми́ша]{.sp} Не зна́ю. Мо́жет быть, на ку́хне?

[Ван Лэй]{.sp} На ку́хне? Нет… А, вот она́! Она́ в ко́мнате, на столе́.

[Ми́ша]{.sp} Му́рка, ты опя́ть на столе́! Плоха́я ко́шка!
:::

## 课文注释

::: notes
1. **[А где все?]{.ru}** [все]{.ru} 指“大家、所有的人”，后面的谓语用复数。王磊一进门没看见人，所以这样问。
2. **[на рабо́те, на заво́де]{.ru}** “在上班”“在工厂”都用 [на]{.ru}，不用 [в]{.ru}。哪些名词要用 [на]{.ru}，第 12 课详讲。
3. **[до́ма]{.ru}** 副词，意思是“在家”，前面不加前置词。不能说 [в до́ме]{.ru} 表示“在家”，[в до́ме]{.ru} 是“在楼房里”。
4. **[Вот, де́лаю уро́ки.]{.ru}** [де́лать уро́ки]{.ru} 是固定说法，指学生在家做老师布置的功课。口语里主语 [я]{.ru} 常常省略，动词词尾已经表明是“我”。
5. **[Мо́жет быть, на ку́хне?]{.ru}** [мо́жет быть]{.ru} 是插入语，后面用逗号隔开。
6. **[на столе́]{.ru}** [стол]{.ru} 变成第六格后重音移到词尾，和复数 [столы́]{.ru} 一样。
:::

## 俄罗斯知识

### 俄罗斯的大学与学制

米沙说安娜“在大学”。俄罗斯的大学一般叫 [университе́т]{.ru}，专科性较强的学院常叫 [институ́т]{.ru} 或 [акаде́мия]{.ru}。大学下设系（[факульте́т]{.ru}），学生入学时就选定系和专业。

俄罗斯的学年从 9 月 1 日开始，这一天叫“知识日”（[День зна́ний]{.ru}），中小学和大学同时开学。一学年分两个学期，期末考试周叫 [се́ссия]{.ru}，一般在 1 月和 6 月；冬季考试后有两周左右的寒假，夏季考试后放暑假。

2003 年俄罗斯加入博洛尼亚进程，此后普遍实行两级制：学士（[бакалавриа́т]{.ru}）四年，硕士（[магистрату́ра]{.ru}）两年。医学等专业保留五到六年的一贯制（[специалите́т]{.ru}）。年级用 [курс]{.ru} 表示，“一年级学生”是“第一个 [курс]{.ru} 的学生”。考试用五分制，5 分最好，2 分不及格。

## 语法

### 一、名词第六格

名词有六个格，词形随在句中的作用而变化。前面学的都是第一格（主格），即词典里的形式。第六格只和前置词连用，所以也叫前置格。本课先学它最常用的意义：和 [в]{.ru}、[на]{.ru} 连用，回答 [где]{.ru}（在哪里）。

::: ex
[— Где ма́ма? — Она́ на рабо́те.]{.ru}[——妈妈在哪儿？——她在上班。]{.gloss}

[— Где А́нна? — Она́ в университе́те.]{.ru}[——安娜在哪儿？——她在大学。]{.gloss}
:::

第六格单数的词尾大多数是 [-е]{.ru}：

| 性 | 第一格词尾 | 第一格 | 第六格 |
|---|---|---|---|
| 阳性 | 硬辅音 | [заво́д]{.ru} | [на заво́де]{.ru} |
| | | [университе́т]{.ru} | [в университе́те]{.ru} |
| | [-й]{.ru} | [музе́й]{.ru} | [в музе́е]{.ru} |
| | [-ь]{.ru} | [слова́рь]{.ru} | [в словаре́]{.ru} |
| 中性 | [-о]{.ru} | [окно́]{.ru} | [на окне́]{.ru} |
| | [-е]{.ru} | [мо́ре]{.ru} | [на мо́ре]{.ru} |
| 阴性 | [-а]{.ru} | [шко́ла]{.ru} | [в шко́ле]{.ru} |
| | [-я]{.ru} | [ку́хня]{.ru} | [на ку́хне]{.ru} |
| | [-ь]{.ru} | [тетра́дь]{.ru} | [в тетра́ди]{.ru} |

规则可以归纳成三条：

1. 以辅音结尾的阳性名词直接加 [-е]{.ru}：[заво́д → заво́де]{.ru}。
2. 词尾 [-й]{.ru}、[-ь]{.ru}、[-о]{.ru}、[-а]{.ru}、[-я]{.ru} 换成 [-е]{.ru}：[музе́й → музе́е]{.ru}，[окно́ → окне́]{.ru}，[ку́хня → ку́хне]{.ru}；以 [-е]{.ru} 结尾的中性名词不变：[мо́ре → на мо́ре]{.ru}。
3. 以 [-ь]{.ru} 结尾的**阴性**名词，词尾换成 [-и]{.ru}：[тетра́дь → в тетра́ди]{.ru}。同样以 [-ь]{.ru} 结尾的阳性名词却用 [-е]{.ru}：[слова́рь → в словаре́]{.ru}。所以以 [-ь]{.ru} 结尾的名词必须先记住性。

**不变格名词**没有格的变化：[фо́то → на фо́то]{.ru}，[метро́ → в метро́]{.ru}。

**重音**：多数名词的重音位置不变，[шко́ла → в шко́ле]{.ru}。但复数重音移到词尾的词，第六格重音往往也在词尾：[стол → на столе́]{.ru}，[слова́рь → в словаре́]{.ru}。

**容易错的地方**：

- 不要把阴性 [-а]{.ru} 词改成 [-ы]{.ru}、[-и]{.ru}，那是复数第一格：[в шко́ле]{.ru}，不是 [в шко́лы]{.ru}。
- 以 [-ия]{.ru}、[-ие]{.ru} 结尾的名词第六格词尾不同，第 12 课讲。

### 二、[в]{.ru} 与 [на]{.ru} 表示处所

[в]{.ru} 表示“在……里面”，[на]{.ru} 表示“在……表面上”：

::: ex
[Му́рка в ко́мнате.]{.ru}[穆尔卡在房间里。]{.gloss}

[Му́рка на столе́.]{.ru}[穆尔卡在桌子上。]{.gloss}

[Кни́га в столе́, а слова́рь на столе́.]{.ru}[书在桌子里，词典在桌子上。]{.gloss}
:::

可是很多名词和 [на]{.ru} 连用并不表示“在表面上”，而是习惯用法，要随词记住。本课出现的有：

| 用 [в]{.ru} | 用 [на]{.ru} |
|---|---|
| [в университе́те]{.ru} 在大学 | [на рабо́те]{.ru} 在上班 |
| [в шко́ле]{.ru} 在学校 | [на заво́де]{.ru} 在工厂 |
| [в библиоте́ке]{.ru} 在图书馆 | [на ку́хне]{.ru} 在厨房 |
| [в поликли́нике]{.ru} 在诊所 | [на мо́ре]{.ru} 在海边 |
| [в ко́мнате]{.ru} 在房间里 | |

[на ку́хне]{.ru} 字面上像“在厨房上面”，实际就是“在厨房里”；[на мо́ре]{.ru} 一般指“在海边度假”。

前置词 [в]{.ru}、[на]{.ru} 后面的名词一定用第六格。回答 [где]{.ru} 的问题时，可以只说前置词词组：

::: ex
[— Где па́па? — На заво́де.]{.ru}[——爸爸在哪儿？——在工厂。]{.gloss}
:::

## 语音·语调

### 前置词与名词连读

前置词不重读，和后面的词连成一个语音词，中间不停顿，读起来像一个长词：

::: ex
[в [шко́ле]{.ic data-n="1"}]{.ru}　[на [рабо́те]{.ic data-n="1"}]{.ru}　[на [столе́]{.ic data-n="1"}]{.ru}
:::

[в]{.ru} 没有元音，必须和后面的词连读。它在清辅音 [п、т、к、ш、с、ф]{.ru} 等前面读作 [[ф]]{.tr}，在元音和浊辅音前面读作 [[в]]{.tr}：

| 写法 | 读音 |
|---|---|
| [в шко́ле]{.ru} | [[фшко́лʼи]]{.tr} |
| [в ко́мнате]{.ru} | [[фко́мнатʼи]]{.tr} |
| [в поликли́нике]{.ru} | [[фпаликлʼи́нʼикʼи]]{.tr} |
| [в университе́те]{.ru} | [[вунʼивʼирсʼитʼе́тʼи]]{.tr} |
| [в библиоте́ке]{.ru} | [[вбʼиблʼиатʼе́кʼи]]{.tr} |

[на]{.ru} 不重读，元音读得轻而短。整个词组的调心落在名词的重读音节上：

::: ex
[Ма́ма на [рабо́те]{.ic data-n="1"}.]{.ru}

[Па́па на [заво́де]{.ic data-n="1"}.]{.ru}

[Она́ в [ко́мнате]{.ic data-n="1"}, на [столе́]{.ic data-n="1"}.]{.ru}
:::

## 参考译文

::: translation
[王磊]{.sp} 米沙，你好！大家都在哪儿？

[米沙]{.sp} 你好！妈妈在上班，她在诊所。

[王磊]{.sp} 那爸爸呢？

[米沙]{.sp} 爸爸也在上班，在工厂。

[王磊]{.sp} 那安娜在哪儿？她在大学吗？

[米沙]{.sp} 对，在大学。她现在在图书馆。

[王磊]{.sp} 你呢？你今天没在学校？

[米沙]{.sp} 没有，我已经在家了。你看，我在做功课。

[王磊]{.sp} 穆尔卡在哪儿？

[米沙]{.sp} 不知道。也许在厨房？

[王磊]{.sp} 在厨房？没有……啊，在这儿呢！它在房间里，在桌子上。

[米沙]{.sp} 穆尔卡，你又跑到桌子上了！坏猫！
:::
