## 语法总表

### 一、[э́то]{.ru} 句型；[кто]{.ru} 与 [что]{.ru}（第 1 课）

[э́то]{.ru} 用来指认人或事物，本身不变；俄语没有冠词，现在时不用系动词。否定时 [не]{.ru} 放在被否定的词前面。

| 问 | 答 |
|---|---|
| [Кто э́то?]{.ru}（问人和动物） | [Э́то А́нна. Э́то ко́шка Му́рка.]{.ru} |
| [Что э́то?]{.ru}（问事物） | [Э́то дом. Э́то фо́то.]{.ru} |
| [Э́то дом?]{.ru} | [Нет, э́то не дом.]{.ru} |

动物也用 [кто]{.ru} 问，这一点和汉语不同。[а]{.ru} 把话题转到另一个人或物上：[А кто э́то?]{.ru}（那这是谁？）

### 二、人称代词；[где]{.ru}、[вот]{.ru}、[там]{.ru}、[тут]{.ru}；[да]{.ru} 与 [нет]{.ru}（第 2、4 课）

| 人称 | 单数 | 复数 |
|---|---|---|
| 第一人称 | [я]{.ru} 我 | [мы]{.ru} 我们 |
| 第二人称 | [ты]{.ru} 你 | [вы]{.ru} 你们；您 |
| 第三人称 | [он, она́, оно́]{.ru} 他（它）、她（它）、它 | [они́]{.ru} 他们；它们 |

第三人称代词替代名词时，按名词的性和数选：[чемода́н → он]{.ru}，[су́мка → она́]{.ru}，[фо́то → оно́]{.ru}，[ма́ма и па́па → они́]{.ru}。

| 问 | 答 | 说明 |
|---|---|---|
| [Где су́мка?]{.ru} | [Вот она́.]{.ru} | 就在眼前，[вот]{.ru} 总在句首 |
| [Где Ми́ша?]{.ru} | [Он там.]{.ru} / [Он тут.]{.ru} | 在那里 / 在这里 |
| [Па́па до́ма?]{.ru} | [Да, до́ма.]{.ru} / [Нет, он не до́ма.]{.ru} | [нет]{.ru} 回答问题，[не]{.ru} 否定句中的词 |

### 三、[ты]{.ru} 与 [вы]{.ru}；问名字（第 4 课）

| 称呼 | 代词 | 问名字 |
|---|---|---|
| 名字 + 父称：[Ива́н Серге́евич]{.ru} | [вы]{.ru} | [Как вас зову́т?]{.ru} |
| 小名：[Ми́ша]{.ru}，[А́ня]{.ru} | [ты]{.ru} | [Как тебя́ зову́т?]{.ru} |
| 两个以上的人 | [вы]{.ru} | [Как вас зову́т?]{.ru} |

回答都是 [Меня́ зову́т…]{.ru}，反问说 [А вас?]{.ru} 或 [А тебя́?]{.ru}。全名由名字 [и́мя]{.ru}、父称 [о́тчество]{.ru}、姓 [фами́лия]{.ru} 组成：[Ива́н Серге́евич Петро́в]{.ru}，[Мари́я Никола́евна Петро́ва]{.ru}。父称由父亲的名字加 [-ович / -овна]{.ru} 或 [-евич / -евна]{.ru} 构成。

### 四、名词的性（第 3 课）

| 性 | 词尾 | 例词 | 代词 |
|---|---|---|---|
| 阳性 | 硬辅音 | [стол, шкаф, дом, чемода́н]{.ru} | [он]{.ru} |
|  | [-й]{.ru} | [чай]{.ru} | [он]{.ru} |
|  | [-ь]{.ru} | [слова́рь]{.ru} | [он]{.ru} |
| 阴性 | [-а]{.ru} | [ко́мната, ла́мпа, кни́га]{.ru} | [она́]{.ru} |
|  | [-я]{.ru} | [фами́лия]{.ru} | [она́]{.ru} |
|  | [-ь]{.ru} | [крова́ть, тетра́дь, пло́щадь]{.ru} | [она́]{.ru} |
| 中性 | [-о]{.ru} | [окно́, кре́сло, письмо́, не́бо]{.ru} | [оно́]{.ru} |

- 以 [-ь]{.ru} 结尾的名词可能是阳性，也可能是阴性，要连同性一起记：[слова́рь]{.ru} 阳性，[крова́ть]{.ru} 阴性。
- 指男人的 [-а]{.ru} 词是阳性：[па́па]{.ru}、[Ми́ша]{.ru}。
- [фо́то]{.ru} 是不变格的中性名词；[и́мя]{.ru} 也是中性。

### 五、物主代词与 [чей]{.ru}（第 3、8 课）

| | 阳性 | 阴性 | 中性 | 复数 |
|---|---|---|---|---|
| 我的 | [мой]{.ru} | [моя́]{.ru} | [моё]{.ru} | [мои́]{.ru} |
| 你的 | [твой]{.ru} | [твоя́]{.ru} | [твоё]{.ru} | [твои́]{.ru} |
| 我们的 | [наш]{.ru} | [на́ша]{.ru} | [на́ше]{.ru} | [на́ши]{.ru} |
| 您的、你们的 | [ваш]{.ru} | [ва́ша]{.ru} | [ва́ше]{.ru} | [ва́ши]{.ru} |
| 谁的 | [чей]{.ru} | [чья]{.ru} | [чьё]{.ru} | [чьи]{.ru} |
| 他的 / 她的 / 他们的 | [его́ / её / их]{.ru}（不变） | | | |

[мой, твой, наш, ваш, чей]{.ru} 和后面的名词在性、数上一致；[его́, её, их]{.ru} 不变，选哪一个只看东西归谁。

::: ex
[— Чья э́то кни́га? — Э́то её кни́га.]{.ru}[——这是谁的书？——这是她的书。]{.gloss}

[— Чьи э́то очки́? — Его́.]{.ru}[——这是谁的眼镜？——他的。]{.gloss}

[Па́па, вот твои́ очки́!]{.ru}[爸爸，这是你的眼镜！]{.gloss}

[Э́то на́ша матрёшка. А тепе́рь она́ ва́ша.]{.ru}[这是我们的套娃。现在它是您的了。]{.gloss}
:::

### 六、名词复数第一格（第 5 课）

| 单数词尾 | 复数词尾 | 例词 |
|---|---|---|
| 硬辅音（阳性） | 加 [-ы]{.ru} | [журна́л → журна́лы]{.ru}，[чемода́н → чемода́ны]{.ru} |
| [-а]{.ru}（阴性） | 改 [-ы]{.ru} | [ко́мната → ко́мнаты]{.ru}，[газе́та → газе́ты]{.ru} |
| [-ь]{.ru}（阳性、阴性） | 改 [-и]{.ru} | [слова́рь → словари́]{.ru}，[тетра́дь → тетра́ди]{.ru} |
| [-я]{.ru}（阴性） | 改 [-и]{.ru} | [фами́лия → фами́лии]{.ru} |
| [-о]{.ru}（中性） | 改 [-а]{.ru} | [кре́сло → кре́сла]{.ru}，[окно́ → о́кна]{.ru} |

**拼写规则**：[г, к, х, ж, ш, щ, ч]{.ru} 后面不写 [ы]{.ru}，写 [и]{.ru}：[кни́га → кни́ги]{.ru}，[ру́чка → ру́чки]{.ru}，[каранда́ш → карандаши́]{.ru}，[ключ → ключи́]{.ru}。

**要单独记的复数**：

- 重音移动：[стол → столы́]{.ru}，[шкаф → шкафы́]{.ru}，[окно́ → о́кна]{.ru}，[письмо́ → пи́сьма]{.ru}，[река́ → ре́ки]{.ru}。
- 元音脱落：[пода́рок → пода́рки]{.ru}。
- 不规则：[дом → дома́]{.ru}，[го́род → города́]{.ru}，[сын → сыновья́]{.ru}，[и́мя → имена́]{.ru}。
- 不变：[фо́то → фо́то]{.ru}；只有复数：[роди́тели]{.ru}，[очки́]{.ru}。

复数名词用 [они́]{.ru} 代替，物主代词用 [мои́, твои́, на́ши, ва́ши]{.ru}，[э́то]{.ru} 不变：[Э́то мои́ кни́ги. — Вот они́.]{.ru}

### 七、动词现在时的两种变位（第 6、7 课）

| 人称 | 第一变位 [чита́ть]{.ru} | 第二变位 [говори́ть]{.ru} | 第二变位 [смотре́ть]{.ru} |
|---|---|---|---|
| [я]{.ru} | [чита́ю]{.ru} | [говорю́]{.ru} | [смотрю́]{.ru} |
| [ты]{.ru} | [чита́ешь]{.ru} | [говори́шь]{.ru} | [смо́тришь]{.ru} |
| [он, она́]{.ru} | [чита́ет]{.ru} | [говори́т]{.ru} | [смо́трит]{.ru} |
| [мы]{.ru} | [чита́ем]{.ru} | [говори́м]{.ru} | [смо́трим]{.ru} |
| [вы]{.ru} | [чита́ете]{.ru} | [говори́те]{.ru} | [смо́трите]{.ru} |
| [они́]{.ru} | [чита́ют]{.ru} | [говоря́т]{.ru} | [смо́трят]{.ru} |

- 第一变位词尾元音是 [е]{.ru}，复数第三人称 [-ют]{.ru}：[де́лать, знать, гуля́ть, игра́ть, отдыха́ть, рабо́тать, слу́шать, понима́ть, разгова́ривать]{.ru}。
- 第二变位词尾元音是 [и]{.ru}，复数第三人称 [-ят]{.ru}：[говори́ть, смотре́ть, звони́ть, ви́деть, спать, лежа́ть, стоя́ть]{.ru}。
- 属于哪种变位，看生词表的 I、II 和第二人称 [-ешь]{.ru} 还是 [-ишь]{.ru}。[понима́ть]{.ru} 是第一变位，[лежа́ть]{.ru}、[спать]{.ru} 却是第二变位。
- [ж, ш, ч, щ]{.ru} 后面写 [у]{.ru}、[а]{.ru}：[лежу́, лежа́т]{.ru}。[спать]{.ru} 的第一人称是 [сплю]{.ru}，[ви́деть]{.ru} 的第一人称是 [ви́жу]{.ru}。
- [смотре́ть]{.ru} 只有第一人称重音在词尾，其余人称移到词干。

现在时既表示正在进行，也表示经常的动作：[Что ты сейча́с де́лаешь? — Я чита́ю.]{.ru} [Ве́чером они́ всегда́ гуля́ют.]{.ru} 否定 [не]{.ru} 放在动词前：[Я не зна́ю.]{.ru}

副词说明动作怎样做，[о́чень]{.ru}、[так]{.ru} 放在副词前面：

::: ex
[Актёры говоря́т так бы́стро!]{.ru}[演员们说得这么快！]{.gloss}

[А́нна говори́т ме́дленно, и я хорошо́ понима́ю.]{.ru}[安娜说得慢，我听得懂。]{.gloss}

[— Вы говори́те по-ру́сски? — Да, говорю́.]{.ru}[——您说俄语吗？——说。]{.gloss}
:::

### 八、形容词第一格与 [како́й]{.ru}（第 9 课）

| | 阳性 | 阴性 | 中性 | 复数 |
|---|---|---|---|---|
| 硬变化 | [но́вый]{.ru} | [но́вая]{.ru} | [но́вое]{.ru} | [но́вые]{.ru} |
| 重音在词尾 | [большо́й]{.ru} | [больша́я]{.ru} | [большо́е]{.ru} | [больши́е]{.ru} |
| 软变化 | [си́ний]{.ru} | [си́няя]{.ru} | [си́нее]{.ru} | [си́ние]{.ru} |
| 混合变化（[ш]{.ru}） | [хоро́ший]{.ru} | [хоро́шая]{.ru} | [хоро́шее]{.ru} | [хоро́шие]{.ru} |
| 混合变化（[к]{.ru}） | [ма́ленький]{.ru} | [ма́ленькая]{.ru} | [ма́ленькое]{.ru} | [ма́ленькие]{.ru} |
| 疑问词 | [како́й]{.ru} | [кака́я]{.ru} | [како́е]{.ru} | [каки́е]{.ru} |

形容词和名词在性、数上一致，可以作定语，也可以作谓语：

::: ex
[Э́то большо́й ста́рый го́род.]{.ru}[这是一座古老的大城市。]{.gloss}

[Моя́ ко́мната ма́ленькая и све́тлая.]{.ru}[我的房间不大，很明亮。]{.gloss}

[— Како́й э́то фильм? — Интере́сный.]{.ru}[——这是一部什么样的电影？——很有意思的。]{.gloss}

[Како́е си́нее не́бо!]{.ru}[天多么蓝啊！]{.gloss}
:::

## 课文

::: {.prose lang="ru"}
**Мои́ фо́то**

Меня́ зову́т Ван Лэй. Вот мои́ фо́то.

Э́то Кра́сная пло́щадь. Кака́я больша́я пло́щадь! А э́то Кремль. Он ста́рый и о́чень краси́вый.

Э́то моя́ ко́мната. Она́ ма́ленькая и све́тлая. Вот мой стол, мои́ кни́ги и слова́рь.

А э́то Ива́н Серге́евич, Мари́я Никола́евна, А́нна и Ми́ша. Ве́чером А́нна чита́ет, Ми́ша игра́ет, а их роди́тели смо́трят телеви́зор.

А чья э́то матрёшка? Моя́! Э́то их пода́рок.
:::

## 参考译文

::: prose-zh
**我的照片**

我叫王磊。这是我的照片。

这是红场。多么大的广场啊！这是克里姆林宫。它很古老，非常漂亮。

这是我的房间。它不大，很明亮。这是我的桌子、我的书和词典。

这是伊万·谢尔盖耶维奇、玛丽亚·尼古拉耶夫娜、安娜和米沙。晚上安娜看书，米沙玩，他们的父母看电视。

这个套娃是谁的？我的！这是他们送的礼物。
:::
