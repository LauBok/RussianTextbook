## 课文

::: {.prose lang="ru"}
В суббо́ту у́тром Мари́я Никола́евна и Ван Лэй иду́т на ры́нок. Ры́нок нахо́дится о́коло метро́. Здесь всё све́жее.
:::

::: {.dialogue lang="ru"}
[Мари́я Никола́евна]{.sp} Здра́вствуйте! Ско́лько сто́ит карто́шка?

[Продаве́ц]{.sp} Со́рок пять рубле́й килогра́мм.

[Мари́я Никола́евна]{.sp} Я беру́ два килогра́мма. Ско́лько с меня́?

[Продаве́ц]{.sp} Девяно́сто рубле́й.

[Мари́я Никола́евна]{.sp} Вот сто.

[Продаве́ц]{.sp} Вот де́сять рубле́й. Спаси́бо!
:::

::: {.prose lang="ru"}
Ван Лэй ви́дит лимо́ны и я́блоки.
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} Ско́лько сто́ят лимо́ны?

[Продаве́ц]{.sp} Три́дцать оди́н рубль шту́ка.

[Ван Лэй]{.sp} Я беру́ два лимо́на. А я́блоки?

[Продаве́ц]{.sp} Девятна́дцать рубле́й шту́ка.

[Ван Лэй]{.sp} Два я́блока, пожа́луйста. Ско́лько всего́?

[Продаве́ц]{.sp} Два лимо́на — шестьдеся́т два рубля́, два я́блока — три́дцать во́семь. Всего́ сто рубле́й.

[Ван Лэй]{.sp} Хорошо́. Вот, пожа́луйста.
:::

::: {.prose lang="ru"}
Мари́я Никола́евна говори́т: «Ван Лэй, ты уже́ хорошо́ счита́ешь по-ру́сски!» Пото́м они́ иду́т домо́й. Там их ждёт Ми́ша: он о́чень лю́бит я́блоки.
:::

## 课文注释

::: notes
1. **[Здесь всё све́жее.]{.ru}** [всё]{.ru} 是“一切”，形容词用中性：“这里样样都新鲜。”
2. **[Со́рок пять рубле́й килогра́мм.]{.ru}** 说单价时，“每公斤”“每个”直接放在价钱后面：[… рубле́й килогра́мм]{.ru}，[… рубль шту́ка]{.ru}。
3. **[Я беру́ два килогра́мма.]{.ru}** 买东西时说 [Я беру́…]{.ru}，意思是“我要……”。
4. **[Ско́лько с меня́?]{.ru}** “我该付多少钱？”字面意思是“从我这里（收）多少？”，[с]{.ru} + 第二格。
5. **[Вот сто.]{.ru}** 口语里说钱数，常省去 [рубле́й]{.ru}。
6. **[Вот, пожа́луйста.]{.ru}** 把东西、钱递给别人时说的话，“给您”。
:::

## 俄罗斯知识

### 卢布与市场

卢布是俄罗斯的货币，1 卢布等于 100 戈比。卢布是世界上最古老的货币名称之一，13 世纪的古罗斯文献里就已出现。2013 年起，卢布有了自己的符号 ₽。

现在流通的硬币有 1、2、5、10 卢布，戈比硬币很少用了，商店标价常常是整卢布。常见的纸币有 50、100、200、500、1000、2000、5000 卢布，纸币上印着俄罗斯各地城市的风景和建筑，比如 2000 卢布纸币上是符拉迪沃斯托克的跨海大桥。在大城市里，用银行卡和手机付款已经很普遍，但在市场的小摊上，现金仍然常用。

莫斯科有不少室内市场，如多罗戈米洛沃市场、达尼洛夫斯基市场。摊位上卖蔬菜、水果、肉、奶制品、蜂蜜和各地的特产，价格多按公斤标出。市场上的东西一般比超市贵，但人们喜欢它新鲜，也喜欢和熟悉的摊主聊几句。蔬菜水果有的论公斤卖，有的论个卖，买的时候要问清楚。

## 语法

### 一、数词 21–100

| 数字 | 俄语 | 数字 | 俄语 |
|---|---|---|---|
| 20 | [два́дцать]{.ru} | 70 | [се́мьдесят]{.ru} |
| 30 | [три́дцать]{.ru} | 80 | [во́семьдесят]{.ru} |
| 40 | [со́рок]{.ru} | 90 | [девяно́сто]{.ru} |
| 50 | [пятьдеся́т]{.ru} | 100 | [сто]{.ru} |
| 60 | [шестьдеся́т]{.ru} | | |

[два́дцать]{.ru}、[три́дцать]{.ru} 是“两个十”“三个十”；[пятьдеся́т]{.ru} 到 [во́семьдесят]{.ru} 是个位数加 [-десят]{.ru}，中间的 [ь]{.ru} 不能丢；[со́рок]{.ru}、[девяно́сто]{.ru}、[сто]{.ru} 不按规律构成，要单独记。

二十以上的数，十位和个位并列，中间不加连词：

::: ex
[два́дцать оди́н]{.ru}（21）　[три́дцать во́семь]{.ru}（38）　[со́рок пять]{.ru}（45）　[девяно́сто де́вять]{.ru}（99）
:::

### 二、[рубль]{.ru} 与数词连用

名词的形式看数词的**最后一个词**，规则和第 35 课相同：

| 最后一个词 | 名词形式 | 例 |
|---|---|---|
| [оди́н]{.ru} | 单数第一格 | [оди́н рубль]{.ru}，[два́дцать оди́н рубль]{.ru} |
| [два, три, четы́ре]{.ru} | 单数第二格 | [два рубля́]{.ru}，[шестьдеся́т два рубля́]{.ru} |
| [пять]{.ru} 以上，以及 11–14 | 复数第二格 | [пять рубле́й]{.ru}，[девяно́сто рубле́й]{.ru}，[оди́ннадцать рубле́й]{.ru} |

所以 [три́дцать оди́н рубль]{.ru} 用单数第一格，[со́рок пять рубле́й]{.ru} 用复数第二格。要特别注意 11–14：虽然以“一”“二”结尾，但 [оди́ннадцать]{.ru}、[двена́дцать]{.ru} 是一个词，最后一个词不是 [оди́н]{.ru}、[два]{.ru}，所以用 [рубле́й]{.ru}。

### 三、问价钱：[Ско́лько сто́ит / сто́ят?]{.ru}

[сто́ить]{.ru} 的主语是商品，动词跟主语的数一致：单数用 [сто́ит]{.ru}，复数用 [сто́ят]{.ru}。

::: ex
[— Ско́лько сто́ит карто́шка? — Со́рок пять рубле́й.]{.ru}[——土豆多少钱？——四十五卢布。]{.gloss}

[— Ско́лько сто́ят лимо́ны? — Три́дцать оди́н рубль шту́ка.]{.ru}[——柠檬多少钱？——三十一卢布一个。]{.gloss}
:::

价钱在 [сто́ит]{.ru} 后面，形式只受数词支配，与 [сто́ит]{.ru} 无关。问一共多少钱，说 [Ско́лько всего́?]{.ru} 或 [Ско́лько с меня́?]{.ru}

## 语音·语调

### 整十数词的读音

[пятьдеся́т]{.ru}、[шестьдеся́т]{.ru} 重音在最后，[се́мьдесят]{.ru}、[во́семьдесят]{.ru} 重音在前面，不要读混。[пятьдеся́т]{.ru} 中 [-ть-]{.ru} 与 [д]{.ru} 相遇读成浊的 [[дʼ]]{.tr}；[шестьдеся́т]{.ru} 的 [т]{.ru} 不发音，[с]{.ru} 读成 [[з]]{.tr}。

::: ex
[пятьдеся́т]{.ru} [[пʼиддʼисʼа́т]]{.tr}　[шестьдеся́т]{.ru} [[шыздʼисʼа́т]]{.tr}

[се́мьдесят]{.ru} [[сʼе́мʼдʼисʼът]]{.tr}　[во́семьдесят]{.ru} [[во́сʼимʼдʼисʼът]]{.tr}

[со́рок]{.ru} [[со́рък]]{.tr}　[девяно́сто]{.ru} [[дʼивʼино́стъ]]{.tr}
:::

### [ИК-4]{.ru}：接着问价钱

问完一样东西的价钱，接着问另一样，用 [а]{.ru} 加名词，读 [ИК-4]{.ru}：

::: ex
[— Ско́лько сто́ят лимо́ны? — Три́дцать оди́н рубль шту́ка. — А [я́блоки]{.ic data-n="4"}?]{.ru}

[— Всего́ сто рубле́й. — [Сто]{.ic data-n="4"}? — Да, [сто]{.ic data-n="1"}.]{.ru}
:::
