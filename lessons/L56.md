## 课文

::: {.prose lang="ru"}
Суббо́та. А́нна и Ван Лэй в большо́м магази́не. Ван Лэй уже́ купи́л тёплую оде́жду: ку́ртку, ша́пку и шарф. Тепе́рь им ну́жно купи́ть пода́рки: они́ то́же есть в спи́ске.
:::

::: {.dialogue lang="ru"}
[Ван Лэй]{.sp} А́нна, что ты пода́ришь мла́дшему бра́ту?

[А́нна]{.sp} Ма́ма и па́па да́рят Ми́ше телефо́н. А я подарю́ ему́ но́вую компью́терную игру́. А ты?

[Ван Лэй]{.sp} На́шему Ми́ше я хочу́ подари́ть футбо́льный мяч.

[А́нна]{.sp} Отли́чная иде́я!

[Ван Лэй]{.sp} А ещё мне ну́жен пода́рок моему́ дру́гу в Пеки́не. Я вы́брал вот э́тот кошелёк.

[А́нна]{.sp} Хоро́ший. Но пусто́й кошелёк дари́ть нельзя́. Тако́е пра́вило: на́до положи́ть туда́ моне́ту.

[Ван Лэй]{.sp} Почему́?

[А́нна]{.sp} Так говоря́т: тогда́ у твоего́ дру́га всегда́ бу́дут де́ньги.

[Ван Лэй]{.sp} Хорошо́, я положу́ туда́ ру́сскую моне́ту!
:::

::: {.prose lang="ru"}
Двадца́того ноября́ Ми́ша получа́ет пода́рки: телефо́н, игру́ и мяч. «Поздравля́ю!» — говори́т Ван Лэй. Пода́рки Ми́ше о́чень нра́вятся.
:::

## 课文注释

::: notes
1. **[Тепе́рь им ну́жно купи́ть пода́рки.]{.ru}** [им]{.ru} 是 [они́]{.ru} 的第三格，指安娜和王磊两人。
2. **[Ма́ма и па́па да́рят Ми́ше телефо́н.]{.ru}** 用现在时表示已经商量好、即将发生的事。
3. **[мне ну́жен пода́рок моему́ дру́гу]{.ru}** 我需要一件送给我朋友的礼物。[пода́рок]{.ru} 后面也可以接第三格，表示送给谁。
4. **[Так говоря́т]{.ru}** 没有主语的复数第三人称，泛指“人们这么说”，常用来引出民间说法。
5. **[тогда́]{.ru}** 这里是“那样的话”，表示前面做法带来的结果。
6. **[«Поздравля́ю!»]{.ru}** 单独使用，就是“祝贺你（您）！”过生日时最常说的祝贺语还有 [С днём рожде́ния!]{.ru}（生日快乐！），这个句型第 91 课讲。
:::

## 俄罗斯知识

### 送礼的讲究

安娜提醒王磊：钱包不能空着送，要放一枚硬币进去，据说这样收礼的人永远不会缺钱。俄罗斯人送礼时还有不少类似的说法：

- 刀、剪刀等锋利的东西据说会让朋友之间起争执。真要送，收礼的人会象征性地付给送礼人一枚硬币，算是“买”下来的。
- 手帕据说会带来眼泪。
- 有人认为送钟表意味着分离，这和中国“送钟”谐音“送终”的忌讳恰好相似。
- 生日礼物不提前送，祝贺也不提前说，提前祝贺被认为不吉利。米沙的礼物早就买好了，却要等到 11 月 20 日当天才送。

收到礼物时，俄罗斯人一般当着送礼人的面打开，表示高兴和感谢，这和很多中国人习惯客人走后再拆不同。到别人家做客，不空着手去，常带一束花、一盒巧克力或一个蛋糕。礼物不一定贵，重要的是用心。

这些说法很多人并不真信，但送礼时还是愿意照着做，图个吉利。

## 语法

### 一、形容词第三格

| | 阳性、中性 | 阴性 |
|---|---|---|
| 硬变化 | [но́вому]{.ru} | [но́вой]{.ru} |
| 软变化 | [си́нему]{.ru} | [си́ней]{.ru} |
| 混合变化 | [хоро́шему]{.ru}，[мла́дшему]{.ru} | [хоро́шей]{.ru}，[мла́дшей]{.ru} |
| 重音在词尾 | [большо́му]{.ru} | [большо́й]{.ru} |

阳性和中性的词尾是 [-ому]{.ru}（软变化 [-ему]{.ru}），阴性是 [-ой]{.ru}（软变化 [-ей]{.ru}）。[ж, ш, ч, щ]{.ru} 后面不带重音时写 [е]{.ru}：[хоро́шему]{.ru}，[хоро́шей]{.ru}，[мла́дшему]{.ru}。

::: ex
[Что ты пода́ришь мла́дшему бра́ту?]{.ru}[你送弟弟什么？]{.gloss}

[Я звоню́ ста́рой ба́бушке.]{.ru}[我给年迈的奶奶打电话。]{.gloss}
:::

阴性形容词的第三格和第二格、第六格同形：[но́вой]{.ru} 可以是 [у но́вой]{.ru}、[о но́вой]{.ru}、[но́вой]{.ru}（给新的……）。阳性的第三格 [-ому]{.ru} 和第二格 [-ого]{.ru} 只差一个字母，不要混：[у моего́ дру́га]{.ru}（第二格），[моему́ дру́гу]{.ru}（第三格）。

### 二、物主代词和指示代词第三格

| 第一格 | 阳性、中性第三格 | 阴性第三格 |
|---|---|---|
| [мой / моя́ / моё]{.ru} | [моему́]{.ru} | [мое́й]{.ru} |
| [твой / твоя́ / твоё]{.ru} | [твоему́]{.ru} | [твое́й]{.ru} |
| [наш / на́ша / на́ше]{.ru} | [на́шему]{.ru} | [на́шей]{.ru} |
| [ваш / ва́ша / ва́ше]{.ru} | [ва́шему]{.ru} | [ва́шей]{.ru} |
| [чей / чья / чьё]{.ru} | [чьему́]{.ru} | [чьей]{.ru} |
| [э́тот / э́та / э́то]{.ru} | [э́тому]{.ru} | [э́той]{.ru} |
| [тот / та / то]{.ru} | [тому́]{.ru} | [той]{.ru} |

[его́]{.ru}、[её]{.ru}、[их]{.ru} 作物主代词时不变：[его́ бра́ту]{.ru}，[её ма́ме]{.ru}，[их сы́ну]{.ru}。

::: ex
[На́шему Ми́ше я хочу́ подари́ть мяч.]{.ru}[我想送咱们米沙一个球。]{.gloss}

[Мне ну́жен пода́рок моему́ дру́гу.]{.ru}[我需要一件送给我朋友的礼物。]{.gloss}

[Что Ми́ша пода́рит твое́й ма́ме?]{.ru}[米沙送你妈妈什么？]{.gloss}

[— Чьему́ бра́ту ты звони́шь? — Её бра́ту.]{.ru}[——你给谁的弟弟打电话？——给她的弟弟。]{.gloss}
:::

### 三、第三格小结：“送谁什么”

[дари́ть]{.ru}、[покупа́ть]{.ru}、[дава́ть]{.ru} 等动词可以同时带两个对象：给谁（第三格）、什么（第四格）。

| 给谁（第三格） | 动词 | 什么（第四格） |
|---|---|---|
| [мла́дшему бра́ту]{.ru} | [подарю́]{.ru} | [компью́терную игру́]{.ru} |
| [на́шему Ми́ше]{.ru} | [пода́рим]{.ru} | [футбо́льный мяч]{.ru} |
| [ста́ршей сестре́]{.ru} | [покупа́ю]{.ru} | [но́вую ку́ртку]{.ru} |

这时要分清形容词的两个格：[подарю́ мла́дшему бра́ту]{.ru}（第三格 [-ому]{.ru}），[подарю́ но́вую игру́]{.ru}（第四格 [-ую]{.ru}）。

## 语音·语调

### [ИК-5]{.ru} 与 [ИК-2]{.ru}：赞叹还是提问

同样用 [како́й]{.ru} 开头，问句用 [ИК-2]{.ru}，调心在 [како́й]{.ru} 上，随后下降；赞叹用 [ИК-5]{.ru}，声调在 [како́й]{.ru} 上升起，保持在高处，到句末重读音节才下降：

::: ex
[[Како́й]{.ic data-n="2"} пода́рок ты хо́чешь?]{.ru}

[[Како́й]{.ic data-n="5"} хоро́ший [пода́рок]{.ic data-n="5"}!]{.ru}

[[Кака́я]{.ic data-n="2"} игра́ тебе́ нра́вится?]{.ru}

[[Кака́я]{.ic data-n="5"} интере́сная [игра́]{.ic data-n="5"}!]{.ru}
:::

祝贺语 [Поздравля́ю!]{.ru} 一般读 [ИК-1]{.ru}，调心音节读得重而长，声调明显下降，表示真诚：

::: ex
[[Поздравля́ю]{.ic data-n="1"}!]{.ru}
:::

## 参考译文

::: prose-zh
星期六。安娜和王磊在一家大商店里。王磊已经买好了冬衣：一件暖和的夹克、一顶帽子和一条围巾。现在他们要买礼物：礼物也在单子上。
:::

::: translation
[王磊]{.sp} 安娜，你送弟弟什么？

[安娜]{.sp} 妈妈和爸爸送米沙一部手机。我送他一个新的电脑游戏。你呢？

[王磊]{.sp} 我想送咱们米沙一个足球。

[安娜]{.sp} 好主意！

[王磊]{.sp} 我还需要一件礼物，送给我在北京的朋友。我挑了这个钱包。

[安娜]{.sp} 是不错。不过钱包不能空着送。有这么个规矩：要在里面放一枚硬币。

[王磊]{.sp} 为什么？

[安娜]{.sp} 人们都这么说：这样你的朋友就永远不缺钱。

[王磊]{.sp} 好，那我在里面放一枚俄罗斯硬币！
:::

::: prose-zh
11 月 20 日，米沙收到了礼物：手机、游戏和足球。“祝贺你！”王磊说。米沙非常喜欢这些礼物。
:::
