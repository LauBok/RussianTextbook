## 语法总表

### 一、[у кого́ есть]{.ru}；人称代词第二格

表示“某人有某物”，拥有者用 [у]{.ru} + 第二格，所有物是主语，用第一格。问“谁有”用 [у кого́]{.ru}。

| 第一格 | [я]{.ru} | [ты]{.ru} | [он, оно́]{.ru} | [она́]{.ru} | [мы]{.ru} | [вы]{.ru} | [они́]{.ru} |
|---|---|---|---|---|---|---|---|
| 第二格 | [меня́]{.ru} | [тебя́]{.ru} | [его́]{.ru} | [её]{.ru} | [нас]{.ru} | [вас]{.ru} | [их]{.ru} |
| 前置词后 | [у меня́]{.ru} | [у тебя́]{.ru} | [у него́]{.ru} | [у неё]{.ru} | [у нас]{.ru} | [у вас]{.ru} | [у них]{.ru} |

::: ex
[— У тебя́ есть брат? — Да, есть.]{.ru}[——你有兄弟吗？——有。]{.gloss}

[У него́ есть соба́ка.]{.ru}[他有一条狗。]{.gloss}

[У неё большо́й сад.]{.ru}[她的园子很大。]{.gloss}
:::

第三人称代词在前置词后面加 [н-]{.ru}：[у него́, у неё, у них]{.ru}；物主代词“他的”“她的”不加：[его́ соба́ка]{.ru}。重点在所有物怎么样、而不是有没有时，[есть]{.ru} 省去。

### 二、名词单数第二格

| 第一格词尾 | 第二格词尾 | 例词 |
|---|---|---|
| 阳性硬辅音、中性 [-о]{.ru} | [-а]{.ru} | [брат → бра́та]{.ru}，[окно́ → окна́]{.ru} |
| 阳性 [-й]{.ru}、[-ь]{.ru}，中性 [-е]{.ru} | [-я]{.ru} | [музе́й → музе́я]{.ru}，[слова́рь → словаря́]{.ru}，[мо́ре → мо́ря]{.ru} |
| [-а]{.ru}（阴性和 [па́па]{.ru} 类阳性） | [-ы]{.ru}（[г к х ж ш щ ч]{.ru} 后 [-и]{.ru}） | [сестра́ → сестры́]{.ru}，[па́па → па́пы]{.ru}，[ба́бушка → ба́бушки]{.ru} |
| [-я]{.ru}、[-ь]{.ru}（阴性） | [-и]{.ru} | [семья́ → семьи́]{.ru}，[тетра́дь → тетра́ди]{.ru} |
| [-ия]{.ru} | [-ии]{.ru} | [Мари́я → Мари́и]{.ru}，[Фра́нция → Фра́нции]{.ru} |

元音脱落的词随第二格一起记：[оте́ц → отца́]{.ru}，[кита́ец → кита́йца]{.ru}。不变格名词不变：[метро́, фо́то]{.ru}。

### 三、第二格的用法

| 用法 | 例句 |
|---|---|
| [нет]{.ru} + 第二格：没有，不在 | [У меня́ нет бра́та.]{.ru} [Ми́ши нет до́ма.]{.ru} |
| [не́ было]{.ru} + 第二格：过去没有 | [Ра́ньше здесь не́ было телеви́зора.]{.ru} |
| 名词 + 第二格：表示所属 | [маши́на отца́]{.ru}，[альбо́м семьи́]{.ru} |
| [у кого́]{.ru}：在某人那里，某人有 | [У ба́бушки есть да́ча.]{.ru} |
| [из / с]{.ru} + 第二格：从哪里来 | [Я из Кита́я.]{.ru} [Хосе́ с Ку́бы.]{.ru} |
| [о́коло, напро́тив, до, по́сле, без]{.ru} + 第二格 | [напро́тив па́рка]{.ru}，[по́сле шко́лы]{.ru} |
| 数词 2–4 + 单数第二格 | [два бра́та]{.ru}，[две сестры́]{.ru} |
| [ско́лько]{.ru} + 第二格 | [Ско́лько вас в семье́?]{.ru} |

**肯定与否定。** [есть]{.ru} 句的所有物是主语，用第一格；换成 [нет]{.ru}、[не́ было]{.ru}，所有物改用第二格，句子没有主语，[бы́ло]{.ru} 一律用中性：

| 现在 | 过去 |
|---|---|
| [У неё есть сестра́.]{.ru} | [У неё была́ сестра́.]{.ru} |
| [У неё нет сестры́.]{.ru} | [У неё не́ было сестры́.]{.ru} |

**语序。** 表示所属的第二格放在被修饰的名词后面：“爸爸的车”是 [маши́на па́пы]{.ru}，不说 [па́пы маши́на]{.ru}。

**[из]{.ru} 还是 [с]{.ru}。** 所在用 [в]{.ru} 的，来处用 [из]{.ru}；所在用 [на]{.ru} 的，来处用 [с]{.ru}：

| [где?]{.ru} | [отку́да?]{.ru} |
|---|---|
| [в Кита́е, в Каза́ни, в Япо́нии]{.ru} | [из Кита́я, из Каза́ни, из Япо́нии]{.ru} |
| [на Ку́бе, на да́че, на уро́ке]{.ru} | [с Ку́бы, с да́чи, с уро́ка]{.ru} |

**支配第二格的前置词。** [у]{.ru} 紧挨着，在某人那里；[о́коло]{.ru} 在附近；[напро́тив]{.ru} 在对面；[до]{.ru} 到……，在……以前；[по́сле]{.ru} 在……以后；[без]{.ru} 没有，不带。

::: ex
[Наш дом напро́тив па́рка, а апте́ка о́коло метро́.]{.ru}[我们家在公园对面，药店在地铁站附近。]{.gloss}

[По́сле шко́лы Ми́ша игра́ет в футбо́л.]{.ru}[放学以后米沙踢足球。]{.gloss}

[Я не могу́ жить без футбо́ла!]{.ru}[我没有足球活不了！]{.gloss}
:::

### 四、形容词、物主代词、指示代词第二格

| 第一格 | 阳性、中性第二格 | 阴性第二格 |
|---|---|---|
| [но́вый, но́вое / но́вая]{.ru} | [но́вого]{.ru} | [но́вой]{.ru} |
| [си́ний, си́нее / си́няя]{.ru} | [си́него]{.ru} | [си́ней]{.ru} |
| [большо́й, большо́е / больша́я]{.ru} | [большо́го]{.ru} | [большо́й]{.ru} |
| [хоро́ший, хоро́шее / хоро́шая]{.ru} | [хоро́шего]{.ru} | [хоро́шей]{.ru} |
| [мой, моё / моя́]{.ru} | [моего́]{.ru} | [мое́й]{.ru} |
| [наш, на́ше / на́ша]{.ru} | [на́шего]{.ru} | [на́шей]{.ru} |
| [э́тот, э́то / э́та]{.ru} | [э́того]{.ru} | [э́той]{.ru} |
| [его́, её, их]{.ru} | 不变 | 不变 |

::: ex
[Э́то дом моего́ ста́ршего бра́та.]{.ru}[这是我哥哥的房子。]{.gloss}

[Ка́тя — студе́нтка медици́нского институ́та.]{.ru}[卡佳是医学院的学生。]{.gloss}

[Апте́ка о́коло на́шего до́ма.]{.ru}[药店在我们家附近。]{.gloss}
:::

形容词、代词跟名词的性走，不看词尾：[моего́ па́пы]{.ru}，[на́шего де́душки]{.ru}。[ж ш ч щ ц]{.ru} 后不重读的 [о]{.ru} 写成 [е]{.ru}：[хоро́шего, ста́ршей]{.ru}。[-ого]{.ru}、[-его]{.ru} 里的 [г]{.ru} 读 [[в]]{.tr}。

### 五、数词与名词连用

| 数词 | 13–20 | 30–100 |
|---|---|---|
| | [трина́дцать, четы́рнадцать, пятна́дцать, шестна́дцать, семна́дцать, восемна́дцать, девятна́дцать, два́дцать]{.ru} | [три́дцать, со́рок, пятьдеся́т, шестьдеся́т, се́мьдесят, во́семьдесят, девяно́сто, сто]{.ru} |

名词的形式看数词的**最后一个词**：

| 最后一个词 | 名词形式 | 例 |
|---|---|---|
| [оди́н, одна́, одно́]{.ru} | 单数第一格 | [оди́н сын, одна́ дочь]{.ru}，[три́дцать оди́н рубль]{.ru} |
| [два / две, три, четы́ре]{.ru} | 单数第二格 | [два бра́та, две сестры́]{.ru}，[шестьдеся́т два рубля́]{.ru} |
| [пять]{.ru} 以上，11–14 | 复数第二格 | [пять челове́к, пять часо́в, пятна́дцать рубле́й]{.ru} |

[челове́к]{.ru}、[час]{.ru}、[рубль]{.ru} 的三种形式要背熟：

| 名词 | 1 | 2–4 | 5–20 |
|---|---|---|---|
| [челове́к]{.ru} | [челове́к]{.ru} | [челове́ка]{.ru} | [челове́к]{.ru} |
| [час]{.ru} | [час]{.ru} | [часа́]{.ru} | [часо́в]{.ru} |
| [рубль]{.ru} | [рубль]{.ru} | [рубля́]{.ru} | [рубле́й]{.ru} |

问价钱：[Ско́лько сто́ит карто́шка?]{.ru} [Ско́лько сто́ят лимо́ны?]{.ru} 动词跟商品的数一致。

### 七、带 [-ся]{.ru} 的动词

| 人称 | [занима́ться]{.ru} | [учи́ться]{.ru} |
|---|---|---|
| [я]{.ru} | [занима́юсь]{.ru} | [учу́сь]{.ru} |
| [ты]{.ru} | [занима́ешься]{.ru} | [у́чишься]{.ru} |
| [он, она́]{.ru} | [занима́ется]{.ru} | [у́чится]{.ru} |
| [мы]{.ru} | [занима́емся]{.ru} | [у́чимся]{.ru} |
| [вы]{.ru} | [занима́етесь]{.ru} | [у́читесь]{.ru} |
| [они́]{.ru} | [занима́ются]{.ru} | [у́чатся]{.ru} |
| 过去时 | [занима́лся, занима́лась, занима́лись]{.ru} | [учи́лся, учи́лась, учи́лись]{.ru} |

辅音后加 [-ся]{.ru}，元音后加 [-сь]{.ru}。[-ся]{.ru} 动词不带第四格宾语：[Учи́тель начина́ет уро́к]{.ru}，但 [Уро́к начина́ется]{.ru}。[-ться]{.ru}、[-тся]{.ru} 读 [[цъ]]{.tr}。

| 动词 | 意思 | 例句 |
|---|---|---|
| [учи́ться]{.ru} | 在某校读书 | [Ми́ша у́чится в шко́ле.]{.ru} |
| [занима́ться]{.ru} | 用功，自习 | [Ве́чером я занима́юсь в библиоте́ке.]{.ru} |
| [учи́ть]{.ru} + 第四格 | 学、背具体的东西 | [Я учу́ но́вые слова́.]{.ru} |
| [находи́ться]{.ru} | 位于 | [Ры́нок нахо́дится о́коло метро́.]{.ru} |

### 八、语调：[ИК-4]{.ru}

对方回答以后，接着问另一个人或另一样东西，用带 [а]{.ru} 的不完全疑问句，读 [ИК-4]{.ru}；问“有没有”读 [ИК-3]{.ru}，调心落在 [есть]{.ru} 上。

::: ex
[— У тебя́ [есть]{.ic data-n="3"} брат? — Нет. — А [сестра́]{.ic data-n="4"}?]{.ru}

[— Я из Кита́я. А [вы]{.ic data-n="4"}?]{.ru}

[— Ско́лько сто́ит карто́шка? — Со́рок пять рубле́й. — А [я́блоки]{.ic data-n="4"}?]{.ru}
:::

## 课文

::: {.prose lang="ru"}
**Моя́ ру́сская семья́**

Я живу́ в кварти́ре Ива́на Серге́евича и Мари́и Никола́евны. Их дом нахо́дится напро́тив па́рка, а о́коло па́рка — метро́ и ры́нок. А́нна у́чится в университе́те, как я, а Ми́ша у́чится в шко́ле.

У меня́ нет бра́та и нет сестры́: в семье́ я оди́н. А у А́нны и Ми́ши есть ба́бушка. Она́ живёт на да́че. Там нет интерне́та, но есть лес и река́. Ве́чером мы смотре́ли ста́рый альбо́м ба́бушки. Вот маши́на её отца́, а вот Ива́н Серге́евич. Тогда́ он был ма́льчик, и у него́ не́ было компью́тера.

В гру́ппе О́льги Ви́кторовны пятна́дцать челове́к. Пьер из Фра́нции, Ю́ми из Япо́нии, Хосе́ с Ку́бы, а я из Кита́я. По́сле уро́ка я занима́юсь в библиоте́ке.

В суббо́ту я ходи́л на ры́нок.
:::

[Продаве́ц]{.sp} Два́дцать оди́н рубль шту́ка.

[Ван Лэй]{.sp} Три я́блока, пожа́луйста.

[Продаве́ц]{.sp} Шестьдеся́т три рубля́.
:::

::: {.prose lang="ru"}
До́ма меня́ ждал Ми́ша: он о́чень лю́бит я́блоки. Сейча́с у меня́ в Москве́ есть и сестра́, и брат.
:::

## 参考译文

::: prose-zh
**我的俄罗斯家庭**

我住在伊万·谢尔盖耶维奇和玛丽亚·尼古拉耶夫娜家。他们家在公园对面，公园旁边是地铁站和市场。安娜和我一样在大学读书，米沙上中学。

我没有兄弟，也没有姐妹：我是独生子。安娜和米沙有奶奶。她住在别墅。那里没有网，但是有树林和河。晚上我们看了奶奶的老相册。这是她父亲的汽车，这是伊万·谢尔盖耶维奇。那时他还是个小男孩，他没有电脑。

奥尔加·维克托罗夫娜的班上有十五个人。皮埃尔来自法国，由美来自日本，何塞来自古巴，我来自中国。下课以后我在图书馆自习。

星期六我去了市场。
:::
