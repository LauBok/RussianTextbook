# 前言

第一册从零起步，学完达到 A2（ТРКИ 基础级），共 108 课，累计词汇约 1300。

## 语音入门

前 8 课单独讲字母和发音，用 8 课学完 33 个字母和基本读音规则。每个字母给出印刷体、手写体、名称、国际音标和发音要领，每课附手写体练习格。材料只用单词和短句，示例词只含已学字母。这一部分不要赶进度：俄语的读音规则很整齐，前 8 课读准了，以后见到生词就能读出来。

## 正课

正课 100 课分 10 个单元，每单元第 10 课是复习课。课文是一个连续的故事：中国留学生王磊九月来到莫斯科，住进彼得罗夫家，上课、交朋友、过节、旅行，学期结束后回国过寒假。

| 单元 | 语法核心 |
|---|---|
| 一 初到莫斯科 | 名词的性、复数第一格、动词两种变位、形容词第一格 |
| 二 开学 | 第六格、过去时 |
| 三 日常生活 | 第四格、基础运动动词 |
| 四 家人与朋友 | 第二格、数词 1–100 |
| 五 计划与时间 | 将来时、动词体的基本对立、时间与日期 |
| 六 喜好与需要 | 第三格、无人称句 |
| 七 兴趣与职业 | 第五格 |
| 八 城市与出行 | 运动动词的过去时与将来时 |
| 九 生活与健康 | 简单复合句、间接引语 |
| 十 节日与告别 | 综合复习；假定式、限定代词、否定代词 |

课文从 30 词左右的短对话起步，逐单元加长到 250 词左右；前三个单元以对话为主，第四单元起叙述逐步增多。

## 本册的特点

- 课文、例句和生词全部标重音。重音位置没有固定规则，每个词都要连同重音一起记。
- 每课有一节“语音·语调”，讲解俄语的五种基本调型和读音规则。
- 每课有一节“俄罗斯知识”，从课文细节引出，讲俄罗斯的名字与父称、住房、饮食、节日、学校、交通和名胜。
- 每篇课文配一张插图，画课文里的一个场景。

## 测试

除了每单元的单元测试，第 50 课后有期中测试，全册最后有期末测试，满分各 150 分。
