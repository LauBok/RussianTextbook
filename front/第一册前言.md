# 前言

本册为《俄语教程》第一册，供零起点学习者使用，学完可达到 A2 级（对外俄语等级考试基础级）。全册共 108 课，包括语音入门 8 课和正课 100 课，累计词汇约 1300 个。

## 语音入门

前 8 课专讲字母和发音，系统介绍 33 个字母和基本读音规则。每个字母列出印刷体、手写体、名称、国际音标和发音要领，每课附手写体练习。材料限于单词和短句，示例词只含已学字母。俄语读音规则较为整齐，初学阶段读音准确，日后遇到生词便能正确拼读，故学习这一部分宜从容，不宜求速。

## 正课

正课分为 10 个单元，每单元第 10 课为复习课。课文以中国留学生王磊的留学生活为线索：九月抵达莫斯科，寄住于彼得罗夫家，此后上课、交友、过节、旅行，学期结束后回国度寒假。各单元的语法重点如下：

| 单元 | 语法重点 |
|---|---|
| 一 初到莫斯科 | 名词的性、复数第一格、动词两种变位、形容词第一格 |
| 二 开学 | 第六格、过去时 |
| 三 日常生活 | 第四格、基础运动动词 |
| 四 家人与朋友 | 第二格、数词 1–100 |
| 五 计划与时间 | 将来时、动词体的基本对立、时间与日期的表达 |
| 六 喜好与需要 | 第三格、无人称句 |
| 七 兴趣与职业 | 第五格 |
| 八 城市与出行 | 运动动词的过去时与将来时 |
| 九 生活与健康 | 简单复合句、间接引语 |
| 十 节日与告别 | 综合复习；假定式、限定代词、否定代词 |

课文篇幅由 30 词左右的短对话逐步增至 250 词左右。前三个单元以对话为主，第四单元起叙述的比重逐步增加。

## 本册特点

本册课文、例句和生词一律标注重音。俄语重音位置不固定，每个词均须连同重音一并记忆。每课设“语音·语调”一节，讲解俄语的五种基本调型和读音规则；设“俄罗斯知识”一节，由课文细节引出，介绍俄罗斯人的姓名与父称、住房、饮食、节日、学校、交通和名胜。每篇课文配插图一幅，描绘课文中的一个场景。

## 测试

除各单元的单元测试外，本册于第 50 课后设期中测试，全册末设期末测试，满分各 150 分。
