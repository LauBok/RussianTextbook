# 前言

第二册接第一册，学完达到 B1（ТРКИ 一级），共 72 课，新增词汇约 1000，累计约 2300。开始学习前，先做书前的入册复习测试：答对 80% 以上可直接学习本册，否则按测试解析回到第一册相关的课复习。

## 内容

全册 8 个单元，每单元第 9 课是复习课。故事接着第一册：王磊二月回到莫斯科，读第二学期，和新同学迪马成为朋友，五月去喀山、沿伏尔加河旅行，六月考试，七月回国。各单元的“俄罗斯知识”与当月的节日和季节对应。

| 单元 | 语法核心 |
|---|---|
| 一 新学期 | 复数第二格、数量表达 |
| 二 朋友们 | 名词、形容词、代词复数各格 |
| 三 春天 | 代词的完整变格、比较级与最高级、短尾形容词 |
| 四 学习 | 动词体的系统用法、变位难点 |
| 五 五月假期 | 定向与不定向运动动词、带前缀的运动动词及其转义 |
| 六 生活与人 | 各类主从复合句 |
| 七 考试周 | 数词变格、不定代词与否定代词、无人称动词、被动结构初识 |
| 八 夏天 | 引语转换、语气词、构词初识、形动词和副动词的形式 |

第二册学完，俄语的变格和变位体系就完整了。形动词和副动词只在最后一个单元认识形式，系统讲解在第三册。

## 本册的特点

- 课文以叙述为主，对话嵌在叙述中，每篇 200–300 词，仍然全文标重音。
- 不再单设语音·语调，读音例外放进生词注音和课文注释。
- 写作成为每课必做的练习：第一、二单元把课文缩写成 50–80 词的一段，第三单元起增加 100–150 词的作文，第五单元起增加书信写作。
