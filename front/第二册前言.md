# 前言

本册为《俄语教程》第二册，供学完第一册的学习者使用，学完可达到 B1 级（对外俄语等级考试一级）。全册共 72 课，新增词汇约 1000 个，累计约 2300 个。开始学习之前，宜先完成书前的入册复习测试：正确率达到 80% 者可直接学习本册，未达到者依据测试解析复习第一册相关各课。

## 内容

全册分为 8 个单元，每单元第 9 课为复习课。课文接续第一册的故事：王磊于二月返回莫斯科，开始第二学期的学习，结识俄罗斯同学迪马，五月赴喀山并沿伏尔加河旅行，六月参加考试，七月回国。各单元的“俄罗斯知识”与当月的节日和季节相对应。各单元的语法重点如下：

| 单元 | 语法重点 |
|---|---|
| 一 新学期 | 复数第二格、数量的表达 |
| 二 朋友们 | 名词、形容词、代词复数各格 |
| 三 春天 | 代词的完整变格、比较级与最高级、短尾形容词 |
| 四 学习 | 动词体的系统用法、变位难点 |
| 五 五月假期 | 定向与不定向运动动词、带前缀的运动动词及其转义 |
| 六 生活与人 | 各类主从复合句 |
| 七 考试周 | 数词变格、不定代词与否定代词、无人称动词、被动结构初步 |
| 八 夏天 | 引语转换、语气词、构词初步、形动词和副动词的形式 |

学完本册，俄语的变格和变位体系即告完整。形动词和副动词在最后一个单元仅作形式上的初步认识，系统讲解见第三册。

## 本册特点

本册课文以叙述为主，对话融入叙述之中，每篇 200–300 词，仍全文标注重音。本册不再单设语音·语调一节，读音例外在生词注音和课文注释中说明。写作练习为每课必做：第一、二单元将课文缩写为 50–80 词的段落，第三单元起增设 100–150 词的作文，第五单元起增设书信写作。
